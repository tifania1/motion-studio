# 광고 영상 검수

대상: $ARGUMENTS (비어 있으면 `python tools/list.py` 로 가장 최근 영상을 묻거나 고릅니다)

1. `python tools/check.py <영상>` 실행.
2. `python tools/build.py <영상>` 후 `python tools/render.py <영상> all sheet`, `python tools/render.py <영상> tall sheet --safe`.
3. sheet 를 모두 Read로 열어 아래를 확인합니다.
   - 글자가 잘리거나 겹치지 않는지, 세이프존(빨간 영역)에 글자·버튼이 없는지
   - 사진 초점이 피사체에 맞는지(특히 9:16), 전환 중 빈 화면이 길지 않은지
   - 오탈자, 띄어쓰기, 어색한 문장, 대조 구문("~가 아닙니다, ~입니다")
   - 브랜드 notes 규칙, 근거 없는 최상급·효능 표현, 지어낸 후기·평점, 실제와 다른 가격·혜택
   - CC BY 사진의 화면 출처 표시, 참고 사진 표시, 협찬이면 광고 표시
   - 사실 정보(영업시간, 가격, 수상 등)는 검색으로 다시 확인
4. 문제를 심각한 순서로 정리해 보고합니다(장면 시각, 형식, 고칠 방법). 사용자가 고쳐 달라고 하면 고치고 다시 sheet 로 확인합니다.
