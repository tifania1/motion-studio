# 빛 관이 휘감는 소품 터짐 (3D·사물)

한 줄: 검은 바탕에서 실사 셀카가 같은 구도의 평면 일러스트로 바뀌고, 굵은 빛 관이 카드와 문장을 한 바퀴 휘감고 지나가요. 끝에는 마크 둘레로 말랑한 3D 소품이 톡 터져 나왔다가 다시 빨려 들어가요.

## 보는 느낌
- 뼈대는 거의 검은 화면이에요. 글은 작게, 가운데 한 줄만. 그 사이사이 색이 가득한 장면(분홍·노랑 판 위 폰, 일러스트 세계, 카드 격자)이 컷으로 끼어들어요.
- 이야기의 축은 '사진이 그림이 된다'예요. 같은 구도의 실사와 평면 일러스트를 연달아 붙여서 변신을 보여 줘요.
- 화면을 잇는 끈은 굵은 빛 관 하나. 짧은 변의 4~6% 두께로, 끝이 둥글고 안쪽이 밝게 빛나서 3D 튜브처럼 보여요. 한 장면에 관은 하나만.
- 일러스트 세계 장면에서는 그림을 꽉 채우고, 가운데 젖빛으로 흐린 흰 글 한 줄만 얹어요.
- 끝은 다시 검은 화면, 둥근 마크 글자와 그 둘레에 흩어진 3D 소품들.

## 색
- 검정 바탕 55 · 일러스트·사진 장면의 색 35 · 흰 글자 7 · 빛 관 3.
- 바탕 #0E0E0F, 글자 #F2F2F0.
- 빛 관: 앞쪽은 파랑 #3E86E8, 뒤쪽은 민트 #4FD8C4(accent). 관 둘레에 같은 색 빛 번짐 한 겹.
- 폰 장면 판: 분홍 #E48AD3(paper), 노랑 #F5D23C 을 컷마다 번갈아.
- 빛나는 문장 하나는 글자 안을 무지개(하늘 → 연두 → 노랑) 그라디언트로 채우고 빛을 번지게 해요. 영상에서 한 번만.

## 글자
- Geist 600(한글은 Noto Sans KR Bold), 자간 −0.015em. 문장은 짧은 변의 6~7%로 작고 단정하게.
- 마크 글자는 둥글고 통통하게 보이도록 Geist 800 에 글자 사이를 살짝 좁혀요.
- 문장은 커서 없이 한 글자씩 찍혀 나와요(초당 14자 안팎). 한 화면에 한 줄, 길어도 다섯 어절.
- 일러스트 위 글자는 흰색 90% + 뒤에 아주 옅은 흰 흐림 띠를 깔아 그림 위에서도 읽혀요.

## 질감과 모양
- 질감은 따로 얹지 않아요. 깨끗한 검정과 선명한 그림이 대비돼요.
- 카드: 둥근 정사각, 모서리 2.2u. 젖빛 유리 카드는 흰 12% + 블러 + 1px 흰 테두리 30%, 아래에 부드러운 그림자.
- 3D 소품: 반들반들한 장난감 질감(연필, 돋보기, 전구, 손 커서, 꽃, 하트 말풍선 같은 창작 도구 모양). 원본 캐릭터 대신 우리 소품을 써요.
- 빛 관: SVG path, stroke-linecap round, 두 겹(밝은 안쪽 선 + 넓고 흐린 바깥 선).

## 움직임
- 115BPM, power3.out. 들어오는 건 빠르게, 머무는 건 1~2박.
- 사진 → 일러스트 변신은 박에 맞춘 컷. 그 뒤 카드로 오므라드는 건 0.5초.
- 빛 관은 그어지는 앞머리와 지워지는 꼬리가 같이 움직여서 '지나가는' 느낌을 줘요(0.8~1.1초).
- 카드 무리는 3D 공간에 흩어져 깊이를 달리해 떠 있다가, 소용돌이를 그리며 한가운데로 모여 작아져요.
- 소품 터짐은 M.spring 'bouncy' 로 튀어나오고, 떠 있는 동안 ±4도로 살랑, 거둘 땐 0.4초에 마크 쪽으로 빨려 들어가요.

## 전환
- 컷이 기본. 유리 카드 → 실사 장면은 흐림(blur)으로 녹여 넘기고, 카드 격자로 들어갈 땐 밀어내기(push).
- 장면 쌓기: cut → blur → push → cut.

## 대표 장면
1. **사진이 그림으로, 관이 감싸며**
   ```
   // 분홍 판 위 폰 속 실사 → 같은 구도 일러스트로 한 박에 컷
   S.ambient(t => {
     photo.style.visibility = t < M.beat(2) ? 'visible' : 'hidden';
     toon.style.visibility  = t < M.beat(2) ? 'hidden' : 'visible';
     const k = M.spring(t - M.beat(4), 'smooth');           // 일러스트가 둥근 카드로 오므라듦
     M.box(card, {x: M.lerp(0, cx - s/2, k), y: M.lerp(0, cy - s/2, k), w: M.lerp(W, s, k), h: M.lerp(H, s, k)});
     const head = M.ease.outCubic(M.prog(t, M.beat(4.5), .9));
     const tail = M.ease.inCubic(M.prog(t, M.beat(5.2), .7));
     M.draw(tube, head, tail);                               // 관이 아래에서 솟아 카드 둘레를 감고 빠짐
   });
   ```
2. **문장을 휘감는 민트 나선**
   - 검은 화면 가운데 문장을 `M.type(text, t, t0, 14)` 로 찍고, 문장 둘레를 한 바퀴 도는 나선 path(바깥 선 `filter: blur(.8u)` + 안쪽 밝은 선)를 `M.draw(spiral, head, tail)` 로 0.9초에 지나가게 해요. 관이 문장 앞을 지날 때만 z 순서를 문장 위로 올려 '감는' 깊이를 줘요.
3. **카드 무리 소용돌이**
   - 카드 12~16장을 `M.rng(7)` 로 3D 위치(x, y, z)에 흩고 부모에 perspective. `a = t * 1.2 + i`, 반지름 `r = M.anim([[0, W * .6], [t1, 0, {d: 1.2, e: 'inCubic'}]], t)` 로 줄이며 `M.place(c, cx + cos(a) * r, cy + sin(a) * r * .5, {s: .4 + z})`. 다 모이면 컷으로 검은 화면.
4. **마크 둘레 소품 터짐**
   - 마크 글자를 `S.chars` 로 한 자씩 0.06초 간격 톡. 이어 소품 i 를 마크 중심에서 바깥 자리 (xi, yi) 로 `k = M.spring(t - t0 - i * .03, 'bouncy')`, `M.place(p, M.lerp(cx, xi, k), M.lerp(cy, yi, k), {s: k, r: Math.sin(t * 2 + i) * 4})`. 1.5초 뒤 같은 식을 거꾸로 0.4초에 돌려 빨아들이고 마크만 남겨요. 장면 쌓기에선 deco shapes·orb 가 이 자리를 대신해요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 창작·그림 도구 런칭, AI 이미지·아바타 서비스, 앱 브랜드 공개, 젊은 크리에이터 커뮤니티, 사진 꾸미기 기능 소개.
- 피할 것: 밝은 흰 바탕만 쓰기, 가는 세리프, 빽빽한 표·숫자, 느린 페이드만 이어 붙이기, 관 선을 여러 개 동시에 쓰기(관은 한 장면에 하나라서 눈길이 따라가요).
