# 격자 색띠와 픽셀 고정폭 (그래픽·도형)

한 줄: 옅은 회색 격자 칸을 따라 보라·자홍·연두·하늘 색띠가 미끄러져 들어와 굵은 둥근 고딕 문장을 품어요. 숯빛 판에서는 블록 커서가 고정폭 대문자 이름을 치고, 5×5 픽셀 칸이 한 칸씩 물드는 브랜드 설명 필름이에요.

## 보는 느낌
- 바탕은 아주 옅은 회색에 그보다 살짝 짙은 가는 격자 선. 칸이 커서(화면 너비의 5분의 1쯤) 눈에 거의 안 띄다가, 색띠가 칸에 맞춰 놓일 때 비로소 질서가 보여요.
- 모든 도형은 모서리가 각진 직사각형이고 반드시 격자 선에 붙어요. 원색 띠는 얇게(칸 높이의 4분의 1), 옅은 색 칸은 한 칸을 통째로, 보라 띠는 여러 칸을 덮을 만큼 넓게.
- 화면이 꽉 차는 순간과 텅 빈 순간이 번갈아 와요. 띠들이 모여 문장을 품었다가 다 빠지고 나면 격자와 작은 낱말 하나만 남아요.
- 중간에 숯빛 판으로 넘어가 고정폭 이름표와 작은 픽셀 아이콘만 두는 조용한 구간이 있고, 다시 밝은 판으로 돌아와 픽셀 칸과 큰 숫자로 이어져요.

## 색
- 밝은 회색 70 · 보라 15 · 원색 띠 10 · 글자 5.
- 바탕 #EDEDED, 격자 선 먹색 7%.
- 보라 #6A3AE8 이 주인공. 넓은 띠, 화면 전체 바탕, 큰 숫자, 마지막 마크에 써요. 보라 위 글자는 흰색.
- 원색 띠: 자홍 #E040D8, 연두 #4FD93A, 하늘 #3FA9EE. 각각 옅게 푼 색(연한 분홍·연두·하늘)으로 한 칸을 칠하기도 해요.
- 진홍 #D9264A 는 위험·문제를 말하는 낱말 하나에만.
- 숯빛 판 #1C2128, 그 위 이름표는 옅은 회색 #ECEDEF.

## 글자
- 큰 문장·낱말: Geist 700(한글은 Noto Sans KR Bold·Black). 둥글고 기하학적인 고딕, 자간 −0.03em 으로 빽빽하게, 소문자 위주. 띠 안 문장은 왼쪽 정렬 두 줄, 짧은 변의 9~11%.
- 화면 하나를 채우는 낱말(한 낱말만 있을 때)은 짧은 변의 22% 안팎, 가운데.
- 작은 낱말·이름표: Geist Mono 400~500 대문자, 자간 +0.15em, 짧은 변의 2.5~3%. 밝은 판에선 회색, 숯빛 판에선 옅은 회색.
- 큰 숫자: Geist 700, 쉼표 뒤 자간을 조금 벌려요. 아래에 가는 줄 하나와 고정폭 대문자 두 줄 설명.
- 한 화면에 큰 글 크기는 하나만.

## 질감과 모양
- 질감 없이 매끈한 평면. 그레인·비네트·그림자 모두 쓰지 않아요.
- 모서리 0, 테두리 없음. 도형은 칠한 면으로만.
- 픽셀 아이콘은 5×5 칸 안에서 작은 정사각형을 켜고 끄는 방식. 칸 사이 틈은 칸 크기의 10%.
- 점 아이콘은 그보다 더 작은 네모 점(짧은 변의 0.8%)을 칸 간격으로 늘어놓아 십자·화살·집 모양을 짓고, 한가운데 네모 하나만 크게.

## 움직임
- 108BPM. 띠 하나가 들어오는 데 0.5초, 박에 맞춰 시차를 두고 들어와요.
- 이징은 `power3.inOut`. 띠는 한쪽 끝을 격자 선에 고정한 채 길이만 늘었다 줄어들어요(위치는 칸에서 벗어나지 않음).
- 큰 문장은 띠가 다 펼쳐진 뒤 줄마다 선 아래에서 올라와요(mask). 한 박 반쯤 머물고 띠와 함께 접혀요.
- 작은 회색 고정폭 낱말은 그대로 두고 아래 큰 낱말만 2박마다 컷으로 갈아요.
- 블록 커서는 반 박마다 깜빡이고, 글자는 초당 14자쯤 쳐져요.
- 픽셀 칸은 칸마다 0.06초 간격으로 무작위 순서대로 켜져요.

## 전환
- 밝은 판 사이는 색띠가 쓸고 지나가는 와이프(wipe)가 기본. 보라 띠가 화면을 다 덮었다가 그대로 보라 바탕 장면이 되기도 해요.
- 숯빛 판으로는 컷, 숫자 장면 사이는 밀어내기(push). 서서히 빠지는 전환은 쓰지 않아요.
- 장면 쌓기: wipe → cut → push.

## 대표 장면

1. 격자 색띠가 문장을 품기
   ```
   // 칸 크기 c, 띠마다 [칸 x, 칸 y, 칸 너비, 칸 높이, 들어오는 박]
   const c = W / 5;
   bands.forEach(([el, gx, gy, gw, gh, b]) => {
     const k = M.ease.inOutCubic(M.prog(t, M.beat(b), .5));
     M.box(el, { x: gx * c, y: gy * c, w: gw * c * k, h: gh * c });  // 왼쪽 끝은 격자 선에 고정
   });
   // 보라 띠(3칸 넓이)가 다 펼쳐지면 흰 문장이 줄마다 올라옴
   S.fx.mask(headline, { at: M.beat(3), stagger: .12 });
   ```
   나갈 땐 같은 식에서 k 를 1 → 0 으로 거꾸로, 띠마다 반 박씩 엇갈려 접어요.
2. 회색 고정폭 낱말 아래 진홍 낱말 갈기
   - 가운데 위쪽에 Geist Mono 회색 작은 낱말 하나를 고정하고, 그 아래 큰 굵은 낱말을 `M.at([[t0, '첫말'], [t0 + M.beat(2), '둘째말']], t)` 로 컷 교체. 큰 낱말만 진홍.
   - 다음 장면은 보라 띠가 화면 전체를 쓸어(`S.tr.wipe`) 보라 바탕 위 흰 낱말 하나로.
3. 숯빛 판 블록 커서 이름표
   ```
   const txt = M.type(name, t, t0, 14);              // 고정폭 대문자, 자간 .15em
   label.textContent = txt;
   cursor.style.opacity = (Math.floor(t / M.beat(.5)) % 2) ? 1 : 0;
   // 오른쪽 5×5 픽셀 아이콘: 칸마다 0.06초 간격으로 켜짐
   cells.forEach((q, i) => q.style.opacity = M.prog(t, t0 + order[i] * .06, .01));
   ```
   이름이 바뀔 때마다 커서·아이콘 색을 자홍 → 하늘 → 보라로 컷 교체해요.
4. 픽셀 칸 물들기 → 큰 숫자 → 점 아이콘 행진
   - 가운데 5×5 칸을 `M.rng(시드)` 로 섞은 순서대로 한 색의 농담 네 단계로 채우고, 2박 뒤 같은 순서로 다른 색에 바꿔 칠한 다음 빈 칸 윤곽만 남겨요.
   - 이어 보라 큰 숫자가 count 로 올라가고(scenes.number), 가는 줄이 가운데서 양쪽으로 `M.draw` 로 그어진 뒤 고정폭 설명 두 줄.
   - 끝 무렵엔 작은 네모 점 아이콘 4개를 가로로 늘어놓고, 박마다 하나씩 점 배치를 `M.at` 으로 바꿔 모양을 갈아요. 마지막엔 보라 마크와 블록 커서 하나만 남아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발자 도구·보안 서비스 브랜드 설명, 제품 라인업 하나씩 훑기, 성과 숫자 보여 주기, 회사 소개·채용 영상, 1분 안팎 브랜드 필름.
- 피할 것: 둥근 모서리 카드와 그림자, 그라디언트와 빛 번짐, 종이·그레인 같은 질감, 세리프와 손글씨, 사진과 3D 소품, 격자 칸을 벗어난 비스듬한 배치.
- 한글 큰 문장은 두 줄 안쪽으로 짧게. 띠 하나에 문장 하나만 담아야 칸의 질서가 살아요.
