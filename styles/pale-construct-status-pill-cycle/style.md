# 설계선 상태 알약 (제품 UI)

한 줄: 옅은 회색 위에서 낱말 하나가 머리카락 같은 설계선으로 풀려요. 선이 모여 알약 하나가 되고, 그 알약이 한자리에서 대기, 실행 중, 검토, 완료로 색과 아이콘을 바꾼 뒤 표 속 한 칸으로 물러나는 조용한 기능 소개.

## 보는 느낌
- 무늬 없는 옅은 회색 판 한가운데에 요소가 늘 하나만 있어요. 낱말 하나, 그다음엔 알약 하나. 나머지는 전부 여백이에요.
- 사이사이 '짓는 과정'이 보여요. 아주 가는 회색 선(먹색 8~15%)이 격자와 원, 타원을 그리고 작은 고정폭 치수 숫자가 붙어요. 도면이 비스듬히 기운 채 천천히 미끄러져서 깊이가 살짝 느껴져요.
- 화면 양옆에 세로 안내선 두 쌍이 아주 옅게 남아 있어 판이 설계된 공간처럼 보여요.
- 마지막엔 바짝 붙은 표와 대시보드가 나오고, 카메라가 물러나면 그 화면이 회색 판 위에 떠 있는 카드가 돼요.

## 색
- 옅은 회색 85 · 먹 회색 글자 10 · 상태색 5.
- 바탕 #ECECEC, 글자 #3A3F47(검정이 아닌 짙은 청회색), 설계선은 같은 색 8~15%.
- 상태색은 알약에만 써요. 대기는 회색 칠 #DEDEDE에 회색 글자, 검토는 연파랑 #D4E3F3에 파랑 #2E5A88, 완료는 연초록 #DDF0DF에 초록 #3E8E4F.
- 상태색 둘이 한 화면에 같이 나오지 않아요. 표 장면에서만 작은 알약들이 여러 색으로 섞여요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold) 하나로. 첫 낱말은 굵기 600, 짧은 변의 9% 안팎, 자간 −0.02em.
- 알약 글은 굵기 500, 짧은 변의 4~5%. 알약 높이는 글자 높이의 2.2배, 옆 여백은 글자 높이만큼.
- 설계선의 치수 숫자와 열 머리글은 Geist Mono 400, 아주 작게(짧은 변의 1.8%) 옅은 회색으로.
- 정렬은 늘 가운데, 한 줄.

## 질감과 모양
- 질감 없이 매끈하게. 그레인·비네트 없음.
- 알약은 완전한 둥근 끝(높이의 절반). 테두리 없이 칠만, 그림자 없음.
- 설계선은 1px, 끝이 열린 긴 선. 원과 타원은 알약보다 훨씬 크게 화면을 가로질러요.
- 마지막 카드만 모서리 1.2u, 아주 옅고 넓은 그림자 하나.

## 움직임
- 80BPM, 느림. 대부분 `power3.inOut`. 한 상태가 3초 정도 머물러요.
- 낱말은 0.8초 페이드로 들어와 2초 머물고, 흐려지며 설계선 아래로 가라앉아요.
- 설계선은 한 줄씩 0.6~1초에 그어지고, 도면 전체가 6초 동안 짧은 변의 4%쯤 비스듬히 흘러요.
- 상태가 바뀔 때 알약 너비는 0.6초에 새 글 길이로, 칠과 글자색은 같은 시간에 번지듯 바뀌어요. 글은 흐림을 끼고 겹쳐 바뀌어요.
- '실행 중' 고리는 1.2초에 한 바퀴씩 계속 돌아요.

## 전환
- 서서히(fade)가 기본이고, 낱말 → 설계선 → 알약처럼 결이 바뀌는 곳에서는 흐림(blur)으로 녹여 이어요. 컷은 쓰지 않아요.
- 장면 쌓기: fade → blur → fade.

## 대표 장면

1. 낱말이 설계선으로 풀림
   ```
   const lines = S.$$('.guide path');                 // 가로세로선, 큰 원, 타원 8~12개
   S.ambient(t => {
     M.place(word, cx, cy, { o: 1 - M.prog(t, 4.6, .9), blur: M.prog(t, 4.6, .9) * 6 });
     lines.forEach((p, i) => M.draw(p, M.ease.inOutCubic(M.prog(t, 5 + i * .35, .8))));
     M.place(plan, cx - u * 4 * M.prog(t, 5, 6), cy, { r: -8 });   // 기운 도면이 천천히 흐름
   });
   ```
   치수 숫자는 Geist Mono 로 선 끝에 붙여 선이 다 그어질 때 0.3초에 페이드.
2. 선이 모여 알약이 됨
   - 큰 원과 가로선을 `M.anim` 으로 알약 윤곽 자리까지 좁히고, 알약 모양 `path` 를 `M.draw` 로 0.8초에 그은 뒤 안쪽 칠 투명도를 0 → 1. 설계선은 그 사이 `o` 1 → 0 으로 사라져요.
3. 한자리 상태 바꾸기
   ```
   const states = [[13, 'idle'], [18, 'run'], [21, 'review'], [24, 'done']];
   S.ambient(t => {
     const s = M.at(states, t), k = M.ease.inOutCubic(M.prog(t, startOf(s), .6));
     M.box(pill, { x: cx - w / 2, y, w: M.lerp(wPrev, wNext, k), h });
     pill.style.background = M.color(fillPrev, fillNext, k);
     spinner.style.transform = `rotate(${t * 300}deg)`;      // 실행 중일 때만 보임
   });
   ```
   글은 앞 글 `blur` 0 → 4px·`o` 1 → 0, 새 글 그 반대로 겹쳐 바꿔요. 아이콘(빈 원 → 고리 → 빈 원 → 체크)도 같은 방식.
4. 표 한 칸으로 물러남
   - 완료 알약 위에 작은 머리글을 0.5초 페이드, 알약은 `M.spring(t - t0, 'smooth')` 로 표 칸 크기까지 줄어요. 표와 대시보드는 그 둘레로 흐림에서 맺히고, 판 전체를 `M.place(board, cx, cy, { s: M.anim([[t1, 2.2], [t1 + 4, .8, { e: 'inOutCubic' }]], t) })` 로 물러나게 해 떠 있는 카드로 마무리. 장면 사이는 `S.tr.blur`.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 작업 흐름·자동화 도구 소개, 상태 표시·진행 추적 기능 공개, 개발·데이터 도구의 한 기능 짚기, 차분한 B2B 제품 런칭.
- 피할 것: 빠른 컷, 진한 색면 바탕, 그레인·종이 같은 질감, 한 화면에 요소 여러 개를 한꺼번에 띄우기, 굵고 큰 글자 쇼, 강조색을 넓게 칠하기.
- 낱말이 짧을수록 잘 살아요. 상태 이름은 두세 어절 안으로.
