# 코발트 두께 라벨과 소품 (3D·사물)

한 줄: 쨍한 코발트 판과 옅은 회색 판을 오가요. 형광 그라디언트를 칠하고 검은 두께가 붙은 낱말 라벨이 톡톡 놓이면, 둘레로 3D 소품이 떠서 돌고 비스듬히 누운 앱 카드와 폰이 천천히 몸을 돌리는 기능 소개예요.

## 보는 느낌
- 바탕은 두 장뿐이에요. 가운데가 살짝 밝아지는 쨍한 코발트 판과, 아주 옅게 푸른 기가 도는 회색 판. 장면마다 둘을 번갈아 써요.
- 회색 판에서는 낱말 라벨 두 줄이 주인공이에요. 라벨 둘레로 3D 소품이 흩어져 떠 있어서 진열장이나 장난감 상자처럼 보여요.
- 코발트 판에서는 앱 카드나 폰 한 대가 주인공이에요. 화면의 40~60%만 차지하게 두고 둘레는 비워 둬요. 라벨은 폰 옆에 붙어요.
- 오프닝은 코발트 위 흰 대문자 한 낱말로 시작해요. 그 앞으로 철사 그물 공 같은 소품이 솟으면 낱말은 뒤로 흐려져요.
- 엔딩은 옅은 회색 위 알약 하나. 넓은 여백에 아무것도 두지 않아요.

## 색
- 코발트 장면: 코발트 #1E2BE8 70 · 흰 카드·폰 20 · 형광 라벨 10.
- 회색 장면: 회색 #E6E7EE 75 · 라벨과 소품 20 · 먹 #101330 5.
- 라벨 그라디언트는 두 벌이에요. 연두 #8CF26A → 하늘 #7FD3FF, 분홍 #F2A7E0 → 연보라 #C9B8FF → 버터 #FFF1A8. 라벨 하나에는 한 벌만 써요.
- 라벨 글자와 두께는 먹색 #101330. 카드 속 확인 표시와 그래프 선만 초록이에요.
- 소품은 코발트·흰색·형광 연두로 칠하고, 철사 그물이나 테두리는 짙은 남색 가는 선으로 그려요.

## 글자
- 큰 낱말과 라벨: Archivo 800, 너비 105~110%로 살짝 넓게, 자간 −0.02em. 한글은 Noto Sans KR Black. 둥글고 통통한 그로테스크 느낌.
- 라벨 글자 크기는 짧은 변의 7~9%. 한 줄에 한두 어절만 써요. 두 줄은 왼쪽 끝을 맞추지 않고 0.3~0.6칸 엇갈려 놓아요.
- 손글씨 낱말: Caveat 700, 한글은 나눔손글씨 펜. 검은 글자에 흰 테두리 0.15em, −10~+8도 기울기. 라벨 한 묶음에 하나만 붙여요.
- 앱 카드·폰 속 글: Geist 500~700, 작게.
- 엔딩 알약 글: Archivo 700, 짧은 변의 3.5%, 가운데 정렬.

## 질감과 모양
- 그레인 없이 매끈하게 가요. 코발트 판에 비네트 0.22만 얹어서 가운데가 밝아 보이게 해요.
- 라벨: 모서리 1.6u, 먹색 1.5px 테두리. 오른쪽 아래로 검은 판을 하나 더 깔아 두께를 만들어요(짧은 변의 1.2%만큼 어긋나게).
- 카드·폰: 흰색, 모서리 2~3u, 아래로 부드러운 그림자 한 겹. 3D로 비스듬히 눕혀요.
- 소품: 반들한 무광 플라스틱 결. 동전·고리는 옆면이 보일 만큼 두껍게.

## 움직임
- 112BPM. 라벨은 반 박(약 0.27초) 간격으로 하나씩 들어와요.
- 라벨은 `back.out(1.6)`로 0.4초에 크기 0.6→1로 톡 튀어나오고, 이후에는 rotateY ±12도, rotateX ±6도로 4초 주기로 천천히 흔들려요.
- 소품은 나타날 때 스프링으로 튀어 오르고, 떠 있는 동안 각자 다른 속도로 돌아요(한 바퀴 6~10초). 위아래로 2u 안팎 둥실거려요.
- 카드·폰은 화면 밖 아래에서 비스듬히 0.8초에 올라오며 rotateY 30도 → 15도로 풀려요. 머무는 동안에도 아주 천천히 돌아요.
- 한 장면은 2~3초 머물러요.

## 전환
- 회색 ↔ 코발트는 컷이 기본이에요.
- 카드가 다음 카드로 바뀔 때는 옆으로 휙(whip). 오프닝 낱말 뒤로는 흐림(blur)으로 깊이를 줘요.
- 장면 쌓기: cut → whip → blur → cut.

## 대표 장면

1. 흐려지는 낱말과 솟는 철사 공
   ```
   // 코발트 판, 흰 대문자 한 낱말
   S.ambient(t => {
     const k = M.spring(t - 1.6, 'bouncy');            // 1.6초에 소품 등장
     M.place(word, cx, cy, { s: 1 + t * .02, blur: M.anim([[0, 0], [1.6, 6, { d: .5 }]], t) });
     M.place(globe, cx, cy + (1 - k) * H * .4, { s: .6 + k * .4, ry: t * 40 });
   });
   // 철사 공: SVG 원 + 위도·경도 타원 path, 아래에 남색 받침 원통
   ```
2. 낱말 라벨 두 줄과 도는 소품
   ```
   // 라벨 = 그라디언트 판 + 뒤에 검은 두께 판, 어절마다 하나씩
   labels.forEach((lb, i) => {
     const ti = .2 + i * M.beat(.5);
     S.fx.pop(lb, { at: ti, ease: 'back.out(1.6)', from: .6 });
   });
   S.ambient(t => {
     labels.forEach((lb, i) => lb.style.transform =
       `perspective(900px) rotateY(${Math.sin(t * 1.6 + i) * 12}deg) rotateX(${Math.cos(t * 1.2 + i) * 6}deg)`);
     props.forEach((p, j) => M.place(p, p.x, p.y + Math.sin(t + j) * U * 2, { r: t * (20 + j * 7), z: p.depth }));
   });
   // 손글씨 낱말 하나: clipPath inset 으로 왼쪽부터 0.4초에 써짐
   ```
3. 비스듬히 도는 앱 카드
   ```
   const k = M.spring(t - .2, 'smooth');
   card.style.transform = `perspective(1200px) translateY(${(1 - k) * 60}%) rotateY(${30 - k * 15 + Math.sin(t * .5) * 3}deg) rotateZ(-6deg)`;
   M.draw(chartPath, M.ease.outCubic(M.prog(t, .8, 1.2)));   // 초록 선 그래프
   // 버튼이 눌리면(1박 뒤) S.tr.whip 으로 다음 카드
   ```
   장면 쌓기에서는 frame: phone 으로 폰 화면을 띄우고, title: pop 으로 옆 라벨 낱말이 톡톡 놓여요.
4. 알약 엔딩
   - 옅은 회색 판 가운데 코발트 알약. 안의 문장을 `M.type(text, t, .3, 24)` 로 쳐 나가고, 다 쳐지면 알약 너비를 `M.box` 로 문장에 맞춰 늘린 뒤 배경색을 `M.color('#1E2BE8', '#8CF26A', k)` 로 0.3초에 바꿔요(글자는 흰색에서 먹색으로). 다음 박에 컷으로 로고 판.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱 기능 소개, 새 기능 런칭, 사용 단계 안내(고르기·누르기·입력하기), 핀테크·예측·투표 서비스, 젊은 브랜드 광고.
- 피할 것: 손그림 종이 질감, 어두운 시네마틱 톤, 가는 세리프, 한 화면에 라벨 세 줄 넘게, 한 라벨에 그라디언트 두 벌 섞기.
- 한글은 두세 글자 어절을 라벨 하나에 담으면 판이 통통하게 살아요.
