# 반원 줄무늬 브랜드 접점 (그래픽·도형)

한 줄: 둥근 머리 기둥에 줄무늬 그라디언트를 채운 무늬 하나가 앱 아이콘, SNS 카드, 웹 화면, 폰·노트북으로 박자마다 옮겨 다니다가 밝은 회색 위 검정 마크 하나로 맺혀요.

## 보는 느낌
- 주인공은 무늬 하나예요. 위가 반원인 세로 기둥을 촘촘히 늘어놓고, 기둥마다 세로 그라디언트를 채워요. 기둥을 45도로 눕히면 사선 띠 바탕이 되고, 아래쪽 끝을 흰색으로 녹이면 빗살처럼 보여요.
- 이 무늬가 장면마다 다른 그릇에 담겨요. 검은 둥근 사각 아이콘 속, SNS 카드 격자의 타일, 어두운 웹 화면 뒤로 비치는 띠, 폰과 노트북 화면, 옷 등판 프린트까지. 같은 무늬가 어디에 놓여도 한 브랜드로 읽히는 게 핵심이에요.
- 어두운 장면(웹 화면, 3D 반원 고리)과 밝은 장면(회색 위 카드, 사진)을 번갈아 놓아 리듬을 만들어요.
- 3D 장면도 같은 모양에서 나와요. 반원 고리를 무지개 띠로 칠하거나, 둥근 머리를 두껍게 밀어내 한 줄로 늘어선 덩어리로 만들어요.
- 끝은 아무 무늬 없는 밝은 회색 한가운데 검정 마크와 이름. 앞의 화려함과 대비돼서 오래 남아요.

## 색
- 밝은 장면: 회색 70 · 무늬 20 · 검정 글자 10. 어두운 장면: 먹색 65 · 무늬 25 · 흰 글자 10.
- 바탕 회색 #ECECEA, 어두운 판 #1E1E1F, 글자 #1C1C1C.
- 무늬 색: 분홍 #E3337F → 주황빨강 #E8452C → 노랑 #F4D23C, 하늘 #3FA8E0 → 라일락 #D9D1E6. 한 무늬 안에서는 따뜻한 쪽이나 차가운 쪽 한 줄기만 써요.
- 첫 장면은 옅은 라일락 #D9D1E6 한 색으로 비워 두고 시작해요.
- 강조색 분홍은 꼬리표·버튼에만, 그 위 글자는 흰색.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 기하학적인 산세리프를 중간 굵기 500 으로, 자간 −0.02em.
- 큰 제목은 짧은 변의 8~10%, 두 줄 안쪽. 웹 화면 안 글자는 작게, 왼쪽 정렬.
- 카드 위 문구는 굵기 500, 흰색 또는 검정 한 가지. 검은 꼬리표 상자 안에 흰 글자로 넣으면 발표 느낌이 나요.
- 마지막 이름은 짧은 변의 12% 안팎, 마크와 같은 높이로 나란히.

## 질감과 모양
- 화면 위에 덧씌우는 질감은 없어요. 무늬는 매끈한 그라디언트, 카드는 부드러운 그림자 한 겹.
- 모서리 2.2u. 아이콘은 더 둥글게(지름의 22%).
- 기둥 머리는 완전한 반원(border-radius 999px 999px 0 0), 기둥 사이 틈은 없거나 아주 얇게.
- 사진 장면(가죽, 돌, 옷감)은 어둡고 결이 거친 소재를 골라서 매끈한 무늬가 돋보이게 해요.

## 움직임
- 116BPM. 장면은 대부분 2박(약 1초)마다 컷.
- 컷 안에서는 카메라가 천천히 다가가요(1초에 2~4%, power3.out). 아이콘은 한 번 크게 다가가요(0.8배 → 1.15배).
- 기둥은 반 박 간격으로 아래에서 솟고, 안의 그라디언트는 4초 주기로 위아래로 흘러요.
- 카드는 아래에서 2u 올라오며 나타나고, 두 장이면 0.15초 차이로 엇갈려 겹쳐요.
- 마지막 마크는 움직이지 않고 그대로 머물러요.

## 전환
- 컷이 기본이에요. 무늬 바탕이 옆으로 밀려나며 카드가 들어올 때만 밀어내기(push), 사선 띠가 화면을 쓸고 지나가며 다음 장면이 드러날 때 와이프(wipe).
- 장면 쌓기: cut → push → wipe.

## 대표 장면
1. **솟아오르는 반원 기둥 무늬**
   ```
   const cols = S.$$('.arch');   // 둥근 머리 기둥 12개, 세로 그라디언트, background-size 100% 200%
   S.ambient(t => {
     cols.forEach((c, i) => {
       const k = M.ease.outCubic(M.prog(t, i * M.beat(.5) * .5, .5));
       M.place(c, W * (i + .5) / cols.length, H * .62 + (1 - k) * H * .5);
       c.style.backgroundPosition = `0 ${50 + Math.sin(t * Math.PI / 2 + i * .4) * 30}%`;
     });
   });
   ```
   장면 쌓기에서는 title: mask 로 제목이 줄마다 선 아래에서 올라오고, deco shapes 가 반원·원 조각을 흩어 둬요.
2. **사선 띠 위 아이콘이 다가오기**
   - 바탕은 `repeating-linear-gradient(45deg, …)` 로 하늘·라일락 띠를 깔고 `background-position` 을 `t * 2u` 씩 밀어 천천히 흘러가게 해요.
   - 가운데 검은 둥근 사각 아이콘 안에 기둥 무늬를 작게 넣고 `M.place(icon, cx, cy, {s: M.anim([[0, .8], [.1, 1.15, {d: 1, e: 'inOutCubic'}]], t)})`.
   - 아이콘 속 모양은 우리 브랜드 마크나 단순한 반원 둘로 새로 그려요.
3. **같은 무늬, 다른 그릇**
   ```
   const shots = S.$$('.shot');  // 아이콘 · SNS 카드 격자 · 어두운 웹 화면 · 폰 · 노트북
   S.ambient(t => {
     const i = M.at(shots.map((_, k) => [k * M.beat(2), k]), t);
     shots.forEach((s, k) => s.style.visibility = k === i ? 'visible' : 'hidden');
     const local = t - i * M.beat(2);
     M.place(shots[i], cx, cy, {s: 1 + M.ease.outCubic(Math.min(local / M.beat(2), 1)) * .03});
   });
   ```
   웹 화면 장면은 어두운 창(frame: card) 뒤에 세로 띠 무늬를 흐리게 비치게 하고, 폰 장면은 빨강→노랑 빗살(아래 끝을 흰색으로 녹인 기둥)을 화면에 채워요. 밀어서 바꿀 땐 `S.tr.whip`, 띠로 쓸 땐 `S.tr.blocks`.
4. **무늬를 걷고 마크로 맺기**
   - 컷으로 밝은 회색 #ECECEA. 가운데 마크와 이름을 한 번에 놓고(`o` 0 → 1, 0.2초) 2~3초 그대로 둬요. 기둥이나 띠는 하나도 남기지 않아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 리브랜딩 공개, 브랜드 시스템·가이드 소개, 투자 유치·새 기능 발표, 스타트업 런칭 티저, 굿즈·접점 쇼케이스.
- 피할 것: 손그림 선, 종이·그레인 질감, 장면마다 다른 무늬 모양 섞기(무늬는 하나여야 해요), 긴 문장, 느린 서서히 전환만 쓰기.
- 무늬 색은 한 장면에 따뜻한 줄기나 차가운 줄기 하나만 써야 깔끔해요.
