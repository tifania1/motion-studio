# 문자 말풍선 앱 짓기 (제품 UI)

한 줄: 아주 옅은 회색 화면에 점 세 개 입력 중 말풍선이 맥박치다 글자 말풍선으로 부풀어요. 대화가 쌓이면 아래에서 폰이 솟아 그 대화창이 되고, 회색 받은 말과 파란 보낸 말이 오가는 사이 앱이 지어져 라임 판 위 폰 세 대로 펼쳐지는 런칭이에요.

## 보는 느낌
- 바탕은 무늬 없는 옅은 회색 한 장. 처음 1초는 그냥 비워 둬서, 그다음 생기는 작은 말풍선 하나에 눈이 모여요.
- 주인공은 문자 말풍선이에요. 앞부분엔 화면 한가운데 두세 개만 크게 쌓이고(말풍선 높이가 화면의 10~12%), 폰이 들어온 뒤엔 대화창 크기로 줄어 왼쪽 회색·오른쪽 파랑으로 나뉘어요.
- 폰은 화면 아래에서 반쯤 잘린 채 솟아오르고, 카메라가 화면 안으로 바짝 다가가 테두리는 양옆에 가는 기둥처럼만 남아요. 대화가 길어지면 카메라가 말풍선을 따라 위로 흘러요.
- 마지막에 딱 한 번 색이 바뀌어요. 연두에서 흰빛으로 번지는 라임 판 위에 폰 세 대가 부채꼴로 서요. 그다음 회색 판으로 돌아와 마크 글자 하나로 닫아요.

## 색
- 회색 바탕 80 · 말풍선(회색·파랑) 15 · 글자 5. 라임은 마지막 폰 판에만, 화면 가득.
- 바탕 #EDEDED, 받은 말풍선 #E2E2E4(글자 #1C1C1E), 보낸 말풍선 #4A9BE6(글자 흰색).
- 장면 쌓기의 강조색은 글자 대비를 맞춘 짙은 파랑 #1A72CC, 글자는 흰색. 실제 말풍선을 그릴 땐 밝은 파랑 #4A9BE6 을 써요.
- 입력 중 점은 #9A9A9E, 맥박칠 때 #6E6E73 까지 진해져요. '읽음' 꼬리표·시간은 회색 60%.
- 라임 판: #D6EC6A 에서 위쪽 #F2F6E4 로 번지는 세로 그라디언트.

## 글자
- Geist 500(한글은 Noto Sans KR Medium). 말풍선 안 글자만 있고 따로 큰 제목은 거의 없어요.
- 앞부분 큰 말풍선 글자는 짧은 변의 5~6%, 대화창 안은 3~3.5%. 자간 −0.01em, 한 말풍선에 한 줄.
- 대화창 위 상대 이름은 Noto Sans KR Bold 작게, 옆에 작은 꺾쇠.
- 엔딩 마크 글자: 앞 몇 글자는 Instrument Serif 이탤릭, 나머지는 Geist 400 으로 이어 한 낱말처럼. 짧은 변의 9% 안팎, 먹색.

## 질감과 모양
- 질감 없이 매끈하게. 그레인·비네트 모두 쓰지 않아요.
- 말풍선은 알약에 가까운 둥근 사각(모서리 2.2u). 받은 말은 왼쪽 아래, 보낸 말은 오른쪽 아래에 작은 꼬리. 그림자 없이 평평하게.
- 입력 중 말풍선은 꼬리 대신 작은 원 두 개(큰 원·더 작은 원)가 왼쪽 아래에 붙어요.
- 폰은 은빛 얇은 테두리, 화면 흰색, 위에 섬 모양 노치와 9:41 상태 막대. 폰과 카드에만 아주 옅은 그림자 하나.

## 움직임
- 100BPM, 말풍선 하나가 대략 1박~2박.
- 말풍선은 0.3초에 크기 0.6 → 1로 톡(back.out(1.5)), 위치는 꼬리 쪽을 기준점으로 커져요.
- 입력 중 점 셋은 0.2초 간격으로 차례로 진해졌다 옅어지며 1~2초 맥박치고, 글자 말풍선으로 바뀔 땐 같은 자리에서 너비가 0.35초에 늘어나며 글이 나타나요.
- 새 말풍선이 오면 위의 것들은 0.4초에 한 칸 밀려 올라가요(power2.out).
- 보낸 말풍선은 글 없이 빈 파란 알약이 먼저 뜨고, 반 박 뒤 너비가 맞춰지며 글이 채워져요.
- 카메라는 대화를 따라 위로 천천히 흐르고, 장면 끝에 살짝 물러나 폰 윗부분까지 보여 줘요.

## 전환
- 말풍선 장면에서 폰 장면으로는 폰이 아래에서 밀어 올라오는 밀어내기(push). 말풍선은 끊기지 않고 대화창 안으로 이어져요.
- 링크 카드에서 라임 폰 판으로는 컷, 폰 판에서 마크 글자로는 짧은 페이드.
- 장면 쌓기: push → cut → fade.

## 대표 장면
1. **입력 중 말풍선이 글자로 부풀기**
   ```
   const k = M.spring(t - t0, 'snappy');
   M.place(typing, cx, cy, {s: .6 + .4 * k, o: k});
   dots.forEach((d, i) => d.style.opacity = .45 + .55 * Math.max(0, Math.sin((t - i * .2) * Math.PI * 1.6)));
   // t1 에 같은 자리에서 글자 말풍선으로
   const w = M.anim([[0, wDots], [t1, wText, {d: .35, e: 'outBack'}]], t);
   M.box(bubble, {x: cx - w / 2, y: cy - h / 2, w, h});
   label.style.opacity = M.prog(t, t1 + .15, .2);
   ```
   다음 말이 오면 앞 말풍선들 y 를 `M.anim` 으로 한 칸(말풍선 높이 × 1.25)씩 올리고, 아래에 새 입력 중 말풍선을 같은 식으로 띄워요.
2. **말풍선 더미 아래에서 솟는 폰**
   - 폰을 화면 아래 밖에 두고 `M.place(phone, cx, M.anim([[0, H * 1.3], [tP, H * .62, {d: .9, e: 'inOutCubic'}]], t))`. 이어 카메라 묶음을 `s: 1 → 1.8` 로 키워 화면 안으로 들어가요.
   - 앞서 뜬 말풍선들은 같은 순간 크기를 줄이며 대화창 왼쪽 자리로 옮겨 가요(`M.anim` 으로 x·y·s 를 함께). 장면 쌓기에서는 frame: phone + deco: bubbles 로 같은 결을 얻어요.
3. **빈 파란 알약 → 글 채우기와 위로 흐르는 카메라**
   ```
   const k = M.spring(t - tS, 'snappy');
   M.place(sent, xRight, y, {s: .6 + .4 * k, o: k});            // 빈 알약
   const w = M.anim([[0, wEmpty], [tS + M.beat(.5), wText, {d: .3, e: 'outCubic'}]], t);
   sentText.textContent = t > tS + M.beat(.5) ? text : '';
   camY = M.anim(rows.map((r, i) => [r.t, -i * rowH, {d: .5, e: 'outCubic'}]), t);
   ```
   마지막 보낸 말 아래 '읽음 09:41' 꼬리표는 `o` 만 0.3초에 켜요.
4. **링크 카드 → 라임 판 위 폰 세 대 → 마크 글자**
   - 대답 말풍선 아래 카드(앱 화면 축소판과 제목 두 줄)를 `M.spring` 으로 띄운 뒤 컷.
   - 라임 그라디언트 판에 폰 셋을 두고 양옆은 ±14°로 기울여 가운데 폰 뒤에 반쯤 숨겨요. 묶음 전체를 4초에 `s: 1 → 1.06` 으로 천천히 다가가요.
   - `S.tr.blur` 로 짧게 넘기거나 페이드한 뒤, 회색 판 가운데 이탤릭 세리프+산세리프 마크 글자를 `o: 0 → 1` 로만 띄우고 오래 머물러요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 대화형 AI·챗봇 런칭, 문자로 쓰는 서비스 소개, 앱 만들기·자동화 도구, 고객 응대 흐름 시연, 짧은 기능 티저.
- 피할 것: 어두운 바탕, 질감·그레인, 강조색 여러 개(파랑 하나와 마지막 라임만), 굵고 큰 제목, 빠른 컷 몽타주.
- 말풍선 글은 한 줄로 짧게(한글 4~12자) 써야 대화 리듬이 살아요.
