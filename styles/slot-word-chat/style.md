# 한 단어 갈아끼우기 (타이포)

한 줄: 아주 옅은 회색 바탕에 채팅 말풍선과 한 줄 문장만. 문장 속 한 단어 자리만 색을 바꿔 가며 갈아끼워서 "이것도, 이것도 돼요"를 짧게 말해요.

## 보는 느낌
- 거의 빈 화면에 한 가지씩만. 말풍선 하나, 카드 묶음 하나, 문장 한 줄, 로고 하나.
- 화면 전체가 아주 천천히 비스듬히 흘러서(M.drift) 멈춘 듯하면서도 살아 있어요.
- 12초 안팎의 짧은 티저에 맞는 속도. 장면마다 2~3초.

## 색
- 바탕 90 · 글자 7 · 강조 3.
- 바탕 #EBEBEB, 글자 #111111. 사용자 말풍선은 남색(#1F4E7E) + 흰 글자, 상대 말풍선은 바탕보다 한 단계 짙은 회색(#DCDCDC) + 먹색 글자.
- 갈아끼우는 단어 색: 파랑 #2C8BE8 → 주황 #F06A1D → 초록 #22C36A. 단어 색 말고는 강조를 쓰지 않아요.

## 글자
- 반듯한 고딕 Regular~Medium(Geist + Noto Sans KR 500). 굵게 쓰지 않아요.
- 문장 크기는 짧은 변의 5% 안팎, 한 줄, 가운데 정렬. 한국어는 "○○가 이제 [찾아요]"처럼 자리 단어를 문장 끝 가까이에 두면 다시 맞춰지는 움직임이 잘 보여요.
- 말풍선 글자는 짧은 변의 2.6%, 두 줄까지.

## 질감과 모양
- 질감 없음.
- 말풍선 모서리 2.2u, 꼬리 없음. 카드는 흰 바탕, 모서리 1.2u, 그림자 0 1u 3u rgba(0,0,0,.12).
- 로고 표시는 검은 원 + 흰 반사 한 줄처럼 아주 단순한 도형이 어울려요(브랜드 로고로 바꿔 씀).

## 움직임
- 120BPM, 1박 0.5초. 카드 쌓기는 반 박보다 빠르게(0.2초 간격), 단어 바꾸기는 1박 남짓.
- 어절 등장: 하나씩 0.15초 간격으로 fade + 아래에서 0.3em. 문장이 늘 때마다 줄 전체가 M.spring 'snappy' 로 가운데를 다시 찾음.
- 어절 퇴장: 뒤에서부터 하나씩 0.12초 간격으로 사라지고 남은 문장이 다시 가운데로. 마지막 한 단어만 회색으로 남겨 다음 장면에 넘겨도 좋아요.
- 로고: 원이 0.3초에 커지고 반 박 쉬었다가 작아지며 왼쪽으로 비켜서고, 이름이 어절 단위로 붙음.

## 전환
- 전부 컷. 빈 바탕에서 다음 요소가 바로 나타나는 식이라 컷이 오히려 매끄러워요.

## 대표 장면

1. 말풍선 + 작업 중 (0~1.8초)
   - 남색 말풍선이 아래에서 0.3초 올라오고, 왼쪽 아래에 작은 아이콘 + "작업 중이에요" 회색 글자.
   - 반짝이: `background: linear-gradient(90deg, 회색 0 40%, 흰색 50%, 회색 60% 100%)`, `background-clip: text`, S.ambient 로 background-position-x = ((t * 0.83) % 1) * 200 + '%'.
2. 카드 부채꼴 (1.8~3.2초)
   ```
   cards.forEach((c, i) => {
     const k = M.spring(t - (t0 + i * .2), 'snappy');
     M.place(c, x0 + i * 4 * u, y0 + i * 3 * u, { s: .96 + .04 * k, o: M.prog(t, t0 + i * .2, .08) });
   });
   ```
3. 단어 자리 갈아끼우기 (5.5~8초)
   ```
   const words = ['찾아요', '읽어요', '정리해요'], colors = ['#2C8BE8', '#F06A1D', '#22C36A'];
   const i = M.at([[t0, 0], [t0 + .6, 1], [t0 + 1.2, 2]], t), ti = t0 + i * .6;
   slot.textContent = words[i]; slot.style.color = colors[i];
   const gap = M.spring(t - ti - .08, 'snappy');           // 0 → 1
   slot.style.margin = `0 ${(.28 * gap).toFixed(3)}em`;     // 공백이 벌어짐
   slot.style.opacity = t - ti < .08 ? 0 : 1;
   // 줄은 text-align:center 라서 공백이 벌어지는 만큼 문장 전체가 저절로 다시 가운데로 맞춰져요
   ```
4. 로고 마무리 (8.5~11초)
   - 원 표시 pop(0.3초) → 1박 머무름 → 지름 60%로 줄며 왼쪽으로 → 이름 어절이 하나씩 붙음.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI·챗봇 기능 소개, 할 수 있는 일 여러 개를 짧게 나열, 10~15초 티저, 앱 업데이트 공지.
- 피할 것: 굵은 장식 글꼴, 배경 무늬, 사진 콜라주, 느린 페이드. 갈아끼울 단어는 서너 개까지.
