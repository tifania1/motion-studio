# 어둠 속 카드 강과 얼굴 무리 (제품 UI)

한 줄: 거의 검은 화면에 굵은 흰 제목이 흐림에서 맺히고 알약 칩이 하나씩 밝아져요. 겹친 얼굴 원을 단 어두운 둥근 카드들이 두 줄로 옆으로 흐르다 멀어지며 흩어지고, 얼굴 원 무리가 흰 알약 버튼 둘레로 모여들어 커서가 눌러요.

## 보는 느낌
- 바탕은 거의 검정 하나예요. 처음과 끝에만 아주 옅은 별가루와 은하 띠가 비스듬히 흐르고, 가끔 별똥별 하나가 가늘게 지나가요.
- 첫 장면은 별가루 위에 은빛 마크 하나가 천천히 떠오르고, 이어 흰 글자 한 낱말이 가운데 놓여요. 마크 자리에는 우리 브랜드 마크를 둬요.
- 칩 장면은 가는 회색 선 두 가로줄과 두 세로줄이 무대 틀을 짜고, 그 안 가운데에 제목 한 줄과 알약 칩 묶음이 놓여요.
- 본 장면은 카드 강이에요. 같은 모양의 어두운 둥근 카드가 두 줄로 화면을 꽉 채우고, 양옆이 늘 잘린 채 옆으로 흘러가요. 카드 사이 간격은 좁고 고르게 둬요.
- 무리 장면은 어둠 속에 얼굴 원 수십 개가 고리처럼 모이고, 가운데에는 흰 알약 버튼 하나만 놓여요.
- 엔딩은 다시 별가루예요. 이번에는 왼쪽 아래에 작은 마크, 큰 제목, 회색 부제를 쌓아 왼쪽 정렬로 닫아요.

## 색
- 검정 바탕 70 · 카드 회색 20 · 흰 글자 8 · 흰 알약 2.
- 바탕 #0D0D0E, 카드 #1D1E20, 카드 테두리와 틀 선 #2F3336, 설명 글 회색 #7A7F85, 제목 흰빛 #E7E9EA.
- 색다운 색은 얼굴 원 속에서만 나와요. 우리 장면에서는 사진 대신 노랑·하늘·분홍·초록 단색 원이나 우리 사진을 써요.
- 강조는 흰 알약 버튼 하나뿐이고 글자는 검정이에요. 제목 속 강조 낱말도 색을 바꾸지 않고 흐림에서 맺히는 순서로만 도드라지게 해요.

## 글자
- Geist 와 Noto Sans KR 로 쓰는 둥글지 않은 산세리프예요. 제목은 700, 자간 −0.02em, 짧은 변의 6~7%.
- 칩 글자는 500, 짧은 변의 2.6%. 왼쪽에 가는 선 아이콘을 하나 둬요.
- 카드 제목은 600~700, 짧은 변의 2.4%, 가운데 정렬이에요. 설명은 400, 회색, 짧은 변의 1.8%, 두세 줄, 줄 간격 1.35.
- 엔딩 제목은 700, 짧은 변의 8%, 왼쪽 정렬이에요. 부제는 회색 400, 제목의 절반 크기.

## 질감과 모양
- 그레인 0.05, 비네트 0.35로 별가루 장면이 살짝 거칠고 가장자리가 가라앉게 해요.
- 카드는 #1D1E20 칠에 1px #2F3336 테두리를 두르고, 모서리는 `--u` × 1.6, 그림자는 없어요.
- 칩은 완전한 알약 모양에 1px 회색 테두리를 두르고, 칠은 바탕보다 아주 조금만 밝게 해요.
- 얼굴 원은 카드 안에서 셋이 지름의 30%씩 겹치고, 원마다 바탕색 2px 테두리를 둘러 서로 갈라 보이게 해요.
- 틀 선은 1px #2F3336이고 화면 끝까지 뻗어요.

## 움직임
- 100BPM, 보통 빠르기예요. 들어오는 건 `power3.out`으로 부드럽게 멈춰요.
- 제목은 어절마다 흐림 8px, 투명도 0에서 0.5초에 맺혀요. 어절 사이는 0.12초예요.
- 칩은 0.15초 간격으로 투명도 0.25에서 1로 밝아져요. 끝의 한두 개는 0.4에 머물러 아직 남은 게 있다는 느낌을 줘요.
- 카드 강은 등속(linear)으로 쉬지 않고 흘러요. 윗줄은 초당 짧은 변의 4.5%, 아랫줄은 3.8%로 속도를 달리해요.
- 카드 강이 끝날 때는 1초 동안 전체가 0.25배로 작아지며 어두워지고 흩어져요.
- 얼굴 원은 바깥에서 안쪽으로 스프링('smooth')처럼 모이고 원마다 0.03초씩 늦게 도착해요. 다 모이면 아주 천천히(8초에 한 바퀴의 5%쯤) 돌아요.

## 전환
- 느린 페이드와 흐림 전환이 기본이에요. 장면 쌓기 순서는 fade → blur예요.
- 칩 장면에서 카드 장면으로 넘어갈 때는 제목만 흐려져 사라지고, 그 자리 아래에서 카드가 맺혀 나와요.
- 카드 강에서 무리 장면으로 넘어갈 때는 카메라가 뒤로 빠지듯 카드가 작아지며 어둠에 녹아요.

## 대표 장면

1. 틀 안 칩 밝히기
   ```js
   // 가는 틀 선 4개는 처음부터 고정, 제목은 장면 쌓기 title: blur 로
   const chips = S.$$('.chip');
   S.ambient(t => {
     chips.forEach((c, i) => {
       const last = i >= chips.length - 2;
       const k = M.ease.outCubic(M.prog(t, .6 + i * .15, .4));
       c.style.opacity = .25 + k * (last ? .15 : .75);
     });
   });
   ```
2. 두 줄 카드 강
   ```js
   // 카드 한 줄을 두 벌 이어 붙여 끝없이 흐르게 (t 의 순수 함수)
   const rows = [[S.$('.row-a'), .045], [S.$('.row-b'), .038]];
   S.ambient(t => rows.forEach(([r, v], i) => {
     const w = r.scrollWidth / 2;
     const x = -((t * v * S.short + i * w * .3) % w);
     M.place(r, x, null);
   }));
   // 들어올 때는 카드마다 M.spring(t - i * .05, 'smooth') 로 흐림 6px → 0
   ```
3. 멀어지며 흩어지는 카드, 모여드는 얼굴 원
   ```js
   const k = M.ease.inOutCubic(M.prog(t, tOut, 1));
   M.place(board, cx, cy, { s: 1 - k * .75, o: 1 - k });
   faces.forEach((f, i) => {
     const a = i / faces.length * Math.PI * 2 + t * .04;
     const r = R * (1 + (M.rng(i)() - .5) * .5);
     const p = M.spring(t - tIn - i * .03, 'smooth');
     M.place(f, cx + Math.cos(a) * r * (2.2 - 1.2 * p), cy + Math.sin(a) * r * (2.2 - 1.2 * p), { o: p });
   });
   // M.Cursor 로 가운데 흰 알약을 누르면(M.cursorAt) 알약 s 1 → .94 → 1, 원들은 한 박 늦게 r × .96
   ```
4. 별가루 엔딩
   - 작은 흰 점 수백 개를 비스듬한 띠 모양으로 뿌리고 `M.drift`로 아주 천천히 흘려요. 가끔 가는 선 하나가 0.4초에 대각선으로 지나가요.
   - 왼쪽 아래에 마크, 제목, 부제를 쌓아요. 제목은 페이드로, 부제는 어절마다 흐림에서 맺혀요(`S.tr.blur` 결). 마지막 어절이 맺히면 2초 머물러요.
