# 블록 글리치 그로테스크 (타이포)

한 줄: 꽉 찬 그로테스크 글자가 휙휙 지나가고, 검정·주황 블록이 글자를 한 프레임씩 덮었다 걷히는 빠른 런칭 필름.

## 보는 느낌
- 밝은 회색 바탕에 검정 글자 하나만. 장면이 0.3~1초마다 바뀌어서 숨 돌릴 틈 없이 몰아쳐요.
- 큰 글자는 화면 밖으로 넘칠 만큼 크게, 작은 문장은 한가운데 한 줄로. 두 크기를 번갈아 써서 리듬을 만들어요.
- 사이사이에 UI 조각(할 일 카드 더미, 결제 알림 목록, 막대·원 그래프, 큰 숫자)이 짧게 끼어들어요.

## 색
- 바탕 회색 75 · 검정 글자 20 · 주황 5. 주황은 한 문장에서 한 단어에만.
- 초록은 '눌렀다·성공' 확인에만(카드 테두리, +금액). 파랑은 그래프 선·막대에만 아주 잠깐.

## 글자
- Archivo 가변 글꼴(한글은 Noto Sans KR Bold·Black). 제목 굵기 800, 자간 -0.04em 으로 빽빽하게.
- 가변 축을 움직임에 써요: 문구가 처음엔 아주 굵고 좁게(weight 900, stretch 70%) 뭉쳐 나왔다가 0.3초 만에 보통 굵기·너비로 풀려요.
- 큰 단어는 한 화면에 한 단어, 잘려도 괜찮아요. 작은 문장은 화면 너비의 60% 안쪽.

## 질감과 모양
- 질감 없이 매끈하게. 대신 컷 사이 한두 프레임에 움직임 흐림(블러)을 얹어 속도를 느끼게 해요.
- 카드: 연한 흰빛, 얇은 회색 테두리, 부드러운 그림자, 모서리 `--u` × 1.4. 3D 로 살짝 눕혀(rotateX 10~15°) 쌓아요.
- 블록 커서: 글자 높이만 한 검정 직사각형. 주황 테두리 상자는 2px 선.

## 움직임
- 128BPM. 대부분의 변화가 박이나 반 박에 맞춰 일어나요.
- 들어오는 건 `expo.out` 으로 확 들어와 바로 멈춤. 나가는 건 따로 애니메이션 없이 컷.
- 글리치 깜빡임은 한 프레임(약 0.07초, 30fps 기준 2프레임) 단위 계단 값이에요.

## 전환
- 컷이 기본. 큰 단어가 옆으로 휙 지나가는 밀어내기(push)와 검은 블록 와이프(wipe)를 섞어요.
- 장면 쌓기: cut → push → wipe.

## 대표 장면
1. **큰 단어 휙 + 블록 와이프**: 화면 높이만 한 단어를 `M.place(word, x, cy)` 로 두고 `x = M.anim([[0, W * 1.2], [t0, -W * .9, {d: .45, e: 'inOutQuart'}]], t)` 로 0.45초 만에 가로질러 보냄(이동 중엔 `blur` 2~4px).
   이어 검은 직사각형을 `M.box(block, {x, y, w, h})` 로 왼쪽 끝 0 너비에서 문구 너비까지 늘렸다가, 오른쪽에서부터 다시 줄이며 새 문구를 드러냄.
2. **블록 글리치 타이핑**: `S.chars(el)` 로 글자를 나누고 2~3글자씩 묶음. 묶음마다 상태 목록 `['black', 'orange', 'outline', 'none']` 을 `M.rng(시드)` 로 섞어 `M.at([[t0, s0], [t0 + .07, s1], …], t)` 로 고름.
   상태별로 묶음 뒤에 검정 칠(글자 흰색) · 주황 칠(글자 흰색) · 주황 2px 테두리를 그려요. 0.5초 뒤 모두 'none' 이 되고 강조 단어만 주황 글자로 남아요. 마지막 글자 뒤에는 검은 블록 커서가 한 박 더 머물다 꺼짐.
3. **카드 더미와 클릭**: 카드 4~5장을 위에서 `M.anim` 으로 떨어뜨려(각각 0.1초 늦게) y 를 조금씩 엇갈려 쌓고, 부모에 `perspective` + 카드 `rotateX(12deg)`. `M.Cursor` 로 맨 앞 카드를 누르면(`M.cursorAt`) 테두리를 `M.color('#D9D9D6', '#34C759', k)` 로 바꾸고 다음 박에 아래로 빠짐(`y += H * .4`, 흐림).
4. **큰 숫자 컷**: 숫자 하나를 두세 프레임마다 다른 값으로 바꿔 끼움(`M.at`). 바뀌는 순간 이전 숫자를 반투명 초록으로 한 프레임 겹쳐 두면 잔상이 생겨요. 아래로 파랑 선 그래프를 `M.draw` 로 빠르게.

## 어울리는 곳 / 피할 것
- 어울림: 신제품·기능 런칭, 성과 숫자 자랑, 세일 카운트다운, 젊은 브랜드 광고. 15~25초 짧은 영상.
- 피할 것: 느린 페이드, 세리프 글꼴, 강조색 여러 개(주황 하나와 확인용 초록만), 글이 긴 장면.
- 한글은 글자 수가 적은 단어(2~4자)를 크게 쓰면 잘 맞아요.
