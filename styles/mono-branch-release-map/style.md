# 가지선 릴리스 지도 (다이어그램·데이터)

한 줄: 어두운 회색 공간에 가는 흰 선 다발이 한 점에서 갈래갈래 뻗고, 갈래 끝마다 흰 네모와 고정폭 꼬리표가 켜져요. 카메라는 기울어진 지도를 천천히 훑고, 문장은 블록 커서를 따라 한 글자씩 쳐져요.

## 보는 느낌
- 바탕은 거의 검은 회색 하나. 가장자리가 비네트로 더 어두워서 가운데 선 다발에 눈이 모여요.
- 주인공은 강줄기나 나무뿌리처럼 갈라지는 가는 흰 선이에요. 오른쪽(또는 화면 밖) 한 점으로 모이고, 왼쪽으로 갈수록 부채처럼 퍼지며 곡선으로 휘어요.
- 갈래 끝에는 작은 흰 네모 + 고정폭 대문자 꼬리표(영문 3자-숫자 4자 꼴의 작업 번호). 꼬리표는 선보다 작고 조용해요.
- 지도는 늘 바닥처럼 기울어 있고, 앞쪽은 초점이 나가 흐리고 뒤쪽은 선명해요. 얕은 피사계 심도가 공간감을 만들어요.
- 지도 장면 사이에 아무것도 없는 검은 화면과 가운데 고정폭 한 줄이 쉼표처럼 끼어요.

## 색
- 바탕 #141415 80 · 흰 선과 글자 #E6E6E3 15 · 회색 꼬리표·먼 선 #8E8F92 5.
- 패널 장면에서는 패널 면만 #1F2023 으로 살짝 밝게.
- 옅은 라벤더 #7F82D8 는 패널 위 작은 제목 한 조각에만, 아주 드물게. 그 밖엔 흑백이에요.

## 글자
- 전부 Geist Mono(한글은 Noto Sans KR Medium). 굵기 400, 대문자, 자간 0.08em.
- 가운데 문장: 짧은 변의 3.5~4.5%, 한 줄. 크게 쓰지 않아요.
- 꼬리표: 짧은 변의 1.6~2%, 흰색 70~90%. 앞에 글자 높이만 한 흰 네모.
- 블록 커서는 글자 높이 그대로의 흰 직사각형, 너비는 글자 한 칸.

## 질감과 모양
- 그레인 0.06(초당 12번), 비네트 0.35.
- 선 두께는 0.5~1.5px 가 대부분, 카메라 가까운 몇 가닥만 3~6px 에 흐림 2~6px. 선 끝은 둥글게, 흰색 35~90% 로 깊이에 따라 다르게.
- 패널은 모서리 0.6u, 1px 흰 테두리 8%, 아주 짙은 그림자.
- 빛 번짐·그라디언트는 쓰지 않아요.

## 움직임
- 80BPM, 느림. power2.inOut 으로 미끄러지듯.
- 선은 모이는 점에서 바깥으로 2~3초에 그어지고, 갈래가 닿는 순서대로 꼬리표가 켜져요(투명도 0 → 1, 0.2초, 살짝 깜빡).
- 카메라는 8~10초 동안 쉬지 않고 옆·앞으로 흘러요. 멈추지 않는 느린 이동이 이 결의 바탕이에요.
- 타이핑은 초당 12~14자. 커서는 0.5초 주기로 깜빡이고, 지울 때는 한 글자씩 조금 더 빨리.

## 전환
- 지도 → 검은 화면 문장은 느린 페이드(0.6초). 문장 → 지도도 페이드.
- 같은 결 장면끼리(지도 → 다른 각도의 지도)는 컷. 장면 쌓기: fade → cut → fade.

## 대표 장면
1. **한 점에서 뻗는 가지선**
   ```
   // 모이는 점 (W*.92, H*.5) 에서 왼쪽 끝 점들까지 3차 곡선 40가닥, 중간에 갈라지는 가지 추가
   const paths = S.$$('.branch');
   S.ambient(t => {
     paths.forEach((p, i) => {
       const k = M.ease.inOutCubic(M.prog(t, .2 + i * .03, 2.4));
       M.draw(p, k);
     });
     tags.forEach((g, i) => g.style.opacity = M.prog(t, tagAt[i], .2)); // 갈래가 닿는 시각에 켜짐
   });
   ```
   깊이 값 z(0~1)를 가닥마다 주고 굵기 `1 + (1 - z) * 4`, 흐림 `(1 - z) * 5px`, 투명도 `.35 + z * .55`.
2. **기울어진 지도 훑기**
   - 지도 전체를 한 판에 담고 부모에 `perspective`, 판에 `rotateX(48deg) rotateZ(-8deg)`.
   - `M.place(board, x, y)` 로 `x = M.anim([[0, W * .08], [9, -W * .12, {d: 9, e: 'inOutSine'}]], t)` 처럼 9초에 걸쳐 천천히 미끄러뜨려요. 기울기도 같은 시간에 4~6도만 바뀌게.
3. **겹쳐 선 패널 세 장**
   - 같은 지도를 작게 담은 어두운 패널 3장을 비스듬히(rotateY −25°) 왼쪽 뒤에서 오른쪽 앞으로 엇갈려 세우고, 각각 0.3초 늦게 `M.spring(t - ti, 'smooth')` 로 떠올라요. 카메라는 맨 앞 패널 쪽으로 천천히 다가가다 컷으로 그 패널 속 지도 클로즈업.
4. **블록 커서 타이핑과 다시 치기**
   - 검은 화면 가운데 `M.type(text, t, t0, 13)`, 끝에 흰 블록 커서(0.5초 깜빡). 친 말을 커서가 한 글자씩 지우고 빈 자리에서 한 박 깜빡인 뒤 마무리 문구를 다시 쳐요.
   - 장면 쌓기에서는 title: type 이 이 결을 그대로 내요. 장면 사이는 `S.tr.blur` 대신 느린 페이드.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 기능·버전 출시 소개, 일정·로드맵 관리 도구, 개발 도구 런칭, 프로젝트 흐름 설명, 차분한 기술 브랜드 티저.
- 피할 것: 밝은 바탕, 강조색 여러 개, 통통 튀는 이징, 굵은 큰 제목, 빠른 컷 몰아치기.
- 꼬리표 문구는 실제 작업 번호처럼 짧게. 한글 꼬리표는 2~4자로 줄여야 선 다발 결이 살아요.
