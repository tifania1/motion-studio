# 이름표 커서 색면 행진 (제품 UI)

한 줄: 옅은 회색 캔버스에 그림자가 부드러운 아이콘 타일과 둥근 산세리프 한 줄을 놓고, 파스텔 이름표를 단 커서들이 그 둘레로 모여들어요. 박자마다 노랑·자홍·청록·파랑 색면으로 컷되면 반들한 3D 소품이 기운 스티커 낱말을 달고 톡 튀어 올라요.

## 보는 느낌
- 기본 무대는 아주 옅은 회색 캔버스예요. 가운데 둥근 산세리프 한 줄이나 아이콘 타일 하나만 두고 둘레를 넉넉히 비워요.
- 그 빈자리를 사람의 흔적이 채워요. 작은 화살표 커서마다 알약 모양 이름표(초록·파랑·분홍·노랑)가 붙어 있고, 여럿이 같은 화면에서 함께 일하는 기분을 줘요.
- 회색 장면 사이사이에 화면을 꽉 채운 단색 색면(노랑, 짙은 자홍, 청록, 파랑, 보라 그라디언트)이 컷으로 끼어들어 리듬을 만들어요.
- 브랜드 재료를 하나씩 펼쳐 보여 주는 구성이에요: 아이콘 타일 격자 → 화면보다 커서 잘린 글자 견본 → 인사말 슬롯 → 색 견본 칸 → 빛나는 반짝이 → 3D 소품과 스티커 → 다시 회색 캔버스 위 문장.

## 색
- 회색 장면: 바탕 #ECECEA 80 · 먹색 글자 #1F1F24 15 · 이름표 파스텔 5.
- 색면 장면: 단색 바탕 85 · 소품 10 · 흰 글자·반짝이 5. 한 장면에 바탕색 하나만 써요.
- 노랑 #F2C92E 는 강조(accent). 위에 올리는 글자는 먹색.
- 보라 #5A3DE6(→ #7A2FD8 그라디언트)는 paper 장면 바탕, 위 글자는 흰색에 아주 옅은 빛 번짐.
- 그 밖의 색면: 자홍 #D9336B, 짙은 자홍 #A8215A, 청록 #4ECDB8, 파랑 #4A6FE0. 색 견본 장면에서만 짙은 자두 #3B0F45, 진초록 #1B3A1A 를 곁들여요.
- 이름표: 초록 #7EDB8A, 파랑 #8FB4FF, 분홍 #F49AC9, 노랑 #F6D85A. 글자는 먹색.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 획 끝이 둥글고 속공간이 넓은 기하 산세리프 느낌으로, 제목 굵기 500, 자간 −0.02em.
- 제목은 짧은 변의 7~9%, 한 줄로 가운데 정렬. 그 위에 짧은 변의 2% 남짓한 작은 머리글 한 줄을 얹기도 해요.
- 글자 견본 장면에서는 같은 글꼴을 짧은 변의 80% 넘게 키워 화면 밖으로 잘리게 깔아요. 읽히기보다 모양이 보이게.
- 색면 장면의 큰 배경 낱말은 바탕과 같은 색 계열에서 한 단계 밝게(불투명 15~20%), 앞의 스티커 낱말은 굵게 700, −6~−10도 기울여요.
- 색 견본 칸 이름표는 짧은 변의 1.5% 정도로 아주 작게, 왼쪽 위에 이름과 색 번호 두 줄.

## 질감과 모양
- 질감은 넣지 않아요. 화면 전체가 매끈하고 밝아요.
- 아이콘 타일: 바탕보다 살짝 밝은 둥근 정사각(모서리 1.6u), 아래로 넓게 퍼지는 아주 옅은 그림자 한 겹. 아이콘은 먹색 가는 선(짧은 변의 0.4%).
- 이름표: 완전 둥근 알약, 테두리 없음, 커서 화살표는 이름표와 같은 색으로 칠해요.
- 선택 상자: 1.5px 파란 선, 네 귀퉁이에 작은 흰 정사각 손잡이.
- 3D 소품: 반들한 플라스틱이나 말랑한 젤리 재질, 아래에 흐린 원 그림자 하나. 스티커는 흰 테두리를 두른 굵은 낱말 오림.
- 반짝이: 흰 네 갈래 별, 보라 장면에서는 둘레로 빛 번짐.

## 움직임
- 110BPM. 장면 하나에 3~4박(1.6~2.2초) 머물러요.
- 커서·스티커·소품은 back.out(1.5)로 살짝 넘쳤다 자리 잡고, 자리 잡은 뒤에는 2~3초 주기로 1u 안쪽에서 천천히 떠 있어요.
- 아이콘 격자와 글자 견본은 등속에 가깝게 천천히 흘러요(4초에 화면 높이의 20%).
- 인사말은 슬롯처럼 한 박마다 위로 밀려 올라가고, 앞 낱말은 옅어지며 위에 잠깐 남아요.
- 색 견본 칸은 박자마다 경계가 미끄러지며 넓이를 바꿔요(power3.inOut, 0.5초).

## 전환
- 컷이 기본. 회색 ↔ 색면 사이는 대부분 컷으로 확 바꿔요.
- 색 견본 장면에서는 칸이 커져 화면을 덮는 블록 전환(blocks), 소품 장면끼리는 옆으로 밀어내기(push), 반짝이에서 다음 장면으로는 원형 열림(iris).
- 장면 쌓기: cut → blocks → push → iris.

## 대표 장면
1. **이름표 커서가 모이는 제목**
   ```js
   // 커서마다 [시작 위치, 멈출 위치, 들어오는 시각]
   const tags = S.$$('.nametag');
   S.ambient(t => tags.forEach((el, i) => {
     const c = C[i], k = M.spring(t - c.t0, 'bouncy');
     const bob = Math.sin((t + i) * Math.PI / 1.2) * u * .5;
     M.place(el, c.x0 + (c.x1 - c.x0) * k, c.y0 + (c.y1 - c.y0) * k + bob, {o: Math.min(1, k * 2)});
   }));
   // 끝: 커서 하나가 문장을 누르면 선택 상자
   const cur = new M.Cursor(S.$('.cursor-main'));
   const sel = M.prog(t, M.cursorAt(cur, phraseEnd), .35);
   M.box(selBox, {x, y, w: w * M.ease.outCubic(sel), h});
   ```
   장면 쌓기에서는 deco cursor + handles 로 같은 결이 나와요.
2. **볼록한 아이콘 타일과 작도선**
   - 타일 하나를 가운데 두고 머리카락 같은 파란 안내선 3~4개를 `M.draw(line, M.prog(t, i * M.beat(.5), .4))` 로 긋고 귀퉁이에 작은 번호를 띄웠다가 한 박 뒤 걷어요.
   - 이어 카메라를 `M.anim([[0, 1.6], [M.beat(4), 1, {d: .9, e: 'inOutCubic'}]], t)` 배율로 물려 5×4 타일 격자를 보이고, 격자를 `y = -t * H * .05` 로 천천히 올려요. 가운데 줄에 온 타일만 아이콘 색을 `M.color('#1F1F24', '#4A6FE0', k)` 로 바꿔요.
3. **색 견본 칸이 밀고 덮기**
   - 칸 4~5개를 `M.box` 로 배치하고 박자마다 경계 x 를 `M.at` 으로 고른 다음 값으로 0.5초 미끄러지게 해요. 칸 왼쪽 위엔 작은 이름·색 번호 두 줄.
   - 마지막 박에 한 칸이 화면 전체로 커지면(`S.tr.blocks` 도 같은 결) 그 색 그대로 다음 소품 장면 바탕이 돼요.
4. **단색 바탕 위 3D 소품과 스티커**
   ```js
   const k = M.spring(t - .2, 'bouncy');
   M.place(prop, cx, cy + (1 - k) * H * .25, {s: .6 + .4 * k, r: (1 - k) * -12});
   M.place(sticker, cx + u * 6, cy + u * 4, {s: M.spring(t - .45, 'bouncy'), r: -8});
   sparkles.forEach((s, i) => M.place(s, ...pos[i], {s: .6 + .4 * Math.abs(Math.sin(t * 3 + i))}));
   ```
   뒤에 같은 색 계열의 아주 큰 낱말을 옅게 깔고, 이름표 커서 하나가 소품 옆으로 들어와 멈춰요.
5. **보라 빛 문장**
   - paper 장면(보라 그라디언트)에 가는 흰 빛 곡선 하나를 `M.draw` 로 화면 구석에서 1.2초에 그어 지나가게 하고, 흰 문장은 `blur` 6px → 0 으로 맺히며 둘레에 `text-shadow: 0 0 2u var(--glow)` 를 남겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 협업·화이트보드 도구 소개, 디자인 시스템·브랜드 리뉴얼 공개, 반응·피드백 같은 팀 기능 홍보, 밝고 친근한 제품 런칭, 커뮤니티·행사 티저.
- 피할 것: 어두운 바탕만으로 끝까지 가기, 종이·필름 질감, 세리프·손글씨 글꼴, 한 화면에 긴 문장, 느리고 무거운 시네마틱 전환, 한 장면에 강조색 셋 이상.
- 3D 소품은 반응을 떠올리게 하는 흔한 사물(하트, 엄지, 로켓, 깃발)을 우리 식으로 새로 만들어 쓰고, 이름표 이름도 영상에 맞게 새로 지어요.
