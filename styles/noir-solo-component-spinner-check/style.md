# 검은 판 부품 견본 (제품 UI)

한 줄: 거의 검은 화면 한가운데에 버튼, 입력창, 링크 같은 UI 부품이 하나씩만 놓여요. 커서가 누르면 바탕이 한 단계 밝아지고, 작은 스피너가 돌다 체크로 맺히는 조용한 컴포넌트 견본 필름이에요.

## 보는 느낌
- 바탕은 거의 검은 #111111 한 색이에요. 장면마다 부품 하나만 정가운데에 작게 놓여요(화면 너비의 12~25%). 나머지는 전부 빈 어둠이에요.
- 부품은 실제 앱에서 떼어 온 크기 그대로 작게 보여 줘요. 버튼, 이메일 입력창, 로딩 버튼, 점선 밑줄 링크 순서로 하나씩 차례가 와요.
- 가끔 리듬을 바꿔요. 어두운 타일 격자가 밝은 큰 타일로 합쳐지거나, 화면 반이 밝은 회색 판이 되어 커다란 글자 하나를 보여 줘요.
- 후반에는 부품 넷이 한 줄로 서고, 카메라가 물러나 문서 화면(미리보기 칸, 탭, 코드 칸, 달력)이 드러나요. 그 뒤 어두운 유리 정육면체가 한 번 돌고, 작은 이름 한 줄로 닫아요.

## 색
- 검정 바탕 85 · 숯빛 부품 면 10 · 흰 글자 5.
- 부품 면은 세 단계를 써요: #1E1E1E(기본), #2C2C2C(눌림·마우스 올림), #EDEDED(흰 주 버튼).
- 글자는 #EDEDED, 자리 글이나 보조 글은 55% 흰색이에요.
- 빨강 #E5484D 는 '위험' 버튼 하나에만 써요. 바탕은 아주 어두운 적갈색(#3A1A1C)이고 글자만 빨강이에요.
- 밝은 판 장면은 #E8E8E8 바탕에 먹색 #111111 글자로 그 장면에서만 뒤집어요.

## 글자
- Geist(한글은 Noto Sans KR Medium). 부품 글자는 500, 짧은 변의 2.2~3%로 작아요.
- 큰 글자는 글꼴 견본 장면에만 나와요. 밝은 판에 한 글자를 짧은 변의 45%로 놓고, 굵기 400의 담백한 모양 그대로 보여 줘요.
- 치수 꼬리표와 코드 칸은 Geist Mono, 짧은 변의 1.4%, 55% 흰색이에요.
- 마무리 이름은 한 줄, 가운데 정렬이에요. 앞부분은 흰색, 뒷부분만 회색으로 나눠요.

## 질감과 모양
- 거의 매끈해요. 타일과 판에 그레인 0.04 만 아주 옅게 깔아요.
- 부품 모서리는 1.2u, 입력창은 조금 더 둥글게 1.6u예요. 테두리는 1px 흰색 8%, 그림자는 쓰지 않아요.
- 안내선은 1px 회색(흰색 30%), 핸들은 지름 0.5u 속이 빈 원이에요.
- 유리 정육면체는 어두운 반투명 면과 1px 밝은 모서리 선으로 만들어요. 빛 번짐은 넣지 않아요.

## 움직임
- 90BPM, 느림. 부품 하나가 2~3박(1.3~2초) 머물러요.
- 들어올 때는 흐림 6px에서 선명해지며 0.5초(power3.out). 나갈 때는 흐림으로 0.3초에 빠지거나 컷이에요.
- 반응은 작고 정확하게 보여 줘요. 누름은 97% 0.1초, 색 단계 바꿈은 0.15초예요. 되튀는 스프링은 쓰지 않아요.
- 카메라는 거의 고정이에요. 문서 장면에서만 1.6배에서 1배로 2초 동안 천천히 물러나요.

## 전환
- 같은 자리에서 부품만 바꿀 땐 컷이나 흐림(blur)으로 넘겨요. 큰 장면 사이만 느린 페이드를 써요.
- 타일 격자가 큰 타일 하나로 합쳐지는 장면은 그 자체로 전환이에요. 합쳐진 밝은 타일이 화면 반을 채우며 글꼴 견본으로 이어져요.
- 장면 쌓기 순서: cut → fade → blur.

## 대표 장면

1. 버튼 하나와 커서 누름
   ```js
   const k = M.anim([[0, 0], [.2, 1, {d: .5, e: 'outCubic'}]], t);
   M.place(btn, cx, cy, {o: k, blur: (1 - k) * 6});
   const cur = M.Cursor(cursorEl, [[.6, W*.62, H*.7], [1.2, cx + 8, cy + 4, {click: true}]]);
   const p = M.cursorAt(cur, t);                       // 누른 순간 p.press 0→1→0
   M.place(btn, cx, cy, {s: 1 - p.press * .03});
   btn.style.background = M.color('#1E1E1E', '#2C2C2C', M.prog(t, 1.2, .15));
   ```
2. 입력창 타이핑 → 스피너 → 체크
   ```js
   input.textContent = t < 2 ? '' : M.type('hello@example.com', t, 2, 18);
   ph.style.opacity = t < 2 ? 1 : 0;                   // 회색 자리 글은 첫 글자에서 사라짐
   // 다음 장면: 작은 정사각 버튼
   spin.style.transform = `rotate(${(t - 4) * 420}deg)`;
   spin.style.opacity = 1 - M.prog(t, 5.5, .2);
   M.draw(checkPath, M.ease.outCubic(M.prog(t, 5.7, .3)));
   ```
3. 원호 안내선과 치수 꼬리표
   - 부품을 지우고 SVG 원호 2~3개를 `M.draw(arc, k)` 로 0.6초에 그어요. 양끝과 가운데에 핸들 원을 `M.place` 로 붙이고, 고정폭 꼬리표(예: `r 24`)를 원호 위에 둬요.
   - `r = M.anim([[0, 120], [1.5, 180, {d: 1.2, e: 'inOutSine'}]], t)` 로 반지름을 천천히 바꾸고, 꼬리표 숫자도 같이 굴려요(`scenes.number: odometer`).
   - 장면 쌓기에서는 deco `handles` 가 제목 둘레에 선택 상자와 손잡이를 둘러 같은 결을 내요.
4. 변형 줄 → 문서 화면으로 물러나기 → 이름 한 줄
   - 흰·숯빛·투명·위험 버튼 넷을 `M.place` 로 0.08초씩 늦게 흐림에서 맺히게 해요. 이어 부모를 `M.place(page, cx, cy, {s: M.anim([[0, 1.6], [.4, 1, {d: 2, e: 'inOutCubic'}]], t)})` 로 물리면 탭, 코드 칸(Geist Mono), 달력이 둘레에 드러나요.
   - 마무리는 `S.tr.blur` 로 넘어가 이름 한 줄을 흐림에서 맺히게 해요(title: blur). 뒷부분 글자만 `onBgMuted` 로 칠해요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·컴포넌트 공개, UI 라이브러리 소개, 개발자 도구 런칭, 기능 하나를 차분히 집중해서 보여 줄 때.
- 피할 것: 화려한 그라디언트와 빛 번짐, 강조색 여러 개(빨강은 위험 버튼 하나에만), 빠른 컷 몽타주, 한 화면에 부품 여러 개를 빽빽이(변형 줄과 문서 장면만 예외), 굵고 큰 제목.
- 한 장면에 문구는 버튼 글자 수준으로 짧게 써요. 설명이 길면 문서 장면의 코드 칸으로 보내요.
