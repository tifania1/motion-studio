# 노드 실행 체인 (제품 UI)

한 줄: 옅은 회색 캔버스 위 흰 노드 카드가 파랑·노랑 곡선으로 이어지고, 커서가 실행 단추를 누를 때마다 다음 카드가 채워지며 카메라가 그 흐름을 따라 옮겨 가요.

## 보는 느낌
- 바탕은 무늬 없는 옅은 회색 캔버스 하나예요. 그 위에 흰빛 노드 카드 서너 장이 가로로 놓이고, 카드끼리 부드러운 S자 곡선으로 이어져요.
- 화면은 늘 카드 두세 장만 보이게 바짝 다가가 있어요. 양 끝 카드는 화면 밖으로 잘려서 캔버스가 옆으로 더 이어진다는 느낌을 줘요.
- 카드마다 위에 작은 회색 이름표가 붙고, 가장자리에 연결 점이 박혀 있어요. 점과 선의 색이 곧 연결 종류예요(그림은 파랑, 글 지시는 노랑, 영상은 초록).
- 그림·결과물은 카드 안 사진 칸에만 들어가요. 사진이 화면 전체를 덮는 일은 없어요.
- 시작과 끝은 빈 회색 판 한가운데 작은 글 한 줄, 작은 마크 하나로 조용하게.

## 색
- 회색 바탕 65 · 흰 카드 25 · 먹색 글자 6 · 선 색 4.
- 바탕 #DADADA, 카드 #F2F2F2, 카드 안 입력 칸 #E4E4E4, 글자 #1C1C1C, 이름표·안내 글 먹색 60%.
- 파랑 #2F6FE0 은 그림 연결선과 선택 막(파랑 15~20%)에, 노랑 #F2C230 은 글 지시 연결선에만, 초록 #3BBF4A 는 영상 출력 점에만 써요.
- 단추 바탕을 파랑으로 칠하면 글자는 흰색. 실행 단추는 흰 알약에 먹색 재생 표시예요.

## 글자
- Geist 하나로(한글은 Noto Sans KR Medium·Bold). 화면 안 글은 거의 다 작아요.
- 오프닝: 회색(먹색 45%) 중간 굵기 낱말 한 개 뒤에 같은 크기의 굵은(700) 검정 낱말이 붙어요. 짧은 변의 6% 안팎, 자간 −0.02em.
- 카드 이름표: 짧은 변의 1.6%, 먹색 60%. 연결 점 옆 꼬리표도 같은 크기.
- 처리 카드 가운데 지시어: 굵은 700, 짧은 변의 2.4%, 두세 낱말. 입력 칸 안 문장은 회색 400.

## 질감과 모양
- 질감 없이 매끈하게. 깊이는 그림자로만 내요.
- 카드: 모서리 `--u` × 1.2, 아래로 길게 퍼지는 부드러운 그림자 한 겹(`0 3u 6u rgba(0,0,0,.16)`), 테두리 없음.
- 연결선: 두께 짧은 변의 0.35%, 끝이 둥근 베지어 곡선. 연결 점은 지름 0.9u 원에 흰 테두리.
- 커서: 흰 테두리를 두른 큰 검정 화살표(짧은 변의 4%).
- 선택 막: 카드 묶음 둘레를 감싸는 옅은 파랑 둥근 사각형, 모서리 1.6u.

## 움직임
- 120BPM. 한 고리가 4박(2초): 지시어 쳐짐(1박) → 커서 이동·누름(1박) → 선 그어짐과 결과 채워짐(2박).
- 카메라 이동은 `power3.inOut`, 한 번에 0.9~1.2초. 결과가 채워지는 동안은 멈춰 있다가, 다음 마디로 갈 때만 움직여요.
- 커서는 카메라와 같은 곡선으로 움직이고, 누를 때 0.1초 동안 92%로 작아졌다 돌아와요.
- 결과 그림은 흐림 8px → 0 과 투명도 0 → 1 을 0.5초에. 새 카드는 오른쪽에서 밀려 들어와(스프링 'smooth') 멈춰요.

## 전환
- 장면 사이를 카메라 이동(push)으로 이어서 한 캔버스 위를 돌아다니는 것처럼 보여요.
- 마무리 마크로 갈 때만 컷, 마크는 천천히 페이드로 빠져요. 장면 쌓기: push → cut → fade.

## 대표 장면

1. **소개말이 캔버스가 되는 오프닝**
   ```js
   S.ambient(t => {
     const shift = M.anim([[0, 0], [1.6, -W * .14, {d: .7, e: 'inOutCubic'}]], t);
     M.place(intro, cx + shift, cy, {o: M.ease.outCubic(M.prog(t, 0, .6))}); // 회색 낱말이 서서히
     nameWord.style.opacity = t > .9 ? 1 : 0;                                  // 굵은 낱말은 컷으로 붙음
     M.place(firstCard, M.anim([[0, W * 1.15], [1.6, W * .74, {d: .8, e: 'outCubic'}]], t), cy + H * .1);
     M.draw(blueWire, M.ease.outCubic(M.prog(t, 2.0, .5)));                     // 카드에서 파랑 선이 이어짐
   });
   ```
   장면 쌓기에서는 title: fade 로 작은 제목이 서서히 떠오르고, 다음 장면으로 push 해요.

2. **치고 → 누르고 → 채워지는 고리**
   ```js
   const words = ['낮은 각도', '바짝 붙여', '사물만'];
   const cursor = new M.Cursor(S.$('.cursor'));
   S.ambient(t => {
     const i = Math.min(words.length - 1, Math.floor((t - 1) / 2)), t0 = 1 + i * 2;
     promptEl.textContent = M.type(words[i], t, t0, 18);
     M.cursorAt(cursor, runBtn, t, t0 + .5);                       // 실행 단추로 가서 누름
     const k = M.ease.outCubic(M.prog(t, t0 + 1, .5));
     M.draw(yellowWire, k);
     M.at(results.map((r, j) => [1 + j * 2 + 1, j]), t);          // 결과 그림 교체
     resultImg.style.filter = `blur(${(1 - k) * 8}px)`;
     camera.style.transform = `translateX(${M.anim(camKeys, t)}px)`; // power3.inOut 로 다음 마디로
   });
   ```
   장면 쌓기에서는 deco: cursor 가 강조 말로 와서 누르고, card: shadow 로 카드가 떠 보여요.

3. **한 점에서 세 갈래로, 선택 막과 차례 재생**
   - 카메라를 뒤로 빼며(`scale 1 → .78`, 1.2초) 출력 점에서 파랑 곡선 셋을 `M.draw(wire[j], M.prog(t, t1 + j * .08, .6))` 로 뻗어요.
   - 선이 닿으면 옅은 파랑 둥근 사각형이 투명도 0 → 1 로 세 카드를 덮고, 선에 `filter: drop-shadow(0 0 1u var(--glow))` 를 0.4초 켰다 꺼요.
   - 카드 셋의 사진 칸을 왼쪽부터 1박씩 늦춰 다음 그림으로 바꿔요(흐림 6px → 0). 영상 출력 점은 초록으로 한 번 맥박쳐요.

4. **작은 마크로 닫기**
   - 컷으로 빈 회색 판. 가운데 검정 마크가 `M.place(mark, cx, cy, {s: .96 + .04 * k, o: k})` 로 0.4초에 맺히고, 한 박 머문 뒤 투명도 .35 까지 천천히 빠져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 생성 도구의 작업 흐름 소개, 자동화·파이프라인 도구 런칭, 단계를 이어 결과를 만드는 기능 설명, 한 입력에서 여러 결과로 갈라지는 기능.
- 피할 것: 어두운 바탕, 빠른 컷 몽타주, 손그림 선과 종이 질감, 화면을 꽉 채우는 큰 제목, 연결 종류와 상관없는 장식용 강조색.
- 카드 속 결과 그림이 고리마다 확실히 달라져야 이 결이 살아요. 같은 대상을 각도·거리·배경만 바꿔 보여 주면 좋아요.
