# 노드 캔버스 재질 글자 (3D·사물)

한 줄: 어두운 노드 캔버스에서 굵은 글자 조각이 카드마다 하나씩 담겨 선으로 이어지고, 프롬프트 한 줄이 쳐지면 조각들이 왼쪽부터 스펀지·말랑이·크롬 재질로 차례차례 갈아입은 뒤 부푼 크롬 글자로 한 줄에 맺혀요.

## 보는 느낌
- 바탕은 거의 검은 짙은 회색 하나. 무늬나 빛 번짐 없이 조용해서 글자 조각의 재질이 도드라져요.
- 주인공은 굵고 뭉툭한 기호 글자예요. 네모를 쌓은 것, 꽃잎처럼 둥근 것, 소용돌이 같은 것이 섞인 우리만의 기호를 그려 써요. 처음엔 납작한 흰색, 노드 카드 속에선 연두, 그다음엔 3D 재질을 입어요.
- 가운데 정렬로 시작해서(작은 글 한 줄 + 아래 기호 글자), 중간엔 캔버스처럼 카드가 흩어지고, 끝은 왼쪽 정렬 포스터로 꽉 채워요.
- 중간에 프롬프트 창 하나를 화면보다 크게 키워 바짝 붙는 컷이 끼어요. 창 모서리만 보이고 글자는 화면 높이의 8~10%로 커요.

## 색
- 바탕 #1E1E20 70 · 흰 글자 20 · 재질 색 10.
- 노드 카드 속 글자와 강조는 연두 #DDF09A. 버튼·꼬리표에 쓰면 글자는 거의 검정.
- 재질 색: 스펀지 노랑 #F2C21B, 말랑이 분홍 #E9A3A0, 파랑 #4A8EE0, 크롬은 #F4F4F4 ~ #6E7078 사이 회색 띠.
- 연결선은 분홍 #E07BB0 과 청록 #4FC3B8, 굵기 1.5px.
- 카드·프롬프트 창 바탕은 #2C2C2F, 테두리는 흰색 12%.

## 글자
- Geist(한글 Noto Sans KR Medium) 하나로 거의 다 해요. 큰 문장은 500 굵기, 자간 −0.03em, 줄 간격 1.0으로 빽빽하게, 화면 너비를 꽉 채우는 두 줄.
- 정보 줄은 Geist 500 대문자, 짧은 변의 4% 안팎. 사이사이에 흰 네모·타원 같은 작은 도형을 글자 대신 끼워요.
- 프롬프트 창의 이름표와 노드 꼬리표는 Geist Mono 400, 아주 작게(흰색 50%).
- 오프닝 작은 글은 짧은 변의 3%. 큰 기호 글자 줄과 크기 차이를 크게 둬요.

## 질감과 모양
- 화면 전체 질감은 없이 매끈하게. 질감은 글자 조각 안에만 있어요.
- 노드 카드: 모서리 1.2u, 검은 속 + 얇은 회색 테두리, 위 가장자리에 작은 이름표 줄, 좌우 가운데에 지름 0.6u 연결 점.
- 재질은 CSS 로 흉내 내요. 스펀지는 노랑 바탕에 어두운 작은 원 구멍 무늬(radial-gradient 반복) + 안쪽 그림자, 말랑이는 분홍에 큰 흰 하이라이트 하나 + 부드러운 안쪽 그림자, 크롬은 회색 띠 linear-gradient 여러 겹 + 가장자리 흰 반사.
- 그림자는 크롬 글자 아래 아주 옅은 검정 한 겹만.

## 움직임
- 120BPM. 장면은 1~2박마다 바뀌고, 재질 물결과 글자 맞추기는 반 박 안쪽의 잘게 쪼갠 간격으로 흘러요.
- 들어오는 건 power3.out 으로 빠르게 와서 부드럽게 멈춤. 글자 조각은 한 자씩 0.08~0.1초 간격으로 톡 놓여요.
- 카메라는 캔버스 위를 계속 천천히 미끄러져요(4초에 화면 너비의 10%). 한 카드에 다가갈 땐 1초 동안 2.5배까지.
- 엔딩의 크롬 글자는 기울어진 채(−25~+30도) 떨어져 하나씩 스프링으로 반듯해지고, 다 맞춰지면 2초 넘게 가만히 머물러요.

## 전환
- 컷이 기본. 캔버스 안에서 옆 카드로 옮길 땐 밀어내기(push), 카드나 프롬프트 창으로 바짝 들어갈 땐 흐림(blur) 전환으로 확대하며 넘겨요.
- 장면 쌓기: cut → push → blur.

## 대표 장면
1. **기호 글자 맞추기 오프닝**: 가운데 작은 글 한 줄을 `S.fx` 로 페이드 인, 1박 뒤 아래에 기호 글자 6~7개를 한 자씩 톡.
   ```
   const g = S.$$('.glyph');
   S.ambient(t => g.forEach((el, i) => {
     const k = M.spring(t - (1 + i * .09), 'snappy');
     M.place(el, x[i], cy + H * .08, {s: .6 + .4 * k, o: k});
   }));
   ```
2. **노드 캔버스와 연결선**: 글자마다 카드에 담아 흩어 놓고(`M.place` 로 약간씩 다른 깊이·크기), SVG 곡선 `path` 를 `M.draw(path, M.prog(t, t0, .6))` 로 카드 연결 점 사이에 그어요. 캔버스 묶음 전체를 `M.place(canvas, cx - t * W * .025, cy)` 로 천천히 흘리고, 마지막에 한 카드로 `S.tr.blur` 확대.
3. **프롬프트 타이핑 → 재질 물결**: 큰 창에 `M.type('스펀지 질감', t, t0, 14)` + 깜빡이는 커서. 컷 뒤 한 줄 타일을 두고, 타일 i 의 재질을 `M.at([[0,'flat'], [t1 + i * .1,'sponge'], [t2 + i * .1,'jelly'], [t3 + i * .1,'blue']], t)` 로 바꿔 클래스만 갈아 끼워요. 바뀌는 순간 `s = 1 + .04 * Math.max(0, 1 - (t - ti) / .15)`.
4. **크롬 글자 엔딩**: 위 정보 줄과 아래 큰 문장 두 줄은 `S.fx` 로 먼저 고정. 크롬 글자 i 는 `M.anim([[0, -H * .2], [ti, y0, {d: .5, e: 'outBack'}]], t)` 로 떨어뜨리고, 회전은 `rot = r0 * (1 - M.spring(t - ti, 'bouncy'))` 로 0도에 맞춰요. ti 는 0.35초 간격으로 순서를 섞어 3초 안에 다 맞춰지게.

- 피할 것: 밝은 바탕, 손그림 선과 종이 질감, 세리프 글꼴, 글자 조각 없이 문장만 있는 장면, 느린 페이드로만 잇기.
- 한글 큰 문장은 두 줄 안에서 끝내고, 재질을 입히는 건 짧은 낱말이나 기호로 만든 글자에만 해요.
