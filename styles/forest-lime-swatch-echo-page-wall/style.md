# 숲색 라임 견본 메아리 (그래픽·도형)

한 줄: 형광 라임과 짙은 숲색 두 판을 컷으로 오가요. 핸들 달린 둥근 사각이 펼쳐지며 마크가 드러나고, 마크 메아리 무늬, 키 큰 색 견본 카드, 사진 위 유리 카드, 비스듬히 흐르는 웹 화면 벽이 차례로 이어지는 리브랜딩 공개.

## 보는 느낌
- 화면은 거의 늘 색 한 판이에요. 쨍한 형광 라임 판과 짙은 숲색 판을 장면마다 번갈아 쓰고, 가끔 옅은 민트·옅은 회색 판으로 숨을 돌려요.
- 한 화면엔 주인공 하나만 둬요. 작은 문장 한 줄, 마크 하나, 커다란 기호 하나, 견본 카드 한 줄처럼요. 여백이 넉넉해요.
- 앞부분은 정체성 조각(마크, 글자 견본, 색 견본, 메아리 무늬)을 하나씩 보여 주고, 뒷부분은 그 조각이 실제 쓰임새(SNS 카드, 배너, 폰, 모니터, 웹 화면, 굿즈 사진)에 입혀진 모습을 차례로 보여 줘요.
- 단색 카드 위에 반들한 3D 소품(별, 동전)이 하나씩 떠서 천천히 돌기도 해요. 사진 장면에서는 실사 위에 젖빛 유리 카드가 떠 있어요.
- 끝은 웹 화면 수십 장이 어두운 바탕에 비스듬히 깔려 천천히 흐르는 벽, 사진 콜라주, 라임에서 민트로 번지는 판 위 3D 마크, 그리고 숲색 판 위 마크 하나로 닫혀요.

## 색
- 숲색 #23391A 45 · 라임 #4BD35B 35 · 흰빛 글자 #F1F5EC 15 · 나머지 5.
- 숲색 판 위 글자·마크는 흰빛, 마크 기호만 라임. 라임 판 위 글자는 흰빛(작은 문장)이나 숲색(큰 글자·버튼).
- 옅은 민트 #E7F0E3 는 견본 카드·조용한 장면 바탕. 쓰임새 장면에서 어두운 바탕 #111311 을 잠깐 써요.
- 산호 #D9606A 와 옅은 분홍 #EBC4C8 은 보조 색 견본 판에서만 넓게 보여 줘요. 다른 장면에서는 작은 칩 정도로만.

## 글자
- 문장·마크 옆 이름: Geist 500~600(한글 Noto Sans KR Medium·Bold). 둥글고 기하학적인 산세리프, 자간 −0.02em.
- 오프닝 문장은 아주 작게(짧은 변의 4~5%), 가운데 한 줄. 끝 낱말 하나만 늦게 맺혀요.
- 웹 화면·배너의 큰 제목은 Archivo 700~800 대문자, 두 줄 가운데 정렬, 자간 −0.01em.
- 기호 하나(앰퍼샌드 같은)를 짧은 변의 30% 크기로 라임 단독으로 세워 글자 견본을 열어요.
- 글자 견본 격자: 같은 두 글자를 칸마다 굵기를 달리해(100 → 900) 줄지어 놓고, 몇 칸은 굵기가 움직이는 중간 모양으로 둬요.

## 질감과 모양
- 질감 없이 매끈한 평면색. 그림자는 3D 소품과 떠 있는 카드에만 아주 옅게.
- 카드·견본·판 모서리는 `--u` × 1.6 둥글게. 견본 카드는 세로로 길쭉하게(너비:높이 1:2.4).
- 선택 핸들은 작은 정사각형 네 개, 라임 위에선 노란빛 도는 연두, 숲색 위에선 흰빛.
- 유리 카드: 흰색 18% + 블러 + 1px 흰 테두리 40%.

## 움직임
- 96BPM, 보통 빠르기. 장면은 2~3초씩 머물러요.
- 들어올 땐 `expo.out` 으로 성큼 들어와 부드럽게 멈춰요. 나갈 땐 거의 컷.
- 작은 문장은 흐림 6px → 0 으로 0.6초에 맺히고, 어절마다 0.12초씩 늦어요.
- 견본 카드는 한 박 간격으로 오른쪽에서 밀려 들어와요(0.5초, 스프링 'smooth').
- 3D 소품과 웹 화면 벽은 장면 내내 아주 천천히 움직여요(소품은 4초에 반 바퀴, 벽은 6초에 화면 너비 15%).

## 전환
- 컷이 기본이에요. 색 판이 라임 ↔ 숲색으로 박에 맞춰 툭 바뀌어요.
- 오프닝에서는 핸들 달린 둥근 사각이 펼쳐져 화면을 덮는 와이프(wipe), 쓰임새 장면 사이는 옆으로 밀어내기(push).
- 장면 쌓기: cut → wipe → push.

## 대표 장면
1. **핸들 사각이 펼쳐져 판이 바뀜**
   ```js
   // 라임 판, 작은 문장이 흐림에서 맺힘
   S.fx.blurIn(line, {at: .2, stagger: .12});
   // 숲색 둥근 사각 + 네 귀퉁이 핸들
   S.ambient(t => {
     const k = M.ease.outExpo(M.prog(t, M.beat(4), .7));
     const w = M.anim([[0, W * .38], [M.beat(4), W * 1.05, {d: .7, e: 'outExpo'}]], t);
     const h = M.anim([[0, H * .38], [M.beat(4), H * 1.05, {d: .7, e: 'outExpo'}]], t);
     M.box(rect, {x: W / 2 - w / 2, y: H / 2 - h / 2, w, h});
     handles.forEach(hd => hd.style.opacity = 1 - k);   // 다 덮으면 핸들은 사라짐
   });
   ```
   장면 쌓기에서는 title: blur, deco: handles 로 같은 결이 나와요. 이어지는 숲색 판에서 마크를 `M.draw` 로 0.6초에 그은 뒤 이름 글자를 흐림에서 맺어요.
2. **마크 메아리 무늬**: 숲색 판에 라임 마크 SVG 를 8~10장 복제해 각각 `M.place(m_i, x0 + i * d, y0 - i * d * .6)` 로 사선으로 겹쳐 놓고, 뒤로 갈수록 0.04초씩 늦게 나타나게 해요(`o = M.prog(t, i * .04, .05)`). 이 꼬리 하나를 격자로 3×3 반복해 화면을 채우고, 무늬 전체를 4초에 짧은 변의 5%만큼 대각선으로 흘려요.
3. **색 견본 카드 줄**: 옅은 민트 판에 세로 카드 4~5장. 카드 i 는 `x_i = M.anim([[0, W * 1.2], [i * M.beat(1), slot_i, {d: .5, e: 'outExpo'}]], t)`. 세 번째 카드에만 작은 이름표(Geist 500, 카드 아래쪽 왼편). 다음 판은 컷으로 산호·분홍 계열 카드 줄로 갈려요.
4. **글자 견본 격자와 웹 화면 벽**
   - 숲색 판에 두 글자 묶음을 6열 4줄로 놓고 열마다 `font-variation-settings: 'wght' ${M.lerp(150, 900, col / 5)}` 로 굵기를 달리해요. 장면 동안 굵기 값을 열마다 반 박씩 엇갈려 한 번 출렁이게 해요.
   - 끝 무렵 어두운 판에 밝은 웹 화면 카드 20~30장을 비스듬한 격자(rotate −6°)로 깔고 `S.ambient` 안에서 격자 전체를 천천히 왼쪽 위로 흘려요. `S.tr.push` 로 들어오고 컷으로 3D 마크 판에 넘겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 리브랜딩 공개, 금융·결제 앱 소개, 브랜드 가이드 발표, 새 웹사이트·앱 런칭, 굿즈·캠페인 묶음 소개.
- 피할 것: 손그림 선과 종이 질감, 그레인·주사선 같은 거친 결, 세리프 글꼴, 산호·분홍을 넓게 쓰기(견본 판에서만), 프레임 단위 글리치나 빠른 깜빡임.
- 두 톤(라임·숲색)이 이 결의 뼈대라서, 브랜드 색을 쓸 땐 쨍한 밝은 색 하나와 같은 계열의 아주 짙은 색 하나를 짝지어 주면 잘 살아요.
