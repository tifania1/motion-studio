# 숯빛 라임 신호 도표 (다이어그램·데이터)

한 줄: 숯빛 판 위에 라임 한 색이 선, 막대, 파형, 점 지구본으로 모양을 바꿔 가며 이어지고, 작은 가운데 문장은 어절마다 흐림에서 맺혀요.

## 보는 느낌
- 처음부터 끝까지 거의 검은 숯빛 판 하나예요. 화면 아래 귀퉁이에만 라임빛 안개가 옅게 번져 있고 나머지는 비워 둬요.
- 색은 라임 한 가지로 잇습니다. 선, 막대, 빛 점, 도형, 강조 낱말이 모두 같은 라임이라 장면이 바뀌어도 신호 한 줄기가 계속 흐르는 것처럼 보여요.
- 글은 작은 문장 한 줄이 화면 가운데에 놓이고, 도표가 그 둘레에 붙어 말을 받쳐요. 문장 아래 막대, 문장 위아래 파형, 문장 옆 지구본처럼요.
- 앱 창, 터미널, 설정 코드 카드는 어두운 판에 가는 라임 테두리 빛을 두르고 비스듬히 기울어 떠요. 그래프 장면에서는 카메라가 선 끝 한 구석으로 바짝 다가가요.

## 색
- 숯빛 80 · 흰 글자 12 · 라임 8.
- 바탕 #232323, 카드 판 #2C2D2B, 글자 #ECECEA.
- 라임 #8FD16A 는 막대, 꽉 찬 도형, 강조 낱말에. 옅은 라임 #B8EE98 은 가는 선, 그래프 선, 빛 점에.
- 비교할 때만 연어빛 #D98466 을 써요(느린 쪽 그래프 선, 위쪽 사인 곡선). 막대그래프에서 문제를 짚을 땐 붉은 막대 #C2504A 하나.
- 기다리는 낱말과 축 눈금은 흰색 50%.

## 글자
- Geist 500 과 Noto Sans KR Medium. 문장은 짧은 변의 4~5%, 자간 -0.01em. 큰 제목은 거의 쓰지 않아요.
- Geist Mono 는 터미널 명령, 설정 코드, 그래프 축 숫자에만.
- 가운데 정렬 한 줄이 기본이에요. 창이 오른쪽에 떠 있으면 왼쪽에 라임 글자 두 줄로 놓아요.
- 두 줄짜리 마무리 문장은 둘째 줄이 한 박 늦게 붙어요.

## 질감과 모양
- 그레인이나 종이 결 없이 매끈하게 둬요. 빛은 가장자리 라임 안개, 선 끝 빛 점, 창 테두리 빛 세 군데에만.
- 창과 카드는 모서리 1.2u, 1px 라임 테두리(30%)에 바깥 빛 한 겹.
- 선은 1~2px, 막대는 모서리를 거의 굴리지 않아요. 도형은 모서리를 깎은 세로로 긴 육각형, 선으로 그린 등각 상자, 정육면체 윤곽처럼 기하학적으로.

## 움직임
- 96BPM, 보통 빠르기. power3.out 으로 들어와 조용히 멈추고, 한 장면에 2~3초 머물러요.
- 어절은 흐림 6px 에서 선명해지며 0.35초 간격으로 붙어요.
- 선은 한 번에 그어지고, 막대는 왼쪽이나 아래에서 차오르고, 파형은 멈추지 않고 옆으로 흘러요.
- 낱말 원통은 1박마다 한 칸씩, 0.5초 inOutCubic 으로 굴러요.
- 창은 기울기 15~20°로 떠서 아주 천천히 돌고, 카메라는 그래프 쪽으로 4초에 1.4배쯤 다가가요.

## 전환
- 흐림 전환(blur)이 기본이고, 도표끼리는 컷으로 이어요.
- 지구본이 라임 구슬로 부풀어 화면을 덮는 순간엔 원형 열림(iris).
- 큰 원의 호가 라임 굵은 선으로 화면을 비스듬히 쓸고 가는 와이프를 한 번쯤 넣어요.
- 장면 쌓기: blur → cut → iris.

## 대표 장면

1. **낱말 원통 문장**: 앞 문장은 고정, 그 바로 뒤에 고르기 낱말 3~4개를 세로로 쌓고 박자마다 한 칸씩 굴려요.
   ```
   const items = S.$$('.drum span');
   S.ambient(t => {
     const k = M.anim([[0, 0], [M.beat(2), 1, {d: .5, e: 'inOutCubic'}], [M.beat(3), 2, {d: .5, e: 'inOutCubic'}]], t);
     items.forEach((el, i) => {
       const d = i - k, n = Math.min(Math.abs(d), 1);   // d = 0 이면 지금 자리
       M.place(el, x0, cy + d * lh, {o: 1 - n * .6, blur: n * 1.5});
       el.style.color = M.color('#8A8A8A', '#8FD16A', 1 - n);
     });
   });
   ```
2. **떨어지는 빛 선**: 위에서 라임 선이 내려와 문장을 뚫고 아래 빛 점으로 멈춰요. 마지막 어절은 흐림에서 맺혀요.
   ```
   const y = M.anim([[0, 0], [.2, cy + lh * 1.5, {d: .7, e: 'outCubic'}]], t);
   M.box(beam, {x: cx - 2, y: 0, w: 4, h: y});          // 둘레에 blur 빛 한 겹
   M.place(dot, cx, y, {s: M.spring(t - .9, 'smooth')});
   M.place(lastWord, wx, cy, {o: M.prog(t, .6, .5), blur: (1 - M.prog(t, .6, .5)) * 8});
   ```
3. **도표 사이에 놓인 문장**: 위에 연어빛 사인 곡선, 아래에 라임 막대 파형을 두고 문장은 가운데에서 맺혀요. 끝나면 선으로 그린 등각 층 두 장이 육각 윤곽 안에 그어지고, 이어 꽉 찬 라임 육각 도형으로 바뀌어요.
   ```
   S.ambient(t => {
     sine.setAttribute('d', wave(t * .4));                // 위상만 밀어 옆으로 흐름
     bars.forEach((b, i) => {
       const h = .3 + .7 * Math.abs(Math.sin(i * .35 - t * 2));
       M.box(b, {x: x0 + i * bw, y: base - h * hMax, w: bw * .7, h: h * hMax});
     });
     layers.forEach((p, i) => M.draw(p, M.ease.outCubic(M.prog(t, M.beat(4) + i * .2, .6))));
     hex.style.opacity = M.prog(t, M.beat(6), .3);        // 윤곽 → 꽉 찬 라임
   });
   ```
   비교 그래프 장면은 두 선을 `M.draw` 로 0.8초에 긋고(연어빛 위, 라임 아래), 카메라를 선 끝 쪽으로 천천히 당겨요.
4. **점 지구본에서 라임 구슬, 그리고 호를 따라 도는 이름**: 위경선 점 300개를 구에 뿌려 y축으로 천천히 돌리고, `M.rng(7)` 로 고른 빛 점 8개를 0.2초 간격으로 켜요. 다음 박에 구 반지름을 키우며 라임으로 채우고 `S.tr.iris` 로 다음 장면을 열어요.
   ```
   const R = M.anim([[0, r0], [tB - .8, M.floodRadius(cx, cy), {d: .8, e: 'inOutCubic'}]], t);
   // 다음 장면: 오른쪽에 큰 원의 호(1px 흰 40%), 이름 목록이 호를 따라 돎
   names.forEach((n, i) => {
     const a = a0 + i * .35 - t * .25;
     M.place(n, cx2 + Math.cos(a) * Rr, cy + Math.sin(a) * Rr, {o: 1 - Math.min(Math.abs(Math.sin(a)) * 1.6, 1)});
   });
   ```
   마무리는 라임 정육면체 윤곽을 `M.draw` 로 긋고 아래에 라임 이름 한 줄. 마지막에 꽉 찬 라임 판이 접히며 흐림 속으로 빠져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발 도구·인프라 소개, API·플랫폼 런칭, 성능 수치 비교, 확장성·전 세계 서비스 설명, 기술 블로그 요약 영상.
- 피할 것: 밝은 바탕, 강조색 여러 개(라임 하나와 비교용 연어빛, 경고용 붉은 막대 하나만), 화면을 채우는 굵은 제목, 손그림·종이 질감, 빠르게 몰아치는 컷.
- 한 장면에 문장 하나와 도표 하나만 두면 이 결이 가장 잘 살아요.
