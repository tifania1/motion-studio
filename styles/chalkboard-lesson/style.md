# 칠판 수업 (손그림)

한 줄: 짙은 초록 칠판에 분필로 쓰는 수업. 분필 가루 결이 남은 흰 글씨, 강조는 노란 분필 밑줄과 동그라미예요.

## 보는 느낌
- 왼쪽 정렬 판서. 제목 한 줄 → 아래로 짧은 설명 → 옆에 작은 그림이나 화살표.
- 가장자리는 비네트로 어둡게, 가운데가 조금 밝아 칠판에 조명이 든 느낌.
- 지운 자국: 장면이 바뀔 때 앞 글씨의 흐릿한 흔적이 잠깐 남아요.

## 색
- 칠판 70 · 흰 분필 25 · 노란 분필 5.
- 칠판(#22302A), 흰 분필(#F1F0E8), 노란 분필(#F2D35B)이 강조.
- 하늘색(#8FD3E8)·분홍(#F29C9C) 분필은 그림에만, 장면마다 하나.

## 글자
- 한글 나눔손글씨 펜, 숫자·영문 큰 글은 Caveat, 작은 글은 개구 굵게.
- 제목 짧은 변의 8%, 설명 5.5%. 줄 간격 1.2. 판서답게 한 줄을 짧게.

## 질감과 모양
- 그레인 0.24(초당 8번 바뀜)가 분필 가루 결 역할을 해요. 종이 질감은 쓰지 않아요.
- 비네트 0.4, 선 떨림 0.9(초당 8번), 움직임은 초당 12장으로 끊어서.
- 카드는 테두리만(outline) 분필 선으로. 막대는 빗금으로 칠함.

## 움직임
- 96BPM. 글씨는 쓰는 속도로: 어절 간격 1.5배, power1.out(넘치지 않음).
- 밑줄·동그라미는 글을 다 쓴 뒤 반 박 쉬고 0.45~0.6초에.
- 칠판이라 튀거나 확대되는 움직임은 쓰지 않아요.

## 전환
- 서서히(fade) 위주, 가끔 컷. 지우개로 지운 것처럼 앞 장면이 흐려지며 다음 판서가 시작돼요.

## 대표 장면

1. 판서 제목 + 노란 밑줄
   ```
   S.fx.rise(S.words(ttl), T0 + .15, { stagger: .07 * 1.5, ease: 'power1.out', y: 0 });   // 제자리에서 써지듯
   // 장면 쌓기는 marker: underline + rough 로 노란 분필 밑줄이 자동으로 그어짐
   ```
2. 지우개 전환
   - S.tr.fade 로 바꾸되, 앞 장면 복제를 opacity .12 · blur(0.4u) 로 0.6초 남겨 지운 자국처럼 보이게(직접 짤 때).
3. 분필 도표
   - 축은 M.rough('line'), 막대는 M.rough('rect') 테두리 + 빗금 채우기. 숫자는 Caveat 로 막대 위에.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 강의·학원 홍보, 개념 설명, 시험·입시 일정 안내, 꿀팁 시리즈, 어두운 분위기 공지.
- 피할 것: 흰 바탕, 사진 많이, 반짝이는 효과, 정교한 UI 화면.

## 배운 곳
- 직접 정리. 갤러리 영상에서 배운 게 아니고, 칠판 판서 설명 영상에서 널리 쓰는 기법(분필 결 그레인, 쓰는 속도, 노란 분필 강조, 지우며 넘어가기)으로 정리했어요.
- 갤러리에서 배운 손그림 결은 따로 있어요: marker-scrawl-montage, chalk-math-board, doodle-faces-strikeout, manga-panel-bubbles, river-line-lettering, serif-marker-word, ink-gesture-blobs, navy-etching-plates.
