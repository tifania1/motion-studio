# 점 잇기 낱말과 무지개 테두리 입력창 (그라디언트·빛)

한 줄: 숯빛 어둠에 흰 점들이 떠 있고, 낱말이 점 자리에 하나씩 놓이면 가는 선이 점을 잇고 뒤로 네 가지 색 빛 덩어리가 번져요. 옅은 회색 판에서는 알약 입력창에 큰 글자가 쳐지고, 어두운 판으로 돌아오면 입력창 테두리에 무지개 빛이 돌아요.

## 보는 느낌
- 세 막으로 흘러요. 처음은 숯빛 바탕의 별자리 같은 점과 작은 낱말, 가운데는 옅은 회색 판의 큰 글자와 하얀 입력창, 끝은 다시 어두운 판에서 빛 테두리를 두른 입력창이에요.
- 어두운 장면은 여백이 아주 넓어요. 화면에 흰 점 몇 개와 작은 낱말 한두 개, 그 뒤 흐린 색 빛 덩어리 하나가 전부예요.
- 밝은 장면은 거의 흰빛에 가까운 회색 위에 물건 하나(입력창, 비스듬히 누운 폰, 큰 낱말)만 두어요. 색은 아주 가는 무지개 선이나 고리로만 들어와요.
- 색 네 가지(파랑·빨강·노랑·초록)는 늘 함께 다니며 흐리게 번진 빛이나 가는 선으로만 보여요. 넓은 색면으로 칠하지 않아요.

## 색
- 어두운 장면: 숯빛 #1E1F23 80 · 흐린 색 빛 15 · 흰 글자와 점 5.
- 밝은 장면: 옅은 회색 #E6E7EA 85 · 먹 글자 #1F2023 12 · 무지개 선 3.
- 빛 네 색: 파랑 #4A86F0, 빨강 #E5483F, 노랑 #F2B632, 초록 #3DAA5C. 빛 덩어리는 이 중 하나를 30~50% 불투명도로 크게 흐려서 써요.
- 강조(accent)는 파랑. 큰 낱말의 마지막 글자, 문장 속 핵심 낱말 하나에만 칠해요. 파랑 버튼 위 글자는 아주 짙은 남색.

## 글자
- 둥글고 담백한 산세리프(Geist, 한글은 Noto Sans KR Medium). 굵기 400, 자간 -0.01em.
- 어두운 장면의 낱말은 작아요. 화면 높이 2.5~3%, 흰색. 점 옆에 붙여서 위·아래로 엇갈려 놓아요.
- 밝은 장면의 큰 낱말은 화면 높이 18~22%, 먹색, 가운데 한 줄. 마지막 글자만 파랑.
- 입력창 안 문구는 화면 높이 3.5% 안팎, 왼쪽 정렬, 끝에 가는 커서.

## 질감과 모양
- 질감은 거의 없이 매끈하게. 어두운 장면에 비네트 0.25 만 살짝.
- 빛 덩어리는 `blur(8~12u)` 로 아주 흐리게, 가장자리가 보이지 않게.
- 점은 지름 0.5u 흰 원, 선은 1px 흰색 50~70%. 색 선은 2~3px 에 선 따라 색이 바뀌는 그라디언트.
- 입력창은 완전한 알약 모양(모서리 `--u` × 3 이상), 흰 바탕에 아주 옅은 그림자. 어두운 판에서는 속이 숯빛이고 테두리만 무지개 빛.
- 폰·카드는 30~40도 눕혀 비스듬히, 그림자는 부드럽게 한 겹.

## 움직임
- 96BPM, 서두르지 않아요. 낱말 하나에 한 박에서 두 박.
- 선은 `power2.inOut` 으로 0.5~0.8초에 그어지고, 빛 덩어리는 1초에 피었다 1.5초에 스러져요.
- 큰 낱말 타자는 초당 8~10자, 입력창 문구는 초당 18자 안팎.
- 무지개 테두리 빛은 4초에 한 바퀴, 쉬지 않고 천천히 돌아요. 로딩 고리는 1.2초에 한 바퀴.
- 카메라는 비스듬히 누운 폰이나 입력창 옆을 천천히 미끄러지듯 지나가요. 지나갈 때 앞쪽은 살짝 흐려져요.

## 전환
- 흐림 전환(blur)이 기본. 어두운 판에서 밝은 판으로 넘어갈 땐 빛 덩어리가 화면 가득 커지며 하얗게 바래요.
- 원형 열림(iris)은 로딩 고리나 빛 고리가 커지며 다음 장면이 될 때. 그 밖에 느린 페이드, 막을 바꿀 때만 컷.
- 장면 쌓기: blur → iris → fade → cut.

## 대표 장면

1. 점 잇기 낱말과 피어나는 빛
   ```js
   // 점 좌표 pts 와 낱말 words 를 짝지어 두고, 박마다 하나씩
   const dots = S.$$('.dot'), words = S.$$('.word'), lines = S.$$('.link path'), blobs = S.$$('.blob');
   S.ambient(t => {
     words.forEach((w, i) => {
       const t0 = i * M.beat(1.5);
       const k = M.ease.outCubic(M.prog(t, t0, .4));
       M.place(w, pts[i].x + 1.2 * u, pts[i].y, { o: k, blur: (1 - k) * 3 });
       if (lines[i]) M.draw(lines[i], M.ease.inOutCubic(M.prog(t, t0 - .2, .6)));
       const b = M.prog(t, t0, 1) - M.prog(t, t0 + 1, 1.5);   // 피었다 스러짐
       M.place(blobs[i % 4], pts[i].x, pts[i].y, { o: b * .45, s: .7 + b * .5 });
     });
   });
   ```
   - 빛 덩어리 넷은 파랑·빨강·노랑·초록 원에 `filter: blur(10u)`. 뒤 장면에서는 직선 대신 색 그라디언트 `path`(사인 물결, 나선)를 같은 `M.draw` 로 그어요.
2. 옅은 회색 판의 큰 타자와 무지개 고리
   ```js
   // 큰 낱말을 한 글자씩, 마지막 글자만 파랑
   S.ambient(t => {
     const s = M.type(word, t, .3, 9);
     big.innerHTML = s.slice(0, -1) + '<b style="color:var(--accent)">' + s.slice(-1) + '</b>';
     ring.style.transform = 'rotate(' + (t * 300) + 'deg)';   // conic-gradient 고리, 1.2초에 한 바퀴
   });
   ```
   - 다음 박에 큰 낱말이 흐려지며 알약 입력창이 `M.spring(t - t1, 'smooth')` 로 떠오르고, 입력창 오른쪽 아이콘 둘레에 같은 고리가 돌아요. 장면 쌓기에서는 title: type 으로 같은 결이 나와요.
3. 어두운 판 입력창의 무지개 테두리 빛
   ```js
   // 알약 둘레에 conic-gradient 를 깔고 안쪽은 숯빛으로 덮어 테두리만 남김
   S.ambient(t => {
     const a = (t / 4) * 360;
     edge.style.background = 'conic-gradient(from ' + a + 'deg, #4A86F0, #E5483F, #F2B632, #3DAA5C, #4A86F0)';
     halo.style.background = edge.style.background;   // 같은 그라디언트를 blur(3u) 로 한 겹 더 깔아 번지게
   });
   // 입력창은 비스듬히 누운 채 들어와 천천히 바로 섬
   M.place(pill, cx, cy, { r: M.anim([[0, -12], [1.6, 0, { d: 1.6, e: 'inOutCubic' }]], t) });
   ```
4. 색이 갈라졌다 모이는 낱말
   - 같은 낱말을 세 겹(빨강·초록·파랑, `mix-blend-mode: screen`) 겹쳐 두고 가로로 `±1.5u` 벌렸다가 `M.anim` 으로 0.6초에 0으로 모아 흰 글자로 맺혀요. 벌어져 있는 동안 `blur` 2px.
   - 이어서 흐린 색 고리(네 색 원을 원형으로 늘어놓고 크게 흐림) 가운데 낱말 하나를 두고, 둘레에 작은 유리 꼬리표 3~4개가 `M.drift` 로 떠다녀요. 장면을 넘길 땐 `S.tr.blur`.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 검색·질문 서비스 런칭, 음성·카메라 입력 기능 소개, 차분한 기술 브랜드 티저, 새 입력 방식 안내. 40~70초쯤의 조금 긴 소개 영상에서 세 막 구성을 살리기 좋아요.
- 피할 것: 굵은 제목, 한 색을 넓게 칠한 색면, 손그림 선과 종이 질감, 빠른 컷 연속, 한 화면에 문장 여러 줄.
- 무지개 네 색은 늘 함께, 흐린 빛이나 가는 선으로만 써요. 한 색만 따로 크게 쓰면 이 결이 흐트러져요.
