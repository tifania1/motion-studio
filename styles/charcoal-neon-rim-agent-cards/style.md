# 숯빛 네온 테두리 에이전트 카드 (제품 UI)

한 줄: 짙은 회색 판 가운데에 굵은 흰 문장이 놓이고 끝말만 금빛으로 물들어요. 어두운 UI 카드 테두리를 따라 자홍에서 금빛으로 번지는 빛이 돌고, 가는 선 끝의 흰 점이 문장과 아이콘 칩을 하나씩 이어 가는 AI 에이전트 소개 필름이에요.

## 보는 느낌
- 바탕은 내내 고른 숯빛 회색 한 장이에요. 무늬도 그라디언트도 깔지 않고, 가장자리만 살짝 어두워요.
- 화면마다 주인공은 하나예요. 가운데 굵은 흰 문장 한두 줄이거나, 어두운 UI 카드 한 장(대화창, 차트 카드, 순위 목록)이에요.
- 빛은 아껴 써요. 카드 테두리, 대화창 아래로 부채처럼 퍼지는 곡선, 한 점으로 모이는 빛줄기처럼 장면마다 한 곳에서만 자홍·금빛이 번져요.
- 문장과 UI가 섞여요. 문장 속 빈칸에 아이콘 칩이나 작은 카드 더미가 끼어들고, 문장 아래로 카드가 떠오르기도 해요.
- 여백이 넉넉해요. 카드는 화면 너비의 40~55%, 문장은 60% 안쪽.

## 색
- 숯빛 바탕 75 · 흰 글자와 회색 카드 18 · 빛(금빛·자홍) 5 · 초록 2.
- 바탕 #202020, 카드 면 #2B2B2B, 카드 테두리 흰색 8~12%.
- 글자 흰색 #F3F3F1, 보조 글씨는 같은 흰색 56%.
- 강조 금빛 #F2B23A → 주황 #EE7A3B 그라디언트는 문장 끝말 하나에만. 자홍 #C83CE6 은 테두리 빛, 빛줄기, 사선 와이프 판에만.
- 초록 #4BD66A 은 수익 숫자, 고른 줄 테두리, 버튼 아이콘처럼 '좋다·됐다' 신호에만.

## 글자
- Geist 700(한글은 Noto Sans KR Bold), 자간 −0.02em. 둥글지 않고 단단한 산세리프.
- 큰 문장은 짧은 변의 7~9%, 가운데 정렬 두 줄, 줄 간격 1.1.
- 카드 속 글씨는 Geist 400~500, 짧은 변의 2~2.5%로 작게. 숫자는 고정폭처럼 반듯하게 맞춰요.
- 알약 버튼(공유, 몇 분 만에 시작 같은 한마디)은 Geist 600, 회색 테두리 알약 안에 초록 아이콘 하나.

## 질감과 모양
- 비네트 0.22 만. 그레인·주사선은 쓰지 않고 매끈하게.
- 카드: 모서리 1.6u, 면 #2B2B2B, 1px 흰색 10% 테두리, 그림자 없이 평평하게.
- 네온 테두리: 카드 바깥 2px 선에 자홍 → 주황 → 금빛 원뿔 그라디언트, 바깥으로 블러 2~3u 번짐 한 겹.
- 아이콘 칩: 지름 3u 원, 짙은 속에 그라디언트 고리 테두리.
- 가는 선은 1px 흰색 35%, 끝에 지름 0.6u 흰 점.

## 움직임
- 100BPM, 장면 하나에 2~4초 머물러요. 서두르지 않지만 들어오는 순간은 빨라요.
- 들어오기: `expo.out` 0.5초. 문장은 어절마다 0.12초 간격으로 아래 마스크에서 올라오거나 선 끝에서 옆으로 미끄러져 나와요.
- 칩은 스프링으로 톡 튀어 크기 0 → 1.08 → 1.
- 테두리 빛은 4초에 한 바퀴 천천히 돌아요. 빛줄기는 1초 안에 한 점으로 모여요.
- 나가기: 대부분 컷. 문장이 옆으로 밀려 마스크 밖으로 빠지기도 해요.

## 전환
- 컷이 기본이에요.
- 사이사이 자홍 판이 사선으로 화면을 쓸고 지나가며 다음 장면을 열어요(wipe).
- 마무리 쪽은 느린 페이드. 장면 쌓기: cut → wipe → fade.

## 대표 장면

1. **금빛 끝말 문장과 끼어드는 칩**
   ```js
   const words = S.words(title);                  // 어절로 나눔
   words.forEach((w, i) => S.fx.rise(w, { at: .2 + i * .12, d: .5, ease: 'expo.out' }));
   last.style.backgroundImage = 'linear-gradient(90deg,#F2B23A,#EE7A3B)';
   last.style.webkitBackgroundClip = 'text'; last.style.color = 'transparent';
   // 문장 둘레 아이콘 칩 4개가 톡
   chips.forEach((c, i) => S.ambient(t => {
     const k = M.spring(t - (1 + i * .15), 'bouncy');
     M.place(c, c.x, c.y, { s: k, o: Math.min(1, k * 2) });
   }));
   ```
   빈칸 자리에는 작은 카드 3~4장을 비스듬히 겹친 더미를 두고, 어절 사이를 벌리며 그 자리에 쏙 들어가게 해요.

2. **네온 테두리 카드와 클릭**
   ```js
   S.ambient(t => {
     rim.style.background = `conic-gradient(from ${t * 90}deg, #C83CE6, #EE7A3B, #F2B23A, #C83CE6)`;
     rim.style.filter = 'blur(calc(var(--u) * 2.5))';
     const k = M.prog(t, 2.4, .3);                 // 커서가 누른 뒤
     row.style.borderColor = M.color('rgba(255,255,255,.1)', '#4BD66A', k);
   });
   const cur = new M.Cursor(S.stage); M.cursorAt(cur, row, 2.4);
   ```
   카드는 아래에서 2u 올라오며 나타나요(`M.spring(t, 'smooth')`). 수익 숫자는 초록으로 `M.count` 해요.

3. **선 끝 흰 점과 갈래 목록**
   ```js
   S.ambient(t => {
     M.draw(line, M.ease.outCubic(M.prog(t, 0, .6)));          // 왼쪽에서 선이 그어지고
     M.place(dot, M.anim([[0, 0], [0, endX, { d: .6, e: 'outCubic' }]], t), cy);
     text.style.clipPath = `inset(0 0 0 ${(1 - M.prog(t, .5, .5)) * 100}%)`; // 점 뒤로 문장이 미끄러져 나옴
     branches.forEach((b, i) => M.draw(b, M.prog(t, 1.2 + i * .2, .4)));   // 갈래 셋, 끝에 칩과 이름표
   });
   ```

4. **한 점으로 모이는 빛줄기, 원 속 마무리**
   - 자홍 곡선 6~8가닥을 SVG path 로 깔고, 각 선 위 작은 빛 점을 `M.along(path, k)` 로 끝점까지 1초에 몰아요. 선은 `stroke-dashoffset` 으로 뒤꼬리가 사라지게.
   - 이어 `S.tr.fade` 로 넘어가, 짧은 변의 80% 지름의 1px 원을 `M.draw` 로 그린 뒤 가운데 한 줄을 놓아요. 가운데 낱말만 금빛 그라디언트.
   - 장면 사이 자홍 사선 판: `S.tr.wipe(prev, next, { angle: 62, color: '#C83CE6', d: .45 })`.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 에이전트·자동화 서비스 소개, 투자·트레이딩 도구, 대화형 제품 기능 투어, 개발자 도구 런칭, 1분 안팎의 기능 설명 영상.
- 피할 것: 밝은 바탕, 손그림·종이 질감, 세리프 글꼴, 카드마다 다른 강조색, 모든 요소에 빛 번짐 넣기, 한 화면에 문장 여러 줄.
- 빛은 장면마다 한 곳만 켜야 숯빛 판이 살아요.
