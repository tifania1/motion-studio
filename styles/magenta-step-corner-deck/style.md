# 마젠타 계단 모서리 덱 (제품 UI)

한 줄: 아주 옅은 회색 판의 두 모서리로 빨강·자홍 계단 도형이 밀려 들어와 장면을 감싸요. 가운데에는 짙은 자두색 어절과 그라디언트 끝말이 흐림에서 맺히고, 자홍 핸들을 단 흰 카드가 밝은 앱 창으로 펼쳐져요.

## 보는 느낌
- 바탕은 거의 흰 옅은 회색 한 장이에요. 무늬 없이 넓게 비워 두고, 한가운데에 문장 한 줄이나 흰 카드 하나, 앱 창 하나만 둬요.
- 화면 가장자리는 계단 도형이 지켜요. 둥근 사각 칸을 계단처럼 엇갈려 붙인 덩어리가 대각선 두 모서리에서 화면 밖으로 반쯤 잘린 채 들어와요. 한 장면은 빨강·자홍, 다음 장면은 파랑으로 모서리를 번갈아 맡아요.
- 글 장면의 문장은 어절이 반듯하게 한 줄로 서지 않아요. 크기와 기준선이 조금씩 달라서 계단처럼 살짝 엇갈려 보여요.
- 앱 장면은 밝은 브라우저 창이에요. 왼쪽에 쪽 목록, 가운데 큰 슬라이드, 오른쪽에 대화 패널이 있고, 슬라이드 안만 사진이나 어두운 판으로 색이 진해요.
- 슬라이드 귀퉁이에 흑백 체크무늬 픽셀 조각(3×3~4×4 칸)이 하나씩 붙어 있어요. 계단 도형과 같은 '칸' 감각이에요.

## 색
- 회색 바탕 75 · 흰 카드·앱 창 15 · 자두색 글자 6 · 그라디언트 4.
- 바탕 #EDEDEC, 글자 짙은 자두 #3A1432, 카드 흰색 #FFFFFF.
- 그라디언트: 빨강 #E3263F → 자홍 #D62E9E → 보라 #8E2BB0. 끝 어절, 계단 도형, 보내기 버튼, 보낸 말풍선에만 써요.
- 파랑 #2F7BE0 은 계단 도형의 짝꿍 색으로만, 빨강 묶음과 같은 화면에 나오지 않게 장면마다 번갈아요.
- 강조색(accent) #C81E64 위 글자는 흰색. 핸들 네모와 버튼에 써요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 제목 굵기 600, 자간 −0.03em 으로 단단하게 모아요.
- 큰 문장은 짧은 변의 7~9%. 한 문장 안에서 어절 크기를 0.85~1.1배로 섞고, 기준선을 ±0.6u 엇갈려요.
- 앞 어절은 자두색 그대로, 끝 어절 하나에만 그라디언트(`background-clip: text`)를 입혀요.
- 카드 안 문구와 입력창 글은 400~500, 짧은 변의 4% 안팎. 앱 창 속 작은 UI 글씨는 회색으로 흐리게.

## 질감과 모양
- 질감 없이 매끈해요. 그레인·비네트를 쓰지 않아요.
- 카드·앱 창 모서리 1.4u, 아주 부드러운 그림자 한 겹(아래 2u, 흐림 6u, 검정 8%).
- 계단 도형은 칸마다 안쪽 모서리를 둥글게(0.8u) 굴려서 딱딱한 픽셀보다 말랑해 보여요.
- 선택 핸들은 0.8u 정사각 자홍 칠, 테두리 없음. 카드 귀퉁이에 정확히 걸쳐요.

## 움직임
- 100BPM, 보통 빠르기. 들어올 땐 `power3.out` 으로 미끄러져 와서 부드럽게 멈춰요.
- 어절은 0.12초 간격으로 흐림 6px·농도 30%·아래 1u 에서 0.5초에 맺혀요. 마지막 어절은 반 박 더 연하게 머물렀다 차올라요.
- 계단 도형은 장면 시작 0.2초 뒤 0.6초에 대각선 바깥에서 밀려 들어오고, 장면이 끝날 때 같은 길로 0.5초에 빠져요.
- 앱 장면에서는 카메라가 천천히 다가가요(4초에 1.0 → 1.15배). 입력창에 붙을 땐 2배 넘게 확대하고 커서를 따라 옆으로 흘러요.
- 글은 초당 18~22자로 쳐지고, 한 장면에 3~5초 머물러요.

## 전환
- 흐림 전환이 기본이에요. 뒤 앱 창이 흐려지며 물러나고 앞의 입력 카드만 선명하게 떠요.
- 계단 도형이 모서리를 덮었다 걷히는 블록 전환(blocks)으로 글 장면과 앱 장면을 이어요.
- 앱 창 안에서 슬라이드가 바뀔 땐 컷, 쪽을 넘길 땐 밀어내기. 장면 쌓기: blur → blocks → cut → push.

## 대표 장면

1. **계단 도형이 감싸는 글 장면**
   ```
   // 모서리마다 둥근 사각 3칸을 엇갈려 붙인 묶음 하나씩 (빨강·자홍 또는 파랑)
   const steps = S.$$('.step');            // [오른쪽 위, 왼쪽 아래]
   const dir = [[1, -1], [-1, 1]];          // 바깥 방향
   S.ambient(t => {
     steps.forEach((g, i) => {
       const inK  = M.ease.outCubic(M.prog(t, .2 + i * .12, .6));
       const outK = M.ease.inCubic(M.prog(t, tEnd - .5, .5));
       const off = (1 - inK + outK) * W * .35;
       M.place(g, cx[i] + dir[i][0] * off, cy[i] + dir[i][1] * off);
     });
   });
   // 칸 채우기: linear-gradient(135deg, #E3263F, #D62E9E 60%, #8E2BB0)
   ```
   장면 쌓기에서는 title: blur 로 어절이 흐림에서 맺히고, 다음 장면은 S.tr.blocks 로 넘어가요. 다음 장면의 계단은 파랑으로 바꿔 반대 모서리에.
2. **엇갈린 그라디언트 어절**
   ```
   const words = S.$$('.w');                // 마지막 .w 에만 .grad (background-clip: text)
   words.forEach((w, i) => {
     const k = M.ease.outCubic(M.prog(t, .3 + i * .12, .5));
     const last = i === words.length - 1 ? M.prog(t, .3 + i * .12 + .6, .4) : 1;
     M.place(w, x[i], y[i] + (1 - k) * U, { o: (.3 + .7 * k) * (.45 + .55 * last), blur: (1 - k) * 6 });
   });
   // y[i] 는 기준선을 ±0.6u 엇갈리게, 글자 크기는 어절마다 0.85~1.1배
   ```
3. **자홍 핸들 카드 → 앱 창**
   - 흰 카드를 `M.box(card, {x, y, w, h})` 로 가운데에 띄우고, 네 귀퉁이 핸들을 0.06초 간격으로 `M.spring(t - ti, 'snappy')` 크기 0 → 1. 안의 문구는 `M.type(text, t, t0, 20)`, 끝말은 그라디언트에 말줄임 점 셋이 박자마다 깜빡여요.
   - 두 박 뒤 같은 `M.box` 를 화면 85% 크기의 브라우저 창으로 0.8초(`inOutCubic`)에 키우고 핸들은 컷으로 지워요. 장면 쌓기의 frame: browser, deco: handles 가 같은 결이에요.
4. **입력창 확대와 흐림 초점**
   - 카메라를 입력창에 2.2배로 붙이고 `camX = M.anim([[t0, x0], [t0 + 2.4, x1, {d: 2.4, e: 'inOutSine'}]], t)` 로 커서(`M.Cursor`)를 따라 옆으로 흘러요. 글은 `M.type` 으로.
   - 앱 창 위에서 고칠 말을 받을 땐 뒤 창에 `blur 8px, o .6` 을 0.5초에 걸고 앞에 입력 카드를 아래에서 2u 올려 띄워요(`S.tr.blur`). 보내기 버튼을 누르면 카드가 오른쪽 대화 패널의 자홍 말풍선 자리로 줄어 들어가고 흐림이 걷혀요.
