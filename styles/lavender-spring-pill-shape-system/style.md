# 라벤더 탄력 알약 시스템 (제품 UI)

한 줄: 옅은 라벤더 바탕에서 둥근 알약 버튼과 UI 카드가 스프링처럼 눌렸다 튀며 모양을 바꾸고, 물결 선 위를 글자가 통통 타고 넘은 뒤 물결 테두리 도형과 넓은 대문자가 컷마다 터지는 디자인 시스템 공개.

## 보는 느낌
- 기본 바탕은 아주 옅은 라벤더. 가운데에 산세리프 제목 한 줄이나 버튼 몇 개만 두고 여백을 넉넉히 남겨요.
- 장면마다 바탕색이 갈려요: 라벤더 → 짙은 자두(테마 바뀜) → 검정(움직임 설명) → 하늘빛(버튼·도형) → 크림(색 견본) → 검정(마무리). 한 장면에는 바탕 한 색.
- 모든 것이 둥글어요. 버튼은 알약, 카드는 크게 둥근 네모, 도형은 물결 테두리 원·꽃·오각형처럼 말랑한 모양.
- 화면 구성은 둘로 나뉘어요. 차분한 장면엔 큰 UI 조각 하나에 바짝 붙고, 신나는 장면엔 도형·색 점·스티커가 한가득 흩어져요.

## 색
- 바탕 70 · 글자와 UI 선 15 · 원색 버튼·도형 15.
- 라벤더 #E8E0F0, 글자 먹색 #1C1B1F, 짙은 자두 #2E1F3A(어두운 테마 판).
- 강조는 분홍 #EE8A98(닫기 버튼, 물결 선, 마무리 큰 글자). 글자는 짙은 밤색 #2B1016.
- 하늘빛 판 #A9CBEB 위에서는 청록 #3DB4E6 알약 버튼, 그 밖에 노랑 #E8C93A·보라 #C98BE0·주황 #D9875E·빨강 #E0605A 를 도형과 견본에 한 장면 두세 색씩.
- 제목 장면 뒤에는 분홍·주황 빛이 가운데서 번지는 부드러운 그라디언트를 한 번 깔아요(mesh).

## 글자
- 제목·UI 글: Geist 500(한글 Noto Sans KR Medium). 둥글고 반듯한 산세리프, 자간 −0.01em. 버튼 글자는 짧은 변의 3~4%.
- 움직임 설명 낱글자: Geist Mono 400, 글자 사이를 크게 벌려 한 글자씩 따로 움직이게.
- 큰 한 방: Archivo 900, stretch 125%, 기울여서(skewX −10°) 화면 너비를 꽉 채우고 가장자리는 잘려도 돼요. 한글은 Noto Sans KR Black 두세 글자.
- 글자 크기 견본 장면: 같은 낱말을 굵기와 크기만 달리해 짙은 판 위 칸칸에 늘어놓고, 칸 위에 아주 작은 고정폭 이름표.

## 질감과 모양
- 질감은 쓰지 않아요. 매끈한 평면 색에 그림자 아주 옅게 한 겹.
- 카드 모서리 `--u` × 2.4, 버튼은 완전 알약(높이의 절반). 작은 아이콘 버튼은 둥근 네모로 시작해 눌리면 알약이 돼요.
- 도형은 물결 테두리(꼭짓점 8~14개를 둥글게 이은 원), 꽃잎 원, 둥근 오각형. 선 없이 칠만.

## 움직임
- 112BPM, 한 박 0.54초. UI 변화는 박에 맞춰 일어나요.
- 이징은 `back.out(1.6)` 이나 스프링. 모든 것이 목표를 살짝 지나쳤다 돌아와요(오버슛 5~10%).
- 눌림: 0.12초에 scaleX 1.08·scaleY 0.9 로 납작 → 0.4초 스프링으로 새 모양. 이웃 요소가 같이 밀려요.
- 테마·색이 바뀔 땐 색만 0.3초에 번지고 배치는 그대로 둬요.
- 큰 도형이 지나갈 땐 0.3초 안에 휙, 이동 방향으로 흐림을 끌어요.

## 전환
- 컷이 기본. 장면 바탕색이 컷마다 갈려 리듬을 만들어요.
- 물결 도형이나 둥근 버튼이 화면보다 크게 부풀며 다음 장면이 되는 원형 열림(iris).
- 끝 무렵 도형 컷들은 방향 흐림을 끄는 휙 넘김(whip). 장면 쌓기: cut → iris → whip.

## 대표 장면

1. 눌리면 튀는 알약 버튼 줄
   ```js
   // 하늘빛 판에 버튼 5개를 가로로. 가운데 버튼을 tP 에 누름
   S.ambient(t => {
     const press = M.prog(t, tP, .12);                 // 0→1 눌림
     const k = M.spring(t - tP - .12, 'bouncy');        // 펴지며 넓어짐
     const w0 = H * .16, w1 = H * .34;
     const w = M.lerp(w0, w1, k);
     M.box(play, {x: cx - w / 2, y: cy - H * .08, w, h: H * .16});
     M.place(play, 0, 0, {sx: 1 + press * .08 * (1 - k), sy: 1 - press * .1 * (1 - k)});
     // 이웃은 넓어진 만큼 밀리고, 밀릴 때 살짝 찌그러짐
     side.forEach((b, i) => M.place(b, baseX[i] + Math.sign(i - 2) * (w - w0) / 2, cy,
       {sx: 1 - .06 * Math.sin(k * Math.PI)}));
   });
   ```
   네모 아이콘 버튼은 `border-radius` 를 `M.lerp(H*.03, H*.1, k)` 로 키워 알약으로, 안의 아이콘은 같은 순간 컷으로 체크로 바꿔요.

2. 물결 선을 타는 글자
   ```js
   // 검은 판, 분홍 path 3가닥을 M.draw 로 0.6초에 그리고 계속 흐르게
   const chars = S.chars(word);                       // Geist Mono, 글자 간격 넓게
   S.ambient(t => {
     lines.forEach((p, i) => p.setAttribute('d', wave(t * .4 + i * .7)));
     chars.forEach((c, i) => {
       const ti = t0 + i * .08;
       const x = left + i * gap;
       const y = waveY(x, t * .4) - H * .05 * Math.abs(Math.sin((t - ti) * 6)) * Math.exp(-(t - ti) * 3);
       M.place(c, x, M.anim([[0, -H * .2], [ti, y, {d: .35, e: 'outBack'}]], t), {o: t > ti ? 1 : 0});
     });
   });
   ```
   앞 컷엔 S자 곡선 그래프를 `M.draw` 로 긋고, 점 하나가 같은 곡선 값으로 미끄러져 이징을 보여 줘요.

3. 도형 무리가 부풀어 다음 장면으로
   - 하늘빛 판에 물결 원·꽃·오각형 8~12개를 가운데서 `M.spring(t - ti, 'bouncy')` 크기로 하나씩 톡 튀어나오게(0.06초씩 늦게, 각자 천천히 회전).
   - 짙은 물결 원 하나를 `S.tr.iris` 처럼 화면보다 크게 부풀리며 다음 장면(검은 판)을 열어요. 테두리 물결은 `sin(각도 × 12 + t)` 로 일렁여요.
   - 장면 쌓기에서는 deco shapes 가 원·네모·세모를 흩어 깔고, title pop 이 글자마다 톡 들어와요.

4. 테마가 통째로 갈리는 타일 벽과 넓은 대문자 마무리
   - 라벤더 판에 컴포넌트 타일 6~8칸(검색 막대, 진행 막대, 로딩 원, 선택 칩)을 깔고, 한 박에 모든 타일 색을 `M.color('#F3EEF8', '#2E1F3A', k)` 로 함께 바꿔 짙은 테마로.
   - 마지막엔 컷으로 분홍 바탕, Archivo 900·stretch 125%·skewX −10° 대문자 한 낱말을 화면보다 크게 박고, `S.tr.whip` 로 넘어가 작은 마크 하나로 닫아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·UI 키트 공개, 앱 새 단장·테마 업데이트, 컴포넌트·위젯 기능 소개, 젊고 밝은 제품 런칭.
- 피할 것: 각진 모서리, 손그림 선과 종이 질감, 느린 서서히 전환만 쓰기, 탁하고 어두운 색만으로 채우기, 한 화면에 긴 문단.
- 탄력이 핵심이라 눌림·커짐에는 꼭 오버슛을 넣고, 글은 짧게 두세 낱말로 줄여요.
