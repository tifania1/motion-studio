# 구름 하늘과 옅은 격자 카드 (제품 UI)

한 줄: 흐린 구름 하늘 위로 폰 한 대가 떠 있고, 그 뒤를 흰 문구가 크게 흘러 지나가요. 옅은 회색 격자 판으로 넘어가면 흰 카드 옆 차트가 차오르고 체크 목록이 한 줄씩 쌓이는 담백한 금융 앱 런칭이에요.

## 보는 느낌
- 두 세계를 오가요. 하나는 부드럽게 흐린 구름 하늘(하늘색과 흰 구름, 초점이 살짝 나간 사진 결)이고, 다른 하나는 따뜻한 기가 도는 옅은 회색 판이에요.
- 하늘에서는 폰 한 대나 젖빛 유리 카드 하나만 가운데 띄워요. 둘레는 비워 두고, 흰 글자는 폰 뒤를 지나가요.
- 회색 판에서는 흰 카드 하나와 큰 차트 판 하나를 나란히 두어요. 차트 판은 바탕보다 아주 조금 밝고, 네 귀퉁이에 작은 재단 표시가 붙어요.
- 정리 장면에서는 양옆에 옅은 정사각 격자 판을 세워 두고, 가운데에 2×2 기능 타일과 왼쪽 정렬 문장을 놓아요.
- 마무리는 다시 하늘로 돌아가요. 둥근 틀 속 하늘이 화면 가득 열리고, 풀밭 위에 폰이 서 있는 장면으로 끝을 맺어요.

## 색
- 회색 판 75 · 먹색 글자 15 · 숫자 강조색 5 · 흰 카드 5.
- 바탕 #E6E5E2, 카드 #F5F5F3, 글자 #161616, 옅은 글자는 먹색 58%.
- 하늘 장면은 하늘색 #9CBEDD 와 흰 구름. 이 장면의 글자는 흰색이에요.
- 강조는 오르는 숫자에 쓰는 초록 #2FB344. 선 그래프는 파랑 #3A8EE6, 내림은 빨강 #E0445E, 빌리기 같은 세 번째 기능은 보라 #9B4DE0 로 해요. 한 장면에는 한 색만 써요.
- 격자선은 먹색 8%. 아주 옅게만 깔아요.

## 글자
- Geist 500(한글은 Noto Sans KR Medium). 둥글지 않고 반듯한 산세리프로, 자간은 −0.02em 이에요.
- 큰 글은 짧은 변의 9~11% 정도라 크지만 굵지 않아요. 카드 속 글은 두 줄로 쓰고, 둘째 줄의 숫자만 강조색 700 으로 칠해요. 앞 낱말은 먹색, 뒷말은 옅은 회색이에요(예: '수익 최대' 먹색 + '연 0%' 초록).
- 문장은 왼쪽 정렬 세 줄, 줄 간격 1.05 로 빽빽하게 써요. 앞에 작은 둥근 아이콘을 하나 붙여요.
- 체크 목록은 줄마다 작은 색 원 아이콘에 짧은 문구 하나씩, 크기는 짧은 변의 4.5% 안팎이에요.

## 질감과 모양
- 질감은 따로 얹지 않고 매끈하게 둬요. 하늘 장면만 사진 자체의 흐림이 결이 돼요.
- 카드는 모서리 1.6u 에 아주 옅은 그림자 하나, 테두리는 없어요. 차트 판은 모서리 2u 에 1px 먹색 6% 테두리를 둘러요.
- 젖빛 유리 카드는 흰색 25% 반투명에 블러 2u 를 줘요. 숫자는 그 안에서 흐릿하게 보여요.
- 막대 차트는 아주 가는 세로 막대 40개 남짓이고, 왼쪽은 옅은 회색에서 오른쪽은 초록으로 넘어가요.

## 움직임
- 90BPM, 보통 빠르기예요. 한 장면이 2박 안팎(약 1.3~2초) 머물러요.
- 들어올 때는 `power3.out` 으로 부드럽게 붙고 바로 멈춰요. 튀는 반동은 쓰지 않아요.
- 숫자와 낱말은 기호에서 글자로 맞춰져요(왼쪽부터 0.6초).
- 폰 뒤 흰 문구는 4초에 화면 너비의 40%쯤 아주 천천히 흘러요. 폰은 그 사이 3~5% 커져요.
- 차트는 0.8초에 왼쪽부터 차오르고(막대는 하나씩 0.02초 간격), 카드 낱말 색은 컷으로 바뀌어요.
- 체크 목록은 반 박마다 한 줄씩 아래에서 1u 올라오며 생기고, 다 차면 목록 전체가 위로 밀려 올라가요.

## 전환
- 회색 판끼리는 컷으로 이어요. 같은 카드 자리를 두고 안의 내용만 갈아 끼워요.
- 하늘과 회색 판 사이는 흐림(blur)으로 넘어가요. 하늘이 흐려지며 회색이 밝아져요.
- 폰이나 큰 문구가 옆으로 빠질 때는 밀어내기(push)를 써요. 장면 쌓기는 cut → blur → push 순서예요.

## 대표 장면
1. **구름 속 유리 카드 숫자**
   ```js
   // 하늘 사진(또는 흐린 하늘색 원 덩어리)을 깔고 젖빛 카드 하나
   S.ambient(t => {
     const k = M.ease.outCubic(M.prog(t, 0, .7));
     num.textContent = M.scramble('12,313', t, .2, .6);   // 기호 → 숫자, 왼쪽부터
     M.place(card, cx, cy, { s: M.anim([[0, 1], [1.4, .55, { d: 1, e: 'inOutCubic' }]], t),
                            blur: M.anim([[0, 0], [1.6, 6, { d: .8 }]], t) });
   });
   // 다음 장면으로는 S.tr.blur
   ```
2. **폰 뒤로 흐르는 흰 문구**
   - 하늘 바탕 가운데 폰(`M.place(phone, cx, cy, {r: -4, s: 1 + t * .01})`). 그 뒤 층에 흰 문구 둘을 놓아요. 하나는 `x = M.anim([[0, W * .1], [4, -W * .3]], t)`, 다른 하나는 반대 방향으로 흐르게 하고, 짧은 변의 12% 크기로 화면 밖으로 잘리게 둬요.
   - 마지막에 폰을 `S.tr.push` 로 옆으로 빼거나 화면 쪽으로 다가가요.
3. **카드 + 차오르는 차트, 색만 갈리기**
   ```js
   bars.forEach((b, i) => {
     const h = Math.pow(i / bars.length, 2.2);            // 곡선처럼 차오름
     const k = M.ease.outCubic(M.prog(t, .2 + i * .02, .5));
     b.style.transform = `scaleY(${h * k})`;
   });
   // 다음 박: 같은 카드에서 강조 낱말 색만 컷으로
   word.style.color = M.at([[0, '#2FB344'], [M.beat(2), '#E0445E']], t);
   M.draw(linePath, M.ease.outCubic(M.prog(t, M.beat(2), .8)));   // 선 그래프
   ```
   - 장면 쌓기에서는 frame: card, deco: marks, number: scramble 로 흰 카드와 귀퉁이 표시, 맞춰지는 숫자가 나와요.
4. **격자 판 사이 체크 목록**
   - 양옆에 정사각 격자 판(SVG 선, 먹색 8%)을 세우고, 가운데 목록은 줄 i 를 `M.place(row, x, y0 + i * lh - scroll, {o: k, y: (1 - k) * u})`, `k = M.spring(t - i * M.beat(.5), 'smooth')` 로 놓아요. 여섯 줄이 다 차면 `scroll = M.anim([[M.beat(4), 0], [M.beat(5), lh * 3, {d: .8, e: 'inOutCubic'}]], t)` 로 밀어 올려요.
   - 마무리는 둥근 틀 안의 하늘을 `M.box` 로 화면 가득 키워 하늘 장면으로 돌아가고, 이름 글자는 기호로 흩어지며 사라져요(`M.scramble` 반대로).

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·투자 앱 런칭, 기능 여러 개를 차분히 훑을 때, 출시·대기 해제 알림, 수익률·금리 같은 숫자 소개, 앱 내려받기 안내.
- 피할 것: 강한 원색 바탕, 손그림 선, 빠른 컷 몽타주, 굵고 빽빽한 제목, 한 화면에 강조색 여러 개.
- 하늘 사진이 없을 때는 하늘색과 흰색 원 덩어리를 크게 흐려 깔면 같은 결이 나요.
