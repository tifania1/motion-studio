# 오려 낸 꽃잎 색 갈아입기 (그래픽·도형)

한 줄: 붓으로 칠한 꽃잎이 가위로 오린 듯한 납작한 도형으로 딱 맞춰지고, 색 목록 칸이 하나씩 바뀔 때마다 화면 속 같은 색 조각이 한꺼번에 새 옷을 입어요.

## 보는 느낌
- 큰 꽃잎·별·줄기 조각이 화면 가장자리에서 잘려 나갈 만큼 크게 놓여요. 화면 안에 다 들어오는 작은 그림보다 바짝 붙은 크롭이 기본이에요.
- 조각은 모두 단색이고 겹쳐도 그림자가 없어요. 가장자리만 붓으로 오린 듯 살짝 울퉁불퉁해요.
- 조각 사이 빈 바탕이 화면의 30~40%쯤 남게 둬요. 꽉 채우면 무늬 천처럼 보여 버려요.
- 글은 장면 위쪽 왼편에 큰 그로테스크 두 줄. 그림은 그 아래 카드 한 장으로 물러나 있다가 다음 장면에서 다시 화면 가득 다가와요.

## 색
- 바탕 45 · 큰 조각(주황·크림) 35 · 작은 조각(연두·분홍·연보라) 15 · 글 5.
- 갈아입기 전: 연보라 바탕(#8EA2EC), 분홍 꽃(#E9A1B7), 노랑 별(#F4E04D), 크림 꽃잎(#F3EDDC), 짙은 녹색 줄기(#1F3A12).
- 갈아입은 뒤: 짙은 초록 바탕(#183A2E), 주황 꽃(#D9531E), 크림 별, 연두 줄기(#C9DB3B), 분홍(#E9A1B7)은 작은 꽃으로.
- 글 장면 바탕은 탁한 세이지(#9DB8AE)나 크림. 강조색 바탕 장면은 주황.
- 색 수는 6~8개로 묶어요. 색 목록에 보이는 칩 수와 화면 속 색 수가 맞아야 '한꺼번에 바뀐다'는 느낌이 살아요.

## 글자
- 제목: 둥글지 않은 담백한 그로테스크(Archivo 500~600, 한글 Noto Sans KR 700). 짧은 변의 6~7%, 줄 간격 1.05, 자간 −0.02em.
- 작은 UI 글(색 이름, 칩 번호): Geist 500, 제목의 30%.
- 글은 늘 왼쪽 정렬. 그림 위에 글을 얹지 않아요.

## 질감과 모양
- 첫 장면의 붓 자국 판에만 종이 결과 물감 번짐이 있어요. 납작해진 뒤에는 아주 옅은 그레인(0.06)만.
- 조각 모양: 꽃잎은 끝이 둥근 물방울, 별은 끝이 뭉툭한 다섯 갈래, 줄기는 굵기가 일정한 둥근 선. 점 무늬는 같은 크기 원 3~6개.
- 선택 상자: 1.5px 파랑(#2F7BF6), 귀퉁이 손잡이는 흰 정사각(0.9u) + 파란 테두리. 벡터 점은 흰 원(0.7u) + 파란 테두리.
- 커서는 흰 테두리 두른 큰 검은 화살표(짧은 변의 6%쯤). 일부러 크게.

## 움직임
- 110BPM. 장면 안 사건은 한 박에 하나, 색 갈아입기만 0.1초 간격으로 빠르게 몰아쳐요.
- 들어올 땐 power3.out, 카메라 이동은 M.spring 'smooth'. 넘침 없이.
- 붓 자국 그리기 0.6초 → 납작해지기 0.3초 → 한 박 쉼.
- 초근접 편집 장면은 카메라가 거의 멈춰 있고, 커서와 조각만 움직여요. 한 조각을 1.5~2박 동안 만져요.

## 전환
- 그림 카드 ↔ 화면 가득: zoom 으로 카드 속으로 들어가거나 물러나요.
- 같은 그림 안에서 다른 조각으로: cut (같은 크기로 바짝 붙은 다른 자리).
- 결과물 여러 장 보여 주기: push 로 카드 석 장이 가로로 밀려 지나감.

## 대표 장면

1. 칠해지다 납작해짐
   ```
   // 꽃잎 경로는 시드 난수(M.rng)로 만든 물렁한 닫힌 경로. 같은 경로 두 벌: 질감판 / 단색판
   // 질감판: SVG 필터 feTurbulence(baseFrequency .04) + feDisplacementMap 으로 물감 번짐, 안쪽에 옅은 색 얼룩 두어 겹
   // 획 마스크: 굵은 stroke 경로를 마스크로 깔고 M.draw(maskPath, M.spring(t - t0, 'smooth'))   // 0.6초에 꽃잎이 자람
   const k = M.prog(t, tFlat, .3);
   disp.setAttribute('scale', M.lerp(14, 0, k));        // 번짐이 걷힘
   texture.style.opacity = 1 - k;  flat.style.opacity = k;
   ```
   - "작업 중…" 같은 작은 알약 UI 를 아래에 두면 바뀌는 순간이 더 또렷해요. 알약은 흰 둥근 상자 + Geist 글.

2. 색 갈아입기
   ```
   // 조각마다 data-c = 색 번호. 오른쪽 색 목록 칩 i 와 같은 번호
   chips.forEach((chip, i) => {
     const k = M.prog(t, tr + i * .1, .12);
     chip.style.background = M.color(before[i], after[i], k);
     pieces[i].forEach(p => p.setAttribute('fill', M.color(before[i], after[i], k)));
   });
   bg.style.background = M.color('#8EA2EC', '#183A2E', M.prog(t, tr + n * .1 + M.beat(1), .15));
   ```
   - 칩 옆 이름표(색 이름)도 같은 순간 바뀌어요. 바탕은 맨 마지막 한 박에 따로.

3. 초근접 손잡이 편집
   - M.camera(world, 조각 중심 x, y, 3~3.5) 로 꽃잎 하나를 화면 가득. 카메라는 그 자리에서 멈춤.
   - 선택 상자와 손잡이는 조각 경로의 getBBox() 로 크기를 잡고 0.15초에 나타남. 벡터 점은 경로 위 5~8곳에 M.place.
   - M.Cursor 로 귀퉁이 손잡이까지 와서 누른 채 끌기: 끄는 동안 조각 scale = 1 + (커서 이동 거리 / 원래 폭), 회전은 위 가운데 손잡이를 끌 때만. 놓으면 그 자리에서 M.spring 'snappy'.
   - 다른 조각은 꼼짝 않아요. 바꾼 조각만 움직여야 편집처럼 보여요.

4. 포스터로 물러나 앱 화면으로
   - 화면 가득 그림 → zoom 으로 물러나 회색 판 위 정사각 포스터 한 장 → 포스터가 둥근 사각(모서리 3u)으로 오므라들며 바탕이 연두(#C3D98F)로 바뀜 → 그 둥근 사각이 폰 화면 크기로 길어지며 아래에 글 두 줄.
   - 원색 도형이 손잡이를 달고 모여 로고가 되는 엔딩이 필요하면 handle-shapes-merge 스타일의 엔딩을 빌려 써요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인·편집 도구의 기능 소개, 꽃집·문구·굿즈 브랜드, 새 색·리브랜딩 발표, 봄 시즌 이벤트, 팟캐스트·책 표지 홍보.
- 피할 것: 사진, 그라디언트와 유리 질감, 가는 선 아이콘, 작은 글자가 빽빽한 장면, 차가운 회색 기업 톤. 영상 속 손글씨 로고나 고유한 꽃 그림을 그대로 따라 그리지 않아요. 조각의 성격(굵고 둥근 끝, 단색, 크게 잘린 크롭)만 가져와요.

## 배운 곳
- keyframe.gallery, mux 재생 ID HgYqPvAhqM3gPHpI00j5AY2ebLAU3UZ1xpFGgEHzPovo.
- 0–5초: 붓 자국 꽃잎이 획 방향으로 자라며 그려지는 바짝 붙은 화면.
- 11.5–16초: 질감이 걷히며 납작한 도형이 되는 순간, 색 수 줄이기 막대.
- 16–20초: 색 목록 칩이 위에서부터 바뀌며 같은 색 조각이 함께 바뀌고 바탕이 마지막에 뒤집힘.
- 22.5–31초: 꽃잎 하나를 화면 가득 키운 채 선택 상자 손잡이로 키우고 돌리기, 벡터 점 편집.
- 39.5–43초: 포스터가 둥근 사각으로 오므라들어 폰 화면이 되는 마무리.
