# 숯빛 입력창에서 자홍 노을로 (그라디언트·빛)

한 줄: 숯빛 둥근 입력판에 굵은 흰 부탁이 쳐지고 보내기 단추가 보라 빛 구슬로 부풀어요. 빛 테두리 줄이 쌓였다 작은 목록으로 접히면 밝은 라벤더 판에서 버튼과 숫자 카드가 움직이고, 끝은 주황·자홍·파랑 노을 위에 흰 문장이 어절씩 쳐지는 AI 기능 런칭.

## 보는 느낌
- 영상 전체가 어둠 → 밝음 → 짙은 색으로 세 칸을 건너요. 앞 3분의 1은 숯빛 입력판과 빛 테두리 목록, 가운데는 옅은 라벤더 회색 판 위 UI 조각, 마지막은 화면 가득한 자홍 노을 그라디언트예요.
- 열기 장면은 화면을 거의 채우는 둥근 숯빛 판 하나. 큰 글자가 왼쪽 위에 몰려 있고, 왼쪽 아래 작은 + 동그라미, 오른쪽 아래 흰 보내기 동그라미만 있어요. 여백이 넓어요.
- 목록 장면은 한가운데 긴 줄 상자 2~3개, 밝은 판 장면은 한가운데 버튼 하나나 카드 하나. 한 화면에 주인공은 늘 하나예요.
- 사이에 실사 사진 한 컷이 1초쯤 끼어 쓰임새를 보여 줘요.
- 빛은 두 군데에만 써요: 눌리는 단추·커서 둘레의 보라 빛무리, 줄 상자·카드 가장자리의 분홍→파랑 번짐.

## 색
- 앞 장면: 숯빛 #1F1F21 70 · 흰 글자 #F2F1F4 25 · 보라 빛 5.
- 가운데 장면: 라벤더 회색 #D9D8E8 70 · 흰 카드 20 · 보라 버튼 #7A6FD6 과 초록 그래프 10.
- 마지막 장면: 메시 그라디언트가 거의 전부. 왼쪽 위 주황 #F26B3A → 가운데 자홍 #E43F86 → 오른쪽 분홍보라 → 아래 파랑 #4F6FE0. 그 위에 흰 글자.
- 강조(accent)는 짙은 자홍 #C2257A, 글자는 흰색. 줄 상자 안 끝 낱말을 분홍으로 물들일 때도 이 계열을 써요.
- 빛무리 glow 는 보라 rgba(150,110,240,.45).

## 글자
- Geist(한글 Noto Sans KR Bold·Medium) 한 가족만. 큰 글은 굵기 600, 자간 −0.03em, 줄 간격 1.0~1.05 로 촘촘하게.
- 열기 부탁: 화면 높이 12% 안팎, 왼쪽 정렬 두 줄. 마무리 문장: 화면 높이 9~11%, 가운데 한 줄.
- 목록 줄·모달 글: 굵기 400~500, 화면 높이 2.5~3%. 작은 아이콘 하나를 앞에 붙여요.
- 숫자 카드: 위 작은 회색 꼬리표, 가운데 큰 숫자(굵기 700), 아래 작은 설명 한 줄.

## 질감과 모양
- 질감은 없어요. 판과 그라디언트가 모두 매끈해요.
- 입력판·모달·카드 모서리 1.6u. 줄 상자는 모서리 1.2u, 1.5px 그라디언트 테두리.
- 흰 카드는 부드러운 그림자 한 겹에 가장자리 바깥으로 분홍(왼쪽)·파랑(오른쪽) 빛이 2u 쯤 번져요.
- 보내기 단추·커서 빛무리는 지름 3~4u 의 흐린 보라 원.

## 움직임
- 110BPM, 장면 하나에 1~2초. 컷이 빠른 편이지만 장면 안 움직임은 부드러워요(power3.out).
- 글은 어절 단위로 쳐지고 가는 세로 커서가 끝을 따라가요. 초당 3~4어절.
- 줄 상자는 아래에서 2u 올라오며 0.4초에 나타나고, 앞 줄은 한 칸 위로 밀려요.
- 버튼은 눌릴 때 0.15초에 살짝 작아지며 rotateX 8~10° 기울었다가 스프링으로 돌아와요.
- 숫자는 카드가 뜬 뒤 1초 동안 천천히 올라가고, 그래프 면도 같이 차올라요.

## 전환
- 기본은 컷. 어두운 장면 → 밝은 장면은 흐림(blur) 전환으로 넘기고, 사진 → 노을 판은 짧은 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **입력판 타이핑 + 빛 구슬 보내기**
   ```js
   // 숯빛 둥근 판, 왼쪽 위 큰 글, 오른쪽 아래 보내기 단추
   S.ambient(t => {
     title.textContent = M.type(prompt, t, .2, 14);           // 어절씩 쳐짐 + 커서
     title.style.color = M.color('#9C8CF0', '#F2F1F4', M.prog(t, .2, .5));
     const k = M.spring(t - 1.9, 'snappy');                   // 다 쳐진 뒤 단추가 부풂
     M.place(send, sx, sy, { s: 1 + k * .35 });
     halo.style.opacity = k;                                 // 보라 빛무리
     M.draw(spinArc, (t - 1.9) * 1.2 % 1);                   // 안에서 진행 호가 돎
   });
   ```
2. **빛 테두리 줄이 쌓였다 모달로 접힘**
   - 줄 i 를 `M.place(row, cx, y_i, { o: k, y: (1 - k) * 2 })`, `k = M.spring(t - ti, 'smooth')`. 안의 글은 `M.type(text, t, ti + .1, 20)`, 끝 낱말은 `M.color('#F2F1F4', '#E43F86', …)` 로 물들여요.
   - 셋이 쌓이면 `M.box(rows, …)` 로 줄 간격과 폭을 0.5초에 70% 로 줄이고 테두리 그라디언트 opacity 를 0 으로. 아래 점 셋과 파란 버튼이 생기면 `M.Cursor` 가 보라 빛무리를 두르고 와서 `M.cursorAt` 순간 누름. 이어 `S.tr.blur` 로 밝은 판으로.
3. **밝은 판의 버튼과 숫자 카드**
   - 라벤더 회색 판 가운데 보라 버튼. 커서가 누르면 `M.anim([[tc, 0], [tc + .15, 9, {e: 'outCubic'}], [tc + .5, 0, {e: 'outBack'}]], t)` 로 rotateX 를 줬다 풀어요.
   - 다음 컷에 흰 카드(가장자리 분홍·파랑 `box-shadow` 두 겹). 큰 숫자는 장면 쌓기 number: count 로 올라가고, 오른쪽 초록 면 그래프는 `M.draw(areaPath, M.prog(t, .2, 1))`.
4. **노을 메시 위 마무리 문장**
   - scenes.bg mesh 로 주황·자홍·파랑 덩어리를 깔고 `M.drift` 로 아주 천천히 흘려요. 문장은 title: type 으로 한 낱말이 쳐진 뒤 컷 → 두 낱말 → 한 줄 완성 순으로 늘려요(낱말마다 0.6초 머묾). 마지막 장은 가운데 마크와 이름 하나만.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 도구의 새 기능 런칭, 결제·연동 기능 소개, 부탁 한 줄로 결과가 나오는 데모, 개발·제작 도구 광고, 15~20초 짧은 소셜 영상.
- 피할 것: 종이·그레인 같은 거친 질감, 세리프나 손글씨 글꼴, 빽빽한 표와 긴 문단, 장면마다 새로 늘어나는 강조색, 끝까지 무채색으로만 마무리하기(마지막 노을 판이 있어야 이 결이 살아요).
- 비슷한 어둠 속 빛 스타일과 달리 여기선 빛을 크게 퍼뜨리지 않고 단추·테두리에만 얇게 둬요. 밝은 판으로 넘어가는 순간이 영상의 숨 고르기예요.
