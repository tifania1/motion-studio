# 라일락 안개 세리프 알약 고르기 (제품 UI)

한 줄: 아주 옅은 회색 판 가장자리에 라일락 안개가 번지고, 책 같은 세리프 한 줄이 흐림에서 맺혀요. 그림자가 부드러운 흰 알약 입력창에 바짝 붙어 문장이 쳐지면, 옆 칩을 눌러 연 세로 목록이 굴러가다 고른 이름에 멈춰요.

## 보는 느낌
- 바탕은 거의 흰 연회색 한 장. 가장자리나 아래 3분의 1에만 라일락·분홍 안개가 흐릿하게 번지고, 가운데는 비워 둬요.
- 화면마다 주인공은 하나예요. 세리프 문장 한 줄, 알약 입력창 하나, 작은 상태 알약 하나, 앱 창 하나 가운데 하나만 보여요.
- 알약 입력창은 두 가지 거리로 써요. 멀리서는 화면 너비의 50% 정도로 가운데 떠 있고, 가까이서는 화면보다 길게 키워 왼쪽이 잘린 채 커서 쪽만 보여요.
- 둘레에는 작은 파스텔 꽃잎 같은 조각과 무늬 없는 둥근 토큰이 깊이를 달리해 떠다녀요. 앞에 있는 것일수록 크고 흐려요.
- 중반에 앱 창(왼쪽 사이드바, 오른쪽 결과 화면)이 옆에서 밀려 들어오고, 그 뒤 바탕은 흐린 사진이나 진보라 풀밭 같은 결이 있는 색면으로 바뀌어요.

## 색
- 연회색 #ECECEC 75 · 먹색 글자 #262626 15 · 보라·라일락 10.
- 보라 #7B4FD6 은 강조 낱말, 첫 장면 제목 앞말, 보내기 단추를 채울 때 써요. 단추 위 화살표는 흰색.
- 라일락 안개 #DCCDF3 → 분홍 #F2C9DE 로 번지고, 조용한 장면 바탕(paper)은 옅은 라일락 #E4DAF4.
- 분홍 구슬 #E86FA0 은 '작업 중' 표시에만, 초록 #4CC94C 점은 '다 됐어요' 확인에만.
- 선택 칸·칩은 따뜻한 베이지 #E9E3DA. 진보라 #7B4FD6 판은 앱 창 뒤 바탕으로 한 번만 넓게 깔아요.

## 글자
- 모두 세리프(고운바탕 400). 제목도 굵게 하지 않아요. 자간 −0.01em.
- 큰 문장은 짧은 변의 8~10%, 가운데 정렬 한 줄. 엔딩 한마디는 먹색, 결과를 알리는 문장은 보라.
- 입력창 안 글자도 같은 세리프로, 짧은 변의 5~6%(클로즈업이면 10% 넘게).
- 칩·목록·상태 알약 글자는 짧은 변의 3% 안팎. 굵기는 칩 이름만 700.

## 질감과 모양
- 질감은 넣지 않아요. 매끈한 판 위에 안개 그라디언트만.
- 알약: 흰색에 아주 넓고 옅은 그림자(0 2u 6u rgba(0,0,0,.08)) 한 겹, 안쪽 위에 흰 하이라이트 1px. 모서리는 다 둥글게(`--u` × 6).
- 보내기 단추는 지름이 알약 높이의 70%인 원. 평소엔 짙은 회색 #4A4A4A, 준비되면 보라.
- 선택 칸·칩은 모서리 `--u` × 1.2 의 베이지 사각, 테두리 없음.
- 앱 창은 흰 판, 모서리 `--u` × 2, 그림자 한 겹.

## 움직임
- 88BPM, 느림. 들어오는 건 `power3.out` 으로 부드럽게 멈춰요. 한 화면에 2~3초씩 머물러요.
- 문장은 어절이나 글자마다 흐림 6px → 0, 투명 → 불투명(0.5초), 왼쪽부터 0.05초 간격.
- 입력창 글은 초당 18자로 쳐지고, 카메라가 커서를 따라 옆으로 천천히 흘러요(초당 짧은 변의 3%).
- 상태 알약 문구는 흐림 전환으로 0.4초에 갈리고, 분홍 구슬은 3초 주기로 숨 쉬어요.
- 선택 목록은 한 칸 굴러가는 데 0.35초, 마지막 칸에서 스프링으로 살짝 넘쳤다 멈춰요.
- 토큰·꽃잎은 위아래로 천천히 떠다니며 조금씩 돌아요.

## 전환
- 흐림(blur) 전환이 기본이에요. 앞 장면이 흐려지며 빠지고 다음 장면이 흐림에서 맺혀요.
- 같은 바탕 안에서는 서서히(fade). 앱 창은 옆에서 밀려 들어와요(push). 클로즈업에서 먼 거리로 갈 땐 컷.
- 장면 쌓기: blur → fade → cut → push.

## 대표 장면
1. **알약 입력창 클로즈업**: 알약을 화면 너비의 1.4배로 두고 커서 자리를 따라 카메라를 옮겨요.
   ```
   const txt = M.type(prompt, t, .4, 18);              // 세리프 문장이 쳐짐
   input.textContent = txt;
   const cx = caretX(txt);                              // 커서 x
   M.place(pill, W * .62 - cx * .8, H * .5, {s: 1.4});  // 왼쪽이 잘린 채 커서 쪽으로 흐름
   const k = M.prog(t, 2.6, .5);                        // 다 쓰면 단추가 보라로
   send.style.background = M.color('#4A4A4A', '#7B4FD6', M.ease.outCubic(k));
   ```
   멀리서 보는 장면은 같은 알약을 `s: .55` 로 두고, 위에 세리프 질문 한 줄을 흐림에서 맺히게 해요.
2. **선택 목록 굴리기**: 칩을 `M.Cursor` 로 누르면(`M.cursorAt`) 칩 위로 목록 세 줄이 떠요.
   ```
   const step = M.at([[0, 0], [.5, 1], [.85, 2], [1.2, 3]], t - t0);   // 한 칸씩
   const y = M.anim([[0, 0], [t0 + 1.2, -step * rowH, {d: .35, e: 'outBack'}]], t);
   rows.forEach((r, i) => {
     const d = Math.abs(i * rowH + y);                  // 가운데에서 떨어진 거리
     M.place(r, cx, cy + i * rowH + y, {o: 1 - d / rowH * .6, blur: d / rowH * 3});
   });
   // 가운데 칸은 베이지 칸 + 체크, 멈추면 칩 글씨를 고른 이름으로 바꿈
   ```
3. **상태 알약과 떠도는 토큰**: 가운데 작은 알약에 분홍 구슬을 달고 `S.ambient(t => M.place(orb, ox, oy, {s: 1 + Math.sin(t * Math.PI * 2 / 3) * .06}))` 로 숨 쉬게 해요. 문구는 `S.tr.blur` 로 '살펴보는 중' → '만드는 중'.
   둘레 토큰 6~8개(무늬 없는 분홍 원판)는 깊이마다 크기와 `blur` 를 달리하고 `M.drift` 로 천천히. 다 되면 구슬이 초록 점으로 바뀌어요.
4. **보라 세리프로 맺히는 결과**: `S.chars(line)` 로 글자를 나누고 글자마다 `M.place(c, x, y, {o: k, blur: (1 - k) * 6})`, `k = M.ease.outCubic(M.prog(t, t0 + i * .05, .5))`. 동시에 뒤 라일락 안개 원 두세 개를 `blur(10u)` 로 흐려 0.8초에 번지게 하고, 꽃잎 조각 몇 개를 위로 천천히 띄워요. 엔딩은 같은 방식으로 먹색 세리프 한마디와 주소 한 줄.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 생성·디자인 도구 런칭, 입력 한 줄로 결과를 만드는 서비스, 브랜드·템플릿을 골라 쓰는 기능 소개, 차분한 크리에이터 도구 소개.
- 피할 것: 굵은 고딕 제목, 빠른 컷 몽타주(오프닝에 한 번만 짧게), 진한 원색 여러 개(보라 하나와 분홍 구슬, 확인용 초록만), 딱딱한 테두리 선과 짙은 그림자, 그레인·주사선 같은 거친 질감.
- 토큰과 꽃잎은 무늬 없는 도형으로 새로 그려요. 원본의 로고 동전이나 꽃 그림은 쓰지 않아요.
