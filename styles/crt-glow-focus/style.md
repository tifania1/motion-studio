# 브라운관 초점 글로우 (시네마틱)

한 줄: 주사선 낀 어두운 브라운관에 비스듬히 누운 코드가 흐르고, 세리프 한 줄이 흐림에서 초록·분홍 번짐으로 맺혔다가 흰 빛으로 가라앉는 밤 화면.

## 보는 느낌
- 짙은 숯빛 화면 전체에 가는 가로 주사선, 가장자리는 어둡게 눌려 오래된 모니터를 카메라로 찍은 듯해요.
- 앞부분은 비스듬히 누운 코드 화면. 초점이 맞는 줄 근처만 또렷하고 위아래는 흐릿하게 녹아요(얕은 심도).
- 뒷부분은 화면 가운데 세리프 한 줄. 글자 둘레에 옅은 빛이 번지고, 맺히는 순간에만 색이 어긋나 보여요.
- 끝은 모든 게 점 하나로 오므라졌다가 깨끗한 검은 화면에 이름만.

## 색
- 숯빛 #1C1D1D 85 · 흰빛 글 10 · 코드 색 5.
- 글은 #ECE9E4(살짝 따뜻한 흰색)에 같은 색 글로우.
- 코드 줄: 분홍 #E2366B(지운 줄 띠), 초록 #4FD08A(더한 줄 띠), 보라 #7C6CF2(버튼), 노랑 #F2B84B(문자열). 모두 빛나는 형광으로, 큰 면에는 쓰지 않아요.

## 글자
- 큰 글: 영문 디스플레이 세리프 400(Instrument Serif), 한글은 고운바탕 400. 짧은 변의 9~11%, 자간 −0.01em.
- 부제: 작은 산세리프(Geist + Noto Sans KR 500), 큰 글 크기의 28%.
- 코드: Geist Mono. 줄 번호는 옅은 회색.

## 질감과 모양
- 주사선 0.35, 색 어긋남(rgbSplit) 1.2 에 초당 12번 살짝 흔들림, 그레인 0.08, 비네트 0.5.
- 글로우: `text-shadow: 0 0 .6u currentColor, 0 0 2u rgba(236,233,228,.35)` 두 겹만.
- 버튼·카드는 얇은 외곽선과 같은 색 빛 번짐(card outline).

## 움직임
- 84BPM, 느림. 곡선은 sine.inOut. 한 장면 3~4초.
- 초점 당기기: 블러 2.5u → 0 을 1초에. 그동안 색 어긋남은 크게(2.5배) 시작해 0.6초 뒤 기본값으로.
- 코드 화면: 카메라가 아래로 천천히 미끄러짐(초당 화면 높이 4%), 줄 띠는 줄 번호부터 옆으로 0.4초에 칠해짐.
- 부제는 초당 16자로 쳐지고, 다 쳐진 자리에서 작은 초록 반짝임이 0.3초 깜빡.

## 전환
- 흐려지며 겹치는 전환(blur)과 느린 페이드뿐. 컷은 마지막 깨끗한 화면으로 넘어갈 때 한 번만.
- 장면 쌓기: blur → fade.

## 대표 장면
1. **세리프 초점 당기기**
   ```
   const k = M.spring(t - t0, { f: .9, z: 1 });               // 느리게 맺힘
   title.style.filter = `blur(${(1 - k) * 2.5 * u}px)`;
   // 색 번짐: 같은 글을 둘 더 겹쳐 (초록 위로, 분홍 아래로) 어긋냄
   const d = (1 - M.prog(t, t0 + .4, .6)) * .5 * u;
   M.place(ghostG, cx, cy - d, { o: .7 * (d > 0) }); M.place(ghostP, cx, cy + d, { o: .7 * (d > 0) });
   ```
   장면 쌓기에서는 `title: blur` 와 질감(rgbSplit·scanlines)이 이 몫을 해요.
2. **누운 코드 화면**
   - 코드 판을 `transform: perspective(60u) rotateX(25deg) rotateY(-18deg)` 로 눕히고, 판 안 줄마다 초점 줄과의 거리로 블러: `blur(Math.abs(y - focusY) / H * 3u)`.
   - 카메라: `M.camera(world, cx, cy0 + t * .04 * H, 1.6)`. 지운 줄 띠는 `S.fx.reveal(band, t)`, 버튼은 `box-shadow` 빛을 `M.anim` 으로 한 번 키웠다 줄임.
   - 장면 쌓기 `frame: terminal` 이 검은 창과 고정폭 글을 맡아요.
3. **브라운관 끄기 엔딩**
   - 글을 블러 1.5u 로 흐리며 `scaleY` 1 → .05(0.3초), 이어서 `scaleX` 1 → .08(0.25초)로 점이 되게. 점은 `M.spring` 으로 둥근 마크 크기로 맺힘.
   - 맺히는 순간 컷: 질감 층(`#fx-look`)을 숨기고 `#cam` 필터를 끈 깨끗한 화면에 이름을 `S.fx.fade`.

## 어울리는 곳 / 피할 것
- 어울림: 개발자 도구·기술 서비스 발표, 신기능 예고, 밤 분위기 한 줄 메시지, 레트로 감성 브랜드 티저.
- 피할 것: 밝은 바탕, 빠른 컷 연타, 굵은 고딕 큰 제목, 원색 그라디언트. 글은 한 화면에 한 줄(부제까지 두 줄).
