# 주황 새벽 그레인과 미색 노드 도면 (제품 UI)

한 줄: 거친 그레인이 낀 주황 판 아래로 노란 새벽빛이 번지고, 한 글자씩 쳐지는 문장 속 숫자가 굴러 올라가요. 컷 한 번에 미색 판으로 넘어가면 모서리 핸들을 단 가는 선 노드가 점선으로 이어지며 흐름도가 넓어지고, 끝에는 화면이 픽셀로 부서진 뒤 가는 주황 선 마크가 그려지는 개발자 런칭.

## 보는 느낌
- 두 판을 오가요. 하나는 그레인과 옅은 가로줄이 낀 쨍한 주황 판이고, 다른 하나는 차분한 미색 판이에요. 주황 판은 말할 때, 미색 판은 보여 줄 때 써요.
- 주황 판 아래 가장자리에서 노랑·흰빛 새벽빛이 반원으로 솟아 있어요. 글은 그 빛 위 가운데에 한 줄만 둬요.
- 미색 판에는 머리카락 같은 선으로 그린 상자, 점선, 둥근 곡선이 깔려요. 상자 네 귀퉁이에 작은 네모 핸들이 달려 있어 설계 도면이나 편집 화면 같아요.
- 사이사이 큰 흰 알약 버튼, 아이콘 줄이 든 앱 창, 주황 뾰족 그래프, 반은 미색 반은 주황인 카드가 한 장씩 끼어들어요.
- 여백이 넓어요. 한 화면에 요소 하나, 많아야 노드 대여섯 개.

## 색
- 미색 판 장면: 미색 #EFECE7 75 · 먹갈색 글자·선 15 · 주황 10.
- 주황 판 장면: 주황 #E5552A 70 · 새벽빛 노랑 #F6C66A 20 · 미색 글자 #FFF4EA 10.
- 강조는 주황 하나예요. 문장에선 끝말 하나만 주황으로, 도면에선 가운데 노드 하나만 주황 선으로.
- 파랑 #5B8FE0 은 작업 흐름 도면 한 장에만 노드 선 색으로 잠깐 써요. 그 도면 속 작은 칩에 분홍·초록 파스텔이 섞여도 괜찮아요.
- 엔딩 판은 미색에 분홍 #F2D3C6 이 번진 따뜻한 살구빛.

## 글자
- Geist 500 (한글은 Noto Sans KR Medium). 둥글지 않은 담백한 그로테스크, 자간 −0.02em.
- 문장은 짧은 변의 5~6%, 가운데 한 줄. 큰 알약 버튼 속 글만 짧은 변의 12% 정도로 크게, 굵기 600.
- 코드·로그 조각은 Geist Mono 400, 아주 작게(짧은 변의 2%) 흐린 먹색으로 무늬처럼 깔아요.
- 숫자는 문장과 같은 크기·굵기로 문장 안에 박혀요. 따로 키우지 않아요.

## 질감과 모양
- 그레인 0.16(초당 12번) + 옅은 가로 주사선 0.1 + 아주 약한 비네트 0.15. 주황 판에서 결이 가장 잘 보이고, 미색 판에서는 은은하게만.
- 선은 1~1.5px, 미색 판에선 먹갈색 25%, 강조 노드는 주황 2px. 점선은 4px 간격.
- 핸들: 선 상자 귀퉁이마다 짧은 변의 1.2% 크기 흰 네모, 가는 테두리.
- 카드·노드 모서리 1.2u. 그림자는 거의 없고, 큰 흰 알약만 아주 옅은 그림자 하나.

## 움직임
- 110BPM, 보통 빠르기. 들어오는 건 power3.out 으로 부드럽게 멈춰요.
- 문장은 초당 18~22자로 한 글자씩 쳐지고, 숫자는 자리마다 굴러 올라가 1박 안에 멈춰요.
- 새벽빛은 4초 주기로 높이 ±6% 숨 쉬어요.
- 선은 0.5~0.8초에 그어지고, 핸들은 선이 다 그어진 뒤 귀퉁이부터 톡 나타나요(0.15초 간격).
- 카메라는 노드 하나에 바짝 붙었다가 2~3초에 걸쳐 천천히 빠져요. 반대로 버튼 쪽으로 미끄러지며 다가가기도 해요.
- 한 장면은 2~3초 머물러요.

## 전환
- 주황 판과 미색 판 사이는 컷. 같은 판 안에서는 옆으로 쓸어 넘기는 와이프(wipe).
- 엔딩 직전 한 번만 큰 픽셀 모자이크로 부서지는 블록 전환(S.tr.blocks).
- 장면 쌓기: cut → wipe → blocks.

## 대표 장면

1. **새벽빛 위 타자 문장과 굴러 오르는 숫자**
   ```
   // 주황 판, 아래 가장자리 반원 빛
   S.ambient(t => {
     const s = 1 + Math.sin(t * Math.PI / 2) * .06;
     M.place(dawn, W / 2, H * 1.05, {s});        // radial-gradient(#FFF6DA, #F6C66A 30%, transparent 70%)
   });
   line.textContent = M.type('지금 이 순간에도 수많은 서비스를 돌리는 중', t, .3, 20);
   const n = Math.round(M.anim([[0, 11], [1.6, 20, {d: M.beat(1), e: 'outCubic'}]], t));
   pct.textContent = n + '%';                    // 장면 쌓기에선 number: odometer
   ```
2. **핸들 단 노드 흐름도**
   - 미색 판에 노드 상자 4~6개를 SVG rect 로 두고 `M.draw(edge, M.ease.outCubic(M.prog(t, t0, .6)))` 로 점선·곡선을 차례로 그어요.
   - 상자 테두리가 다 그어지면 네 귀퉁이 핸들을 `M.place(h, x, y, {s: M.spring(t - t1 - k * .15, 'snappy')})` 로 톡톡.
   - 가운데 노드만 `M.color('rgba(43,26,20,.25)', '#E5552A', k)` 로 선이 주황으로 바뀌고, 안 아이콘도 주황으로 채워져요.
   - 카메라: 부모를 `M.place(stage, cx, cy, {s: M.anim([[0, 2.2], [.4, 1, {d: 2.4, e: 'inOutCubic'}]], t)})` 로 바짝 붙었다 빠지게.
3. **기호에서 맞춰지는 끝말**
   - 가운데 문장의 앞뒤는 그대로 두고, 가운데 낱말 자리만 흐린 기호 가루에서 글자로 맞춰진 뒤 주황으로 물들어요. 장면 쌓기에서는 `marker: color` 가 끝말을 주황으로 칠해요.
   ```
   const r = M.rng(7);
   word.textContent = M.at([[0, '·/#%_'], [.5, '..ɑ/√'], [.9, '세계 어디서나']], t);
   word.style.color = M.color('rgba(43,26,20,.35)', '#E5552A', M.prog(t, .9, .3));
   ```
4. **픽셀로 부서지고 선 마크가 그려지는 엔딩**
   - 주황 새벽빛 판에서 `S.tr.blocks` 로 큰 픽셀 모자이크가 번지며 살구빛 미색 판으로 넘어가요.
   - 우리 브랜드 마크 윤곽을 SVG path 로 두고 `M.draw(mark, M.ease.inOutCubic(M.prog(t, .2, 1.2)))`. 그어지는 동안 경로 위 앵커 점(작은 흰 네모)이 선 끝을 따라 하나씩 켜졌다가 선이 다 그어지면 꺼져요.
   - 다음 박에 마크 아래로 작은 주소 한 줄, 주소 속 이름만 주황.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발자 도구·플랫폼 런칭, 인프라·배포 서비스 소개, 작업 흐름·자동화 설명, 숫자 하나로 규모를 자랑할 때, 기술 행사 오프닝. 40~60초 길이에서 판을 여러 번 오가면 잘 살아요.
- 피할 것: 손그림 선, 주황 말고 강조색 여러 개(파랑은 노드 도면 한 장에만), 굵은 블랙 제목, 그레인 없는 매끈한 주황, 빠른 글리치 컷.
- 주황 판 위 미색 글자는 대비가 조금 낮아서 짧은 변의 5% 이상 크기로만 써요.
