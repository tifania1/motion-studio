# 앵커와 핸들로 짓는 마크 (그래픽·도형)

한 줄: 옅은 회색 위에 흩어진 앵커 점이 글자 자리로 모여 외곽선이 되고, 어두운 화면에서 파란 앵커와 핸들이 달린 큰 곡선을 훑은 뒤, 보라 가이드선 속에서 마크가 한 칸씩 지어져 단색으로 채워지는 제작 과정 필름.

## 보는 느낌
- 벡터 편집 프로그램의 작업 화면을 아주 깔끔하게 다듬은 모습이에요. 바탕은 무늬 없는 옅은 회색이나 짙은 숯색 한 가지이고, 그 위에 가는 선과 작은 점만 놓여요.
- 화면에 있는 건 거의 다 '만드는 도구'예요. 속 빈 사각 앵커, 파란 둥근 앵커, 끝에 점이 달린 핸들 막대, 화면을 가로지르는 보라·분홍 가이드선. 완성된 글자나 마크는 마지막에 잠깐만 나와요.
- 여백이 아주 넓어요. 낱말은 화면 너비의 40% 안팎, 마크는 짧은 변의 25% 안팎으로 가운데 작게 두어요.
- 크기를 두 가지로 오가요. 곡선 하나가 화면을 넘칠 만큼 바짝 붙은 확대 장면과, 낱말이나 마크 전체가 보이는 먼 장면을 번갈아 써요.

## 색
- 바탕 80 · 선과 글자 15 · 파랑·보라 5.
- 밝은 장면은 #E6E6E6 바탕에 짙은 회색 #2B2B2B 선과 마크. 어두운 장면은 #262626 바탕에 옅은 회색 선과 흰 글자 #EDEDED.
- 파랑 #5A7BE0 은 선택된 앵커 점과 핸들 끝 점에만 써요. 넓게 칠하지 않아요.
- 보라 #B04DB0 는 가이드선 전용이에요. 어두운 화면에선 20~30% 정도로 흐리게, 밝은 화면에선 분홍빛으로 15~25% 겹쳐요.
- 마지막 마크와 낱말은 단색 하나로만 채워요.

## 글자
- 주인공 낱말은 넓고 기하학적인 그로테스크예요. Archivo 를 stretch 120~125%, 굵기 700 으로 쓰고, 한글은 Noto Sans KR Bold. 대문자, 자간 0.02em.
- 외곽선 상태(1px 선, 채움 없음)에서 채움 상태로 넘어가는 것을 글자 연출로 써요. 굵기나 크기는 바꾸지 않아요.
- 작은 주석은 Geist Mono 를 짧은 변의 1.6% 크기로 써요. 좌표나 치수처럼 가이드선 끝에 붙여요.
- 한 화면엔 낱말 하나나 짧은 한 줄만 두어요.

## 질감과 모양
- 질감은 없어요. 완전히 매끈한 평면이에요.
- 경로 선은 1~1.5px 회색, 가이드선은 1px 보라.
- 앵커는 두 가지예요. 모서리 앵커는 짧은 변의 0.8% 크기의 속 빈 사각, 곡선 앵커는 같은 크기의 파란 원. 핸들 막대는 1px 선이고 끝에 작은 원이 붙어요.
- 모서리는 거의 각지게(0.2u) 두고 그림자는 쓰지 않아요.

## 움직임
- 96BPM, 차분하고 정확한 결이에요. 카메라와 선 그리기는 `power3.inOut` 으로 미끄러지듯 시작하고 끝나요.
- 앵커 점은 0.15초에 톡 생기고, 경로 선은 앵커 사이를 0.4~0.6초에 그어요.
- 확대 장면에선 카메라가 곡선을 따라 2초 동안 한 방향으로 천천히 흘러요.
- 글자 채움은 한 자에 0.1초로 딱 채워지고, 글자 사이 간격은 반 박이에요. 순서는 섞어요.
- 완성된 마크나 낱말은 1.5~2초 머물러요.

## 전환
- 밝은 화면과 어두운 화면 사이는 컷으로 넘어가요.
- 같은 바탕 안에서는 짧은 페이드(0.3초)나 카메라 이동으로 이어요.
- 장면 쌓기 순서는 cut → fade → cut.

## 대표 장면
1. **흩어진 앵커가 모여 외곽선으로**
   ```
   // 글자 외곽선 path 를 따라 앵커 자리를 뽑아 두고, 흩어진 시작점에서 모음
   const pts = anchors.map((a, i) => ({ a, from: M.rng(i).point(W, H), to: a.pos }));
   S.ambient(t => {
     pts.forEach(({ a, from, to }, i) => {
       const k = M.ease.inOutCubic(M.prog(t, .2 + i * .01, 1.5));
       M.place(a.el, M.lerp(from.x, to.x, k), M.lerp(from.y, to.y, k), { o: .3 + k * .7 });
     });
     segs.forEach((p, i) => M.draw(p, M.prog(t, 1.6 + i * .04, .5)));   // 점 사이 곡선과 핸들
   });
   ```
2. **어두운 화면, 곡선을 따라가는 카메라**
   - 숯색 바탕에 화면보다 큰 곡선 path 한두 개를 두고, 위에 파란 앵커와 핸들 막대를 얹어요. 무대 전체를 `M.anim([[0, {x: 0, s: 3}], [2, {x: -W * .4, s: 3, e: 'inOutCubic'}]], t)` 로 옮겨 곡선을 따라 흐르게 해요.
   - 이어서 `s: 3 → 1` 로 크게 빠지면 보라 가이드선(세로·가로 SVG line) 위에 외곽선 낱말이 보여요. 글자마다 `fill-opacity` 를 `M.at([[t0 + 순서[i] * M.beat(.5), 1]], t)` 로 한 번에 1로 바꿔 채워요.
   - 장면 쌓기에서는 scenes.bg lines 가 가이드선을, deco handles 가 제목 둘레의 선택 상자와 손잡이를 깔아 줘요.
3. **사각 경로를 끌어 마크 짓기**
   ```
   // 직사각형 path 의 꼭짓점 하나를 끌어 L자·평행사변형으로
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, .6, .8));
     const p = M.lerp(rectPts, lShapePts, k);          // 꼭짓점 배열 보간
     path.setAttribute('d', M.poly(p));
     handles.forEach((h, i) => M.place(h, p[i].x, p[i].y));   // 사각 앵커가 꼭짓점을 따라감
     M.draw(ring, M.prog(t, 1.6, .6));                   // 곡선 고리 더하기, 파란 앵커 함께
   });
   ```
4. **분홍 가이드가 걷히며 단색 마크**
   - 완성된 외곽선 마크 위에 분홍 보조 격자선(가로·세로 6~8개)과 동심원 2개를 `M.draw` 로 0.5초에 겹쳐 그려요. 한 박 머문 뒤 가이드와 앵커를 0.3초에 지우고, 같은 순간 마크 채움을 짙은 회색으로 바꿔요. 다음은 컷으로 낱말 한 줄. 필요하면 `S.tr.blur` 를 아주 짧게 써도 결이 맞아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 로고·리브랜딩 공개, 디자인 스튜디오 작업 소개, 디자인·편집 도구 소개, 브랜드 가이드 오프닝, 꼼꼼함을 보여 주고 싶은 B2B 브랜드.
- 피할 것: 그라디언트와 빛 번짐, 종이·그레인 질감, 빠른 컷 몽타주, 손그림 선, 강조색을 넓게 칠하기, 글이 긴 장면.
- 원본 마크 모양은 따라 그리지 않아요. 우리 브랜드 로고의 실제 경로로 같은 과정을 다시 짜요.
