# 점 가루 핸들 리본 모니터 (제품 UI)

한 줄: 옅은 회색 위 초록 점 가루가 작은 네모 점판으로 가라앉고, 초록 선택 핸들 상자 속에서 가는 선다발 리본이 물결치다 웹페이지 장식이 돼요. 카메라가 뒤로 빠지면 그 화면은 회색 스튜디오 속 모니터예요.

## 보는 느낌
- 처음 4초는 거의 빈 옅은 회색 화면이에요. 작은 점과 네모만 있고 글자는 하나도 없어요. 여백이 화면의 90% 넘게 남아요.
- 점 가루 → 네모 점판 → 초록 점 하나 → 선택 상자 → 리본. 작은 것 하나가 점점 큰 그림으로 자라나는 순서예요.
- 선택 상자는 디자인 툴에서 도형을 잡은 모습이에요. 네 귀퉁이에 꽉 찬 초록 네모, 둘레는 1px 초록 선, 핸들에서 화면 끝까지 아주 옅은 안내선이 가로·세로로 뻗어요.
- 리본이 웹페이지 첫 화면의 장식이 되면서 화면 구성이 갑자기 웹사이트로 바뀌어요. 왼쪽에 짙은 제목 세 줄과 검은 버튼, 오른쪽에 문서형 카드 목록.
- 후반은 회색 스튜디오 바닥과 벽, 가운데 검은 테 모니터 한 대. 모니터 화면만 바뀌고 나머지는 거의 그대로예요.

## 색
- 옅은 회색 바탕 75 · 먹색 글자와 모니터 테 15 · 초록과 연두 10.
- 바탕 #EDEDEC, 글자 #1A1C1B, 회색 점·네모 #BDBEBD, 스튜디오 벽 #8A8C8B → 바닥 #5E605F.
- 초록 #34A853 은 켜진 점·핸들·상자 선에만. 연두 #C3E24A 는 리본 끝자락과 켜지는 순간의 반짝임 한 프레임에만.
- 리본 선은 #2E9E4F → #9FD447 → #C3E24A 로 흐르는 그라디언트, 가닥마다 불투명 40~70%.
- 웹페이지 안은 흰 바탕 #FFFFFF, 카드는 아주 옅은 민트 회색 #EEF3EF.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 웹페이지 제목은 굵기 600, 자간 −0.02em, 왼쪽 정렬 세 줄, 짧은 변의 6~7%.
- 제목 아래 한두 줄 설명은 400, 짧은 변의 2% 안팎, 핵심 낱말 두세 개만 굵게.
- 버튼은 검은 알약 안 흰 글씨, 옆에 작은 글자 링크 하나.
- 앞부분 점판 장면에는 글자를 쓰지 않아요. 글자는 웹페이지 화면에서 처음 나와요.

## 질감과 모양
- 거의 매끈해요. 그레인 0.04 로 회색 면이 너무 납작하지 않게 하고, 비네트 0.18 은 스튜디오 장면 가장자리를 살짝 어둡게.
- 점은 지름 0.2~0.4u 동그라미, 점판의 네모는 0.6u 정사각형(모서리 없음). 핸들은 1.2u 꽉 찬 초록 정사각형.
- 리본 선은 0.08u 두께로 아주 가늘게. 가닥 수가 많아야 면처럼 보여요.
- 웹 카드 모서리 0.8u, 그림자는 아주 옅게 한 겹. 모니터 테는 검정 1.2u, 모서리 1.4u, 아래에 짙은 회색 받침대.

## 움직임
- 96BPM, 대략 한 박 반(0.9초)마다 한 단계씩 바뀌어요.
- 점 가루는 처음에 아주 천천히 떠다니다 0.8초 만에 `power3.inOut` 으로 격자 자리에 내려앉아요.
- 핸들은 가운데 점에서 0.3초에 튀어나오고(살짝 넘쳤다 제자리), 상자는 1.2초에 걸쳐 바깥으로 넓어져요.
- 리본은 늘 천천히 물결쳐요. 가닥마다 위상만 조금씩 다른 사인 곡선이라 꼬인 천처럼 보여요(한 주기 4초).
- 모니터 공개는 카메라가 1초에 뒤로 빠지며 화면이 62% 크기로 줄고 아래에서 받침대가 들어와요. 이후 모니터는 거의 정지, 아주 느리게 0.5% 다가가기만.

## 전환
- 점판 → 웹페이지는 흐림(blur)으로 녹아 바뀌어요.
- 웹페이지 → 모니터는 끊지 않고 카메라가 빠지는 한 동작이에요.
- 모니터 안 화면끼리는 밀어내기(push)나 컷. 마지막 흰 마크 화면은 컷.
- 장면 쌓기: blur → push → cut.

## 대표 장면

1. 점 가루가 네모 점판으로 가라앉기
   ```
   const rnd = M.rng(7);
   const dots = S.$$('.dust');            // 300개, 초록 30% · 회색 70%
   const home = dots.map(() => [rnd() * W, rnd() * H]);
   const grid = dots.map((_, i) => i < 24 ? [cx + (i % 6 - 2.5) * W * .1, cy + ((i / 6 | 0) - 1.5) * H * .14] : null);
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, .6, .8));
     dots.forEach((d, i) => {
       const [hx, hy] = home[i], g = grid[i];
       const dx = hx + Math.sin(t * .7 + i) * 6, dy = hy + Math.cos(t * .5 + i) * 6;
       if (g) M.place(d, dx + (g[0] - dx) * k, dy + (g[1] - dy) * k, {s: 1 + k});
       else M.place(d, dx, dy, {o: 1 - k});   // 나머지 가루는 흩어지며 사라짐
     });
   });
   // 1.6초쯤 가운데 네모 하나만 배경색 → 초록 (M.color, 0.15초)
   ```
2. 선택 핸들이 벌어지고 리본이 물결치기
   ```
   // 핸들 4개와 1px 상자, 핸들에서 화면 끝까지 옅은 안내선
   S.ambient(t => {
     const pop = M.spring(t - M.beat(3), 'bouncy');
     const grow = M.ease.inOutCubic(M.prog(t, M.beat(4), 1.2));
     const w = W * (.02 + .4 * grow) * pop, h = H * (.02 + .4 * grow) * pop;
     M.box(frame, {x: cx - w / 2, y: cy - h / 2, w, h});
     corners.forEach((c, i) => M.place(c, cx + (i % 2 ? w : -w) / 2, cy + (i < 2 ? -h : h) / 2));
     // 리본: path 40가닥, 위상만 다른 사인 곡선
     lines.forEach((p, j) => p.setAttribute('d', wave(w, h, t * 1.5 + j * .08, j / 40)));
     M.draw(ribbon, M.ease.outCubic(M.prog(t, M.beat(4.5), .8)));
   });
   ```
   장면 쌓기에서는 deco handles 가 제목 둘레에 선택 상자와 손잡이를 두르고, deco dots 가 바탕에 점판을 깔아요.
3. 웹페이지에서 모니터로 빠지기
   - 리본을 그대로 둔 채 S.tr.blur 로 웹페이지 첫 화면(frame browser, 왼쪽 정렬 제목 세 줄 + 검은 알약 버튼 + 오른쪽 카드 목록)이 맺혀요. 리본은 오른쪽 위로 옮겨 장식이 돼요.
   - 한 박 뒤 화면 전체를 모니터 틀에 넣고 `s = M.anim([[0, 1], [tB, .62, {d: 1, e: 'inOutCubic'}]], t)` 로 줄이며, 바탕을 회색 스튜디오(위는 #8A8C8B, 아래 바닥은 #5E605F 그라디언트)로 바꿔요. 받침대는 아래에서 `M.anim` 으로 올라와요.
4. 모니터 화면 갈아 끼우기와 마크
   - 모니터 틀은 고정, 화면 안만 박자마다 바꿔요: 색 카드 다섯 장이 나란한 페이지 → 차분한 문서 페이지 → 흰 화면.
   - `M.at([[t0, 0], [t0 + M.beat(1.5), 1], [t0 + M.beat(3), 2]], t)` 로 어느 화면을 보일지 고르고, 사이는 push 나 컷.
   - 마지막 흰 화면 가운데 초록 마크와 짙은 이름 한 줄이 `M.spring(t - tL, 'smooth')` 로 살짝 커지며 맺히고 끝까지 머물러요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발 도구·문서 서비스 공개, 웹사이트 개편 소개, B2B 제품 런칭, AI·데이터 플랫폼 티저. 8~15초 짧은 공개 영상.
- 피할 것: 어두운 바탕 위주, 손그림 선, 원색 여러 개(초록 한 계열만), 빠른 글리치 컷, 굵고 큰 포스터 글자.
- 앞부분은 글자 없이 점과 선만으로 버텨야 이 결이 살아요. 문구는 웹페이지 화면이 열린 다음에 넣어요.
