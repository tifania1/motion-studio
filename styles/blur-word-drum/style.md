# 흐림 낱말 드럼 (타이포)

한 줄: 아주 옅은 회색 위에서 낱말 원통이 세로 흐림을 끌며 굴러가다 파란 낱말 하나에 멈춰요. 빠른 움직임마다 방향 흐림이 남고, 기울어 뜬 카드 가장자리엔 파란 빛이 번져요.

## 보는 느낌
- 거의 흰 회색 바탕에 글과 카드만. 화면이 밝고 공기가 많아요.
- 빠르게 움직이는 것은 언제나 그 방향으로 흐림을 끌어요(세로로 구르면 세로 흐림, 옆으로 빠지면 가로 흐림). 멈추면 바로 또렷해져요.
- 장 사이마다 낱말 드럼이 나와 "이번엔 이 쓰임새"라고 알려 주고, 그다음 기운 앱 카드로 들어가요.

## 색
- 바탕 #EEEEF0 80 · 글자 12 · 파랑 6 · 아이콘 색 2.
- 글자 먹색 #1F1F1F, 드럼의 옅은 낱말 #C9C9CE.
- 파랑 #3D6FE0 → #7BA7F5 그라디언트는 드럼 가운데 낱말·막 친 글자·카드 빛 번짐에만.
- 커서·아이콘 타일 안 작은 색(초록 #34A853, 노랑 #F4B400)은 점처럼만.

## 글자
- Geist 500 + Noto Sans KR 500. 제목도 500~600, 굵게 쓰지 않아요.
- 드럼 낱말은 짧은 변의 11~13%, 줄 간격 1.0, 자간 −0.025em. 한 단어(두세 글자)로.
- 타자 문장은 짧은 변의 7%, 가운데 정렬, 두 줄까지.

## 질감과 모양
- 질감 없음.
- 카드: 흰색, 모서리 2.2u, `perspective(1400px) rotateX(14deg) rotateY(-12deg) rotateZ(-6deg)` 쯤 기울임.
  가장자리 빛: `box-shadow: 0 0 6u 1u rgba(66,133,244,.35)` 한 겹. 빛은 카드에만 쓰고 글자에는 넣지 않아요.
- 아이콘 타일: 글자 높이만 한 둥근 정사각(모서리 0.6u) 연회색 #E2E2E6, 안에 작은 색 아이콘.

## 움직임
- 110BPM. 들어오고 멈출 때 power4.out(빠르게 와서 길게 감속). 넘침 없음.
- 드럼 회전 0.7초, 멈춘 뒤 가운데 낱말 색이 0.3초에 회색 → 파랑.
- 큰 아이콘·사물은 화면 밖에서 크고 흐리게(blur 2u) 날아와 0.5초에 제 크기로 또렷해져요(피사계 심도처럼).
- 흐림 세기는 그 순간 속도에 비례: 속도가 0이면 흐림 0.

## 전환
- 가로로 휙(whip)이 기본: 장면 전체가 옆으로 빠지며 가로 흐림. 그다음 흐림(blur) 겹침, 카드로 들어갈 땐 확대(zoom).

## 대표 장면

1. **낱말 드럼**
   ```
   // 낱말 N개를 원통에 배치. 회전각 a(t) 는 t0 에서 시작해 tStop 에 목표 칸에서 멈춤
   const a = M.anim([[0, a0], [t0, aTarget, { d: .7, e: 'outQuart' }]], t);   // 칸 단위
   const v = (a - M.anim([[0, a0], [t0, aTarget, { d: .7, e: 'outQuart' }]], t - 1/60)) * 60; // 속도
   words.forEach((w, i) => {
     const th = (i - a) * .42;                         // 칸 사이 각도
     M.place(w, W/2, H/2 + Math.sin(th) * R, { sy: Math.cos(th), o: Math.cos(th) > .1 ? 1 : 0 });
     w.style.filter = `blur(${Math.min(14, Math.abs(v) * 3)}px)`;     // 세로 흐림 대신 흐림 + 아래 잔상
     w.classList.toggle('on', Math.round(a) === i && Math.abs(v) < .2);   // .on = 파랑 그라디언트 글자
   });
   // CSS: .on { background: linear-gradient(90deg, #3D6FE0, #7BA7F5); -webkit-background-clip: text; color: transparent }
   ```
   세로로만 흐리게 보이려면 같은 낱말 복제 2~3개를 위아래로 속도만큼 벌리고 투명도 .25 로 겹쳐요.
2. **휙 빠지기 → 기운 카드**
   - `S.tr.whip` 으로 다음 장면. 직접 짤 때는 장면 x 를 `M.anim(..., {d: .35, e: 'inExpo'})` 로 −W 까지, 복제 3장을 x 간격 4u, 투명도 .3 으로 겹쳐 가로 흐림.
   - 카드는 기운 채 오른쪽 아래에서 `M.spring('soft')` 로 들어와 멈추고, 카메라(`M.camera`)가 입력칸 쪽으로 1.4배 다가감.
3. **아이콘이 끼는 문장 타자**
   ```
   line.textContent = M.type(text, t, t0, 14);       // 어절 경계마다 타일 span 을 넣어 둠
   caret.style.background = M.at([[t0, '#3D6FE0'], [tw1, '#34A853'], [tw2, '#F4B400']], t);
   tile.style.transform = `scale(${M.spring(t - tw1, 'pop')})`;
   // 막 친 어절: M.color('#3D6FE0', '#1F1F1F', M.prog(t, tw + .5, .3))
   ```
