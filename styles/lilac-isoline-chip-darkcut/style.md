# 연보라 등각 도면과 어둠 컷 (3D·사물)

한 줄: 옅은 회색 위에 연보라 가는 선으로 그린 등각 칩 도면이 층층이 들리며 선을 뻗어 작은 판들을 잇고, 사이사이 숯빛 화면으로 컷되면 흰 두 줄 문장과 빛나는 아이콘 띠가 지나가는 차분한 B2B 런칭이에요.

## 보는 느낌
- 밝은 장면은 옅은 회색 바탕이고, 가장자리(특히 아래와 양옆)에 연보라 안개가 은은하게 껴요. 한가운데에는 문장 한 줄이나 등각 도면 하나만 놓여요.
- 도면은 모두 가는 연보라 선과 아주 옅은 흰 면으로 그려요. 칩·판·자물쇠·방패 같은 소품이 바닥 격자 위에 놓이고, 연결선이 등각 축을 따라 곧게 뻗어 작은 판들을 이어요.
- 바닥에는 아주 옅은 등각 격자선과 넓은 연보라 빛 띠가 비스듬히 지나가요.
- 어두운 장면은 거의 검은 숯빛이에요. 귀퉁이에 작은 십자 눈금, 가는 가로·세로 안내선이 있고, 글은 흰색 두 줄이에요. 끝으로 갈수록 점 무늬 동심원이 바탕에 깔려요.
- 밝음과 어둠을 장(章)처럼 번갈아 써요: 밝은 문장 → 밝은 도면 → 어두운 선언 → 밝은 도면 여러 장 → 어두운 묶음 → 어두운 마무리.

## 색
- 밝은 장면: 회색 바탕 75 · 연보라 선과 안개 15 · 먹색 글자 8 · 보라 강조 2.
- 바탕 #EDEDF0, 글자 #1F1F24, 도면 선 #A99BEF, 진한 강조 보라 #6A45E0.
- 보라는 문장 속 낱말 하나에만 써요. 도면 안에서는 버튼 하나나 막대 하나만 진한 보라로 칠해요.
- 어두운 장면: 숯빛 #161618 바탕, 흰 글자 #EDEDF0, 아랫줄은 흰색 55%. 아이콘 띠의 가운데 칸만 연보라 빛(glow)을 둘러요.

## 글자
- Geist 와 Noto Sans KR 로 담백한 산세리프를 써요. 제목 굵기 600, 자간 -0.02em.
- 문장은 짧은 변의 5~6% 크기로 가운데 한두 줄. 결론 한마디("이제 됩니다" 같은)만 두 배쯤 크게, 굵기 700으로 써요.
- 도면 꼬리표는 짧은 변의 2.5% 정도로 작게 쓰고, 바닥 면에 눕혀 등각 축으로 기울여요. 두 줄이면 오른쪽 정렬.
- 어두운 장면의 두 줄 문장은 윗줄을 선명하게, 아랫줄은 아래로 갈수록 흐려지는 그라디언트를 입혀요.

## 질감과 모양
- 그레인 0.04 정도만 깔아서 어두운 장면의 점 무늬와 밝은 바탕의 안개가 매끈하게 보이게 해요.
- 선 두께는 1.5px 안팎으로 일정하게. 모서리는 0.8u 로 살짝만 둥글려요.
- 그림자는 쓰지 않고, 소품 아래에 옅은 연보라 번짐 하나만 둬요.
- 어두운 장면의 아이콘 칸은 0.8u 둥근 네모, 가운데 칸만 테두리와 빛이 밝아요.

## 움직임
- 96BPM, 보통 빠르기. 장면 하나에 2~4초씩 머물러요.
- 들어올 땐 power2.out 으로 부드럽게 멈춰요. 도면 층은 0.6초 간격으로 위로 들리고, 연결선은 0.5초에 그어져요.
- 카메라는 장면 내내 아주 천천히(4초에 짧은 변의 3~4%) 비스듬히 흘러서 도면이 살아 있게 보여요.
- 문장은 흐림에서 선명하게 맺히고, 낱말을 바꿀 땐 그 낱말 자리만 흐림으로 갈아 끼워요("아직" → 보라색 "이미").
- 큰 숫자는 옅은 채로 한 박에 수백씩 올라가다 둥근 수에서 멈춰요.

## 전환
- 밝음과 어둠 사이는 컷이에요. 같은 밝기 안에서는 느린 페이드나, 도면이 같은 자리에서 다른 소품으로 바뀌는 컷을 써요.
- 장면 쌓기: cut → fade. 밀어내기·흔들기 전환은 쓰지 않아요.

## 대표 장면
1. **층이 들리는 등각 칩**
   ```js
   // 등각 판 하나 = SVG 마름모 path. 층 i 를 위로 들어 올림
   const iso = (x, y) => [ (x - y) * .866, (x + y) * .5 ];
   layers.forEach((L, i) => {
     const k = M.ease.outCubic(M.prog(t, .4 + i * .6, .6));
     M.place(L, cx, cy - i * u * 1.2 * k, { o: M.prog(t, .2 + i * .6, .3) });
   });
   links.forEach((p, j) => M.draw(p, M.ease.outCubic(M.prog(t, 2.6 + j * .25, .5))));
   S.ambient(t => M.place(camera, cx - t * u * .8, cy - t * u * .4));   // 느린 비스듬 흐름
   ```
   연결선 끝의 작은 판은 선이 다 닿는 순간 `M.spring(t - tj, 'smooth')` 로 내려앉아요.
2. **바닥에 누운 꼬리표와 소품 바꾸기**
   - 꼬리표에 `transform: rotate(-30deg) skewX(30deg) scaleY(.86)` 를 걸어 바닥 면에 눕혀요.
   - 소품(자물쇠판 → 방패 → 괄호 쌍)은 같은 자리에 겹쳐 두고 `M.at([[0, 0], [t1, 1], [t2, 2]], t)` 로 하나만 보이게 컷. 꼬리표도 같은 시각에 바꿔요.
3. **숯빛 선언과 빛나는 아이콘 띠**
   - 컷으로 s-paper(숯빛) 장면. 귀퉁이 십자 눈금은 deco marks, 문장은 title: blur 로 맺히고 아랫줄은 `background: linear-gradient(#EDEDF0, rgba(237,237,240,.4)); -webkit-background-clip: text`.
   ```js
   const x = M.anim([[0, W * .1], [.2, -W * .1, { d: 3, e: 'inOutSine' }]], t);
   M.place(strip, cx + x, cy - u * 3);
   center.style.boxShadow = `0 0 ${3 * u}px var(--glow)`;          // 가운데 칸만 빛
   num.textContent = Math.round(M.anim([[.4, 17800], [2.4, 18000, { d: 2 }]], t)).toLocaleString();
   ```
4. **동심원 위 마무리**
   - 점 무늬 동심원(deco rings)을 천천히 숨 쉬게 두고, 흰 두 줄 문장을 흐림에서 맺은 뒤 페이드로 마크 하나만 남겨요. `S.tr.blur` 로 문장에서 마크로 넘어가면 같은 결이에요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: B2B·개발자 도구 런칭, 보안·인프라 플랫폼 소개, 구조를 도면으로 풀어 설명할 때, 연결·통합 서비스.
- 피할 것: 손그림 선, 꽉 찬 원색 면, 반 박마다 몰아치는 컷, 두꺼운 그림자와 반짝이는 3D 재질, 한 화면에 문장 세 줄 이상.
- 보라는 아껴 써요. 낱말 하나, 도면 속 칸 하나만 진하게 칠하면 이 결이 살아요.
