# 연두 판 슬롯 채우기 (제품 UI)

한 줄: 옅은 연두 바탕 위 짙은 밤색 패널의 보라 빈칸을 큰 검정 커서가 자홍으로 물들여 누르면, 같은 틀 안에 내용이 1초마다 갈아 끼워지고 끝에는 패널 벽으로 물러나는 컴포넌트 데모예요.

## 보는 느낌
- 바탕은 거의 흰빛에 가까운 옅은 연두 한 색이에요. 무늬도 질감도 없이 판판해요.
- 주인공은 가운데 놓인 짙은 밤색 패널 하나. 화면 높이의 55~65% 크기이고, 위 막대에 짧은 제목과 작은 동그라미 단추 둘이 있어요. 안쪽에는 보라 가는 선으로 그은 빈칸이 있어요.
- 패널 바로 위 왼쪽에 아주 작은 보라 이름표(작은 마름모 아이콘 + 낱말)가 붙어서, 이게 '부품'이라는 걸 알려 줘요.
- 여백이 넓어요. 한 화면에 패널 하나, 커서 하나. 패널을 여러 개 늘어놓는 건 마지막 물러나는 장면에서만 해요.
- 첫 장면은 왼쪽 위에 산세리프 두 줄을 왼쪽 정렬로 두고, 끝말 하나만 보라로 칠해요.

## 색
- 연두 바탕 65 · 밤색 패널 25 · 보라·자홍 7 · 흰 글자·손잡이 3.
- 바탕 #E3ECD5, 글자 #1C1A1A, 패널 #2F2324, 패널 위 글자 #F2EEEE.
- 보라 #7E4FE0 은 '아직 비어 있음'과 이름표, 제목 끝말에 써요. 자홍 #D61FB4 는 '지금 채우는 중'이라는 신호라서 커서가 빈칸에 올라간 순간에만 켜요.
- 연보라 #B9A6F2 는 패널 속 막대그래프·카드 같은 채워진 내용에만 써요.
- 툴바 장면은 아주 옅은 회색 #EEEEEE 바탕에 짙은 회색 아이콘, 눌림 상태만 옅은 파랑이에요.
- 마무리 한 장은 거의 검정 #121212 위에 흰 글자로 해요.

## 글자
- 큰 문장: Geist 500(한글 Noto Sans KR Medium). 짧은 변의 8~9%, 자간 −0.02em, 왼쪽 정렬, 줄 간격 1.05로 촘촘하게 써요.
- 패널 제목: Archivo 를 좁게(stretch 75%, 굵기 500) 써서 작고 단단한 이름표처럼 보이게 해요. 한글은 Noto Sans KR Bold.
- 패널 속 숫자: Geist 600, 크게 셋을 나란히 두고 숫자 아래에 아주 작은 회색 꼬리표를 달아요.
- 이름표·툴팁: Geist 500, 짧은 변의 2% 안팎.

## 질감과 모양
- 질감은 없어요. 판판한 색면과 가는 선만 써요.
- 패널 모서리 1.2u, 그림자 없이 바탕과 색 대비로만 떠 보여요.
- 빈칸 테두리는 1.5px 보라, 채우는 중엔 같은 굵기의 자홍. 선택 상자는 1.5px 보라 선과 네 귀퉁이 흰 네모 손잡이(테두리 보라)예요.
- 커서는 화면 높이 9~10%로 크게 키운 검정 화살표에 흰 외곽선 2px, 아래로 옅은 그림자 하나를 둬요.

## 움직임
- 104BPM, 보통 속도. 커서는 power3.out 으로 미끄러져 와서 멈추고, 누를 땐 0.1초 동안 90%로 줄었다 돌아와요.
- 빈칸 채우기는 박에 맞춰요. 커서 도착 → 반 박 뒤 자홍 → 한 박 뒤 누름 → 내용이 0.25초 만에 올라오며 맺혀요.
- 내용 갈아 끼우기 구간은 1초(약 2박)마다 한 번, 컷으로 바꿔요. 패널 틀은 꼼짝하지 않아요.
- 카메라는 툴바나 패널 속 한 줄로 0.6~0.8초에 바짝 다가가고(power3.inOut), 마지막엔 1.2초에 걸쳐 크게 물러나요.
- 큰 문장은 어절마다 아래에서 살짝 올라와요(rise). 두 번째 줄은 한 박 늦게 붙어요.

## 전환
- 패널끼리는 밀어내기(push): 새 패널이 오른쪽에서 들어오고 앞 패널은 왼쪽 가장자리에 반쯤 걸친 채 밀려 나가요.
- 툴바·목록 확대는 카메라 줌으로 이어 가고, 내용 갈아 끼우기와 검정 마무리 판은 컷으로 해요.
- 장면 쌓기: push → cut → push → fade.

## 대표 장면

1. **빈칸에 커서가 들어와 채우기**
   ```js
   const cur = new M.Cursor(S.$('.cursor'));
   S.ambient(t => {
     cur.at(M.cursorAt([[0, W*.78, H*.85], [.6, cx, cy, {e: 'outCubic'}]], t));
     const hot = M.prog(t, .9, .15);                       // 반 박 뒤 자홍으로
     slot.style.borderColor = M.color('#7E4FE0', '#D61FB4', hot);
     M.place(plus, cx - 1*u, cy - 1*u, {s: M.spring(t - .9, 'snappy'), o: hot});
     const k = M.spring(t - 1.5, 'smooth');                // 누른 뒤 내용이 차오름
     M.place(content, 0, (1 - k) * 2*u, {o: k});
   });
   ```
2. **같은 틀, 내용만 1초마다 갈기**
   ```js
   const fills = S.$$('.fill');      // 프로필 숫자 · 연보라 막대 · 재생 목록 카드
   S.ambient(t => {
     const i = M.at(fills.map((_, k) => [k * M.beat(2), k]), t);
     fills.forEach((f, k) => f.style.visibility = k === i ? 'visible' : 'hidden');
     title.textContent = titles[i];
     bars.forEach((b, j) => b.style.transform = `scaleY(${M.ease.outCubic(M.prog(t, i * M.beat(2) + j * .03, .3))})`);
   });
   ```
   장면 쌓기에서는 frame: window 로 패널 틀을 두고, deco cursor 가 강조 말로 와서 눌러요.
3. **툴바에 바짝 붙어 툴팁 띄우기**
   - 카메라를 `M.anim([[0, 1], [0, 2.4, {d: .7, e: 'inOutCubic'}]], t)` 배율로 툴바에 붙이고, 커서가 아이콘에 멈추면 짙은 툴팁을 `M.place(tip, x, y - 1*u, {s: M.spring(t - t1, 'snappy'), o: 1})` 로 톡. 누르는 순간 아이콘 바탕을 `M.color('#EEEEEE', '#D8E6FB', k)` 로 바꿔요.
4. **선택 상자가 줄을 옮겨 다니다 패널 벽으로**
   - 밤색 목록 위에 손잡이 상자를 `M.box(sel, {x, y: rowY[M.at(rowTimes, t)], w, h})` 로 줄마다 0.3초에 옮겨요(power3.out). 그다음 카메라 배율을 2.2 → 0.45 로 1.2초에 내려 연두 바탕 위 패널 6~8개가 엇갈려 놓인 벽을 드러내요. 벽은 `M.drift` 로 아주 천천히 위로 흘러요.
   - 이어 컷으로 검정 판, 흰 Geist 두 줄이 한 박 차이로 올라와요. 장면 사이에 흐림이 필요하면 `S.tr.blur` 를 짧게 써요.
