# 미니어처 사물 검색 고리 (3D·사물)

한 줄: 옅은 회색 화면 가운데 둥근 글자 한 줄과 알약 검색창은 그대로 두고, 둘레의 오려낸 사물·별점 카드·작은 사람 모형이 한 묶음씩 천천히 녹아 사라졌다가 새 묶음으로 피어나는 진열장 같은 장면.

## 보는 느낌
- 옅은 회색 바탕 한가운데에 둥글둥글한 보라 글자 한 줄, 바로 아래 흰 알약 검색창(오른쪽 끝 보라 동그라미 버튼). 이 둘은 영상 내내 움직이지 않는 닻이에요.
- 둘레를 사물이 고리처럼 둘러싸요. 위쪽 가운데와 아래쪽 가운데에는 커다란 오림 사물(베개, 신발, 의자와 스탠드, 냄비)을, 네 귀퉁이 쪽에는 흰 상품 카드와 기운 정사각 사진 타일을 짝지어 겹쳐 둬요.
- 크기 장난이 핵심이에요. 사물 위에 손가락만 한 사람 모형이 앉아 있거나 옆에 서 있어서, 평범한 물건이 집채만 한 무대처럼 보여요.
- 왼쪽 가장자리에 얇은 아이콘 줄, 아래 가운데에 작은 페이지 점 줄. 화면이 앱 첫 화면처럼 정돈돼 있어요.
- 가운데 띠(글자와 검색창)는 비워 두고, 사물은 화면 위·아래 3분의 1 안에만 놓아요.

## 색
- 회색 바탕 70 · 사물과 흰 카드 25 · 보라 5.
- 바탕 #ECECED, 카드 #FFFFFF, 글자 #1C1C1F.
- 보라 #5A31F4 는 가운데 글자, 검색 버튼, 왼쪽 줄의 지금 아이콘 하나에만.
- 별점 노랑 #F2B84B 은 카드 속 작은 별에만. 사물 사진은 베이지·크림·회색 #C9C3B8 처럼 바랜 생활 색이 많아 바탕과 잘 섞여요.

## 글자
- 가운데 한 줄: Geist 700(한글 Noto Sans KR Bold), 자간 −0.02em, 짧은 변의 7~8%. 둥글고 친근하게.
- 검색창 안 안내 문구: Geist 400, 아주 작게(짧은 변의 1.8%), 옅은 회색.
- 카드 글: 상품 이름 한 줄(Geist 500, 짧은 변 1.4%), 그 아래 별 다섯 개와 괄호 숫자. 줄 간격 1.3.
- 큰 제목을 따로 쓰지 않아요. 글은 가운데 한 줄과 카드 꼬리표가 전부.

## 질감과 모양
- 질감 없이 매끈하게. 사진과 사물은 밝고 고른 조명.
- 흰 카드: 모서리 1.6u, 아주 넓고 옅은 그림자(0 1.2u 3u rgba(0,0,0,.08)). 카드 안 사진 칸은 모서리 1u.
- 사진 타일: 정사각, 모서리 1u, −8~+8도로 살짝 기울여 카드 뒤에 반쯤 걸쳐요.
- 오림 사물: 배경 없는 컷아웃, 바닥에 흐린 접지 그림자 하나.
- 검색창: 흰 알약, 1px 회색 테두리 대신 옅은 그림자.

## 움직임
- 80BPM, 느림. 묶음 하나가 3~6초 머물러요.
- 머무는 동안 사물과 카드는 제각각 아주 천천히 떠다녀요(4초에 짧은 변의 0.5% 안팎). 가운데 글자와 검색창은 꼼짝 않아요.
- 묶음이 나갈 땐 전부 함께 0.6초에 투명도 1→0, 흐림 0→6px, 크기 1→0.97.
- 새 묶음은 0.1~0.15초 간격으로 하나씩 들어와요: 투명도 0→1, 흐림 6→0, 크기 0.94→1, `power2.out` 0.7초. 큰 사물 먼저, 카드, 타일 순.
- 사람 모형은 사물이 자리 잡고 한 박(0.75초) 뒤에 크기 0→1 로 톡(`back.out(2)`, 0.3초) 나타나요. 머무는 중간에 자리를 한 번 옮기기도 해요.

## 전환
- 장면 사이는 흐려지며 옅어지는 녹아내림(fade + blur). 컷이나 밀어내기는 쓰지 않아요.
- 바뀌는 건 둘레 묶음뿐이라, 가운데 닻이 있는 장면끼리는 전환 없이 묶음만 갈아 끼워도 돼요. 장면 쌓기: fade → blur.

## 대표 장면
1. **가운데 닻 + 둘레 묶음 갈아 끼우기**
   ```
   // 묶음 3개를 미리 겹쳐 두고, 각 묶음의 들어오기·나가기를 t 의 함수로
   const sets = S.$$('.set');                 // 각 .set 안에 .item 8~10개
   const T = [[0, 2.6], [3.2, 9.4], [10.2, 99]]; // [들어옴, 나감]
   S.ambient(t => sets.forEach((set, s) => {
     const [a, b] = T[s];
     S.$$('.item', set).forEach((el, i) => {
       const kin = M.ease.outCubic(M.prog(t, a + i * .12, .7));
       const kout = M.prog(t, b, .6);
       const k = kin * (1 - kout);
       const [dx, dy] = M.drift(t, i + s * 10, .5);   // 아주 느린 떠다님
       M.place(el, el._x + dx, el._y + dy, {o: k, blur: (1 - k) * 6, s: .94 + .06 * kin - .03 * kout});
     });
   }));
   // 가운데 글자·검색창은 S.ambient 밖에 고정
   ```
2. **커다란 사물 위 작은 사람**
   - 사물을 `M.place` 로 두고, 사람 모형(오림 그림, 사물 높이의 12~18%)을 사물 윗면 좌표에 붙여요.
   - `k = M.spring(t - (tIn + M.beat(1)), 'bouncy')` 로 크기 0→1. 중간에 `M.anim([[t1, x0], [t1 + .5, x1, {d: .5, e: 'inOutCubic'}]], t)` 로 사물 위 다른 자리로 옮겨 앉혀요.
   - 장면 쌓기에서는 stage 템플릿의 소품 자리에 사물을 크게, 사람 모형을 작게 겹쳐 같은 크기 대비를 내요.
3. **별점 카드와 기운 타일 짝**
   - 흰 카드(사진 칸 + 이름 + 별 다섯)를 귀퉁이에 두고, 정사각 사진 타일을 카드 뒤로 반쯤 겹쳐 `rotate(-6deg)`. 타일이 카드보다 0.1초 먼저 들어와요.
   - 별은 카드가 다 들어온 뒤 왼쪽부터 0.04초 간격으로 노랗게 켜요(`M.at`).
4. **페이지 점 진행 표시**
   - 아래 가운데 점 5개, 지금 칸만 너비 3배 막대. 묶음이 바뀌는 순간 `M.box(bar, {x: M.anim([[b, xs], [b + .6, xs + 칸, {d: .6, e: 'inOutCubic'}]], t), w})` 로 막대가 다음 칸으로 미끄러져요.
   - 마지막 묶음에서 검색창에 `M.type(문구, t, t0, 18)` 로 짧은 검색어를 치고 보라 버튼을 살짝 눌러(크기 0.92→1) 끝내요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 쇼핑·커머스 앱 소개, 검색·추천 기능 런칭, 카테고리별 상품 훑기, 편집숍·생활용품 브랜드, 선물 고르기 캠페인.
- 피할 것: 어두운 바탕, 빠른 컷과 흔들림, 굵고 큰 문장 여러 줄, 강한 질감·그레인, 강조색 여러 개(보라 하나와 별점 노랑만).
- 묶음마다 주제를 하나로 묶으면(옷·신발 / 집·가구 / 부엌·간식) 바뀌는 순간이 이야기처럼 읽혀요.
