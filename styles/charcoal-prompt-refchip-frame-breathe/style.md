# 숯빛 입력창 참조 칩과 숨 쉬는 결과 액자 (제품 UI)

한 줄: 점 격자가 옅게 깔린 숯빛 화면에서 둥근 입력창에 부탁이 쳐지고, 이름표 단 연두 커서가 참조 카드를 끌어와 칩으로 접어 넣어요. 생각 로그가 세로 줄을 따라 차오른 뒤, 결과 영상이 화면 가득 떴다가 흐린 제 바탕 위 둥근 액자로 줄었다 다시 커져요.

## 보는 느낌
- 영상이 세 막으로 나뉘어요. 부탁하기(입력창과 참조 카드), 생각하기(단계 로그), 보여 주기(결과 영상). 앞의 두 막은 거의 검은 숯빛 화면에 작은 UI만, 마지막 막은 사진·영상이 화면을 꽉 채워요.
- UI 막은 여백이 아주 넓어요. 입력창 하나가 화면 너비의 35~40%, 나머지는 옅은 점 격자뿐이에요. 카메라는 입력창 둘레에 살짝 다가가 있고 크게 움직이지 않아요.
- 결과 막은 반대로 색이 가득해요. 영상이 둥근 액자로 줄어들면 둘레에 같은 영상을 크게 흐리고 밝게 바랜 바탕이 깔려서, 액자가 자기 빛 위에 떠 있는 것처럼 보여요.
- 화면 오른쪽 아래 구석에 작은 점 구슬(점으로 짠 공 모양 로딩 표시)이 천천히 돌아요.

## 색
- UI 막: 숯빛 바탕 #131313 85 · 입력창·카드 #2A2A2A 10 · 연두 #C3E27E 5.
- 글자는 밝은 회색 #E6E6E3, 보조 글과 지나간 단계는 52% 회색.
- 연두는 커서 화살표와 이름표에만 써요. 이름표 글자는 짙은 올리브 #22300F.
- 점 격자는 흰색 7%. 결과 막의 흐린 바탕은 영상 색을 따라가되 밝게 바래요(옅은 세이지 #B9BFB0 안팎).

## 글자
- Geist 400~500, 한글은 Noto Sans KR Medium. 큰 제목을 쓰지 않고 모두 작게.
- 입력창 글은 화면 높이 2.6% 안팎, 두 줄까지 왼쪽 정렬. 탭(물어보기·자동·계획)은 그보다 작고 고른 것만 옅은 회색 알약.
- 생각 로그는 왼쪽 정렬, 줄 간격 1.4. 단계 제목은 밝게, 설명은 흐린 회색.
- 칩 글은 화면 높이 2% 안팎. 앞에 정사각 썸네일을 붙여요.

## 질감과 모양
- 화면 질감은 따로 없이 매끈하게. 바탕 무늬는 점 격자 하나뿐이에요.
- 입력창: #2A2A2A 채움, 흰색 8% 1px 테두리, 모서리 1.4u. 보내기 단추는 밝은 회색 원에 위쪽 화살표.
- 참조 카드: 사진 위 모서리 0.6u, 아주 옅은 그림자. 칩은 #333 알약에 1u 썸네일.
- 결과 액자: 모서리 1.4u, 그림자 없이 흐린 바탕과 대비로만 떠 보여요.

## 움직임
- 100BPM, 보통 속도. 들어오는 건 `power3.out`, 액자가 줄고 커지는 건 `inOutCubic` 으로 0.7~0.9초.
- 입력창 타이핑은 초당 25~30자. 참조 카드는 커서가 끌고 오는 대로 따라와 0.3초 스프링으로 놓이고, 칩으로 접힐 땐 0.4초에 크기와 위치가 함께 줄어요.
- 생각 로그는 한 단계에 1~1.5초. 칩 목록은 0.15초 간격으로 하나씩 붙고, 새 단계가 오면 목록이 0.5초에 위로 밀리며 흐려져요.
- 결과 영상은 장면마다 2~3초 머물러요. 화면 가득 1초 → 액자로 줄어 1초 → 다시 커지거나 다음 결과가 올라와요.

## 전환
- UI 막 안에서는 컷과 짧은 페이드. 입력창 화면에서 로그 화면으로 넘어갈 땐 입력창이 사라지고 로그가 0.3초 페이드로 떠요.
- 로그 → 결과는 컷으로 화면 가득. 결과끼리는 다음 영상이 아래에서 밀려 올라오는 push.
- 엔딩은 검은 화면으로 컷, 작은 마크가 페이드로 떴다가 옆으로 이름 글이 밀려 나와요.
- 장면 쌓기: cut → push → fade.

## 대표 장면

1. 입력창과 참조 카드 접기
   ```js
   // 입력창 가운데 고정, 글은 초당 28자로
   input.textContent = M.type(prompt, t, .3, 28);
   // 연두 이름표 커서가 카드 셋을 끌어옴
   const cur = new M.Cursor(S.$('.cursor'), {tag: '이름표'});
   cur.path([[0, W*.7, H*.2], [1.2, W*.55, H*.32], [2.6, W*.62, H*.36], [3.8, W*.66, H*.6]], t);
   cards.forEach((c, i) => {
     const k = M.spring(t - (1.2 + i*.25), 'smooth');           // 위로 놓임
     const f = M.ease.inOutCubic(M.prog(t, 3.2 + i*.08, .4));   // 칩으로 접힘
     M.box(c, M.lerpBox(cardBox[i], chipBox[i], f));
     c.style.opacity = k;
   });
   if (M.cursorAt(t, 4.2)) sendBtn.classList.add('pressed');
   ```
2. 생각 로그 세로 줄
   - `S.fx.spin(dot)` 로 작은 회전 표시와 '생각 중' 한 줄, 아래에 1px 세로 줄과 회색 점을 둬요.
   - 단계마다 `M.place(step, x, y, {o: M.prog(t, ti, .4)})` 로 흐린 회색에서 밝게. 칩은 `S.$$('.chip').forEach((c, j) => M.place(c, x, y + j*gap, {o: M.spring(t - ti - j*.15, 'smooth')}))`.
   - 새 단계가 오면 목록 묶음을 `M.anim([[0, 0], [tNext, -H*.18, {d: .5, e: 'outCubic'}]], t)` 로 위로 밀고 앞 단계 투명도를 .35 로.
3. 결과 영상 액자 숨쉬기
   ```js
   // 같은 영상 두 겹: 뒤는 크게 흐리고 밝게, 앞은 둥근 액자
   back.style.filter = 'blur(calc(var(--u)*4)) brightness(1.25) saturate(.7)';
   const s = M.anim([[0, 1], [1.0, .8, {d: .8, e: 'inOutCubic'}], [2.2, 1, {d: .8, e: 'inOutCubic'}]], t);
   const r = (1 - s) / .2;                       // 줄어들수록 모서리가 둥글게
   M.place(front, W/2, H/2, {s});
   front.style.borderRadius = `calc(var(--u) * ${1.4 * r})`;
   // 다음 결과는 아래에서 밀어 올림
   S.tr.push(cur, next, {dir: 'up', d: .6});
   ```
4. 검은 화면 마무리
   - 컷으로 #131313 바탕, 가운데 작은 마크를 `M.place(mark, cx, cy, {o: M.prog(t, 0, .4)})` 로 띄우고, 한 박 뒤 마크가 왼쪽으로 비키며 이름 글이 `clipPath: inset(0 X% 0 0)` 로 0.5초에 드러나요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 이미지·영상 생성 도구 소개, 프롬프트에서 결과까지 한 흐름 보여 주기, 협업 캔버스·참조 관리 기능, 제작 도구 런칭 티저.
- 피할 것: 밝은 흰 바탕 UI, 굵고 큰 제목, 강조색 여러 개(연두 하나만), 결과물 없이 UI만 이어지는 구성, 손그림·종이 질감.
- 결과 막이 이 결의 보상이에요. 앞의 UI 막을 조용하고 어둡게 둘수록 결과 영상이 화면 가득 뜰 때 크게 느껴져요.
