# 크레용 동화 (손그림)

한 줄: 크림색 도화지에 크레용으로 그린 동화책. 굵고 거친 선이 크게 꿈틀대고, 원색 동그라미와 통통 튀는 등장이 있어요.

## 보는 느낌
- 가운데 정렬. 글은 크고 짧게, 그림책 한 페이지처럼 한 장면에 한 마디.
- 바탕에 옅은 점 무늬. 카드는 오려 붙인 종이처럼 기울어 있어요.
- 해·구름·별 같은 크레용 낙서를 구석에 하나씩.

## 색
- 도화지 70 · 글자 18 · 원색 12.
- 도화지(#FFF6E3), 글자 보라빛 먹색(#2A2238).
- 강조는 주황빨강 크레용(#E4502F). 파랑(#3E8EDE)·노랑(#F7C843)·초록(#5DBB63)은 그림과 동그라미에 돌아가며 하나씩.

## 글자
- 개구(Gaegu) 굵게, 한글·영문 모두. 제목 짧은 변의 9~11%, 줄 간격 1.15.
- 숫자도 개구로 크게. 글자를 −2~2도 살짝 기울여도 좋아요.

## 질감과 모양
- 종이(cream) + 섬유 0.5 + 그레인 0.16(초당 6번)으로 크레용 결.
- 선 떨림 크게(1.6, 초당 6번, 무늬 0.022). 움직임도 초당 6장(stepped 6)으로 끊어 손으로 넘긴 그림책처럼.
- 모서리 둥글게(2.4u). 카드·막대는 손 테두리와 빗금.

## 움직임
- 108BPM, 밝게. 들어올 땐 back.out(1.8)로 통통 튀어요. 어절 간격 1.2배.
- 다 들어오면 살짝 기운 채 멈추고, 박마다 아주 작게 흔들려도 좋아요(S.fx.bob).

## 전환
- 밀어내기, 원형(iris), 컷. 원형은 마지막 장면이나 큰 숫자 앞에서 한 번.

## 대표 장면

1. 통통 튀는 제목
   ```
   S.fx.rise(S.words(ttl), T0 + .1, { stagger: .06 * 1.2, ease: 'back.out(1.8)' });
   tl.fromTo(ttl, { rotation: -4 }, { rotation: -1.5, duration: .5, ease: 'back.out(2)' }, T0 + .1);
   ```
2. 크레용 동그라미
   - 장면 쌓기는 marker: circle + rough 가 자동. 직접 짤 때는 M.rough('ellipse', {amp: 1.6}) 를 굵게(글자 높이의 12%), 장면마다 색을 바꿔요.
3. 오려 붙인 카드
   - 카드가 2도 기울어 위에서 떨어지듯 들어오고(back.out 1.8), 손 테두리가 그어진 뒤 안쪽이 빗금으로 채워져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 키즈 클래스·학원, 가족 행사, 동네 가게 이벤트, 캠페인·봉사 모집, 어린이날·방학 특강.
- 피할 것: 어두운 바탕, 가는 세리프, 정교한 데이터 표, 고급·럭셔리 무드.

## 배운 곳
- 직접 정리. 갤러리 영상에서 배운 게 아니고, 그림책·키즈 애니메이션에서 널리 쓰는 방식(크레용 결, 초당 6번 굵은 선 떨림, 원색 팔레트, 통통 튀는 등장)으로 정리했어요.
- 갤러리에서 배운 손그림 결은 따로 있어요: marker-scrawl-montage, chalk-math-board, doodle-faces-strikeout, manga-panel-bubbles, river-line-lettering, serif-marker-word, ink-gesture-blobs, navy-etching-plates.
