# 미색 다홍 번호표 안내 (제품 UI)

한 줄: 따뜻한 미색 바탕에 얇은 테라코타 테두리를 두른 앱 화면이 떠 있고, 다홍 동그라미 번호와 알약 띠가 누를 곳 바로 옆에 붙어 단계를 하나씩 짚어요. 카메라는 그 자리로 차분히 다가가요.

## 보는 느낌
- 바탕은 따뜻한 미색 한 가지예요. 무늬도 질감도 깔지 않고 넓게 비워 둬요.
- 여는 장면에서는 흐리게 기운 폰·앱 화면 서너 장이 깊이를 달리해 떠 있고, 그 사이 가운데에 짧은 문장 한 줄이 놓여요.
- 본 장면은 사용법을 따라가요. 화면 가득 앱 창 하나를 두고, 지금 할 일 옆에 다홍 번호표가 붙어요. 번호표가 있는 곳만 또렷하고 나머지 UI 는 그냥 배경처럼 조용해요.
- 앱 창은 얇은 테라코타 선으로 테두리를 둘러서 미색 바탕에서 살짝 떠 보여요.
- 끝에서 한 번만 따뜻한 빛이 드는 실내 사진을 깔고, 그 위에 유리 알약 낱말을 띄운 다음 다시 미색 판으로 돌아와 작은 글 한 줄과 마크로 닫아요.

## 색
- 미색 바탕 70 · 흰 UI 면 15 · 먹색 글자 10 · 다홍 5.
- 바탕 #ECE8E1, 글자 #24211D, 흐린 글 먹색 62%.
- 다홍 #CF3D1A 는 번호 동그라미, 단계 알약 띠, 문장 속 강조 알약, 마지막 결과 낱말에만 써요. 다홍 위 글씨는 늘 흰색.
- 앱 창 테두리는 옅은 테라코타 #E3A28F 1~1.5px. 회색 말풍선과 칸 구분은 #D9D4CC.

## 글자
- 산세리프 하나로 통일해요. 영문 Geist, 한글 Noto Sans KR Medium(굵은 곳만 Bold).
- 제목도 굵기 500 안팎으로 가볍게, 크기는 화면 높이의 5~6%. 자간 -0.02em, 가운데 정렬 한 줄.
- 강조 낱말은 같은 크기 그대로 다홍 알약에 담아요. 알약은 글자 높이의 1.5배, 좌우 여백 0.5em.
- 단계 알약 띠 글씨는 작게(화면 높이 2.2% 안팎), 흰색 500.
- 진행 카드는 굵은 제목 한 줄 + 아래 작은 흐린 상태 줄.

## 질감과 모양
- 질감 없이 매끈하게. 흐림은 깊이 표현에만 써요(뒤에 있는 폰 화면 3~6px).
- 카드·창 모서리 1.6u, 아주 옅고 넓은 그림자 하나.
- 번호 동그라미는 지름이 알약 띠 높이와 같고, 띠의 왼쪽 끝에 살짝 겹쳐 붙어요.
- 커서는 크고 검은 화살표(흰 외곽선). 손가락 모양은 쓰지 않아요.

## 움직임
- 96BPM, 보통 속도. 대부분 power3.out 으로 들어와 부드럽게 멈춰요.
- 번호 동그라미는 0 → 1.08 → 1 로 톡 커지고(0.3초), 이어 알약 띠가 왼쪽부터 펼쳐지며 글씨가 함께 드러나요(0.35초).
- 카메라는 한 단계에 한 번만 움직여요. 앱 창 전체에서 누를 곳으로 1.2배~1.8배 다가가는 데 0.8~1초, 다가간 채 1.5~2초 머물러요.
- 커서는 곡선을 그리며 1초 안쪽으로 이동하고, 누를 때 0.9배로 살짝 줄었다 돌아와요.
- 떠 있는 폰 화면들은 4~6초 주기로 아주 조금씩 오르내려요.
- 진행 카드의 상태 줄은 1.2초마다 위로 굴러 다음 줄로 바뀌어요.

## 전환
- 흐림 전환(blur)이 기본이고, 단계와 단계 사이는 컷, 끝 장면은 서서히(fade).
- 장면 쌓기: blur → cut → fade.
- 번호표 띠는 장면이 바뀔 때 같이 사라지지 않고, 다음 단계 자리로 미끄러져 옮겨 붙으면 이어지는 느낌이 나요.

## 대표 장면

1. 알약 낱말 한 줄과 떠 있는 화면들
   ```js
   // 뒤: 흐린 폰 화면 4장, 깊이마다 흐림·크기 다르게
   S.ambient(t => phones.forEach((p, i) =>
     M.place(p, p.x0, p.y0 + Math.sin(t * .3 + i) * U * .6,
       { s: p.s, r: p.r, blur: p.depth * 4 })));
   // 앞: 문장은 어절마다 올라오고, 강조 낱말 알약은 늦게 펼쳐짐
   const k = M.ease.outCubic(M.prog(t, t0 + .4, .35));
   pill.style.clipPath = `inset(0 ${(1 - k) * 100}% 0 0 round 99px)`;
   ```
   - 장면 쌓기에서는 marker: highlight 가 강조 낱말을 다홍 알약으로 칠해요.

2. 단계 번호표가 UI 에 붙기
   ```js
   // 번호 동그라미 톡, 띠 펼침, 단계마다 자리 옮김
   const pos = M.at([[0, step1], [tB, step2], [tB * 2, step3]], t);
   M.place(badge, pos.x, pos.y, { s: M.spring(t - pos.t, 'bouncy') });
   badge.textContent = M.at([[0, '1'], [tB, '2'], [tB * 2, '3']], t);
   M.box(band, { x: pos.x, y: pos.y - h / 2, h,
     w: bandW * M.ease.outCubic(M.prog(t, pos.t + .25, .35)) });
   ```

3. 테두리 앱 창으로 다가가 누르기
   ```js
   // 창 전체 → 버튼으로 다가감, 커서가 와서 누름
   const z = M.anim([[0, 1], [t1, 1.6, { d: .9, e: 'inOutCubic' }]], t);
   M.place(win, cx - (btn.x - cx) * (z - 1), cy - (btn.y - cy) * (z - 1), { s: z });
   const cur = new M.Cursor(cursorEl, [[t1, start], [t1 + .8, btn, 'click']]);
   cur.at(t);
   ```
   - 장면 쌓기에서는 frame: window + deco: cursor 로 앱 창과 누르는 커서가 따라와요. 창 테두리는 `outline: 1.5px solid #E3A28F`.

4. 진행 카드와 사진 위 마무리
   - 흰 둥근 카드 가운데 제목은 그대로 두고, 아래 상태 줄 서너 개를 `M.at` 으로 1.2초마다 골라 y 를 위로 0.3초 굴려 바꿔요. 다 끝나면 `S.tr.blur` 로 결과 앱 창으로 넘어가요.
   - 마지막엔 따뜻한 실내 사진을 깔고 노트북·폰 화면을 얹은 뒤, 위에 유리 알약 두 개(흰 15% + 블러)와 다홍 알약 하나를 0.15초 간격으로 왼쪽부터 톡톡 띄워요. 이어 fade 로 미색 판, 작은 글 한 줄, 마크.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 가져오기·옮기기 사용법, 새 기능 따라 하기, 온보딩 단계 설명, 웹에서 앱으로 넓히는 소개, 고객 지원 도움말.
- 피할 것: 어두운 바탕을 길게 쓰기, 다홍 말고 다른 강조색, 빠른 컷 몽타주, 굵고 큰 제목으로 화면 채우기, 번호표 없이 UI 만 늘어놓기(번호표가 이 결의 중심이에요).
- 한 화면에 번호표는 하나만. 단계가 바뀌면 앞 번호표는 옮겨 가거나 사라져요.
