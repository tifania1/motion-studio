# 알약 낱말 띠와 검은 커서 (제품 UI)

한 줄: 옅은 회색 위에 아이콘 하나가 알약 칩으로 오므라들고, 문장이 그 알약 안을 낱말씩 흘러 지나가요. 알약은 검은 버튼으로 뒤집히고, 큰 검은 화살 커서가 그 버튼을 눌러 입력창과 바랜 앱 화면으로 이끄는 조용한 기능 소개예요.

## 보는 느낌
- 무늬 없는 옅은 회색 바탕에 한 번에 하나만 놓아요. 아이콘 하나, 알약 하나, 버튼 하나. 화면의 80% 이상이 늘 비어 있어요.
- 앞부분은 화면 한가운데의 알약 칩 하나가 주인공이에요. 아이콘이 칩이 되고, 칩 속을 문장이 흘러가고, 칩이 버튼이 되고, 버튼이 입력창이 돼요. 한 물건이 계속 몸을 바꾸며 이야기를 이어 가요.
- 앱 화면은 바탕과 거의 같은 회색으로 반쯤 바래 깔려요. 사이드바와 패널 윤곽만 겨우 보이고, 지금 다루는 버튼이나 입력창만 또렷해요.
- 큰 검은 화살 커서가 안내자예요. 늘 화면 안에 있다가 다음에 누를 곳으로 미리 옮겨 가요.

## 색
- 바탕 회색 #ECECEC 80 · 먹색 글자와 검은 버튼 17 · 초록 3.
- 먹색 #161616 은 글자, 커서, 버튼 바탕에 써요. 패널은 한 단 밝은 #F7F7F6, 알약 테두리와 바랜 UI 선은 #BDBDBD.
- 초록 #2FCB7E 은 검은 버튼 속 선 아이콘, 막 들어온 낱말 첫 글자, 바뀐 곳 표시 같은 아주 작은 자리에만 써요. 넓게 칠하지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium) 500, 자간 -0.015em. 둥글고 담백한 그로테스크.
- 알약 속 낱말은 짧은 변의 9~11%로 크게, 한 화면에 한 낱말만. 문장은 낱말 단위로 끊어 흘려요.
- 버튼 글자는 흰색 500, 짧은 변의 5% 안팎. 앱 화면 속 글은 아주 작게(2~2.5%) 두어 읽히기보다 분위기로 보여요.
- 가운데 정렬. 앱 패널 안에서만 왼쪽 정렬이에요.

## 질감과 모양
- 질감 없이 매끈하게. 그레인, 비네트, 빛 번짐 모두 쓰지 않아요.
- 알약: 완전히 둥근 끝, 옅은 회색 1.5px 테두리, 안은 바탕보다 아주 조금 밝게. 그림자는 없어요.
- 검은 버튼: 먹색 바탕 알약, 왼쪽에 초록 동그라미 선 아이콘.
- 입력창·패널: 모서리 1.6u, 1px 옅은 테두리, 그림자 거의 없음.
- 커서: 짧은 변의 6~7%로 큼직한 채운 검은 화살, 살짝 돌아가 있어요.

## 움직임
- 120BPM, 조용한 보통 빠르기. 낱말은 2박(1초)마다 하나씩 지나가요.
- 들어올 때는 power3.out 으로 미끄러져 와 멈추고, 나갈 때는 power3.in 으로 같은 방향으로 빠져요. 알약 폭은 낱말이 바뀌는 동안 같은 곡선으로 늘고 줄어요.
- 아이콘 등장은 살짝 튀는 back.out, 변신(알약 → 버튼 → 입력창)은 0.5초 inOutCubic.
- 커서는 다음 목표로 0.6~0.8초에 부드럽게 휘어 가고, 누를 때 0.1초 작아졌다 돌아와요. 누른 버튼도 함께 살짝 눌려요.
- 앱 화면에서는 한 장면에 1.5~2초 머물러요. 글은 초당 20자 안팎으로 쳐져요.

## 전환
- 대부분 전환 없이 한 물건이 변신하며 이어가요(같은 자리 맞춤 컷).
- 앱 패널은 옆에서 밀려 들어오고(push), 앱 화면에서 빈 회색 마무리로 갈 때는 짧은 흐림(blur)이나 컷.
- 장면 쌓기: cut → push → blur.

## 대표 장면

1. 아이콘이 알약 칩이 되기 (0.9–2.4초)
   ```
   const s = M.anim([[0, 0], [.9, 1, {d: .4, e: 'outBack'}], [1.6, .3, {d: .5, e: 'inOutCubic'}]], t);
   const ix = M.anim([[0, cx], [1.6, cx - pillW * .36, {d: .5, e: 'inOutCubic'}]], t);
   M.place(icon, ix, cy, {s});
   const w = M.anim([[0, 0], [1.7, pillW, {d: .5, e: 'outCubic'}]], t);
   M.box(pill, {x: cx - w / 2, y: cy - pillH / 2, w, h: pillH});   // overflow: hidden, 둥근 끝
   M.place(word0, cx + pillW * .1, cy, {o: M.prog(t, 1.9, .3)});
   ```
2. 알약 속을 흘러가는 낱말 띠 (2.6–6.0초)
   ```
   words.forEach((el, i) => {
     const ti = 2.6 + i * M.beat(2);
     const x = M.anim([[0, cx + pillW], [ti, cx, {d: .35, e: 'outCubic'}], [ti + M.beat(2) - .35, cx - pillW, {d: .35, e: 'inCubic'}]], t);
     M.place(el, x, cy);
     el.firstChild.style.color = M.color('#2FCB7E', '#161616', M.prog(t, ti + .2, .4));
   });
   // 알약 폭은 지금 낱말 너비 + 여백을 따라 M.anim 으로 늘고 줄어요
   ```
   장면 쌓기에서는 title: slot + deco cursor 로 낱말이 한 자리에서 갈려 드는 결을 내요.
3. 검은 버튼 → 입력창 → 보내기 (6.3–8.9초)
   ```
   const cur = new M.Cursor(S.$('.cursor'));
   const press = M.cursorAt(cur, t, [[6.3, btnX, btnY - 8 * u], [7.0, btnX, btnY, {click: true}]]);
   const k = M.ease.inOutCubic(M.prog(t, 7.1, .5));
   M.box(btn, {x: M.mix(btnX0, inX, k), y: btnY - M.mix(btnH, inH, k) / 2, w: M.mix(btnW, inW, k), h: M.mix(btnH, inH, k)});
   btn.style.background = M.color('#161616', '#F7F7F6', k);
   field.textContent = M.type(prompt, t, 7.7, 20);
   ```
   바랜 앱 화면(사이드바 선, 패널 윤곽)은 처음부터 opacity .35 로 깔아 두고 버튼만 또렷하게.
4. 채팅 패널과 마무리 (9.4–18.1초)
   - S.tr.push 로 채팅 패널을 오른쪽에서 밀어 넣고, 단계 목록 4줄을 한 박씩 옅게 켠 뒤 답 문장을 M.type 으로. 검은 작은 버튼 둘이 뜨면 커서가 왼쪽 버튼을 눌러요.
   - S.tr.blur 로 빈 회색에 넘어가 검은 알약 버튼 하나와 커서. 다음 컷에 마크를 가운데 두고 커서가 오른쪽 아래에서 와서 마크 끝에 멈춘 채 1.5초 머물다 커서만 사라져요.
