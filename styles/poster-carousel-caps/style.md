# 포스터 판 넘기기 (타이포)

한 줄: 밝은 회색 작업판 위에 원색 포스터들이 한 줄로 서 있고, 박자마다 옆으로 한 칸씩 넘어가요. 판마다 굵은 대문자 글자가 다른 방식으로 들어와요.

## 보는 느낌
- 디자인 도구의 작업판을 위에서 내려다본 화면. 밝은 회색 바탕 위에 포스터 판(세로형·가로형 섞임)이 가로로 늘어서 있어요.
- 가운데 판이 주인공이고, 양옆 판은 화면 가장자리에 반쯤 걸쳐 다음 장면을 미리 보여 줘요.
- 판 하나 = 메시지 하나. 판 안은 굵은 대문자가 꽉 차서 포스터처럼 보여요.

## 색
- 작업판 회색 #E3E3E5 40 · 포스터 바탕색 45 · 글자 15.
- 포스터 바탕은 판마다 다르게: 빨강 #E1361F(검정 글자), 형광 연두 #5DF04A(검정 글자), 하늘 #4FA6EE(흰 글자), 국방 #6F6B4E(노랑 #EDE53A 글자), 검정 #121212(흰 글자), 베이지 #E2D6BF(검정 글자).
- 선택선·손잡이·끝 버튼은 보라 #8B6CF0. 이 보라는 도구 표시에만 쓰고 포스터 안에는 쓰지 않아요.

## 글자
- 굵은 그로테스크 대문자: Archivo 800~900(가로 폭 100~110%) + 한글 Noto Sans KR Black.
- 줄 간격 0.88, 자간 −0.03em. 판 폭의 85%까지 꽉 채우게 `S.fit`.
- 한 판에 2~4줄. 작은 정보 줄(날짜·장소)은 같은 글꼴 500으로 아주 작게 판 아래쪽에.
- 영문은 대문자. 한글은 짧게 끊어 줄마다 한두 어절.

## 질감과 모양
- 질감 없음. 판 모서리는 거의 각지게(0.4u), 판 아래 아주 옅은 그림자.
- 선택선 1px 보라, 모서리 손잡이는 0.8u 흰 정사각형 + 보라 테두리. 판 위 이름표는 1.4u 회색 작은 글씨.
- 사진을 쓰는 판은 사진 위에 흰 대문자를 겹치고, 글과 사진 사이에 어떤 상자도 두지 않아요.

## 움직임
- 120BPM, 빠름. 판 넘기기는 두 박(1초)마다, 0.45초 expo.out.
- 판이 가운데 오자마자 0.1초 뒤 글자 등장이 시작돼 0.5~0.7초 안에 끝나요. 나머지 시간은 가만히.
- 글자 등장 네 가지를 판마다 돌려 써요(아래 대표 장면 2).

## 전환
- 밀기(push)가 기본: 줄 전체가 옆으로 한 칸. 카메라를 움직이지 않고 줄이 움직여요.
- 끝 장면으로 갈 때만 컷(검은 화면).

## 대표 장면

1. **포스터 줄 넘기기**
   ```
   // row: 판들을 가로로 나란히(gap = 판폭/3). i 번째 판이 가운데 오게
   const step = M.anim(boards.map((_, i) => [t0 + i * M.beat(2), i, { d: .45, e: 'outExpo' }]), t);
   row.style.transform = `translateX(${W/2 - (step * (bw + gap) + bw/2)}px)`;
   // 선택선: 가장 가까운 판에만. 손잡이 네 개는 판 모서리에 M.place
   sel.style.opacity = Math.abs(step - Math.round(step)) < .15 ? 1 : 0;
   ```
2. **판마다 다른 글자 등장** (`S.chars` 로 쪼갠 뒤)
   - 떨어지며 좁혀짐: 글자마다 y −1.2em → 0, 자간 .4em → −.03em, 0.06초 간격.
   - 뒤집혀 돌아옴: `rotateX(180deg)` → 0, 투명도 .2 → 1, 글자 순서를 섞어(시드 난수) 0.04초 간격.
   - 흐림에서 선명: 글자마다 `blur(10px)`·x +0.3em → 0, 왼쪽부터 0.05초 간격(장면 쌓기 `title: mask` 와 섞어 써도 좋아요).
   - 잘린 조각: 줄을 위·아래 반으로 `clip-path` 나눈 복제 둘을 서로 반대로 0.2em 어긋냈다 0.4초에 맞춤.
3. **검은 끝 장면과 버튼**
   - 컷으로 검은 화면 → 굵은 흰 두 줄이 `M.rise` 로 줄마다 올라옴 → 짧은 한 마디로 바뀜 → 보라 알약이 `M.spring('pop')` 으로 커짐 → `M.Cursor` 가 아래에서 올라와 누름(누를 때 버튼 0.96배).

## 어울리는 곳 / 피할 것
- 어울리는 곳: 행사·팝업 스토어 안내, 신상품·컬렉션 여러 개 소개, 이번 주 일정·라인업, 포스터를 여러 장 쓰는 캠페인.
- 피할 것: 세리프 글꼴, 가는 글씨, 판 하나에 글 네 줄 넘게, 부드러운 그라디언트 바탕. 실제 브랜드 포스터를 따라 만들지 않아요.
