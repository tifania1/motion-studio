# 가장자리 골동품 진열 (3D·사물)

한 줄: 옅은 회색 바탕 한가운데 작은 책 세리프 몇 줄. 오래된 물건 사진이 아래에서 솟아 문장을 양쪽으로 갈라놓거나, 화면 테두리를 따라 진열장처럼 둘러서요.

## 보는 느낌
- 화면 대부분이 비어 있어요. 글은 가운데에 작게(짧은 변의 3.5~4.5%), 한두 줄.
- 소품은 두 가지 쓰임만 있어요.
  - 주인공 하나: 화면 가운데 아래쪽, 글 바로 밑이나 문장 사이. 화면 높이의 40~50%.
  - 테두리 진열: 화면 가장자리를 따라 10~12개. 각각 화면 높이의 8~18%로 크기를 섞고, 가운데 45%는 비워 둬요.
- 소품끼리 겹치지 않고, 글과도 겹치지 않아요. 서로 사이가 비슷하게 벌어져 있어서 진열장 칸에 놓인 것처럼 보여요.
- 소품만 색이 있고 나머지는 회색과 먹색뿐이라, 소품이 나오는 순간 화면이 확 따뜻해져요.

## 색
- 바탕 88 · 글 4 · 소품 8(테두리 진열 장면은 소품 20).
- 바탕 옅은 회색 #ECEBE8, 글 먹색 #1F1E1C, 막 들어온 글은 회색(먹색 55%).
- 소품 색은 사진 그대로: 나무 갈색, 놋쇠, 누런 종이, 자수정 보라, 시약 연두 같은 바랜 색. 채도 높은 원색 소품은 피해요.
- 강조는 색보다 기울임 세리프로. 꼭 색이 필요하면 짙은 고동(#8A5A2B) 한 낱말.

## 글자
- 영문 세리프 Instrument Serif(기울임 포함), 한글 고운바탕 400. 굵게 쓰지 않아요.
- 문장 두 줄 가운데 정렬, 줄 간격 1.25. 갈라진 문장은 기울임으로.
- 작은 꼬리표(위의 '…에서:' 같은 말)는 같은 글꼴 회색, 본문의 55% 크기.
- 아이콘 아래 이름은 본문의 50%, 아이콘은 1.5px 선 아이콘(먹색).

## 질감과 모양 (소품 사진의 배치·조명·리듬)
- 바탕에는 질감 없음. 질감은 소품 사진 안에만 있어요(오래된 인쇄물, 판화, 바랜 사진).
- 조명: 모든 소품이 왼쪽 위에서 오는 따뜻한 빛 하나를 받은 것처럼 고르고, 그림자는 소품 바로 밑 접지 그림자 하나만. 소품마다 빛 방향이 다르면 진열장이 흐트러져 보여요.
- 테두리 진열의 기울기는 −10°~10°, 이웃끼리 같은 방향으로 기울지 않게.
- 주인공 소품은 정면에 가깝게 반듯이, 탁자·받침 같은 바닥면이 살짝 보이는 눈높이.

## 3D 소품을 우리 엔진에서 만드는 법
- 사진(기본): 배경을 지운 투명 PNG. 순서는 사용자가 준 제품·소품 사진 → 박물관 공개 자료(CC0·퍼블릭 도메인, tools/photo.py 로 위키미디어에서) → ChatGPT 웹에서 고화질로 만든 '오래된 판화·사진풍 사물' 이미지. tools/cutout.py 로 배경을 지우고 photo.py add 로 넣어요.
- 톤 맞추기: 출처가 섞이면 모두에 filter: sepia(.25) saturate(.85) contrast(1.05) 를 걸어 바랜 톤을 맞춰요.
- 접지 그림자: 소품 아래에 같은 폭 70%의 납작한 타원 div(radial-gradient(rgba(60,40,20,.22), transparent 70%), 높이 1.2u) 를 따로 두고, 소품이 솟아오를 때 그림자는 제자리에서 진해지기만 해요.
- 사진이 없을 때(CSS 대체): 둥근 사각(모서리 0.6u) 카드에 연한 종이색(#F6F3EC)과 접지 그림자, 안에 1.5px 선 아이콘. 대신 크기·기울기·테두리 배치 규칙은 그대로 지켜야 이 결이 남아요.

## 움직임
- 88BPM, 한 박에 한 가지. 느리고 단정하게.
- 글은 회색으로 0.2초에 나타났다가 0.3초 뒤 먹색으로(power2.out). 위치 이동 없이 제자리.
- 주인공 소품은 화면 아래 밖에서 0.3초에 솟아오름(M.spring 'snappy', 넘침 아주 조금). 나갈 땐 0.25초에 아래로(inCubic).
- 테두리 진열: 각 소품이 가장 가까운 화면 가장자리 바깥에서 들어옴. 0.06초 간격, 0.35초씩, 넘침 없음. 들어온 뒤에는 움직이지 않아요(떠다니게 하지 않음).
- 글 블록이 위로 밀릴 때는 M.spring 'smooth'.

## 전환
- 대부분 컷. 장면이 바뀔 때 화면이 한 박 비었다가(바탕만) 다음 글이 나와요.
- 마지막 주소·로고는 0.3초 페이드.

## 대표 장면

1. 솟아올라 가르기
   ```
   // 글 블록 txt, 소품 prop(투명 PNG), 접지 그림자 sh
   const up = M.spring(t - tProp, 'snappy');
   M.place(prop, S.W / 2, M.lerp(S.H + propH / 2, S.H * .62, up), {ay: .5});
   txt.style.transform = `translateY(${-M.spring(t - tProp, 'smooth') * S.H * .09}px)`;   // 글이 위로 밀림
   // tSplit 에 글을 끄고, 기울임 문장을 두 조각으로: left 는 오른쪽 끝을 소품 왼쪽 4u 앞에, right 는 반대
   S.fx.fade(left, tSplit, {d: .2}); S.fx.fade(right, tSplit + M.beat(.5), {d: .2});
   // tOut 에 소품만 아래로: y += M.ease.inCubic(M.prog(t, tOut, .25)) * S.H * .6
   ```
2. 테두리 진열장
   ```
   // 자리표: 화면 둘레를 12칸으로 나눈 점(가운데 45% 직사각형 바깥). 칸마다 크기·기울기는 시드 난수 M.rng(3)
   slots.forEach((p, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + i * .06, .35));
     const [fx, fy] = p.edgeOut;                       // 가장 가까운 가장자리 바깥 좌표
     M.place(p.el, M.lerp(fx, p.x, k), M.lerp(fy, p.y, k), {rot: p.rot, s: p.s});
   });
   ```
   - 진열이 다 선 다음 박부터는 화면이 멈춰 있어도 괜찮아요. 가운데 글만 다음 일을 해요.
3. 아이콘 줄이 하나씩
   ```
   // 항목 n 개, 폭 w, 간격 g. 지금까지 붙은 개수 m(t) = M.anim([[t0,1],[t0+b,2],…], t) (spec {d:.25})
   items.forEach((it, i) => it.style.transform = `translateX(${(i - (m - 1) / 2) * (w + g)}px)`);
   // 새 항목 opacity = M.prog(t, ti, .2), color = M.color('#8F8E8B', '#1F1E1C', M.prog(t, ti + .3, .3))
   ```
4. 회색 글자 채우기(주소·마무리)
   - 앞부분만 먹색으로 쓰고 나머지는 회색으로 먼저 보여 준 뒤, 0.15초마다 한 덩어리씩 먹색이 됨. 커서는 그리지 않아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 기술·연구 발표, 보고서·지표 공개, 박물관·전시·고서점, 빈티지·앤티크 숍, 차분한 기업 소개.
- 피할 것: 굵은 고딕 큰 제목, 원색 바탕, 빠른 컷 연타, 반들반들한 만화풍 3D 소품, 소품을 글 위에 겹치기. 영상에 나온 소품을 그대로 따라 만들지 않아요. 배치(테두리·가운데 아래), 한 방향 조명, 한 박에 하나씩 붙는 리듬만 가져와요.
