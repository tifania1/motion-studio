# 카드 고리와 허브 (제품 UI)

한 줄: 옅은 회색 위에서 크기와 색이 제각각인 UI 카드들이 고리를 이뤄 돌고, 가운데 이름이 박자마다 갈려요. 끝에는 카드들이 흩어져 유리빛 허브 카드 둘레에 가는 선으로 이어져요.

## 보는 느낌
- 바탕은 거의 무늬 없는 옅은 회색 하나. 그 위에 카드들이 떠 있고, 글은 작고 가볍게 한두 마디만.
- 주인공은 카드 무리예요. 어두운 카드, 사진 카드, 보라·빨강·주황 카드가 섞여 있어서 한 장 한 장보다 '많이 있다'는 느낌이 먼저 와요.
- 고리 장면은 화면 가운데 지름이 화면 높이의 70% 남짓. 가운데는 비워 두고 작은 이름 한 줄만 둬요.
- 사이사이 숨 고르는 장면: 디자인 시스템 판(글꼴 견본, 버튼 줄, 색 단계)을 바짝 붙어 훑거나, 사진 위에 둥근 위젯 하나를 띄우거나, 빈 회색 화면에 낱말 몇 개만 놓아요.
- 끝은 허브. 가운데 유리빛 하늘색 카드가 있고, 둘레 위성 카드들이 가는 회색 선으로 이어진 별자리 같은 그림이에요.

## 색
- 회색 바탕 70 · 카드들 25 · 글자 5.
- 바탕 #E6E6E4, 글자 #1C1C1E. 흐린 설명은 같은 먹색 60%.
- 카드 속 색은 넓게 써도 돼요: 남보라 #5B5BD6(버튼·강조), 보라 #8A5CF6(빛 번지는 카드), 빨강 #C8242E(포스터·달력 카드), 허브의 하늘색 #BFD7F2.
- 바탕에 깔린 글자에는 색을 넣지 않아요. 색은 카드 안에서만 살아요.

## 글자
- 산세리프 하나(Geist, 한글은 Noto Sans KR Medium). 제목 굵기 500, 자간 −0.02em.
- 고리 가운데 이름은 짧은 변의 4% 안팎으로 작게. 여는 제목만 짧은 변의 9% 정도, 왼쪽 정렬 두 줄.
- 빈 화면 문장은 짧은 변의 3.5%. 낱말이 한 번에 하나씩 놓이고, 문장이 다 놓이면 가운데로 모여요.
- 카드 안 글은 실제 UI 처럼 작고 촘촘하게(숫자, 날짜, 버튼 글씨).

## 질감과 모양
- 질감은 쓰지 않아요. 매끈한 화면.
- 카드: 모서리 `--u` × 1.6, 아래로 길고 옅은 그림자 한 겹(먹색 12%). 밝은 카드는 1px 흰 테두리.
- 허브 카드: 하늘색에서 흰빛으로 흐르는 그라디언트 + 반투명 유리 느낌, 테두리 흰색 60%.
- 연결선: 1px 회색(먹색 35%), 끝에 점 없이 카드 가장자리에 바로 닿아요.

## 움직임
- 100BPM, 보통 빠르기. 큰 움직임은 `power3.inOut` 로 부드럽게 떠나 부드럽게 멈춰요.
- 고리는 2박마다 30도씩 돌고 사이에는 아주 천천히(초당 2도) 흘러요. 카드마다 깊이(크기 0.85~1.1)를 달리해 3D 처럼 보이게.
- 카드가 나타날 때는 가운데에서 바깥으로 튕겨 나오며 0.04초씩 엇갈려요(스프링 'smooth').
- 가운데 이름은 흐림 6px → 0 으로 0.4초에 맺히고, 바뀔 땐 흐림으로 빠져요.
- 디자인 시스템 판은 4초 동안 화면 너비의 15%만큼 옆으로 미끄러지며 살짝 다가가요.

## 전환
- 컷이 기본. 숨 고르는 장면 사이엔 흐림(blur), 같은 무리의 카드가 옆으로 넘어갈 땐 밀어내기(push).
- 카드 한 장이 가운데 작은 타일로 오므라들어 다음 장면의 씨앗이 되는 이음을 한 번 넣어요.
- 장면 쌓기: cut → blur → push.

## 대표 장면

1. **도는 카드 고리와 바뀌는 이름**
   ```
   const cards = S.$$('.ring .card');            // 10~12장, 색·크기 제각각
   const names = S.$$('.ring .name');            // 가운데 이름 3~4개를 겹쳐 둠
   const R = Math.min(W, H) * .34;
   S.ambient(t => {
     const spin = M.anim([[0, 0], [M.beat(2), -30, {d: .9, e: 'inOutCubic'}],
                          [M.beat(4), -60, {d: .9, e: 'inOutCubic'}]], t) - t * 2;
     cards.forEach((c, i) => {
       const a = (i / cards.length * 360 + spin) * Math.PI / 180;
       const k = M.spring(t - i * .04, 'smooth');
       const depth = .85 + .25 * (Math.sin(a) * .5 + .5);
       M.place(c, cx + Math.cos(a) * R * k, cy + Math.sin(a) * R * .9 * k, {s: depth * k, r: Math.cos(a) * 3});
     });
     const n = M.at([[0, 0], [M.beat(2), 1], [M.beat(4), 2]], t);
     names.forEach((el, j) => {
       const v = j === n ? M.ease.outCubic(M.prog(t, M.beat(2 * j), .4)) : 0;
       M.place(el, cx, cy, {o: v, blur: (1 - v) * 6});
     });
   });
   ```
   - 박이 바뀔 때 고리 뒤쪽(작게 보이는 쪽) 카드 2~3장만 새 카드로 갈아 끼우면 무리가 계속 바뀌는 느낌이 나요.
2. **카드가 씨앗으로 오므라들고 고리가 피어남**
   - 앞 장면의 큰 카드를 `M.place(card, cx, cy, {s: M.anim([[0, 1], [.6, .14, {d: .8, e: 'inOutQuart'}]], t)})` 로 가운데 작은 타일까지 줄이고 반 박 머물게 해요.
   - 그 타일이 고리의 첫 카드가 되고, 1번 장면의 `k` 스프링을 타일이 멈춘 시각부터 시작해 나머지 카드가 튕겨 나와요.
3. **디자인 시스템 판 훑기**
   - 글꼴 견본(큰 'Aa'), 남보라 버튼 줄, 색 단계 막대를 둥근 판 위에 짜 두고 판 전체를 `M.place(board, cx - M.anim([[0, 0], [4, W * .15, {d: 4, e: 'inOutSine'}]], t), cy, {s: 1 + t * .02})` 로 천천히 밀어요.
   - 버튼 줄은 0.06초씩 엇갈려 위에서 2u 내려앉고, 점선 상자(구역 표시)는 `M.draw` 로 그어져요.
4. **허브와 위성 카드**
   ```
   const sats = S.$$('.hub .sat'), lines = S.$$('.hub path');
   S.ambient(t => {
     M.place(hub, cx, cy, {s: .9 + .1 * M.spring(t, 'smooth')});
     lines.forEach((ln, i) => M.draw(ln, M.ease.outCubic(M.prog(t, .3 + i * .06, .5))));
     sats.forEach((s, i) => {
       const k = M.spring(t - .4 - i * .06, 'smooth');
       const [x, y] = spots[i];                     // 허브 둘레 흩어진 자리, 깊이마다 크기 다르게
       M.place(s, x + Math.sin(t * .4 + i) * 6, y + Math.cos(t * .35 + i) * 6, {o: k, s: (.8 + i % 3 * .12) * k});
     });
   });
   ```
   - 선 끝 좌표도 위성 카드의 흔들림을 따라 매 프레임 다시 계산해서 선이 늘 카드 가장자리에 닿게 해요.
5. **빈 회색 위 낱말 문장**
   - 바탕만 남긴 채 낱말을 `M.at` 으로 한 박마다 하나씩 보여 주고, 마지막 박에 모든 낱말이 한 줄로 모여 맺혀요. 장면 쌓기에서는 title: blur 가 이 결을 따라가요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 템플릿·에셋 묶음 소개, 디자인 시스템·컴포넌트 공개, 여러 기능을 한 제품으로 묶어 보여 줄 때, 플랫폼 연동·통합 런칭.
- 피할 것: 어두운 바탕 전체, 굵고 큰 제목, 거친 질감·손그림 선, 빠른 컷 몽타주, 카드 하나만 덩그러니 오래 두기(무리가 있어야 이 결이 살아요).
