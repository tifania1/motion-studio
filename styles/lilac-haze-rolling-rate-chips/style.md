# 연보라 안개 숫자 굴림 (제품 UI)

한 줄: 위아래로 연보라가 번지는 옅은 안개 바탕에 중간 굵기 보라 글씨가 어절마다 슬롯처럼 올라오고, 큰 퍼센트 숫자는 자리마다 굴러 멈춘 뒤 막대 위에 올라앉아요. 아이콘 줄은 하나에서 멈췄다 화면 가득 흩어지고, 점선 가지 끝에 칩이 달리는 차분한 금융 설명 필름이에요.

## 보는 느낌
- 바탕은 거의 흰 회보라(#E9E8EE)에서 아래로 갈수록 연보라(#DCD7EE)가 안개처럼 번지는 세로 그라디언트 하나. 무늬도 질감도 없이 매끈해요.
- 한 화면에 말 한 줄(많아야 두 줄)을 가운데 두고, 그 둘레나 아래에 소품 하나만 붙여요: 큰 숫자, 막대 두 개, 원형 아이콘 줄, 흰 카드와 점선 가지, 세로 낱말 목록, 폰 한 대.
- 여백이 넉넉해요. 글과 소품을 합쳐도 화면의 40% 안쪽.
- 문장 사이 낱말 자리에 작은 아이콘(반짝이, 퍼센트, 플러그)이 글자 높이로 끼어들어 말을 그림으로 이어 줘요.

## 색
- 안개 바탕 75 · 보라 글자 15 · 회색 설명 6 · 진보라 칩·막대 4.
- 큰 제목과 숫자는 연보라 #9A86EC(아주 큰 글자에만), 읽어야 하는 문장은 진한 보라 #5B45C9.
- 설명 글씨는 회보라 회색 #8C8A99, 작고 가볍게.
- 막대는 #8E90F2(푸른 보라) → #9A86EC 세로 그라디언트, 다른 하나는 #B49AF0 한 색. 칩은 진보라 #6E56E0 바탕에 흰 글씨.
- 흰 카드 #F7F6FA, 아이콘 줄은 처음엔 회색 40%, 고른 것만 제 색.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 둥근 기하 산세리프, 제목 굵기 500~600, 자간 -0.02em.
- 크기 대비가 커요: 퍼센트 숫자는 짧은 변의 22~26%, 제목은 7~8%, 설명은 3% 안팎.
- 가운데 정렬 두 줄이 기본. 폰이 나오는 장면만 폰 옆에 왼쪽 정렬.
- 줄 간격 1.15로 바짝. 꼬리표·칩 글씨는 2.2% 크기 500.

## 질감과 모양
- 질감은 쓰지 않아요. 그레인·비네트 없이 깨끗한 화면.
- 카드: 거의 흰색, 모서리 1.6u, 그림자 없이 바탕과 살짝만 구분.
- 칩·꼬리표: 완전한 알약. 선택 표시는 1.5px 보라 알약 테두리.
- 막대: 위 모서리만 둥글게(1u), 아래는 화면 밖으로 이어짐.
- 점선: 2px 회보라 점선, 직각으로 꺾이는 가지.
- 물결 밑줄: 끝이 둥근 2px 보라 선, 손으로 한 번 그은 듯 살짝 출렁여요.

## 움직임
- 96BPM, 보통 속도. 장면 하나가 2~3초 머물러요.
- 들어올 땐 `power3.out` 으로 부드럽게 멈춰요. 어절은 아래에서 1.5u 올라오며 옅은 색에서 제 색으로 0.4초, 어절 사이 0.08초.
- 숫자는 자리마다 세로 띠가 굴러가 멈추는 방식. 값이 바뀔 땐 바뀐 자리만 다시 굴러요.
- 나갈 땐 글이 옅어지며 위로 조금 빠지고, 소품은 화면 밖으로 밀려나요(폰은 위로, 아이콘은 사방으로).
- 떠다니는 아이콘은 `M.drift` 로 아주 천천히, 크기별로 속도를 달리해 깊이를 만들어요.

## 전환
- 느린 페이드가 기본이고, 소품이 화면 밖으로 밀려나는 밀어내기(push)를 섞어요. 장 끝을 맺을 때만 컷.
- 장면 쌓기: fade → push → cut.
- 앞 장면의 숫자·카드가 다음 장면 자리로 옮겨 가며 이어지게 하면 이 결이 살아요(숫자 → 막대 꼭대기, 빈 카드 → 제목 카드).

## 대표 장면

1. **굴러 멈추는 숫자와 물결 밑줄**
   ```
   // 자리마다 0~9 세로 띠를 두고 overflow: hidden 창으로 보여 줌
   const cols = S.$$('.digit-col');
   S.ambient(t => {
     cols.forEach((c, i) => {
       const k = M.ease.outCubic(M.prog(t, .2 + i * .06, .7));
       c.style.transform = `translateY(${-(target[i] + 10) * k * 100}%)`;
     });
     M.draw(squiggle, M.ease.outCubic(M.prog(t, M.beat(3), .4)));   // 핵심 낱말 밑 물결 선
   });
   ```
   설명 어절은 `S.chars` 대신 어절 단위로 나눠 각자 y 를 다르게 시작해(±1.5u) 0.4초에 한 기준선으로 모아요. 장면 쌓기에서는 `number: odometer` 가 같은 일을 해요.
2. **숫자가 막대 위로**
   - 다음 박에 숫자를 `M.place(num, x, y, {s: .5})` 로 옆으로 줄이며 옮기고, 그 아래 막대를 `M.box(bar, {x, y: H, w, h})` 로 높이 0 에서 차오르게(`M.spring(t - t0, 'smooth')`). 막대 꼭대기 안쪽에 진보라 칩을 0.1초 늦게 톡.
   - 두 막대는 높이를 달리해 값 차이를 보여 줘요. 왼쪽 막대에도 작은 숫자가 같은 방식으로 굴러 올라와요.
3. **하나에 멈추는 아이콘 줄 → 흩어짐**
   ```
   const x = M.anim([[0, W * .3], [.2, -W * .05, {d: 1.4, e: 'inOutCubic'}]], t);
   row.style.transform = `translateX(${x}px)`;
   const pick = M.prog(t, 1.5, .4);                       // 가운데 아이콘
   M.place(center, cx, cy, {s: 1 + pick * .25});
   center.style.filter = `grayscale(${1 - pick})`;
   ```
   다음 박에 아이콘마다 `M.rng(시드)` 로 자리·크기(0.4~1.6배)를 정해 `M.spring` 으로 퍼뜨리고, 퍼진 뒤엔 `M.drift` 로 떠다니게. 가운데에 제목이 어절씩 올라와요. 장면 쌓기에서는 `deco: shapes` 가 흩어진 원들을 깔아요.
4. **카드와 점선 가지, 그리고 낱말 목록**
   - 흰 빈 카드가 `M.spring` 으로 커지며 제목을 품고, 카드 아래 점선 가지를 `M.draw(path, k)` 로 위에서 아래로 0.6초. 가지 끝마다 빈 알약이 `M.place(..., {s: k})` 로 톡 생기고, 한 박 뒤 아이콘과 이름이 채워져요.
   - 낱말 목록: 문장 앞부분은 고정, 옆 세로 목록을 `y = M.at([[t0, 0], [t0 + M.beat(2), -h], …], t)` 를 부드럽게 이어 한 칸씩 올리고, 가운데 칸 둘레 보라 알약 테두리는 제자리. 위아래 낱말은 가운데서 멀수록 투명도를 낮춰요.
