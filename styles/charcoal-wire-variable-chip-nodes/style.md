# 변수 칩 노드 배선 (제품 UI)

한 줄: 무늬 없는 숯빛 캔버스에서 어두운 노드 카드에 문장이 쳐지면 낱말 하나가 자두색 칩이 돼요. 왼쪽에서 들어온 작은 카드가 연보라 곡선으로 이어지고 거기서 치는 글자가 칩에 그대로 따라 바뀌어요. 끝에는 결과 칸 속 그림이 화면 가득한 노을빛 실사로 커져요.

## 보는 느낌
- 거의 검은 숯빛 바탕이고 격자나 점 같은 무늬는 깔지 않아요. 화면에는 늘 한두 가지만 놓여요. 가운데 작은 문장 한 줄이거나, 어두운 노드 카드 두세 장이에요.
- 노드 카드는 바탕보다 한 단 밝은 회색 판이에요. 왼쪽 위에 아주 작은 이름표, 안쪽에 한 단 더 밝은 입력 칸, 아래에 '+ 변수 더하기' 같은 작은 글자 버튼이 있어요. 양옆 가장자리에는 연보라 고리 모양 연결 단자가 달려요.
- 카드끼리는 연보라 곡선 한 줄로 이어지고, 선이 화면 밖에서 들어오기도 해요. 카메라는 지금 일이 벌어지는 곳(타이핑 칸, 새 카드, 실행 단추)으로 천천히 옮겨 가며 배율을 바꿔요.
- 마지막에는 카드 속 작은 결과 그림이 화면 가득한 실사로 커지고, 그 위에 얇은 흰 문장 한 줄이 놓여요.

## 색
- 숯빛 바탕 #131314 80 · 카드 회색 #2A2A2D 12 · 연보라 5 · 흰 글자 3.
- 연보라 #C98AD9 는 연결선, 단자 고리, 칩 글자에 써요. 칩 바탕은 어두운 자두색 #5B3F63 이에요.
- 연한 라임 #D9E7A8 은 오프닝 문장의 끝말에 딱 한 번만 써요.
- 결과 사진 장면에서만 노을빛 따뜻한 색(#D99A6A 계열)이 화면 가득 들어와요. 앞 장면을 차갑고 비워 둘수록 이 순간이 살아요.

## 글자
- Geist(한글은 Noto Sans KR Medium)를 400 안팎으로 가볍게 써요. 큰 제목은 없고, 문장은 짧은 변의 4~5% 크기예요.
- 카드 안 이름표와 버튼 글자는 아주 작게(짧은 변의 2%) 옅은 회색 55%로 써요.
- 칩은 낱말 뒤에 자두색 둥근 사각(모서리 0.3u)을 깔고 좌우 여백 0.3em 을 줘요. 글자는 밝은 연보라예요. 칩 앞에 @ 를 붙여 변수라는 걸 알려 줘요.
- 마지막 문장도 같은 가벼운 산세리프로 가운데 정렬해요.

## 질감과 모양
- 질감 없이 매끈하게 가요. 그림자도 거의 없고, 카드와 바탕은 명도 차로만 갈라요.
- 카드 모서리 1u 에 1px 흰색 6% 테두리를 둘러요. 입력 칸 안쪽에는 1px 흰색 10% 테두리를 둘러요.
- 연결선은 2px 연보라예요. 가로로 나갔다가 가로로 들어오는 S자 베지어로 그려요. 단자는 지름 0.9u 고리이고 속은 카드색이에요.
- 결과 칸이 비어 있을 때는 옅은 회색 체크무늬로 투명함을 보여 줘요.

## 움직임
- 96BPM, 보통 속도예요. 사람이 손으로 만지는 빠르기에 맞춰요.
- 타이핑은 초당 10~14자이고 얇은 세로 커서가 깜빡여요.
- 카메라는 1~1.2초에 power3.inOut 으로 옮기고 1.5~3초 머물러요. 배율은 1과 1.6 사이를 오가요.
- 새 카드는 0.4초 동안 크기 0.96에서 1로, 투명도 0에서 1로 들어와요(power2.out). 연결선은 0.5초에 단자에서 단자로 그어져요.
- 칩 안 글자는 왼쪽 카드에서 칠 때마다 한 글자씩 같은 순간에 바뀌어요. 지연을 두지 않아야 연결된 느낌이 나요.
- 결과 그림은 체크무늬 위로 0.6초에 흐림에서 선명해져요.

## 전환
- 오프닝 문장끼리는 컷으로 이어요. 문장 장면에서 캔버스로 넘어갈 때는 서서히 바꿔요(fade).
- 캔버스 안에서는 장면을 바꾸지 않고 카메라만 움직여요. 그래야 한 판 위에서 일이 이어지는 느낌이 나요.
- 가장 큰 전환은 카메라가 결과 칸으로 파고들어 사진이 화면을 채우는 순간이에요. 그 뒤 끝 마크는 컷으로 검은 화면에 놓아요.
- 장면 쌓기 순서는 cut → fade → blur 예요.

## 대표 장면
1. **문장 속 칩 끼워 넣기**: 가운데 문장의 앞 어절과 뒤 어절은 그대로 두고, 사이만 벌려 칩을 넣어요.
   ```
   const gap = M.anim([[0, 0], [1.0, chipW, {d: .4, e: 'outCubic'}]], t);
   M.place(left, cx - gap / 2, cy);
   M.place(right, cx + gap / 2, cy);
   M.place(chip, cx, cy, {o: M.prog(t, 1.1, .2)});
   chip.textContent = M.type('@바뀌는', t, 1.2, 12);   // 자두색 바탕, 연보라 글자
   ```
   다음 문장은 컷으로 바꾸고, 끝말만 라임 #D9E7A8 로 칠해요. 장면 쌓기에서는 title: type 과 marker: highlight 로 같은 결이 나요.
2. **변수 카드 배선과 실시간 칩**: 왼쪽 카드가 떠오르면 선을 긋고, 같은 시각 함수로 두 칸을 함께 채워요.
   ```
   const k = M.spring(t - t0, 'smooth');
   M.place(varCard, x0, y0, {o: k, s: .96 + k * .04});
   M.draw(wire, M.ease.outCubic(M.prog(t, t0 + .3, .5)));   // 출력 단자에서 입력 단자로
   const word = M.type('자전거', t, t0 + 1, 10);
   varField.textContent = word;
   chip.textContent = word;                                 // 칩이 같은 박자로 바뀜
   const camS = M.anim([[0, 1], [t0 - 1.2, 1.5, {d: 1.1, e: 'inOutCubic'}]], t);
   M.place(canvas, camX, camY, {s: camS});
   ```
   두 번째 변수도 같은 방식으로 아래에 붙이고, 선은 겹치지 않게 S자 높이를 달리해요.
3. **실행 단추 → 결과 그림 → 화면 가득**: 커서가 결과 칸 오른쪽 아래 단추를 누르면 그림이 맺히고, 카메라가 그 칸으로 파고들어요.
   ```
   const press = M.cursorAt(runBtn, t, tRun);               // 커서가 와서 누름
   const k = M.prog(t, tRun + .3, .6);
   M.place(img, ix, iy, {o: k, blur: (1 - k) * 6});          // 체크무늬 위로 맺힘
   const zoom = M.anim([[0, 1], [tZ, 4.2, {d: 1.4, e: 'inOutCubic'}]], t);
   M.place(canvas, imgCx, imgCy, {s: zoom});                 // 결과 칸이 화면을 덮을 때까지
   ```
   사진이 화면을 덮으면 S.tr.blur 로 실사 장면에 넘겨요. 가운데 문장은 어절마다 흐림에서 맺히고, 끝말은 연보라로 들어왔다가 1초 뒤 M.color('#C98AD9', '#FFFFFF', k) 로 흰색이 돼요.
4. **변수만 바꿔 다시 실행**: 카메라를 왼쪽 변수 카드로 잠깐 옮겨 두 낱말을 지우고 새로 쳐요. 칩 두 개가 같이 바뀐 뒤 결과 칸으로 돌아와 다시 누르면, 앞 그림이 흐려지며 새 그림이 맺혀요. 같은 틀에서 내용만 갈리는 게 이 결의 요점이에요.
