# 베이지 등고선 데스크와 흙빛 음성 안개 (제품 UI)

한 줄: 옅은 등고선이 흐르는 베이지 바탕화면에서 카메라가 앱 창에 바짝 붙어 세리프 답이 흘러나오는 걸 보여 주고, 말로 입력할 땐 화면이 흐려지며 아래에서 테라코타 안개가 번져 올라오는 차분한 데스크톱 데모.

## 보는 느낌
- 바탕은 따뜻한 베이지 한 색이고, 그 위로 지도 등고선 같은 가는 곡선이 크게 굽이쳐요. 선은 바탕보다 살짝 밝은 흰빛이라 가까이 봐야 보일 만큼 옅어요.
- 화면에는 늘 물건 하나만 주인공이에요. 처음엔 가운데 흙빛 둥근 사각 아이콘, 그다음 바탕화면 위 문서 창, 그다음 화면을 거의 채운 흰 대화 창.
- 카메라가 창에 바짝 붙어 창 가장자리가 화면 밖으로 잘려요. 위아래로 다른 창 귀퉁이가 살짝 비치는 정도로만 깊이를 줘요.
- 단축키를 누르는 순간에는 왼쪽 위 빈자리에 큰 대괄호와 키캡이 떠서 '지금 무엇을 눌렀는지' 알려 줘요.
- 음성 입력 장면만 색이 확 바뀌어요. 흰 창이 흐려지고 아래에서 테라코타 안개가 차올라요.

## 색
- 베이지 바탕 60 · 흰 창 30 · 먹색 글자 7 · 테라코타 3.
- 바탕 #E3DDD2, 등고선 흰빛 55%, 창 #F7F5F1, 글자 #1F1C19~#2B2622.
- 테라코타 #D27654 는 아이콘, 보내기 버튼, 답 끝의 작은 반짝 기호, 음성 안개에만 써요. 그 위 글자는 아주 짙은 갈색 #1A0F0A.
- 키 꼬리표·대화 말풍선은 바탕보다 한 톤 짙은 모래색 #C9C1B4 로 납작하게.
- 입력 막대가 뜰 때 뒤 화면 위에 먹색 25~30% 덮개를 깔아 한 톤 가라앉혀요.

## 글자
- 답 글은 세리프(고운바탕 400, 영문도 함께), 짧은 변의 2.6~3% 크기, 줄 간격 1.5. 꼬리 제목만 고운바탕 700.
- 질문 말풍선, 입력 막대, 버튼, 메뉴 같은 창 장식은 Geist + Noto Sans KR 500, 작고 옅게.
- 엔딩 로고타입과 장면 쌓기 큰 제목은 Instrument Serif(한글은 고운바탕), 굵기 400, 자간 −0.01em. 큰 글자도 화면 너비의 40% 안쪽으로 조용하게.
- 답 글은 왼쪽 정렬로 줄마다 써지고, 큰 제목만 가운데 정렬.

## 질감과 모양
- 질감 효과는 쓰지 않아요. 결은 등고선 무늬와 부드러운 그림자로만 내요.
- 창: 흰 바탕, 모서리 `--u` × 1.2, 아래로 길고 옅은 그림자 한 겹(먹색 12%, 흐림 4u). 위 막대엔 점 셋.
- 입력 막대·음성 알약: 모서리 `--u` × 1.6, 흰 바탕이거나 흰빛 18% 반투명 + 1px 흰 테두리.
- 키캡: 흰 둥근 사각 안에 기호와 작은 이름, 아래 2px 짙은 테두리로 두께. 둘레를 먹색 대괄호가 크게 감싸요.
- 음성 안개는 가장자리가 전혀 없는 큰 흐림 덩어리(10u 이상).

## 움직임
- 96BPM, 보통 빠르기. 카메라 확대·이동은 `power3.inOut` 으로 0.8~1.2초 천천히 붙었다 멈춰요.
- 버튼·막대처럼 작은 것은 `back.out(1.2)` 로 0.35초에 톡 솟아요.
- 질문은 초당 18자쯤 쳐지고, 답은 줄 단위로 0.15초 간격으로 나타나며 창 안에서 위로 천천히 밀려 올라가요(스크롤).
- 키캡은 눌릴 때 0.12초 동안 y 로 짧은 변의 0.6%만큼 내려갔다 올라와요.
- 한 장면에 3~5초 머무르고, 바뀌는 순간은 박에 맞춰요.

## 전환
- 대부분 카메라 확대로 이어져서 따로 전환이 필요 없을 땐 컷.
- 음성 입력으로 들어가고 나올 땐 흐림(blur), 엔딩 아이콘으로 넘어갈 땐 느린 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면

1. **아이콘에서 바탕화면으로 빠지기**
   ```
   // 0초: 가운데 흙빛 둥근 사각 아이콘 하나. 2초: 도크 줄을 화면보다 크게 당겨 잡고 → 바탕화면 전체로 빠짐
   const s = M.anim([[0, 3.2], [M.beat(3), 1, {d: 1.4, e: 'inOutCubic'}]], t);
   M.place(desk, cx, cy, {s});                       // 도크·문서 창이 든 바탕화면 판 통째로
   M.place(icon, cx, cy, {o: 1 - M.prog(t, M.beat(2.5), .3)});
   // 등고선: SVG path 5~6개, 흰빛 55%, M.drift 로 아주 천천히 일렁임
   ```
2. **키캡 누르고 입력 막대 띄우기**
   ```
   const press = (k0) => -0.006 * H * M.ease.outCubic(1 - Math.abs(M.prog(t, k0, .12) * 2 - 1));
   M.place(key1, x1, y0 + press(t1));
   M.place(key2, x2, y0 + press(t1 + M.beat(.5)));
   dim.style.opacity = .28 * M.prog(t, t1 + .3, .3);   // 뒤 화면 한 톤 가라앉힘
   M.place(bar, cx, H * .82, {o: M.spring(t - t1 - .4, 'smooth'), y: (1 - M.spring(t - t1 - .4, 'smooth')) * H * .04});
   barText.textContent = M.type('2025년 매출을 추정해 줄래?', t, t1 + .8, 18);
   ```
   이어 카메라가 대화 창으로 1초에 파고들고(`M.place(app, …, {s: M.anim(…)})`), 답 줄들을 `M.at` 으로 0.15초마다 하나씩 켜며 창 안 목록을 `y` 로 천천히 올려요.
3. **테라코타 음성 안개**
   ```
   const k = M.ease.inOutCubic(M.prog(t, tv, 1));
   app.style.filter = `blur(${k * 7}px)`;            // 엔진 전환으로는 S.tr.blur
   haze.style.transform = `translateY(${(1 - k) * 40}%)`;  // 아래 3분의 1의 큰 흙빛 흐림 덩어리
   haze.style.opacity = k;
   bars.forEach((b, i) => b.style.transform = `scaleY(${.3 + .7 * Math.abs(Math.sin(t * 9 + i * 1.7))})`);
   ```
   알약은 안개가 반쯤 찼을 때 `M.spring` 으로 솟고, 손을 떼면 같은 곡선을 거꾸로 돌려 안개가 가라앉으며 입력 막대에 말한 문장이 한 번에 맺혀요.
4. **누르면 튀는 빛살 엔딩**
   - 등고선 바탕 가운데 아이콘, `M.Cursor` 가 와서 누르면(`M.cursorAt`) 아이콘이 0.3초에 작은 마크 크기로 줄고 둥근 사각 판이 사라져요.
   - 둘레에 짧은 먹색 획 8개를 방사형으로 두고, 반지름을 `M.anim` 으로 0.5초에 키우며 `M.draw` 로 길이를 줄여 튀었다 사라지게. 이어 세리프 로고타입이 `opacity` 와 흐림 4px → 0 으로 맺혀요. 마크는 우리 브랜드 것으로 그려요.
