# 골지 유리와 안내 공 (제품 UI)

한 줄: 흐린 모자이크 위에 세로 점선이 깔린 바탕, 형광 연두 공이 앞장서서 번호 칩을 끌고 다니며 목록을 펼치는 UI 필름.

## 보는 느낌
- 바탕은 연회색. 그 뒤로 흐릿한 연두·청록 사각 조각(모자이크)이 비치고, 위에 아주 가는 세로 점선이 촘촘히 깔려 골지 유리 너머를 보는 듯해요.
- 화면에는 늘 카드 하나와 공 하나만. 나머지는 비워 둬서 공이 어디로 가는지 눈이 따라가게 해요.
- 카드는 반투명 유리판에 얇은 어두운 테두리. 행 사이에는 아주 옅은 구분선만 있어요.

## 색
- 바탕 연회색 70 · 카드 흰빛 20 · 글자 짙은 녹회색 · 강조 10.
- 강조는 두 가지뿐: 형광 연두(공, 단어 형광펜)와 짙은 초록(확인 버튼, 완료 카드).
- 행 앞 작은 아이콘 칩만 여러 색(노랑·파랑·주황)을 조금씩 써도 돼요.

## 글자
- 깔끔한 산세리프(Geist + Noto Sans KR) 500. 크기 차이는 작게, 글자보다 움직임이 주인공이에요.
- 목록 행: 번호(옅게) · 이름 칩 · 할 일 문장 · 오른쪽 끝 마감(옅게). 왼쪽 정렬 한 줄.
- 입력창 문장 속 핵심 단어 하나에 연두 형광펜.

## 질감과 모양
- 질감은 없어요. 모자이크와 세로 점선은 바탕을 그려서 만들어요(아래 대표 장면 1).
- 모서리 반경 크게(카드 `--u` × 2.2). 칩·버튼은 알약 모양.
- 공: 연두 원에 위쪽 밝은 반사, 가장자리만 살짝 번지게. 다른 요소엔 그림자·빛을 쓰지 않아요.

## 움직임
- 110BPM. 공이 박에 맞춰 이동하고, 따라오는 칩·행은 반 박 안에 촘촘히 따라붙어요.
- 공 이동은 앞쪽이 빠르고 끝이 부드러운 스프링(`lead`), 따라오는 것들은 `trail`.
- 행이 펼쳐질 땐 0.06초 간격, 사라질 땐 반대 순서로 0.04초 간격.
- 장면 사이에 멈춤이 거의 없어요. 다음 동작이 시작될 때까지 공이 제자리에서 아주 조금 떠다녀요.

## 전환
- 컷이 거의 없어요. 카드가 공 쪽으로 오므라들거나(줌), 항목이 흩어졌다 다시 모이며 다음 장면이 돼요.
- 장면 쌓기에서는 zoom → fade → cut 순서.

## 대표 장면
1. **바탕 만들기**: 큰 사각 조각 20~30개를 `M.rng(7)` 로 위치·크기·색(연두·청록·회색 사이)을 정해 깔고 부모에 `filter: blur(2.4u)`. 그 위에 세로 점선 판:
   `background: repeating-linear-gradient(90deg, rgba(46,110,60,.18) 0 1px, transparent 1px 1.6u)` 에 가로 점 마스크(`mask: repeating-linear-gradient(0deg, #000 0 2px, transparent 2px 5px)`). `S.ambient` 에서 조각들만 `M.drift` 로 아주 천천히.
2. **세 점 → 공 → 번호 칩**: 세 점을 `M.place` 로 놓고, `M.anim` 으로 가운데로 모은 뒤(0.4초) 공 요소를 `M.spring(t - t0, 'pop')` 으로 키움. 공 경로 `path = [[t0,[x0,y0]], [t1,[x1,y1]], …]` 를 `M.anim(path, t, 'lead')` 로 계산하고,
   칩 i 는 `M.anim(path, t - .08 * (i + 1), 'trail')` 위치에 아래로 조금씩 엇갈려 둠. 시간만으로 정해지니 뱀처럼 따라오는 줄이 돼요.
3. **칩 → 목록 행**: 각 행을 `M.box(row, {x, y, w, h, r})` 로 칩 크기(3u × 3u)에서 행 크기(70u × 6u)로 모프. 시작 시각만 `0.06 * i` 씩 늦춤. 글자는 `M.rise` 로 행 안에서 올라옴.
   공이 행에 닿는 시각에 그 행 배경을 `M.color(paper, '#E9F6C8', k)` 로 바꾸고 체크 아이콘을 `M.spring(…,'pop')`.
4. **흩어졌다 다시 모이기**: 행들을 `M.rng(3)` 으로 정한 3D 자리(perspective 부모 안 `rotateY ±25°`, z 깊이)로 `M.anim` 해서 흩고, 공이 지나가며 고른 몇 개만 새 목록 자리로 다시 `M.anim`. 고르지 않은 행은 `o` 를 0으로.
   마지막에 입력창 카드가 아래에서 올라오고 `M.type` 으로 문장, `S.mark` + 연두 형광펜, 공이 전송 버튼 위에 내려앉아 누름(`down` 처럼 scale .9 → 1).

## 어울리는 곳 / 피할 것
- 어울림: 앱 기능 소개, 할 일·업무 관리, AI 추천·비서 기능, B2B 서비스 데모. 정리·우선순위·자동화를 보여 줄 때 특히 좋아요.
- 피할 것: 굵은 검정 큰 제목, 짙은 그림자, 빠른 컷 편집, 공 말고 다른 반짝이 효과. 공은 하나만.
