# 한 줄 잉크 손짓과 흰 방울 (손그림)

한 줄: 따뜻한 베이지 바탕에 굵은 먹선 한 줄이 그어지며 손짓 그림이 되고, 손끝에서 흰 방울이 톡 생겨 떠다니다 터져요. 문장은 어절마다 옅은 회색에서 먹색으로 차올라요.

## 보는 느낌
- 화면 가운데에 그림 하나, 아니면 문장 한 줄. 둘이 같이 있지 않아요. 나머지는 비어 있는 따뜻한 베이지.
- 그림은 굵기가 고른 먹선 하나로 그린 간단한 손 기호. 선이 고리를 만들며 이어지고 손가락은 같은 굵기의 긴 고리 서너 개. 붓처럼 굵기가 변하지 않고 마커처럼 고르게, 끝은 둥글게.
- 흰 방울은 동그라미를 10~12각으로 살짝 각지게 깎은 모양. 매끈한 원보다 종이를 오려 붙인 느낌이에요. 크기는 짧은 변의 3%부터 20%까지 섞어요.
- 문장 장면은 방울 3~4개가 문장 둘레에 흩어져 떠 있고, 그중 하나가 커져 다음 화면이 돼요.

## 색
- 베이지 바탕 85 · 흰 방울 10 · 먹선과 글자 5.
- 바탕 #D2CABE, 먹 #141414, 방울과 다음 장면 종이 #ECEAE5.
- 강조색 테라코타(#B5573F)는 마지막 로고 옆 작은 기호나 단추 하나에만. 문장 강조는 색 대신 차오르는 순서로 해요.
- 들어오는 어절의 처음 색은 #8C857A(바탕 위 옅은 회갈색).

## 글자
- 고운바탕(Gowun Batang) 400. 책 본문 같은 차분한 세리프, 굵게 쓰지 않아요.
- 문장 크기는 짧은 변의 4.5~5.5%, 가운데 정렬, 자간 −0.01em. 문장은 한 줄로 짧게(한국어 14~18자).
- 작은 UI 글자가 필요하면 Noto Sans KR 500 을 세리프 크기의 40% 로.

## 질감과 모양
- 질감은 거의 없음(그레인 0.03). 선 떨림(boil)과 끊어 그리기는 쓰지 않아요. 선은 매끈하게 그어지고 멈추면 가만히 있어요.
- 장면 쌓기에서는 rough 로 카드·막대 둘레를 손으로 한 획씩 긋되, 다 그어진 선은 움직이지 않게. 카드는 종이색(#ECEAE5) 판, 모서리 1.6u.
- 방울에는 그림자·테두리가 없어요.

## 움직임
- 80BPM, 느리게. 그리기와 방울은 power2.out, 방울이 커질 때만 아주 조금 넘침(M.spring 'soft').
- 손 그림: 1.5초 동안 한 번에 그어지고(속도는 고르게), 반 박 뒤 손끝 방울 0.4초, 1박 머묾, 방울이 터지며 선이 0.5초에 거둬짐.
- 문장: 어절마다 0.25초 간격, 하나가 0.3초에 #8C857A → 먹색으로 차오름(자리 이동 없음). 다 들어오면 2박 머묾.
- 떠다니는 방울은 서로 다른 느린 속도(초당 짧은 변의 0.5% 안팎)로 흐르고, 1초에 한 번쯤 모양이 살짝 바뀌어요.

## 전환
- 방울이 커져 덮는 이음이 기본. 장면 쌓기에서는 iris(둥글게 열림)가 가장 가깝고, 그다음은 0.4초 서서히(fade).
- 다음 장면이 밝은 종이색이면 덮은 방울의 모양이 둥근 사각형으로 바뀌며 그 장면의 바탕·창이 돼요.

## 대표 장면

1. 한 줄 잉크 손짓
   ```
   // 손 기호 path 하나(직접 그린 단순한 손짓, stroke #141414, width 1.1u, linecap round, fill none)
   S.ambient(t => {
     const draw = M.prog(t, T0, 1.5), undo = M.prog(t, T1, .5);   // T1: 방울이 터지는 시각
     M.draw(hand, draw - undo);                                     // 되감듯 거둬짐
     M.place(handG, cx + S.W * .02 * M.prog(t, T0, 3), cy);         // 그리는 동안 아주 천천히 흘러감
   });
   ```
2. 손끝의 흰 방울과 터짐
   ```
   // 방울: 10~12각 다각형 path. 꼭짓점 반지름 = R * (1 + .05 * 노이즈(i, floor(t)))  ← M.rng 시드, 1초마다 모양이 살짝 바뀜
   const k = M.spring(t - (T0 + 1.5 + M.beat(.5)), 'soft');           // 점 → 제 크기
   M.place(blob, tipX, tipY - R, { s: k });
   // T1 에 터짐: 방울 scale 1 → 0 (0.15초), 작은 물방울 5개를 M.rng(3) 방향(위쪽 반원)으로
   // 거리 = M.ease.outCubic(M.prog(t, T1, .6)) * 6u, 크기·불투명도는 같이 줄어듦
   ```
3. 문장이 차오르고 방울이 다음 화면이 됨
   ```
   const ws = S.words(line);
   ws.forEach((w, i) => tl.fromTo(w, { color: '#8C857A', opacity: .4 }, { color: '#141414', opacity: 1, duration: .3, ease: 'power2.out' }, T2 + i * .25));
   // 덮기: 방울 하나의 반지름을 M.floodRadius(x, y) 까지 0.6초(power2.inOut)로 키워 화면을 덮고,
   // 덮인 순간 같은 색의 둥근 사각형(M.box)으로 바꿔 {w: 화면의 86%, h: 80%, r: 1.6u} 로 0.4초에 오므려 다음 장면의 창이 되게
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: 따뜻한 브랜드의 첫 장면·엔딩, AI·도구 소개의 도입, 감성 문장 한 줄, 강의·교육 인트로, 보여 주기 전에 궁금하게 만드는 티저.
- 피할 것: 굵은 고딕, 선명한 원색, 글이 빽빽한 장면, 빠른 컷, 선이 계속 꿈틀대는 떨림(boil).
- 손 기호는 특정 브랜드의 그림을 따라 그리지 말고, 영상 내용에 맞는 단순한 손짓(가리키기, 집기, 손바닥 펴기)을 한 줄로 새로 그려요.

## 배운 곳
- keyframe.gallery, mux 재생 ID TFUcyLdEvvHX756oXM3FQ3BY60094RGEd4X9kBzEj4Bo.
- 0~3.5초: 먹선 하나가 고리를 만들며 손 기호가 되는 그리기, 손끝에서 각진 흰 방울이 커지는 순간.
- 3.5~4.3초: 방울이 일그러지며 물방울로 터지고 선이 되감기듯 거둬지는 퇴장.
- 4.1~6.6초, 71~75초: 흰 방울이 흩어진 바탕 위 세리프 문장이 어절마다 회색에서 먹색으로 차오르는 등장, 방울 하나가 커져 화면을 덮고 다음 화면의 창이 되는 이음.
