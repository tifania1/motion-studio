# 비트맵 풍경과 자막 (제품 UI)

한 줄: 색을 서너 개로 줄여 점으로 찍은 하늘·바위 산 사진 위에 흰 알약 입력창이 타자되고, 화면 아래 자막 상자가 끝까지 말을 이어 가요. 후반은 주황 판 위 흰 꼬리표 낱말과 오려 낸 사물이 박자에 맞춰 갈려요.

## 보는 느낌
- 세 가지 화면이 번갈아 와요. ① 디더링한 풍경 사진(파란 하늘, 검정·주황 바위 산) 한가운데 흰 UI 하나. ② 연회색·연청회색 판에 얇은 흰 격자선, 그 위 깨끗한 UI 조각(입력창, 버튼, 단계 목록, 코드 한 줄). ③ 주황 판에 흰 꼬리표 낱말, 디더링한 바위 산 띠, 오려 낸 사물.
- 화면 아래 세이프존 안쪽에는 자막 상자가 처음부터 끝까지 있어요. 위 장면은 0.5~1초마다 컷으로 바뀌어도 자막은 문장 단위(2~3초)로만 바뀌어서 한 사람이 차분히 설명하는 듯 이어져요.
- UI는 화면 가운데 한 덩어리만. 장식은 불규칙한 격자선, 상자 대각선 귀퉁이의 작은 초록 네모, 낱말 뒤 형광 연두 하이라이트 정도.
- 중간에 실제 웹 화면 같은 장면을 0.4초씩 다섯 장쯤 빠르게 넘기며 키워드에만 연두 하이라이트를 쳐요.

## 색
- 바탕(사진·판) 60 · 흰 UI 25 · 먹색 글 10 · 연두·초록 5.
- 주황 판 #CF4015, 하늘 #2DA9E8, 바위 먹색 #151313, 종이 흰색 #F4F1EC. UI 판 바탕은 연청회색(#BAC4D6 안팎)이나 아주 옅은 회색.
- 연두 #C6F04A 는 낱말 뒤 납작한 하이라이트에만. 초록(#3CCB4A 안팎)은 귀퉁이 네모와 '다시 실행' 같은 성공 글자에만. 주황빨강은 실행 버튼과 코드 속 문자열.
- 자막 상자는 검정 75% 반투명이라 주황 위에서는 짙은 갈색(#3B241A 근처), 회색 위에서는 짙은 회색으로 비쳐요. 글은 흰색.
- 스타일 색을 켜면 바탕 주황 · 글 미색 · 강조 연두로 칠해져요. 강조색(연두) 바탕 장면은 쓰지 않아요.

## 글자
- Geist(한글 Noto Sans KR 500·700) 하나로 UI·자막·큰 낱말을 다 쓰고, 입력창 명령과 코드만 Geist Mono.
- 꼬리표 낱말: 굵기 600~700, 자간 −0.02em, 짧은 변의 9~11%. 영문은 소문자 그대로, 두 낱말이면 두 줄로 나눠 줄마다 꼬리표를 따로.
- 자막: 500, 짧은 변의 3.2~3.6%, 한 줄. 상자 안 좌우 여백 0.8em, 위아래 0.35em.
- 입력창 글: Geist Mono 400, 알약 높이의 45%. 끝에 커서 막대가 깜빡.
- 마지막 주황 장면의 문장: 미색 600, 줄마다 정렬이 달라요(윗줄 왼쪽, 아랫줄 오른쪽). 두 줄 사이 빈 틈에 사물이 끼어요.

## 질감과 모양
- 디더는 사진에 강하게. 하늘·먹·주황·흰 네 색으로 줄인 Bayer 점 무늬, 점 크기 짧은 변의 0.4~0.6%. 구름 가장자리에 분홍빛 점이 조금 섞이면 이 결이 나요.
- 화면 전체 질감은 약하게(dither 0.18, grain 0.05). UI 면과 글자는 깨끗하게 남아요.
- 흰 알약 입력창: 높이 짧은 변의 8~9%, 끝이 완전히 둥글고 그림자 없음.
- UI 카드: 모서리 `--u` × 0.4 로 거의 각지고, 테두리 없이 흰 면. 주소창이 있는 창은 왼쪽 위 점 셋과 아주 작은 고정폭 주소.
- 꼬리표: 각진 흰 직사각형, 글 좌우 여백 0.4em. 두 줄이면 줄마다 길이가 달라 계단처럼 어긋나고, 그 홈에 주황 판이 비쳐요.
- 격자: 1px 흰 선(주황 위 30%, 회색 위 60%). 간격이 들쭉날쭉한 세로·가로 선 몇 줄이라 설계 도면처럼 보여요.
- 커서: 흰 화살표에 검정 테두리, 버튼 위에서는 손가락.

## 움직임
- 116BPM, 빠름. 장면은 대개 1~2.5초, 자막은 2~3초. 두 리듬이 따로 가요.
- 대부분은 컷으로 그냥 나타나요. 움직이는 건 `power3.out` 0.2~0.3초, 넘침 없음.
- 타자: 짧은 명령은 초당 18자 안팎, 긴 문장은 초당 30자. 다 쓰고 나면 커서가 반 박 간격으로 깜빡.
- 버튼 글 바뀜: 누르는 순간 글자가 무작위 기호로 흩어졌다가(0.3초) 새 낱말로 맞춰지고 글자색이 주황빨강에서 초록으로.
- 이름 맞추기: 빈칸이 많은 상태에서 글자가 무작위 순서로 하나씩 채워져 0.4초에 완성.
- 주황 장면: 꼬리표 낱말은 0.6~1초마다 다른 자리에 컷으로, 사물 컷아웃은 0.3~0.5초마다 갈아 끼움.
- 머무는 동안 풍경과 구름은 천천히 옆으로 흘러요(초당 화면 폭의 1~2%).

## 전환
- 거의 다 컷. 장면만 바뀌고 자막 상자는 그대로 둬요.
- 큰 이음 두 번만 zoom: 버튼에서 확 빠지며 옛 웹 창 여러 장이 겹친 화면이 드러나는 것, 그리고 마지막에 주황 판 전체가 연회색 위 작은 카드로 줄어들며 로고 화면이 되는 것.
- 장면 쌓기: cut → cut → zoom.

## 대표 장면
1. **비트맵 풍경 + 알약 입력창**
   ```
   // 풍경 사진은 S.start 안에서 한 번 canvas 로 4색 Bayer 디더 → data URI (팔레트·행렬 고정이라 매번 같은 결과)
   const blink = Math.floor(t / M.beat(.5)) % 2 ? '|' : '';
   cmd.textContent = M.type('POST /v1/agents', t, t0, 18) + blink;   // 알약 폭은 글 폭 + 2em 을 따라 늘어남
   M.place(pill, S.W / 2, S.H * .42, {s: M.anim([[0, 1], [t0 + .35, 1.6, {d: .15, e: 'outCubic'}]], t)});   // 타자 도중 한 번 확 다가옴
   land.style.backgroundPosition = `${-t * 1.5}% 50%`;   // 풍경은 천천히 흐름
   ```
2. **끝까지 남는 자막 띠**
   - 자막 상자를 장면 층 바깥(카메라 밖) 맨 위 층에 두고, 문장 목록 `[[시각, '문장'], …]` 을 `M.at` 으로 골라 넣어요. 바뀌는 순간만 0.15초 페이드.
   - 위치는 `S.safe.bottom` 위 2u, 가운데. 상자 폭은 글 폭을 따라가요(`width: max-content`).
3. **버튼 글 흩어졌다 맞춰짐 + 초록 귀퉁이**
   ```
   // M.Cursor 로 화살표를 버튼에 데려와 누름. 누른 시각 tc 부터
   const k = M.prog(t, tc, .3), r = M.rng(5);
   label.textContent = k < 1 ? next.split('').map(c => r() < k ? c : '#&%@*'[Math.floor(r() * 5)]).join('') : next;
   label.style.color = M.color('#E2552C', '#3CCB4A', k);
   // 코드 상자 귀퉁이 초록 네모 둘: M.place(sq, x, y, {o: t > tc ? 1 : 0}) 로 컷 등장
   ```
   - 장면 쌓기에서는 scenes.number 의 scramble 이 같은 결을 따라가요.
4. **주황 판 꼬리표와 사물 갈아 끼우기**
   - 주황 판에 불규칙한 흰 격자선 4~6줄, 아래쪽에 디더링한 바위 산 띠. 꼬리표 낱말은 `M.at` 으로 0.8초마다 자리를 바꿔 컷 등장(왼쪽 위 → 오른쪽 위 → 가운데).
   - 마지막 장면: 문장 두 줄 사이 틈에 사물 컷아웃(사용자 제품 사진을 `tools/cutout.py` 로 오리고 같은 4색 디더)을 `M.at([[t1, a], [t1 + .4, b], [t1 + .8, c]], t)` 로 갈아 끼움. 끝은 `S.tr.zoom` 으로 판 전체를 작은 카드로 줄여 로고 화면에 놓아요.

## 어울리는 곳 / 피할 것
- 어울림: 개발자 도구·API 소개, AI 에이전트·자동화 서비스, 웹 서비스 기능 출시, 스타트업 런칭. 말로 설명할 게 많은 20~30초 영상.
- 피할 것: 부드러운 그라디언트, 손글씨, 세리프, 사진을 깨끗한 원본 그대로 쓰기, 자막 없이 큰 글만 이어 가기.
- 풍경 사진은 사용자 사진이나 CC0 사진을 디더로 바꿔 써요. 영상 속 로고와 실제 웹사이트 화면은 쓰지 않고, 색 수를 줄인 사진과 깨끗한 UI가 부딪치는 원리만 가져와요.
