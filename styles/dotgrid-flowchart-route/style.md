# 점 격자 순서도 (다이어그램·데이터)

한 줄: 점 격자 화이트보드 위에 굵은 회색 상자·마름모로 짠 순서도. 카메라가 연결선을 따라 상자에서 상자로 옮겨 다니고, 갈래는 빨강·초록 둥근 꺾임 선으로 나뉘며, 상자 위로 반응이 터져요.

## 보는 느낌
- 연회색 판에 점 격자(간격 짧은 변의 3%, 점 지름 0.25u). 판 위에 순서도: 둥근 사각 상자(질문·할 일), 마름모(갈림), 그 사이 굵은 연결선.
- 처음엔 판 전체를 한 번 작게 보여 주고, 그다음부터는 상자 하나가 화면 가운데 오도록 바짝 다가가 선을 따라 옮겨 다녀요. 화면에 상자는 1~2개만 크게.
- 상자 안 글은 두 줄 안쪽의 짧은 질문이나 할 일. 갈래 끝에는 "예/아니요" 같은 작은 꼬리표.
- 판은 둥근 모서리 카드(frame card) 안에 들어 있고, 카드 모서리에 +/− 확대 단추와 작은 버튼이 붙어 있으면 실제 작업판처럼 보여요.
- 가로 경로 칩 장면은 점 격자 없이 빈 판 가운데 한 줄로만 놓아 숨을 돌려요.

## 색
- 판 80 · 회색 선과 글자 12 · 갈래 색 8.
- 판 #E7E7E7, 점 #1C1C1C 20%, 상자 테두리와 기본 연결선 #6B6B6B, 글자 #1C1C1C.
- 갈래: 빨강 #D63E28('아니요', 강조색), 초록 #2FA04C('예'). 선택·댓글·이름표는 파랑 #2F7BEA. 반응 고르기 원판 테두리만 보라를 아주 조금.
- 경로 칩: 옅은 바탕 + 같은 계열 진한 글자. 주황(#F6D9CF / #D2501E), 파랑(#D6E3FA / #2F6FE0), 초록(#D3EEDA / #22924A), 갈림 칩은 회색(#D6D6D6 / #6B6B6B).

## 글자
- Geist + Noto Sans KR 500. 상자 글은 짧은 변의 3.8~4.5%, 가운데 정렬. 꼬리표는 그 70%.
- 제목 장면도 굵게 키우지 않고 500 그대로, 크기만 짧은 변의 6% 정도(scale 0.95).
- 고칠 말은 상자 안에서 타자로 바꿔요(title: type).

## 질감과 모양
- 질감 없음. 매끈한 화면.
- 상자: 테두리 0.45u(1080 기준 약 5px) 회색, 모서리 0.9u, 안은 판보다 아주 살짝 밝게(#EDEDED). 마름모는 같은 선으로 45도.
- 연결선: 0.45u, 꺾이는 곳은 반지름 2u 의 둥근 모서리, 끝은 열린 화살촉(V자). 빨강·초록 선도 같은 굵기.
- 경로 칩: 모서리 0.5u, 테두리 없음. 화살표는 가는 선(0.15u) + 작은 화살촉.

## 움직임
- 100BPM. 카메라 이동은 power2.inOut 0.8초, 멈추면 1박 머묾. 확대·축소도 같은 곡선.
- 선은 M.draw 로 0.4초에 그어지고, 상자는 선이 닿는 순간 0.2초에 테두리가 그려지며 글이 fade.
- 커서는 상자 앞에서 살짝 느려졌다 누름. 선택 테두리·손잡이는 0.15초에 톡.
- 반응 스티커는 상자 모서리 한 점에서 위쪽 부채꼴로 0.8초 동안 7~10개가 서로 다른 크기로 뿜어 올라 커졌다 옅어져요.

## 전환
- 판 안에서는 끊지 않고 카메라가 선을 따라가는 것 자체가 장면 전환이에요. 장면 쌓기에서는 push(선 방향으로 밀기) → zoom(전체 보기에서 상자로 다가가기) → cut.
- 판 전체 보기와 상자 바짝 보기를 오가는 확대·축소가 리듬을 만들어요.

## 대표 장면

1. 선 따라 카메라 투어
   ```
   // world: 순서도 판(1080×1080 판 기준 2.5배 크기). 정거장 목록 = [[t, x, y, zoom], ...]
   const stops = [[0, 540, 540, .4], [M.beat(3), 300, 520, 1.6], [M.beat(6), 620, 520, 1.6], [M.beat(9), 860, 300, 1.6]];
   S.ambient(t => {
     const [x, y, z] = M.anim(stops.map(([tt, x, y, z], i) => i ? [tt, [x, y, z], { d: .8, e: 'inOutQuad' }] : [tt, [x, y, z]]), t);
     M.camera(world, x, y, z);
     links.forEach(l => M.draw(l.path, M.prog(t, l.t0, .4)));   // 카메라가 지나가기 직전에 선이 그어짐
   });
   ```
2. 빨강·초록 갈래
   - 마름모 오른쪽 꼭짓점에서 선 두 개: 위로 꺾이는 빨강, 아래로 꺾이는 초록. path 는 직선 + 반지름 2u 호 + 직선.
   - 두 선을 0.1초 엇갈려 M.draw, 끝에 화살촉이 닿으면 꼬리표("아니요"/"예")가 fade, 이어 그 끝 상자 테두리가 그려짐.
3. 상자 글 고치기 → 반응 → 댓글
   ```
   // M.Cursor 로 상자 클릭 → 파란 1px 선택 테두리 + 손잡이 점 넷(S.fx.pop), 위에 검은 도구 막대(S.fx.rise)
   // 글 선택: 파란 덮개 폭 0 → 글 폭 (0.25초), 그다음 txt.textContent = M.type(새말, t, t1, 14)
   // 반응: i 번째 스티커 위치 = 시작점 + 방향(M.rng(5)) * M.ease.outCubic(M.prog(t, t2 + i*.05, .8)) * 12u, 크기 .4→1.2, 끝 0.2초에 옅어짐
   // 이름표 커서: 이름표 상자 폭·높이를 M.anim 으로 말풍선 크기까지 늘리고 그 안에 댓글을 타자
   ```
4. 가로 경로 칩
   - 칩A(할 일) fade → 화살표 path M.draw 0.3초 → 회색 칩(갈림) → 화살표 → 칩B(결과). 각 단계마다 줄 전체의 x 를 M.spring 'smooth' 로 다시 가운데로.
   - 다음 경로: 칩 글자를 흐림 4px 로 0.2초에 바꾸고(M.swap 대신 직접 blur·opacity), 칩 색은 M.color 로 주황 → 파랑 → 초록. 갈림 칩과 화살표는 그대로 둬요.
