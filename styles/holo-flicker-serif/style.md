# 홀로그램 잔상 (그라디언트·빛)

한 줄: 흐릿한 무지개 형체가 반 박마다 바뀌는 뒤로 세리프 한 줄이 고정된, 그레인 짙은 꿈결 같은 장면.

## 보는 느낌
- 가운데 흰 세리프 문구 한 줄은 제자리에 머물고, 뒤 그림만 박자마다 휙휙 바뀌어요.
- 뒤 그림은 꽃·나비·얼굴 같은 형체인데, 심하게 흐리고 빨강·청록이 서로 어긋나(RGB 분리) 열화상이나 홀로그램 스티커처럼 보여요.
- 굵은 그레인이 화면 전체를 덮어 필름을 다시 찍은 듯한 거친 맛이 있어요.

## 색
- 바탕(그림): 분홍 #FF5FA2, 청록 #5EE3D0, 노랑 #F6C35B, 보라 #8C7CF0 이 섞인 무지개. 어두운 장면은 올리브·자줏빛 어둠 #35303D.
- 글자는 흰빛 #FAF6F2. 마지막 밝은 장면에선 어절마다 파랑·분홍·청록·자주.
- 비율: 그림 85 · 글자 10 · 그레인 5.

## 글자
- 세리프(Noto Serif KR Black). 원본은 보통 굵기라 가는 세리프가 있으면 그쪽이 더 맞아요. 한 줄, 화면 너비 60~70%.
- 큰 첫 글자 장면에선 화면 높이 40% 넘는 거대한 세리프.

## 질감과 모양
- 그레인 0.16(초당 12장 바뀜), 비네트 0.22.
- 그림 위에 `blur(3~5u)` + 채도 1.6. 빨강·청록 복제본을 1u 씩 어긋나게 겹쳐 RGB 분리.

## 움직임
- 128BPM, 빠름. 그림은 반 박(약 0.23초)마다 컷. 문구는 처음 한 번 나타난 뒤 끝까지 그대로.
- 그림 하나하나는 머무는 동안 살짝 커지거나(1 → 1.04) 옆으로 흘러요.
- 거대한 첫 글자는 오른쪽에서 0.6초 동안 밀려 들어오고, 무지개 번짐은 왼쪽에서 오른쪽으로 0.5초.

## 전환
- 그림끼리는 컷. 앞뒤 장면과는 짧은 페이드(흰 바탕으로 빠지며 문구만 남음).
- 장면 쌓기: cut → fade.

## 대표 장면
1. **고정 문구 + 반 박 그림 교체**: 그림 판 하나에 사진(꽃, 나비, 인물 실루엣 등) 6~10장을 겹쳐 두고, `const k = Math.floor((t - t0) / M.beat(.5)) % n` 으로 지금 보일 한 장만 `o = 1`. 문구는 `S.fx.fade` 로 한 번만.
   각 사진: 원본 + 빨강 복제(`filter: blur(4u) saturate(1.8) hue-rotate(-20deg)`, `mix-blend-mode: screen`, x +1u) + 청록 복제(`hue-rotate(160deg)`, x -1u).
2. **거대한 첫 글자 + 무지개 번짐**: 문구 첫 낱말을 화면 높이 40% 로 키워 `M.place(big, M.anim([[0, W * 1.3], [t1, W * .55, {d: .6, e: 'outCubic'}]], t), cy)`.
   뒤에서 무지개 판(`conic-gradient` + `blur(8u)`)을 `clip-path: inset(0 ${(1 - k) * 100}% 0 0)` 로 왼쪽부터 드러냄(`k = M.prog(t, t1, .5)`).
3. **밝은 바탕에 남는 색 문구**: 그림 판 `o` 를 0으로 빼고(0.3초) 바탕을 밝게. `S.words(문구)` 의 어절마다 색 목록에서 하나씩 칠해 멈춤. 마지막 반 박 동안 RGB 분리를 글자에 0.5u 만 남겼다가 0으로.

## 어울리는 곳 / 피할 것
- 어울림: 이미지·AI 생성 서비스, 음악·공연 티저, 뷰티·패션 무드, 새 시즌 컬렉션. 영상 앞부분 3~5초 훅으로 특히 좋아요.
- 피할 것: 또렷한 제품 사진, UI 화면, 긴 문장, 느린 페이드로만 잇기.
- 빠르게 깜빡이는 장면이라 길게 쓰지 않아요(한 번에 5초 안쪽).
