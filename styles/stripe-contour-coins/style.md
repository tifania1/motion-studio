# 세로 줄무늬 등고선 (레트로·픽셀)

한 줄: 밝은 회색 위에 가는 세로 줄로 칠한 등고선 덩어리가 물결처럼 번지고, 줄무늬 동전이 뒤집히며 날아다녀요. 기울인 굵은 낱말은 글자마다 살짝 뛰고, 끝엔 픽셀 글꼴 칩이 띠로 흘러요.

## 보는 느낌
- 밝은 회색 바탕 가운데 짧은 낱말 하나. 둘레는 비우거나, 화면 가장자리에서 세로 줄무늬 덩어리가 지형도처럼 밀려 들어와요.
- 모든 색 면은 꽉 칠하지 않고 가는 세로 줄로 칠해요. 그래서 렌티큘러 인쇄나 옛 전광판 같은 결이 나요.
- 사이사이 남색 전체 화면이 한 번씩 끼어 박자를 끊어 줘요.

## 색
- 회색 #EDEDED 60 · 줄무늬 덩어리 25 · 검정 글자 8 · 남색 7.
- 줄무늬 색: 연보라 #C990EE, 크림 #F2E9C4, 세이지 #8FB39A, 연두 #B9EE7E, 남색 #2222E6.
- 남색 #2222E6 은 강조 글자 하나, 알약 꼬리표, 전체 화면 장면에. 남색 장면에서는 흰 글자.
- 끝 칩 띠는 주황 #E8812F·노랑 #E8B623·초록 #2E9E6A 까지 더해 여러 색.

## 글자
- 기울인 굵은 그로테스크: Archivo 650~700(폭 100%) + Noto Sans KR Bold. 기울임은 `font-style: italic`(브라우저 기울임)이나 `skewX(-10deg)`.
- 한 장면에 한 낱말 + 마침표("모으기." "빌리기." 처럼). 크기는 짧은 변의 7~9%로 크지 않게.
- 꼬리표·본문: Geist 500 + Noto Sans KR 500. 칩 띠: 영문 Silkscreen, 한글 Galmuri11.

## 질감과 모양
- 화면 전체 질감은 없음. 결은 줄무늬 채우기에만 있어요.
- 줄무늬: `repeating-linear-gradient(90deg, 색 0 .45u, transparent .45u 1.2u)`. 덩어리 가장자리는 2u 칸 단위 계단(픽셀처럼).
- 동전: 원판 + 테두리 1.2u 남색 줄무늬, 앞면은 크림·분홍 줄무늬에 옅은 노랑 반사 한 조각.
- 알약 꼬리표: 남색 바탕 흰 글자, 모서리 완전히 둥글게, 두 개를 계단처럼 어긋나게.

## 움직임
- 116BPM. 낱말은 박에 맞춰 0.3초 power3.out, 글자 물결은 글자마다 0.04초 간격으로 0.3em 위로 갔다 돌아옴(넘침 없음).
- 줄무늬 덩어리는 노이즈 지형을 시간에 따라 천천히 바꿔(초당 0.3 칸) 숨 쉬듯 번졌다 오므라듦.
- 동전 뒤집기 0.4초, 뒤집힌 가운데(폭 0.1)에서 안 글자를 바꿔요.
- 시계 바늘은 박마다 한 번씩 툭 돌아감.

## 전환
- 원형 열림(iris): 등고선 구멍이 커지며 다음 장면이 드러나요. 다음은 칸 덮기(blocks): 연두 픽셀 띠가 계단 모양으로 쓸어 올림. 그 밖에는 컷.

## 대표 장면

1. **세로 줄무늬 등고선 바탕**
   ```
   // 2u 칸 격자에서 칸마다 값 v = 거리(가운데) * a + noise(x, y, t * .3)  (시드 난수로 만든 값 노이즈)
   // v 구간마다 색을 정하고(구멍 → 크림 → 세이지 → 연보라 → 남색), canvas 에 칸마다 세로 줄 하나씩 그림
   S.ambient(t => { for (칸) { const c = band(v(x, y, t)); if (c) ctx.fillRect(x, y, .45 * u, 2 * u); } });
   // 구멍 반지름을 M.anim 으로 키우면 iris 전환과 같은 결
   ```
2. **글자 물결 + 한 글자 반짝임**
   ```
   const cs = S.chars(word);
   cs.forEach((c, i) => {
     const k = M.prog(t, t0 + i * .04, .3);
     c.style.transform = `translateY(${-Math.sin(k * Math.PI) * .3}em)`;
     c.style.color = i === hi ? M.color('#2222E6', '#111111', M.prog(t, t0 + .5, .25)) : '#111111';
   });
   ```
   나갈 때는 앞 글자 두세 개를 `M.at` 으로 기호(&, %, L…)로 바꿨다가 지움.
3. **줄무늬 동전 뒤집기**
   - 원판의 `scaleX = Math.abs(Math.cos(M.anim([[0, 0], [tf, Math.PI, { d: .4, e: 'inOutCubic' }]], t)))`, 0.1 이하일 때 안 글자를 다음 낱말로 바꿈(`M.at`).
   - 흩어진 동전 6~8개: 시드 난수 자리·기울기, 저마다 다른 속도로 `scaleX` 를 돌리며 천천히 위로 떠감.
4. **칩 띠와 남색 끝 화면**
   - 칩(Silkscreen/Galmuri11, 색 바탕) 두세 줄을 서로 반대 방향으로 일정 속도로 흘림 → 가운데 문장이 타자되는 동안 줄이 위아래 가장자리로 작아지며 띠가 됨(장면 쌓기 `deco: ticker`).
   - 컷으로 남색 전체 화면, 흰 주소를 `M.type` 으로.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 핀테크·투자·포인트 서비스, 새 기능을 한 단어씩 소개, 앱 출시, 숫자·시간 강조(24시간·365일).
- 피할 것: 손그림, 사진 배경, 부드러운 흐림 그라디언트, 세리프 글꼴. 금융 상품은 수익을 단정하는 말 없이, 필요한 안내 문구를 함께.
