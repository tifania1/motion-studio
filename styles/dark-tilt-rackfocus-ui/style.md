# 어둠 속 기운 화면 초점 훑기 (제품 UI)

한 줄: 거의 검은 공간에 비스듬히 누운 UI 판을 카메라가 천천히 훑어요. 흐림 속에 있던 카드와 노드 선, 칩이 하나씩 초점에 맺히고, 끝은 회색 두 줄 문장으로 조용히 닫히는 제품 영상이에요.

## 보는 느낌
- 바탕은 거의 검은 #111113 한 가지예요. 무늬도 빛줄기도 없이 비네트로 가장자리만 더 어두워요.
- 모든 UI 는 정면을 보지 않아요. 판을 원근으로 15~25도 눕히거나 비틀어 두고, 카메라가 그 위를 비스듬히 지나가요.
- 얕은 심도가 이 결의 중심이에요. 한 화면에서 또렷한 곳은 띠 하나뿐이고, 앞과 뒤는 크게 흐려요. 흐린 부분이 화면의 절반 넘게 차지해도 괜찮아요.
- 정보는 적게 보여요. 이슈 한 줄과 설명 몇 줄, 노드 몇 개, 칩 세 개처럼 한 번에 하나의 생각만 맺혀요.
- 장면 사이 숨은 길게 둬요. 판 하나를 4~6초 동안 훑어요.

## 색
- 검정 바탕 80 · 회색 글자와 카드 17 · 강조 3.
- 카드 #1C1C1F 에 1px 흰 테두리 8~12%. 연결선은 흰색 25~35%.
- 글자는 밝은 회색 #E6E6E8, 보조 글은 55% 회색. 순백은 쓰지 않아요.
- 강조 보라 #8B7FF0 은 칩 속 작은 아이콘, 체크 동그라미, 버튼 테두리에만 써요. 빨강 #E0524A 는 꼬리표 앞 작은 점 하나에만.
- 마무리 문장은 회색(60%)으로 맺혔다가 40%로 더 가라앉아요.

## 글자
- Geist(한글 Noto Sans KR Medium) 500, 자간 -0.01em. 크기 대비는 작아요. 제목이 본문의 1.5배를 넘지 않아요.
- 꼬리표·번호는 Geist Mono 대문자, 아주 작게(짧은 변의 1.6% 안팎), 자간 +0.06em.
- 이슈 제목은 한 줄 안에서 일부 어절만 밝게, 나머지는 옅게 둬서 읽는 순서를 만들어요.
- 마무리 문장은 가운데 정렬 두 줄, 짧은 변의 4.5%.

## 질감과 모양
- 그레인 0.05, 비네트 0.45. 어둠이 매끈하되 살짝 숨 쉬게.
- 모서리는 작게(`--u` × 0.6). 칩은 조금 더 둥글게(× 0.8).
- 그림자는 쓰지 않고 1px 테두리로 판을 나눠요. 접사 장면에서 칩 윗면에만 아주 옅은 반사(흰색 6%)를 줘요.
- 흐림은 깊이마다 0~1.4u. 초점 띠 밖은 최소 0.6u 로 흐려요.

## 움직임
- 80BPM, 느림. 카메라 이동은 `power2.inOut`, 한 번에 4~6초.
- 들어오는 건 흐림 → 선명 + 투명 → 불투명을 함께 1~1.5초. 나가는 건 거꾸로 흐려지며 어둠에 잠겨요.
- 초점 띠가 판 위를 천천히 지나가며 줄마다 0.3초 간격으로 맺혀요.
- 튀거나 넘치는 움직임은 없어요. 패널 안 커서 클릭만 짧게(0.15초) 눌러요.

## 전환
- 흐림 전환(blur)이 기본: 앞 판이 초점 밖으로 흐려지는 동안 다음 판이 흐림 속에서 맺혀요.
- 마무리 문장으로 갈 땐 페이드, 마지막 마크는 컷으로 짧게.
- 장면 쌓기: blur → fade → cut.

## 대표 장면
1. **기운 판과 지나가는 초점 띠**
   ```
   // 판을 3D 로 눕히고, 카메라 대신 판을 천천히 옮김
   plate.style.transform = `perspective(140u) rotateX(22deg) rotateZ(-8deg)`;
   const lines = S.$$('.plate .line');
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, 0, 5));
     M.place(plate, M.lerp(W*.56, W*.46, k), M.lerp(H*.58, H*.5, k));
     const focusY = M.lerp(-.2, 1.2, k);               // 초점 띠 위치 0~1
     lines.forEach((l, i) => {
       const d = Math.abs(i / lines.length - focusY);
       l.style.filter = `blur(${Math.min(1.4, d * 3)}u)`;
       l.style.opacity = 1 - Math.min(.6, d);
     });
   });
   ```
2. **노드 지도 대각선 훑기**
   - 카드 10~14장을 z 깊이 세 층(-30u, 0, +20u)에 흩고, 카드 사이를 SVG 꺾임 선으로 이어 `M.draw(path, k)` 로 0.8초씩 차례로 그어요. 선 끝엔 Geist Mono 대문자 꼬리표와 테두리 칩.
   - 카메라는 `M.anim([[0, {x:-.08*W, y:.06*H}], [6, {x:.08*W, y:-.06*H, e:'inOutQuad'}]], t)` 로 대각선 이동. 층마다 흐림을 다르게(앞·뒤 1.2u, 가운데 0) 둬서 가운데 층만 맺혀요.
3. **칩 접사에서 패널로 빠지기**
   - 칩 세 개(아바타, 보라 아이콘 칩, 빨간 점 칩)를 화면 너비 80% 로 키워 `rotateY(-28deg)` 로 기울이고, 가장자리에 `mask-image` 선형 그라디언트 + 흐림. 2초 뒤 `M.anim` 으로 scale 3 → 1, 회전 0 으로 2.5초에 빠지며 평평한 패널 속 한 줄로 들어가요.
   - 패널 줄은 왼쪽 회색 이름 + 오른쪽 칩. 체크 동그라미만 보라로 채워지고, `M.Cursor` 가 버튼을 눌러 팝오버가 흐림 속에서 열려요(장면 쌓기 deco cursor).
4. **회색 두 줄로 가라앉는 끝**
   - 가운데 두 줄을 `S.fx` 흐림 등장(title: blur)으로 1.2초에 맺히게 하고, 2박 뒤 `opacity` 1 → .65 로 더 어둡게. `S.tr.blur` 로 빈 검정, 컷으로 작은 마크 하나.
