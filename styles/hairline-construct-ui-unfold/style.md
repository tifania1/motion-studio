# 가는 선 설계 UI 펼침 (제품 UI)

한 줄: 옅은 회색 판에 머리카락 같은 선이 한 줄씩 그어져 칸을 짜요. 그 칸 안에서 입력창, 파란 버튼, 표, 색 견본이 차례로 열리고, 끝은 숯빛 판 위 세리프 한 줄로 조용히 맺혀요.

## 보는 느낌
- 거의 빈 옅은 회색 판에서 시작해요. 처음 2초쯤은 아무것도 없고, 이어 머리카락처럼 가는 회색 선이 화면 끝에서 끝까지 한 줄씩 그어져요.
- 선이 겹치는 자리에 작은 점이 찍히고, 점 넷이 이루는 칸이 다음 요소가 들어설 자리가 돼요. 모든 UI는 이 선 사이에 딱 맞게 끼워져요. 입력창 위아래가 가로선 둘에 닿고, 아이콘은 세로선 사이 칸에 하나씩 들어가요.
- 한 화면에 UI는 하나만 둬요. 입력창, 파란 버튼 하나, 표, 아이콘 줄, 색 견본 타일 순서로 크게, 가운데에.
- 마지막에는 숯빛 판으로 바뀌고, 같은 가는 선이 다시 그어지며 세리프 한 줄을 감쌌다가 사라져요.

## 색
- 회색 판 #E4E4E6 70 · 먹색 선과 글자 #1C1D21 20 · 파랑 #2E4BE8 10.
- 가이드선은 먹색 14~20% 투명도. 교차점 점만 먹색 그대로.
- 파랑은 버튼 하나, 표 속 링크 글자, 견본 타일 한 장에만 써요.
- 표의 꼬리표는 아주 옅은 파스텔(하늘·보라·주황·초록)로 칸 안에만 작게 둬요.
- 회색 단계 #C9CACF · #9A9CA3 · #4A4B50 은 견본 타일과 세로 그라디언트 판에 써요.
- 엔딩 판 #17191E, 글자 #E9E9EC, 선은 흰색 15%.

## 글자
- UI 글: Geist(한글은 Noto Sans KR Medium) 400~500, 작고 반듯하게. 버튼 글은 짧은 변의 4% 안팎.
- 엔딩 문장: Instrument Serif(한글은 고운바탕) 400, 짧은 변의 7~8%, 가운데 한 줄, 자간 -0.01em.
- 굵은 제목은 쓰지 않아요. 크기 대비는 작은 UI 글과 엔딩 세리프 한 줄 사이에서만 생겨요.

## 질감과 모양
- 질감 없이 매끈하게 둬요. 그레인도 비네트도 없어요.
- 선 두께 1px, 교차점 점 지름은 짧은 변의 0.6%.
- 모서리는 거의 각지게(--u × 0.2). 입력창은 판보다 한 톤 밝은 #EFEFF1, 그림자 없이 선만으로 자리를 잡아요.
- 깊이가 필요하면 그림자 대신 반투명 사각형을 여러 겹 겹쳐요(격자 메아리 장면).

## 움직임
- 100BPM, 한 박에 하나씩. 선 하나가 그어지는 데 0.6~0.8초, power3.inOut 으로 천천히 출발해 끝에서 사뿐히 멈춰요.
- 점은 선이 지나간 뒤 0.1초 간격으로 그냥 켜져요(튀는 이징 없이).
- UI 요소는 칸 안에서 가운데부터 가로로 열리며 나타나요(0.5초, expo.out). 글은 초당 20자쯤 쳐져요.
- 장면마다 1.5~2초 머물러요. 나갈 때 요소는 컷으로 빠지고 선은 다음 장면까지 남기도 해요.
- 엔딩은 느려져요. 세리프 글이 왼쪽부터 1초에 드러나고, 2초 머문 뒤 선이 걷혀요.

## 전환
- 컷이 기본이에요. 선이 화면을 가로지르며 다음 칸을 여는 와이프를 섞고, 숯빛 엔딩 판으로 넘어갈 때만 페이드.
- 장면 쌓기: cut → wipe → fade. 장면 바탕은 회색 판 두 번 뒤 숯빛 판(schemes dark, dark, paper).

## 대표 장면

1. 선 긋고 점 찍고 도형 차오르기
   ```
   // SVG line 6개(세로 2 · 가로 2 · 사선 2)를 반 박씩 늦게, 점은 교차점마다
   const lines = S.$$('.guide'), nodes = S.$$('.node');
   S.ambient(t => {
     lines.forEach((l, i) => M.draw(l, M.ease.inOutCubic(M.prog(t, 1.8 + i * M.beat(.5), .7))));
     nodes.forEach((d, i) => d.style.opacity = t > 3.4 + i * .1 ? 1 : 0);
     const k = M.ease.outCubic(M.prog(t, 3.9, .5));          // 칸 속 작은 네모가 먹색으로
     M.place(cell, cx, cy, {s: 1 + k * .6});
     cell.style.background = M.color('#C9CACF', '#1C1D21', k);
   });
   ```
   - 차오른 도형 자리는 브랜드 마크로 바꿔요. 원본 마크 모양은 따라 그리지 않아요.

2. 칸 속 입력창 → 파란 버튼 → 표
   ```
   // 입력창: 가로선 둘 사이 높이, 가운데에서 양옆으로 열림
   const k = M.ease.outExpo(M.prog(t, t0, .5));
   field.style.clipPath = `inset(0 ${50 - k * 50}% 0 ${50 - k * 50}%)`;
   field.querySelector('.text').textContent = M.type(text, t, t0 + .6, 20);
   // 컷 → 가운데 파란 버튼 하나, 아이콘 반짝임은 계단 값
   icon.dataset.on = M.at([[t1, 0], [t1 + .5, 1], [t1 + .6, 0], [t1 + .7, 1]], t);
   // 컷 → 표: 행마다 0.06초 늦게 '생성 중…' 칸이 값으로 바뀜
   rows.forEach((r, i) => r.classList.toggle('done', t > t2 + i * .06));
   ```
   - 장면 쌓기에서는 bg grid 가 가이드선을, deco marks 가 교차점 표시를, deco cursor 가 버튼을 누르는 커서를 맡아요.

3. 격자 메아리 터짐
   ```
   // 칸 많은 격자 사각형을 8겹 복제, 겹마다 다른 배율로 커지며 옅어짐
   S.$$('.echo').forEach((e, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + i * .04, .9));
     M.place(e, cx, cy, {s: 1 + k * (.4 + i * .25), o: .12 * (1 - k * .5)});
   });
   ```
   - 이어서 견본 타일(파랑 한 장, 회색 단계 여러 장)이 세로선 칸에 맞춰 아래에서 한 장씩 올라오고(M.spring 'smooth', 0.1초 간격), 컷으로 세로 그라디언트 판 넷이 나란히 서요.

4. 숯빛 판 세리프 엔딩
   ```
   // 페이드로 숯빛 판에 들어가 가로선 둘 · 세로선 둘이 문장 둘레로 그어짐
   [hTop, hBot, vL, vR].forEach((l, i) => M.draw(l, M.ease.inOutCubic(M.prog(t, t0 + i * .15, .6))));
   // 문장은 왼쪽 세로선을 문턱 삼아 왼쪽부터 드러남 (title: mask)
   const r = M.ease.inOutCubic(M.prog(t, t0 + .4, 1));
   line.style.clipPath = `inset(0 ${100 - r * 100}% 0 0)`;
   // 2초 뒤 선만 0.6초에 걷히고, 로고타입도 같은 방식으로 드러나며 오른쪽 끝을 blur 3px 에서 0 으로
   ```
