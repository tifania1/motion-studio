# 남색 동판화 (손그림)

한 줄: 옅은 회색 종이에 남색 한 가지로 새긴 동판화 삽화와 차분한 세리프 문장. 가는 테두리 판 아래 캡션 상자에 어절이 하나씩 내려앉고, 장면 사이엔 카메라가 빗금 구름 하늘로 올려다봐요.

## 보는 느낌
- 옛 책의 삽화 판과 캡션 같은 구도. 화면 위 2/3 에 1px 남색 테두리 판(그림이나 사진), 그 아래 판과 폭이 같은 낮은 캡션 상자 하나. 둘 사이 간격은 짧은 변의 2%.
- 판 안 그림은 남색 단색. 가는 펜 선으로 윤곽을 잡고, 어두운 면은 빗금과 교차 빗금을 촘촘히 쌓아 칠하고, 밝은 면은 종이를 그대로 남겨요. 회색 면칠이나 그라디언트는 쓰지 않아요.
- 구도는 정면 원경(도시 실루엣, 건물 정면) → 가까이 다가감 → 아래에서 올려다보기 순서로 점점 극적으로. 사람·사물은 판 안에 작게 두고 여백을 크게 남겨요.
- 로고·숫자 장면에서는 판이 사라지고 넓은 종이 위에 빗금 구름 몇 덩이가 가장자리에 걸쳐 떠 있어요.
- 같은 판이 가운데부터 갈라져 세 칸이 되고, 가운데 칸은 비워서 글 칸으로 쓰는 변주가 이 결의 리듬이에요.

## 색
- 종이 80 · 남색 선과 글자 17 · 연보라빛 남색 강조 3.
- 종이 #EAEAEA(아주 살짝 차가운 회색), 선·글자 남색 #2B3256, 강조 어절 #5A72B8. 빗금이 옅게 겹친 곳은 #9AA6CF 정도로 보여요.
- 남색 하나로 다 해결해요. 다른 색은 넣지 않고, 사진을 쓸 때도 질감의 색 입히기(tint)로 남색 단색처럼 맞춰요.

## 글자
- 영문 큰 글은 Instrument Serif, 한글은 고운바탕(Gowun Batang) 400. 굵게 쓰지 않아요. 낮은 대비의 책 세리프 느낌.
- 캡션 문장은 짧은 변의 4.5~5%, 가운데 정렬, 자간 −0.01em. 로고·숫자 장면만 크게(숫자는 짧은 변의 12%, 강조색).
- 강조 어절 하나만 강조색, 나머지는 남색. 밑줄·형광펜은 쓰지 않아요.

## 질감과 모양
- 흰 종이 + 섬유 조금(0.25) + 아주 약한 그레인(0.05). 색 입히기 #34417A(color, 0.2)로 사진·그림을 남색 쪽으로 당겨요.
- 선 떨림(boil)이나 끊어 그리기는 쓰지 않아요. 판화는 선이 단단하게 멈춰 있어야 해요.
- 판·캡션 상자 테두리는 1px 남색, 모서리 0, 그림자 없음. 장면 쌓기에서는 frame poster(여백 테두리) + card outline + 재단 표시(marks).
- 빗금 명암을 직접 그릴 때: 선 굵기 0.12u, 간격 0.45u, 각도 −35도. 더 어두운 곳은 같은 간격으로 +35도 한 겹을 더 얹어요.

## 움직임
- 84BPM, 느리게. 판 안 그림은 멈추지 않고 늘 천천히 밀고 들어가요(3초에 1.00 → 1.12, 거의 선형).
- 어절은 0.15초 간격, 하나가 0.35초에 내려앉음(power3.out). 문장이 다 들어오면 1.5박 머묾.
- 나갈 때는 왼쪽 어절부터 0.1초 간격으로 회색으로 옅어지고 흐려져요. 그동안 같은 상자에 다음 문장이 겹쳐 들어와 상자는 비지 않아요.
- 구름은 장면마다 서로 다른 속도(초당 짧은 변의 0.3~1%)로 가로로 흘러요.

## 전환
- 판 안에서는 확대(zoom): 그림 속으로 밀고 들어가다 다음 그림으로 겹쳐 바뀜(0.5초 흐림 겹침).
- 판 → 하늘 장면은 위로 틸트(push 위 방향): 내용이 아래로 빠지고 새 내용이 위에서 내려와요.
- 장면 쌓기 템플릿 순서는 zoom → blur → push.

## 대표 장면

1. 판과 캡션 상자, 어절 내려앉기
   ```
   // 판: 1px 남색 테두리 안에 그림(img). 캡션: 같은 폭의 outline 상자
   S.fx.kenburns(img, T0, 3, { from: 1.0, to: 1.12, x0: 0, x1: 0 }); // 판 안 그림은 내내 천천히 밀고 들어감
   const ws = S.words(cap);
   ws.forEach((w, i) => {
     const t = T0 + .3 + i * .15;
     tl.fromTo(w, { scale: .6, y: '-.5em', opacity: .3, filter: 'blur(4px)', color: '#9AA6CF' },
                  { scale: 1, y: 0, opacity: 1, filter: 'blur(0px)', color: 'var(--on-bg)', duration: .35, ease: 'power3.out' }, t);
   });
   // 강조 어절만 color: var(--accent) 로 끝남. 나가기: ws 를 왼쪽부터 .1초 간격으로 opacity .25 + blur(3px)
   ```
2. 판이 세 칸으로 갈라짐
   - 판 하나를 같은 그림이 든 세 칸(왼쪽·가운데·오른쪽)으로 겹쳐 두고, 가운데 칸 그림만 0.2초에 지움.
   - 칸 사이 틈을 0 → 짧은 변의 1.5% 로 M.spring(t − t0, 'smooth') 로 벌리고, 가운데 칸 폭은 판의 30%로 줄여 빈 글 칸이 되게. 그 안에 문장이 1번 방식으로 들어옴.
   - 나갈 때는 오른쪽 칸만 화면 밖으로 밀려나고 나머지가 다시 한 판으로 합쳐짐.
3. 빗금 구름 하늘로 올려다보기 → 로고·숫자
   ```
   // 틸트: 앞 장면 묶음 y 를 0 → +H, 새 장면 묶음 y 를 −H → 0 (0.8초, power2.inOut)
   // 구름 SVG 3~5개(윤곽 펜 선 + 아래쪽 반에만 교차 빗금 clipPath). 위치는 t 의 순수 함수:
   S.ambient(t => clouds.forEach((c, i) => M.place(c, x0[i] + v[i] * t, y0[i] + (t < tt ? 0 : -H * M.ease.inOutCubic(M.prog(t, tt, .8))) * .6)));
   // 숫자: 화면 위에서 흐림 6px·크게(1.3배)로 내려와 0.6초에 가운데 자리 잡음 → S.fx.counter 로 올라감
   ```
4. 그린 사물이 화면을 닦음 (마무리)
   - 빗금으로 그린 탈것 하나가 오른쪽에서 왼쪽으로 0.6초에 가로질러 지나가며(가로 흐림 8px) 그 뒤에서 글이 바뀌어요. 사물은 따라 그릴 고유 그림 대신 그 브랜드·지역에 맞는 흔한 사물로.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·투자·법률 서비스, 도시·부동산·여행지 소개, 기관이나 오래된 브랜드의 이야기, 고급 제품 런칭, 숫자 하나를 크게 보여 주는 발표.
- 피할 것: 원색 여러 개, 굵은 고딕 큰 제목, 둥근 모서리 카드와 그림자, 빠른 컷 연타, 선이 떨리는 손그림 효과.
- 그림은 사용자가 준 사진을 남색 색 입히기로 쓰거나, ChatGPT 웹에서 "navy monochrome copperplate etching, fine pen lines, cross-hatching shading, white paper highlights, no gray fills" 같은 말로 새로 그려 넣어요.

## 배운 곳

- 0~5초: 판과 캡션 상자 구도, 판 안으로 밀고 들어가는 카메라, 어절이 작고 옅게 위에서 내려앉는 등장과 왼쪽부터 흐려지는 퇴장.
