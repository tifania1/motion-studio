# 옅은 폰 알림 부풀기 (제품 UI)

한 줄: 아주 옅은 회색 위에 윤곽만 남은 폰 한 대가 있고, 그 위쪽에 뜬 알림 카드 하나가 카메라 앞까지 부풀었다 돌아가요. 이어 회색 알림이 같은 자리에서 한 박마다 조용히 갈려요.

## 보는 느낌
- 바탕과 폰이 거의 같은 회색이에요. 폰은 테두리 없이 부드러운 그림자와 위쪽 알약 모양 홈만으로 형태가 드러나고, 아래쪽은 화면 밖으로 잘려요.
- 주인공은 폰 위쪽 3분의 1 지점에 뜬 알림 카드 하나예요. 폰 안쪽 너비보다 살짝 넓게 놓여 폰 가장자리를 넘어도 괜찮아요.
- 한 화면에 카드는 늘 하나만 두고 나머지는 비워요. 여백이 화면의 80% 넘게 남아요.
- 카메라가 카드로 다가가면 아바타 얼굴과 이름 첫 글자들이 화면 절반을 채워요. 카드 모서리와 글 뒷부분은 화면 밖으로 잘려 나가요.

## 색
- 회색 바탕 85 · 카드 10 · 강조 5.
- 바탕 #EBEBEB, 폰 몸체 #F2F2F2(그림자 rgba(0,0,0,.08) 한 겹).
- 첫 카드: 하늘 회색 #E1E8EF 칠 + 1px 파랑 #3D9BE0 테두리. 이름은 먹색 #1C1C1E, 둘째 줄은 회색 #6B6F76.
- 자홍 #D6157A 는 아바타에 붙은 하트 배지에만 써요.
- 뒤이은 카드들은 중간 회색 #9E9E9E 칠에 흰 글자(80%), 둘째 줄은 흰 45%. 버튼 줄은 한 단 밝은 회색 #B4B4B4.
- 파랑은 첫 카드 테두리와 로딩 호에만 나와요.

## 글자
- Geist, 한글은 Noto Sans KR 500·700. 이름은 700, 이어지는 동사는 500, 둘째 줄은 500 회색.
- 카드 안 글은 짧은 변의 3~3.5%로 작게, 두 줄 왼쪽 정렬. 큰 제목은 쓰지 않고, 크기 대비는 카메라 확대로 만들어요.
- 자간 −0.01em, 줄 간격 1.25.

## 질감과 모양
- 질감 없이 매끈한 평면. 그림자는 아주 부드럽게 한 겹만.
- 카드 모서리 1.6u, 폰 모서리는 짧은 변의 8% 정도로 크게 둥글려요.
- 확대 장면에서 카드 왼쪽 위 모서리 안쪽에 파란 4분의 1 호(선 두께 0.4u, 끝이 둥긂)가 돌아요.
- 아바타 원 오른쪽 아래에 흰 테두리 원, 그 안에 자홍 하트.

## 움직임
- 68BPM 쯤, 한 박이 약 0.9초. 장면이 바뀌는 간격도 한 박이에요.
- 첫 카드: 0.94배·흐림 6px 에서 1배·선명으로 0.5초(power3.out).
- 다가가기: 아바타 중심으로 1배에서 4배까지 0.9초(inOutCubic), 한 박 머문 뒤 같은 곡선으로 1배까지 돌아와요.
- 돌아온 뒤에는 카드가 회색으로 바뀌고 내용이 한 박마다 갈려요. 새 카드는 0.92배·흐림에서 맺히고, 앞 카드는 0.96배로 줄며 흐려져요(0.35초 겹침). 너비는 내용에 맞춰 매번 달라요.
- 마지막 카드에만 아래 버튼 줄이 붙어 키가 커지고, 그대로 머물며 끝나요.

## 전환
- 흐림(blur)과 느린 페이드로 이어요. 컷이나 밀어내기는 쓰지 않아요. 장면 쌓기: blur → fade.
- 큰 변화는 장면 전환보다 카메라 확대로 만들어요.

## 대표 장면

1. 옅은 폰 위 첫 알림
   ```
   const M = Studio.M;
   S.ambient(t => {
     const k = M.spring(t - .9, 'smooth');
     M.place(toast, cx, phoneTop + H * .18, { s: .94 + .06 * k, o: k, blur: (1 - k) * 6 });
   });
   // 폰: 바탕보다 한 단 밝은 둥근 사각 + box-shadow 한 겹, 위에 알약 홈 하나
   ```
2. 알림으로 바짝 다가갔다 빠지기
   ```
   S.ambient(t => {
     const z = M.anim([[0, 1], [1.8, 4, { d: .9, e: 'inOutCubic' }], [3.6, 1, { d: .9, e: 'inOutCubic' }]], t);
     M.place(world, cx, cy, { s: z });            // transform-origin 은 아바타 중심
     spinner.style.transform = `rotate(${t * 300}deg)`;   // 4분의 1 호, 확대 중에만 보이게
     spinner.style.opacity = M.prog(t, 2.2, .3) * (1 - M.prog(t, 3.5, .2));
     const h = M.spring(t - 2.4, 'bouncy');
     M.place(heart, hx, hy, { s: h, o: Math.min(1, h * 2) });
   });
   ```
3. 같은 자리에서 갈리는 회색 알림
   ```
   const toasts = S.$$('.toast.gray');
   S.ambient(t => toasts.forEach((el, i) => {
     const t0 = 4.2 + i * M.beat(1);
     const a = M.spring(t - t0, 'smooth');
     const last = i === toasts.length - 1;
     const b = last ? 0 : M.prog(t, t0 + M.beat(1), .35);
     M.place(el, cx, toastY, { s: (.92 + .08 * a) * (1 - .04 * b), o: a * (1 - b), blur: (1 - a) * 5 + b * 4 });
   }));
   // 마지막 카드만 아래 버튼 줄이 M.prog 로 0.3초에 펼쳐지며 키가 커짐
   ```
4. 장면 쌓기로 만들 때
   - frame: phone 으로 폰 화면을 두고, card: shadow + title: blur 로 카드 글이 흐림에서 맺혀요. 장면 사이는 S.tr.blur.
   - 강조 낱말은 marker: color 로 자홍 한 단어만. 장면 바탕은 회색 → 하늘 회색(paper) → 회색 순서로 아주 조금씩만 바뀌어요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 알림·메시지 기능 소개, 앱 업데이트에서 작은 UI 개선 보여 주기, 소셜·커뮤니티 앱, 상태 표시나 토스트 디자인 공개, 기능 한 가지를 짧게 보여 주는 티저.
- 피할 것: 진한 색 바탕, 빠른 컷과 밀어내기, 한 화면에 카드 여러 장, 큰 굵은 제목, 종이·그레인 질감, 강조색 여러 개(자홍 하트와 파랑 테두리만 써요).
