# 어둠 속 재생목록과 노을 알약 (제품 UI)

한 줄: 거의 검은 화면에 곡 목록, 입력창, 분위기 알약, 앨범 카드가 차례로 떠올라요. 고른 것만 노을빛에서 보랏빛으로 물들고, 끝에는 둥근 윤곽선이 메아리처럼 퍼지는 음악 앱 소개 결이에요.

## 보는 느낌
- 바탕은 거의 검정이에요. 가운데에 UI 조각 하나만 놓고 둘레는 넉넉히 비워 둬요. 가장자리는 비네트로 한층 더 어둡게 가라앉아요.
- UI는 짙은 회색 둥근 카드와 알약으로 이뤄져요. 곡 줄, 입력창, 분위기 낱말 알약, 진행 막대, 앱 창이 하나씩 차례로 지나가요.
- 색은 아껴 두었다가 '고른 것'에만 켜요. 고른 알약, 사진 둘레 고리, 진행 막대의 빛 같은 곳이에요. 영상 한가운데서 딱 한 번 화면 전체가 노을에서 보라로 번지는 그라디언트로 바뀌고, 그때 숫자를 크게 보여 줘요.
- 사진은 앨범 표지처럼 둥근 정사각형이나 동그라미로만 써요. 표지 여러 장이 비스듬히 겹쳐 쌓였다가 깊이를 달리하며 화면 가득 흩어지는 장면이 한 번 들어가요.
- 소리는 세로 막대 파형으로 보여 줘요. 파형 끝에서 가는 곡선이 이어져 나가며 다음 자리로 시선을 끌고 가요.
- 입력창 장면에서는 흐린 사진 위에 입력창을 화면보다 크게 키워 바짝 붙고, 프롬프트가 쳐지는 걸 보여 줘요.

## 색
- 검정 바탕 70 · 짙은 회색 카드 18 · 흰 글자 8 · 노을/보라 4.
- 바탕은 #0D0D0E, 카드는 #1E1E20, 글자는 #F1F1EF, 흐린 글은 흰색 56%로 써요.
- 강조는 노을 산호 #E8604A 에서 보라 #8A5FB8, 파랑 #5A63D0 으로 이어지는 그라디언트예요. 알약, 고리, 윤곽선처럼 작은 면적에 쓰고, 화면 전체에 까는 건 숫자 장면 한 번뿐이에요.
- 산호 단색 위 글자는 아주 짙은 갈색 #1A0C08 을 써요. 그라디언트 판 위의 흰 글자는 유리 원 안에 담아 읽히게 해요.

## 글자
- Geist 에 한글은 Noto Sans KR Medium·Bold 를 붙여요. 제목 굵기는 500, 자간은 -0.01em 이에요. 크게 외치기보다 UI 글자 크기에 가깝게 조용히 써요.
- 입력창 문장은 화면 높이의 4~5%예요. 바짝 붙는 장면에서는 입력창째 키워서 글자가 짧은 변의 10% 가까이 커져요.
- 분위기 알약은 낱말 앞에 '+' 를 붙여요. 고른 순간 글자가 기울어지며 살짝 커져요.
- 곡 줄은 제목을 굵게, 그 아래 작은 회색 부제, 오른쪽 끝에 재생 시간을 둬요. 숫자는 tabular-nums 로 자리를 맞춰요.

## 질감과 모양
- 그레인 0.05, 비네트 0.3. 매끈한 바탕에 어둠만 살짝 거칠게 남겨요.
- 카드 모서리는 --u × 1.6, 알약은 양끝을 완전한 반원으로 둥글게 해요. 테두리는 흰색 6~8%에 1px 이에요.
- 고른 알약은 안을 그라디언트로 채우고, 바깥에 같은 색 빛을 한 겹(blur 1.5u)만 번지게 해요.
- 보통 선은 흰색 25~40%에 1px, 강조 윤곽은 그라디언트로 칠한 1.5px 선이에요.

## 움직임
- 96BPM, 보통 빠르기예요. 들어올 때는 power3.out 으로 부드럽게 멈추고, 떠 있는 동안에도 아주 천천히 흘러요.
- 목록과 알약은 늘 조금씩 움직여요(초당 짧은 변의 2~4%). 완전히 멈춰 있는 UI는 거의 없어요.
- 강조가 켜질 때는 0.3초 안에 색이 차오르고 크기가 1.06배가 돼요.
- 숫자는 0.8초에 걸쳐 올라가고, 숫자를 담은 유리 원도 함께 1.3배로 부풀어요.
- 장면 하나는 1.5~3초 머물러요. 끝의 윤곽선 메아리만 5초쯤 길게 둬요.

## 전환
- 흐림 섞인 페이드가 기본이에요. 앞 장면이 흐려지며 어두워지는 사이 다음 장면이 흐림에서 맺혀요(S.tr.blur).
- 사진 원이 커지며 다음 장면을 여는 원형 열림(S.tr.iris)을 한 번 써요.
- 파형 끝에서 이어진 곡선이 다음 장면 자리로 데려가는 선 잇기도 섞어요.
- 장면 쌓기 순서는 fade → blur → iris 예요.

## 대표 장면
1. **휠처럼 흐르는 곡 목록**: 곡 줄 12개를 세로로 쌓고, 가운데에서 멀어질수록 작고 어둡고 흐리게 해요.
   ```
   const rows = S.$$('.row');            // 줄 높이 h
   S.ambient(t => {
     const off = M.anim([[0, 0], [.4, -h * 6, {d: 1.6, e: 'inOutCubic'}]], t);
     rows.forEach((r, i) => {
       const y = cy + i * h + off;
       const d = Math.min(1, Math.abs(y - cy) / (h * 4));   // 가운데서 멀수록 1
       M.place(r, cx, y, {s: 1.08 - d * .14, o: 1 - d * .75, blur: d * 2});
     });
   });
   ```
2. **분위기 알약 세 줄**: 알약 줄 셋을 서로 반대 방향으로 흘리고, 박마다 하나씩 그라디언트로 채워요. 부모에 perspective 를 주고 rotateX 8도로 살짝 눕히면 깊이가 생겨요.
   ```
   S.ambient(t => {
     lines.forEach((ln, j) => M.place(ln, cx + (j % 2 ? 1 : -1) * t * W * .03, rowY[j]));
     picks.forEach((p, i) => {                       // p: 고를 알약
       const k = M.ease.outCubic(M.prog(t, M.beat(i + 1), .3));
       p.querySelector('.fill').style.opacity = k;  // 산호→파랑 그라디언트 층
       p.style.transform = `scale(${1 + k * .06})`;
       p.style.boxShadow = `0 0 ${k * 3}vmin var(--glow)`;
       p.querySelector('b').style.fontStyle = k > .5 ? 'italic' : 'normal';
     });
   });
   ```
3. **사진 원이 열리고 숫자를 세는 판**: 검정 위 동그란 사진에 산호 고리를 두르고, 원이 열리며 그라디언트 판이 드러나요. 엔진 전환 S.tr.iris 를 써도 같은 결이에요.
   ```
   const R = M.anim([[0, r0], [tA, M.floodRadius(cx, cy), {d: .7, e: 'inOutCubic'}]], t);
   grad.style.clipPath = `circle(${R}px at ${cx}px ${cy}px)`;
   rings.forEach((c, i) => c.setAttribute('r', r0 * (1.6 + i * .7) + Math.sin(t * 1.2 + i) * 4));
   const k = M.ease.outCubic(M.prog(t, tB, .8));
   num.textContent = Math.round(1200 + (3500 - 1200) * k).toLocaleString();
   M.place(glass, cx, cy, {s: 1 + k * .3});        // 흰 10% 유리 원 + blur
   ```
   그라디언트 판 아래쪽에는 아주 작은 흰 안내 문장 한 줄을 둬요.
4. **둥근 윤곽 메아리 엔딩**: 둥근 십자 모양 path 하나를 그은 뒤 같은 모양을 바깥으로 한 겹씩 키워요. 안에는 브랜드 이름 글자를 S.chars 로 나눠 흐림에서 하나씩 맺히게 해요.
   ```
   M.draw(shape, M.ease.outCubic(M.prog(t, t0, .9)));
   echoes.forEach((e, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + .6 + i * .35, 1.2));
     M.place(e, cx, cy, {s: 1 + (i + 1) * .55 * k, o: (1 - i * .2) * k});
   });
   S.chars(nameEl).forEach((c, i) => {
     const k = M.prog(t, t0 + .4 + i * .05, .4);
     M.place(c, 0, 0, {o: k, blur: (1 - k) * 6});
   });
   ```
   장면 쌓기에서는 deco rings 가 동심원 선을 깔아 이 결을 대신해요.
