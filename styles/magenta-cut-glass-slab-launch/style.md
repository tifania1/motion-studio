# 마젠타 컷 유리판 런칭 (3D·사물)

한 줄: 검은 무대에서 청록·은빛·보라 유리판 더미를 카메라가 바짝 붙어 훑고, 박자마다 화면 전체가 마젠타 단색으로 번쩍 바뀌어요. 어두운 기기 화면과 숫자 카드, 눌리는 마젠타 버튼이 번갈아 나오는 금융 앱 런칭이에요.

## 보는 느낌
- 거의 검은 무대가 기본이에요. 그 위에 세 종류 장면이 2초 안팎으로 번갈아 지나가요: 유리 소품 접사, 어두운 기기(노트북·폰·앱 창), 마젠타 단색 판.
- 유리 소품은 둥근 사각판을 비스듬히 쌓은 기둥이에요. 판 하나가 화면 절반을 넘을 만큼 크게 잡혀서 늘 가장자리가 잘려 보이고, 젖빛 유리라 속이 흐리게 비쳐요.
- 기기 장면은 어두운 바닥에 위에서 조명이 떨어지는 무대. 가장자리는 어둡게 가라앉고 기기만 떠올라요.
- 마젠타 판은 쉬어 가는 숨표이자 알림이에요. 단색으로 꽉 채우거나, 큰 원이 열리며 덮거나, 흐린 액체 그라디언트로 번져요. 그 위엔 어두운 카드 하나만 띄워요.
- 후반엔 밝은 장면도 한두 번 끼어들어요: 흐린 분홍 바탕 위 흰 알약 카드, 밝은 화면 모드의 폰. 바로 다시 어둠으로 돌아가요.
- 끝은 검은 화면에 작은 흰 글씨 한 줄로 조용히 맺어요.

## 색
- 검정 #111112 60 · 마젠타 #D4127F 20 · 흰 글자 #F1EEF0 12 · 유리 소품(청록 #2FD3B0, 보라 #7A3CF0, 은빛 #C9CCD2) 8.
- 마젠타는 넓게 칠하는 색이에요. 단색 판, 큰 원, 알약 버튼, 넓은 대문자 한 줄의 앞 낱말.
- 마젠타 위 버튼·글자는 흰색. 마젠타 판 위 카드는 어두운 #1D1D20.
- 초록은 '살아 있음·성공'에만: 꼬리표 앞 작은 점, 완료 체크, +수익률.
- 청록·보라·은빛은 유리 소품과 동전에만 쓰고 글자·카드에는 쓰지 않아요.

## 글자
- 큰 제목: Archivo 800~900, 너비(stretch) 115~125% 로 넓고 낮게, 대문자, 자간 -0.02em. 한글은 Noto Sans KR Black.
- 넓은 대문자 한 줄에서 앞 낱말만 마젠타, 뒤 낱말은 마젠타 40% 로 흐리게 시작했다 밝아져요.
- 카드 속 숫자: Archivo 700, 카드 높이의 40% 로 크게. 위 꼬리표는 작은 대문자(자간 +0.06em)에 초록 점.
- 본문·UI 글씨: Geist 400~500(한글 Noto Sans KR Medium), 짧은 변의 2.5~3.5%. 마무리 한 줄도 같은 글꼴로 담백하게.

## 질감과 모양
- 매끈한 디지털 면. 그레인 없이 비네트 0.28 만 얹어 기기 장면을 무대 조명처럼.
- 유리판: 둥근 사각, 반투명 색 + 안쪽 흐림, 모서리를 따라 흰 빛 1~2px, 아래쪽에 색이 짙게 고여요.
- 카드·창: 어두운 #1D1D20, 1px 흰 7% 테두리, 모서리 `--u` × 1.6. 그림자는 거의 없이 바탕과 명도 차로만 떠요.
- 버튼은 완전한 알약 모양. 동전은 납작한 원판에 굵은 테두리와 기호.

## 움직임
- 112BPM. 장면은 4박(약 2초)마다 바뀌고, 마젠타 번쩍임은 박 위에서 컷으로.
- 들어오는 건 `power3.out` 으로 빠르게 와서 길게 미끄러지며 멈춰요. 나가는 건 대부분 컷.
- 유리판 접사는 카메라가 2~3초 동안 한 방향으로 계속 흘러요(등속에 가깝게). 판 자체는 초당 3~5도로 아주 천천히 돌아요.
- 숫자는 자리마다 굴러 줄어들고(odometer), 마지막 자리에서 살짝 넘쳤다 맞춰져요.
- 버튼을 누르면 0.1초 눌림 → 창 내용이 컷으로 바뀜 → 체크가 0.5초에 그려짐.

## 전환
- 컷이 기본. 마젠타 장면으로 갈 때는 큰 원이 열리는 iris, 기기 사이에서는 옆으로 밀어내기(push).
- 장면 쌓기: cut → iris → cut → push.

## 대표 장면
1. **유리판 더미 접사**
   ```js
   // 둥근 사각 div 5장: background: rgba(색,.55); backdrop-filter: blur(1u); box-shadow: inset 0 0 0 1px rgba(255,255,255,.35)
   const slabs = S.$$('.slab');
   S.ambient(t => {
     const camX = M.anim([[0, W * .25], [M.beat(6), -W * .2, {d: M.beat(6), e: 'linear'}]], t);
     slabs.forEach((s, i) => M.place(s, cx + camX + i * U * 6, cy - i * U * 9,
       {r: -28 + Math.sin(t * .4 + i) * 3, s: 2.2}));   // 크게, 화면 밖으로 잘리게
   });
   ```
2. **마젠타 원이 열리고 숫자가 줄어드는 카드**
   ```js
   // 기기 장면 → S.tr.iris 로 마젠타 원이 열림. 이어 바탕을 흐린 원 3~4개(blur 10u, M.drift)로 액체 그라디언트처럼
   const k = M.spring(t - t0, 'smooth');
   M.place(card, cx, cy, {s: .92 + .08 * k, o: k});
   num.textContent = Math.round(M.anim([[t0, 200], [t0 + .3, 61, {d: 1.2, e: 'outCubic'}]], t)) + 'ms';
   // 장면 쌓기에선 number: odometer + frame: card 로 같은 결
   ```
3. **마젠타 버튼 → 초록 체크 → 유리 아이콘 카드**
   ```js
   const cur = new M.Cursor(root);
   const press = M.cursorAt(cur, btn, t, tP);             // 커서가 와서 누름
   btn.style.transform = `scale(${1 - .05 * press})`;
   M.draw(checkCircle, M.ease.outCubic(M.prog(t, tP + .2, .35)));
   M.draw(checkTick,   M.ease.outCubic(M.prog(t, tP + .45, .25)));
   // 다음 박: 컷으로 둥근 카드, 가운데 젖빛 유리 마름모가 rotateY 를 천천히 오감
   ```
4. **넓은 대문자 한 줄과 쏟아지는 동전**
   - 검은 바탕 가운데 Archivo 900 stretch 125% 대문자 두 낱말. title: mask 로 줄 아래에서 올라오고, 앞 낱말은 마젠타, 뒤 낱말은 `M.color` 로 마젠타 40% → 100% 로 밝아져요.
   - 동전 장면: 원판 40~60개를 `M.rng` 로 자리·기울기·늦음을 정해 위에서 `M.anim` 으로 떨어뜨려 화면을 메우고, 한쪽 위에서 마젠타 원이 걸쳐 들어와요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·거래 앱 런칭, 속도·지연 시간 같은 성능 숫자 자랑, 다크 모드 대시보드 소개, 결제·보상 기능 공개, 젊은 테크 브랜드 티저. 30~45초.
- 피할 것: 종이·손그림 질감, 따뜻한 크림 바탕, 강조색 여러 개(마젠타 하나, 성공은 초록, 유리 소품만 청록·보라), 세리프 글꼴, 긴 문장 여러 줄.
- 로고 판은 우리 브랜드 마크로 따로 만들어요. 마젠타 단색 위에 흰 마크 하나만 두면 이 결과 잘 맞아요.
