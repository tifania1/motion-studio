# 미색 입력창 학습 경로 (제품 UI)

한 줄: 따뜻한 미색 바탕 가운데 입력 카드에 부탁이 머뭇거리며 쳐지고, 작은 상태 알약을 지나 계단처럼 엇갈린 학습 단계 목록이 펼쳐지며 동그라미가 하나씩 파랗게 체크돼요. 끝에는 옅게 덮인 주제 카드 벽이 흘러요.

## 보는 느낌
- 따뜻한 미색 바탕 한 가지에 무대 위 요소는 늘 하나뿐이에요. 입력 카드 → 상태 알약 한 줄 → 세로 학습 경로 목록이 같은 자리를 차례로 넘겨받아요.
- 여백을 아주 넓게 둬요. 입력 카드는 화면 너비 40% 안팎, 경로 목록도 가운데 좁은 기둥 하나로만 서요.
- 중간에 짧고 굵은 문장 한 줄만 있는 숨 고르기 장면이 끼고, 이어 화면 가득한 주제 카드 벽이 미색 막에 덮인 채 흐르며 그 위에 굵은 문장 한 줄이 놓여요.
- 마무리는 다시 빈 미색 위 작은 마크와 안내 한 줄, 그 아래 더 작은 설명 한 줄.

## 색
- 미색 #ECE8DE 80 · 짙은 밤먹색 글자 #2A2321 15 · 하늘 파랑 #7DB6E8 5.
- 카드 면 #F4F1EA, 테두리는 먹색 8%, 그림자는 아래로 아주 옅게 한 겹.
- 하늘 파랑은 보내기 단추와 끝낸 단계 동그라미에만 써요. 단추 안 아이콘과 체크는 짙은 남색 #1B2A38.
- 잠긴 단계는 회색 #D8D2C6 동그라미에 먹색 30% 자물쇠.
- 카드 벽의 그림 칸만 파스텔(모래 #E2CFAE, 민트 #CFE1DA, 라벤더 #DAD4EA, 연분홍)을 쓰고, 그 위를 미색 55~65%로 덮어 전체를 가라앉혀요.

## 글자
- Geist + Noto Sans KR, 둥글고 단정한 산세리프 하나로 다 해요.
- 입력 글: 굵기 400~500, 화면 높이 2.6% 안팎, 왼쪽 정렬, 줄 간격 1.5. 자리 표시 글은 먹색 45%.
- 제목(경로 제목, 숨 고르기 문장, 카드 벽 문장): 700, 자간 −0.01em, 화면 높이 4~5%. 크게 키우지 않고 가운데 한 줄로 둬요.
- 단계 이름은 화면 높이 2%로 작게 두 줄, 잠긴 단계 이름은 먹색 40%. 섹션 카드의 진행 수(2/3 같은)는 더 작고 흐리게.
- 상태 알약 글은 먹색 50%로 작게.

## 질감과 모양
- 질감 없이 매끈한 화면이에요. 깊이는 옅은 그림자 한 겹으로만 내요.
- 입력 카드: 모서리 1.2u, 1px 먹색 8% 테두리. 보내기 단추는 하늘 파랑 정사각, 모서리 0.5u, 가운데 종이비행기 선 아이콘.
- 상태 알약: 미색보다 살짝 밝은 면, 1px 먹색 10% 테두리, 양끝 둥글게.
- 단계 동그라미: 지름 4u, 위쪽이 살짝 밝은 볼록한 단추 모양. 섹션 카드는 넓고 낮은 둥근 사각.
- 카드 벽 칸: 위는 그림 칸, 아래는 작은 제목 한 줄, 모서리 1u.

## 움직임
- 90BPM, 느긋하게. 이징은 power2.out. 들어오는 건 0.4~0.6초 페이드에 아래에서 1u 올라오기.
- 타자: 초당 18~22자. 줄바꿈 앞에서 한 박 쉬고, 말줄임 뒤에서 한 박 반 머뭇거려요. 커서는 1초 주기로 깜빡.
- 기다림 표시: 먹색 동그라미가 0.6초 주기로 살짝 눌렸다 펴지며 위아래 0.5u 통통.
- 경로 목록: 섹션 카드는 위부터 0.15초 간격, 단계 동그라미는 비스듬한 계단 자리로 0.12초 간격으로 톡. 다 놓이면 위부터 0.4초 간격으로 회색에서 파랑으로 물들며 체크가 그어져요.
- 카메라: 목록 전체가 작게 보이다가 1초에 걸쳐 1.6배로 다가가고, 이어 2초 동안 천천히 위로 흘러요.
- 카드 벽: 줄마다 반대 방향으로 4초에 짧은 변의 5%씩 옆으로 흘러요.
- 머무는 시간은 넉넉하게. 한 요소가 다 나온 뒤 한두 박 그대로 둬요.

## 전환
- 서서히(fade)가 기본이에요. 앞 요소가 흐려지며 빠지고 다음 요소가 같은 자리에서 피어나요.
- 숨 고르기 문장 뒤에만 컷으로 빈 미색 한 박을 두고, 카드 벽은 흐림(blur)에서 맺혀요.
- 장면 쌓기: fade → cut → blur.

## 대표 장면
1. **머뭇거리는 입력 카드 타자**
   ```
   const card = S.$('.prompt'), txt = S.$('.prompt .text'), send = S.$('.prompt .send');
   const L = ['…배우고 싶은 것', '…나에 대한 한마디', '그리고…', ' 그림으로 설명해 줘요'];
   const at = [1.0, 3.6, 5.6, 7.1];               // 줄 사이 한 박, 말줄임 뒤 한 박 반
   S.ambient(t => {
     M.place(card, cx, cy, {o: M.ease.outCubic(M.prog(t, 0, .5))});
     txt.textContent = M.type(L[0], t, at[0], 20) + '\n' + M.type(L[1], t, at[1], 20)
                     + '\n' + M.type(L[2], t, at[2], 18) + M.type(L[3], t, at[3], 18);
     M.place(send, sx, sy, {s: M.anim([[0, 1], [9.0, .92, {d: .1}], [9.1, 1, {d: .15}]], t)});
   });
   ```
   장면 쌓기에서는 frame: card + title: type 으로 같은 결의 떠 있는 카드 속 타자를 얻어요.
2. **상태 알약과 기다림 표시**
   - 보내기 직후 카드는 `o` 1 → 0 (0.4초). 같은 자리에 상태 알약을 `M.place(pill, cx, cy, {o: k})`, `k = M.spring(t - t0, 'smooth')`, 글은 `M.type('알았어요! 길을 짜는 중…', t, t0 + .2, 16)`.
   - 알약 아래 먹색 동그라미: `M.place(dot, cx, cy + u * 6, {y: -Math.abs(Math.sin(t * Math.PI / .6)) * u * .5, s: 1 - .06 * Math.cos(t * Math.PI / .3)})`. 브랜드 마크가 있으면 그걸 써요.
3. **계단 학습 경로가 열리고 체크로 물듦**
   ```
   const nodes = S.$$('.step');
   nodes.forEach((n, i) => {
     const k = M.spring(t - (t0 + i * .12), 'smooth');
     const x = cx - u * 3 + (i % 3) * u * 3;          // 섹션마다 오른쪽으로 비스듬히 계단
     M.place(n, x, yOf(i), {o: k, s: .8 + .2 * k});
     const done = M.prog(t, t1 + i * .4, .3);
     n.style.background = M.color('#D8D2C6', '#7DB6E8', done);
     M.draw(n.querySelector('.check path'), M.ease.outCubic(done));
   });
   // 카메라: 목록 묶음 전체에 배율과 세로 위치
   M.place(list, cx, M.anim([[t1, cy], [t1 + 1.6, cy - u * 18, {d: 2, e: 'inOutCubic'}]], t),
           {s: M.anim([[t0, 1], [t0 + .6, 1.6, {d: 1, e: 'inOutCubic'}]], t)});
   ```
   끝내지 않은 섹션의 동그라미는 회색 자물쇠로 남겨 두고, 진행 수 글자만 한 번 `M.at` 으로 바꿔요.
4. **숨 고르기 → 카드 벽 → 마무리**
   - 굵은 문장 한 줄을 가운데 페이드로 두고 한 박 머문 뒤 컷으로 빈 미색 한 박.
   - 카드 벽: 칸 7~8개짜리 줄 5개, 줄 r 은 `x = 시작 + (r % 2 ? -1 : 1) * t * W * .0125` 로 흐르고, 맨 위에 미색 60% 막 한 장. 벽 전체는 `S.tr.blur` 로 맺히고 그 위 문장은 0.5초 페이드.
   - 마무리: 벽이 서서히 빠지고 빈 미색 위 작은 마크와 안내 한 줄이 흐림에서 맺혀요(`blur` 4px → 0, 0.6초). 아래 작은 설명은 한 박 뒤.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 학습·교육 앱, AI 맞춤 추천·계획 짜기, 온보딩·사용법 소개, 차분한 서비스 런칭, 질문 하나로 결과가 펼쳐지는 기능.
- 피할 것: 빠른 컷 몰아치기, 짙은 그라디언트나 네온 빛, 강조색 여러 개(하늘 파랑 하나만), 화면을 꽉 채우는 큰 글자, 손그림 떨림이나 거친 질감.
- 한 화면에 요소 하나만 두는 게 이 결의 핵심이라, 카드 벽 장면 말고는 여러 UI 를 한꺼번에 띄우지 않아요.
