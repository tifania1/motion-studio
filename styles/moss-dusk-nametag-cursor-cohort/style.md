# 이끼빛 어둠 이름표 커서 모임 (제품 UI)

한 줄: 짙은 녹회색 어둠에 흐린 빛 방울이 떠 있고, 파스텔 이름표를 단 커서들이 왼쪽 정렬 굵은 문장 둘레를 맴돌아요. 얼굴 카드가 흐림을 끌며 밀려와 한 줄로 서고, 민트 말풍선이 쌓인 뒤 화살표가 물결 꼬리를 끌고 솟아올라요.

## 보는 느낌
- 바탕은 초록 기운이 도는 짙은 회색 한 면이에요. 그 위에 더 어두운 흐린 원(빛 방울) 몇 개가 아주 천천히 떠다니고, 오른쪽 가장자리에는 옅은 청록 빛이 번져요. 먼지 같은 작은 점과 옅은 그레인이 깔려요.
- 글은 화면 왼쪽 3분의 1 지점에서 시작하는 두 줄 문장 하나. 오른쪽 빈자리에는 커서 떼, 얼굴 카드, 영상 카드와 채팅 판이 번갈아 들어와요.
- 여백이 넓어요. 한 화면에 문장 하나와 UI 덩어리 하나만 두고, 나머지는 어둠으로 남겨요.
- 처음과 끝은 가운데에 흰 낱말 하나만 놓인 조용한 화면이에요.

## 색
- 녹회색 바탕 #1C2522 75 · 흰 글자 #ECEFEC 15 · 이름표·카드·청록 10.
- 청록 #6CC6C0 은 문장마다 마지막 낱말 하나에만 칠해요.
- 이름표 알약: 분홍 #F2A9B4, 연보라 #B9A6F0, 하늘 #8FB4F0, 연두 #6FD08C, 자홍 #D27BE8. 커서 화살도 같은 색, 알약 안 글씨는 짙은 먹색.
- 채팅 판은 어두운 초록 유리 #2A3A33, 말풍선은 민트 #6FCB9E 계열, 보낸 쪽 알약은 하늘색.
- 끝 장면 화살표 꼬리는 보라 #7A6CF0 에서 하늘 #8FB4F0 으로 번져요.

## 글자
- 둥근 기운이 있는 산세리프 굵게(Geist 700, 한글은 Noto Sans KR Bold). 자간 -0.01em.
- 문장은 짧은 변의 6~7%, 두 줄, 왼쪽 정렬, 줄 간격 1.15.
- 이름표 글씨는 아주 작게(짧은 변의 1.6%), 500 굵기.
- 끝의 워드마크 낱말만 가운데 정렬, 문장보다 두 배쯤 크게.

## 질감과 모양
- 그레인 0.06(초당 12번), 비네트 0.35. 어둠이 살짝 필름처럼 보이게.
- 얼굴 카드·영상 카드: 모서리 `--u` × 1.4, 얇은 흰 테두리(15%), 아래로 부드러운 그림자 한 겹.
- 채팅 판은 반투명 초록 유리 + 블러, 모서리 `--u` × 1.8.
- 이름표는 완전한 알약 모양, 커서는 작은 삼각 화살.
- 워드마크 획은 두께가 고르고 끝이 둥근 흰 선(짧은 변의 2.5%).

## 움직임
- 110BPM, 보통 속도. 들어오는 건 `power3.out` 으로 미끄러지듯 와서 부드럽게 멈춰요.
- 커서는 장면 내내 쉬지 않고 떠돌아요. 각자 3~5초 주기로 짧은 변의 2~4%만큼, 서로 다른 위상으로.
- 문장은 줄마다 아래에서 살짝 올라오며 나타나고, 청록 낱말은 마지막에 색이 들어와요.
- 한 장면은 2~3초 머물러요. 끝 장면들은 조금 더 길게(3초).

## 전환
- 휙(whip)이 기본: 화면 전체가 옆으로 흐름 흐림을 끌며 넘어가요. 커서와 이름표는 다른 요소보다 조금 늦게 따라가 꼬리가 길어져요.
- 문장으로 바짝 파고드는 확대 + 흐림(blur)으로 마지막 장으로 넘어가고, 워드마크 화면 사이에는 컷.
- 장면 쌓기: whip → blur → cut.

## 대표 장면

1. 흰 획이 낱말을 짓는 오프닝
   ```
   // 낱말 윤곽을 굵은 stroke path 몇 개로 나눠 두고, 획마다 날아들며 그려짐
   const strokes = S.$$('.mark path');           // stroke-linecap: round
   S.ambient(t => {
     strokes.forEach((p, i) => {
       const k = M.ease.outCubic(M.prog(t, .6 + i * M.beat(1), .5));
       M.draw(p, k);
       M.place(p, 0, 0, {o: k > 0 ? 1 : 0, blur: (1 - k) * 3});
     });
   });
   // 뒤에서 흐린 원 3~4개가 M.drift 로 아주 천천히
   ```
2. 문장 둘레를 떠도는 이름표 커서 떼
   ```
   const tags = S.$$('.tag');   // 화살 + 파스텔 알약
   S.ambient(t => tags.forEach((g, i) => {
     const [x0, y0] = home[i], ph = i * 1.7, T = 3 + i * .5;
     const k = M.spring(t - (.2 + i * .12), 'smooth');
     M.place(g, x0 + Math.sin(t * 2 * Math.PI / T + ph) * U * 3,
                y0 + Math.cos(t * 2 * Math.PI / T + ph) * U * 2, {o: k, s: .8 + k * .2});
   }));
   // 다음 장면으로는 S.tr.whip
   ```
   장면 쌓기에서는 deco cursor 가 커서를 강조 낱말로 데려가고, marker color 가 끝 낱말을 청록으로 물들여요.
3. 얼굴 카드 줄 서기 → 영상 카드와 채팅
   - 얼굴 카드 3장을 오른쪽 화면 밖에서 `M.anim([[0, W * 1.1], [t0 + i * .15, x_i, {d: .6, e: 'outCubic'}]], t)` 로 밀어 넣고, 움직이는 동안 `blur` 3px. 커서 하나가 가운데 카드 아래로 와서 멈춰요.
   - 다음 장면은 영상 카드 한 장만 남기고 그 아래 유리 판에 말풍선 i 를 `M.place(b, x, y_i, {o: k})`, `k = M.spring(t - ti, 'smooth')` 로 하나씩. 바닥에는 점 세 개 알약이 `1 + sin(t * 6) * .05` 로 맥박쳐요.
4. 빛 고리에서 솟는 화살표
   ```
   // 문장으로 바짝 파고들며(S.tr.blur) 넘어온 뒤
   const r = M.ease.outCubic(M.prog(t, .2, .5));
   M.place(ring, cx, H * .82, {s: r, o: r});           // 납작한 청록 타원
   const y = M.anim([[0, H * .8], [.6, H * .25, {d: 1.4, e: 'inOutCubic'}]], t);
   M.place(arrow, cx + Math.sin(t * 3) * U * 1.5, y);
   M.draw(trail, M.prog(t, .6, 1.4));                   // 보라→하늘 물결 꼬리 path
   // 옅은 격자 네모(SVG 선 6×6)는 화살표가 지나갈 때 o .15 → .4
   ```
   마지막은 컷으로 빈 어둠, 오프닝과 같은 흰 획이 낱말을 다시 지어 처음과 끝을 이어요.

- 이름표 안에는 짧은 인사나 이름 정도만 넣어요. 사람 얼굴 카드는 실제 참여자 사진이나 일러스트로 바꿔 써요.
