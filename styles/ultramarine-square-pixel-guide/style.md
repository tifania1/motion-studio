# 울트라마린 정사각 씨앗 (그래픽·도형)

한 줄: 옅은 회색 위 파란 정사각형 하나가 씨앗이 되어 격자로 불어나고, 둥근 픽셀 칸으로 쪼개져 원과 글자를 짓고, 블록 커서가 되어 글을 친 뒤 화면을 파랗게 덮는 담백한 브랜드 가이드 필름.

## 보는 느낌
- 옅은 회색 바탕에 쨍한 울트라마린 하나. 화면의 모든 것이 이 파란 정사각형 하나에서 태어나고 마지막에 다시 그 하나로 돌아와요.
- 여백이 아주 넓어요. 첫 장면은 화면 짧은 변의 4분의 1쯤 되는 사각형 하나뿐이고, 몇 초 동안 그대로 둬도 괜찮아요.
- 사각형은 같은 크기로 복제되어 격자를 이루거나, 작은 둥근 사각 칸으로 쪼개져 픽셀 원·픽셀 글자(네모 칸과 동그라미 칸을 섞어 짠 글자)가 돼요.
- 큰 글자 장면에서는 글자를 화면보다 크게 키워 가장자리에서 잘라 쓰고, 한쪽 귀퉁이에 파란 사각형을 걸쳐 둬요. 큰 기호 하나(@ 같은)를 파란 판 가운데 꽉 차게 두기도 해요.
- 중간에 짧은 막간이 있어요. 숯빛 판 위 아이콘 격자, 앱 화면, 고정폭 문자 디더로 그린 사진처럼 시스템이 실제로 쓰이는 모습이 1~2초씩 컷으로 지나가요.

## 색
- 회색 바탕 #EBEBEA 70 · 파랑 #1E14E6 22 · 먹색 글자 #141414 8.
- 장면 바탕은 회색 → 파랑 → 회색 → 숯빛 #1C1C1E 순으로 돌려요. 파란 판 위 글자와 도형은 회색 #EBEBEA.
- 활자 견본의 깔린 글자는 연보라 #A9A5F3. 켜진 글자만 파랑으로 바꿔요.
- 분홍 #E9A3C9 는 사각형 색이 바뀔 수 있다는 걸 보여 주는 한 장면에서만 잠깐.

## 글자
- 둥글고 기하학적인 산세리프(Geist + Noto Sans KR). 제목 500, 자간 −0.02em. 너무 굵지 않게, 반듯하고 단정하게.
- 로고타입처럼 쓰는 낱말은 소문자, 왼쪽에 작은 파란 사각형을 붙여요. 세 낱말을 세로로 쌓아 오른쪽 가장자리에서 잘리게 두기도 해요.
- 굵기 목록은 기울인 글자로 가는 것부터 굵은 것까지 6줄. 같은 목록을 Geist Mono 기울임으로 한 번 더 보여 주면 서체 가족이 넓다는 걸 말할 수 있어요.
- 마지막 문장은 짧은 변의 3% 정도로 아주 작게, 가운데 두 줄.

## 질감과 모양
- 질감 없이 납작하게. 그림자·빛 번짐·그라디언트를 쓰지 않아요.
- 정사각형과 픽셀 칸은 모서리를 아주 살짝만 굴려요(0.4u). 픽셀 칸 사이 틈은 칸 크기의 15~20%.
- 선은 거의 쓰지 않아요. 모양은 모두 칠한 면으로.

## 움직임
- 110BPM, 보통 빠르기. 큰 변화는 2박마다, 픽셀 칸 깜빡임은 반 박 단위.
- 도형이 옮겨 갈 땐 `power3.inOut` 으로 출발과 멈춤을 모두 부드럽게. 튕기지 않아요.
- 픽셀 칸은 서서히 나타나지 않고 켜짐·꺼짐 두 상태로만 바뀌어요. 가운데에서 바깥으로 거리 순서대로 켜면 원이 '지어지는' 느낌이 나요.
- 활자 견본 끝 장면만 예외로, 글자마다 다른 기울기로 통통 튀어요.
- 한 장면은 2~3초 머물러요. 처음과 끝 정사각형 장면은 3초 넘게 가만히 둬도 좋아요.

## 전환
- 컷이 기본. 사각형이 커져 화면을 덮는 와이프(wipe)로 회색에서 파랑으로 넘어가고, 픽셀 칸이 한꺼번에 켜졌다 꺼지는 블록 전환(blocks)으로 다음 장면을 열어요.
- 장면 쌓기: cut → blocks → wipe.

## 대표 장면
1. **씨앗 사각형이 격자로 불어남**
   ```
   // 가운데 사각형 하나 → 5×3 격자. 모든 칸이 가운데서 출발해 제자리로
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, M.beat(4), .6));
     cells.forEach((c, i) => {
       const [gx, gy] = grid[i];
       M.place(c, cx + (gx - cx) * k, cy + (gy - cy) * k, {o: i === mid ? 1 : (k > 0 ? 1 : 0)});
     });
   });
   ```
   이어 픽셀 원: 원 안에 드는 칸만 골라 가운데서의 거리 d 로 켜는 시각을 정해요. `c.style.opacity = t > t0 + d * .004 ? 1 : 0` 처럼 켜짐·꺼짐 두 상태로만. 몇 칸은 `M.rng(시드)` 로 반 박마다 꺼졌다 켜져 원 속에 무늬가 숨 쉬게 해요.
2. **블록 커서로 쳐서 화면 덮기**
   ```
   const s = M.type(text, t, t0, 14);              // 한 자씩
   label.textContent = s;
   const x = label.offsetLeft + label.offsetWidth;  // 글 끝에 붙는 파란 사각형
   const k = M.ease.inOutCubic(M.prog(t, t0 + text.length / 14 + M.beat(1), .6));
   M.box(cursor, {x: x * (1 - k), y: cy0 * (1 - k), w: h + (W - h) * k, h: h + (H - h) * k});
   ```
   장면 쌓기에서는 title: type 으로 같은 결의 타자가 나오고, 다음 장면은 accent(파란 판)으로 이어져요.
3. **활자 견본 속 켜지는 글자**
   - 연보라 글자 판(Aa Bb … 0–9)을 깔고, `const i = M.at(keys.map((g, n) => [t0 + n * M.beat(.5), n]), t)` 로 반 박마다 글자 하나만 파랑·굵기 700 으로.
   - 파란 판으로 컷: 굵기 목록 6줄을 한 박마다 한 줄씩 `M.anim` 으로 아래에서 1u 올리며 놓아요.
   - 끝: 글자마다 `M.spring(t - ti, 'bouncy')` 로 튀고 기울기는 `M.rng(n)() * 24 - 12` 도. 흩어진 뒤 `S.tr.blocks` 로 다음 장면.
4. **막간을 지나 하나로 돌아오기**
   - 숯빛 판(paper)에서 아이콘 격자와 앱 화면을 1~2초씩 컷으로. 이어 파란 판 위 회색 사각형 셋이 가로로 미끄러져 지나가요(`x = M.anim([[t0, W * 1.1], [t0, -W * .1, {d: 1.2, e: 'inOutCubic'}]], t)`).
   - 회색 판에 작은 두 줄 문장 → 컷 → 파란 로고타입 → 컷 → 처음과 같은 자리, 같은 크기의 파란 정사각형 하나. 이 마지막 장면은 3초 동안 움직이지 않게 둬요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 리뉴얼·아이덴티티 공개, 디자인 시스템·가이드 소개, 개발자 플랫폼 런칭, 새 서체·아이콘 세트 소개, 차분한 기업 소개.
- 피할 것: 그라디언트와 빛 번짐, 종이·그레인 같은 거친 질감, 강조색 여러 개(파랑 하나에 연보라·분홍은 아주 잠깐), 기울어진 3D 카메라.
- 씨앗 도형은 자기 브랜드의 기본 도형으로 바꿔 써요. 원본 마크를 그대로 옮기지 않아요.
