# 미색 프롬프트 열화상 컷 (제품 UI)

한 줄: 따뜻한 미색 바탕의 흰 입력창에 문장이 쳐지면 그 말대로 지은 앱 화면이 2초마다 컷으로 이어지고, 사이사이 열화상처럼 엉켜 흐르는 판 위에 검은 알약 버튼 하나가 떠서 눌려요.

## 보는 느낌
- 기본 무대는 따뜻한 미색 바탕이에요. 가운데에는 작은 글 한 줄이나 흰 입력창 하나만 두고 둘레를 넓게 비워요.
- 입력창에 문장이 쳐지면 바로 그 말대로 지은 앱 화면이 컷으로 이어져요. 사진을 꽉 깐 첫 화면, 들여쓴 파일 트리, 색 칩이 박힌 달력, 폰 화면, 완료 화면이 2초 안팎으로 바뀌어요.
- 사이사이 숯빛 판(고정폭 코드, 연두 화살표와 커서 막대, 작은 동그라미 격자)이나 흑백 접사 사진이 한 컷씩 끼어 숨을 골라요.
- 중반부터는 열화상처럼 주황·노랑·분홍·하늘이 엉켜 흐르는 판, 무지갯빛으로 흐린 판, 복숭앗빛에서 청록으로 내려가는 수평선 판이 바탕이 되고, 그 위에는 검은 알약 버튼이나 흰 대화 상자 하나만 떠요.
- 끝은 다시 미색. 작은 무지갯빛 구슬 하나가 주황 테두리 알약 낱말로 바뀌며 조용히 닫혀요.

## 색
- 미색 바탕 60 · 앱 화면과 사진 25 · 먹색 글자 10 · 주황 5.
- 바탕 #E7E3DD, 글자 #1C1C1B, 흐린 글자는 먹색 60%.
- 숯빛 막간 판 #252524, 그 위 글자 #EDEBE6. 코드 속 강조와 화살표는 연두 #C9DC5A.
- 주황 #E8742A 는 달력의 고른 칩, 버튼, 엔딩 알약 테두리에만. 주황 위 글자는 짙은 먹색.
- 달력 칩: 연두 #C9DC5A · 하늘 #A9CBEA · 베이지 #E9DCC4 · 주황 #E8742A.
- 열화상·무지개 판: 주황 #F08A2E, 노랑 #F6D35A, 분홍 #F2B8C6, 하늘 #A9CBEA, 연보라 #CBB8F0 를 크게 흐려 섞어요.

## 글자
- 본문과 제목은 Geist(한글은 Noto Sans KR Medium·Bold). 작은 문장은 짧은 변의 3~4%, 굵기 400~500. 꺾쇠 < > 로 낱말을 감싸 코드 냄새를 살짝 풍겨요.
- 앱 화면 제목은 Geist 600, 자간 −0.03em. 부제와 파일 트리, 코드, 날짜는 Geist Mono 400 으로 작고 옅게.
- 사진 위 큰 두 낱말: Geist 600, 자간 −0.04em, 짧은 변의 20% 안팎. 두 낱말 사이에 작은 원형 아이콘을 끼우고 양 끝은 화면 밖으로 잘리게 둬요.
- 연결 문장은 낱말마다 1px 테두리 알약에 담아요(예: [연결] ⊕ [일정]).

## 질감과 모양
- 미색 판은 질감 없이 매끈해요. 색은 열화상·무지개 판에만 몰아서, 큰 덩어리를 아주 흐리게 섞어 칠해요.
- 입력창: 흰색, 모서리 1.6u, 아주 옅은 그림자 한 겹. 오른쪽 위에 검은 정사각 화살표 버튼, 아래에 + 와 마이크 아이콘.
- 알약 버튼: 검정 바탕 흰 글자, 모서리 0.6u. 테두리 알약: 1px 먹색(엔딩만 주황).
- 빗금 조각: 길이 1.2u, 굵기 2px 의 먹색 사선.
- 앱 화면은 테두리 없이 화면에 꽉 차거나, 모서리 1.2u 카드로 떠 있어요.

## 움직임
- 112BPM. 장면은 2박에서 4박, 대부분 박에 맞춰 컷.
- 들어올 땐 expo.out 으로 확 자리 잡고, 나갈 땐 따로 움직이지 않고 컷.
- 타자는 초당 18~22자, 끝에 커서 막대가 반 박 간격으로 깜빡여요.
- 빗금 조각은 가운데서 바깥으로 1~2u 튀며 15~30도 돌고, 0.5초 뒤 사라져요.
- 커서는 부드럽게 와서 누르고, 버튼은 0.94배로 눌렸다 0.15초 만에 돌아와요.
- 열화상 판의 색 덩어리는 8초 주기로 천천히 흘러요. 파일 트리는 줄마다 0.06초씩 늦게 펼쳐져요.

## 전환
- 컷이 기본이에요. 미색에서 열화상·무지개 판으로 넘어갈 때만 흐림(blur)으로 번지듯 잇고, 마지막 구슬 장면은 페이드로 닫아요.
- 장면 쌓기: cut → blur → cut → fade.

## 대표 장면

1. **꺾쇠 낱말과 튀는 빗금**
   ```
   // 가운데 '< 만들기 >' 한 줄, 둘레에 사선 조각 8개
   const r = M.rng(7);
   S.$$('.slash').forEach((s, i) => {
     const a = i / 8 * Math.PI * 2 + r() * .4;
     const k = M.ease.outExpo(M.prog(t, .1 + i * .03, .5));
     M.place(s, cx + Math.cos(a) * (6 + k * 2) * u, cy + Math.sin(a) * (4 + k * 2) * u,
             {rot: a * 57 + k * 25, o: 1 - M.prog(t, .6, .2)});
   });
   ```
2. **입력창 타자 → 앱 화면 컷**
   - 흰 입력창을 `M.place(box, cx, cy, {s: .96 + M.spring(t, 'smooth') * .04})` 로 띄우고 안의 글은 `M.type(text, t, .3, 20)`. 화살표 버튼을 `M.Cursor` 로 누른 박에 컷.
   - 이어서 앱 화면 판 4~5장을 겹쳐 두고 `M.at([[0, 0], [M.beat(2), 1], [M.beat(4), 2], …], t)` 로 한 장만 보이게 해요. 사진 판에는 아이콘 낀 큰 두 낱말을 `M.place(word, x, cy)` 로 걸고 x 를 4초에 짧은 변의 3%만 흘려요.
   - 장면 쌓기에서는 title: type + frame: card 로 같은 결이 나와요.
3. **열화상 판 위 검은 버튼**
   ```
   S.tr.blur();                                   // 미색에서 번지듯 넘어감
   S.ambient(t => {
     blobs.forEach((b, i) => M.place(b, ...M.drift(i, t, {period: 8, r: 12 * u}),
                                     {s: 1.6, blur: 10 * u}));
     const press = M.cursorAt(cursor, btn, t, M.beat(2));   // 커서가 와서 누름
     M.place(btn, cx, cy, {s: 1 - press * .06});
   });
   ```
   - 흰 대화 상자일 때는 오른쪽 아래 작은 주황 버튼을 같은 방식으로 눌러요.
4. **구슬이 알약 낱말로**
   - 미색 위 작은 원에 `radial-gradient` 로 분홍·하늘·연보라를 섞고 `blur(.4u)`. 2박 뒤 `M.box(pill, {w: M.anim([[0, 2 * u], [tA, 9 * u, {d: .5, e: 'outExpo'}]], t)})` 로 가로로 늘려 알약이 되며, 안쪽 색은 빠지고 1px 주황 테두리와 낱말만 남아요.
