# 보라 활동 격자 매크로 훑기 (제품 UI)

한 줄: 어두운 판에 카메라가 바짝 누워 비스듬히 미끄러져요. 화면보다 큰 요일 머리글자가 지나가고, 빈 칸들이 물결처럼 보라로 켜지며, 툴팁 하나가 뜬 뒤 평면 카드로 물러나는 조용한 데이터 UI 필름.

## 보는 느낌
- 거의 검은 숯빛 판 하나가 무대예요. 그 판 위에 어두운 둥근 칸이 촘촘히 깔려 있고, 카메라는 판에 거의 닿을 듯 낮은 각도로 비스듬히 누워 있어요.
- 초점이 아주 얕아요. 화면 가운데 띠만 선명하고 앞쪽 칸과 먼 쪽 칸은 부드럽게 흐려서, 작은 UI 조각이 큰 사물처럼 보여요.
- 처음엔 회색 요일 머리글자만 크게 지나가고, 이어 칸들이 보라로 켜지며 화면이 밝아져요. 보라가 화면의 절반 가까이 차는 순간이 가장 화려하고, 그 뒤로는 다시 덜어내요.
- 마지막엔 카메라가 빠져 평면 카드 하나(작은 이름표, 제목 한 줄, 가로로 긴 격자)를 보여 주고, 빈 화면 왼쪽에 흰 두 줄 문장, 가운데 작은 마크로 닫아요.

## 색
- 숯빛 바탕 65 · 꺼진 칸과 카드 20 · 보라 12 · 흰 글자 3.
- 바탕 #1E1E21, 카드 #2A2A2E, 꺼진 칸 #2C2C30.
- 보라는 한 색을 세 농도로만 써요: 짙은 #6A4BE0 · 보통 #8B6CF0 · 옅은 #B29BF7. 켜진 칸 둘레에 보라 빛 번짐(glow 42%) 한 겹.
- 요일 머리글자는 옅은 회색(흰색 70~80%), 문장은 흰색 #ECECEE.
- 툴팁은 바탕보다 더 짙은 #141416 에 흰 글자, 보라는 넣지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold) 하나로 통일. 기하학적이고 담백한 산세리프.
- 요일 머리글자: Geist 500, 판에 눕혀 원근으로 아주 크게. 읽는 글자라기보다 판 위 표지처럼 써요.
- 마무리 문장: 500, 짧은 변의 6% 안팎, 왼쪽 정렬 두 줄, 줄 간격 1.15, 자간 −0.01em. 화면 왼쪽 3분의 1에 둬요.
- 툴팁: 위 줄 500, 아래 줄 400, 가운데 정렬, 짧은 변의 3%쯤.
- 큰 굵은 제목은 쓰지 않아요.

## 질감과 모양
- 그레인 0.05, 비네트 0.34. 가장자리가 어둡게 가라앉아 가운데 초점 띠로 눈이 모여요.
- 칸: 모서리를 넉넉히 둥글린 정사각형(칸 한 변의 22%), 칸 사이 간격은 한 변의 25%. 꺼진 칸은 바탕보다 아주 조금 밝게만.
- 켜진 칸은 위로 살짝 솟고(translateZ) 위쪽 면이 약간 더 밝은 그라디언트, 둘레에 보라 빛.
- 카드: 모서리 1.2u, 테두리 없이 바탕보다 한 단계 밝은 면. 그림자도 거의 없어요.
- 깊이 흐림은 질감이 아니라 카메라 효과라서 장면 안에서 칸마다 거리 따라 blur 를 줘요.

## 움직임
- 80BPM, 느림. 카메라는 한 장면 내내 같은 방향으로 일정하게 미끄러지고(power2.inOut 으로 시작과 끝만 부드럽게), 멈칫하거나 튀지 않아요.
- 칸 켜짐: 왼쪽 앞줄부터 대각선 물결로 0.06초 간격, 칸 하나는 0.35초에 0 → 보라로 차오르며 0.1u 솟아요.
- 툴팁: 칸이 밝아진 뒤 반 박 늦게 아래에서 1u 떠오르며 흐림에서 선명으로(0.4초), 두 박 머물러요.
- 장면 하나는 4~6초로 길게 머물러요. 문장과 마크도 2~4초씩 충분히 보여 줘요.

## 전환
- 흐림 전환(blur)이 기본: 초점이 풀리며 다음 장면이 맺혀요. 매크로 판에서 평면 카드로 갈 땐 카메라가 위로 빠지는 움직임 자체가 전환이에요.
- 문장 → 마크는 느린 페이드, 영상 시작은 검정에서 페이드인. 장면 쌓기: blur → fade → cut.

## 대표 장면
1. **누운 판 위 거대한 요일 글자**: 판(div)을 `perspective: 90u` 부모 안에 두고 `rotateX(58deg) rotateZ(-22deg)` 로 눕혀요. 판 왼쪽 가장자리에 요일 머리글자를 세로로 크게 늘어놓고, 카메라 이동은 판의 translate 로.
   ```
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, 0, 4));
     board.style.transform = `rotateX(58deg) rotateZ(-22deg) translate(${-k * 30}u, ${k * 12}u)`;
     S.$$('.wk').forEach(el => {                 // 화면 가운데에서 멀수록 흐리게
       const d = Math.abs(M.rect(el).cy - H / 2) / H;
       el.style.filter = `blur(${M.clamp((d - .12) * 14, 0, 6)}px)`;
     });
   });
   ```
2. **물결처럼 켜지는 보라 칸**: 칸 i 의 열·행으로 지연 `di = (col + row * .6) * .06` 을 만들고, 농도는 `M.rng(시드)` 로 세 단계 중 하나를 미리 정해요.
   ```
   cells.forEach((c, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + delay[i], .35));
     c.style.background = M.color('#2C2C30', tone[i], k);
     c.style.transform = `translateZ(${k * .1}u)`;
     c.style.boxShadow = `0 0 ${k * 1.6}u var(--glow)`;
   });
   ```
   카메라(판 translate)는 켜지는 앞줄을 따라 같은 속도로 미끄러지고, 장면 끝으로 갈수록 각도를 조금 세워 가로로 긴 띠 전체가 보이게 해요.
3. **툴팁 하나와 위로 빠지기**: 고른 칸 하나만 `M.color(tone, '#B29BF7', k)` 로 밝히고, 툴팁을 `M.place(tip, x, y - (1 - k2) * u, {o: k2, blur: (1 - k2) * 4})`, `k2 = M.spring(t - tT, 'smooth')`. 두 박 뒤 판의 rotateX 를 `M.anim([[tP, 58], [tP + 1.6, 0, {d: 1.6, e: 'inOutCubic'}]], t)` 로 0까지 세우고 scale 을 줄여 카드 속 작은 격자로 정착시켜요(카드 이름표·제목은 그 뒤 페이드인).
4. **흐림으로 맺히는 문장과 마크**: `S.tr.blur` 로 넘어가 왼쪽 정렬 두 줄 문장을 장면 쌓기 title: blur 로 어절마다 흐림에서 선명하게. 이어 페이드로 빈 판 가운데 작은 마크 하나, 마크 옆 보라 칸 하나가 마지막으로 한 번 켜지면 처음 격자와 이어져요.

- 피할 것: 밝은 바탕, 강조색 여러 개(보라 한 가지를 농도로만), 빠른 컷과 튀는 이징, 굵고 큰 제목, 손그림·종이 질감.
- 한 영상에 보여 줄 UI 는 하나로 좁혀요. 같은 격자를 가까이·멀리 여러 거리에서 보여 주는 게 이 결의 힘이에요.
