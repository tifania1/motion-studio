# 대화창에서 점 세계로 (다이어그램·데이터)

한 줄: 밝은 회색 메신저 화면에 다급한 질문이 쌓이다가, 화면이 어두워지며 점·망점·문자 가루로 짠 흑백 데이터 세계로 들어가요. 작은 문장은 계단처럼 어절씩 놓이고, 끝에는 다시 밝은 대화창에 고정폭 표 하나가 답으로 놓여요.

## 보는 느낌
- 두 세계를 오가는 이야기예요. 밝은 세계는 연회색 메신저 화면(왼쪽 옅은 목록, 가운데 메시지와 입력창), 어두운 세계는 숯빛 바탕 위 점과 망점, 기호 문자로 짠 덩어리.
- 어두운 세계에서 글은 늘 작아요. 화면 높이 3~4% 문장 하나가 넓은 어둠 한가운데나 계단처럼 흩어져 놓이고, 둘레를 점 덩어리가 무늬처럼 채워요.
- 점 덩어리는 모양을 바꿔 가며 이야기를 받쳐요: 흐르는 망점 물결 → 네모 점 묶음 → 점으로 쌓은 피라미드 → 원통(데이터 저장소) → 기호로 짠 동심 호 → 만화경 같은 점 무늬.
- 중간에 고정폭 표와 가는 선 그래프가 빽빽한 터미널 화면이 잠깐 지나가고, 마지막엔 다시 밝은 대화창으로 돌아와 표 하나로 답해요.

## 색
- 흑백만 써요. 어두운 장면: 숯빛 바탕 #1A1A1A 80 · 점·문자 가루(흰색 20~70%) 15 · 흰 글자 5.
- 밝은 장면: 연회색 #EDEDEB 80 · 먹색 글자 #1D1C1D 15 · 옅은 회색 선 5. 메시지 속 이름표 정도의 아주 작은 색만 허용.
- 강조는 흰 상자 #EDEDED 에 어두운 글자 #141414 로 낱말 하나를 뒤집거나, 흰 밑줄 한 줄.
- 빛 점(반짝임)만 순백 #FFFFFF 에 짧은 십자 빛살.

## 글자
- 문장: Geist 400(한글 Noto Sans KR Medium), 작고 가볍게, 화면 높이 3~4%. 큰 제목은 쓰지 않아요.
- 질문 꼬리표·표·마무리 한 줄: Geist Mono 400, 더 작게(2~2.5%). 꼬리표는 흰색 35% 글자에 아주 옅은 회색 상자.
- 계단 배치: 어절마다 한 줄씩 내려가며 오른쪽으로 밀려요(1줄 왼쪽 → 2줄 왼쪽 → 3줄 가운데 → 4줄 오른쪽). 줄 간격은 글자 높이의 2배 가까이 넉넉히.
- 대화창 안 글씨는 메신저처럼 굵은 이름 + 보통 본문.

## 질감과 모양
- 그레인 0.1(초당 12번), 비네트 0.35. 어두운 세계가 화면 속 화면처럼 살짝 거칠어요.
- 점은 네모 픽셀(1~3px)과 둥근 망점 두 가지. 덩어리는 가운데가 밝고 가장자리로 갈수록 성기게.
- 모서리 각은 작게(0.6u). 그림자·유리·그라디언트 없이 평평하게.
- 빛 점은 작은 흰 점에 가로·세로 빛살 두 줄과 옅은 번짐.

## 움직임
- 96BPM, 보통 빠르기. 들어오는 건 power3.out 으로 부드럽게 멈추고, 머무는 시간이 길어요(문장 하나에 2~3초).
- 메신저 메시지는 한 박마다 아래에 하나씩 붙고 위 메시지들은 한 칸 밀려 올라가요. 카메라는 그동안 4초에 걸쳐 5~8% 다가가요.
- 계단 문장은 어절마다 0.4박 간격으로 opacity 0 → 1, 2u 위에서 내려앉음.
- 점 덩어리는 늘 아주 천천히 흘러요(물결 이동, 원통·피라미드는 y 축으로 느린 회전, 동심 호는 서로 반대 방향으로 회전).
- 기호 문자는 자리마다 무작위로 다른 기호로 바뀌며 반짝여요(초당 6~8번).

## 전환
- 밝은 세계 → 어두운 세계: 화면이 회색으로 바래며 흐려졌다가 어둠 속 점 무늬로 맺히는 흐림 전환(blur). 다시 밝은 세계로 돌아올 때도 같은 결.
- 어두운 장면끼리는 컷이나 느린 페이드. 점 덩어리가 흩어졌다 다음 모양으로 모이는 식으로 이어도 좋아요.
- 장면 쌓기: blur → cut → fade.

## 대표 장면
1. **질문이 쌓이는 대화창 → 바래며 어둠으로**
   ```
   // 메시지 i 가 박마다 붙고, 카메라는 천천히 다가감
   msgs.forEach((m, i) => {
     const k = M.spring(t - M.beat(i), 'smooth');
     M.place(m, 0, yOf(i, t), { o: k });
   });
   M.place(chat, cx, cy, { s: 1 + .07 * M.prog(t, 0, 4) });
   // 끝에서 회색으로 바래며 흐림 → 어두운 점 장면
   S.tr.blur(chatScene, dotScene, { at: tEnd, d: .8 });
   ```
2. **망점 물결 위 계단 문장과 뒤집히는 낱말**
   - 망점 덩어리: 점 판 캔버스에서 각 점 크기를 `size = f(x + t * 20, y)` 같은 부드러운 물결 값으로 정함(S.ambient 안).
   - 옅은 질문 꼬리표(고정폭)는 `M.drift` 로 가장자리를 가로로 천천히 미끄러짐.
   - 어절 w_i 를 계단 자리에 두고 `M.place(w, x_i, y_i, { o: M.ease.outCubic(M.prog(t, t0 + i * M.beat(.4), .4)) })`. 마지막 낱말은 0.3초 뒤 흰 상자 뒤집기(`marker: highlight`) 또는 밑줄을 `M.draw` 로.
3. **점으로 쌓은 원통·피라미드와 빛 점**
   - 원통은 타원 고리 8~10층을 점으로 찍고 고리마다 각도를 `t * .3` 씩 돌림. 피라미드는 층마다 점 수를 줄여 쌓음.
   - 빛 점 5~7개를 `M.at` 으로 박마다 하나씩 켜고 0.6초에 걸쳐 빛살 길이를 줄이며 끔. 가운데에 작은 문장 한 줄.
4. **기호 동심 호 + 고정폭 한 줄**
   ```
   // 호마다 기호를 늘어놓고 반대 방향으로 천천히 회전, 기호는 무작위로 갈아 끼움
   const G = [':', "'", 'I', 'V', 'S', '$', '.'];
   S.ambient(t => arcs.forEach((a, j) => {
     a.rot = (j % 2 ? -1 : 1) * t * 4;
     a.chars.forEach((c, n) => c.textContent = G[Math.floor(M.rng(n * 31 + Math.floor(t * 7))() * G.length)]);
   }));
   // 가운데 고정폭 한 줄: 쳐지는 자리 앞에 무작위 글자 하나가 떠서 따라감
   line.textContent = M.type(text, t, t0, 14);
   ```
   장면 쌓기에서는 title: type, number: scramble 로 같은 결이 나와요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 데이터·분석 도구 소개, AI 질의응답 서비스, 업무 메신저 연동 기능, 문제에서 해결로 가는 이야기형 런칭, 개발자·분석가 대상 영상. 40~70초 긴 호흡에 잘 맞아요.
- 피할 것: 원색 강조색, 따뜻한 종이 질감, 굵고 큰 제목, 빠른 컷 몽타주, 둥글고 통통 튀는 등장.
- 메신저 화면은 우리 엔진의 uidemo 결로 새로 그리고, 실제 앱 모양을 그대로 따라 그리지 않아요.
