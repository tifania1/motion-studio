# 진주 소품 계획 체크리스트 (제품 UI)

한 줄: 따뜻한 잿빛 분홍 바탕에 굵은 둥근 산세리프 한 줄이 놓이고, 무지갯빛 진주 소품 사이로 유리 입력창에 부탁이 쳐져요. 이어 세로 체크리스트가 한 단계씩 초록 체크로 차오르는 차분한 일 맡기기 UI 필름이에요.

## 보는 느낌
- 바탕은 분홍기가 살짝 도는 따뜻한 잿빛 하나예요. 장면마다 가운데에 놓인 요소는 하나뿐이고, 둘레는 넉넉히 비워 둬요.
- 처음과 끝은 짙은 올리브 판이에요. 가운데에 흰 굵은 이름, 위에 작은 알약 꼬리표, 아래에 아주 작은 안내 글을 둬요.
- 무지갯빛 진주 3D 소품(말풍선, 가방, 탈것처럼 일상 물건)은 늘 화면 귀퉁이에서 반쯤 잘린 채 떠 있어요. 주인공은 가운데의 입력창이나 목록이에요.
- UI는 아주 담백해요. 유리 입력창, 세로 체크리스트, 결과 카드 하나, 브라우저 창 하나. 각각 한 화면에 하나씩만 보여요.
- 사진을 쓸 때는 모서리가 둥근 사진 타일 서너 장을 화면 가장자리에 흩어 놓고, 가운데 작은 글 한 줄로 결과를 알려요.

## 색
- 잿빛 분홍 바탕 #EAE4E1 75 · 짙은 회갈색 글자 #46403F 15 · 올리브 판 #4B4C43 7 · 초록 체크와 진주빛 3.
- 올리브 #4B4C43 은 여는 판과 닫는 판의 바탕으로, 그 위 글자는 #F3EFEB.
- 체크 원은 연초록 #BFE3C4 에 짙은 초록 체크. 확인 표시에만 써요.
- 보내기 버튼과 커서는 거의 검정 #2E2B2A.
- 진주 소품은 흰빛 바탕에 라벤더 #D9CCEB, 하늘, 살구가 얇게 비쳐요. 그림자는 아주 옅게.

## 글자
- Geist(한글은 Noto Sans KR Bold). 헤드라인은 700, 자간 −0.03em 으로 빽빽하고 둥글게 보여요. 크기는 짧은 변의 10~12%, 가운데 정렬 한두 줄.
- UI 글자는 Geist 500·Noto Sans KR Medium, 짧은 변의 2.5~3.5%. 체크리스트 단계 이름은 굵게, 도구 칩 글씨는 더 작고 옅게.
- 헤드라인 색은 순검정보다 한 톤 부드러운 회갈색. 강조는 색을 바꾸는 대신 아이콘 칩을 낱말 사이에 끼워 넣는 방식으로 해요.

## 질감과 모양
- 질감 없이 매끈하게 둬요. 깊이는 진주 소품과 유리 입력창의 부드러운 그림자로만 내요.
- 입력창: 흰빛 반투명 유리, 1px 흰 테두리, 넓고 흐린 그림자, 모서리 `--u` × 2. 왼쪽 아래 작은 + 버튼, 오른쪽 아래 검은 동그라미 화살표 버튼.
- 체크리스트: 지름 1.6u 체크 원, 원 사이를 잇는 1px 회색 세로선, 테두리만 있는 알약 도구 칩(아이콘 + 짧은 말).
- 결과 카드는 흰 바탕에 왼쪽 작은 주황빛 아이콘 네모 하나, 모서리 1.4u.

## 움직임
- 96BPM, 보통 속도. 들어올 때는 `power3.out` 으로 부드럽게 멈추고, 화면 전체는 거의 가만히 있어요.
- 헤드라인은 어절이 아래에서 1u 올라오며 맺히고, 아이콘 칩은 0에서 1.1배로 톡 튀었다가 1배로 내려앉아요.
- 입력창 글은 초당 18~22자로 쳐지고, 쳐진 뒤 반 박 쉬었다가 커서가 버튼을 눌러요.
- 체크리스트는 한 단계에 2박. 스피너가 1박 돌고, 체크로 바뀌면서 도구 칩이 0.15초 간격으로 붙어요. 다음 단계가 생기면 목록 전체가 한 칸 위로 밀려요.
- 진주 소품은 6~8초 주기로 아주 천천히 떠다니며 빛 반사가 돌아요.
- 한 장면에 3~4초 머물러요.

## 전환
- 컷이 기본이에요. 올리브 판에서 잿빛 판으로, 체크리스트에서 결과 카드로 컷.
- 대기 화면에서 체크리스트로 넘어갈 때만 짧은 페이드를 써요. 결과 카드를 누른 뒤에는 브라우저 창이 옆에서 밀려 들어와요(push).
- 장면 쌓기: cut → fade → cut → push.

## 대표 장면

1. **진주 소품 사이의 유리 입력창**
   ```
   // 입력창은 가운데, 소품 둘은 귀퉁이에서 반쯤 잘린 채 천천히 떠다님
   const k = M.spring(t - t0, 'smooth');
   M.place(box, cx, cy + (1 - k) * u * 2, {o: k});
   txt.textContent = M.type(prompt, t, t0 + .4, 20);
   S.ambient(t => {
     M.place(propA, W * .86, H * .08, {r: Math.sin(t * .8) * 4, y: Math.sin(t * .9) * u});
     M.place(propB, W * .1, H * .92, {r: Math.cos(t * .7) * 5});
   });
   const c = new M.Cursor(cursorEl);
   c.go(sendBtn, tSend - .5, tSend);          // 반 박 쉬고 누르기
   if (M.cursorAt(t, tSend)) sendBtn.style.transform = 'scale(.92)';
   ```
   장면 쌓기에서는 card: glass 와 deco cursor·bubbles 가 같은 결을 내요.

2. **점 셋 대기 → 세로 체크리스트**
   ```
   // 대기: 점 셋이 서로 다른 위상으로 맴돎
   dots.forEach((d, i) => M.place(d, x0 + Math.cos(t * 3 + i * 2.1) * u * .5,
                                       y0 + Math.sin(t * 3 + i * 2.1) * u * .5));
   // 단계 i: 2박마다 하나씩
   steps.forEach((s, i) => {
     const ti = t1 + i * M.beat(2);
     const done = t > ti + M.beat(1);
     spin[i].style.opacity = done ? 0 : 1;      // 돌던 원호가
     check[i].style.opacity = done ? 1 : 0;     // 초록 체크로
     M.draw(line[i], M.ease.outCubic(M.prog(t, ti + M.beat(1), .4)));   // 다음 원까지 세로선
     chips[i].forEach((ch, j) => M.place(ch, 0, 0, {o: M.prog(t, ti + M.beat(1) + j * .15, .25)}));
   });
   // 진행 중인 줄은 글자에 옅은 빛 그라디언트가 왼→오로 훑고 끝이 바램
   ```

3. **결과 카드 클릭 → 브라우저 창**
   - 위에 짧은 완료 문장 한 줄, 아래 흰 결과 카드 하나. 커서가 카드로 와서 누르면 카드가 0.96배로 눌렸다 돌아오고, `S.tr.push` 로 브라우저 창 장면이 오른쪽에서 밀려 들어와요.
   - 브라우저 창 안에서는 왼쪽 대화 기록, 가운데 만들어진 문서 한 장만 보여 주고 카메라는 움직이지 않아요.

4. **아이콘이 끼어드는 헤드라인과 올리브 엔딩**
   ```
   const w = S.words(title);                   // 어절 나누기
   w.slice(0, 2).forEach((e, i) => S.fx.rise(e, t0 + i * .12));
   M.place(chip, 0, 0, {s: M.anim([[tC, 0], [tC + .25, 1.1], [tC + .4, 1]], t)});
   w.slice(2).forEach((e, i) => S.fx.rise(e, tC + .3 + i * .12));
   // 마지막: 컷으로 올리브 판, 흰 굵은 이름 + 위에 작은 알약 꼬리표
   ```
