# 한 기호, 여러 재료 (시네마틱)

한 줄: 화면 가운데 육각 기호는 자리를 지키고 몸만 연필 스케치·코드·빛 윤곽·빗금·그라디언트·사물 사진으로 박자마다 갈아입다가, 프롬프트 한 줄과 커서 손질을 거쳐 검은 화면 위 작은 마크로 맺히는 브랜드 공개예요.

## 보는 느낌
- 주인공은 화면 한가운데 기호 하나. 짧은 변의 25~35% 크기로 늘 같은 자리에 있어서, 바탕과 재료가 컷으로 바뀌어도 눈이 한 점에 머물러요.
- 처음 9초는 재료 릴레이예요. 회색 종이 사진 위 연필 스케치 → 코드 글자 위에 겹친 파란 윤곽 → 거의 검은 화면에서 희미하게 빛나는 윤곽 → 밝은 회색 판의 점선 구성 격자 위 가는 먹선 → 어둠 속 꼭짓점 앵커만 남은 선 → 파란 빗금으로 채운 기호 → 보라 그라디언트.
- 가운데 토막은 밝은 회색 판의 도구 화면: 큰 글씨 프롬프트, 파란 막대 커서, 파란 둥근 보내기 버튼, 흰 입력 카드.
- 결과는 실제 사물 위에 입혀 보여 줘요. 종이컵, 나무 벽에 걸린 액자 포스터, 흐린 그라디언트 카드. 사진은 1초 남짓만 머물러요.
- 끝은 다시 거의 검은 화면, 작은 기호와 그 아래 아주 작은 고정폭 낱말 하나. 여백이 화면 대부분을 차지해요.

## 색
- 검정 판 #121212 50 · 밝은 회색 판 #ECECEA 40 · 그라디언트와 파랑 10. 글자는 늘 판의 반대색.
- 파랑 #2F5FE6 은 막대 커서, 보내기 버튼, 선택 상자 선, 빗금 채움에만 써요. 버튼 위 글자·화살표는 흰색.
- 그라디언트는 기호 몸이나 한 장면 바탕에만 잠깐: 보라 #8A5CF0, 분홍 #E46A8E, 주황 #F08A4B, 청록 #8CC9D2.
- 사진 장면은 나무·스테인리스 색을 그대로 두고 다른 색을 얹지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium) 500, 자간 −0.02em. 프롬프트 문장은 짧은 변의 7~8%로 크게, 한 줄만.
- 입력 카드 안 글씨는 짧은 변의 2.5%. 옅은 회색 자리표시 글이 지워지고 먹색 입력이 쳐져요.
- 코드 조각과 마지막 낱말은 Geist Mono 400, 짧은 변의 2% 안팎으로 작게. 마지막 낱말은 일부러 아주 작게 둬요.
- 큰 글자는 딱 한 번, 굵고 둥근 자리표시 낱말이 짧은 변의 20%로 떴다가 작은 로고타입으로 줄어드는 순간이에요.

## 질감과 모양
- 화면 전체 질감은 깔끔하게 두고, 질감은 기호의 재료로만 보여 줘요(연필 결, 빗금, 그라디언트, 사진).
- 구성 격자: 밝은 회색 위 1px 점선, 먹색 8~10%. 가로·세로와 30°·60° 사선이 기호 중심을 지나요.
- 앵커는 꼭짓점마다 지름 0.6u 흰 점. 선택 상자는 1px 파란 선과 네 귀퉁이 작은 흰 네모.
- 입력 카드와 버튼은 모서리 1.4u, 아주 옅은 그림자 한 겹. 보내기 버튼은 파란 둥근 네모에 흰 위쪽 화살표.

## 움직임
- 100BPM 안팎. 재료 릴레이는 한두 박마다 갈아입고, 도구 장면은 2~3초씩 머물러요.
- 기호 자체는 거의 움직이지 않아요. 바뀌는 건 몸의 재료와 바탕이라 컷이 튀지 않고 한 몸이 변하는 것처럼 보여요.
- 카메라는 아주 천천히 밀고 들어가요(2초에 3~5%). 앵커 장면만 꼭짓점에 바짝 붙어 선을 따라 미끄러져요.
- 프롬프트는 초당 14~18자. 줄이 길어지면 문장 전체가 왼쪽으로 밀리고 오른쪽에 버튼이 들어와요. 버튼은 눌리면 0.9배로 줄었다 돌아와요(power3.out).
- 엔딩 지우기는 커서를 낱말 끝에 대고 반 박마다 한 글자씩. 선택 상자 너비도 같이 줄어요.

## 전환
- 컷이 기본. 재료가 바뀔 때는 2~3프레임 흐림(blur)을 섞어요. 밝은 판과 검정 판 사이는 짧은 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **재료 릴레이 오프닝**
   - 기호 판 6~7장을 같은 자리에 겹쳐 두고 한 박마다 하나만 보이게: `S.ambient(t => { const i = M.at(boards.map((_, k) => [k * M.beat(1), k]), t); boards.forEach((b, k) => b.style.visibility = k === i ? 'visible' : 'hidden'); })`.
   - 판마다 재료만 달라요: 회색 종이 사진 + 연필 path, `pre` 코드 글자 + 파란 윤곽, 검정 위 `drop-shadow` 윤곽, 점선 격자 위 `M.draw(path, M.ease.outCubic(M.prog(t, t0, .5)))`, SVG `pattern` 빗금 채움 + 앵커 점, 보라 `linear-gradient` 채움. 바뀌는 순간 `S.tr.blur` 0.1초.
2. **색 슬라이더와 선택 상자**
   - 기호 아래 무지개 막대 손잡이를 `M.Cursor` 가 끌면 `hue = M.anim([[t0, 260], [t0 + .2, 330, {d: 1, e: 'inOutCubic'}]], t)` 로 기호 그라디언트 색상이 돌아요.
   - 컷으로 그 색이 화면 가득 번진 바탕 위에 흰 기호를 두고, deco handles 로 선택 상자와 손잡이를 둘러요.
3. **프롬프트와 보내기 버튼**
   - 밝은 회색 판에 `M.type(text, t, t0, 16)` 큰 글씨, 끝에 파란 막대 커서 깜빡. 다 쳐지면 문장 `x` 를 `M.anim` 으로 왼쪽으로 밀고 버튼을 `M.spring(t - t1, 'smooth')` 로 들여요.
   - `M.cursorAt` 으로 버튼을 누르는 순간 `s` 0.9 → 1, 이어 결과 기호가 컵·액자 포스터 사진 위에 1초씩 컷. 장면 쌓기에서는 title: type 과 deco cursor 가 이 결을 따라가요.
4. **낱말 지우기 엔딩**
   - 검정 화면, 기호 + 로고타입을 선택 상자로 감싸고 커서를 낱말 끝에. `n = M.at(steps.map((_, k) => [t0 + k * M.beat(.5), len - k]), t)` 로 글자를 줄이고 `M.box(sel, {x, y, w: 기호폭 + 글자폭(n), h})` 로 상자도 따라 줄여요.
   - 기호만 남으면 상자가 꺼지고, 아래에 Geist Mono 작은 낱말을 `M.type` 으로 쳐서 멈춰요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 로고·브랜드 공개, 디자인·생성 도구 소개, 리브랜딩 발표, 마크 변형·활용 쇼케이스, 만드는 과정을 보여 주는 티저.
- 피할 것: 기호가 화면을 돌아다니거나 여러 개 겹치는 구성, 굵은 큰 제목 남발, 파랑 말고 다른 UI 강조색, 손그림 선 떨림, 화면 전체에 깐 질감.
- 기호가 단순할수록 재료 릴레이가 잘 살아요. 기호 하나를 끝까지 같은 자리에 두는 게 이 결의 중심이에요.
