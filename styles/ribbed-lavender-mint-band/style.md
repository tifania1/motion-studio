# 라벤더 결면과 민트 줄 띠 (그래픽·도형)

한 줄: 숯빛 판 위로 가는 줄결이 새겨진 라벤더 곡면이 천천히 쓸고 지나가고, 화면보다 큰 도넛·막대·숫자 조각과 UI 카드가 컷으로 이어져요. 옅은 민트 판 위아래에서는 세로 줄 띠가 물결처럼 일렁여요.

## 보는 느낌
- 판은 셋을 오가요. 짙은 숯빛 판, 옅은 민트 회색 판, 꽉 찬 라벤더 판. 장면마다 한 판만 써서 컷이 또렷하게 갈려요.
- 오프닝은 숯빛 판이에요. 귀퉁이에서 라벤더 곡면이 비스듬히 들어오는데, 곡면에는 아주 가는 평행 줄이 새겨져 있어 골판지나 레코드 결처럼 반짝여요. 가운데에는 작은 흰 글 한 줄뿐이라 여백이 넓어요.
- 데이터 장면은 조각을 화면보다 크게 잘라요. 도넛은 지름이 화면 높이의 1.5배쯤 되어 호 일부만 보이고, 막대그래프와 선 그래프는 화면 아래 3분의 1을 채워요.
- 민트 판에서는 위아래 가장자리를 세로 줄 띠가 채우고, 가운데에 숯빛 큰 낱말 한 줄을 둬요. 카드 판에서는 둥근 카드 서너 장이 나란히 떠 있고, 그중 한두 장 속에 같은 줄 띠 무늬가 들어가요.

## 색
- 숯빛 판 장면: 숯빛 #262723 70 · 라벤더 20 · 흰 글자 8 · 민트 빛 2.
- 민트 판 장면: 민트 회색 #D4E3DC 70 · 숯빛 글자 15 · 줄 띠(민트 #7FE6B2 → 라벤더 #B07FE8) 15.
- 라벤더 #B07FE8 이 유일한 강조색이에요. 도넛 조각, 막대, 알약 버튼, 카드 하나를 칠할 때 써요. 그 위 글자는 숯빛.
- 민트는 빛과 그라디언트로만 써요. 곡면 가장자리의 번짐, 줄 띠의 한쪽 끝, 숫자 기둥 발치.
- 보조로 밝은 회색 #EBEBE9(도넛·버튼 장면 바탕), 올리브 회색 #B9BAA4(카드 하나 정도).

## 글자
- Geist(한글은 Noto Sans KR Medium). 제목 굵기 500, 자간 −0.03em. 너무 굵지 않은 그로테스크라 차분하고 단단해 보여요.
- 크기 대비가 커요. 오프닝 문장은 짧은 변의 4% 안팎으로 작게, 민트 판의 큰 낱말은 짧은 변의 12~16%, 숫자는 20% 넘게.
- 큰 낱말은 한두 줄 가운데 정렬, 줄 간격 0.95. 대문자 낱말 하나만 크게 두는 장면도 있어요.
- 그래프 눈금과 꼬리표는 아주 작게(짧은 변의 1.6%), 흰색 50%.

## 질감과 모양
- 질감은 따로 얹지 않아요. 결은 라벤더 곡면의 줄과 줄 띠가 다 맡아요.
- 곡면 줄결: 1~2px 간격의 평행 줄, 라벤더 위에 흰색 25%·어두운 라벤더 25%를 번갈아. 가까운 쪽 가장자리는 흐림 6~10px.
- 줄 띠: 1.5px 굵기 세로 줄을 2px 틈으로 촘촘히, 줄마다 위아래 그라디언트(민트 → 라벤더 → 투명).
- 카드 모서리 `--u` × 1.2, 테두리·그림자 없이 납작하게. 버튼과 숫자 꼬리표는 끝이 둥근 알약.

## 움직임
- 108BPM, 보통 빠르기. 들어올 때는 `power3.out` 으로 미끄러지듯 멈춰요.
- 라벤더 곡면은 4~6초 동안 천천히 회전하며 쓸어 가요(`sine.inOut`). 그 위 글은 박마다 어절 하나씩 붙어요.
- 그래프는 박에 맞춰 자라요. 막대는 반 박 간격으로 아래에서 솟고, 도넛 조각은 1초에 호를 그리며 차고, 선 그래프는 왼쪽부터 1.5초에 그어져요.
- 줄 띠는 장면 내내 쉬지 않고 오르내려요. 줄마다 위상이 달라 물결이 옆으로 흘러가는 느낌.
- 카드는 아래에서 3u 올라오며 0.15초씩 엇갈려 들어와요.

## 전환
- 컷이 기본. 판 색이 바뀌는 순간이 리듬이 돼요.
- 알약 버튼이나 카드가 사라질 때는 가는 세로 줄로 쪼개지며 걷혀요(blocks). 라벤더 판이 화면을 덮을 때는 비스듬한 면이 쓸고 들어오는 와이프(wipe).
- 장면 쌓기: cut → wipe → blocks.

## 대표 장면

1. **줄결 곡면 오프닝**
   ```
   // 큰 사각에 줄결을 칠하고, 곡선 clip-path 로 휜 면처럼 보이게
   sheet.style.background = 'repeating-linear-gradient(115deg, #B07FE8 0 2px, #C9A6F0 2px 3px, #9A68D6 3px 5px)';
   sheet.style.boxShadow = '0 0 calc(var(--u)*4) var(--glow)';   // 가장자리 민트 빛
   S.ambient(t => {
     const k = M.ease.inOutSine(M.prog(t, 0, 6));
     M.place(sheet, W * (1.1 - .7 * k), H * (1.2 - .6 * k), {r: -28 + 14 * k, blur: (1 - k) * 8});
   });
   // 가운데 작은 흰 글: 박마다 어절 하나씩 (scenes.title rise 와 같은 결)
   ```
2. **민트 판과 세로 줄 띠**
   ```
   const bars = S.$$('.band i');      // 위아래 띠에 각 160개, 1.5px 너비
   const rnd = M.rng(7);
   const ph = bars.map(() => rnd() * 6.28);
   S.ambient(t => bars.forEach((b, i) => {
     const h = .35 + .3 * Math.sin(t * 2.2 + i * .18 + ph[i]) + .15 * Math.sin(t * 5 + i * .05);
     b.style.transform = `scaleY(${h})`;   // 배경: linear-gradient(#7FE6B2, #B07FE8, transparent)
   }));
   ```
   가운데에는 숯빛 큰 낱말 한두 줄만. 같은 띠를 카드 안이나 사진 카드 아래 테두리에도 깔아요.
3. **화면보다 큰 데이터 조각**
   - 도넛: SVG 원 둘(민트 회색 바탕 고리, 라벤더 조각)을 지름 1.5H 로 키워 잘리게 두고 `M.draw(arc, M.ease.outCubic(M.prog(t, t0, 1)))` 로 조각을 차오르게.
   - 막대: 숯빛 판에 라벤더 막대 12개, 막대 i 는 `M.anim([[0, 0], [t0 + i * M.beat(.5), h_i, {d: .5, e: 'outCubic'}]], t)` 로 솟아요.
   - 숫자 기둥: 라벤더 세로 막대 속 위쪽에 큰 숫자(Geist 500), 기둥 아래 절반은 민트 그라디언트가 `clipPath: inset(X% 0 0 0)` 로 차올라요. 숫자는 scenes.number count 로 올라가요.
4. **카드 판과 줄로 걷히는 버튼**
   - 민트 판에 둥근 납작 카드 서너 장(라벤더 카드, 흰 카드, 줄 띠 무늬 카드)을 `M.spring(t - t_i, 'smooth')` 로 아래에서 올려 나란히. 숫자 꼬리표 하나에는 민트 → 라벤더 화살표 칩.
   - 라벤더 알약 버튼이 떠 있다가 다음 장면으로 넘어갈 때 오른쪽부터 가는 세로 줄로 쪼개지며 사라져요. 엔진 전환 `S.tr.blocks` 를 세로 줄로 쓰면 같은 결이에요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 데이터·분석 도구 브랜드 필름, 마케팅 플랫폼 소개, 성과 숫자 발표, 기능 묶음을 차분하게 훑을 때, 리브랜딩 공개.
- 피할 것: 손그림 선과 종이 질감, 강조색 여러 개(라벤더 하나와 민트 빛만), 통통 튀는 스프링, 굵은 블랙 제목, 한 화면에 문장 여러 줄.
- 한글 큰 낱말은 2~5자로 짧게 두면 민트 판 가운데가 시원하게 살아요.
