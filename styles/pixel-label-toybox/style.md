# 픽셀 꼬리표 장난감 상자 (레트로·픽셀)

한 줄: 검은 바탕 위 픽셀 글꼴 꼬리표. 한두 박마다 컷으로 작은 장난감 화면이 바뀌고, 핵심 낱말만 흰 상자로 뒤집혀요.

## 보는 느낌
- 거의 검은 바탕(#121214)에 작은 픽셀 글이 화면 가운데 한 줄. 글은 화면 폭의 30~40%만 차지하고 둘레는 넉넉히 비워요.
- 장면마다 '장난감' 하나만 보여 줘요: 흰 선 카드 묶음, 원색 도형 판, 3×3 칸 흰 선 루프, 네온 선 아이콘 3×3 같은 것. 한 장면에 장난감 둘을 섞지 않아요.
- 다크 장면 사이사이에 연회색(#D7D7D9) 장면이 한 번씩 끼어 밝기가 툭 바뀌어요. 그 판에서만 원색이 터져요.
- 마지막엔 그동안 나온 장면들이 작은 판(아트보드)으로 줄어 격자로 깔린 큰 작업판을 훑고, 픽셀 로고로 끝나요.

## 색
- 다크 장면: 바탕 85 · 흰 글·흰 선 12 · 색 3.
- 밝은 장면: 연회색 바탕 55 · 원색 도형 40(파랑이 절반, 빨강·노랑·민트가 나머지) · 검은 글 5.
- 파랑 #3A6DF0, 빨강 #E23F4B, 노랑 #E9A21B, 민트 #3ED6B5. 네온 선 아이콘은 같은 색을 채도 높여 1.5px 선으로.
- 강조색 바탕 장면은 쓰지 않아요(schemes 에서 accent 를 뺌).

## 글자
- 제목·꼬리표: 픽셀 글꼴(Galmuri11, 한글까지 한 글꼴). 크기는 짧은 변의 3.5~5%로 작게. 굵게 만들지 않고 자간 +0.02em.
- 작은 설명·숫자: Geist Mono + Noto Sans KR 500. 픽셀 글꼴의 60% 크기.
- 강조 낱말: 흰 상자(위아래 여백 0.25em, 좌우 0.35em)에 검은 글자. 상자 오른쪽 아래로 1px 흰 테두리를 0.3u 어긋나게 한 겹 더.
- 영문 픽셀 대문자가 필요하면 Silkscreen 을 꼬리표에만.

## 질감과 모양
- 질감 없음. 화면이 깨끗한 디지털이어야 픽셀 글이 또렷해요.
- 선은 모두 1~1.5px 흰 선, 끝이 각지게. 카드 모서리는 0.6u.
- 원색 도형: 원, 모서리 1.5u 둥근 네모, 끝이 둥근 짧은 막대. 아래로 옅은 그림자(0 1.2u 2u rgba(0,0,0,.12))만 주고 테두리는 없음.
- 메뉴 칸: 흐린 회색 1px 테두리(rgba(255,255,255,.18)), 선택 칸만 흰 1.5px.

## 움직임
- 120BPM. 장면 하나가 2~4박(1~2초)으로 짧아요. 장면이 바뀌는 건 늘 박 위의 컷.
- 들어오는 움직임은 expo.out 0.25초로 빠르게 서고, 머무는 동안은 계속 천천히 돌거나 떠 있어요(멈춘 화면이 없게).
- 잔상 묶음: 같은 모양 8~12장을 0.04초씩 늦게 같은 움직임을 따라가게 하고, 뒤쪽일수록 투명도·밝기를 낮춰요.
- 끈적한 합체: 붙는 순간은 0.3초, 떨어질 때는 늘어난 목이 끊어지며 각자 스프링 'snappy' 로 둥글게 돌아감.

## 전환
- 기본은 컷. 2~4박마다 바로 다음 장난감으로.
- 로고가 나올 때만 blocks(격자 칸이 차례로 덮었다 걷힘)로 픽셀처럼 흩어지게.
- 끝에서 한 번 zoom 으로 모든 장면이 작은 판이 된 큰 작업판으로 물러나요.

## 대표 장면

1. 뒤집힌 낱말 상자
   ```
   // 문장을 S.words 로 쪼개고 강조 낱말 w 만 .inv (background: var(--on-bg); color: var(--bg))
   // .inv::after 로 1px 테두리를 right/bottom 으로 0.3u 밀어 한 겹 더
   S.fx.fade(line, t0, {d: .15});                  // 문장은 그냥 켜지듯
   gsap: w 의 clip-path inset(0 100% 0 0) → inset(0 0 0 0), 0.2초 expo.out, t0 + M.beat(1)
   ```
2. 굴러가는 메뉴
   ```
   // 항목 높이 h. 칸 i 의 y = (i - M.anim(steps, t)) * h  (steps: [[t0,0],[t0+.5,1],[t0+1,2]…], spec {d:.25, e:'expo.out'})
   // 가운데 고정 칸과 겹치는 정도 k = 1 - |y| / h  →  글자 상자 배경 opacity = k > .5 ? 1 : 0 (뒤집힘은 딱 끊어서)
   // 위아래로 멀어질수록 글 opacity .25
   ```
3. 잔상 카드 묶음
   ```
   // 흰 선 둥근 사각(SVG rect, rx 0.6u) 10장. 각 장 j 는 같은 함수를 j*0.04초 늦게 따라감
   const pose = tt => ({ rot: 25 * Math.sin(tt * 1.6), x: 6 * Math.sin(tt * .8) });
   cards.forEach((c, j) => { const p = pose(t - j * .04); c.style.transform = `perspective(900px) rotateY(${p.rot}deg) translateX(calc(var(--u) * ${p.x}))`; c.style.opacity = 1 - j * .07; });
   ```
   - 같은 방식으로 픽셀 낱말 하나를 12겹 깊이 방향으로 늘어놓고(translateZ, 뒤로 갈수록 투명) 한 덩어리로 기울여도 돼요.
4. 끈적한 원색 장난감 판
   ```
   // 도형을 담은 g 에 SVG 필터: feGaussianBlur(stdDeviation 1.6u) → feColorMatrix(alpha 18 -7) → 원래 그래픽과 feComposite atop
   // 파란 원 둘만 이 필터 g 에 넣고 나머지 도형은 밖에 두면, 파란 원끼리만 끈적하게 붙음
   blobA.cx = M.lerp(ax, bx, M.spring(t - tMeet, 'smooth') * .55);  // 가까워지면 목이 생기며 합쳐짐
   // 모든 도형: S.fx.bob 진폭 0.6u + 회전 ±6°, 그림자는 도형 아래 따로 둔 흐린 같은 모양
   ```
5. 픽셀 로고 마무리
   - 로고 글자를 0.5u 칸으로 잘라 칸마다 시드 난수(M.rng)로 정한 순서·색(파랑·빨강·노랑·민트)으로 0.03초씩 깜빡이게 → 칸들이 가운데 2×2 색 정사각으로 모여 오므라듦 → 컷으로 검은 화면에 작은 픽셀 글 한 줄.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱·서비스 기능 여러 개를 빠르게 나열, 개발 도구·게임 툴 발표, 인디 게임·픽셀 감성 브랜드, 짧은 티저 릴, 업데이트 소식.
- 피할 것: 세리프 글꼴, 사진을 꽉 채운 장면, 부드러운 페이드, 두 줄 넘는 문장, 그라디언트 바탕. 영상 속 로고나 캐릭터 모양은 쓰지 않고 픽셀 글·흰 선·원색 도형의 원리만 가져와요.
