# 분홍 회로 유리 허브 (제품 UI)

한 줄: 거의 검은 어둠에서 분홍 빛 회로선이 둥글게 꺾이며 유리 아이콘 타일을 하나씩 잇고 가운데 허브 타일로 모여요. 남색 격자 판으로 넘어가면 넓은 유리 입력창에 짧은 명령이 1초마다 바뀌어 쳐지고, 끝은 넓고 굵은 대문자가 어절마다 하얗게 켜지는 연동 소개 필름.

## 보는 느낌
- 새까만 화면에서 시작해 자두빛 판, 남색 판으로 옮겨 가요. 판마다 가장자리는 어둡고 빛은 한곳에만 고여요. 자두 장면은 가운데에 분홍 빛, 남색 장면은 왼쪽 아래에 파란 빛이 번져요.
- 바탕에는 아주 옅은 정사각 격자(흰색 5~8%)가 깔려 공간이 깊어 보여요.
- 주인공은 반투명 유리 아이콘 타일이에요. 둥근 정사각형에 흰 테두리 한 줄, 가운데 흰 선 아이콘 하나. 타일 사이를 분홍 빛 회로선이 둥근 직각으로 꺾이며 이어요.
- 가운데에는 늘 허브 타일 하나가 있어요(짙은 남색 속, 흰 마크). 연결이 모이면 테두리에 분홍 빛이 번져요.
- 글 장면은 한가운데 넓고 굵은 대문자 한두 줄뿐이에요. 꾸밈은 글 뒤에 가는 둥근 사각 선 하나 정도.

## 색
- 어둠(#0E0D14, #170C17) 65 · 자두·남색 빛 20 · 흰 글자와 유리 10 · 분홍 5.
- 분홍 #E64FC6 은 회로선, 빛 알약, 허브 테두리 빛에만 써요. 글자는 칠하지 않아요.
- 자두 판 #2B1430(가운데 #3A1838 빛), 남색 판 #1E1D5C 에서 왼쪽 아래 #4B4FD6 빛으로.
- 두 번째 줄이나 아직 안 켜진 어절은 회색 #8A8AA0, 켜지면 흰색 #F2F1F6.
- 유리 타일·입력창: 흰색 10~14% + 뒤 흐림, 테두리 흰색 30%.

## 글자
- 제목: Archivo 가변 글꼴을 넓게(stretch 125%, weight 850), 한글은 Noto Sans KR Black. 모두 대문자, 자간 -0.02em, 줄 간격 0.95. 크기는 짧은 변의 11~14%.
- 두 줄 제목은 위 줄 흰색, 아래 줄 회색으로 무게를 나눠요.
- 입력창 글: Geist 400(한글 Noto Sans KR Medium), 짧은 변의 4.5%, 왼쪽 정렬. 아래 알약 칩 글씨는 그 70%, 앞에 작은 흰 점.
- 주소·꼬리표: 어두운 둥근 상자 속 작은 Geist, 회색 테두리 한 줄.

## 질감과 모양
- 비네트 0.35. 그 밖에는 그레인도 종이도 없이 매끈하게.
- 타일 모서리 1.4u, 입력창 1.2u, 알약 칩은 완전히 둥글게.
- 회로선 두께는 짧은 변의 0.25%, 꺾이는 모서리 반지름 3u. 선에 분홍 빛(drop-shadow 0 0 1.2u) 한 겹.
- 빛 알약: 길이 4u, 두께 0.8u 둥근 막대, 선보다 한 톤 밝은 분홍.

## 움직임
- 120BPM. 들어오는 것은 power3.out, 카메라는 sine.inOut 으로 느리게 미끄러져요.
- 회로선은 0.8초에 그어지고, 0.3초 뒤 빛 알약이 선을 따라 0.9초에 미끄러져요. 알약이 닿는 순간 타일 테두리가 0.2초 분홍으로 번쩍.
- 제목 글자는 흩어진 차례로 글자마다 톡 켜지고(0.6초 안에 다), 나갈 때도 흩어진 차례로 꺼져요.
- 입력창 문장은 초당 25자쯤 쳐지고 커서가 깜빡여요. 2박(1초)마다 컷으로 다음 문장.
- 끝 문장은 회색으로 다 깔린 뒤 어절마다 한 박 간격으로 흰색으로 켜져요.

## 전환
- 검은 화면에서 서서히(fade) 열고, 자두빛 공간으로는 흐림(blur)으로 들어가요. 입력창 사이는 컷, 입력창 무리로는 카메라가 뒤로 빠지며, 엔딩은 다시 fade.
- 장면 쌓기: fade → blur → cut → push.

## 대표 장면
1. **회로선과 빛 알약**
   ```
   const wire = S.$$('.wire')[0];            // 둥근 직각으로 꺾이는 SVG path, 분홍 빛 한 겹
   const L = wire.getTotalLength();
   S.ambient(t => {
     M.draw(wire, M.ease.outCubic(M.prog(t, t0, .8)));
     const k = M.prog(t, t0 + .3, .9);
     const p = wire.getPointAtLength(L * M.ease.inOutCubic(k));
     M.place(pill, p.x, p.y, {o: k > 0 && k < 1 ? 1 : 0});
     const hit = M.prog(t, t0 + 1.2, .2);   // 닿는 순간 번쩍
     tile.style.borderColor = M.color('rgba(255,255,255,.3)', '#E64FC6', 1 - Math.abs(hit * 2 - 1));
     M.place(world, M.anim([[0, 0], [t0, -W * .25, {d: 2.4, e: 'inOutSine'}]], t), 0);   // 카메라가 선을 따라
   });
   ```
   자두 판에는 장면 쌓기 bg grid 를 깔고, 타일은 card glass 로 흐린 유리 결을 내요.
2. **허브로 모이는 연결**
   - 허브 타일을 `M.place` 로 가운데 두고, 짧은 분홍 대시 8개를 바깥에서 허브 가장자리까지 `M.anim` 으로 0.5초씩 겹쳐 들여보내요. 닿은 대시는 바로 사라져요.
   - 허브 그림자 `box-shadow: 0 0 6u var(--glow)` 의 세기를 `M.prog(t, t1, 1.2)` 로 키워요. deco orb 가 그 뒤에 숨 쉬는 빛을 깔아요.
3. **1초마다 바뀌는 유리 입력창, 그리고 입력창 무리**
   ```
   const lines = ['…', '…', '…', '…', '…'];   // 짧은 명령 문장
   S.ambient(t => {
     const i = M.at(lines.map((_, k) => [t0 + k * M.beat(2), k]), t);
     field.textContent = M.type(lines[i], t, t0 + i * M.beat(2) + .1, 25);
   });
   ```
   - 마지막 문장 뒤 `S.tr.blur` 로 넘어가 무대에 `perspective` 를 주고, 같은 입력창 8장을 깊이와 `rotateY(-18deg)` 를 달리해 허브 둘레에 띄워요. 무리 전체 크기를 `M.anim` 으로 1.8 → 1 (1.5초, inOutCubic) 줄여 카메라가 빠지는 느낌을 내요.
4. **어절이 켜지는 넓은 대문자 엔딩**
   - 제목은 `S.chars(el)` 로 나눈 뒤 `M.rng(시드)` 로 섞은 차례대로 글자마다 톡 켜요(장면 쌓기 title pop).
   - 마지막 문장은 어절 `ws` 를 회색으로 깔고 `w.style.color = M.color('#8A8AA0', '#F2F1F6', M.prog(t, t0 + k * M.beat(1), .25))` 로 한 박씩 켜요. 뒤의 가는 둥근 사각 선은 `M.draw(box, M.prog(t, t0, .7))`, 아래 주소 알약은 테두리부터 켜지고 글씨가 반 박 늦게 밝아져요.
