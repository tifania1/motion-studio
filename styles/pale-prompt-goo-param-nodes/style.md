# 옅은 회색 덩어리 빚기 (제품 UI)

한 줄: 옅은 회색 위 검은 점 가루가 흩어지면 프롬프트 창에 부탁이 쳐지고, 말랑한 그라디언트 덩어리가 슬라이더를 따라 꿈틀대며 색을 갈아입어요. 끝에는 노드 카드가 곡선으로 이어지고 자두·라임 덩어리 무늬가 화면을 덮는 제작 도구 데모.

## 보는 느낌
- 바탕은 거의 흰빛에 가까운 옅은 회색 한 장이에요. 그 위에 그림자가 아주 옅은 흰 패널, 프롬프트 창, 캔버스 창이 조용히 놓여요.
- 화면에서 색을 가진 건 결과물뿐이에요. UI 는 회색과 먹색으로 담담하게 두고, 가운데 덩어리(자두에서 주황으로, 또는 라임)가 유일하게 짙은 색 덩어리가 돼요.
- 카메라 거리가 자주 바뀌어요. 앱 창 전체를 넓게 보여 주다가 프롬프트 창이나 슬라이더 패널에 화면보다 크게 바짝 붙고, 다시 넓게 빠져요.
- 뒤쪽에서는 화면이 노드 그래프로 넓어져요. 사진 카드, 설명 카드, 결과 카드가 가는 회색 곡선으로 이어지고 연결 점에 작은 초록·주황 점이 붙어요.
- 마무리는 어두운 자두색 바탕에 보라·라임 덩어리 무늬가 화면을 꽉 채우고, 가운데 작은 흰 대문자 한 줄. 그다음 옅은 회색 위 작은 이름 한 줄로 닫아요.

## 색
- 옅은 회색 #E9E9E8 70 · 흰 패널 #F6F6F5 15 · 먹색 글자 #1F1F22 10 · 보라 #5F55D6 와 결과물 색 5.
- 보라 #5F55D6: 프롬프트 속 지시 낱말, 슬라이더 막대, 켜진 토글. 버튼에 칠하면 글자는 흰색.
- 분홍 #E2557A: 보내기 화살표와 눌린 버튼의 빛 테두리(glow)에만 아주 작게.
- 결과물 덩어리: 자두 #3A1E4A → 주황 #E8652E 세로 그라디언트, 바뀐 뒤엔 라임 #B6E33A → 올리브 #5E7A1C. 엔딩 무늬도 이 자두·보라·라임 세 색.
- 코드 창의 바뀐 줄은 옅은 연두 칠(#B6E33A 40%).

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 제목도 500 정도로 가볍고, 자간 -0.02em.
- 프롬프트 문장은 짧은 변의 5~6%까지 크게 키워 바짝 붙은 장면에서 읽혀요. 회색 #6B6B70 문장 안에서 지시 낱말만 보라.
- 패널 꼬리표(이름표, 값)는 작고 회색, 왼쪽 정렬. 코드와 FPS 같은 숫자는 Geist Mono.
- 엔딩 한 줄은 아주 작은 대문자, 자간 +0.06em.

## 질감과 모양
- 질감은 없어요. 매끈한 화면 녹화 결.
- 패널·창·카드는 모서리 `--u` × 1.6, 얇은 1px 회색 테두리(#1F1F22 8%)와 아주 넓고 옅은 그림자 한 겹.
- 슬라이더는 두꺼운 둥근 막대(보라 칠 + 연회색 빈칸), 색 고르기는 무지개 띠에 흰 손잡이, 토글은 보라 알약.
- 덩어리는 가장자리가 부드럽게 붙었다 떨어지는 메타볼. 표면에 아래쪽 반사광이 살짝.
- 커서는 큰 검은 화살표에 흰 테두리.

## 움직임
- 110BPM, 보통. 들어오는 건 `power3.out` 으로 부드럽게 멈추고, 카메라 다가가기·빠지기는 0.8~1.2초 `inOutCubic`.
- 프롬프트는 초당 25~30자로 쳐지고, 지시 낱말은 다 쳐지는 순간 회색에서 보라로 0.2초 물들어요.
- 덩어리는 늘 아주 천천히 숨 쉬고(3~4초 주기), 슬라이더가 움직이는 동안에만 크게 꿈틀대요. 색이 바뀔 땐 0.6초에 걸쳐 섞이며 넘어가요.
- 노드 카드는 하나씩 0.3박 간격으로 떠오르고, 이어 곡선이 왼쪽에서 오른쪽으로 그려진 뒤 결과 카드 안 그림이 바뀌어요.
- 장면마다 2~3초 머물러요.

## 전환
- 컷이 기본. 넓은 화면에서 패널로 바짝 붙을 땐 흐림(blur) 한 번으로 넘어가고, 엔딩 어두운 장면과 마지막 이름은 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **점 가루가 흩어지고 프롬프트 창이 남음**
   ```
   // 검은 점 400개를 소용돌이 구름으로 두고, 흩어진 뒤 빈 창을 띄움
   const rnd = M.rng(7), dots = S.$$('.dust');
   const seed = dots.map(() => ({ a: rnd() * 6.28, r: rnd() ** .6, s: .3 + rnd() * 1.4 }));
   S.ambient(t => {
     const k = M.ease.inCubic(M.prog(t, 1.6, 1.2));          // 1.6초부터 흩어짐
     dots.forEach((d, i) => { const p = seed[i], a = p.a + t * .4 * (1.2 - p.r);
       M.place(d, cx + Math.cos(a) * p.r * W * .35 * (1 + k * 2), cy + Math.sin(a) * p.r * H * .22 * (1 + k * 2), { s: p.s, o: 1 - k }); });
     M.place(prompt, cx, cy, { o: M.prog(t, 2.6, .5), s: .96 + .04 * M.spring(t - 2.6, 'smooth') });
   });
   ```
2. **바짝 붙은 프롬프트 + 보내기**
   - 카메라를 프롬프트 창 오른쪽 아래로 크게 당긴 채 `M.type(text, t, t0, 28)`. 지시 낱말 span 은 다 쳐진 순간 `M.color('#6B6B70', '#5F55D6', M.prog(t, tw, .2))`.
   - `M.Cursor` 를 분홍 화살표로 옮겨 누르면(`M.cursorAt`) 화살표에 `box-shadow: 0 0 2u var(--glow)` 가 한 번 번지고, `S.tr.blur` 로 캔버스 창 장면으로 넘어가요. 장면 쌓기에선 title: type + frame: window + deco: cursor 로 같은 결이 나와요.
3. **슬라이더를 끌면 덩어리가 꿈틀**
   ```
   // SVG goo 필터(feGaussianBlur 12 + feColorMatrix 알파 18 -9) 안에 원 6개 = 메타볼
   S.ambient(t => {
     const v = M.anim([[0, .45], [t1, .8, { d: 1.2, e: 'inOutCubic' }]], t);   // 커서가 끄는 슬라이더 값
     M.box(bar, { w: v * barW });
     balls.forEach((b, i) => M.place(b, cx + Math.cos(t * .7 + i) * R * v, cy + Math.sin(t * .9 + i * 2) * R * .8 * v));
     const c = M.prog(t, t2, .6);                                              // 색 띠 손잡이가 옮겨 가면
     stopTop.setAttribute('stop-color', M.color('#3A1E4A', '#B6E33A', c));
     stopBot.setAttribute('stop-color', M.color('#E8652E', '#5E7A1C', c));
   });
   ```
4. **노드 카드가 곡선으로 이어지고 엔딩 무늬**
   - 카드 3~4장을 `M.place(card, x, y, { o: k, y: (1 - k) * 2 * u })`, `k = M.spring(t - ti, 'smooth')`, ti 는 0.3박씩. 이어 곡선 `path` 를 `M.draw(path, M.prog(t, tj, .5))`, 다 그려지면 결과 카드 속 그림을 컷으로 바꿔요.
   - 엔딩은 자두 바탕에 같은 goo 필터로 보라·라임 원 20개를 화면 가득 `M.drift`, 가운데 작은 흰 대문자 한 줄을 `S.fx` 로 흐림에서 맺히게. 마지막은 `S.tr.fade` 로 옅은 회색 위 이름 한 줄.
