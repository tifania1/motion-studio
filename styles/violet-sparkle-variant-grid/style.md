# 보라 반짝이 시안 격자 (제품 UI)

한 줄: 보라 그라디언트 위 편집기 창에서 반짝이 버튼으로 카메라가 파고들고, 어두운 패널의 알약 칩을 커서가 고르면 포스터 시안 한 장이 격자로 불어나는 짧은 AI 편집 도구 소개.

## 보는 느낌
- 첫 장면은 위가 짙은 보라, 아래가 연보라로 번지는 그라디언트 위에 밝은 편집기 창 하나가 떠 있어요. 창 가운데엔 세로 포스터 시안 한 장, 오른쪽엔 설정 패널.
- 거의 1초마다 컷이 바뀌는데, 한 컷에는 조작 하나만 크게 보여 줘요. 반짝이 아이콘, 칩 고르기, 버튼 누르기가 화면을 가득 채울 만큼 확대돼요.
- 가운데쯤 시안 한 장이 여러 장으로 불어나 화면을 격자로 덮어요. 칸은 모두 같은 틀인데 안의 제목만 제각각이라 '아이디어가 쏟아진다'는 느낌이 나요.
- 끝은 검은 화면에 흰 굵은 한 줄, 그 다음 보라 알약 하나만 남는 조용한 마무리.

## 색
- 밝은 회색 #E7E6EB 50 · 숯빛 패널 #2B2930 과 검정 #141316 25 · 보라 #7C44E2 15 · 연보라 #B79BF0 10.
- 보라는 반짝이 아이콘, 눌리는 버튼, 마지막 알약, 첫 장면 그라디언트에만 써요. 연보라는 아이콘 둘레 원과 시안 칸 테두리.
- 어두운 패널 위 칩은 패널보다 한 단계 밝은 회보라(흰 8~12%), 고른 칩은 흰 20% 로 밝아져요. 칩 글자는 옅은 흰색.
- 포스터 시안 속 사진·색은 자유지만 한 가지 색 계열로 통일해서 격자가 어지럽지 않게 해요.

## 글자
- Geist(한글은 Noto Sans KR). UI 글씨는 500, 마무리 한 줄은 700 에 자간 -0.03em 으로 빽빽하게.
- 마무리 문장은 짧은 변의 9~10%, 한 줄, 가운데.
- 칩·버튼 글씨는 짧은 변의 4~5% 로 크게 보이도록(카메라가 붙어 있으니까).
- 시안 칸 속 포스터 제목은 Archivo 800~900 두 줄. 칸마다 크기·너비(stretch 70~110%)·위치를 다르게, 일부는 칸 밖으로 잘리게.

## 질감과 모양
- 질감 없이 매끈하게. 그림자는 앱 창과 패널에만 아주 옅게 한 겹.
- 칩·버튼은 완전한 알약, 패널·앱 창은 모서리 `--u` × 1.6.
- 시안 칸: 흰 카드에 1px 연보라 테두리, 모서리는 거의 각지게(0.2u).
- 커서는 흰 테두리 두른 큰 검은 화살표, 짧은 변의 8~10% 크기.
- 반짝이: 네 갈래 별 두 개(큰 것, 작은 것)를 보라로 채우고 뒤에 연보라 원.

## 움직임
- 120BPM. 컷은 2박(1초)마다, 격자 칸 바뀜은 두세 프레임마다.
- 카메라 확대·축소는 `power3.out` 으로 확 다가가 부드럽게 멈춤(0.4~0.5초).
- 커서는 살짝 휘는 길로 0.5초에 와서 누르고, 누를 때 커서 0.9배·대상 0.96배로 눌렸다가 스프링으로 돌아와요.
- 격자는 가운데 한 장에서 시작해 바깥쪽 칸으로 0.04초씩 늦게 톡톡 나타나요(stagger 0.6).

## 전환
- 컷이 기본. 편집기 창에서 아이콘으로 파고들 땐 확대 끝에 흐림 전환(`S.tr.blur`)을 짧게.
- 격자 장면에서 검은 마무리로 갈 때만 페이드. 장면 쌓기: cut → blur → cut → fade.

## 대표 장면
1. **반짝이 아이콘으로 파고들기**
   ```
   // 보라 그라디언트 위 앱 창, 툴바 아이콘(ix, iy) 쪽으로 카메라 확대
   const s = M.anim([[0, 1], [.5, 4.2, {d: .45, e: 'outCubic'}]], t);
   M.place(win, cx + (cx - ix) * (s - 1), cy + (cy - iy) * (s - 1), {s});
   // 아이콘 원과 반짝이는 확대된 판에서 따로 그려 선명하게
   const c = new M.Cursor(cursorEl);
   c.path(t, [[1.0, W * .8, H * .9], [1.5, ix + 30, iy + 30]]);
   const k = M.spring(t - 1.5, 'snappy');           // 누른 뒤 원이 톡 부풂
   M.place(halo, ix, iy, {s: 1 + (1 - k) * .08});
   ```
2. **어두운 패널 칩 고르기 → 보라 버튼 누르기**
   - 숯빛 패널에 알약 칩 네 개를 2×2 로 두고 `M.cursorAt` 으로 커서가 첫 칩에 닿으면 칩 바탕을 `M.color('rgba(255,255,255,.08)', 'rgba(255,255,255,.2)', k)` 로 밝혀요.
   - 컷으로 보라 알약 버튼(왼쪽에 둥근 아바타 배지, 글자 앞에 작은 반짝이). 커서가 누르면 `M.place(btn, x, y, {s: 1 - .04 * press})`, 패널 나머지는 회색으로 흐려져요.
3. **시안 한 장이 격자로 불어남**
   ```
   const tiles = S.$$('.tile');                     // 5×3, 가운데가 원본
   const rnd = M.rng(7);
   tiles.forEach((el, i) => {
     const d = Math.hypot(col[i] - 2, row[i] - 1);
     const k = M.spring(t - (5.0 + d * .04), 'snappy');
     M.place(el, gx[i], gy[i], {s: .6 + .4 * k, o: k});
     // 두세 프레임마다 제목 판을 갈아 끼우다 6.4초에 멈춤
     const v = M.at([[5.0, 0], [5.1, 1 + (i % 3)], [5.2, 2 + (i % 4)], [6.4, i % 5]], t);
     el.dataset.v = v;                               // 크기·굵기·잘린 자리 조합
   });
   const z = M.anim([[5.0, 1.8], [6.2, 1, {d: 1.2, e: 'outCubic'}]], t);   // 카메라 뒤로
   M.place(grid, cx, cy, {s: z});
   ```
   - 장면 쌓기에서는 deco handles 로 원본 칸에 연보라 선택 상자를 두르고, deco cursor 가 그 칸을 눌러요.
4. **검은 화면 한 줄과 보라 알약**
   - `S.tr.fade` 로 검정. 흰 굵은 문장이 어절마다 아래에서 0.3초에 올라오고(title rise), 한 박 머문 뒤 컷으로 가운데 보라 알약 하나(브랜드 이름이나 주소)만 남겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 생성·추천 기능 소개, 디자인·편집 도구 런칭, 템플릿·시안 여러 개를 한 번에 보여 줄 때, 10초 안팎 짧은 기능 티저.
- 피할 것: 손그림 선과 종이 질감, 긴 문장, 느린 장면 머무름, 보라 말고 다른 강조색, 필름 그레인·비네트 같은 거친 질감.
- 기존 '따뜻한 편집기 확대'보다 차갑고 보라빛이며, 결과물이 격자로 불어나는 순간이 핵심이에요. 격자 장면은 꼭 넣어요.
