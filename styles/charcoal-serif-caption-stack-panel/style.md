# 숯빛 세리프 자막과 설정 패널 (제품 UI)

한 줄: 숯빛 판 가운데 세리프 자막 한 줄이 놓이고 핵심 낱말에 가는 밑줄이 그어져요. 장면이 바뀌면 작은 흰 설정 패널이 사물 옆에 뜨고, 커서가 남보라 버튼을 누를 때마다 옆의 카드와 동그라미가 간격과 쌓이는 방향을 바꿔요.

## 보는 느낌
- 두 종류 장면을 번갈아 써요. 하나는 숯빛 판 한가운데 세리프 자막 한 줄만 있는 장면, 다른 하나는 사물 하나와 작은 설정 패널이 나란히 놓인 시연 장면이에요.
- 시연 장면의 바탕은 숯빛이거나 따뜻한 밝은 회색(#BDBBB5) 판이에요. 그 위에 문서 창, 색 카드 격자, 겹친 동그라미, 선으로 그린 사물 같은 결과물이 하나 있고, 오른쪽 위나 옆에 손바닥만 한 흰 패널이 떠 있어요.
- 여백이 넉넉해요. 결과물은 화면 가운데 40~60%, 패널은 화면 너비의 15~20% 정도로 작게.
- 결과물이 크게 확대된 컷(색 카드가 화면 밖으로 잘림)과 전체를 보는 컷을 섞어 간격 변화를 바짝 보여 줘요.
- 오프닝은 어두운 판에 무광 입체 하나와 금빛 가는 작도선(원·대각선) 몇 줄로 열어도 좋아요. 입체 모양은 우리 브랜드 것으로 새로 만들어요.

## 색
- 숯빛 바탕 65 · 밝은 회색 판과 흰 패널 20 · 자막·글자 10 · 남보라 5.
- 바탕 #1F1F1F, 자막 #ECEAE4, 밑줄은 자막 색 50% 정도로 옅게.
- 남보라 #5856D6 는 패널에서 선택된 버튼, 선택 핸들, 커서가 누른 칸에만 써요.
- 결과물 쪽에서는 색을 넉넉히 써도 돼요: 다홍 #E0461E, 겨자 #E39A12, 올리브 #9A9637, 미색 문서 #E4DCC8. 동그라미 테두리는 주황·분홍·보라·초록처럼 밝은 원색.

## 글자
- 자막: 고운바탕 700, 짧은 변의 5~6%, 가운데 한 줄. 자간 −0.01em. 문장 끝에 마침표 없이 짧게.
- 강조 낱말은 굵기·색을 바꾸지 않고 아래에 가는 밑줄만 그어요(선 두께 짧은 변의 0.25%).
- 패널 글씨: Geist·Noto Sans KR Medium, 아주 작게(짧은 변의 1.6~2%). 제목 한 줄, 옆에 작은 아이콘, 아래 칸에 숫자와 꼬리표.
- 문서 창 안 글은 세리프 본문, 제목만 굵게.

## 질감과 모양
- 질감은 넣지 않아요. 매끈한 평면에 그림자만.
- 패널: 흰색, 모서리 `--u` × 1.2, 아주 옅은 그림자 하나, 안쪽 칸은 연회색 둥근 사각. 선택된 분할 버튼만 남보라 칠에 흰 아이콘.
- 문서 창: 미색, 왼쪽 위 작은 점 셋, 아래 가운데 떠 있는 알약 도구 막대, 넓고 부드러운 그림자.
- 선택 핸들: 결과물 네 귀퉁이에 작은 남보라 정사각형, 사이를 1px 남보라 선으로.

## 움직임
- 96BPM, 보통 빠르기. 자막은 2박쯤 머물고, 시연 장면은 4~8박.
- 자막은 0.4초에 맺혀요(투명 → 선명, 아래로 0.5u 올라오며). 밑줄은 자막이 다 보인 뒤 0.5초에 왼쪽부터 그어져요.
- 커서는 패널 칸으로 미끄러져 와서(0.5초, power3.out) 살짝 눌리고, 누른 순간 결과물이 0.5초 스프링으로 다시 짜여요. 넘치거나 튀지 않게 'smooth' 정도.
- 숫자 칸 값은 결과물 변화와 같이 굴러가요(예: 24 → 147).
- 나갈 때는 따로 움직이지 않고 컷.

## 전환
- 자막 ↔ 시연은 컷. 같은 결과물을 확대해 보는 장면 사이만 짧은 페이드(0.3초).
- 장면 쌓기: cut → fade → cut.

## 대표 장면
1. **세리프 자막과 밑줄**
   ```js
   const M = Studio.M;
   S.ambient(t => {
     const k = M.ease.outCubic(M.prog(t, 0, .4));
     M.place(caption, cx, cy + (1 - k) * u * .5, { o: k });
     M.draw(underline, M.ease.outCubic(M.prog(t, .45, .5)));   // 강조 낱말 아래 가는 선
   });
   // 장면 쌓기에서는 title: fade + marker: underline 이 같은 결을 내요
   ```
2. **패널을 누르면 옆 결과물이 다시 짜임**
   ```js
   const cur = new M.Cursor(S.root);
   const press = 1.6;                                  // 커서가 분할 버튼을 누르는 때
   S.ambient(t => {
     M.cursorAt(cur, [[0, offX, offY], [1.0, btnX, btnY, { d: .5, e: 'outCubic' }], [press, btnX, btnY, { click: true }]], t);
     const k = M.spring(t - press, 'smooth');         // 0 → 1
     const gap = M.lerp(u * .6, u * 2.4, k);           // 카드 사이 간격이 벌어짐
     cards.forEach((c, i) => M.place(c, x0 + i * (cw + gap), y0));
     seg.style.background = M.color('#ECEBE8', '#5856D6', M.prog(t, press, .15));
     valueEl.textContent = Math.round(M.lerp(24, 147, k));
   });
   ```
   - 쌓이는 방향을 바꿀 땐 같은 k 로 카드 x·y 를 가로줄 자리에서 세로줄 자리로 옮겨요.
3. **겹친 동그라미와 테두리 포함/제외**
   - 색 테두리 동그라미 4개를 가로로 겹쳐 두고 둘레에 deco handles(선택 상자).
   - 커서가 '제외'를 누르면 `overlap = M.lerp(ring, 0, k)` 로 겹친 폭이 테두리 두께만큼 줄고, '맨 앞이 위' 를 고르면 `zIndex` 를 반 박 지나 거꾸로 바꿔 순서가 뒤집혀요.
4. **밝은 회색 판 위 문서 창 확대**
   - frame: window 로 미색 문서 창을 띄우고 옆에 패널. 여백 값을 바꾸면 본문 블록의 좌우 안쪽 여백이 스프링으로 넓어지고, 다음 장면은 같은 창을 크게 확대해(페이드 `S.tr.fade`) 줄 끝이 맞춰지는 걸 보여 줘요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인·편집 도구 기능 소개, 설정 하나가 결과를 바꾸는 걸 보여 줄 때, 업데이트 노트 영상, 레이아웃·템플릿 기능 설명.
- 피할 것: 화려한 그라디언트 바탕, 두 줄 넘는 자막, 빠른 휙 전환과 흔들기, 남보라 말고 다른 UI 강조색, 굵고 꽉 찬 고딕 제목.
- 자막은 기능 하나를 짧게 말하는 한 문장이면 충분해요. 그다음 장면이 바로 그 말을 눈으로 보여 주게 짝을 맞춰요.
