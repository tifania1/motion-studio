# 민트 소리 띠 (그라디언트·빛)

한 줄: 옅은 민트 바탕 아래쪽에 흐린 초록 빛 띠가 소리 물결처럼 넘실대고, 초록 글이 흐림에서 맺혔다 작아지며 사라져요. 세로 줄 모자이크, 겹겹이 퍼지는 알약, 한 줄로 모이는 선이 차례로 이어지는 오디오 런칭.

## 보는 느낌
- 거의 흰 민트 바탕(#EEF3EC)에 크게 흐린 초록 빛 덩어리 하나. 처음엔 아래 1/3 에 가로 띠로 있고, 장면마다 모양을 바꿔요(세로 줄 모자이크, 겹 알약, 가운데 둥근 빛, 가는 가로선).
- 글은 한가운데 한두 줄만. 장면마다 글과 소품이 딱 하나씩이라 여백이 넉넉해요.
- 날카로운 모서리가 없어요. 빛은 늘 흐리고, 카드와 막대는 둥글고, 글도 흐림에서 들어와 흐림으로 나가요.
- 중반의 한 장면만 화면 전체가 밝은 민트·연두로 꽉 차요. 나머지는 옅은 바탕.

## 색
- 옅은 민트 바탕 60 · 초록 빛 덩어리 30 · 글 10.
- 빛: 초록 #7EE08F, 민트 #7FF0C4, 연두 #C9F2B8 가 섞이고, 아주 가끔 하늘빛이 살짝 비쳐요.
- 글: 첫 인사 문장은 밝은 초록(#3DCB6C 안팎), 기능 설명은 짙은 초록빛 먹색 #1F2A22. 스타일 색을 켜면 읽기 쉽게 짙은 초록 #17552D 로 써요.
- 강조(accent) 초록 #2FBF62. 강조 바탕 장면은 화면 전체를 민트·연두 띠로 채우고 글은 짙은 초록.
- 재생 막대 카드: 흰 바탕, 초록 재생 단추와 진행 점.

## 글자
- Geist(한글 Noto Sans KR 500·700). 둥글고 부드러운 산세리프 느낌이 맞아요.
- 큰 문장: 500, 짧은 변의 9~11%, 자간 −0.01em, 가운데 정렬, 두 줄까지.
- 기능 설명: 600, 짧은 변의 6~7%. 두 덩어리로 나눠 하나는 왼쪽 위, 하나는 오른쪽 아래에 두고 그 사이에 UI(재생 막대)를 끼워요.
- 아주 작은 머리글("이용할 수 있는 곳" 같은): 400, 짧은 변의 2.5%, 밝은 초록.

## 질감과 모양
- 그레인 0.04 거의 없음. 빛 덩어리는 `blur(6~10u)` 로 아주 흐리게.
- 재생 막대 카드: 흰 둥근 사각(모서리 `--u` × 1), 높이 짧은 변의 6%, 아주 옅은 그림자. 안에 재생 세모, 가는 선 막대, 진행 점, 시간 글자.
- 겹 알약: 모서리가 완전히 둥근 알약 너덧 겹, 겹마다 민트와 연두가 번갈아 들고 가장자리는 흐려요.
- 구간 막대: 둥근 모서리 막대 하나를 6칸으로 나눠 칸마다 초록 농도를 달리하고, 위에 작은 흰 이름표 줄.
- 가는 가로선: 두께 짧은 변의 0.8%, 민트 #7FF0C4.

## 움직임
- 100BPM, 보통. `power2.out` 으로 부드럽게, 넘침 없음. 장면은 2~3초씩 머물러요.
- 빛 띠는 3초 주기로 위아래로 넘실대요(가운데가 볼록, 양 끝이 오목해졌다 반대로).
- 글 등장: 흐림 8px → 0, 0.4초. 머무는 1초 동안 크기가 1 → 0.88 로 천천히 작아져요. 나갈 땐 다시 흐려지며 옅어지거나, 가로로 납작해지며 사라져요.
- 둘째 줄은 빛 띠 뒤에서 위로 떠올라요(첫 줄보다 0.15초 늦게).
- 재생 막대: 카드가 옆으로 늘어나는 동안 시간 글자가 0:30 → 3:00 으로 1.2초에 올라가요.
- 겹 알약: 카메라가 알약 겹을 지나 안으로 들어가듯 2.5초 동안 커지고, 가운데 글도 작게 시작해 크게 맺혀요.
- 선 모으기: 가는 가로선 네댓 줄이 0.6초에 한 줄로 모여 두꺼운 막대가 되고, 막대가 칸으로 나뉘며 이름표가 왼쪽부터 0.15초 간격으로 켜져요.
- 끝의 목록: 이름이 세로로 한 칸씩 굴러 올라가요(0.7초에 한 칸). 가운데 이름만 진하고 위아래는 옅게.

## 전환
- 흐림(blur)이 기본: 앞 글이 흐려지며 다음 글이 흐림에서 맺혀요.
- 세로 줄 모자이크(blocks): 화면이 세로 줄 칸으로 쪼개져 칸마다 다른 속도로 위아래로 번졌다 걷혀요.
- 그 밖에는 느린 페이드. 빠른 컷은 쓰지 않아요.
- 장면 쌓기: blur → blocks → fade.

## 대표 장면
1. **넘실대는 빛 띠 + 흐림에서 맺히는 글**
   ```
   // 빛 띠: 가로로 긴 타원 3~4개(초록·민트·연두)를 blur(8u) 로 흐리고 아래 1/3 에
   blobs.forEach((b, i) => M.place(b, S.W * (.2 + i * .3), S.H * .72 + Math.sin(t * 2 * Math.PI / 3 + i * 1.3) * S.H * .03, {sy: 1 + .15 * Math.sin(t * 2.1 + i)}));
   // 글: 흐림 → 선명, 머무는 동안 천천히 작아짐
   const k = M.prog(t, t0, .4);
   M.place(title, S.W / 2, S.H * .45, {s: 1 - .12 * M.prog(t, t0, 1.4), blur: (1 - k) * 8, o: k});
   ```
   - 장면 쌓기에서는 scenes.title 의 blur 와 bg 의 aurora 가 이 결을 따라가요.
2. **세로 줄 모자이크와 재생 막대**
   ```
   // 세로 칸 8~10개. 칸마다 색(민트·연두·하늘)과 위상이 다르고 blur(2u)
   cols.forEach((c, i) => M.place(c, (i + .5) * S.W / n, S.H / 2 + Math.sin(t * 1.6 + i * .9) * S.H * .08));
   const k = M.spring(t - t1, 'smooth');
   M.box(card, {x: S.W / 2, y: S.H / 2, w: M.lerp(20, 44, k) * u, h: 6 * u, r: u, bg: '#fff'});
   const mmss = v => { const s = Math.round(v); return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, '0')}`; };
   S.fx.counter(timeEl, t1, 1.2, 30, 180, {format: mmss});   // 0:30 → 3:00
   ```
   - 장면 사이 이음은 `S.tr.blocks(B, a, b, {color: '#C9F2B8', n: 9})`.
3. **겹 알약 속으로**
   - 알약 5겹을 같은 가운데에 두고 겹 i 의 크기를 `s_i = Math.pow(1.35, i) * M.lerp(.5, 1.6, M.prog(t, t2, 2.5))` 로 키우면 안으로 들어가는 느낌이 나요. 겹 색은 민트·연두 번갈아, 가장자리 `blur(1.5u)`.
   - 가운데 글은 `M.place(text, cx, cy, {s: M.lerp(.4, 1, M.spring(t - t2, 'soft'))})`, 나갈 땐 흐려지며 1.15 배로.
4. **선이 모여 구간 막대로, 굴러 올라가는 목록**
   - 가로선 5줄의 y 를 `M.lerp(y_i, cy, M.spring(t - t3, 'snappy'))` 로 한 줄에 모으고, 두께를 `M.anim` 으로 0.8u → 4u. 칸 경계와 이름표는 `M.at` 으로 0.15초 간격.
   - 목록은 열 하나의 y 를 0.7초마다 한 칸씩 `M.anim` 으로 올리고, 가운데에서 멀수록 opacity 를 낮춰요.

## 어울리는 곳 / 피할 것
- 어울림: 음악·오디오 서비스, AI 기능·모델 출시, 웰니스·헬스케어, 친환경 브랜드. 조용하고 밝은 20~30초 영상.
