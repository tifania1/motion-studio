# 기록 필름과 궤도 세리프 (다이어그램·데이터)

한 줄: 바랜 기록 필름 컷이 이야기를 열고, 먹빛 화면으로 넘어가면 가는 세리프 한 줄 둘레를 흰 머리카락 같은 타원 궤도선이 감싸며 천천히 기울어 도는 흑백 선화 설명 필름.

## 보는 느낌
- 두 막으로 나뉘어요. 앞 막은 옛 자료 화면처럼 바랜 색의 사진·영상 컷(지구, 계산기 화면, 금고 문, 지폐 인쇄기, 신문 스크랩 더미)이 화면을 꽉 채우고 몇 초마다 바뀌어요.
- 앞 막 끝에서 사진들이 작은 직사각형 틀로 줄어 엇갈려 겹치다가 하나씩 꺼지고, 먹빛 화면만 남아요.
- 뒤 막은 거의 빈 먹빛 화면. 가운데 작은 세리프 한 줄과 흰 가는 궤도선 몇 개가 전부예요. 여백이 화면의 90% 이상.
- 궤도선은 문장을 감싸는 타원이 되기도 하고, 여러 개가 비스듬히 서서 돌거나 화면 밖까지 크게 벌어져 지나가기도 해요. 끝에는 고리들이 모여 선으로 짠 구 하나가 돼요.
- 장면 사이 쉼표로 위아래 가장자리에 짧은 가로 막대 눈금이 흘러가요.

## 색
- 먹빛 바탕 #111111 85 · 흰 선과 글자 #E8E6E1 12 · 나머지 3.
- 궤도선은 흰색 50~90%로 농도를 달리해 겹친 깊이를 줘요. 뒤에 있는 고리일수록 옅게(30~45%).
- 앞 막 자료 화면은 바랜 황토 #B5874F 와 옛 필름 남색 #2E4A63 쪽으로 기운 색. 이 색은 사진에만 남고 그래픽에는 쓰지 않아요.
- 신문지 같은 미색 #E9E6DE 는 스크랩 장면(paper)에만 짧게.
- 강조색은 따로 두지 않고 거의 흰색 #F2F0EB 하나로 끝내요.

## 글자
- 영문은 Instrument Serif 400, 한글은 고운바탕 400. 가늘고 차분하게.
- 크기는 짧은 변의 4~5%로 작게, 가운데 정렬 한 줄. 두 줄을 넘기지 않아요.
- 강조는 굵기나 색 대신 궤도선으로 감싸서 해요. 이탤릭은 마무리 낱말 하나에만.
- 작은 설명 글은 Geist 400, 흰색 58%.

## 질감과 모양
- 그레인 0.06(초당 12번), 비네트 0.12. 기록 필름의 거친 맛이 먹빛 화면까지 살짝 이어지게.
- 궤도선 굵기는 1~1.5px. 두 겹 평행선(간격 3~4px)이 군데군데 끊기고, 끊긴 자리에 짧은 마디 눈금이 있어요.
- 그림자·빛 번짐·채움은 쓰지 않아요. 모든 그래픽은 선 하나로.
- 사진 틀은 모서리 거의 직각(0.4u), 테두리 없이.

## 움직임
- 80BPM, 느림. `sine.inOut` 으로 숨 쉬듯.
- 문장은 초당 12~14자로 글자씩 쳐지고, 다 쳐진 뒤 2~3초 머물러요.
- 궤도선은 1.2~1.8초에 걸쳐 한쪽 끝부터 그어지고(outCubic), 그 뒤 8~12초 주기로 아주 천천히 기울기를 바꾸며 돌아요.
- 고리 여러 개가 함께 돌 땐 각자 속도와 축을 조금씩 달리해 겹침이 계속 바뀌어요.
- 앞 막 자료 컷은 3~4초마다 바뀌고, 컷 안에서는 아주 느린 밀어 들어가기(4초에 3%)만.

## 전환
- 앞 막 자료 화면끼리는 컷.
- 앞 막에서 뒤 막으로는 사진이 작은 틀로 줄어 꺼지며 먹빛으로 페이드.
- 뒤 막 문장 사이는 컷이나 짧은 페이드(0.4초). 궤도선이 다음 장면까지 이어져 남아 있으면 장면이 끊기지 않고 흘러요.
- 장면 쌓기: cut → fade → cut.

## 대표 장면

1. 문장을 감싸는 궤도선
   ```
   // 가운데 세리프 한 줄 + SVG 타원 path 두 개(간격 3px), dasharray 로 군데군데 끊김
   S.ambient(t => {
     line.textContent = M.type(text, t, .3, 13);
     const k = M.ease.outCubic(M.prog(t, 1.4, 1.6));
     [outer, inner].forEach(p => M.draw(p, k));
     const tilt = Math.cos(t * Math.PI * 2 / 10) * .35 + .65;   // 10초 주기로 납작↔둥금
     ring.setAttribute('transform', `translate(${cx} ${cy}) rotate(${Math.sin(t * .2) * 8}) scale(1 ${tilt})`);
   });
   ```
   장면 쌓기에서는 marker: circle 과 deco rings 가 같은 결을 내요.
2. 기울어 도는 고리 무리
   - 고리 5개를 같은 중심에 두고 고리 i 의 세로 배율을 `Math.cos(t * w_i + φ_i)`, 회전을 `θ_i + t * 4` 도로. 투명도는 배율이 작을수록(옆으로 선 고리) 짙게.
   - 한 박마다 중심을 `M.anim` 으로 조금씩 옮겨 고리들이 비스듬한 줄로 늘어섰다가 다시 모이게 해요.
3. 선으로 짠 구
   - 같은 반지름 고리 6~8개를 서로 다른 축으로 돌려 구처럼 보이게 하고, 처음엔 `M.place(group, cx, cy, {s: 2.4})` 로 화면 밖까지 크게 벌어져 있다가 `M.spring(t - t0, 'smooth')` 로 1.0까지 오므라들어요. 다 모이면 구 전체가 아주 느리게 한 바퀴.
4. 기록 필름에서 먹빛으로
   - 자료 사진 4~5장을 겹쳐 두고 `M.at` 으로 3.5초마다 하나씩 보이게. 마지막엔 사진마다 `M.box` 로 화면 크기에서 작은 직사각형(짧은 변의 25~40%)까지 엇갈린 자리로 줄이고, 0.3초 간격으로 꺼뜨린 뒤 `S.tr` 페이드로 첫 세리프 장면에 넘겨요.
   - 쉼표 장면엔 위아래 가장자리에 짧은 가로선 3~4개를 `M.drift` 로 옆으로 천천히 흘려요(deco marks).

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·결제 인프라 소개, 기술 비전·선언 필름, 개념을 차근차근 설명하는 긴 영상, 지난 역사에서 오늘로 넘어오는 브랜드 이야기.
- 피할 것: 밝은 바탕 장면을 길게 쓰기, 굵은 제목, 원색 강조색, 빠른 박자 컷과 튀는 이징, 손그림 선 떨림.
- 자료 화면은 직접 찍었거나 쓸 권리가 있는 옛 사진·영상으로 채워요. 없으면 앞 막을 짧게 줄이고 궤도선 장면만으로도 이 결이 살아요.
