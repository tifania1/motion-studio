# 마커 노트 (손그림)

한 줄: 크림색 모눈 종이에 마커로 쓴 메모. 선이 살짝 떨리고, 강조할 말엔 빨간 동그라미가 한 획에 그어져요.

## 보는 느낌
- 왼쪽 정렬. 글은 화면 왼쪽 2/3 안에, 오른쪽엔 낙서(화살표, 별표, 작은 체크)를 하나쯤 둬요.
- 바탕에 옅은 모눈. 카드는 종이 쪽지처럼 살짝 기울고(−1~1.5도) 아주 옅은 그림자.
- 한 화면에 글 두 줄, 많아야 세 줄. 칠판보다 공책에 가까운 밝고 친근한 느낌.

## 색
- 바탕 75 · 글자 20 · 강조 5.
- 바탕 크림 종이(#F4EDE0), 글자 마커 먹색(#1E1B18).
- 강조는 빨간 마커(#E2553A) 하나. 보조로 파란 볼펜(#2F6BDB)·노란 형광펜(#F2C94C)을 장면마다 한 군데만.

## 글자
- 손글씨: 한글은 나눔손글씨 펜(Nanum Pen), 영문·숫자 큰 글은 Caveat, 본문·작은 글은 개구(Gaegu) 굵게.
- 제목은 짧은 변의 8~10%, 줄 간격 1.1, 자간 0. 굵기를 바꾸지 말고 크기와 색으로만 위계를 줘요.
- 숫자는 Caveat 로 크게(짧은 변의 25% 이상). 단위는 손글씨 펜으로 작게.

## 질감과 모양
- 종이(warm) + 섬유 + 아주 약한 그레인 + 비네트 조금.
- 선 떨림(boil) 1.0, 초당 8번. 움직임은 초당 12장으로 끊어서(stepped 12) 손으로 그린 애니메이션처럼.
- 모서리 1.2u. 카드·숫자 상자·막대 둘레는 손으로 그은 테두리(장면 쌓기 rough).

## 움직임
- 100BPM. 들어올 땐 back.out(1.4) 로 아주 조금 넘쳤다 자리 잡음. 어절 사이 간격은 보통의 1.3배.
- 글이 다 써진 뒤 강조 동그라미 0.6초, 그다음 반 박 쉬고 다음 장면.
- 나갈 때는 따로 사라지지 않고 다음 장면이 밀고 들어와요.

## 전환
- 밀어내기(push)와 컷. 공책 페이지를 넘기듯 옆으로 밀어요. 원형·조리개 같은 매끈한 전환은 쓰지 않아요.

## 대표 장면

1. 써지는 제목 + 동그라미
   ```
   const ws = S.words(ttl);                         // 어절로 쪼갬
   S.fx.rise(ws, T0 + .1, { stagger: .07 * 1.3, ease: 'back.out(1.4)' });
   // 강조 동그라미: 장면 쌓기는 marker: circle + rough 로 자동. 직접 짤 때는
   path.setAttribute('d', M.rough('ellipse', { cx, cy, rx: w / 2 + pad, ry: h / 2 + pad * .5, seed: 3 }));
   tl.fromTo(path, { strokeDashoffset: L }, { strokeDashoffset: 0, duration: .6, ease: 'power2.inOut' }, T0 + 1.1);
   ```
2. 쪽지 카드
   - 카드가 −1.2도 기울어 아래에서 올라오고, 0.3초 뒤 둘레에 손 테두리(M.rough('rect'))가 한 변씩 그어져요.
3. 숫자 메모
   - Caveat 큰 숫자가 S.fx.counter 로 올라가고, 다 오르면 빨간 마커 밑줄(M.rough('line', {amp: 1.6}))이 0.45초에 그어져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 수강생 모집, 강의·클래스 소개, 공지, 체크리스트·꿀팁, 작은 가게 소식.
- 피할 것: 반짝이는 그라디언트, 유리 질감, 굵은 고딕 큰 제목, 한 화면에 글 세 줄 넘게.

## 배운 곳
- 직접 정리. 갤러리 영상에서 배운 게 아니고, 마커 메모·화이트보드 설명 영상에서 널리 쓰는 기법(획 순서, 동그라미 강조, 초당 8번 선 떨림, 초당 12장 끊어 그리기)으로 정리했어요.
- 갤러리에서 배운 손그림 결은 따로 있어요: marker-scrawl-montage, chalk-math-board, doodle-faces-strikeout, manga-panel-bubbles, river-line-lettering, serif-marker-word, ink-gesture-blobs, navy-etching-plates.
