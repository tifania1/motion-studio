# 산호 글자꼴 해부 (타이포)

한 줄: 옅은 회색·짙은 회색·산호 분홍 세 색만으로 글자꼴을 뜯어 보여 주는 서체 공개 필름. 문장부호가 커서 옆에서 갈아 끼워지고, 화면보다 큰 글자 획과 기준선, 굵기가 차오르는 글자 줄이 박자마다 컷으로 이어져요.

## 보는 느낌
- 주인공은 글자 하나하나예요. 화면엔 낱말 하나, 글자 하나, 아니면 글자의 획 한 토막만 놓여요.
- 크기를 극단으로 오가요. 작은 가는 글씨 한마디(짧은 변의 4% 안팎)가 가운데 놓였다가, 다음 컷엔 굵은 낱말이 화면 양끝을 넘쳐요. 이 들숨·날숨이 리듬의 뼈대예요.
- 글자를 도면처럼 다뤄요. 가는 기준선, 곡선을 따라 그은 호, 앵커 네모와 직각 구성선이 글자 둘레에 잠깐 드러났다 사라져요.
- 장면 바탕은 옅은 회색 → 산호 → 옅은 회색 → 짙은 회색으로 컷마다 바뀌고, 짙은 회색 판이 옆에서 밀려 들어와 화면을 반으로 가르기도 해요.
- 끝 무렵엔 회색 겹 줄무늬가 글자 하나를 감싸는 착시 무늬, 굵은 글자들이 제각각 돌아 흩어진 판이 한 장씩 끼어들어요.

## 색
- 옅은 회색 #ECECEC 55 · 짙은 회색 #3C3C3C 30 · 산호 #DE5267 15.
- 옅은 회색 위 글자는 짙은 회색, 짙은 회색 위 글자는 흰색·옅은 회색. 산호는 강조 낱말, 커서, 기준선, 구성선, 그리고 통째로 칠하는 바탕 한두 장에 써요.
- 산호 바탕 위 글자는 흰색으로 크고 굵게 쓰면 잘 읽혀요. 작은 글씨를 산호 위에 둘 땐 거의 검정(#141414)으로.
- 중간 회색 #959595 는 겹 줄무늬 장면의 한 겹으로만.

## 글자
- 둥글고 반듯한 기하 산세리프 하나로 끝까지 가요. Geist 가변(100~900) + 한글 Noto Sans KR.
- 굵기 대비가 핵심이에요. 작은 말은 200~300 으로 가늘게, 큰 낱말은 800~900 으로 꽉 차게. 한 글자를 크게 보여 줄 땐 300 정도로 가늘게 두어 획 모양이 드러나게 해요.
- 큰 낱말은 자간 −0.02em, 화면 너비보다 커서 양끝이 잘려도 괜찮아요. 작은 말은 자간 0, 가운데 한 줄.
- 한 문장 안에서 앞 낱말은 짙은 회색, 뒤 낱말만 산호로 칠해 강조해요.
- 한글은 2~4자 낱말을 크게, 문장은 짧게 끊어서.

## 질감과 모양
- 질감 없이 평평하고 매끈하게. 그림자·빛·그레인을 쓰지 않아요.
- 선은 두 종류: 아주 가는 산호 선(1~2px, 기준선·호·구성선)과 글자 획 굵기의 단색 면.
- 앵커는 작은 짙은 회색 정사각형, 커서는 흰 화살표에 짙은 테두리.
- 모서리는 거의 각지게(0.4u). 판과 줄무늬는 직각.

## 움직임
- 104BPM, 보통 빠르기. 작은 말 장면은 2박쯤 머물고, 큰 낱말·해부 장면은 1~2박에 컷.
- 판이 밀려 들어오거나 글자 줄이 흐를 땐 `power3.inOut` 으로 미끄러지듯, 큰 낱말은 `expo.out` 으로 확 자리 잡아요.
- 문장부호 바꾸기, 산호 블록 얹기 같은 작은 변화는 애니메이션 없이 박에 맞춘 컷이에요.
- 굵기는 움직임의 재료예요. 글자가 가는 굵기에서 굵게 0.5초 만에 차오르거나, 줄지은 같은 글자가 왼쪽부터 굵기를 한 단계씩 올려요.
- 작은 말은 커서를 따라 초당 14자쯤으로 쳐져요.

## 전환
- 컷이 기본. 짙은 회색 판이 옆에서 밀려와 화면을 덮는 와이프, 큰 낱말이 옆으로 빠지는 밀어내기를 섞어요.
- 장면 쌓기: cut → wipe → push → cut. 페이드·흐림 전환은 쓰지 않아요.

## 대표 장면

1. **문장부호 갈아 끼우기 → 산호 홍수**
   ```
   // 낱말 + 끝 부호 + 산호 막대 커서. 부호만 박마다 바뀜
   const marks = ['.', '?', '!'];
   S.ambient(t => {
     punct.textContent = M.at(marks.map((m, i) => [M.beat(i * 2), m]), t);
     caret.style.opacity = (t % M.beat(1)) < M.beat(.5) ? 1 : 0;   // 깜빡
     block.style.visibility = t >= M.beat(6) ? 'visible' : 'hidden';   // 첫 글자에 산호 블록 한 박
   });
   // 다음 박에 컷: 산호 바탕, 흰 '!' 하나를 짧은 변의 30% 크기로 가운데
   ```
2. **기준선 위 굵은 낱말과 글자 해부**
   - 가는 산호 가로선 4개(윗선·엑스하이트·밑선·내림선)를 `M.draw(line, M.prog(t, t0 + i * .06, .4))` 로 왼쪽부터 긋고, 굵은 산호 낱말을 그 위에 `M.place(word, cx, cy)` 로 컷 등장.
   - 큰 글자 하나(굵기 300, 화면 높이 80%)의 곡선 둘레에 SVG 호 3개를 `M.draw` 로 0.6초에 그어요. 다음 컷엔 같은 글자를 4배로 키워 획 한 토막만 보이게 잘라 짙은 회색·옅은 회색 면으로.
   - 구성선: 앵커 네모를 `M.anim([[t0, x0], [t0 + .5, x1, {e: 'inOutCubic'}]], t)` 로 끌고, 산호 선이 앵커를 따라 직각으로 꺾이며 늘어나요. 커서(`M.Cursor`)가 앵커를 잡고 있어요.
3. **굵기가 차오르는 글자 줄 + 판 와이프**
   ```
   // 같은 글자 8개를 한 줄로, 굵기를 왼쪽부터 한 단계씩
   S.ambient(t => {
     glyphs.forEach((g, i) => {
       const k = M.prog(t, i * .08, .5);
       g.style.fontVariationSettings = `'wght' ${200 + 700 * M.ease.inOutCubic(k)}`;
     });
     row.style.transform = `translateX(${M.anim([[0, 0], [M.beat(4), -W * .3, {e: 'inOutCubic'}]], t)}px)`;
   });
   // 짙은 회색 판: M.box(panel, {x: W - w, y: 0, w, h: H}), w 를 0 → W*.5 로 power3.inOut
   ```
   - 짙은 회색 위에선 같은 줄을 흰색·산호 세로 막대 글자(가는 글자들)로 바꿔 한 번 더 보여 줘요.
4. **겹 줄무늬 착시 → 산호 엔딩**
   - 짙은 회색·중간 회색·옅은 회색 직각 띠를 글자 하나 둘레에 겹겹이 두르고, 가운데 글자만 산호로. 띠는 `M.box` 로 바깥에서 안쪽으로 한 겹씩 0.1초 간격.
   - 이어 굵은 글자 몇 개를 제각각 돌려 흩뿌린 판 한 장(`S.tr.whip` 으로 들어옴), 그다음 컷으로 산호 바탕 가운데 작은 흰 문장이 쳐지고 마지막 낱말만 굵게 덧붙어요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 서체·글꼴 공개, 브랜드 리뉴얼 발표, 디자인 시스템 소개, 이름·로고타입 공개, 타이포 중심 티저.
- 피할 것: 그라디언트·빛 번짐, 사진·3D 소품, 세 색 밖의 강조색, 손그림 선, 그레인·종이 질감, 한 화면에 긴 문단 여러 개(본문 견본은 한 장, 크게 잘라서만).
