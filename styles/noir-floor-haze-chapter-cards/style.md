# 어둠 아래 장 바뀌는 안개 (제품 UI)

한 줄: 거의 검은 화면 아래쪽에 흐린 빛기둥 안개가 깔리고, 장이 바뀔 때마다 그 안개가 파랑, 호박, 청록으로 물들어요. 그 위로 어두운 UI 카드가 비스듬히 미끄러져 와 평평하게 내려앉고, 흰 글자는 흐림에서 한 글자씩 맺혀요.

## 보는 느낌
- 화면 위쪽 60%는 거의 검은 #0E0F11. 아래쪽 40%에만 안개가 있어요. 안개는 세로로 긴 빛 덩어리 여러 개를 아주 크게 흐려 놓은 모양이라, 멀리 초점 밖의 불빛 기둥처럼 보여요.
- 장마다 안개 색이 하나씩 정해져요. 여는 장 파랑, 두 번째 장 호박, 세 번째 장 청록, 마지막 장과 끝은 다시 파랑. 색이 바뀌는 순간이 곧 장이 바뀌는 신호예요.
- 주인공은 안개 위에 떠 있는 어두운 UI 카드 한 장. 카드는 화면 너비의 50~70%, 가운데에 놓여요. 카드 뒤로 안개가 비쳐 아랫변이 살짝 밝아요.
- 장 사이에는 UI 없이 흰 표제 한두 줄만 가운데에 둬요. 여백이 넓고 조용해요.

## 색
- 검정 바탕 60 · 안개 25 · 흰 글자 10 · 카드 속 작은 색 5.
- 바탕 #0E0F11, 카드 #1C1D20(가장자리에 흰색 8% 1px 선), 글자 #EDEEF0, 흐린 글자 흰색 60%.
- 안개 세 색: 파랑 #4F8EF0(+ 하늘 #9CC3F0 섞음), 호박 #E39A4A(+ 모래 #D9B98A), 청록 #5FC6A8(+ 옅은 민트 #A8E0CC). 한 장에는 한 색만.
- 카드 속 작은 색: 꺾은선은 하늘 #6EC3E8, 지도 점은 빨강 #E0443A 와 맥박 치는 초록 #4BD06A, 음성 말풍선은 연두 #CFE8B8, 터미널 글씨는 호박 노랑 #F2C14E.
- 강조색(accent)은 파랑 #4F8EF0, 그 위 글자는 아주 짙은 남색.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 표제는 500~600 굵기, 자간 −0.01em, 가운데 정렬 한두 줄. 짧은 변의 7~9% 크기.
- 카드 속 제목은 600 굵기로 짧은 변의 4% 안팎, 왼쪽 정렬. 그 위 작은 이름표와 시간은 흰색 50%, 아주 작게.
- 터미널 장면만 Geist Mono, 호박 노랑 글씨에 줄 맨 앞 기호(`$`, `#`, `>`).
- 글자는 늘 흐림에서 맺혀요. 한 글자씩 왼쪽부터, 아직 맺히지 않은 글자는 자간이 살짝 벌어지고 흐려요.

## 질감과 모양
- 그레인·종이 같은 질감은 쓰지 않아요. 부드러움은 모두 안개의 큰 흐림에서 와요.
- 카드 모서리 1.6u, 얇은 흰 테두리 하나와 아래로 깊고 옅은 그림자. 메뉴는 알약 모양, 고른 칸만 흰색 10% 로 채워요.
- 폰은 검은 둥근 틀, 아래 홈 막대. 지도 카드는 짙은 회색 지도에 흰 지명.
- 움직이는 동안에는 이동 방향으로 흐림 2~4px 를 얹어요.

## 움직임
- 96BPM, 보통 속도. 장면 하나가 3~5초 머물러요.
- 카드는 비스듬히 누운 채(rotateY −22°, rotateX 10°, 조금 크게) 오른쪽 아래에서 들어와 1.2초에 걸쳐 평평하게 서요(power3.out). 선 뒤엔 1~2초 동안 아주 천천히 다가가요(크기 +3%).
- 표제와 카드 제목은 글자마다 흐림 8px → 0, 투명 → 불투명으로 0.5초, 글자 사이 0.04초.
- 안개는 쉬지 않고 일렁여요. 빛기둥마다 높이와 좌우 위치가 6~9초 주기로 조금씩 달라져요.
- 커서는 작은 흰 화살표. 천천히 와서 누르면 알약이 0.15초 눌렸다 돌아와요.

## 전환
- 흐림 전환(blur)이 기본. 장면이 흐려지며 빠지고 다음 장면이 흐림에서 맺혀요.
- 표제 장면은 서서히(fade), 카드끼리 바뀔 땐 옆으로 밀어내기(push)에 흐림을 얹어요.
- 장면 쌓기: blur → fade → push. 안개 층은 전환 동안에도 그대로 남고 색만 바뀌어요.

## 대표 장면

1. 장마다 색이 바뀌는 바닥 안개
   ```js
   // 빛기둥 7개: 세로로 긴 둥근 사각을 크게 흐림, 화면 아래 40% 안에만
   const pillars = S.$$('.haze i');            // filter: blur(calc(var(--u)*6))
   const chapters = [[0, '#4F8EF0'], [9.5, '#E39A4A'], [15.5, '#5FC6A8'], [23.5, '#4F8EF0']];
   S.ambient(t => {
     const prev = M.at(chapters.map(([at, c], i) => [at, i > 0 ? chapters[i - 1][1] : c]), t);
     const next = M.at(chapters, t);
     const at = M.at(chapters.map(([a]) => [a, a]), t);
     const col = M.color(prev, next, M.ease.inOutCubic(M.prog(t, at, 1)));
     pillars.forEach((p, k) => {
       const h = 1 + Math.sin(t * .8 + k * 1.7) * .12;
       M.place(p, W * (k + .5) / 7 + Math.sin(t * .5 + k) * W * .015, H * .9, { sy: h });
       p.style.background = col;
     });
   });
   ```
2. 비스듬히 들어와 평평하게 서는 카드
   ```js
   const k = M.ease.outCubic(M.prog(t, t0, 1.2));
   card.style.transform = `perspective(1400px) translate(${(1 - k) * W * .18}px, ${(1 - k) * H * .12}px)
     rotateY(${(1 - k) * -22}deg) rotateX(${(1 - k) * 10}deg) scale(${1.15 - k * .15 + M.prog(t, t0 + 1.2, 3) * .03})`;
   card.style.filter = `blur(${(1 - k) * 4}px)`;
   S.fx.blurIn(S.chars(title), { at: t0 + .4, each: .04, dur: .5 });   // 카드 제목 한 글자씩 맺힘
   // 이어 M.Cursor 로 메뉴 알약을 누르고, 꺾은선은 M.draw(line, M.prog(t, t0 + 2.4, 1.6))
   ```
3. 장 표제와 호박빛 터미널
   - 안개 색이 바뀌는 1초 동안 가운데에 흰 표제 두 줄을 `S.fx.blurIn` 으로 맺히게 하고, 한 박 머문 뒤 `S.tr.blur` 로 다음 장면에 넘겨요.
   - 이어 반투명 어두운 창(위 막대에 작은 제목) 속에 Geist Mono 호박 노랑 줄을 `M.type(text, t, ti, 30)` 로 한 줄씩 쳐요. 마지막 줄만 따옴표 속 낱말이 하얗게.
4. 폰 대화창, 지도 맥박, 그리고 끝
   - 폰을 화면 아래에서 `M.spring(t - t0, 'smooth')` 로 올리고, 말풍선을 하나씩 톡 띄운 뒤 음성 말풍선의 막대 파형이 왼쪽부터 차올라요. 다음 박에 카메라가 물러나며 폰 전체가 보이고 대화가 위로 밀려 쌓여요.
   - 지도 카드는 빨간 점들이 박마다 깜빡이고, 커서가 누른 자리에 초록 점이 `M.place(dot, x, y, {s: 1 + Math.sin(t * 4) * .15})` 로 맥박 치며 커져요. 옆에서 작은 정보 카드가 밀려 들어와 꺾은선을 그어요.
   - 끝은 파란 안개 위 가운데에 작은 흰 기호가 반 바퀴 돌며 내려앉고, 한 박 뒤 왼쪽에 낱말 하나가 흐림에서 맺혀 나란히 서요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 에이전트·자동화 기능 런칭, 기능을 세 갈래 장으로 나눠 소개할 때, 개발자 도구·API 소개, 대화·메신저 연동 기능, 데이터·지도 대시보드 시연.
- 피할 것: 흰 바탕이나 밝은 판, 안개를 화면 위까지 채우기(위쪽 어둠이 있어야 카드가 떠 보여요), 빠른 컷 몽타주, 굵고 꽉 찬 제목, 한 장면에 강조색 여러 개.
- 장을 셋쯤으로 나누고 장마다 안개 색 하나를 정해 두면 이 결이 가장 잘 살아요.
