# 선 아이콘 분할 시스템 (제품 UI)

한 줄: 먹색 바탕 가운데 작은 파란 선 아이콘 하나가 동심원 물결로 퍼지고, 화면이 밝은 판과 어두운 판으로 갈라져 박자마다 아이콘이 갈려요. 오른쪽에선 점·네모·고리·알약이 서로 모양을 바꾸고, 끝에는 큰 UI 조각과 아이콘 격자로 이어져요.

## 보는 느낌
- 처음과 끝은 거의 빈 먹색 화면이에요. 한가운데 아이콘 하나나 짧은 문장 한 줄만 작게 두고, 나머지는 다 비워요.
- 가운데 토막은 분할 화면이에요. 왼쪽 밝은 회색 판에 연파랑 정사각 타일과 그 안의 남색 선 아이콘, 오른쪽 먹색 판엔 파란 도형 하나. 판 경계가 옆으로 밀리며 비율이 바뀌어요(1:1 → 2:1 → 1:2).
- 그다음엔 UI 조각을 화면보다 크게 잘라 보여 줘요. 탭 막대, 둥근 전환 버튼, 주소 줄, 별점과 알약 칩. 모서리가 화면 밖으로 넘쳐도 괜찮아요.
- 아이콘은 모두 같은 굵기의 둥근 끝 선 그림이에요. 이 하나의 선 굵기가 화면 전체의 결을 묶어 줘요.

## 색
- 먹색 #1F252B 60 · 밝은 회색 판 #E6EAEE 25 · 파랑 #2FA0D4 10 · 연파랑 #A9CDE9 와 남색 #1E3A52 5.
- 먹색 위 아이콘과 도형은 파랑, 글자는 아주 옅은 청회색 #E3EBF2.
- 밝은 판 위에선 아이콘을 남색으로 그리고 뒤에 연파랑 정사각 타일을 깔아요. UI 조각 속 선택된 칸만 파랑.
- 엔딩은 화면 전체를 파랑 한 장으로 칠하고 글자는 흰빛.

## 글자
- 둥글고 굵은 산세리프 느낌으로 Geist 800 (한글은 Noto Sans KR Bold·Black). 자간 −0.01em.
- 문장은 작게, 짧은 변의 4~5%. 가운데 정렬 한 줄. 앞이나 뒤에 같은 높이의 선 아이콘을 붙여요.
- 큰 낱말은 동심원 오프닝 한 번만, 짧은 변의 20% 안팎으로 화면 아래 가장자리에 걸쳐 잘리게.
- UI 조각 속 글자는 Geist 600~700, 남색. 아래 줄은 400 으로 굵기만 낮춰 위계를 줘요.

## 질감과 모양
- 질감 없이 매끈한 평면. 그림자도 거의 없고, UI 조각의 전환 버튼에만 아주 옅은 그림자 하나.
- 선 아이콘: 둥근 끝·둥근 꺾임, 선 굵기는 아이콘 크기의 약 9%.
- 아이콘 타일은 모서리 없는 정사각, UI 칩·버튼·토글은 완전한 알약. 카드 모서리는 `--u` × 2.4.

## 움직임
- 100BPM. 아이콘 바꾸기는 반 박(0.3초), 분할 판 이동은 2박.
- 아이콘은 `back.out(1.5)` 로 살짝 넘쳤다 자리 잡아요. 나갈 땐 컷.
- 도형 모양 바꾸기는 스프링처럼 부드럽게 0.5초. 점이 늘어나 막대가 되고, 막대가 줄어 알약 손잡이가 되는 식으로 늘 이어져요.
- UI 조각은 한 장면에 3~4초 머물며 카메라가 천천히 옆으로 흘러요(4초에 화면 너비의 8%).

## 전환
- 분할 판 경계가 옆으로 쓸고 지나가는 와이프가 기본. 오프닝은 동심원이 열리는 원형 열림(iris).
- 아이콘끼리는 컷, UI 조각 사이는 밀어내기. 장면 쌓기: wipe → iris → cut → push.

## 대표 장면
1. **작은 아이콘에서 동심원 물결**
   ```
   const k = M.spring(t - .2, 'bouncy');
   M.place(icon, cx, cy, {s: .4 + k * .6});
   rings.forEach((r, i) => {               // SVG circle 4개, 안쪽일수록 진한 파랑
     const R = M.anim([[0, 0], [1 + i * .15, M.floodRadius(cx, cy) * (1 - i * .2), {d: .9, e: 'outCubic'}]], t);
     r.setAttribute('r', R);
   });
   scatter.forEach((ic, i) => {            // 작은 선 아이콘 20여 개, 고리 따라 바깥으로
     const a = i / scatter.length * Math.PI * 2, d = M.ease.outCubic(M.prog(t, 1.2, .8)) * W * .45;
     M.place(ic, cx + Math.cos(a) * d, cy + Math.sin(a) * d, {o: d > 0 ? 1 : 0});
   });
   // 장면 쌓기에선 deco rings 와 S.tr.iris 로 같은 결
   ```
2. **분할 화면과 모양 바꾸는 도형**
   - 왼쪽 판(`paper`)의 연파랑 타일 속 남색 아이콘을 `M.at([[t0, 0], [t0 + M.beat(.5), 1], …], t)` 로 반 박마다 갈아 끼우고, 바뀔 때 `M.spring(t - ti, 'bouncy')` 로 0.9 → 1 톡.
   - 오른쪽 먹색 판의 파란 도형은 `M.box(shape, {x, y, w, h, r})` 하나로: 점(w=h, r=50%) → 둥근 네모(r=20%) → 고리(테두리만, 속 비움) → 세로 막대(h=H) → 막대 위 알약 손잡이가 위아래로 미끄러짐. 값마다 `M.anim(…, {d: .5, e: 'inOutCubic'})`.
   - 판 경계는 `clipPath: inset(0 X% 0 0)` 로 2박마다 옮겨요. 엔진 전환 `S.tr.blocks` 대신 와이프 한 줄이 이 결이에요.
3. **크게 자른 UI 조각**
   - 탭 막대·전환 버튼·별점을 화면보다 1.6배 크게 두고 `M.place(ui, x0 - t * W * .02, cy)` 로 천천히 흘려요. 전환 버튼은 흰 알약이 `M.anim` 으로 옆 칸으로 미끄러지고, 별점은 별 다섯 개가 0.08초 간격으로 `M.spring` 톡 → 파랑으로 채움(`M.color`).
4. **아이콘 줄과 한 줄 문장**
   - 9×5 격자 아이콘을 `M.rng(7)` 순서로 0.03초 간격 톡 켠 뒤 컷. 이어 먹색 가운데 `아이콘 + 짧은 문장`, 문장 위 아이콘 줄 6~7개를 박자마다 다른 묶음으로 바꾸다 마지막엔 하나만 남김. 오른쪽에서 왼쪽으로 쓰는 말을 보여 줄 땐 아이콘을 문장 반대편으로 옮기고 좌우 뒤집어요(`scaleX(-1)`).
   - 엔딩은 `S.tr.wipe` 로 파란 판(accent) 한 장, 가운데 이름 한 줄을 pop.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·아이콘 세트 공개, 앱 리뉴얼 소개, 기능을 아이콘으로 훑을 때, 다국어·접근성 이야기.
- 피할 것: 그라디언트와 빛 번짐, 종이·그레인 같은 질감, 채운 아이콘이나 3D 아이콘, 파랑 말고 다른 강조색, 긴 문장.
- 아이콘은 모두 같은 선 굵기로 맞춰요. 굵기가 섞이면 이 결이 금방 흐트러져요.
