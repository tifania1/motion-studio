# 옛 검색창 이야기 (레트로·픽셀)

한 줄: 2000년대 웹 검색 화면에서 검색어를 하나씩 쳐 나가며 이야기를 들려줘요. 자동완성 목록, 파란 밑줄 링크, 초록 주소, 회색 버튼, 넓게 봤다가 컷으로 바짝 붙는 화면.

## 보는 느낌
- 아무 장식 없는 옛 웹 화면 하나가 무대예요. 가운데 큰 이름(브랜드 이름을 글자로), 얇은 입력칸, 작은 회색 버튼 둘.
- 사람이 직접 검색하는 화면을 녹화한 듯한 담담한 결. 말은 화면 속 검색어가 다 해요.
- 장면은 세 가지 크기만 오가요: 전체 화면, 결과 목록, 결과 한 줄을 바짝 당긴 화면.

## 색
- 바탕 #F1F1F1(살짝 바랜 흰색) 80 · 검정 글 #222 12 · 링크 파랑 #1A0DAB 5 · 주소 초록 #228822 2 · 나머지 1.
- 입력칸 테두리 #A0A0A0, 눌린 칸에는 파란 빛 #4D90FE 이 은은하게.
- 이름(로고 자리)을 색으로 쓰고 싶으면 파랑·빨강 #DD4B39·노랑 #EEB211·초록을 글자마다 돌려 써도 돼요.

## 글자
- 작은 산세리프: Archivo 400(폭 95%) + 한글 Noto Sans KR 500. 옛 웹 기본 글꼴(Arial·돋움) 같은 담백한 결.
- 결과 제목은 파란 밑줄 + 친 검색어 부분만 굵게. 요약은 검정, 친 낱말만 굵게. 주소는 초록 작은 글씨.
- 화면 속 글은 작게(짧은 변의 2.2~3%). 확대 컷에서만 커 보여요. 큰 제목을 따로 띄우지 않아요.

## 질감과 모양
- 그레인 0.05, 비네트 0.12. 오래된 화면 녹화처럼 아주 살짝 바랜 느낌.
- 입력칸: 1px 회색 테두리, 모서리 거의 0. 버튼: 연회색 바탕 + 1px 테두리 + 위가 살짝 밝은 그라디언트.
- 자동완성 목록: 입력칸 바로 아래 흰 상자, 1px 테두리, 줄 간격 1.35, 커서가 닿은 줄만 연파랑 #D6E4FD.

## 움직임
- 96BPM. 카메라는 미끄러지지 않고 컷으로 크기를 바꿔요(전체 → 목록 → 한 줄). 확대 컷 안에서만 아주 천천히 다가감(2초에 4%).
- 타자는 사람 손처럼 고르지 않게: 글자 간격 0.08~0.16초(시드 난수), 띄어쓰기 뒤에 조금 쉼.
- 커서는 화살표와 손가락 두 가지. 링크 위에서는 손가락, 누를 때 0.08초 눌림.

## 전환
- 컷이 기본(버튼을 누르면 곧바로 다음 화면). 그다음 확대(zoom) 컷, 끝맺음만 페이드.

## 대표 장면

1. **입력칸 모서리에서 물러남**
   ```
   // world 에 검색 첫 화면을 1080 기준으로 그려 두고
   M.camera(world, 입력칸왼쪽x + 40, 입력칸y, M.at([[0, 4.2], [t1, 1]], t));   // 컷이라 계단 값
   caret.style.opacity = Math.floor((t - t0) / M.beat(.5)) % 2 ? 0 : 1;
   // 크게 당긴 동안 입력칸 테두리에 box-shadow: 0 0 1.2u var(--glow)
   ```
2. **타자 + 자동완성**
   ```
   const typed = M.type(q, t, t0, 9);
   list.innerHTML = 후보(typed).map(s => `${S.esc(typed)}<b>${S.esc(s.slice(typed.length))}</b>`).join('<br>');
   // 커서 경로: M.cursorAt([[tA, 목록줄x, 목록줄y, .4], [tB, 버튼x, 버튼y, .3]], [tB + .1], t)
   ```
   후보 문구는 이야기를 돕는 짧은 말로 직접 지어요(실제 검색 순위처럼 보이게 하지 않기).
3. **결과 화면 → 한 줄에 바짝**
   - 버튼 누름 + 0.1초 → 컷. 결과 묶음 3~4개(파란 밑줄 제목, 요약 두 줄, 초록 주소).
   - 반 박 뒤 컷으로 `M.camera` 2.5배, 결과 한 줄이 화면 폭을 채움. 손가락 커서가 제목 위로 와서 누르면 제목 색이 #660099(누른 링크)로.
4. **끝맺음**
   - 마지막 검색어를 치고 버튼에 커서가 닿는 순간 화면이 0.5초에 회색으로 비고, 가운데 작은 회색 한 마디(짧은 변의 2.6%)가 페이드로 떴다 2초 뒤 사라짐.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 감성 이야기, 추억·향수를 건드리는 광고, 고객 여정 보여 주기, 검색·질문으로 푸는 정보 광고.
- 피할 것: 요즘 둥근 UI, 그라디언트와 유리 질감, 큰 굵은 제목, 빠른 장면 연타. 실제 검색 서비스의 로고·화면을 그대로 그리지 않아요(이름과 색 배치는 브랜드 것으로).
