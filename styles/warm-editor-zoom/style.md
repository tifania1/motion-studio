# 편집기 줌 투어 (제품 UI)

한 줄: 따뜻한 회색 바탕에 떠 있는 앱 창. 카메라가 편집하는 곳으로 바짝 다가가 툴바·색 견본·선택 상자를 보여 주고, 장면은 가로로 휙 넘겨요.

## 보는 느낌
- 실제 앱을 잘 다듬어 녹화한 화면. 앱 창은 흰색, 둘레는 따뜻한 회색이라 종이 위에 놓인 화면처럼 보여요.
- 넓게 보여 줄 때는 창 전체가 화면의 80%, 일할 때는 글 상자 하나가 화면 폭을 넘을 만큼 바짝 확대.
- 편집 중인 결과물(포스터·슬라이드)은 진한 색이어도 괜찮아요. 둘레 UI 가 밝아서 결과물이 돋보여요.

## 색
- 바탕 60 · 흰 창 30 · 글자 7 · 강조 3.
- 바탕 #E7E6E1, 창 #FFFFFF, 글자 #1C1B19.
- 강조는 선택 파랑(#3E63DD) 하나. 선택 테두리·드래그 하이라이트(파랑 35%)·손잡이·@멘션 칩에 써요.
- 편집되는 결과물 색은 브랜드 색을 그대로(예: 어두운 판 #212727 + 청록 #48A8B4).

## 글자
- UI 글자는 반듯한 고딕(Geist + Noto Sans KR 500/700). 작고 또렷하게.
- 자막이 필요하면 창 밖 왼쪽 위에 작게. 화면 글의 주인공은 편집되는 결과물 속 제목이에요.
- 결과물 속 제목은 굵은 그로테스크가 잘 어울려요(브랜드 글꼴이나 Archivo 900).

## 질감과 모양
- 질감 없음.
- 창 모서리 1.4u, 아주 옅고 넓은 그림자(0 2u 6u rgba(0,0,0,.08)).
- 툴바·팝오버: 흰 바탕, 모서리 1u, 그림자 조금 진하게. 손잡이는 흰 사각 + 파란 1px 테두리.
- 커서는 M.Cursor(화살표 ↔ 손가락). 클릭 고리(ring)는 꼭 보이게.

## 움직임
- 110BPM. 카메라는 power4.inOut 처럼 천천히 출발해 빨리 가고 부드럽게 멈춰요(M.anim 'soft' 또는 {d:.8, e:'inOutQuart'}).
- 확대한 뒤에도 카메라를 완전히 멈추지 않고 커서 쪽으로 아주 조금씩 따라가게.
- 팝오버·툴바는 0.18초에 scale .96→1 + 위로 0.6u. 사라질 때 0.12초.
- 타자는 초당 16자 안팎. 드래그 선택은 0.35초.

## 전환
- 같은 앱 안에서는 컷 없이 카메라로만 이동(zoom 바꾸기, 옆으로 흐르기).
- 다른 장면으로 넘어갈 때는 가로 push 0.35초 + 이동 중 가로 흐림. 마지막엔 컷.

## 대표 장면

1. 창 전체 → 글 상자로 확대
   ```
   const cam = M.anim([[0, [540, 540, 1]], [t1, [gx, gy, 2.8], 'soft']], t);   // world 1080×1080 판
   M.camera(world, cam[0], cam[1], cam[2]);
   ```
2. 구절 고쳐 쓰기
   - M.Cursor 로 글 상자 클릭 → 선택 테두리와 손잡이 0.15초에 나타남 → [t, x0, y] 에서 [t+.35, x1, y] 로 드래그(누른 채) → 하이라이트 폭 = 커서 x − 시작 x.
   - 놓으면 0.1초 뒤 하이라이트 구절 삭제 → M.type(새 구절, t, t2, 16).
3. 툴바·색 견본으로 바꾸기
   - 글 상자 위에 서식 툴바가 떠 있고, 손 커서가 색 칸을 누르면 팝오버(견본 7~8칸 목록)가 열림.
   - 견본 하나를 누르면(클릭 고리) 결과물 바탕색이 M.color(앞색, 새색, M.prog(t, tc, .25)) 로 바뀜.
4. 결과물 여러 크기 나란히 + 휙 넘기기
   - 1:1·4:5·9:16 결과물 카드가 오른쪽에서 0.12초 간격으로 밀려 들어오고 카메라가 따라 옆으로 흐름.
   - 다음 장면으로: S.tr.push(B, 앞, 뒤) 를 쓰고, 그 0.35초 동안 두 장면에 filter: blur(12px) 를 가로로만 보이게(scaleX 1.04 와 함께) 걸었다 풀기.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱·웹 서비스 기능 소개, 편집·디자인 도구 시연, B2B 데모, "이렇게 쓰면 돼요" 튜토리얼 광고.
- 피할 것: 화면을 꽉 채운 사진, 강한 그라디언트, 손그림 질감, 3D 물체. 커서 없이 화면만 바뀌게 하지 않기(누가 하는지가 보여야 해요).
