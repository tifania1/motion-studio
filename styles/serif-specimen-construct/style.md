# 활자 견본 조립 (그래픽·도형)

한 줄: 미색 바탕에서 화면보다 큰 세리프 글자 윤곽을 앵커와 핸들이 짚고 지나가요. 짙은 판 위 활자 견본 타일은 박자마다 글자를 갈아 끼우고, 낱말 메아리가 탑처럼 쌓인 뒤 작은 마크와 세리프 로고타입이 작도선 속에서 맺히는 브랜드 공개예요.

## 보는 느낌
- 바탕은 회색빛이 도는 미색 한 장. 그 위에 숯빛 하나만 써서, 거의 흑백 인쇄물처럼 조용해요.
- 크기 대비가 이 결의 뼈대예요. 화면 밖으로 잘릴 만큼 거대한 글자 한 자와, 구석에 작게 놓인 로고타입 한 줄을 같은 화면에 함께 둬요.
- 중간에 한 번 바탕이 숯빛 판으로 뒤집혀요. 그 위에 연세이지 둥근 타일이 활자 견본처럼 맞물려 있어요.
- 후반에는 화면이 점점 비어 가요. 아주 가는 작도선, 점선 타원, 흐린 안개만 남고 그 속에서 작은 마크 하나가 자리를 잡아요.
- 끝은 검정 → 어두운 갈색 화면 가운데 작은 크레딧.

## 색
- 미색 바탕 80 · 숯빛 글자·도형 17 · 연세이지 타일 3.
- 바탕 #DCDBD3, 글자·마크·앵커 #2B2B2A, 견본판 #353533, 타일 #CBCFBF.
- 안개 장면은 #E8E5DC 에서 옅은 하늘빛 회색으로 흐릿하게 번져요. 크레딧 화면은 #2A211C.
- 따로 튀는 강조색이 없어요. 강조는 크기와 굵기, 그리고 숯빛 판으로 뒤집는 것으로 해요.

## 글자
- 제목·로고타입: Instrument Serif(한글은 고운바탕). 굵기 400, 자간 −0.01em, 두 줄 왼쪽 맞춤 로고타입을 마크 오른쪽에 붙여요.
- 거대한 글자: 같은 세리프 한 자를 짧은 변의 120~160%로 키워 가장자리에서 잘리게. 낱말 메아리 탑은 맨 아래가 화면 너비의 50%, 위로 갈수록 0.82배씩 줄어요.
- 꼬리표·버튼: Geist 대문자, 아주 작게(짧은 변의 2%), 자간 +0.2em.
- 견본 타일 속 글리프는 타일 높이의 60%. 이탤릭은 한두 칸에만.

## 질감과 모양
- 그레인 0.06, 비네트 0.18. 안개 장면에만 흐린 구름결(큰 원 3~4개를 blur 12u)을 얹어요.
- 선은 모두 1px 숯빛 30~60%. 앵커는 작은 정사각형(속 미색, 테두리 1px), 핸들은 작은 동그라미.
- 타일·버튼 모서리 1u. 버튼은 그림자 두 겹(위 밝게, 아래 어둡게)으로 눌린 듯한 볼록함을 줘요.
- 작도 격자는 점선 원과 둥근 사각을 겹친 가는 선이에요.

## 움직임
- 84BPM, 느림. `power3.inOut` 으로 천천히 들어와 천천히 멈춰요.
- 거대한 글자 판은 4초에 짧은 변의 5%쯤 흘러요. 앵커는 0.2초 간격으로 하나씩 켜져요.
- 견본 타일 글자 갈기는 반 박(약 0.36초)마다 컷이고, 한 번에 두세 칸만 바뀌어요.
- 메아리 탑은 아래에서 위로 한 줄씩 0.08초 간격으로 쌓여요.
- 마크는 한 장면에 2~3초 넉넉히 머물러요.

## 전환
- 기본은 컷. 안개 장면으로 넘어갈 때만 느린 페이드, 거대 로고를 훑을 땐 밀어내기(push).
- 장면 쌓기: cut → fade → push.

## 대표 장면
1. **거대 글자와 앵커 핸들**
   ```js
   // 글자 윤곽 위 점 목록 pts = [{x,y,kind:'anchor'|'handle'}...]
   S.ambient(t => {
     M.place(glyph, W * .42 - t * W * .012, H * .55);       // 아주 천천히 흐름
     pts.forEach((p, i) => {
       const k = M.ease.outCubic(M.prog(t, .3 + i * .2, .3));
       M.place(p.el, p.x, p.y, {o: k, s: .6 + .4 * k});
     });
     M.draw(handleLines, M.prog(t, .3, pts.length * .2));    // 앵커-핸들 잇는 가는 선
   });
   ```
2. **활자 견본판**: 장면 바탕을 accent(숯빛)로 두고 둥근 타일 12~14칸을 격자로. 칸마다 글리프 목록을 정해 두고 반 박마다 몇 칸만 바꿔요.
   ```js
   const r = M.rng(7);
   tiles.forEach((tile, i) => {
     const marks = [[0, 0]].concat([1,2,3,4,5].map(n => [n * M.beat(.5), r() < .35 ? n : 0]));
     tile.textContent = glyphs[i][M.at(marks, t) % glyphs[i].length];
   });
   ```
   가운데 큰 칸에는 로고타입, 위아래 칸에는 브랜드 마크를 둬요.
3. **낱말 메아리 탑**: 같은 짧은 낱말을 12줄 겹쳐 `s = .82 ** i`, `y = 바닥 - Σ높이` 로 쌓고, `M.place(row, cx, y_i, {o: M.prog(t, i * .08, .15)})` 로 아래부터 하나씩. 다 쌓이면 한 박 머문 뒤 컷.
4. **작도선 속 마크와 안개 마무리**: 큰 동심 호 3~4개를 `M.draw` 로 그리고 호 위 앵커를 켠 뒤 `M.anim` 으로 짧은 변의 15% 크기까지 줄여 가운데로. 둘레 점선 원·둥근 사각 작도선은 `M.draw` 로 0.8초에 그었다 페이드. 이어 `S.tr.blur` 로 안개 장면에 들어가 로고를 화면보다 크게 옆으로 훑고(push), 마지막에 가운데 마크+로고타입을 `o 0→1, blur 6→0` 로 맺어요. 엔딩은 컷으로 검정, 1초 뒤 갈색 크레딧.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 공개·리브랜딩, 출판·잡지·문화 재단 소개, 활자·디자인 스튜디오 쇼릴, 웹사이트 인트로, 차분한 캠페인 티저.
- 피할 것: 형광·원색 강조, 빠른 컷 연속, 굵은 고딕 제목, 반짝이는 그라디언트·네온, 한 화면에 긴 문장.
- 마크는 브랜드 자기 로고를 넣고, 작도선과 앵커만 이 결로 그려요.
