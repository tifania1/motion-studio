# 코발트 유리 견본 공개 (그래픽·도형)

한 줄: 밝은 회색 위 작은 글 한 줄이 흐림에서 맺히고, 가는 선으로 지은 원과 정사각 도형이 코발트 그라디언트 위 두꺼운 유리 입체로 바뀐 뒤, 색 견본 띠와 글꼴 견본, 모니터 화면이 컷으로 이어지는 차분한 브랜드 공개예요.

## 보는 느낌
- 밝은 회색 바탕 한가운데 작은 산세리프 한 줄. 화면의 90%는 비워 두고, 글은 짧은 변의 3~4% 크기로 조용히 놓여요.
- 이야기는 세 덩어리로 흘러요. 옛 작업 화면과 손 작업 사진을 회색 여백 안에 작게 띄운 도입, 가는 선 도형과 앵커가 마크를 짓고 그 마크가 코발트 그라디언트 위 유리 입체가 되는 공개, 색 견본·글꼴 견본·모니터 화면이 컷으로 이어지는 가이드 훑기. 끝은 검은 화면에 작은 문장과 마크 하나.
- 도형은 원과 정사각 두 가지면 충분해요. 선으로 그릴 땐 머리카락처럼 가늘게, 입체로 만들 땐 두껍고 투명한 유리로. 우리 브랜드 마크도 이 두 결(가는 선 / 유리 입체)로 번갈아 보여 줘요.
- 견본 장면은 화면을 반듯한 색면으로 잘라요. 가로 띠 셋, 또는 정사각 타일 체커보드.
- 모니터 장면은 옅은 회색 스튜디오 바닥 위에 화면 한 대. 화면 속엔 마크 하나, 다음 컷엔 앱 화면.

## 색
- 회색 바탕 65 · 코발트 20 · 먹색 글자 10 · 흑요석 5. 마무리 장면만 흑요석이 화면 전체를 덮어요.
- 바탕 #E6E6E4, 글자 #141414, 흐린 글 먹색 60%.
- 코발트 #2F55E8 은 주로 그라디언트로 써요. 한쪽 귀퉁이 짙은 #1A33C8 → 가운데 #4F75E6 → 반대쪽 옅은 회색 #E6E6E4 로 하얗게 빠짐.
- 견본 색면: 코발트 #5B7FEA, 옅은 회색 #E3E4E8, 흑요석 #121212.
- 마무리 검은 화면 #121212 위 글자 #ECECEA, 흐린 글은 그 60%.
- 강조 낱말은 코발트 글자 하나로만. 다른 색은 들이지 않아요.

## 글자
- Geist(한글 Noto Sans KR 500·700). 문장은 500, 짧은 변의 3~4%, 가운데 정렬 한두 줄, 자간 -0.02em, 줄 간격 1.3.
- 크게 쓰는 곳은 글꼴 견본 장면 하나. 'AaBbCc' 같은 글자 줄을 짧은 변의 45%로 왼쪽 정렬해 오른쪽 끝을 화면 밖으로 잘라 두고, 아래에 굵기 이름을 작게 나열한 뒤 지금 굵기 옆에 점 하나.
- 색 이름과 hex 값은 Geist Mono, 짧은 변의 1.6%, 색면 왼쪽 위.
- 낱말 원통 장면: Geist 500, 짧은 변의 6%. 가운데 줄만 먹색으로 선명하고 위아래 줄은 코발트·회색으로 흐려져요.
- 타자 장면: 글자 몇 개를 얇은 코발트 선택 상자로 감싸고 오른쪽에 깜빡이는 세로 커서.

## 질감과 모양
- 거의 매끈해요. 그라디언트 장면에만 그레인 0.05 를 얹어 색 띠가 생기지 않게.
- 안내선은 1px 먹색 30~40%. 앵커 점과 핸들은 지름 0.5u 파란 점과 가는 파란 선.
- 유리 입체: 두께 있는 투명 정사각 틀 안에 원 구멍. 가장자리에서 흰 반사와 검은 반사가 맞닿고, 뒤의 코발트가 살짝 휘어 비쳐요.
- 모서리는 거의 직각(0.4u). 그림자는 모니터 장면 바닥에만 넓고 옅게.

## 움직임
- 96BPM. 한 장면에 2~3초 머물러요. 서두르지 않고, 컷 뒤엔 꼭 숨 돌릴 틈을 둬요.
- 글자는 왼쪽부터 써지는데 맨 앞 서너 글자는 흐림 4px·투명 40%에서 0.25초에 맺혀요. 글자 하나 간격 0.04초.
- 도형과 카메라는 power3.out 으로 들어와 그대로 천천히 떠 있어요. 유리 입체는 6초 동안 15도쯤 돌고, 카메라는 그쪽으로 조금씩 다가가요.
- 빛은 아래에서 위로: 코발트 빛 덩어리가 화면 아래 가장자리에서 1.2초에 지평선처럼 솟아요.
- 낱말 원통은 위로 굴러가며 세로 흐림을 끌다가 가운데 줄에서 멈춰요.
- 마무리: 검은 화면에 작은 문장이 같은 흐림 타자로 써지고, 페이드 뒤 작은 마크 하나가 두 박 머물러요.

## 전환
- 컷이 기본이에요. 유리 입체 공개 앞뒤엔 흐림(blur) 전환으로 맺히듯 넘어가고, 검은 마무리 화면으로는 느린 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **흐림에서 맺히는 한 줄**
   ```
   const cs = S.chars(line);
   S.ambient(t => cs.forEach((c, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + i * .04, .25));
     c.style.opacity = .4 + .6 * k;
     c.style.filter = `blur(${(1 - k) * 4}px)`;
     c.style.visibility = t < t0 + i * .04 ? 'hidden' : 'visible';
   }));
   ```
   검은 마무리 화면에서도 같은 코드로 써요. 장면 쌓기에서는 title: blur 가 이 결을 맡아요.
2. **선 도형 아래 솟는 코발트 빛**
   ```
   M.draw(squarePath, M.ease.outCubic(M.prog(t, 0, .6)));
   M.draw(circlePath, M.ease.outCubic(M.prog(t, .2, .6)));
   const y = M.anim([[0, H * .8], [.9, H * .45, {d: 1.2, e: 'outCubic'}]], t);
   M.place(glowBlob, W / 2, y);   // 넓은 타원 radial-gradient(#2F55E8 → 투명), blur 8u
   ```
   다음 컷에서 화면보다 큰 외곽선 글자에 파란 앵커 점이 하나씩 켜지고(M.at 으로 0.08초 간격), 그다음 마크 둘레에 옅은 안내 정사각 넷을 깔아 마크를 가운데 세워요. 장면 쌓기 deco handles·marks 가 이 선택 상자와 눈금을 깔아요.
3. **코발트 위 유리 입체**
   ```
   // 바탕: linear-gradient(120deg, #1A33C8, #4F75E6 45%, #E6E6E4)
   // glass: 두꺼운 반투명 테두리 + backdrop-filter: blur + 흰·검정 inset 그림자, 안에 원 구멍
   S.ambient(t => M.place(glass, W * .55, H * .5, {s: 1.5 + t * .03, r: -8 + t * 2.5}));
   ```
   들어올 땐 S.tr.blur 로 맺히고, 나갈 땐 컷. 같은 유리 틀을 나중에 원 고리 모양으로 바꿔 한 번 더 비춰요.
4. **색 견본 띠와 타일 판**
   - 화면을 가로 띠 셋(코발트·옅은 회색·흑요석)으로 나눠 `M.box(band, {x: 0, y, w: W, h})` 로 위에서부터 0.12초 간격 펼치고, 띠 왼쪽 위에 Geist Mono 색 이름과 hex.
   - 다음 박엔 컷으로 4×2 정사각 타일 체커보드. 타일마다 마크 변형(가는 선 / 유리 / 채움 / 빈칸)을 `M.at([[t0, a], [t0 + M.beat(.5), b], …], t)` 로 반 박마다 갈아요.
   - 이어 잘린 글꼴 견본 한 장, 흐린 낱말 원통 한 장, 회색 스튜디오 모니터 두 장을 컷으로 이어 가이드를 훑어요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 리뉴얼·아이덴티티 공개, 개발·디자인 도구 런칭 티저, 사전 신청 모집, 브랜드 가이드 소개, 새 마크 발표.
- 피할 것: 손그림 선과 떨림, 강조색 여러 개(코발트 하나만), 화면을 꽉 채우는 굵은 제목 남발(크게 쓰는 건 글꼴 견본 한 장뿐), 반 박마다 몰아치는 컷, 무지개·네온 그라디언트.
- 원본의 마크 모양을 그대로 쓰지 말고, 우리 브랜드 마크를 선·유리·채움 세 결로 바꿔 가며 보여 줘요.
