# 검은 비단 물결 위 앱 창 (제품 UI)

한 줄: 검은 비단처럼 일렁이는 물결 바탕 위로 어두운 앱 창이 하나씩 떠요. 카메라는 입력창과 버튼에 바짝 붙었다가 천천히 물러나고, 끝에는 흩어져 있던 창들이 아래 도크로 모여드는 다크 UI 런칭이에요.

## 보는 느낌
- 바탕은 거의 검은 화면이고, 그 위로 비단 주름 같은 흰빛 결이 크게 휘어지며 천천히 흘러요. 주름은 밝은 부분도 흰색 20~35% 정도라서 늘 어둑해요.
- 화면 한가운데 어두운 앱 창 하나. 창은 화면 너비의 35~55%로 작게 두고, 둘레에 물결이 넉넉히 보이게 해요.
- 장면 사이사이 카메라가 창 속 한 곳(입력창, 알약 버튼, 목록 한 줄)을 화면보다 크게 키워 바짝 붙어요. 이때 창 테두리는 화면 밖으로 잘려요.
- 마무리는 창 대여섯 개가 크기를 달리해 화면 곳곳에 떠 있고, 아래에 도크 한 줄. 마지막 장은 물결만 남은 어둠 가운데 작은 흰 마크와 아주 작은 글씨 한 줄이에요.

## 색
- 검정 바탕과 물결 70 · 어두운 창 22 · 흰 글자 7 · 파랑 1.
- 바탕 #0B0B0C, 창 #1E1E20, 창 안 칸·테두리 #3A3A3E, 글자 #EDEDED, 흐린 글자 흰색 58%.
- 파랑 #2563EB 는 대화 상자의 확인 버튼이나 고른 항목 하나에만 써요. 글자는 흰색.
- 창 왼쪽 위 신호등 점(빨강 #FF5F57·노랑·초록)은 창마다 작게 둬요. 그 밖의 색은 창 속 사진·아이콘에서만 나와요.

## 글자
- Geist(한글은 Noto Sans KR Medium) 400~500, 작고 가볍게. 화면에 따로 띄우는 큰 제목은 거의 쓰지 않고, 글은 창 안에 들어 있어요.
- 창 안 기본 글씨는 짧은 변의 2~3%. 접사 장면에서는 같은 글씨가 화면 높이의 10~14%까지 커져요. 크기 대비는 카메라 거리로 만들어요.
- 상태 표시(되감는 중…, 준비 중…)처럼 작은 기계 글씨는 Geist Mono, 흰색 50%.
- 정렬은 가운데. 입력창 글은 왼쪽 정렬에 얇은 세로 커서.

## 질감과 모양
- 비네트 0.32 로 가장자리를 더 어둡게. 그레인은 쓰지 않아요. 물결은 매끈하게 흘러야 해요.
- 창: #1E1E20, 1px 흰색 10% 테두리, 모서리 `--u` × 1.4, 아래로 크고 옅은 검은 그림자 하나. 창 위 막대에 신호등 점 셋.
- 알약 버튼·입력창: 창보다 조금 밝은 #2A2A2D, 1px 흰색 14% 테두리, 완전히 둥근 모서리.
- 빛 번짐은 쓰지 않아요. 밝기는 물결 주름에서만 나와요.

## 움직임
- 96BPM, 보통 빠르기. 카메라와 창 크기 변화는 `power3.inOut` 으로 느긋하게 출발해 느긋하게 멈춰요.
- 접사에서 물러나는 데 1.2초, 창 크기가 바뀌는 데 0.8초. 창 속 새 내용은 크기 변화가 끝나기 0.2초 전부터 0.3초 동안 페이드로 들어와요.
- 입력창 타자는 초당 14~18자. 다 치고 나면 커서가 한 박 더 깜빡이다 사라져요.
- 장면마다 3~4초 머물러요. 창은 머무는 동안에도 아주 조금(짧은 변의 0.5%) 떠다녀요.
- 물결은 쉬지 않고 흘러요. 한 바퀴가 20초쯤 걸리게 아주 천천히.

## 전환
- 흐림 전환(blur)이 기본: 카메라가 창에서 멀어지거나 다가가는 순간 화면이 2~4px 흐려졌다 맺혀요.
- 같은 창 안에서 내용만 바뀔 땐 페이드, 마무리 마크로 넘어갈 땐 컷. 장면 쌓기: blur → fade → cut.
- 물결 바탕은 전환 내내 끊기지 않고 그대로 흘러요. 바뀌는 건 위에 뜬 창뿐이에요.

## 대표 장면
1. **비단 물결 바탕**
   ```js
   // 흐린 흰 선 띠 4~5개를 SVG path 로 깔고 천천히 비틀어요
   const folds = S.$$('.fold');                 // stroke: url(#silk) 흰색 0→35%→0 그라디언트, 굵기 6~14u, blur(1.5u)
   S.ambient(t => folds.forEach((f, i) => {
     const a = t * .3 + i * 1.7;
     f.setAttribute('d', `M -10 ${50 + i * 9} C 30 ${30 + Math.sin(a) * 18}, 70 ${80 + Math.cos(a * .8) * 16}, 110 ${40 + i * 7}`);
   }));
   // 장면 쌓기에서는 bg: mesh + 비네트로 가까운 결을 내요
   ```
2. **접사 타자에서 창 전체로**
   ```js
   const k = M.anim([[0, 0], [t0 + 2.4, 1, {d: 1.2, e: 'inOutCubic'}]], t);   // 0 = 바짝, 1 = 전체
   M.place(win, cx + (1 - k) * W * .35, cy, {s: M.lerp(4.2, 1, k), blur: M.bump(k) * 3});
   input.textContent = M.type('지금 바로 만들어 볼까요', t, t0 + .3, 16);
   ```
   - 바짝 붙은 동안 카메라는 커서를 따라 옆으로 흘러요(`x` 를 글자 수에 맞춰 조금씩 왼쪽으로). 장면 쌓기에서는 frame: window + title: type 이 같은 결을 내요.
3. **자리를 지키며 모양만 바뀌는 창**
   ```js
   const sizes = [[.42, .30], [.36, .34], [.56, .40], [.30, .26]];   // 목록 → 재생기 → 대시보드 → 대화 상자
   const i = M.at(sizes.map((_, n) => [n * M.beat(6), n]), t);
   M.box(win, {cx, cy, w: W * M.anim(...), h: H * M.anim(...)});  // 각 칸 사이 0.8초 inOutCubic
   panes.forEach((p, n) => p.style.opacity = n === i ? M.prog(t, n * M.beat(6) + .6, .3) : 0);
   ```
   - 대화 상자에서는 `M.Cursor` 가 파란 확인 버튼으로 가서 누르고(`M.cursorAt`), 버튼 글씨가 '보내는 중…' 으로 바뀌어요.
4. **창들이 흩어지고 도크가 올라오는 마무리**
   - 창 대여섯 개를 깊이마다 크기를 달리해(0.55~1배) `M.place` 로 띄우고 각자 `M.drift` 로 조금씩 떠다니게 해요.
   - 도크 막대는 아래에서 `M.spring(t - tD, 'smooth')` 로 올라오고, 아이콘은 왼쪽부터 0.12초 간격으로 `s: 0 → 1`(`back.out` 아주 약하게). 다 놓이면 `S.tr.blur` 로 어둠에 녹이고, 컷으로 물결만 남은 화면 가운데 작은 흰 마크와 흐린 글씨 한 줄.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 데스크톱 앱 런칭, AI로 앱 만들기 도구, 여러 작은 앱을 묶어 소개할 때, 개발자·크리에이터용 도구, 밤 분위기의 차분한 제품 영상.
- 피할 것: 흰 바탕, 강조색 여러 개(파란 버튼과 창 신호등 점만), 빠른 컷 몽타주, 굵고 큰 제목 문장, 손그림·종이 질감.
- 창 속 사진·캐릭터·아이콘은 우리 제품 화면으로 새로 채워요. 물결과 창의 비율, 카메라 거리 변화가 이 결의 핵심이에요.
