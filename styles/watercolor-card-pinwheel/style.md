# 수채 카드 바람개비 (3D·사물)

한 줄: 밝은 회색 공간에서 수채 물감 결을 입힌 카드들이 옆선 하나로 나타나 부채처럼 펼쳐지고, 바람개비로 돌다 비스듬한 격자로 화면을 덮어요. 사이사이 짙은 초록 문장이 어절씩 올라오고, 짙은 초록 판 위 연두 마크로 닫아요.

## 보는 느낌
- 바탕은 그림자도 바닥도 없는 밝은 회색 한 가지예요. 주인공은 카드 한 종류뿐이고, 카드마다 물감이 번진 수채 무늬가 칠해져 색은 전부 카드에서 나와요.
- 카드 장면과 글 장면을 번갈아 둬요. 글 장면은 회색 한가운데 짧은 문장 한 줄만 있고 나머지는 비워 둬요. 카드 장면은 색이 꽉 차고, 글 장면은 텅 비어서 숨이 쉬어져요.
- 카드는 늘 3D 로 기울어 있어요. 사선으로 서고, 부채로 펼쳐지고, 별 모양으로 돌고, 격자로 눕고, 폰 화면 속에 겹쳐 꽂혀요.
- 끝은 컷으로 짙은 초록 판 하나로 바뀌고, 연두 마크만 남아요.

## 색
- 회색 바탕 65 · 카드 수채 색 28 · 짙은 초록 글자 5 · 연두 2.
- 바탕 #EDEDED, 문장 짙은 초록 #2A4A12.
- 카드 수채 색은 장마다 두세 색씩 섞어요: 연두 #9FE870 · 하늘 #3FB6D8 · 주홍 #E8603C · 보라 #B57BE0 · 노랑 #F2D04A.
- 엔딩 판은 짙은 초록 #223A0E, 마크와 글자는 연두 #9FE870. 연두는 이 판에서만 넓게 써요.

## 글자
- Geist 600(한글은 Noto Sans KR Bold), 자간 −0.02em. 작고 단정하게, 짧은 변의 6~7% 안팎.
- 한 장면에 한 줄, 서너 어절까지만. 가운데 정렬.
- 카드 위 작은 알림·폰 화면 글씨는 Geist 500, 짧은 변의 2% 안팎, 먹색.

## 질감과 모양
- 화면 전체에는 질감을 깔지 않아요. 수채 결은 카드 안에만 있어요.
- 카드 비율 1.58:1, 모서리 1.2u. 아주 옅은 그림자 한 겹(아래로 1u, 흐림 3u, 먹색 12%).
- 수채 무늬: 큰 radial-gradient 서너 겹 + SVG feTurbulence 로 번진 결을 섞고, 위쪽에 아주 옅은 흰 사선 하이라이트를 얹어요.
- 카드 귀퉁이에 작은 흰 마크 자리(단순한 둥근 사각)만 두고, 진짜 로고는 그리지 않아요.

## 움직임
- 100BPM, 보통 빠르기. 카드는 power3.out 으로 미끄러지듯 들어와 천천히 멈추고, 멈춘 뒤에도 아주 느리게 계속 돌거나 흘러요.
- 글 장면은 어절마다 0.3초 간격으로 2u 아래에서 올라와요. 막 들어온 어절은 기준선이 0.3u 낮다가 0.2초 뒤 맞춰져요. 한 줄이 다 보이면 1박쯤 머물렀다 컷.
- 바람개비는 한 바퀴에 8초쯤, 격자 흐름은 4초에 짧은 변의 10%쯤. 급하게 돌지 않아요.

## 전환
- 컷이 기본이에요. 카드 접사에서 빠질 땐 흐림(blur), 엔딩 직전엔 짧은 페이드.
- 장면 쌓기: cut → blur → cut → fade. 마지막 장면만 paper(짙은 초록) 바탕.

## 대표 장면

1. 옆선 하나에서 부채, 그리고 바람개비
   ```
   // 카드 12장을 같은 자리에 겹쳐 두고, 축 하나에 매달아 돌림 (t 의 순수 함수)
   const cards = S.$$('.wc-card');
   S.ambient(t => {
     const turn = M.ease.outCubic(M.prog(t, 0, .8));        // 옆선 → 앞면 (rotateY 88° → 20°)
     const fan  = M.ease.outCubic(M.prog(t, .6, 1.2));      // 부채 펼침
     const star = M.ease.inOutCubic(M.prog(t, 2.0, 1.4));   // 부채 → 별 모양
     cards.forEach((c, i) => {
       const a = i / cards.length * 360 * star + i * 9 * fan * (1 - star) + t * 45 * star;
       M.place(c, cx, cy, { rot: a, s: .55 });
       c.style.transform += ` rotateY(${88 - 68 * turn}deg) translateX(${star * 1.1 * cardW}px)`;
     });
   });
   ```
2. 비스듬한 카드 격자
   - 부모에 `perspective` + `rotateX(50deg) rotateZ(-30deg)` 를 주고 카드 6×6 을 틈 0.4u 로 깔아요. 카드마다 수채 색 조합을 `M.rng(시드)` 로 섞고, 판 전체를 `S.ambient` 에서 대각선으로 천천히 흘려요(`x = -t * W * .03`).
   - 들어오기 직전 장면은 카드 한 장에 바짝 붙은 접사(scale 4, 화면 밖으로 미끄러짐)이고, `S.tr.blur` 로 격자로 넘어가요.
3. 짙은 초록 문장이 어절씩
   - `S.words(el)` 로 어절을 나누고 어절 i 를 `M.place(w, x_i, cy + (1 - k) * 2 * u + (1 - k2) * .3 * u, {o: k})`, `k = M.spring(t - i * .3, 'smooth')`, `k2 = M.prog(t, i * .3 + .2, .2)`. 장면 쌓기에서는 title: rise, scale 0.9, deco 없음으로 같은 결이 나와요.
4. 카드 위 알림, 그리고 엔딩
   - 카드 4장을 높이를 달리해 비스듬히 띄우고, 카드마다 위에 흰 알약 알림(작은 원 아이콘 + 글 + 금액)이 0.2초 간격으로 톡 떠요(`M.spring` 'snappy', y −1u).
   - 컷으로 짙은 초록 판. 연두 마크(단순한 도형 조합)가 `M.spring` 으로 커졌다가 1박 뒤 둥근 사각 아이콘으로 `M.box` 를 줄이며 접혀요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 카드·결제 상품 출시, 디자인 고르기 기능 소개, 컬렉션·한정판 공개, 색이 많은 제품 라인업.
- 피할 것: 어두운 바탕 장면을 길게 쓰기(마지막 판만 짙은 초록), 화면 전체 질감(그레인·종이), 굵고 큰 제목, 카드 말고 다른 소품 섞기, 빠른 깜빡임 컷.
- 색은 카드에 다 모아 두고 글 장면은 비워 두는 게 이 결의 핵심이에요.
