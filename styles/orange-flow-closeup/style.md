# 주황 물결과 초근접 (그라디언트·빛)

한 줄: 흐릿하게 일렁이는 주황 바탕 위에 흰 입력창과 폰. 마지막엔 음성 메시지 하나에 바짝 붙어 재생 막대가 주황으로 물들어 가는 걸 보여 줘요.

## 보는 느낌
- 바탕 전체가 크게 흐려진 주황 비단처럼 천천히 일렁여요. 그 위 흰 UI 가 또렷하게 떠 보여요.
- 장면은 단순하게 셋: 입력창 하나 → 폰 속 대화 → 음성 메시지 초근접.
- 초근접 장면에선 바탕이 거의 사라지고 회색 UI 와 큰 글자만 남아요. 바탕 주황과 막대 주황이 이어져 색이 한 줄로 꿰여요.

## 색
- 주황 바탕 70 · 흰·회색 UI 22 · 먹색 6 · 막대 주황 2.
- 바탕은 #DE883D 를 중심으로 밝은 살구(#F2B077)와 짙은 주황(#C86A1E)이 섞여 흘러요.
- UI 는 #EDEDED, 사용자 말풍선·보내기 버튼은 먹색(#141414) + 흰 글자, 상대 말풍선은 #E2E2E2 + 먹색 글자.
- 재생된 막대만 #E39A2C. 나머지 막대는 회색 #8E8E8E.
- 바탕 위에 바로 글을 쓸 일이 있으면 먹색(#1A120A)으로. 흰 글자는 주황 위에서 잘 안 읽혀요.

## 글자
- 반듯한 고딕 Regular~Medium(Geist + Noto Sans KR 500).
- 입력창·말풍선 글자는 짧은 변의 2.4%, 초근접 장면에선 같은 글자가 화면 높이의 1/10쯤으로 커져요.
- 화면 밖 자막은 쓰지 않는 쪽이 이 스타일다워요. 필요하면 엔딩 로고 옆 한 줄.

## 질감과 모양
- 아주 약한 그레인(0.05)으로 그라디언트 띠 끊김을 막아요.
- 입력창: 흰 알약, 왼쪽 + 원 버튼, 오른쪽 먹색 원 버튼(파형 아이콘), 넓고 옅은 그림자.
- 폰: 흰 몸체, 모서리 7u, 위쪽 검은 알약 하나. 말풍선 모서리 2u.
- 음성 메시지: 회색 알약 안에 재생 원 버튼 + 세로 막대 40~60개(둥근 끝, 굵기 0.5u, 간격 0.5u) + 시간.

## 움직임
- 100BPM. 바탕은 늘 천천히, UI 는 정확하고 부드럽게(power3.inOut, 'soft').
- 타자 초당 14자. 폰 올라오기 0.6초 'soft'. 화면 밀림 0.45초 'snappy'.
- 초근접 장면의 카메라 옆 흐름은 막대 진행과 같은 속도로 아주 느리게(초당 1.5u 안팎).
- 막대 물들기: 한 막대씩 0.06초 간격, 색 바뀜은 0.1초 페이드.

## 전환
- 입력창 → 폰: 이음(같은 문구가 입력창에서 사라지는 순간 폰 속 말풍선으로 나타남).
- 폰 → 초근접: 컷. 크기 차이가 커서 컷이 시원해요.
- 엔딩: 컷으로 밝은 회색 바탕 + 로고.

## 대표 장면

1. 흐르는 주황 바탕
   ```
   // .blob 4개: border-radius 50%, 크기 70~110% of W, filter: blur(calc(var(--u)*10))
   const B = [['#F2B077', .2, .3, 9], ['#C86A1E', .8, .7, 11], ['#E58A3A', .5, .1, 8], ['#F6C08E', .3, .9, 12]];
   S.ambient(t => B.forEach(([c, x, y, T], i) => {
     M.place(blob[i], S.W * (x + .12 * Math.sin(t * 2 * Math.PI / T + i)), S.H * (y + .1 * Math.cos(t * 2 * Math.PI / T * .8 + i)), { s: 1 + .08 * Math.sin(t / T * 4 + i) });
   }));
   ```
2. 입력창 → 폰 (0.8~5초)
   - 입력창 글 = M.type(Q, t, t0, 14). 다 치면 반 박 쉬고 보내기 버튼 눌림(scale .9).
   - 입력창이 아래로 6u 빠지며 옅어지는 동안, 폰이 화면 아래에서 'soft' 로 올라와 그 문구가 먹색 말풍선으로 들어 있음.
   - 추가 말풍선·답 말풍선이 올 때마다 화면 내용 y 를 M.anim 으로 위로 밀기.
3. 음성 메시지 초근접 (8~13초)
   ```
   // 컷 직후 말풍선이 화면 높이 절반. 재생 버튼: t1 에 누름
   btn.style.transform = `scale(${1 - .1 * M.prog(t, t1 - .06, .06) + .1 * M.spring(t - t1, 'snappy')})`;
   icon = t < t1 ? '재생' : '일시정지';
   bars.forEach((b, i) => b.style.background = M.color('#8E8E8E', '#E39A2C', M.prog(t, t1 + .2 + i * .06, .1)));
   M.camera(world, cx0 + (t - t1) * 1.5 * u, cy, Z);       // 진행 따라 옆으로 천천히
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: 메신저·음성 기능 소개, 알림·브리핑 서비스, 따뜻한 톤의 앱 광고, 10~20초 티저.
- 피할 것: 차가운 파랑·보라 강조, 두꺼운 테두리, 글자만 있는 장면 연속, 복잡한 표. 주황 바탕 위에 작은 흰 글자를 올리지 않기.
