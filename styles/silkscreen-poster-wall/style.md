# 실크스크린 포스터 벽 (콜라주·사진)

한 줄: 어두운 갈색 판 위에 원색 포스터 세 장이 나란히 서고 박마다 통째로 갈리는, 판 찍기 색 겹침과 뭉툭한 대문자의 포스터 벽.

## 보는 느낌
- 두 가지 화면을 번갈아 써요.
  - 포스터 셋: 어두운 갈색 판에 세로 포스터 세 장이 같은 간격, 같은 높이로 서 있어요. 위 가운데 작은 대문자 이름, 각 포스터 밑에 작은 꼬리표.
  - 포스터 벽: 크기가 다른 포스터·사진 칸이 얇은 검은 틈으로 화면을 꽉 채운 벽. 칸은 화면 밖으로 잘려 나가도 괜찮아요.
- 포스터 한 장은 원색 바탕 한 색 + 그 위 굵은 대문자 + 그림이나 사진 하나. 장마다 바탕색이 달라 셋이 나란히 서면 색이 부딪혀요.

## 색
- 판 #33261A 35 · 포스터 원색 55 · 글 10.
- 포스터 바탕: 빨강 #E12A2A, 연두 #C9E83A, 진초록 #1F7A3A, 파랑 #2D46C8, 분홍 #F58AC0, 노랑 #E8C21E 중에서 셋을 골라 나란히.
- 포스터 글은 바탕과 보색이나 큰 대비로(초록 위 분홍, 파랑 위 빨강, 노랑 위 진초록). 판 위 작은 글은 크림 #F2E6C9.
- 판 찍기 원리: 색을 섞지 않고 판 하나에 한 색. 같은 계열 옅은 색으로 거대한 글자를 바탕에 한 번 더 찍어 깊이를 만들어요.

## 글자
- 넓고 뭉툭한 그로테스크 900(Archivo, 폭 112~125%) + 한글 Noto Sans KR Black. 모두 대문자, 줄 간격 0.88, 자간 −0.01em.
- 포스터 안 제목은 포스터 폭을 꽉 채우게(짧은 변의 10~14%). 두세 줄로 쌓아요.
- 판 위 이름·꼬리표는 같은 글꼴 700, 짧은 변의 2%, 자간 0.08em.

## 질감과 모양
- 거친 잉크: 그레인 0.12, 하프톤 0.1(점 크기 0.9u), 색 어긋남 0.5(흔들림 없이 고정, 판이 살짝 어긋나 찍힌 느낌).
- 포스터 모서리는 각지게(0). 그림자 없음.
- 큰 면은 단색으로 평평하게. 그라디언트를 쓰지 않아요.
- 그림이 필요하면 브랜드 사진이나 사용자가 준 일러스트를 2~3색으로 줄여(포스터화) 써요.

## 움직임
- 110BPM, 빠름. 박마다 무언가 바뀌어요.
- 포스터 셋: 1.3초(두 박 반)마다 세 장이 한꺼번에 컷으로 새 판. 바뀐 직후 각 포스터 안에서 한 가지만 움직임(맨 아래 낱말이 칠해지듯 드러남, 또는 큰 대문자가 쾅).
- 쾅: scale 1.25 → 1, 0.18초, power4.out. 넘침 없음.
- 포스터 벽: 1초에 3% 정도로 아주 천천히 커지고, 물결선 하나가 0.8초에 그어짐.

## 전환
- 컷이 거의 전부. 판 전체를 바꿀 때만 옆으로 밀기(push).
- 장면 쌓기: cut → cut → push, 장면 바탕은 dark(판) → accent(빨강) → paper(연두) → dark.

## 대표 장면
1. **포스터 셋 갈아끼우기**
   ```
   // 판 위에 포스터 자리 세 개(같은 폭·높이·간격). 세트 n 을 박마다 바꿈
   const n = Math.floor((t - t0) / (M.beat(1) * 2.5));
   slots.forEach((s, i) => s.innerHTML = sets[n % sets.length][i]);   // 컷 (미리 만들어 두고 visibility 로 켜고 끔)
   // 바뀐 직후 한 포스터의 큰 글자: S.fx.stamp(word, tn) / 아래 낱말: S.fx.reveal(bottom, tn + .15)
   ```
   장면 쌓기에서는 `frame: poster`(여백 테두리·재단 표시)와 `title: stamp`, `scale: 1.35` 가 포스터 한 장 느낌을 만들어요.
2. **바탕에 한 톤 밝은 거대 글자**
   - 포스터 바탕 위에 같은 계열 옅은 색(`color-mix(in srgb, 바탕 70%, #fff)`)으로 낱말을 포스터 높이만큼 크게 세로로 쌓고, 그 위에 그림과 진짜 제목을 얹어요. 거대 글자는 움직이지 않아요.
3. **포스터 벽과 물결선**
   - 칸 배치는 시드 고정(`M.rng(5)`)으로 2~4열, 칸 사이 틈 0.6u. 벽 전체 `M.camera(wall, cx, cy, 1 + .03 * (t - t0))`.
   - 굵은 물결선: SVG path(사인파를 손으로 그은 듯 진폭을 들쭉날쭉) 선 굵기 1.4u, `M.draw(path, M.prog(t, t1, .8))`. 장면 쌓기 `deco: scribble, marks` 가 이 몫이에요.

## 어울리는 곳 / 피할 것
- 어울림: 지역·관광 홍보, 축제·공연 라인업, 로컬 브랜드·굿즈, 전시·문화 행사.
- 피할 것: 부드러운 그라디언트, 유리 질감, 가는 글씨, 무채색의 차분한 장면.
- 포스터 그림은 영상 속 작품을 따라 그리지 않아요. 색 수·판 겹침·배치 원리만 가져와요.
