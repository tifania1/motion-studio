# 만화 칸과 말풍선 (손그림)

한 줄: 굵은 먹선 칸이 차례로 화면을 나누고, 말풍선이 하나둘 불어나 화면을 덮고, 강조할 땐 집중선이 떨리는 흑백 만화 결에 청록 한 색이에요.

## 보는 느낌
- 흑백 만화 원고 한 장. 흰 바탕(살짝 회색 도는 종이)과 검은 바탕(작은 무늬 스크린톤)을 번갈아 써요.
- 화면을 칸으로 나눠요. 크기가 다른 네모 칸 3~6개, 칸 사이엔 흰 틈. 칸 하나에 메시지 하나.
- 칸 모서리에는 작은 네모 꼬리표(캡션 상자)가 칸 테두리에 반쯤 걸쳐 붙어요. 안에 손글씨 대문자 낱말 하나.
- 말풍선은 흰 타원에 굵은 먹선 테두리, 안에 손글씨 대사 두 줄. 꼬리는 짧게 하거나 생략.
- 강조할 순간엔 화면 가장자리에서 가운데로 모이는 집중선. 앱 화면 같은 UI 는 기울어진 칸 안에 넣고, 칸 바깥 한쪽에 사선 집중선을 둬요.
- 캐릭터·마스코트는 따라 그리지 않아요. 브랜드 마스코트가 있으면 그걸 칸 안에 넣어요.

## 색
- 흰 종이 55 · 먹 35 · 청록 10.
- 종이 #EBEBE9, 먹 #111111, 검은 페이지 #121212 위 글자는 #F1F1EE.
- 청록 #6CC6BA 하나만 색으로 써요. 같은 계열 옅은 #ABDBCF, 짙은 #3E8178 은 칸을 칠할 때만. 회색 톤 #C3C3C1 은 칸 채우기용.
- 색은 넓은 면(칸 하나를 꽉 칠함)으로만. 글자에 청록을 쓰지 않아요.

## 글자
- 제목: 좁고 굵은 대문자 고딕(Archivo 를 font-stretch 62~75% · 800~900, 한글은 Noto Sans KR Black). 자간 0, 짧은 변의 6~9%. 영어는 대문자.
- 대사·꼬리표: 개구(Gaegu) 700. 만화 식자처럼 대문자·느낌표·물음표를 넉넉히("진짜???", "드디어!!!"). 말풍선 지름의 12~15% 크기, 가운데 정렬 두 줄.
- 숫자: 제목과 같은 좁은 굵은 고딕을 크게.

## 질감과 모양
- 하프톤 0.08(점 0.9u)을 아주 옅게 덮어 인쇄 만화 톤만 살짝. 그레인 0.04.
- 검은 장면 바탕엔 작은 무늬를 촘촘히 반복한 스크린톤(장면 쌓기 bg dots, 무늬색 #111 위 흰색 6~8%).
- 먹선: 칸 테두리 0.5~0.7u, 말풍선 0.35~0.5u, 꼬리표 0.25u. 모서리 0. 그림자 없음.
- 집중선: 바깥이 굵고 안쪽 끝이 뾰족한 검은 쐐기. 가운데 지름 40% 원 안은 비워 둬요.

## 움직임
- 124BPM, 장면 하나 4~8박. 빠르고 경쾌하게.
- 말풍선·꼬리표·칸은 톡 튀어 나와요: 0.12초에 1.1배, 0.2초에 제자리(back.out(1.6)). 어절 사이 간격은 짧게(0.6배).
- 칸 판은 오른쪽에서 밀려 들어와 멈추고, 칸은 그 안에서 한 박에 하나씩 생겨요.
- 집중선은 움직이는 동안 초당 12번 선마다 길이·각도를 조금씩 바꿔 떨리게(시드 난수, t 의 순수 함수).
- 마무리: 흰 바탕 곳곳에 크기 다른 빈 칸이 하나씩 툭툭 생기고, 칸 안에 그림이 들어가요.

## 전환
- 컷이 기본, 칸 판은 밀어내기(push), 강조 장면은 확대(zoom)로 쿵. 말풍선이 화면을 다 덮은 흰 화면을 다음 장면 바탕으로 이어 쓰면 전환 없이 넘어가요.

## 대표 장면

1. 말풍선이 불어나 화면을 덮음
   ```
   // 검은 페이지(s-paper) 가운데 제목 한 줄. 말풍선 위치·크기는 M.rng(7) 로 미리 32개 정해 둠
   // 나오는 시각: 0번은 T0, 1~2번은 T0+M.beat(1), 3~6번은 T0+M.beat(1.75), 7~14번 T0+M.beat(2.25), 나머지 T0+M.beat(2.6)
   S.ambient(t => bubbles.forEach((b, i) => {
     const k = M.spring(t - at[i], { f: 4.2, z: .55 });          // 0.12초에 1.1배 넘쳤다 자리
     M.place(b, x[i], y[i], { s: k, o: t >= at[i] ? 1 : 0 });
   }));
   // 다 덮이면 S.tr.cut 으로 흰 바탕 다음 장면 (말풍선 흰색 = 다음 장면 종이)
   ```
2. 칸 나누기 + 꼬리표
   - 판 전체를 S.fx.slide 로 오른쪽에서 밀어 넣고, 칸마다 `M.rough('rect', { over: .2 })` 테두리를 0.25초에 긋고 바로 안을 칠함(먹·회색·흰색·청록·옅은 청록·짙은 청록). 칸 모서리 꼬리표는 S.fx.pop 으로 0.1초 늦게. 장면 쌓기에서는 frame: panel 이 칸 테두리와 번호를 그려요.
3. 떨리는 집중선
   ```
   // 쐐기 48개: 각도 a_i, 바깥 반지름 R, 안쪽 반지름 r_i
   S.ambient(t => {
     const r = M.rng(1 + Math.floor(t * 12));                    // 초당 12번 새 무늬
     wedges.forEach((w, i) => w.setAttribute('d', wedge(a[i] + (r() - .5) * .02, R, r0 * (.9 + r() * .25), .012 + r() * .01)));
   });
   // 가운데로 큰 글을 S.fx.stamp, 집중선은 같은 박에 S.fx.fade 로 0.1초
   ```
4. 기울어진 칸 속 UI
   - 앱 화면 카드를 −4도 기운 굵은 먹선 칸 안에 넣고, 칸 왼쪽 바깥에 사선 집중선 12~16개. 카드는 아래에서 M.spring 'snappy' 로 올라오고, 칸 위 모서리에 손글씨 꼬리표 하나.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱·게임 출시, 새 기능 "드디어" 공개, 웹툰·캐릭터 브랜드, 이벤트 당첨 발표, 실제 이용자 반응 소개.
- 피할 것: 부드러운 그라디언트, 흐림·유리 질감, 색 여러 개, 느린 서서히 전환, 남의 캐릭터를 그대로 따라 그리기. 말풍선 대사는 지어낸 후기처럼 보이지 않게, 브랜드가 하는 말이나 실제 반응만 넣어요.
