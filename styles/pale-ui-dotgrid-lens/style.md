# 회색 UI 원색 점판 돋보기 (제품 UI)

한 줄: 아주 옅은 회색 뼈대 UI 위에 파란 번호 핀과 검은 팝업이 톡 떠요. 원색 점들이 쏟아져 반듯한 점판으로 쌓이면, 굵은 테 돋보기가 그 위를 지나며 속의 코드를 비춰 주는 담백한 개발 도구 소개 필름이에요.

## 보는 느낌
- 바탕은 거의 흰 회색 하나예요. UI는 글씨를 다 빼고 회색 줄과 둥근 상자만 남긴 뼈대라서, 화면 전체가 흐릿하고 조용해요.
- 그 조용한 판 위에 작고 진한 것만 하나씩 올라와요. 파란 번호 핀, 검은 팝업, 검은 알약 도구 막대, 화살표 커서 같은 것들이에요.
- 중간에 원색 점판 장면이 한 번 크게 터져요. 영상 전체에서 색이 가장 많은 순간이고, 앞뒤는 다시 회색으로 돌아와요.
- 글은 늘 화면 가운데에 작게 한 줄만 둬요. 여백이 화면의 80% 넘게 남아요.
- 장면 사이 쉼표로 문자 기호로 짠 작은 얼굴 같은 마크가 가끔 가운데에 놓여요. 우리 영상에서는 브랜드 마크나 아주 단순한 기호로 바꿔 쓰고, 원본 모양은 따라 하지 않아요.

## 색
- 회색 바탕 #EDEDED 80 · 먹색 글자와 검은 팝업 15 · 원색 5.
- 글자 #2A2A2A, 흐린 UI 뼈대는 먹색 6~10%.
- 파랑 #2F8BEA 는 번호 핀과 입력칸 테두리처럼 '여기'를 짚는 데만 써요.
- 강조색 주황 #E8892E 는 문장 끝 낱말 하나에만. 주황 위 글자는 짙은 먹색.
- 코드 속 문자열은 빨강 #D9395F, 확인은 초록 #4CC764.
- 점판과 색 곡선 장면에서만 노랑 #E8C61E · 빨강 · 주황 · 청록 #35C4C0 · 초록 · 보라 #6A4FE0 · 파랑을 고루 섞어요.

## 글자
- Geist(한글은 Noto Sans KR Medium), 굵기 500. 문장은 짧은 변의 4~5%로 작고 담백하게, 자간 -0.01em.
- 입력창 안 글은 조금 더 크게(짧은 변의 6%) 두고 세로 막대 커서가 따라가요.
- 코드는 Geist Mono. 흐르는 장면에서는 짧은 변의 7~9%로 크게 키워 화면 밖까지 잘리게 둬요.
- 엔딩 이름은 짧은 변의 8%, 굵기 500. 큰 제목은 거의 쓰지 않아요.

## 질감과 모양
- 질감 없이 매끈해요. 그레인·비네트를 넣지 않아요.
- 뼈대 UI 상자 모서리 `--u` × 1.4, 검은 팝업은 모서리 1.2u에 아주 옅은 그림자 하나.
- 번호 핀은 지름 1.6u 파란 동그라미에 흰 숫자, 얇은 흰 테.
- 돋보기는 흰 렌즈에 먹색 테(짧은 변의 1.2%)와 부드러운 그림자. 렌즈 안은 흰 바탕에 흐린 코드.
- 도구 막대는 완전한 알약 모양 검정에 흰 선 아이콘.

## 움직임
- 100BPM, 보통 속도. 들어올 때는 `power3.out` 으로 빨리 와서 부드럽게 멈춰요.
- 핀·팝업·아이콘은 0.8 → 1 로 커지며 톡 나타나요(아주 약한 튐, `back.out(1.6)`).
- 점은 하나에 0.05초 간격으로 쏟아지고, 떨어지는 데 0.35초, 착지할 때 한 번 살짝 튀어요.
- 문장은 초당 18~22자로 쳐지고, 장면마다 2~3초 머물러요.
- 카메라는 뼈대 UI 위를 아주 천천히 밀어 들어가요(4초에 1.05배).

## 전환
- 서서히 사라지기(fade)와 흐림(blur)이 기본이에요. 코드가 흐르는 장면에서 빠질 때만 흐림을 길게 끌어요.
- 이름 엔딩과 기호 마크 사이는 컷.
- 장면 쌓기: fade → blur → cut.

## 대표 장면

1. 원색 점이 쏟아져 점판이 되고 돋보기가 지나감
   ```
   const dots = S.$$('.dot');              // 40개, 10열 × 4줄
   const rng = M.rng(7), cols = ['#E8C61E','#D9395F','#E8892E','#35C4C0','#4CC764','#6A4FE0','#2F8BEA'];
   dots.forEach(d => d.style.background = cols[Math.floor(rng() * cols.length)]);
   S.ambient(t => {
     dots.forEach((d, i) => {
       const k = M.ease.outCubic(M.prog(t, .3 + i * .05, .35));
       const [gx, gy] = [x0 + (i % 10) * gap, y0 + Math.floor(i / 10) * gap];
       M.place(d, M.lerp(sx, gx, k), M.lerp(sy, gy, k) - Math.sin(k * Math.PI) * gap, {o: k > 0 ? 1 : 0});
     });
     const lx = M.anim([[0, x0 - gap], [2.6, x0 + gap * 6, {d: 2, e: 'inOutSine'}]], t);
     M.place(lens, lx, cy);                // 렌즈 안에는 clip-path: circle() 로 흐린 코드 판만 보이게
   });
   ```
2. 뼈대 UI에 번호 핀과 검은 팝업
   - 회색 줄·상자만 남긴 화면을 깔고 `M.Cursor` 로 커서를 목표 줄까지 옮겨요. `M.cursorAt` 순간에 파란 핀을 `M.spring(t - tc, 'snappy')` 로 0 → 1 크기로 꽂고, 0.15초 뒤 검은 팝업을 핀 옆에서 `M.place(pop, x, y, {s: .85 + .15 * k, o: k})` 로 열어요. 팝업 안 입력칸 테두리는 파랑, 아래 작은 '취소' 글씨는 먹색 40%.
   - 장면 쌓기로는 deco cursor 가 커서를 강조 말로 데려가 누르고, title type 이 문장을 커서와 함께 쳐요.
3. 검은 알약 도구 막대와 색 곡선
   - 가운데 알약을 `S.fx` 로 가로로 펼친 뒤 아이콘 다섯 개를 0.08초 간격으로 톡톡 띄워요. 셋째 아이콘에만 작은 파란 숫자 배지를 붙여요.
   - 이어서 색 곡선 장면: SVG path 4~5개(초록·하늘·노랑·보라·먹색)를 `M.draw(path, k)` 로 위에서 아래로 그리고, 파란 핀 하나가 `getPointAtLength` 로 선을 따라 내려가요.
4. 크게 흐르는 코드가 한 줄로 오므라듦, 그리고 이름
   - 고정폭 코드 판을 짧은 변의 8% 크기로 두고 비스듬히 흘리며 `blur` 6px, 빨간 문자열 한 토막만 흐림 0. 그 뒤 `S.tr.blur` 로 넘어가 가운데 작은 문장이 쳐지고 마지막 낱말만 `M.color(onBg, accent, k)` 로 주황이 돼요.
   - 엔딩은 회색 바탕에 이름을 `M.type(name, t, t0, 12)` 로 치고, 컷 뒤 마크가 먹색에서 회색으로 서서히 옅어지며 끝나요.
