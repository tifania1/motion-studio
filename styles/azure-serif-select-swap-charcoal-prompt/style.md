# 하늘 파랑 세리프 고쳐 쓰기와 숯빛 입력 카드 (제품 UI)

한 줄: 쨍한 하늘 파랑 면에 흰 세리프 한 줄이 쳐지고, 카메라가 낱말 하나에 바짝 붙어 선택 상자로 덮은 뒤 새 낱말로 갈아 써요. 숯빛 판에서는 밝은 입력 카드의 버튼으로 파고들었다 빠지고, 보내기를 누르면 파란 원이 솟아올라 화면을 덮어요.

## 보는 느낌
- 판은 두 가지뿐이에요. 하늘 파랑 면에는 흰 세리프 한 줄만, 숯빛 판에는 밝은 회색 입력 카드 하나만 둬요. 둘 다 화면 가운데에 작게 놓고 둘레는 넉넉히 비워요.
- 파란 면에서는 글이 주인공이에요. 문장이 화면 너비의 30~40% 크기로 조용히 쳐지다가, 고칠 낱말이 나오면 카메라가 그 낱말로 바짝 붙어서 글자가 화면 밖으로 잘릴 만큼 커져요.
- 첫 장면에는 옅은 파랑의 굵은 곡선 획이 문장 뒤를 크게 한 번 휘감고 지나가요. 장식은 그것 하나로 충분해요.
- 숯빛 판의 입력 카드는 실제 앱처럼 반듯해요. 위에는 알약 탭 막대, 안에는 입력 줄, 작은 토글 한 줄, 아래에 버튼 넷(검색, 모음, 반짝이, 파란 동그라미 보내기)이 있어요.
- 커서는 하얀 테두리 화살표예요. 숯빛 판에서는 테두리만 보이게 크게 그려요.

## 색
- 숯빛 판 장면: 숯빛 #232526 70 · 밝은 카드 #ECECEA 22 · 먹 글자 #1C1D1E 5 · 파랑 3.
- 파란 면 장면: 하늘 파랑 #2F9BE6 85 · 흰 세리프 12 · 옅은 파랑 선택 상자 #8CC6F0(흰색 25%를 얹은 파랑) 3.
- 파랑은 보내기 버튼, 입력 커서, 켜진 버튼, 막 쳐진 어절에만 써요.
- 다홍 #E2553A 는 끝 판으로 넘어가는 쐐기 와이프에서 한 번만 나와요.
- 장면 쌓기에서 강조색 바탕을 쓰면 글자는 짙은 남색(#0B1724)이 돼요. 파란 면에 흰 세리프를 직접 놓을 때는 글자를 짧은 변의 8% 이상으로 크게 써서 대비를 지켜요.

## 글자
- 파란 면의 문장: Instrument Serif 400(한글은 고운바탕 400). 굵기를 올리지 않고, 자간은 0으로 둬요. 크기는 짧은 변의 8~10%, 가운데 정렬 한 줄.
- 문장은 짧게 두세 어절로 써요. 첫 판에서는 한 낱말로 시작해 한 박마다 어절을 붙여 가요.
- UI 안 글자: Geist(한글은 Noto Sans KR 500·700). 탭과 버튼 이름은 짧은 변의 2% 안팎, 입력 줄은 2.4% 안팎이에요.
- 끝의 세리프 문장 사이에는 실제 버튼 모양 칩(옅은 파랑 판, 둥근 아이콘과 작은 글자)을 글자 높이에 맞춰 끼워 넣어요.

## 질감과 모양
- 질감은 쓰지 않아요. 매끈한 면 위에 반듯한 UI만 놓아요.
- 입력 카드는 모서리 1.2u, 테두리 없이 아주 옅은 그림자 하나만 둬요. 탭 막대는 같은 회색으로 따로 떠 있는 둥근 띠이고, 고른 탭만 흰 알약이에요.
- 버튼: 회색 테두리 알약 둘, 아이콘 정사각 하나, 파란 동그라미 하나. 툴팁은 검은 둥근 사각에 흰 글자예요.
- 선택 상자는 모서리 없는 직사각형이에요. 글자 높이보다 위아래로 10%씩 넉넉하게 덮어요.

## 움직임
- 100BPM, 한 박에 0.6초쯤. 파란 면에서는 1초마다 문장 한 상태씩 바뀌어요.
- 타이핑은 초당 14~18자로 하고, 세로 막대 커서가 깜빡여요.
- 카메라 확대·축소는 0.6~0.8초, `power3.inOut` 이에요. 확대한 채로 0.5~1초 머문 뒤 빠져요.
- 숯빛 판의 커서는 부드러운 곡선으로 0.6초에 이동해요. 누르면 버튼이 0.92배로 눌렸다가 돌아와요.
- 막 쳐진 어절은 파랑으로 나왔다가 0.4초 뒤 먹색으로 가라앉아요.

## 전환
- 파란 면에서 숯빛 판으로 넘어갈 때는 컷.
- 숯빛 판에서 파란 면으로 넘어갈 때는 원형 열림(iris)을 써요. 보내기 버튼 아래쪽에서 파란 원이 솟아 커지며 화면을 덮어요.
- 끝 판으로는 다홍 쐐기가 오른쪽 아래 모서리에서 비스듬히 쓸고 들어오는 와이프를 써요. 장면 쌓기 순서: cut → iris → wipe.

## 대표 장면

1. 파란 면 낱말 고쳐 쓰기
   ```
   // 문장 한 줄을 쳐 두고, 고칠 낱말 자리로 확대 → 선택 상자 → 갈아 쓰기 → 축소
   S.ambient(t => {
     const z = M.anim([[0, 1], [1.2, 2.6, {d: .7, e: 'inOutCubic'}], [2.6, 1, {d: .7, e: 'inOutCubic'}]], t);
     M.place(stage, cx - (wordX - cx) * (z - 1), cy, {s: z});    // 낱말 쪽으로 붙기
     M.box(sel, {x: wordX, y: wordY, w: wordW * M.ease.outCubic(M.prog(t, 1.6, .25)), h: wordH});
     sel.style.opacity = t < 2.1 ? 1 : 0;                         // 새 낱말을 치기 시작하면 걷힘
     word.textContent = t < 2.1 ? '다듬' : M.type('고쳐', t, 2.1, 16);
   });
   ```
   - 첫 판의 큰 곡선 획은 옅은 파랑 SVG path 하나를 `M.draw(path, M.prog(t, .3, .8))` 로 그은 뒤 0.4초에 흐려 지워요.
   - 마지막 낱말은 `M.Cursor` 를 그 자리로 옮기고, 누르는 순간(`M.cursorAt`) 낱말을 `M.spring(t - tc, 'snappy')` 로 0.9배에서 1배로 톡 띄워요.
2. 입력 카드 버튼으로 파고들기
   - 숯빛 판 가운데 카드와 탭 막대를 두고 입력 줄에 `M.type(prompt, t, t0, 16)`.
   - 커서가 반짝이 버튼으로 가면 카드 묶음을 `M.place(card, …, {s: M.anim([[t1, 1], [t1, 2.4, {d: .7, e: 'inOutCubic'}]], t)})` 로 버튼 쪽으로 키우고, 검은 툴팁을 버튼 위에 `M.spring` 으로 띄워요.
   - 누르면 버튼 바탕을 `M.color('#E2E2E0', '#CFE6F8', k)` 로 켜고 다시 1배로 빠져요. 입력 줄은 짧은 부탁을 지우고 긴 문장으로 다시 치며, 새로 붙는 어절만 `accent` 색에서 0.4초 뒤 먹색으로 바꿔요.
3. 보내기 버튼에서 솟는 파란 원
   ```
   // 다음 장면(파란 면)을 원으로 잘라 버튼 아래에서 키움
   const R = M.anim([[0, 0], [tS, M.floodRadius(bx, H * 1.05), {d: .9, e: 'inOutCubic'}]], t);
   next.style.clipPath = `circle(${R}px at ${bx}px ${H * 1.05}px)`;
   ```
   - 장면 쌓기에서는 `S.tr.iris` 로 같은 결을 내요. 파란 면에는 세리프 두 어절 사이에 실제 버튼 칩을 끼워 문장처럼 읽히게 해요.
4. 다홍 쐐기로 끝 판
   - 파란 면의 글을 0.3초에 흐리게 빼면서, 다홍 삼각형(`clip-path: polygon`)을 오른쪽 아래 모서리에서 비스듬히 0.5초에 쓸어 화면을 덮어요. 바로 이어 숯빛 끝 판으로 컷하고, 가운데에 브랜드 마크와 이름 한 줄을 0.4초 페이드로 놓아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 문서·글쓰기 도우미 소개, AI 입력창 기능 하나 시연, 업무용 도구의 새 버튼 알리기, 15~20초 기능 티저.
- 피할 것: 종이·그레인 같은 질감, 굵은 산세리프 큰 제목, 파랑 말고 다른 강조색 여러 개(다홍은 끝 와이프에서 한 번만), 빽빽한 대시보드, 반 박마다 갈리는 몽타주 컷.
- 한글 문장은 두세 어절로 짧게 쓰고, 고칠 낱말은 두 글자 안팎일 때 확대가 가장 잘 살아요.
