# 남색 앵커 장부 세리프 (그래픽·도형)

한 줄: 남색 판과 옅은 회색 판을 오가요. 가는 파란 격자 위에서 흰 앵커 점이 큰 글자를 지어 올리고, 차분한 세리프 문장과 머리카락 같은 선 도표가 칸마다 놓이는 금융 브랜드 설명 필름.

## 보는 느낌
- 화면 전체에 가는 파란 격자가 늘 깔려 있어요. 선은 화면을 큰 칸 몇 개로 나누는 정도로 성기고, 남색 판에서는 칸 안에 아주 옅은 점 판이 하나 더 깔려요.
- 처음과 끝은 깊은 남색 판, 가운데 설명 부분은 옅은 회색 판이에요. 두 판 모두 장식 없이 선·점·네모만으로 화면을 짜요.
- 글은 한 화면에 한두 줄. 세리프 제목을 가운데 두고, 그 아래 격자 칸 안에 작은 항목 네 개가 나란히 들어가거나 파란 이탤릭 한 줄이 받쳐 줘요.
- 숫자·도표 장면은 3×3 칸 판처럼 정리돼요. 칸마다 작은 선 도표가 하나씩 있고, 카메라가 한 칸씩 들어가 보여 줘요.
- 사진을 쓸 때는 파란 한 색으로 눌러 칠하고 세리프 문장 옆에 반듯하게 붙여요.

## 색
- 회색 판 장면: 옅은 회색 #E9ECEF 75 · 남색 글자와 도형 18 · 파랑 7.
- 남색 판 장면: 남색 #14243B 80 · 연회색 #B9C4D0 글자 채움 12 · 흰 앵커 점과 파란 격자 8.
- 파랑 #1F6FD6 은 이탤릭 강조 한 줄, 큰 숫자, 반반 판의 오른쪽 면, 막대 하나에만 써요. 파랑 면 위 글자는 흰색.
- 격자 선은 파랑 16% 안팎, 반투명 글자 띠는 하늘빛 #8FB4E6 30%.

## 글자
- 제목·문장: Instrument Serif 400(한글은 고운바탕 400). 가볍고 반듯하게, 짧은 변의 6~8%, 가운데 정렬 두 줄, 줄 간격 1.1.
- 강조 한 줄: 같은 세리프의 이탤릭을 파랑으로. 한 장면에 한 줄만.
- 큰 숫자: 세리프 400 을 짧은 변의 12% 로 키워 파랑, 둘레의 보조 숫자는 남색으로 작게.
- 꼬리표·축 이름: Geist 500(한글 Noto Sans KR Medium) 대문자, 짧은 변의 1.4%, 자간 +0.06em.
- 앵커로 짓는 큰 글자: Archivo 800, stretch 100%(한글 Noto Sans KR Black). 브랜드 이름이나 짧은 낱말 하나를 화면 너비 70% 로.

## 질감과 모양
- 질감은 쓰지 않아요. 매끈한 벡터 화면 그대로.
- 선은 모두 1px 머리카락 두께. 앵커 점은 한 변 0.6u 흰 정사각형, 도표 마디는 0.5u 속 빈 원.
- 모서리는 거의 직각(0.2u). 칸·카드는 테두리만 있고 그림자는 없어요.
- 막대 하나쯤은 남색 점을 빽빽하게 찍은 망점 무늬로 채워서 칠한 막대와 짝을 지어요.

## 움직임
- 96BPM(한 박 0.625초). 크고 느긋한 변화가 박에 맞춰 일어나고, 한 장면에 3~5초 머물러요.
- 이징은 power3.inOut. 카메라 줌과 도형 이동은 미끄러지듯 시작해 부드럽게 멈춰요.
- 선은 0.6~0.8초에 그어지고, 점은 그 선을 따라 한 박 안에 차례로 톡톡 켜져요(0.04초 간격).
- 세리프 문장은 줄마다 선 아래에서 올라오고(mask), 강조 이탤릭은 반 박 늦게 따라와요.
- 나갈 때는 대부분 그대로 둔 채 다음 전환이 덮어요.

## 전환
- 판 바꾸기는 닦아 내기(wipe)가 기본. 남색 → 회색은 격자 선 하나를 따라 면이 쓸려 나가요.
- 3×3 칸 판에서는 카메라가 한 칸으로 들어가는 줌이 곧 전환이에요. 칸 테두리가 화면 테두리가 되면 컷.
- 끝에 남색으로 돌아갈 때만 느린 페이드. 장면 쌓기: wipe → cut → fade.

## 대표 장면

1. 앵커 점에서 지어지는 큰 글자
   ```
   // 남색 판, 격자 SVG 위에 앵커 점·띠·글자 윤곽을 겹쳐 둠
   const pts = S.$$('.anchor');                 // 글자 윤곽의 꼭짓점마다 흰 네모
   S.ambient(t => {
     M.draw(dropLine, M.ease.outCubic(M.prog(t, 0, .8)));            // 첫 점에서 세로 선
     pts.forEach((p, i) => M.place(p, p._x, p._y, {o: +(t > M.beat(2) + i * .04)}));
     bands.forEach((b, i) => M.place(b, b._x, b._y, {rot: M.anim([[0, -30], [M.beat(3) + i * .1, b._rot, {d: .8, e: 'inOutCubic'}]], t), o: .3}));
     M.draw(outline, M.prog(t, M.beat(6), 1));                       // 점을 잇는 윤곽
     letters.style.fillOpacity = M.prog(t, M.beat(8), .6);           // 연회색으로 채움
   });
   ```
   글자 아래 작은 세리프 한 줄은 채움이 끝난 다음 박에 mask 로 올라와요.
2. 세 장으로 펼쳐지는 정사각형
   ```
   // 같은 크기 네모 셋을 가운데 겹쳐 두고 박마다 대각선으로 벌렸다 모음
   const k = M.anim([[0, 0], [M.beat(2), 1, {d: .6, e: 'inOutCubic'}], [M.beat(6), 0, {d: .6, e: 'inOutCubic'}]], t);
   [gray, blue, navy].forEach((sq, i) => M.place(sq, cx + (i - 1) * k * u * 4, cy + (i - 1) * k * u * 3));
   ```
   펼쳐진 순간 아래 격자 칸 하나가 파랑 16% 로 살짝 차올라요.
3. 3×3 선 도표 판으로 파고들기
   - 칸 9개에 SVG 도표를 두고 `M.draw` 로 동시에 0.8초에 그어요. 마디 원은 선이 지나갈 때 `M.spring(t - ti, 'snappy')` 로 톡.
   - 카메라는 판 전체를 `M.place(board, x, y, {s})` 로 옮겨 한 칸이 화면을 채우게(s ≈ 3) 1.2초 power3.inOut 으로 들어가고, 거기서 곡선 꼬리표(대문자 Geist)를 한 박씩 켠 뒤 컷으로 다음 칸.
4. 호 위의 아이콘 원과 큰 숫자
   - 회색 판 가운데 큰 반원 호를 `M.draw` 로 긋고, 호 위 7곳에 속 빈 원을 같은 간격으로 놓아요. 원 사이를 잇는 가는 곡선 다발이 아래로 늘어져요.
   - 가운데 큰 파란 세리프 숫자는 장면 쌓기 number: count 로 올라가고, 양옆 보조 숫자 둘은 남색으로 작게. 원 안 작은 도형이 왼쪽부터 하나씩 색을 띠어요(`M.at` 으로 0.3초 간격).
   - 반반 판(왼쪽 남색 세리프 문장, 오른쪽 파랑 면 흰 문장)은 `S.tr.wipe` 결로 파랑 면이 오른쪽에서 밀려 들어오고, 작은 알약 꼬리표가 반 박 간격으로 떠요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·투자 브랜드 소개, 펀드·자산 운용 설명, 신뢰가 중요한 B2B 서비스, 연례 보고·성과 숫자, 브랜드 리뉴얼 공개.
- 피할 것: 손그림 선과 떨림, 크게 둥근 모서리, 강조색 여러 개(파랑 하나만), 빠른 컷 몽타주, 그레인·종이 질감, 굵은 세리프 제목.
- 한글 제목은 고운바탕으로 짧게 두 줄. 이탤릭 강조는 한글 대신 숫자나 짧은 영문 낱말에 걸면 결이 더 살아요.
