# 핸들 도형 합체 (그래픽·도형)

한 줄: 검은 바탕에 원·알약·물방울·과녁 도형이 네 귀퉁이 작은 정사각형을 달고 톡톡 생겨나 한데 모여 마크가 되는 엔딩.

## 보는 느낌
- 까만 화면에 납작한 원색 도형 네다섯 개. 도형마다 편집 프로그램의 선택 핸들처럼 네 귀퉁이에 작은 정사각형이 붙어 있어요.
- 도형이 하나씩 생기며 화면을 채우다가, 한가운데로 빨려 들어 겹치며 하나의 마크가 돼요. 짧고 경쾌한 로고 엔딩.
- 마지막엔 검은 화면 자체가 앱 아이콘만 하게 오므라들어 밝은 회색 바탕에 놓여요.

## 색
- 검정 바탕 #0F0F10 70 · 원색 도형 25 · 핸들 5.
- 도형: 빨강 #E23C44, 주황 #E46D3E, 초록 #44D16E, 파랑 #3E5BE8, 하늘 #6EEBE5. 핸들은 도형과 대비되는 색(보라 #8A2BE2, 연두 #D8F38A, 연분홍 #D38BE3, 파랑).
- 브랜드 색으로 바꿀 땐 브랜드 색 4~5개를 도형에, 보색 계열을 핸들에.
- 엔딩 바탕 #D9D9D9.

## 글자
- 거의 없어요. 필요하면 엔딩에 브랜드 이름 한 줄(Geist 700 + Noto Sans KR Bold).

## 질감과 모양
- 질감 없음, 완전히 납작한 면. 그림자·테두리 없음.
- 도형: 원, 알약(가로로 긴), 물방울(한 귀만 뾰족한 원), 과녁(겹 원 3겹), 사각 테두리 안 원. 핸들은 도형 지름의 20% 정사각형.
- 엔딩 아이콘은 둥근 사각(`--u` × 2 보다 크게, 앱 아이콘 비율).

## 움직임
- 128BPM, 빠름. 도형은 박마다 하나씩, 0에서 `pop` 스프링으로(살짝 넘침). 핸들은 도형보다 0.05초 늦게 바깥에서 붙음.
- 도형들은 머무는 동안 제자리에서 천천히 돌고(핸들도 같이), 서로 조금씩 다가가요.
- 합쳐질 때는 한 박 안에 `expo.in` 처럼 빨려 들어가 겹침.

## 전환
- 오므라드는 줌: 검은 화면이 아이콘 크기로 작아지며 다음(엔딩) 바탕이 드러나요.
- 장면 쌓기: zoom → cut.

## 대표 장면
1. **도형 + 핸들 생성**: 도형 i 를 `M.place(shape_i, x_i, y_i, {s: M.spring(t - M.beat(i), 'pop'), rot: (t - M.beat(i)) * 20})`. 핸들 4개는 도형 중심에서 대각선 거리 d 에 두되 `d = M.lerp(d0 * 1.6, d0, M.spring(t - M.beat(i) - .05, 'snappy'))`, 같은 회전각을 더함.
2. **한가운데로 합체**: 합체 시각 tM 에 각 도형 위치를 `M.anim([[0, [x_i, y_i]], [tM, [cx + ox_i, cy + oy_i], {d: .45, e: 'inExpo'}]], t)` 로 모음(ox·oy 는 마크 안 자리). 크기도 0.6배로.
   핸들은 마크 둘레 사각 테두리 자리로 모였다가 다음 박에 `o` 0.
3. **검은 화면 → 앱 아이콘**: 검은 판 전체를 `M.box(board, {w, h, r})` 로 W×H, r 0 에서 아이콘 크기(18u), r 4u 로 `smooth` 스프링 축소. 바깥은 #D9D9D9. 마크도 판과 같은 비율로 작아짐.
   두 번째 아이콘(제휴·연동 상대, 브랜드 소유 이미지만)을 오른쪽 밖에서 `M.anim` 으로 미끄러뜨려 나란히 세우고, 사이에 작은 세로 막대 하나.

## 어울리는 곳 / 피할 것
- 어울림: 로고 엔딩, 연동·제휴 발표, 디자인·크리에이티브 브랜드, 짧은 로고 루프(4~6초).
- 피할 것: 사진, 긴 문장, 그라디언트, 부드러운 페이드.
- 원본 로고의 도형 조합을 그대로 따라 만들지 않아요. 브랜드 로고를 이루는 도형으로 새로 짜요.
