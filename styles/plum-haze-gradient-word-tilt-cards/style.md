# 자두빛 안개 속 기운 유리 카드 (그라디언트·빛)

한 줄: 짙은 자두빛 어둠 가장자리에 보라·분홍 빛이 번지고, 가운데 낱말은 흐림에서 맺히며 라벤더에서 분홍으로 물들어요. 그 사이로 노드 그래프와 가격 카드, 코드 창이 비스듬히 누운 채 초점을 옮겨 가며 지나가요.

## 보는 느낌
- 바탕은 거의 검은 자두빛이에요. 화면 위쪽 가운데와 아래 모서리에서 보라·분홍 빛이 안개처럼 번지고, 가운데는 어둡게 비워 둬요.
- 글 장면은 한가운데 낱말 하나나 짧은 한 줄만 둬요. 여백이 넓고, 글자는 크지만 굵지 않아요.
- UI 장면은 늘 기울어 있어요. 노드 그래프, 코드 창, 가격 카드를 3D로 눕혀 놓고 카메라가 천천히 미끄러지며, 초점 밖은 부드럽게 흐려져요.
- 시작만 밝은 회색 화면이에요. 세로 막대 커서와 회색 문장 한 줄로 열고, 아래에서 보라 빛이 차오르며 어둠으로 넘어가요.
- 사이사이 화면보다 큰 빛 테두리 원이 위아래로 잘린 채 지나가며 장면을 감싸요.

## 색
- 자두빛 어둠 70 · 빛 안개(보라·분홍) 20 · 흰 글자와 라벤더 강조 10.
- 바탕 #1A1424, 유리 카드 #2A2236(반투명), 글자 #ECE6F5.
- 그라디언트 낱말: 라벤더 #B49CF4 → 분홍 #E8638F. 안개는 보라 #6F4BD8 와 분홍 #E8638F 를 섞어요.
- 강조(accent)는 라벤더 #B49CF4. 카드 테두리 빛, 알약 꼬리표에 써요. 꼬리표 글자는 짙은 자두색.
- 빛줄기에 아주 잠깐 파랑을 섞어도 좋아요. 다른 원색은 꼬리표 하나 정도로 아껴요.

## 글자
- Geist 500(한글은 Noto Sans KR Medium). 둥글고 반듯한 산세리프, 자간 -0.02em.
- 큰 낱말은 짧은 변의 14~18%, 짧은 문장은 7~8%. 늘 가운데 정렬, 한 줄.
- 큰 숫자는 Geist 600 정도로 조금만 더 굵게, 그 아래 작은 꼬리표 한 줄(아이콘 칩 + 낱말).
- 코드 창은 Geist Mono, 회색 바탕 위 연보라·분홍·하늘색 구문 색.

## 질감과 모양
- 그레인 0.05, 비네트 0.35. 어둠의 그라디언트가 띠지지 않게 아주 옅게만.
- 유리 카드: 흰색 6~10% + 블러 + 1px 흰 테두리(20%), 모서리 `--u` × 1.6. 위쪽 테두리에 라벤더 빛이 살짝 맺혀요.
- 고른 카드는 테두리 전체가 라벤더로 빛나고(`box-shadow: 0 0 4u var(--glow)`), 나머지는 흐리게 물러나요.
- 노드 상자는 짙은 회보라 둥근 사각, 가는 회색 연결선, 둥근 아이콘 원.

## 움직임
- 96BPM, 느림. 들어오는 건 `power2.out`, 카메라 미끄럼은 `sine.inOut`.
- 낱말은 흐림 8px·불투명 0에서 0.6초에 맺히고, 나갈 땐 다시 흐려지며 빠져요.
- 기운 UI 판은 4~6초 동안 짧은 변의 10~15%만큼 옆으로 미끄러지고, 초점은 1.5초에 걸쳐 다음 카드로 옮겨 가요.
- 장면마다 2.5~3.5초 머물러요. 서두르지 않아요.

## 전환
- 흐림 전환(blur)이 기본이에요. 앞 장면이 흐려지며 다음 장면이 흐림 속에서 맺혀요.
- 큰 빛 테두리 원이 열리며 넘어가는 원형 열림(iris), 그리고 느린 페이드. 장면 쌓기: blur → iris → fade.

## 대표 장면
1. **밝은 회색에서 어둠으로**: 밝은 회색 판 가운데 세로 막대(주황→빨강 그라디언트)가 깜빡이다 회색 문장 한 줄로 바뀌어요. 아래에서 보라 안개가 차오르며 판이 어두워져요.
   ```
   S.ambient(t => {
     M.place(bar, cx, cy, {o: Math.floor(t * 2) % 2 ? 1 : .2});
     const k = M.ease.inOutCubic(M.prog(t, 3, 2));
     bg.style.background = M.color('#EDEBF0', '#1A1424', k);
     M.place(haze, cx, H, {o: k, s: .8 + k * .4});
   });
   ```
2. **흐림에서 맺히는 그라디언트 낱말과 빛줄기**: 낱말에 `background: linear-gradient(90deg, #B49CF4, #E8638F); -webkit-background-clip: text`. 아래에 다음 낱말을 흐린 회색으로 깔아 둬요.
   ```
   const k = M.spring(t - t0, 'smooth');
   M.place(word, cx, cy, {o: k, blur: (1 - k) * 8});
   M.place(streak, cx + Math.sin(t * .5) * W * .08, cy + H * .06, {blur: 24, o: .8});
   M.place(next, cx, cy + H * .14, {o: .25, blur: 6});
   ```
   장면 쌓기에서는 title: blur, deco streaks 로 같은 결이 나와요.
3. **빛 테두리 원과 숫자**: SVG `circle` 하나에 흰→분홍 그라디언트 선(2px)과 바깥 빛 한 겹. 오프닝에서는 지름을 화면의 1.6배로 두어 위아래만 보이게 하고, 숫자 장면에서는 숫자를 감싸도록 줄여요. 원이 열리며 다음 장면으로 갈 땐 `S.tr.iris`.
   ```
   const r = M.anim([[0, H * .9], [t0, H * .32, {d: 1.2, e: 'inOutCubic'}]], t);
   ring.setAttribute('r', r);
   num.textContent = Math.round(M.ease.outCubic(M.prog(t, t0, 1.4)) * 9) + 'x';
   ```
4. **기운 판 위 초점 이동**: 노드 그래프나 가격 카드 더미를 부모 `perspective` 안에 `rotateX(28deg) rotateZ(-8deg)` 로 눕히고, 판 전체를 천천히 옆으로 밀어요. 카드마다 초점 시각을 정해 흐림을 바꿔요.
   ```
   M.place(plane, M.anim([[0, cx + W * .06], [5, cx - W * .06, {d: 5, e: 'inOutSine'}]], t), cy);
   cards.forEach((c, i) => {
     const f = 1 - Math.min(1, Math.abs(t - focusAt[i]) / 1.5);
     M.place(c, c._x, c._y, {blur: (1 - f) * 6, o: .5 + f * .5});
     c.style.boxShadow = f > .8 ? '0 0 4u var(--glow)' : 'none';
   });
   ```
   노드 연결선은 `M.draw(path, k)` 로 판이 미끄러지는 동안 한 줄씩 그어요.
