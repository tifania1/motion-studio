# 격자와 주석 (그래픽·도형)

한 줄: 둥근 사각 격자 선이 깔린 미색 바탕에 작은 고정폭 주석과 점, 그라디언트 정사각형 하나로 짜는 조용한 설계도풍.

## 보는 느낌
- 미색 바탕에 둥근 모서리 사각형들이 서로 맞물린 가는 회색 격자 선이 깔려 있어요(퍼즐 조각 테두리처럼).
- 화면엔 아주 작은 것들만: 가운데 글씨 한 줄, 양 끝 작은 점, 고정폭 주석 몇 개, 그라디언트 정사각형 하나. 큰 것이 하나도 없어서 오히려 눈이 가운데로 모여요.
- 가끔 화면이 짙은 회색으로 반전되고, 점 몇 개가 원을 그리며 '찾는 중'을 보여 줘요.

## 색
- 바탕 #E4E3E0 85 · 격자 선 #C5C3BE 5 · 글자 검정 7 · 그라디언트 정사각형 3.
- 강조는 회보라 #6E6AA8(로고 옆 부제 같은 곳). 그라디언트 정사각형은 남색·자두·하늘이 흐릿하게 섞인 색.
- 반전 장면: 바탕 #2A2A2B, 글자·점 흰색.

## 글자
- 제목: Geist 500 + Noto Sans KR Medium, 화면 높이 2.5~3%로 작게. 굵기 대비(굵은 이름 + 보통 굵기 설명)만 써요.
- 주석: Geist Mono, 아주 작게(1.4~1.8%), 앞에 작은 점이나 사각 표시. 두세 줄짜리 짧은 라벨. 고정폭은 띄어쓰기가 넓어 한글 문장엔 어색하니 영문·숫자 라벨(예: AGENT_01, 12:04)에만 써요. 본문은 Geist + Noto Sans KR.

## 질감과 모양
- 그레인 0.03(거의 안 보일 만큼). 격자 선 1px.
- 둥근 모서리 `--u` × 2.6. 그라디언트 정사각형도 모서리를 살짝 둥글게.

## 움직임
- 100BPM, 보통. 이동은 `expo.inOut` 처럼 천천히 출발해 미끄러지고 부드럽게 멈춤.
- 점·주석은 박마다 하나씩 바뀌어요. 글자는 한 글자씩 써지고 지울 때도 한 글자씩.
- 격자 선은 가운데에서 바깥으로 한 겹씩 0.08초 간격으로 그려짐.

## 전환
- 포털 줌: 그라디언트 정사각형이 화면 가득 커지며 그 안이 다음 장면. 반대로 다음 장면이 작은 정사각형으로 오므라들며 돌아오기도 해요.
- 장면 쌓기: zoom → cut.

## 대표 장면
1. **막대 → 두 점 → 문구**: 세로 막대 2개(일시정지 표시)를 가운데 두고, 막대 높이를 `M.anim` 으로 줄여 점으로 만든 뒤 양옆으로 `M.anim([[0, 0], [t1, d, 'smooth']], t)` 만큼 벌림.
   그 사이 문구는 `M.type(문구, t, t1 + .15, 20)` 로 한 글자씩. 끝낼 땐 거꾸로 지우면서 점이 다시 모임.
2. **주석 달린 정사각형 → 포털**: 가운데 정사각형(14u)에 `radial-gradient` 두세 겹. 둘레 네 방향에 고정폭 주석을 `M.place` 로 두고 박마다 `M.swap` 으로 내용 바꿈. 정사각형 안 그라디언트도 `M.color` 로 남색↔자두 사이를 오감.
   포털: `M.box(sq, {w, h, r})` 의 w·h 를 `M.anim([[0, 14u], [tP, S.W * 1.1, {d: .9, e: 'inOutExpo'}]], t)` 로 키우고, 안에 다음 장면을 같은 크기로 함께 키움(또는 `clip-path` 로 안쪽만 보이게).
3. **격자 선이 퍼짐**: 둥근 사각 격자를 SVG `path` 로 그리고 가운데에서 거리 순서로 정렬. path i 를 `M.draw(p, M.prog(t, t0 + .08 * ring_i, .5))`.
4. **반전 장면의 점 원**: 바탕을 `M.color('#E4E3E0', '#2A2A2B', k)` 로 바꾸고 점 12~16개를 반지름 R 원 위에 둠. 각 점 각도 `a_i + t * .6`, 반지름 `R + Math.sin(t * 2 + i) * .6u`, 크기 0.4~0.8u 제각각(`M.rng(2)`). 가운데 '찾는 중…' 같은 작은 고정폭 글씨.
