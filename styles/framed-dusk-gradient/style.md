# 액자 속 짙은 그라디언트 (그라디언트·빛)

한 줄: 가장자리를 얇게 남긴 미색 액자 안에서 자두·남색 그라디언트가 흐르고, 흰 입력 카드에 문장이 타이핑되는 무드.

## 보는 느낌
- 화면 가장자리에 얇은 미색 띠가 남아 있고, 그 안쪽 둥근 사각 '액자'에 짙은 자두·보라·남색 그라디언트가 가득해요. 그림을 벽에 건 것처럼 한 걸음 떨어져 보는 느낌.
- 가운데엔 흰 입력 카드 하나. 카드 그림자는 거의 없고, 배경의 짙은 색이 카드를 띄워 줘요.
- 문구 장면에선 액자 안 그라디언트 색이 낱말과 함께 바뀌어요(호박·남색·자두·청보라).

## 색
- 액자 안 그라디언트 80(#4B2340 자두, #8C3A6E, #5B6FA8 남색, #C9A27A 호박 중 두세 색) · 미색 띠와 카드 #EFEDEE 15 · 글자 5.
- 강조는 분홍 #E07AB4: 입력 카드 속 핵심 단어 형광 블록.
- 짙은 쪽은 거의 검정에 가까운 자두색까지 내려가요. 밝은 쪽은 회분홍.

## 글자
- 산세리프 400(Geist + Noto Sans KR Medium). 입력 카드 안 문장은 화면 높이 2.5%, 그라디언트 위 문구는 흰색 3%.
- 'A — B' 처럼 고정된 앞말과 바뀌는 뒷말 사이에 가는 줄표. 뒷말만 조금 더 진하게.

## 질감과 모양
- 그레인 0.08. 그라디언트에 고운 입자가 보여야 비싼 인쇄물 같아요.
- 액자 안쪽 모서리 `--u` × 2.4, 미색 띠 두께는 짧은 변의 1~1.5%.
- 입력 카드: 미색, 모서리 크게, 오른쪽 아래에 검은 원 버튼 두 개.

## 움직임
- 100BPM, 보통. 그라디언트는 늘 천천히 흐르고(8~12초 주기), 카드와 글자는 `power3.inOut` 으로 단정하게.
- 타이핑은 초당 18~22자. 형광 블록은 왼→오로 0.3초 칠해지고 한 박 머물다 사라짐.
- 뒷말이 바뀌는 문구는 한 박에 하나씩.

## 전환
- 카드가 화면 가득 커지며(줌) 다음 UI 장면으로, 또는 그라디언트 색만 바뀌는 페이드.
- 체크무늬 칸 전환: 화면을 3×3 칸으로 나눠 그라디언트 칸과 UI 칸이 번갈아 들어섰다가 한 화면으로 합쳐짐.
- 장면 쌓기: zoom → fade → cut.

## 대표 장면
1. **액자 그라디언트**: 화면 전체를 미색으로 칠하고 안쪽 판을 `inset: 1.2u` + 둥근 모서리. 판 안에 큰 원 4~5개(`radial-gradient`, 자두·남색·회분홍)를 `blur(12u)` 로 흐리고 `S.ambient` 에서 각 원을 `sin/cos(t * .1 + i)` 로 천천히 이동. 위에 그레인은 스타일 look 이 덮어 줘요.
2. **입력 카드 타이핑 + 분홍 형광**: 카드 안 문장 `M.type(문장, t, t0, 20)`. 핵심 단어가 다 쳐진 뒤 `S.mark(el, '단어')` + `S.fx.marker(mark, t1)` 를 분홍으로. 다음 박에 마커 불투명도를 0으로.
   파일 아이콘 2~3개가 카드 위쪽 밖에서 `M.anim` 으로 날아와 카드 안 왼쪽 위에 0.1초 간격으로 붙음(`pop` 스프링).
3. **뒷말 따라 바탕색 바뀜**: 'A — B' 문구에서 B 를 `M.at(목록, t)` 로 박마다 바꾸고(바뀔 때 `M.swap` 짧게), 같은 박에 그라디언트 원들의 색을 `M.color(이전, 다음, M.spring(t - tk, 'soft'))` 로 함께 바꿈.
4. **체크무늬 칸 → 한 화면**: 화면을 3×3 으로 나눈 칸 9개 중 다섯 칸엔 그라디언트, 네 칸엔 UI 조각을 넣고 `M.rng(6)` 순서로 0.08초 간격 등장. 한 박 뒤 칸 사이 틈(0.6u)을 0으로 줄이며 하나의 큰 UI 화면으로 합침.

## 어울리는 곳 / 피할 것
- 어울림: AI 도구·입력창 중심 기능, 연동·통합 소개(뒷말 바꾸기), 프리미엄 서비스, 음성·대화 서비스.
- 피할 것: 밝은 원색, 크고 굵은 제목, 손그림.
- 사진(인물 격자)을 섞을 땐 미색 바탕에 따로 장면을 만들고 액자 장면과 번갈아 써요.
