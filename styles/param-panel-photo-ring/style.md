# 설정 패널 사진 고리 (제품 UI)

한 줄: 푸른 회색 바탕에 흰 설정 패널이 하나 떠 있어요. 커서가 슬라이더와 토글을 건드릴 때마다 패널 뒤 결과물이 면 그래프, 사진 벽, 어둠 속 3D 사진 고리로 다시 펼쳐지는 도구 시연 필름이에요.

## 보는 느낌
- 바탕은 차분한 푸른 회색 한 가지예요. 그 위에 흰 패널 하나가 화면 가운데나 오른쪽 3분의 1에 떠 있어요. 패널은 늘 같은 크기, 같은 자리에 있어서 눈이 기준을 잃지 않아요.
- 주인공은 패널 뒤 결과물이에요. 값을 바꾸면 결과물이 화면 가장자리까지 꽉 차게 다시 그려져요. 겹친 면 그래프, 파란 테두리 사진 격자, 흩어진 사진 카드, 고리로 말린 사진 띠, 포스터 시안이 차례로 나와요.
- 시작은 흐린 하늘빛·미색 물결 무늬 위 입력 카드예요. 중간에 보라빛이 도는 어둠이 오고, 다시 회색으로 돌아왔다가 끝은 숯빛 화면에 두 색 문장 한 줄로 맺어요. 밝음과 어둠을 번갈아 오가며 숨을 바꿔요.
- 커서는 크고 검은 화살표 하나예요. 늘 무언가를 누르러 가는 중이에요.

## 색
- 회색 바탕 60 · 흰 패널 25 · 결과물 색 10 · 파랑 5.
- 바탕 #A8AFBB, 패널 #F4F4F5. 패널 글자는 #1C1C1E, 보조 글자는 같은 색 55%.
- 조작의 색은 파랑 #3C9BE8 하나예요. 슬라이더 채움, 켜진 토글, 버튼, 선택 테두리, 사진 카드 1px 테두리에 써요. 파랑 위 글자는 짙은 남색 #0A1626.
- 결과물 색은 장면마다 한 계열만 써요. 자홍 그라디언트(#C8366E → #E79BD0), 초록 농담(#2F5A1E → #B8E04A), 사진 장면은 사진 색 그대로, 포스터는 라임 #D4EE3E.
- 어두운 장면 바탕은 보라 기운이 도는 검정 #1A1622, 엔딩은 #141414.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 패널 글씨는 400~500 굵기로 작고 가볍게, 짧은 변의 2.2~2.8%.
- 패널 제목은 500, 아이콘 하나 옆에 둬요. 이름 글자가 쳐질 때는 막 들어온 서너 자만 파랑으로 보였다가 0.3초 뒤 검정으로 가라앉아요.
- 엔딩 문장은 짧은 변의 9% 안팎, 500, 자간 -0.02em. 앞 낱말은 파랑, 나머지는 흰색으로 두고 두 줄을 계단처럼 엇갈려 놓아요.
- 숫자 입력칸은 오른쪽 정렬이에요. 슬라이더가 움직이면 숫자도 자리마다 굴러가요.

## 질감과 모양
- 질감은 없이 매끈하게 가요. 깊이는 그림자와 흐림으로만 내요.
- 패널: 흰색, 모서리 1.6u, 아주 옅은 그림자 한 겹(0 1u 3u 검정 12%). 맨 위 줄에 아이콘·제목, 오른쪽에 작은 아이콘 둘.
- 슬라이더는 가는 회색 홈에 파랑 채움과 흰 손잡이, 토글은 파랑 알약이에요.
- 사진 카드는 모서리 없이 1px 파랑 테두리를 둘러요. 고른 카드는 네 귀퉁이에 작은 흰 네모 손잡이가 붙어요.
- 어두운 3D 장면에서는 먼 카드에 흐림 4~10px, 빠르게 지나가는 카드에 방향 흐림을 얹어요.

## 움직임
- 100BPM, 보통 빠르기예요. 조작은 박에 맞추고, 결과물은 그 박에 바로 바뀌어요.
- 커서는 power3.out 으로 목표에 붙어요. 0.1초 눌린 뒤(크기 0.9) 값이 바뀌어요.
- 패널은 높이만 0에서 끝까지 0.5초에 열리고(power3.out), 안의 줄은 0.06초 간격으로 차례로 나타나요.
- 그래프는 면 꼭짓점이 새 값으로 0.6초에 미끄러지며 색이 함께 바뀌어요. 사진 격자는 0.5초에 칸 크기를 다시 맞춰요.
- 사진 고리는 8초에 한 바퀴쯤 천천히 돌아요. 흩뿌림 장면에서는 카메라가 1.5초 동안 앞으로 밀고 들어가요.
- 조작 하나에 머무는 시간은 1.5~2.5초예요.

## 전환
- 컷이 기본이에요. 버튼을 누르는 그 프레임에 컷으로 결과물 장면이 돼요.
- 핵심은 '같은 자리 컷'이에요. 패널은 그대로 두고 뒤의 결과물만 갈아 끼워요.
- 밝은 장면과 어두운 장면 사이는 흐림 전환(S.tr.blur)으로, 도구 화면을 옆으로 넘길 때는 밀어내기로 이어요. 장면 쌓기 순서는 cut → push → blur.

## 대표 장면

1. 입력 카드가 설정 패널로
   ```
   prompt.textContent = M.type(text, t, 1.0, 24);              // 물결 바탕 위 카드에 문장 치기
   const w = M.anim([[0, W * .5], [3.2, W * .34, {d: .4, e: 'inOutCubic'}]], t);
   const h = M.anim([[0, U * 6], [4.0, U * 26, {d: .5, e: 'outCubic'}]], t);
   M.box(card, {x: cx - w / 2, y: cy - U * 3, w, h});         // 줄었다가 아래로 펼쳐짐
   S.chars(title).forEach((c, i) => {
     const ci = 3.5 + i * .05;
     c.style.opacity = t > ci ? 1 : 0;
     c.style.color = M.color('#3C9BE8', '#1C1C1E', M.prog(t, ci + .15, .3));
   });
   rows.forEach((r, i) => M.place(r, 0, 0, {o: M.prog(t, 4.2 + i * .06, .2)}));
   ```
2. 슬라이더를 밀면 뒤 그래프가 바뀜
   ```
   // 커서는 M.Cursor 로 손잡이까지 옮기고, M.cursorAt 으로 누르는 시각 tP 를 잡아요
   const v = M.anim([[0, .3], [tP, .72, {d: .6, e: 'outCubic'}]], t);
   fill.style.width = v * 100 + '%';
   num.textContent = Math.round(v * 8);                       // 숫자칸도 같이
   series.forEach((p, s) => {
     p.setAttribute('d', area(data[s].map(d => d * (.6 + v * .8))));
     p.style.fill = M.color(magenta[s], green[s], M.prog(t, tP, .6));
   });
   ```
   패널은 움직이지 않아요. 그래프 선 위 점(흰 원)과 꺾은선만 M.draw 로 0.4초에 다시 그어 주면 '방금 바뀌었다'가 읽혀요.
3. 사진 벽이 3D 고리로 말림
   ```
   S.ambient(t => cards.forEach((c, i) => {
     const k = M.ease.inOutCubic(M.prog(t, 0, 1.4));
     const a = i / cards.length * Math.PI * 2 + t * .8;
     const x = gx[i] + (cx + R * Math.cos(a) - gx[i]) * k;
     const y = gy[i] + (cy + (i % 5 - 2) * U * 4 - gy[i]) * k;
     const z = R * Math.sin(a) * k;
     c.style.transform = `translate3d(${x}px,${y}px,${z}px) rotateY(${-a * k}rad)`;
     c.style.filter = `blur(${Math.max(0, -z) / R * 6}px)`;
   }));
   ```
   회색 격자 장면에서 어두운 고리 장면으로는 S.tr.blur 로 넘어가요. 고리가 다시 풀릴 때는 카드마다 무작위 깊이(M.rng)를 주고, 카메라 z 를 1.5초 동안 앞으로 밀어요. 지나가는 카드는 가로 흐림으로 처리해요.
4. 선택 손잡이와 두 색 엔딩
   - 커서가 이미지 하나를 누르면 파랑 테두리와 네 귀퉁이 흰 손잡이가 0.15초에 톡 붙어요(deco handles). 이어 오른쪽에 같은 패널이 밀려 들어오고, 버튼을 누르면 포스터 시안 서너 장이 비스듬히 겹쳐 생겨나요.
   - 마지막은 숯빛 화면이에요. 파랑 낱말과 흰 낱말 두 줄이 어절마다 아래에서 올라와요(M.spring 'smooth', 0.12초 간격). 둘레 가장자리에는 앞에서 만든 결과물 조각(그래프 한 귀퉁이, 사진 더미, 버튼)이 반쯤 잘린 채 걸리고, 커서는 흰 윤곽 화살표로 바뀌어 한 번 누르고 끝나요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 플러그인·생성 도구 소개, 디자인·편집 기능 시연, 설정 하나로 결과가 바뀌는 기능, 사진·자료를 한꺼번에 정리하는 서비스, 개발자 도구 런칭.
- 피할 것: 손그림 선과 종이 질감, 강조색 여러 개(조작은 파랑 하나), 패널 자리가 장면마다 흔들리는 연출, 글이 긴 큰 제목, 느린 페이드만으로 잇기.
- 패널 속 낱말은 짧은 이름표(모양, 너비, 간격, 색 조합)로만 써요. 문장은 입력 카드와 엔딩 두 곳에만 둬요.
