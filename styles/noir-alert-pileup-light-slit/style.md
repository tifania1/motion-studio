# 어둠 속 알림 더미와 빛 틈 (제품 UI)

한 줄: 새까만 화면에서 빛나는 버튼 하나를 누르면 어두운 유리 알림 카드가 하나씩 불어나 불꽃 그래프 대시보드 더미로 번지고, 세로 빛 틈이 한 번 지나간 뒤 회색 문장 한 줄이 어절마다 하얗게 밝아져요.

## 보는 느낌
- 거의 검은 바탕. 처음엔 화면이 텅 비어 있고 요소가 하나뿐이에요(빛나는 버튼 → 앱 아이콘 하나).
- 이야기는 '조용함 → 쌓임 → 꽉 찬 혼란 → 다시 비움' 순서로 흘러요. 알림 카드가 하나씩 늘면서 여백이 줄고, 대시보드 장면에서는 창들이 서로 겹쳐 화면 가장자리까지 넘쳐요.
- 혼란이 꽉 찬 순간 세로 빛 틈이 화면을 가르고, 그 뒤엔 검은 화면 한가운데 작은 글 한 줄만 남아요. 마지막 여백이 아주 넓을수록 앞의 혼란이 살아요.

## 색
- 검정 #0E0E0F 75 · 어두운 카드·창 #1E1F21 15 · 흰 글자 7 · 불꽃 주황·노랑 3.
- 카드 제목은 흰색 #ECECEA, 둘째 줄은 흰색 50%.
- 주황 #F26A1F 과 노랑 #F5C542 는 불꽃 그래프와 경고 표시에만 써요. 문제가 터졌다는 신호라서 앞쪽 조용한 장면에는 나오지 않아요.
- 빛 틈은 흰 심지에 하늘빛 #9CC8FF 번짐. 영상 전체에서 단 한 번.
- 앱 아이콘 색(청록·보라·빨강)은 작은 네모 안에만, 한 번에 한 색.

## 글자
- Geist + Noto Sans KR Medium. 작고 가볍게. 엔딩 문장도 화면 높이의 3% 안팎이에요.
- 알림 카드: 제목 500, 둘째 줄 400 에 옅게. 카드 너비는 화면의 18~22%.
- 터미널 창과 표 안의 글은 Geist Mono, 아주 작게(읽히기보다 결로 보이게).
- 엔딩 문장은 가운데 정렬 한 줄. 아직 안 밝아진 어절은 흰색 25%, 밝아진 어절은 흰색 100%.

## 질감과 모양
- 그레인 0.05, 비네트 0.28. 빛 틈 장면에서 그레인이 가장 잘 보여요.
- 카드: 흰색 6~8% 반투명 + 블러 + 1px 흰 테두리(12%), 모서리 1.2u, 아래로 깊은 그림자 하나.
- 창: 위 막대와 빨강·노랑·초록 점 셋, 짙은 회색 몸통. 겹칠 때 뒤 창은 70% 정도로 어둡게.
- 빛나는 버튼: 흰 알약에 넓고 부드러운 흰 빛 번짐(glow). 눌린 뒤엔 번짐이 꺼진 회색 알약.

## 움직임
- 96BPM. 알림은 한 박(약 0.6초)마다 하나씩, 대시보드 장면에서는 반 박으로 빨라져 쌓임이 몰아쳐요.
- 카드는 아래에서 1u 올라오며 0.3초 만에 나타나요(power3.out). 크게 튀지 않아요.
- 화면 전체가 아주 천천히(10초에 3%쯤) 다가가서 쌓일수록 숨이 막히게 느껴져요.
- 엔딩 문장은 어절마다 0.4초 간격으로 회색에서 흰색으로 밝아지고, 다 밝아진 뒤 2박 머물러요.

## 전환
- 조용한 장면 사이는 느린 페이드(fade). 대시보드 창이 쌓일 땐 컷(cut).
- 혼란에서 엔딩으로 넘어갈 땐 세로 빛 틈: 가운데 세로 빛줄기가 번쩍 넓어졌다 좁아지며 화면을 하얗게 지운 뒤 검은 화면으로 가라앉아요. 장면 쌓기에선 blur 와 deco streaks 로 비슷한 결을 내요.
- 장면 쌓기: fade → cut → blur.

## 대표 장면
1. **빛나는 버튼 누르기**
   ```
   // 뒤에 흐린 코드(Geist Mono, 흰색 12%, blur 2px), 가운데 흰 알약 버튼
   const k = M.prog(t, 1.9, .15);                    // 커서가 누르는 순간
   M.place(btn, cx, cy, {s: 1 - Math.sin(k * Math.PI) * .04});
   btn.style.boxShadow = `0 0 ${M.anim([[0, 6], [2.0, 0, {d: .4}]], t)}u var(--glow)`;
   btn.textContent = t < 2.2 ? '배포' : '배포 중…';   // 눌린 뒤 회색 알약으로
   // 커서는 M.Cursor 로 오른쪽 아래에서 버튼까지, M.cursorAt 로 클릭
   ```
2. **아이콘 둘레로 알림이 붙음**
   - 가운데 작은 앱 아이콘의 색을 `M.at([[t0,'#3FD0E0'],[t0+M.beat(1),'#9B5CF0'],[t0+M.beat(2),'#E03A3A']], t)` 로 박마다 바꿔요.
   - 카드 i 는 미리 정한 빈자리(위·오른쪽 아래·왼쪽…)에 `M.place(card, x_i, y_i + (1 - e) * u, {o: e})`, `e = M.ease.outCubic(M.prog(t, t0 + M.beat(i), .3))`. 네 장째부터 가장 오래된 카드는 `o: .5` 로 물러나요.
3. **대시보드 더미로 번짐**
   - 카드 뒤로 창 5~6개(불꽃 그래프·표·터미널·대화창)를 반 박마다 컷으로 하나씩 얹고, 위치는 화면 밖으로 반쯤 잘리게.
   - 불꽃 그래프는 세로 막대 수십 개를 `M.rng(시드)` 높이로 두고 아래 진빨강 → 주황 → 노랑 그라디언트, 높이를 `sin(t*6 + i)` 로 조금씩 일렁여요.
   - 전체 묶음은 `M.place(stack, cx, cy, {s: 1 + (t - t0) * .003})` 로 아주 천천히 다가가요.
4. **빛 틈과 엔딩 한 줄**
   ```
   // 세로 빛줄기: 너비 w 가 번쩍 넓어졌다 좁아짐
   const w = M.anim([[tB, 0], [tB + .25, W * .06, {e: 'outCubic'}], [tB + .9, 0, {e: 'inCubic'}]], t);
   beam.style.cssText = `width:${w}px; box-shadow:0 0 ${w * 3}px var(--glow)`;
   // 이어서 S.tr.blur 로 검은 장면, 어절마다 회색 → 흰색
   S.words(line).forEach((wd, i) => wd.style.opacity = .25 + .75 * M.prog(t, tE + i * .4, .4));
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발·운영 도구 소개, 모니터링·장애 대응 서비스, 문제 상황을 먼저 보여 주고 해결을 말하는 제품 영상, 어두운 분위기의 B2B 런칭.
- 피할 것: 밝은 바탕, 큰 굵은 제목, 강조색을 넓게 칠하기(불꽃 그래프와 경고에만), 통통 튀는 등장, 손그림 선.
- 알림 문구는 짧게(제목 1~3어절, 둘째 줄 한 줄). 영상 안의 실제 서비스 이름이나 문구는 쓰지 않고, 우리 상황에 맞는 말로 새로 지어요.
