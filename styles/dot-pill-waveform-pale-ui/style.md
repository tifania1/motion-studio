# 점과 알약 파형 (제품 UI)

한 줄: 옅은 회색 위에서 검은 점 하나가 어절 사이를 뛰어다니며 문장을 이끌어요. 점이 갈라져 소리 물결이 되고, 그 물결은 검은 알약 안의 막대 파형으로 접혔다가 하늘빛이 번지는 흰 앱 창으로 펼쳐지는 조용한 음성 UI.

## 보는 느낌
- 바탕은 거의 흰 옅은 회색 한 장이에요. 무늬도 질감도 없이 비워 두고, 한가운데 요소 하나만 둬요.
- 주인공은 검은 점 하나예요. 문장 앞이나 뒤에 붙어 커서 노릇을 하다가, 갈라져 선이 되고, 알약이 되고, 마지막엔 다시 점으로 돌아와요. 영상 전체가 이 점 하나가 모양을 바꿔 가는 이야기처럼 이어져요.
- 문장은 짧게, 한 화면에 서너 어절. 어절이 기준선이 엇갈린 채 붙었다가 한 줄로 맞춰져요.
- UI 장면에서는 흰 앱 창 한 장이 화면 가운데 놓이고, 그 아래 검은 알약 자막 한 줄이 기능을 짧게 말해 줘요. 창은 가끔 살짝 뒤로 눕혀(사다리꼴) 깊이를 줘요.
- 쉼표 같은 장면 두 개: 점 속에 비친 하늘 사진이 원형으로 열려 화면을 덮는 장면, 가운데 한 줄 둘레로 둥근 타일이 반원으로 도는 장면.

## 색
- 회색 바탕 80 · 검정(점·알약·글자) 15 · 파랑 5.
- 바탕 #ECECEC, 글자와 점·알약 #111111.
- 파랑 #2F6FDB 는 문장 속 한 어절에만. 버튼처럼 칠할 땐 글자를 흰색으로.
- 앱 창은 흰색 #FFFFFF, 가장자리에 하늘빛 #A9C8F2 이 아주 흐리게 번져요(그림자 대신).
- 하늘 사진은 원 안이나 전환 장면에서만 잠깐 써요.

## 글자
- 둥글고 반듯한 산세리프(Geist, 한글은 Noto Sans KR Medium·Bold). 제목 굵기 600, 자간 −0.03em 으로 살짝 조여요.
- 문장 크기는 짧은 변의 7~9%. 마무리 이름은 그보다 두 배 가까이 크게, 굵기 700.
- 알약 자막은 흰 글자 500, 짧은 변의 2.6% 안팎. 알약 높이는 글자의 2.2배, 양옆 여백은 넉넉하게.
- 가운데 정렬. 줄은 늘 한 줄.

## 질감과 모양
- 질감은 없어요. 매끈한 평면 그대로.
- 점은 글자 x높이만 한 꽉 찬 검은 원. 알약은 완전히 둥근 끝.
- 앱 창은 모서리 1.4u, 얇은 회색 테두리, 바깥으로 하늘빛 빛 번짐 한 겹(`box-shadow: 0 0 4u var(--glow)`).
- 앱 타일은 흰 둥근 사각, 아주 옅은 그림자 하나.

## 움직임
- 100BPM, 박마다 변화 하나. 서두르지 않지만 머뭇거리지도 않아요.
- 들어올 땐 `power3.out` 으로 쓱 와서 부드럽게 멈춰요. 점이 옆으로 뛸 땐 작은 포물선(위로 1u)을 그리며 0.25초.
- 어절은 위나 아래로 0.6~1em 어긋난 자리에서 톡 나타나 0.3초 만에 기준선으로 내려앉아요.
- 막대 파형은 막대마다 다른 위상으로 높이가 출렁여요(0.4초 주기 안팎). 소리가 끝나면 막대가 점 크기로 줄어들어요.
- 한 장면에 2~3초 머물러요. 나갈 땐 서서히 옅어지거나, 다음 모양으로 바로 변해서 이어져요.

## 전환
- 서서히 사라짐(fade)이 기본. 점 속 하늘이 원형으로 열리는 순간에만 iris.
- 모양이 이어지는 곳(점 → 선 → 알약 → 창)은 전환 없이 한 요소가 변신하며 넘어가요.
- 장면 쌓기: fade → iris → cut → fade.

## 대표 장면

1. 점이 끌고 가는 문장
   ```
   const dot = S.$('.dot'), words = S.$$('.word');
   S.ambient(t => {
     words.forEach((w, i) => {
       const t0 = M.beat(i);                          // 박마다 한 어절
       const k = M.spring(t - t0, 'smooth');
       const off = (i % 2 ? -0.7 : 0.6) * (1 - k);    // 엇갈린 기준선에서 내려앉음
       M.place(w, w.x0, w.y0 + off * w.h, { o: t > t0 ? 1 : 0 });
     });
     const i = M.at(words.map((_, k) => [M.beat(k), k]), t);
     const hop = M.prog(t, M.beat(i), .25);
     M.place(dot, words[i].right + S.u, cy - Math.sin(hop * Math.PI) * S.u);
   });
   // 강조 어절 하나만 color: var(--accent)
   ```
2. 점 → 물결 선 → 알약 파형
   ```
   // 점 둘이 양끝으로 벌어지고, 사이 SVG path 3가닥이 사인 물결로 떨림
   const a = M.anim([[0, 0], [.2, W * .28, { d: .6, e: 'outCubic' }]], t);
   M.place(dotL, cx - a, cy); M.place(dotR, cx + a, cy);
   lines.forEach((p, j) => p.setAttribute('d', M.wave(cx - a, cx + a, cy, amp * Math.sin(t * 6 + j), 3)));
   // 다음 박에 선이 가운데로 모이며 검은 알약으로 M.box, 안에 흰 막대 5개
   bars.forEach((b, j) => M.box(b, { h: barH * (.4 + .6 * Math.abs(Math.sin(t * 7.8 + j * 1.3))) }));
   ```
3. 알약이 번져 앱 창으로
   - 알약 왼쪽에 작은 아이콘을 `M.spring(t - t1, 'pop')` 으로 붙이고, 한 박 뒤 알약을 `M.box` 로 창 크기까지 늘리며 검정 → 흰색(`M.color('#111', '#fff', k)`). 창 안 글은 `M.type(text, t, t2, 30)`, 가장자리 하늘빛은 k 에 맞춰 차오름.
   - 창 아래 검은 알약 자막을 아래에서 1u 올라오며 `o` 0 → 1. 장면 쌓기에서는 frame: window + card: shadow 가 이 결을 맡아요.
4. 타일 고리와 하늘빛 고리 마무리
   - 둥근 타일 12개를 반지름 R 원 위에 두고 `angle = base + t * .12` 로 천천히 돌려, 아래쪽 반은 화면 밖으로 잘리게. 가운데 한 줄 문장 끝에 검은 점.
   - 이어 `S.tr.iris` 를 거꾸로 쓰듯, 흐린 하늘빛 고리(`border` 굵게 + `blur(2u)`)를 화면보다 크게 두고 `M.anim` 으로 0.9초 만에 점 크기까지 오므려 검은 점으로 맺어요. 장면 쌓기 deco rings·orb 가 고리와 숨 쉬는 구슬을 깔아 줘요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 음성 입력·받아쓰기 도구, AI 비서·자동 답장 기능, 여러 앱과 이어지는 연동 소개, 조용한 제품 런칭, 기능 하나를 차분히 보여 줄 때.
- 피할 것: 어두운 바탕, 강조색 여러 개(파랑 하나만), 빠른 컷 연속, 질감·그레인, 손그림 선, 한 화면에 긴 문장.
- 점 하나가 끝까지 이어지는 게 이 결의 핵심이라, 점이 여러 개 동시에 흩어지는 연출은 갈라짐 장면 하나로만 아껴요.
