# 청록 안개 알약 변신 (제품 UI)

한 줄: 짙은 청록 안개 속에 비스듬한 폰 화면 벽이 흐르고, 카메라가 알약 입력창에 다가가면 그 알약이 파형, 진행 문구, 민트 덩어리, 물결 테두리 꽃 모양으로 차례차례 몸을 바꾸는 어두운 OS 소개.

## 보는 느낌
- 바탕은 거의 검은 청록. 화면 한쪽(주로 위나 가운데 뒤)에 짙은 청록 안개가 흐릿하게 번져 있고, 네 귀퉁이는 비네트로 더 어두워요.
- 오프닝은 폰 화면 여러 대를 벽처럼 기울여 늘어놓고 천천히 훑어요. 화면 속도 같은 청록 결이라 벽 전체가 한 덩어리로 보여요.
- 그다음부터는 한 장면에 주인공 하나만. 폰 아래쪽 알약, 폰 윗부분 알림 카드, 손목시계, 화면 가운데 큰 알약 순서로 카메라가 하나씩 다가가요.
- 주인공 둘레는 늘 흐려요. 가까이 있는 것만 선명하고 나머지는 안개 속으로 녹아요.
- 끝은 아무것도 없는 어둠 가운데 작은 마크와 이름 한 줄.

## 색
- 바탕 어둠 #0D1413 65 · 청록 안개·유리 #173A35~#2C5C55 25 · 글자 #E3ECE9 7 · 민트 #4ACBB0 3.
- 민트는 '지금 듣는 중·지금 일하는 중'을 알리는 데에만 써요. 마이크 원, 파형, 알약 아래 빛 띠, 변신하는 덩어리.
- 유리 카드·알약 몸통은 #1A3530 에 흰빛 8~12% 를 얹고, 테두리는 위쪽만 밝은 1px 선(흰색 25%).
- 진행 문구처럼 덜 중요한 글은 옅은 청회색 #8FB1A9.

## 글자
- 둥근 기하 산세리프 400(Geist + Noto Sans KR Medium). 굵은 제목은 쓰지 않아요.
- 알약 안 글: 알약 높이의 30% 안팎, 옅은 흰색. 진행 문구: 화면 높이 4%, 청회색, 가운데 정렬 한 줄.
- 큰 글자는 잠금화면 시계 숫자처럼 아주 가는 굵기(200~300)로만 크게 써요.
- 퍼센트 숫자는 문구보다 조금 밝은 흰색, 같은 굵기.

## 질감과 모양
- 그레인 0.06(초당 12번), 비네트 0.42. 어둠이 살짝 거칠고 가장자리가 가라앉아 보여요.
- 알약 몸통 왼쪽 아래에 아주 고운 망점 결을 국소로 깔아 유리가 두툼해 보이게 해요(전체 질감으로는 쓰지 않아요).
- 모서리는 전부 둥글게. 알약은 완전한 반원 끝, 카드는 `--u` × 2.4.
- 빛은 민트 요소 둘레에만 한 겹. 덩어리·마이크 원 아래로 `box-shadow: 0 0 6u var(--glow)`.

## 움직임
- 84BPM, 느림. 대부분 `power3.inOut` 으로 천천히 시작해 천천히 멈춰요.
- 카메라는 늘 조금씩 움직여요. 4~5초 동안 짧은 변의 5~8% 만큼 다가가거나 옆으로 흘러요.
- 모양 변신은 끊김 없이 이어져요. 알약 → 파형 → 진행 문구 → 덩어리 → 꽃 모양이 한 몸처럼 1~1.5초씩 걸려 바뀌어요.
- 한 상태에 2~3초 머물고, 머무는 동안에도 민트 빛과 덩어리 테두리는 숨 쉬듯 일렁여요.

## 전환
- 흐림(blur)이 기본. 앞 장면이 안개처럼 번지며 다음 장면이 흐림에서 맺혀요.
- 마크 엔딩 앞은 어둠으로 서서히(fade). 장면 쌓기: blur → fade.

## 대표 장면

1. 기운 폰 화면 벽
   ```
   // 폰 6~8대를 격자로 놓고 부모를 기울여 천천히 흘림
   wall.style.transform = 'rotate(-12deg)';
   S.ambient(t => {
     M.place(wall, cx + M.anim([[0, 0], [0, -W * .06, {d: 4, e: 'inOutCubic'}]], t), cy - t * H * .01);
   });
   phones.forEach((p, i) => M.place(p, ..., {o: M.spring(t - i * .08, 'smooth')}));
   ```
2. 폰 윗부분 유리 네모가 알림 카드로
   - 폰 윗부분에 바짝 붙고, 작은 유리 네모(1.5u 둥근)를 `M.box(card, {x, y, w, h})` 로 카드 크기까지 1.2초에 넓혀요(`inOutCubic`). 다 넓어지면 아이콘·두 줄 글·진행 막대·버튼 둘을 0.1초 간격으로 흐림에서 맺히게 하고, 진행 막대는 `M.draw` 로 천천히 차요.
3. 큰 알약의 변신
   ```
   // 알약 하나를 상태 사이로 이어 바꿈
   const k1 = M.ease.inOutCubic(M.prog(t, 1.0, .6));   // 마이크 원 민트로 차오름
   mic.style.background = M.color('#2C5C55', '#4ACBB0', k1);
   const k2 = M.prog(t, 2.0, .5);                       // 글 → 파형 막대
   bars.forEach((b, i) => b.style.height = (k2 * (.3 + .7 * Math.abs(Math.sin(t * 6 + i)))) * barH + 'px');
   label.textContent = t < 3.2 ? '' : M.type('자동으로 처리하는 중…', t, 3.2, 20);
   M.box(pill, {w: M.anim([[0, pillW], [4.6, pillW * .32, {d: 1.1, e: 'inOutCubic'}]], t), h: pillH});
   ```
   - 알약 아래 가장자리에 민트 그라디언트 띠를 깔고, 파형 단계부터 투명도를 0.3 → 0.8 로 올려요.
4. 민트 덩어리가 꽃 모양으로 + 퍼센트
   ```
   // 반지름이 각도마다 물결치는 닫힌 path. a 가 0 이면 둥근 덩어리, 커지면 꽃 테두리
   S.ambient(t => {
     const a = .09 * M.ease.inOutCubic(M.prog(t, .4, 1.2));
     const pts = [...Array(120)].map((_, i) => {
       const th = i / 120 * Math.PI * 2, r = R * (1 + a * Math.sin(10 * th + t * .8));
       return [cx + r * Math.cos(th), cy + r * Math.sin(th)];
     });
     blob.setAttribute('d', 'M' + pts.join('L') + 'Z');
     pct.textContent = Math.round(M.anim([[0, 48], [.4, 63, {d: 2.4, e: 'outCubic'}]], t)) + '% 완료';
   });
   ```
   - 위 문구 '만드는 중…'은 청회색으로 흐림에서 맺히고, 장면 쌓기에서는 title: blur + number: count 가 같은 결을 내요. 장면 사이는 `S.tr.blur`.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 비서·음성 입력 기능 소개, 모바일 OS·기기 기능 런칭, 백그라운드 자동 처리 안내, 위젯·개인화 기능 소개, 밤 분위기의 차분한 제품 티저.
- 피할 것: 밝은 흰 바탕, 빠른 컷과 몰아치는 리듬, 굵고 큰 제목, 강조색 여러 개(민트 하나만), 딱딱한 각진 모서리.
- 한 장면에 한 가지 상태만 보여 주고, 변신은 끊지 말고 이어서 보여 줘야 이 결이 살아요.
