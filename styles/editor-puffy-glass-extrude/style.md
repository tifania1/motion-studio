# 편집기 속 말랑 입체 (3D·사물)

한 줄: 옅은 회색 디자인 편집기 화면에서 선택 상자에 잡힌 납작한 글자와 도형이 효과 하나를 누르는 순간 말랑한 점토나 맑은 유리 입체로 부풀어요. 유리는 뒤 글자를 휘게 비추고, 커서가 지나가면 입체 글자가 하나씩 고개를 들어요.

## 보는 느낌
- 화면 전체가 편집기예요. 왼쪽에 레이어 목록, 오른쪽에 속성 패널, 위 가운데에 작은 도구 막대가 떠 있고, 가운데 넓은 회색 캔버스 위에 흰 대지 하나가 놓여요.
- 주인공은 대지 속 물건 하나예요. 앱 아이콘, 짧은 영문 낱말, 한글 두 글자, 지도 핀, 별·꽃 도형처럼 단순한 모양이 반들하고 통통한 입체가 돼요.
- 대지 바탕은 장면마다 달라요. 흰색, 하늘 사진, 원색 포스터(하늘색·연어색·청록·살구), 연보라, 숯빛 하나쯤. 편집기 틀은 늘 밝은 회색으로 같아요.
- 카메라는 편집기 전체를 보여 주다가 대지로 슬쩍 다가가고, 효과 패널을 열 때만 패널 쪽으로 옮겨 가요.

## 색
- 편집기 회색 #E6E6E8 55 · 흰 대지와 패널 25 · 입체의 색 15 · 선택 파랑 5.
- 선택 상자·핸들·켜진 토글은 파랑 #3F5BE0 하나만 써요. 위에 글자가 오면 흰색.
- 입체 색은 한 장면에 한 계열로 정해요. 주황 #F2742B(노랑에서 붉은 주황으로 번짐), 연보라 #B07CF0(분홍에서 보라로), 연어 #E98C86(옆면은 더 짙은 붉은색), 유리는 거의 투명한 흰빛에 푸른 기.
- 원색 포스터 장면에서는 바탕과 입체 옆면을 같은 계열로, 앞면만 밝게 두어 두께가 또렷해 보이게 해요.

## 글자
- 편집기 글씨(레이어 이름, 속성 값)는 Geist·Noto Sans KR 500, 아주 작게(짧은 변의 1.6~2%), 옅은 회색.
- 입체가 되는 글자는 Archivo 800~900(한글은 Noto Sans KR Black). 자간 −0.03em 으로 붙여 덩어리처럼 보이게, 짧은 변의 20~35%.
- 대지 속 설명 문장은 Geist 400 이나 Instrument Serif 400 으로 입체 아래 작게 한두 줄. 세리프는 차분한 장면(유리 도형 뒤 낱말, 도형 이름표)에만.
- 가운데 정렬. 한 대지에 큰 글은 한 낱말.

## 질감과 모양
- 화면은 매끈하게 둬요. 질감 레이어는 쓰지 않고, 입체 안의 빛과 그림자로만 깊이를 만들어요.
- 입체: 앞면은 밝은 그라디언트, 옆면은 같은 색을 30~40% 어둡게, 모서리는 둥글게 부푼 느낌. 위쪽 가장자리에 흰 반사 줄 하나, 바닥에 부드러운 그림자 한 겹.
- 유리: 흰색 10~20% + 뒤 흐림 + 1px 흰 테두리, 뒤 글자는 휘어 확대되고 가장자리에 아주 얇은 무지개 번짐.
- 패널·대지·버튼 모서리는 `--u` × 1.2, 아이콘 대지는 더 둥글게.
- 선택 상자는 1px 파랑 선과 네 귀퉁이 작은 흰 네모 핸들.

## 움직임
- 96BPM, 보통 빠르기. 한 대지를 3~5초 보여 주고 다음으로 넘어가요.
- 부풀기: `back.out(1.7)` 으로 0.6초. 두께가 먼저 뒤로 밀려 나오고, 겉면 반사가 왼쪽 위에서 오른쪽 아래로 한 번 훑고, 크기가 살짝 넘쳤다 돌아와요.
- 다 부푼 입체는 가만있지 않고 6초 주기로 ±8도쯤 천천히 좌우로 돌아요. 유리 도형은 더 느리게 돌며 떠다녀요.
- 커서는 부드럽게 미끄러져 와서 누를 때 살짝 작아졌다 돌아와요. 슬라이더를 끌면 입체의 두께·굴절이 같이 바뀌어요.
- 글자가 처음 나타날 땐 글자마다 톡톡 튀어 올라요(장면 쌓기 title: pop).

## 전환
- 대지에서 대지로는 컷이 기본. 같은 편집기 안에서 옆 대지로 옮길 땐 캔버스째 옆으로 밀어내기(push).
- 숯빛 대지로 들어가거나 엔딩 타일 벽으로 갈 때만 느린 페이드. 장면 쌓기: cut → push → fade.

## 대표 장면
1. **효과를 누르면 부푸는 아이콘**: 대지 가운데 평면 도형, 둘레에 선택 상자(deco handles). `M.Cursor` 로 오른쪽 효과 목록 칸을 누르면(`M.cursorAt`) 그 시각 `t0` 부터 부풀어요.
   ```
   const k = M.spring(t - t0, 'bouncy');          // 0 → 1, 살짝 넘침
   const depth = 14;                              // 두께 장 수
   layers.forEach((L, i) => M.place(L, cx, cy, {   // 같은 도형을 겹겹이 쌓아 옆면을 만듦
     x: i * .5 * k, y: i * .5 * k, o: i ? k : 1
   }));
   M.place(front, cx, cy, {s: 1 + (1 - k) * .0 + Math.sin(Math.min(1, t - t0) * Math.PI) * .06});
   sheen.style.backgroundPosition = `${M.anim([[t0, -40], [t0 + .1, 140, {d: .5, e: 'outCubic'}]], t)}% 0`;
   ```
   부푼 뒤에는 `S.ambient(t => M.place(group, cx, cy, {ry: Math.sin(t * Math.PI / 3) * 8}))` 로 천천히 돌려요.
2. **문장 위를 지나는 유리 도형**: 대지에 큰 영문·한글 문장을 두고, 그 위에 둥근 별꽃 모양 유리를 띄워요. 유리 안에는 같은 문장을 복사해 `scale(1.15)` 와 SVG `feDisplacementMap` 으로 휘게 하고, `clip-path` 를 유리 모양으로. `M.drift` 로 유리를 문장 위에서 천천히 돌리며 옮기면 지나간 글자만 휘어 보여요. 가장자리엔 빨강·파랑 그림자를 1px 씩 어긋나게.
3. **원색 포스터의 두꺼운 한글**: 하늘색이나 연어색 대지에 한글 두 글자를 Noto Sans KR Black 으로 크게. `S.chars(el)` 로 글자를 나누고 글자마다 `text-shadow` 를 1px 씩 12겹 쌓아 옆면을 만들어요. 두께 `n = Math.round(12 * M.spring(t - ti, 'smooth'))` 를 글자마다 0.1초씩 늦게 키우면 왼쪽부터 차례로 솟아요. 옆 대지로는 `S.tr.push` 로 넘겨요.
4. **커서를 따라 고개 드는 글자 → 타일 벽**: 입체 낱말 위로 `M.Cursor` 가 지나갈 때 글자 i 의 커서와의 거리 `d` 로 `lift = Math.max(0, 1 - d / (W * .15))`, `M.place(ch, x, y, {y: -lift * 2u, rx: lift * 12, ry: (cursorX - x) / W * 30})`. 마지막엔 그동안의 대지들을 `M.box` 로 크기가 다른 타일 격자에 끼워 넣고, 카메라를 1.6배에서 1배로 빼며 벽 전체를 보여 줘요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인·3D 도구 소개, 기능 업데이트 하이라이트, 앱 아이콘·브랜드 굿즈 공개, 젊고 말랑한 브랜드 런칭, 포스터·SNS 시안 모음.
- 피할 것: 필름 그레인·종이 같은 거친 질감, 어두운 바탕만 계속 쓰기, 날카로운 각진 금속 재질, 한 화면에 입체 여러 개를 동시에 부풀리기, 편집기 틀 없이 입체만 보여 주기(편집기 안에서 만들어지는 과정이 이 결의 맛이에요).
- 한글은 받침 적은 두 글자 낱말이 두께를 받았을 때 가장 덩어리지게 보여요.
