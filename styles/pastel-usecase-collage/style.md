# 파스텔 쓰임새 콜라주 (그래픽·도형)

한 줄: 쓰임새 하나에 파스텔 색 한 벌. 가운데 짙은 말풍선 하나를 두고 UI 카드와 거친 질감 사각형이 둘레에 겹겹이 쌓여요.

## 보는 느낌
- 쓰임새(영업팀, 마케팅팀, 개발팀처럼)마다 화면 전체 색이 바뀌어서 지금 무슨 이야기인지 색으로 먼저 알 수 있어요.
- 가운데 말풍선이 "이 일을 맡겨요" 한 문장을 말하고, 둘레 카드들이 그 일의 결과(표, 문서, 알림)를 보여 줘요.
- 카드·사각형이 앞뒤로 겹쳐 종이 콜라주 같은 깊이가 있지만, 전체는 깔끔한 UI 화면.

## 색
- 바탕 65 · 흰 카드 20 · 짙은 말풍선 10 · 진한 사각형 5.
- 색 한 벌(바탕 / 말풍선 / 사각형):
  - 민트: #D7E8DE / #184824 / #30CC6C
  - 살구: #E7DDD4 / #48240C / #E07A2E
  - 라벤더: #E0DCEA / #302454 / #8454D8
- style.json 의 colors 는 민트 한 벌이에요. 장면마다 다른 벌로 바꾸고 싶으면 장면 바탕색만 직접 바꿔 주세요.
- 카드는 흰색(#F4F4F2), 카드 속 글자는 먹색.

## 글자
- 반듯한 고딕(Geist + Noto Sans KR 500/700).
- 말풍선 글자가 주인공: 짧은 변의 3.4%, 두 줄, 흰색. 카드 속 글자는 작게(1.6~2%) 두어 분위기만 전해요.
- 장면 사이 문장 한 줄("○○를 팀 메신저로")은 회색 바탕에 가운데 5% 크기, 마지막 낱말만 옅은 회색.

## 질감과 모양
- 사각형에만 질감: 같은 색 그라디언트 위에 노이즈. 화면 전체 그레인은 아주 약하게(0.04)만.
- 사각형 질감 만들기: SVG feTurbulence(baseFrequency .9, numOctaves 2) 를 사각형 안에 mix-blend-mode: overlay, 투명도 .35.
- 말풍선 모서리 2.4u, 카드 모서리 1.2u, 카드 그림자 0 1.5u 4u rgba(0,0,0,.10). 사각형은 모서리 없음.
- 작은 마스코트 얼굴(둥근 도형 + 눈 두 점) 같은 귀여운 표시가 카드 사이에 하나쯤 있으면 좋아요(브랜드 마스코트로 바꿔 씀).

## 움직임
- 112BPM. 들어오는 건 빠르게(0.3초 안), 머무는 동안은 느리게 흐름.
- 들어올 때: 말풍선 → 카드들 0.12초 간격 → 사각형들. 모두 M.spring 'snappy', 넘침 거의 없음.
- 머무는 동안: 깊이별로 다른 속도로 위 또는 옆으로 흐름(앞 0.8u/초, 중간 0.4u/초, 뒤 0.2u/초). M.drift 를 깊이마다 a 값을 달리해 걸어도 돼요.
- 마스코트 표시는 S.fx.bob 으로 살짝 까딱.

## 전환
- 쓰임새 사이: 컷(바탕색이 확 바뀌는 게 이 스타일의 맛).
- 쓰임새 묶음이 끝나고 채팅·문장 장면으로 갈 때만 0.3초 페이드.

## 대표 장면

1. 쓰임새 콜라주 (장면당 2.5~3초)
   ```
   bubble: M.place(b, cx, cy + (1 - M.spring(t - t0, 'snappy')) * 3 * u, { o: M.prog(t, t0, .12) });
   cards.forEach((c, i) => {
     const k = M.spring(t - (t0 + .15 + i * .12), 'snappy');
     M.place(c, c.x, c.y - drift(c.depth, t), { s: .92 + .08 * k, o: M.prog(t, t0 + .15 + i * .12, .1) });
   });
   // drift(depth, t) = (t - t0) * [0.8, 0.4, 0.2][depth] * u
   ```
2. 쓰임새 세 개 이어 보기
   - 민트 → 살구 → 라벤더 순으로 컷. 장면이 바뀌면 바탕·말풍선·사각형 색이 함께 바뀌고, 카드 구성만 달라져요.
   - 마지막에 처음 색(민트)으로 한 번 더 돌아오면 묶음이 닫히는 느낌.
3. 알림 묶음
   ```
   q: 위에서 M.place(q, cx, cy + (1 - M.spring(t - t1, 'snappy')) * -6 * u)
   a: t1 + .4 에 같은 자리로 내려오며 덮음.
   q 는 그때부터 M.anim([[t1+.4, [1, 0]], [t1+.45, [.94, 1.2*u], 'snappy']], t) 로 줄며 아래로 비침
   ```
   - 쓰임새마다 바탕 색을 바꿔 가며 2~3번 반복(질문 알림 색도 그 벌의 짙은 색).
4. 문장 줄이기
   - "○○를 □□로 데려와요" 를 어절 단위로 세우고, 1박 쉬었다가 뒤에서부터 0.12초 간격으로 지워 첫 낱말과 마지막 낱말만 남기기.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 협업·업무 도구의 쓰임새 소개, 팀별·부서별 기능, 사례 세 가지를 한 영상에, B2B SaaS 광고.
- 피할 것: 채도 높은 바탕, 어두운 바탕, 손그림 선, 큰 글자만 이어지는 장면. 한 장면에 카드 다섯 장을 넘기지 않기.
