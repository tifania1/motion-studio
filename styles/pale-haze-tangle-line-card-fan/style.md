# 엉킨 선 정리 런칭 (제품 UI)

한 줄: 옅은 회색 가장자리에 분홍 안개가 번지고, 굵은 검정 선이 고리를 지으며 엉키다 자두빛 판에서 문제를 말해요. 남보라 굵은 낱말 하나로 정리된 뒤 자홍·주황·파랑 그라디언트 판을 지나, 끝에는 비스듬히 누운 UI 판들이 가운데 문장 둘레로 부채처럼 돌아요.

## 보는 느낌
- 바탕은 아주 옅은 회색. 화면 아래 귀퉁이에 분홍·붉은 안개가, 위쪽 가장자리엔 라벤더·하늘빛 안개가 옅게 번져요. 가운데는 늘 비워 두고 굵은 고딕 한 줄만 놓아요.
- 이야기가 두 갈래로 흘러요. 앞부분은 문제 쪽이라 검정 글자와 굵은 검정 선, 짧게 끼어드는 자두빛 어두운 판. 뒷부분은 해결 쪽이라 남보라 글자, 그라디언트 판, UI 카드.
- 선이 이야기를 끌고 가요. 한 줄로 들어온 선이 고리를 그리며 아이콘 원을 하나씩 꿰다 엉켜 버리고, 그 엉킨 모양이 곧 '흩어진 일'이 돼요.
- UI 는 낱개 카드나 비스듬히 누운 화면 묶음으로만 짧게 보여 주고, 마지막엔 두께 있는 판들이 방사형으로 둘러서요.

## 색
- 옅은 회색 70 · 글자 20 · 강조와 그라디언트 10.
- 바탕 #EEEDF0, 문제 쪽 글자 먹색 #17161C, 해결 쪽 글자 남보라 #3B2E85, 커서와 버튼 #4A3BD1(위 글자는 흰색).
- 어두운 문제 판 #1D1B2B(자두빛이 도는 남색), 위의 선과 글자는 #F2F1F6.
- 그라디언트 판: 왼쪽 위 자홍 #D61BD8 → 오른쪽 위 주황 #F06A3A → 왼쪽 아래 파랑 #3B8BEF, 가운데는 보라로 섞여요. 이 판에서만 색을 넓게 써요.
- 가장자리 안개는 분홍 #E84078 을 20~30%로만.

## 글자
- 기하 고딕 굵게: Geist 700, 한글은 Noto Sans KR Bold. 자간 −0.03em 으로 붙여서 단단하게.
- 큰 제목은 짧은 변의 12~16%, 한 줄에 2~3어절. 두 줄일 땐 위 줄을 작게(60%) 해서 크기 대비를 줘요.
- 타자 문장은 짧은 변의 6% 안팎, 굵기 600, 남보라.
- 작은 꼬리표·카드 글씨는 Geist 500, 회색.
- 모두 가운데 정렬, 줄 간격 1.05.

## 질감과 모양
- 그레인 0.06. 그라디언트 판과 안개에서 결이 살짝 보이는 정도예요.
- 굵은 검정 선은 짧은 변의 1.6% 두께, 끝은 둥글고 맨 끝에 지름 6% 점 하나. 어두운 판의 흰 선은 0.4% 로 가늘게.
- 아이콘 원: 흰 원(지름 8%) 안에 작은 선 아이콘, 아주 옅은 그림자.
- 카드: 흰색, 모서리 1.6u, 부드러운 그림자. 마지막 방사형 판은 은회색 두께가 붙은 입체(rotateY·rotateX 로 기울여 옆면 보이게).

## 움직임
- 110BPM, 장면 하나에 2~2.5초. 들어올 땐 expo.out 으로 빠르게 와서 길게 멈춰요.
- 선은 늘 끝점이 앞장서요. 점이 먼저 움직이고 선이 뒤따라 그려지는 모양(M.draw), 0.6~1초.
- 글자는 어절마다 아래서 0.5u 올라오며 흐림 6px → 0, 혹은 남보라 막대 커서로 초당 18자 타자.
- 지우는 글자는 0.3초 동안 기호로 뒤섞였다가 가로줄이 왼쪽에서 오른쪽으로 그어져요.
- 방사형 판은 8초에 20도쯤 천천히 돌면서 카메라가 조금씩 다가가요.

## 전환
- 컷이 기본이고, 남보라 낱말이 맺히는 장면은 흐림 전환(blur), 로고·마무리 앞은 느린 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **점이 끌고 오는 선, 엉켜서 어두운 판으로**
   ```
   // 고리 여러 개를 품은 path 하나, 아이콘 원 3개를 path 위 지점에 둠
   S.ambient(t => {
     const k = M.ease.outCubic(M.prog(t, .3, 1.0));
     M.draw(line, k);                                   // 선이 뒤따라 그려짐
     const p = line.getPointAtLength(line.getTotalLength() * k);
     M.place(dot, p.x, p.y);                            // 끝점이 앞장섬
     icons.forEach((ic, i) => M.place(ic, ic.x, ic.y, {s: M.spring(t - (.5 + i * .18), 'pop')}));
   });
   // 다 엉키면 컷 → s-paper(자두빛) 장면에서 흰 가는 선 다발 + 가운데 굵은 흰 문장
   ```
2. **뒤섞여 지워지는 낱말**
   - `S.chars(word)` 로 나누고 0.3초 동안 `M.at` 으로 글자마다 `M.rng(시드)` 기호를 0.05초마다 바꿔 끼운 뒤 원래 글자로. 동시에 글자 높이 가운데 가로줄 `M.box(strike, {w})` 를 0 → 낱말 너비로 0.25초. 한 박 뒤 컷으로 남보라 낱말이 `S.tr.blur` 로 맺혀요.
3. **남보라 커서 타자와 고쳐 쓰기**
   - `M.type(text, t, t0, 18)` 로 치고, 커서는 글자 높이만 한 남보라 막대(0.5초 주기 깜빡). 끝 낱말을 `M.type` 역방향으로 지운 뒤 새 낱말을 다시 쳐요. 장면 쌓기에서는 title: type 이 이 결을 맡아요.
4. **그라디언트 판과 방사형 UI 부채**
   - 그라디언트 판: 큰 원 3개(자홍·주황·파랑)를 `blur(12u)` 로 흐려 `M.drift` 로 천천히, 위에 흰 굵은 문장 한 줄.
   - 마무리: 두께 있는 판 12장을 가운데 둘레에 각도 `i * 30°` 로 놓고 부모에 `perspective`. `S.ambient` 안에서 부모 회전 `rot = t * 2.5`, 판마다 `rotateX(55deg)` 로 눕히고 `M.place(fan, cx, cy, {s: 1 + t * .02})` 로 조금씩 다가가요. 가운데엔 먹색 두 줄 문장.

## 어울리는 곳 / 피할 것
- 어울리는 곳: SaaS·업무 도구 새 버전 런칭, 여러 도구를 하나로 묶는 제품 소개, 문제 제시에서 해결로 넘어가는 이야기형 광고, 기능 묶음 훑기. 30~60초 영상.
- 피할 것: 손그림 선과 종이 질감, 세리프 글꼴, 한 장면에 강조색 여러 개(그라디언트 판 말고는 남보라 하나), 긴 문단, 어두운 판을 오래 끌기(문제 장면 한두 컷만).
- 한글은 2~5자 낱말을 크게, 문장은 두 어절 안팎으로 끊으면 이 결이 살아요.
