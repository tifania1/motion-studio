# 찢은 종이 편집 콜라주 (콜라주·사진)

한 줄: 회색 종이 위에 찢긴 색종이와 오림 도형, 흑백 망점 사진이 박마다 툭툭 붙고, 화면을 넘치는 큰 세리프 낱말은 글자가 몇 번 갈아 끼워지다 제 이름으로 멈춰요.

## 보는 느낌
- 잡지 펼침면을 아주 빠르게 넘기는 느낌. 한 화면에 큰 낱말 하나, 오림 조각 3~5개, 아주 작은 본문 단 1~2개, 가는 기준선 2~3줄, 십자 표시 한두 개.
- 큰 낱말은 화면 가장자리에서 잘려도 돼요. 오히려 잘려야 이 결이 나와요.
- 조각은 겹치고 서로 가려요. 반듯하게 줄 세우지 않고, 기준선·여백 칸에는 맞춰요.
- 회색 종이 바탕 장면과 원색(파랑·주황·노랑·연보라) 꽉 찬 장면이 1~2초마다 번갈아 와요.

## 색
- 종이 회색 바탕 40 · 원색 조각 40 · 먹색 글 15 · 흑백 사진 5.
- 원색: 코발트 파랑 #2F64E0, 주황 #E2572B, 겨자 노랑 #E9A928, 연보라 #DDB8EE, 짙은 초록 #2E6B45. 한 화면에 원색은 셋까지.
- 원색 조각에는 아주 옅은 얼룩·긁힘 결이 있어요(인쇄한 종이를 다시 찍은 듯). 사진은 흑백 망점으로만.
- 작은 대문자 꼬리표는 원색 하나로 들어왔다 먹색으로 가라앉아요.

## 글자
- 큰 낱말: 대비 높은 디스플레이 세리프(Instrument Serif, 기울임도 자주). 한글은 Noto Serif KR Black. 짧은 변의 20~35%로 화면을 넘치게.
- 힘 있는 낱말·숫자: 좁고 굵은 그로테스크(Archivo 800~900, stretch 70~80%) 대문자. 한글은 Noto Sans KR Black.
- 작은 꼬리표와 본문 단: Archivo 500, 짧은 변의 1.2~1.6%, 대문자 꼬리표는 자간 +0.04em. 본문 단은 6~10줄 양끝 맞춤.
- 한 화면에 세리프 큰 낱말과 그로테스크 큰 낱말을 같이 두지 않아요. 하나가 주인공.

## 질감과 모양
- 종이: 차가운 회색 종이 결(fiber 0.3) + 그레인 0.14. 원색 판에도 그대로 얹혀요.
- 찢긴 가장자리: 색판 한 변만 찢겨 들쭉날쭉(SVG 경로를 시드 난수로 2~4px 흔든 것). 회색 콘크리트 같은 회색 조각도 한두 장.
- 오림 도형: 오각형, 반원, 활 모양 고리, 가는 선 별표(8~12갈래), 빗금(주황 사선 4~6줄)이 들어간 도형. 모서리는 둥글리지 않아요.
- 표시: 0.5px 기준선 가로줄, 작은 십자(+), 귀퉁이 재단 표시.
- 사진: 흑백 망점(halftone) 처리한 컷아웃. 둥근 틀이나 사각 틀에 넣거나 배경을 지워 오림 조각처럼.

## 움직임
- 124BPM. 박마다 무언가가 붙거나 바뀌어요. 머무는 장면은 2~4박.
- 붙을 때 expo.out 0.15~0.25초, 넘침 없음. 미끄러질 땐 화면 밖에서 짧게 들어와 딱 멈춤.
- 글자 갈아 끼우기는 0.1~0.2초 간격의 계단(부드럽게 섞지 않음). 마지막 글자가 멈추는 순간이 박 위에 오게.
- 머무는 동안 화면 전체를 2~3% 천천히 키우거나 밀어요(멈춘 듯 보이지 않게).
- 3D 맛은 딱 두 가지만: 원근 복도(네 면이 색판인 터널 속 낱말)와 동전 돌듯 납작해지는 타원.

## 전환
- 대부분 하드 컷. 배치와 바탕색이 통째로 바뀌어요.
- 장 구분이 필요할 때 wipe(색 막대 셋) 한 번.
- 마무리는 blocks 나 컷으로 원색 바탕(연보라 → 파랑 → 주황)을 반 박씩 갈아 치우며 로고 글자가 하나씩 모여요.

## 대표 장면

1. 글자 갈아 끼우기
   ```
   // 큰 낱말을 S.chars 로 쪼갬. 글자 i 마다 바뀔 후보 목록과 바뀌는 시각을 시드 난수로 (M.rng)
   const r = M.rng(7);
   chars.forEach((c, i) => {
     const keys = cands[i].map((ch, j) => [t0 + j * (.1 + r() * .1), ch]);   // 0.1~0.2초 계단
     c.textContent = M.at(keys, t);
     const last = keys.findLast(k => k[0] <= t);
     c.style.color = t - (last ? last[0] : 0) < M.beat(1) ? '#E9A928' : 'var(--on-bg)';   // 막 바뀐 글자만 노랑
   });
   band.style.width = word.getBoundingClientRect().width + 'px';   // 연보라 띠는 글자 폭을 따라감 (M.anim 으로 'snappy')
   ```
   - 한글 낱말이면 같은 획 수의 다른 글자들을 후보로(예: '봄' 자리에 '밤·봉·볕'). 마지막 글자만 먹색으로 멈춰요.
   - 장면 쌓기에서는 scenes.title 의 scramble 이 이 결을 따라가요.

2. 박마다 붙는 오림 조각
   ```
   // 조각 목록: [모양, 색, 놓일 자리, 들어오는 방향]. 박 n 마다 하나
   pieces.forEach((p, n) => {
     const k = M.spring(t - M.beat(n), {f: 4, z: 1});
     M.place(p.el, M.lerp(p.fromX, p.x, k), M.lerp(p.fromY, p.y, k), {rot: p.rot, o: k > 0 ? 1 : 0});
   });
   // 화면 전체: cam scale = 1 + .025 * M.prog(t, sceneStart, sceneLen)
   ```
   - 망점 사진은 tools/photo.py 로 받은 사진을 흑백으로 바꾼 뒤 CSS mask 나 tools/cutout.py 로 오려서 써요. 흑백 망점은 S.look 의 halftone 을 쓰지 말고 사진에만 SVG 필터(feColorMatrix 흑백 + 점 패턴 마스크)로.

3. 띄어 있던 글자가 모임 + 동전 타원
   ```
   // 글자 i 의 x 간격을 1.8em → 0 으로: gap = M.lerp(1.8, 0, M.spring(t - t1, 'snappy'))
   // 타원: scaleX = Math.abs(Math.cos(M.prog(t, t2, .5) * Math.PI)); 0 을 지날 때 fill 색을 다음 색으로
   ```

4. 원근 복도 속 낱말
   - 화면 네 귀퉁이에서 가운데 사각으로 모이는 사다리꼴 네 장(위 초록·노랑, 아래 주황·연보라, 왼쪽 먹색, 오른쪽 파랑)을 겹겹이 두 벌. 가운데 흰 사각에 낱말.
   - 바깥 벌은 scale 1.15 → 1, 안쪽 벌은 0.85 → 1 로 반 박 어긋나게 들어오면 앞으로 걸어 들어가는 느낌이 나요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 패션·편집숍·잡지, 전시·페스티벌·공연, 디자인 스튜디오 포트폴리오, 브랜드 리뉴얼, 로컬 문화 공간.
- 피할 것: 부드러운 그라디언트, 유리 질감, 둥근 UI 카드, 느린 페이드, 가운데 정렬 짧은 문장만 되풀이하기. 영상 속 로고와 인물 사진은 쓰지 않고, 조판·조각·색 비율의 원리만 가져와요. 사진은 사용자 사진이나 CC0 를 흑백 망점으로 바꿔 써요.

## 배운 곳
- keyframe.gallery, mux 재생 ID 01Yo1cDQxiqCI4ZVK2jScHhlZjU4c01yW8ZKHlFYMrufo.
- 0.5–3초: 큰 세리프 낱말의 글자가 0.1~0.2초마다 따로 바뀌다 멈춤, 색으로 들어왔다 먹색이 되는 꼬리표, 연보라 띠.
- 3–6초: 반원·고리·별표가 하나씩 붙고 굵은 대문자 낱말에 선택 상자.
- 14–17초: 원근 복도 속 낱말. 17.5–20초: 큰 대문자와 둥근 틀 망점 사진. 20–21초: 고리 모양으로 도는 글자.
- 30–37초: 글자가 모여 낱말이 됨, 동전 돌듯 납작해지는 타원, 숫자 자리가 굴러 바뀜.
- 39–45.5초: 흑백 망점 인물 컷아웃과 큰 한자, 원색 바탕을 갈아 치우며 로고 글자가 모이는 마무리.
