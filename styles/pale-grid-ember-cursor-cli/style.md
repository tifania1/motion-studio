# 옅은 격자 불씨 커서 CLI (제품 UI)

한 줄: 옅은 회색 격자에서 짙은 터미널 창으로 바짝 다가가면 주황 블록 커서가 빛을 머금고 명령을 쳐요. 주황 네모 점이 하나씩 켜져 픽셀 아이콘이 되고, 앱 창 위로 주황 빛 덩어리가 쓸고 지나가며, 이름표 단 커서가 화면을 돌아다니는 개발 도구 소개예요.

## 보는 느낌
- 바탕은 아주 옅은 회색이고, 머리카락처럼 가는 격자선과 모서리 십자 눈금이 겨우 보일 만큼 깔려 있어요. 빈 화면으로 시작해도 설계도 위에 있는 느낌이 나요.
- 장면은 세 가지 결을 오가요. 밝은 회색 위 가운데 문장이나 픽셀 아이콘 하나, 화면을 가득 채운 짙은 터미널 창, 밝은 앱 창 한 대.
- 중간 한 번은 거의 검은 공간으로 넘어가요. 터미널 창을 가운데 두고 둘레에 웹 화면 조각들이 깊이를 달리해 흩어져 떠 있거나, 세로 카드들이 부채처럼 비스듬히 줄지어 서요.
- 여백이 넉넉해요. 문장 장면에는 문장 두 줄 말고 아무것도 두지 않아요.

## 색
- 옅은 회색 70 · 먹색 글자와 짙은 창 22 · 주황 8.
- 바탕 #EDEDED, 글자 #1C1C1C, 터미널·코드 창 #2A2A2A(안 글자 #E8E8E6).
- 주황 #E8541E 는 문장의 첫 낱말, 커서, 픽셀 아이콘, JSON 의 값 글자에만 써요. 픽셀 아이콘은 살구 #F2A27A 에서 주황까지 농담 세 단계로 칠해요.
- 빛 덩어리와 커서 빛무리는 rgba(255,122,40,.45). 마지막 한 장만 아래에서 주황이 화면 절반까지 차올라요.
- 아직 들어오는 중인 낱말은 회색 #8C8C8C 로 흐리게 있다가 먹색으로 맺혀요.

## 글자
- 문장: Geist 600(한글 Noto Sans KR Bold), 자간 −0.02em, 짧은 변의 6% 안팎, 가운데 정렬 두 줄. 첫 낱말만 주황.
- 터미널·꼬리표·코드: Geist Mono. 터미널은 바짝 다가간 상태라 글자가 짧은 변의 10% 넘게 커요. 꼬리표는 짧은 변의 2.5%로 작고 담백하게.
- 제목 장면은 주황 낱말과 먹색 낱말을 한 줄에 나란히(이름 + 종류) 두고, 굵기는 같게 맞춰요.

## 질감과 모양
- 질감은 따로 깔지 않아요. 매끈한 화면에 빛과 흐림만으로 깊이를 내요.
- 앱 창·터미널 창: 모서리 1.2u, 위 막대에 작은 점 셋, 옅고 넓은 그림자 한 겹.
- 커서 블록: 글자 높이만 한 주황 직사각형에 `box-shadow: 0 0 2u var(--glow)` 빛무리.
- 이름표 커서: 검은 화살표 + 짙은 알약(흰 글자, 작은 원 아이콘). 상태 꼬리표: 흰 알약 + 작은 픽셀 아이콘 + 고정폭 글자.

## 움직임
- 100BPM, 보통 속도. 카메라 확대·이동은 `expo.out` 으로 빠르게 다가가 길게 멈추고, 창 안 화면은 천천히 커져요(4초에 6% 정도).
- 픽셀 점은 반 박(0.3초)마다 하나씩 톡, 글자는 초당 18자.
- 문장은 어절마다 흐림 6px → 0, 회색 → 먹색으로 0.4초에 맺혀요.
- 장면 하나는 2~3초 머물러요. 문장 장면은 짧게, 화면 시연은 길게.

## 전환
- 컷이 기본. 앱 창 장면은 흐린 주황 빛 덩어리가 대각선으로 쓸고 가며 흐림 전환(blur)으로 넘기고, 문장과 마무리는 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면

1. 빛나는 커서로 명령 치기
   ```
   const cam = S.$('.term'), line = S.$('.cmd'), cur = S.$('.cur');
   S.ambient(t => {
     const s = M.anim([[3.6, 1], [4.4, 2.6, {d: .8, e: 'outExpo'}]], t);   // 터미널로 바짝
     const x = M.anim([[4.4, 0], [7, -W * .3, {d: 2.6, e: 'inOutSine'}]], t); // 커서 따라 옆으로
     M.place(cam, W / 2 + x, H / 2, {s});
     line.textContent = M.type(cmd, t, 4.4, 18);
     cur.style.opacity = (t * 2 | 0) % 2 ? 1 : .4;   // 반 박 깜빡임, 빛무리는 CSS 로
   });
   ```
2. 네모 점 픽셀 아이콘 + 꼬리표
   ```
   const px = S.$$('.px');                    // 4×4, 칸마다 살구·중간·주황 중 하나
   const order = M.rng(7).shuffle(px.map((_, i) => i));
   S.ambient(t => {
     px.forEach((c, i) => {
       const k = M.spring(t - 8 - order[i] * M.beat(.5), 'pop');
       M.place(c, cx + gx[i], cy + gy[i], {s: k, o: k});
     });
     label.textContent = M.type('수집', t, 9.6, 14);   // Geist Mono, 아이콘 아래
   });
   ```
   - 다음 장면 전엔 점 대부분을 같은 방식으로 거꾸로 꺼서 서너 개만 남기고, 컷으로 문장 장면. 장면 쌓기에서는 deco `dots` 가 이 점 판을, `marks` 가 십자 눈금을 깔아요.
3. 앱 창 위를 쓸고 가는 주황 빛
   ```
   S.ambient(t => {
     M.place(win, W / 2, H / 2, {s: 1 + (t - 13) * .015});
     const p = M.ease.inOutCubic(M.prog(t, 14.2, 1.6));
     M.place(glow, M.lerp(-W * .2, W * 1.2, p), M.lerp(H * 1.1, -H * .1, p), {o: Math.sin(p * Math.PI)});
   });
   // glow: 지름 0.8W 원, radial-gradient(var(--glow), transparent), filter: blur(8u)
   S.tr.blur(prev, next, 16.2, .6);
   ```
4. 이름표 커서가 화면을 누빔
   - 밝은 브라우저 창 안에서 `M.Cursor` 로 검은 화살표를 움직이고 짙은 이름표 알약을 커서 오른쪽 아래에 붙여 함께 옮겨요. `M.cursorAt` 순간 버튼이 살짝 눌리고 다음 화면으로 컷. 왼쪽 아래 흰 알약 상태 꼬리표는 내내 그대로 두고, 안의 픽셀 아이콘만 반 박마다 점 하나씩 깜빡여요.
   - 결과 화면은 짙은 창 안 JSON 을 한 줄씩 아래에서 밀어 올리고 값 글자만 주황.
5. 주황 마무리
   - 컷으로 옅은 회색 위 제목 한 줄과 문장 한 줄을 차례로 보여 준 뒤, `linear-gradient(to top, var(--accent), transparent)` 판을 `M.anim` 으로 아래에서 화면 절반까지 1.2초에 끌어올리고 가운데 흰 마크를 띄워요.
