# 분홍 안개 다이얼 막대 (그라디언트·빛)

한 줄: 분홍·라벤더·살구빛 안개 위로 중간 굵기 산세리프 한 줄이 어절씩 붙고, 숯빛 판이 부드럽게 덮었다 걷혀요. 젖빛 판 위 파형은 다이얼을 돌리면 고르게 펴지고, 비스듬히 누운 숯빛 카드에서는 막대가 차오르는 차분한 기술 소개 무드예요.

## 보는 느낌
- 바탕 두 가지가 번갈아 나와요. 하나는 분홍을 바탕으로 라벤더와 살구빛이 귀퉁이에서 번지는 아주 흐린 안개, 다른 하나는 매끈한 숯빛 판.
- 화면마다 주인공은 하나만 둬요. 가운데 한 줄 문장, 파형 하나, 다이얼 하나, 카드 한 장. 나머지는 넓은 여백으로 남겨요.
- 숯빛 판에서는 흰 소리 파형이나 흰 글 한 줄이 뜨고, 그 아래 둥근 흰 네모 토큰들이 한 줄로 늘어서요(긴 네모 둘, 짧은 네모 여럿).
- 데이터는 3D로 살짝 기운 카드에 담아요. 젖빛 상자 위 파형, 숯빛 카드 위 가로 막대. 카메라가 카드를 조금씩 돌아보듯 기울기가 천천히 바뀌어요.
- 후반에는 화면보다 큰 흰 대문자 벽이 위아래로 잘린 채 깔리고, 그 앞에 폰 한 대가 떠요. 끝 무렵에는 흰 바탕에 회색 비네트가 진 조용한 판, 숯빛 코드 화면으로 마무리해요.

## 색
- 안개 65 · 숯빛 25 · 글자 8 · 파랑 2.
- 안개: 분홍 #EBD3D8 바탕에 라벤더 #CDAEE0, 살구 #F2DCC0 덩어리를 크게 흐려 얹어요. 귀퉁이 하나는 라벤더가 짙게, 다른 귀퉁이는 살구가 밝게.
- 숯빛 판 #2A2A2B, 그 위 카드 #4A4A4C, 글과 파형은 #F2EEEE.
- 안개 위 글자는 짙은 회갈색 #2B2828. 큰 대문자 벽은 흰색 #FAF6F5 를 60~80% 불투명도로.
- 파랑 #4A9BE0 은 막대 차트에서 '우리 쪽' 막대에만 써요. 버튼·꼬리표에 쓰면 글자는 거의 검정.

## 글자
- Geist(한글은 Noto Sans KR Medium). 문장은 굵기 500, 짧은 변의 6~7% 크기, 가운데 한 줄.
- 다이얼 꼬리표와 차트 머리글은 작은 대문자(짧은 변의 3%), 굵기 600, 자간 +0.04em.
- 큰 한마디(배수, 구호)는 Geist 850~900, 한글은 Noto Sans KR Black. 차트 옆에 두 줄로 박거나, 화면보다 크게 키워 대문자 벽으로 깔아요.
- 숫자 범위는 굵기 800 으로 크게 쓰고 아래 아주 작은 설명 한 줄.
- 코드 장면만 Geist Mono.

## 질감과 모양
- 그레인 0.05 로 안개에 아주 옅은 결만. 비네트 0.22 는 흰 판 장면에서 가장자리가 회색으로 가라앉게.
- 카드 모서리 1.2u. 젖빛 카드는 흰색 70% + 블러, 그림자 하나. 숯빛 카드는 그림자 없이 납작하게.
- 막대는 모서리 2px 의 짙은 회색 #6A6A6C, 강조 막대만 파랑. 막대 끝에 작은 고정폭 숫자.
- 다이얼: 굵은 먹색 원(선 두께 짧은 변의 0.8%)과 바늘 하나, 위쪽 호를 따라 짧은 눈금 다섯 개.

## 움직임
- 100BPM. 문장 어절은 한 박마다 하나씩 옅게 나타나요(0.3초 페이드, 위치 고정).
- 카드와 차트는 power2.out 으로 미끄러져 들어와 멈추고, 머무는 동안 rotateY 가 2~3도쯤 천천히 흘러요.
- 다이얼 바늘은 0.6초에 돌고, 바늘이 닿는 순간 파형이 바뀌어요. 막대는 0.15초 간격으로 왼쪽부터 차올라요.
- 장면 하나는 2~3박 머물러요. 큰 대문자 벽은 아주 천천히 옆으로 흘러요(4초에 짧은 변의 5%).

## 전환
- 컷이 기본. 안개와 숯빛 판 사이는 와이프로 이어요. 숯빛 판이 위로 걷히며 아래 가장자리가 3u 흐림으로 번진 채 안개를 드러내요.
- 흰 판·끝 장면으로는 느린 페이드. 장면 쌓기: cut → wipe → fade.
- 움직임 흐림이 큰 휘어진 띠(라벤더·모브 리본)가 화면을 휙 지나가며 장면 사이를 잇기도 해요.

## 대표 장면
1. **어절이 붙는 한 줄 + 부드러운 와이프**
   ```
   // 안개: 큰 원 3개(라벤더·살구·흰빛)를 blur(12u)로 흐리고 천천히 떠다니게
   S.ambient(t => blobs.forEach((b, i) => M.place(b, ...M.drift(i, t, .04))));
   // 어절은 한 박마다 하나씩 페이드
   words.forEach((w, i) => w.style.opacity = M.prog(t, t0 + i * M.beat(1), .3));
   // 숯빛 판이 위로 걷힘: 아래 가장자리를 mask 그라디언트로 3u 번지게
   const y = M.anim([[0, 0], [tB, -H * 1.1, {d: .7, e: 'inOutCubic'}]], t);
   M.place(darkPanel, cx, cy + y);   // 또는 S.tr.blocks 대신 S.tr.blur 로 부드럽게
   ```
2. **숯빛 판의 파형과 토큰 줄**
   - 흰 파형은 SVG path 하나를 `M.draw(path, M.prog(t, t0, .8))` 로 왼쪽부터 그려요. 이어 글 한 줄 아래 둥근 흰 네모 7~9개를 0.06초 간격으로 톡톡 켜고(`o` 0 → 1, `s` .8 → 1), 마지막 네모 하나는 깜빡여 입력 중인 느낌을 줘요.
3. **다이얼이 돌면 파형이 펴짐**
   ```
   const k = M.ease.inOutCubic(M.prog(t, tD, .6));
   needle.style.transform = `rotate(${-55 + 110 * k}deg)`;
   // 거친 파형(진폭 큰 노이즈) → 고른 사인 → 원형 고리로 말림
   wave.setAttribute('d', M.mix(roughPath, smoothPath, k));
   ring.style.opacity = M.prog(t, tD + M.beat(2), .5);
   ```
   - 판은 부모 `perspective` + `rotateX(14deg) rotateY(-8deg)` 로 눕히고, 꼬리표는 '기존'·'새 방식'처럼 짧은 대문자 둘로.
4. **기운 숯빛 막대 차트 + 큰 배수**
   - 숯빛 카드를 `M.place(card, x, cy, {ry: -18})` 로 옆에서 밀어 넣고(`M.spring(t - t0, 'smooth')`), 막대 너비를 `M.anim` 으로 0.15초 간격 차오르게. 파랑 막대가 다 차면 한 박 뒤 오른쪽에 굵은 두 줄 대문자 배수를 컷으로 박아요.
   - 장면 쌓기에서는 number: count 로 숫자가 올라가고, marker: color 로 강조 낱말이 파랑으로 켜져요.
