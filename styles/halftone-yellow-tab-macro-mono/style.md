# 노랑 망점 탭 접사 (제품 UI)

한 줄: 형광 노랑 망점 바탕에 걸린 어두운 앱 창으로 카메라가 비스듬히 파고들어요. 얕은 초점 속에서 탭 하나만 선명하게 열리고 이름이 바뀌고, 끝은 빈 숯빛 화면의 고정폭 한 줄로 조용히 닫혀요.

## 보는 느낌
- 첫 장면만 밝아요. 형광 노랑 바탕에 촘촘한 망점이 깔리고, 어두운 앱 창의 왼쪽 위 귀퉁이(신호등 점 셋, 작은 아이콘, 첫 탭)가 비스듬히 걸려 있어요.
- 그 뒤로는 거의 숯빛 하나예요. 카메라가 창 위 탭 막대에 아주 바짝 붙어 비스듬히 누워 있고, 초점이 얕아서 화면의 3분의 2는 흐려요. 선명한 건 늘 탭 알약 하나뿐.
- 한 번쯤 카메라가 물러나 탭 막대가 납작하게 작아 보이는 장면을 넣어, 지금까지 본 탭들이 한 줄에 있다는 걸 알려 줘요. 그리고 다시 탭 하나로 다가가요.
- 마무리는 UI 가 하나도 없는 빈 숯빛 화면. 가운데 고정폭 글자 한 줄만 작게 놓여요. 여백이 화면의 90% 넘게 남아요.

## 색
- 숯빛 바탕 85 · 탭 회색과 흰 글자 12 · 노랑과 파랑 3.
- 바탕 #141414, 탭 알약 #2B2B2B, 글자 #E8E8E6, 뒷말·흐린 글자 회색 #8C8C8A.
- 형광 노랑 #E4F01C 는 첫 장면 바탕에만 넓게 써요. 위에 같은 노랑을 조금 짙게 한 망점을 깔아요.
- 파랑 #5B7CF5 는 탭 앞 작은 아이콘에만. 아이콘 둘레에 파란 빛이 살짝 번져요.
- 신호등 점 셋(빨강·노랑·초록)은 창 귀퉁이 장면에서만 작게.

## 글자
- UI 안 글자: Geist(한글 Noto Sans KR Medium) 500, 탭 이름 크기. 카메라가 붙어 있어서 화면에선 짧은 변의 6~9%까지 커 보여요.
- 마무리 문장: Geist Mono 400~500, 짧은 변의 3% 안팎으로 작게, 가운데 정렬 한 줄. 앞쪽 핵심 말은 흰색, 뒤쪽 꾸밈말은 회색으로 두 톤을 나눠요(marker: color).
- 큰 제목은 쓰지 않아요. 크기 대비는 카메라 거리로 만들어요.

## 질감과 모양
- 그레인 0.05, 비네트 0.32. 어두운 접사 화면 가장자리가 자연스레 가라앉게.
- 탭 알약: 모서리 1u, 회색 #2B2B2B 칠, 테두리 없음. 고른 탭만 조금 밝은 회색.
- 얕은 초점: 초점면에서 멀어질수록 blur 를 0 → 1.2u 까지 키워요. 이 흐림이 이 결의 질감 대부분이에요.
- 첫 장면 망점은 바탕에만 그리는 무늬예요(deco dots). 화면 전체 질감으로는 깔지 않아요.

## 움직임
- 90BPM, 느림. 탭 하나의 사건(열림·눌림·이름 바뀜)마다 2초 남짓.
- 카메라는 power3.inOut 으로 쉬지 않고 천천히 옆으로 흐르고, 사건 사이엔 초점만 옮겨요(0.6초).
- 새 탭은 옆에서 미끄러져 나와 살짝 넘쳤다 자리 잡아요. 단축키 꼬리표는 0.15초에 톡.
- 탭 이름 바꾸기는 지우기(초당 30자) → 쓰기(초당 14자), 끝에 세로 커서가 한 박 깜빡여요.
- 마무리 문장은 흐림에서 맺히고 2~3초 머문 뒤 컷.

## 전환
- 노랑 오프닝 → 접사: 카메라가 창 안으로 파고들며 노랑이 화면 밖으로 밀려나는 이어진 움직임.
- 접사 사이: 흐림(blur)으로 초점이 빠졌다 다시 맺히며 넘어가요.
- 창 → 마무리: 창 전체가 어둡게 가라앉는 느린 페이드. 마무리 문장끼리는 빈 화면을 한 박 두고 컷.
- 장면 쌓기: blur → fade → cut.

## 대표 장면
1. **노랑 망점에서 창 안으로**: 바탕에 노랑 칠과 `radial-gradient` 망점(간격 0.6u). 창은 화면 오른쪽 아래로 크게 걸어 두고 카메라 판을 키워요.
   ```
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, .6, 1.4));
     M.place(stage, W * (.62 - .3 * k), H * (.7 - .35 * k), { s: 1 + k * 1.8, r: -14 });
     yellow.style.opacity = 1 - M.prog(t, 1.2, .5);
   });
   ```
2. **얕은 초점 탭 접사**: 부모에 `perspective`, 탭 막대에 `rotateX(28deg) rotateZ(-14deg)`. 카메라 x 는 `M.anim` 으로 계속 흐르고, 탭마다 초점 거리를 재서 흐림을 줘요.
   ```
   const focusX = M.anim([[0, x0], [2.0, x1, { d: .6, e: 'inOutCubic' }], [4.2, x2, { d: .6 }]], t);
   tabs.forEach(tb => tb.style.filter = `blur(${Math.min(1.2, Math.abs(cx(tb) - focusX) / W * 3)}u)`);
   ```
   장면 쌓기에서는 frame: window + title: blur 로 같은 결이 나와요.
3. **+ 눌림 → 새 탭 → 이름 바뀜**: + 에 `M.place(plus, x, y, { s: 1 - .12 * press })` 로 눌림, 꼬리표는 `M.spring(t - tp, 'snappy')` 로 톡. 새 탭은 `M.spring(t - tn, 'smooth')` 로 옆에서 밀려 나오고, 이름은 `M.type(old, …)` 거꾸로 지운 뒤 `M.type(newName, t, tn + 1.2, 14)`. 파란 아이콘만 `box-shadow: 0 0 1.5u var(--glow)`.
4. **빈 화면 고정폭 한 줄**: 창을 `o` 1 → 0 으로 1초에 가라앉힌 뒤 한 박 비우고, Geist Mono 한 줄을 `S.tr.blur` 로 맺어요. 앞말 `color: var(--on-bg)`, 뒷말 `color: var(--on-bg-muted)`. 2.5초 머물고 컷, 다음 한 줄도 같은 자리.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 데스크톱 앱 기능 소개, 개발 도구 업데이트, 작은 UI 변화 하나를 보여 줄 때, 조용한 런칭 티저.
- 피할 것: 화면 가득 찬 UI 여러 개, 빠른 컷 몰아치기, 강조색 여러 개, 굵고 큰 제목, 밝은 바탕으로 계속 머물기(노랑은 첫 장면에서만).
