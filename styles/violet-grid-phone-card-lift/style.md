# 보라 격자 폰 카드 들어올림 (제품 UI)

한 줄: 옅은 격자가 깔린 진보라 판 가운데 밝은 결제 폰 화면이 서 있고, 화면 속 카드 한 장이 폰보다 넓게 커지며 떠올라요. 네 귀퉁이 재단 표시가 그 카드를 잡아 주고, 잠시 머문 카드는 제자리로 쏙 내려앉아요.

## 보는 느낌
- 화면 전체가 진보라 한 색이고, 그 위에 아주 옅은 흰 격자(칸 하나가 짧은 변의 6% 남짓)가 깔려 있어요.
- 가운데에 밝은 회색 폰 화면 한 대. 테두리나 기기 몸체 없이 둥근 판만 있고, 위쪽 뒤로 다음 화면이 연보라 탭처럼 살짝 비쳐요.
- 주인공은 화면 속 카드 한 장이에요. 합계, 달력, 주문 요약처럼 한 구역이 폰 너비보다 넓게 커져 앞으로 떠오르고, 나머지 폰은 그 아래에서 조용히 받쳐 줘요.
- 떠오른 카드 둘레 조금 바깥에 ㄱ자 재단 표시 네 개가 붙어서 '여기 보세요' 하고 잡아 줘요. 화살표나 동그라미는 쓰지 않아요.
- 한 장면에 떠오르는 카드는 늘 하나뿐이에요.

## 색
- 보라 바탕 65 · 밝은 회색 화면 30 · 파랑 5.
- 바탕 #5730D0, 격자 선은 흰색 10%, 재단 표시는 흰색 55~70%.
- 화면 판 #F0F0F2, 글자 #1C1C1E, 작은 설명은 같은 먹색 50%.
- 파랑 #1F5FD6 은 '결제' 버튼, 고른 날짜 칸, 라디오 점에만. 버튼 글자는 흰색.
- 뒤에 비치는 다음 화면 탭은 연보라 #A99BEA.

## 글자
- 깔끔한 산세리프(Geist, 한글은 Noto Sans KR). 화면 속 실제 UI 글씨처럼 작고 반듯해요.
- 떠오른 카드의 제목만 600 굵기로 짧은 변의 3.5~4%, 나머지 항목은 400~500 으로 2.5% 안팎. 가격 숫자는 제목과 같은 크기로 오른쪽 정렬.
- 화면 밖에 따로 큰 문구를 띄우지 않아요. 말하고 싶은 건 카드 제목과 항목 글로 전해요.
- 줄 간격은 넉넉하게(1.4), 구역 사이엔 얇은 회색 선.

## 질감과 모양
- 질감 없이 매끈하게. 그레인·비네트도 쓰지 않아요.
- 폰 판 모서리는 크게(짧은 변의 3%), 떠오른 카드는 1.6u. 떠오른 카드에만 넓고 옅은 그림자(아래로 2u, 흐림 6u, 먹색 18%).
- 재단 표시는 1.5px 선, 한 변 길이 2u 의 ㄱ자.
- 카드 안 버튼과 칸은 0.8u 모서리, 고른 칸은 파랑으로 꽉 채워요.

## 움직임
- 96BPM, 차분한 보통 속도. 장면 하나가 3.5~4초.
- 카드 들어올림: 0.6초 `power3.out` 으로 커지며 앞으로. 재단 표시는 카드보다 0.1초 늦게, 바깥에서 안쪽으로 1u 미끄러져 붙어요.
- 카드가 다 커진 뒤 한 박 쉬고 안에서 조작 하나(날짜 칸 채우기, 목록 펼치기). 그다음 2초쯤 머물러요.
- 내려앉기: 0.5초 `power2.inOut` 으로 정확히 원래 자리, 원래 크기로. 그림자와 재단 표시가 같이 옅어져요.
- 폰 전체는 내내 거의 움직이지 않아요. 카드만 오르내려요.

## 전환
- 화면 갈기는 세로 흐림(blur): 폰 위로 비치던 다음 화면 탭이 내려오며 폰이 0.3초 세로로 흐려지고, 새 화면이 맺혀요. 맨 위 이름 줄만 바뀌고 틀은 그대로.
- 장면 쌓기: blur → push. 밀어내기도 세로 방향으로 짧게.

## 대표 장면
1. **카드 들어올림 + 재단 표시**
   ```
   // slot: 폰 안에서 카드가 원래 있던 자리 {x, y, w, h}
   S.ambient(t => {
     const up = M.anim([[0, 0], [t0, 1, {d: .6, e: 'outCubic'}], [t1, 0, {d: .5, e: 'inOutQuad'}]], t);
     const w = slot.w * (1 + .3 * up), h = slot.h * (1 + .3 * up);
     M.box(card, {x: slot.cx - w / 2, y: slot.cy - h / 2 - up * u * 1.5, w, h});
     card.style.boxShadow = `0 ${2 * up}u ${6 * up}u rgba(28,28,30,${.18 * up})`;
     const m = M.anim([[0, 0], [t0 + .1, 1, {d: .4, e: 'outCubic'}], [t1, 0, {d: .3}]], t);
     marks.forEach((c, i) => M.place(c, cornerX(i, w) + sx(i) * (1 - m) * u, cornerY(i, h), {o: m}));
   });
   ```
   장면 쌓기에서는 frame: phone + deco: marks 로 같은 결이 나와요.
2. **떠오른 카드 안의 조작 하나**
   - 달력: 고른 날짜 칸 배경을 `M.color('#F0F0F2', '#1F5FD6', k)`, 글자를 흰색으로. `k = M.spring(t - (t0 + M.beat(1)), 'snappy')`.
   - 묶음 목록: 하위 항목 3줄을 `M.place(row, x, y, {o: k, y: (1 - k) * u})` 로 0.08초씩 늦게 펼치고, 카드 높이는 `M.box` 로 같이 늘려요.
3. **다음 화면이 비쳤다 내려오며 갈림**
   - 폰 위쪽 뒤에 연보라 탭(다음 화면 윗부분)을 1u 보이게 두었다가, 장면 끝에 `S.tr.blur` 로 넘겨요. 직접 만들 땐 새 화면 y 를 `M.anim([[tB, -H * .08], [tB + .35, 0, {d: .35, e: 'outCubic'}]], t)`, 이동 중 `filter: blur()` 를 세로로 0 → 6px → 0.
4. **처음으로 돌아와 닫기**
   - 마지막 장면은 첫 화면으로 돌아와 아래쪽 알림 띠 하나만 살짝 떠 있게(들어올림 0.3배). 첫 장면과 같은 자리라 한 바퀴 돈 느낌으로 끝나요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 결제·주문 화면 소개, 앱 기능을 하나씩 짚을 때, 폰 앱 업데이트 안내, 쇼핑·구독 서비스 설명.
- 피할 것: 질감·그레인, 빠른 컷 몽타주, 손그림 선, 강조색 여러 개(파랑 하나만), 카드 여러 장을 한꺼번에 띄우기.
- 화면 속 글이 곧 문구라서, 카드 제목은 2~6자, 항목은 한 줄로 짧게 쓰면 잘 읽혀요.
