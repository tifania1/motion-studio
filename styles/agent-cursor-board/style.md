# 시안 판 위 AI 커서 (제품 UI)

한 줄: 점 격자 캔버스 위에 웹페이지 시안들이 놓여 있고, 보라색 AI 커서가 "바꾸는 중…" 꼬리표를 달고 지나가면 구역이 하나씩 다시 칠해져요. 굵은 제목은 글 상자 안에서 솟아올라요.

## 보는 느낌
- 디자인 툴 캔버스를 그대로 영상으로 옮긴 화면. 옅은 회색 점 격자 위에 시안이 떠 있어요.
- 큰 제목은 화면 가운데, 얇은 글 상자 테두리 안. 편집기 속 글자라는 걸 테두리 하나로 보여 줘요.
- 사람 커서(검정)와 AI 커서(보라)가 함께 나와서 "누가 고치는지"가 색으로 구분돼요.

## 색
- 바탕 55 · 시안(사진·흰 판·어두운 판) 35 · 글자 7 · 보라 3.
- 바탕 #E1E1E1 + 점 격자 rgba(17,17,17,.12). 글자 #111111.
- 강조 보라 #6A3FE0: AI 커서, 꼬리표, 고치는 구역 덮개(보라 18%) + 테두리(보라 80%).
- 글 상자 테두리와 글자 선택 하이라이트는 연한 청보라(#A9B6E0).
- 시안 속 어두운 판은 #1E1A19 같은 따뜻한 검정.

## 글자
- 제목: 굵은 그로테스크(Archivo 800~900, 폭 100~105%) + 한글 Noto Sans KR Black. 자간 −0.04em, 줄 간격 0.95.
- 제목 위 작은 머리말("새로 나온")은 Geist 600, 제목 크기의 22%.
- 꼬리표·UI 글자는 Geist + Noto Sans KR 500, 작게.

## 질감과 모양
- 질감 없음. 점 격자만 바탕 무늬로(간격 3u, 점 지름 0.25u).
- 모서리는 거의 각지게(0.6u). 시안 판에는 옅은 그림자 0 .8u 2.4u rgba(0,0,0,.12).
- 글 상자: 1px 청보라 선, 손잡이 없음. 고치는 구역 덮개: 1.5px 보라 선 + 보라 18% 채움.
- AI 커서: 보라로 꽉 찬 삼각형(일반 화살표보다 조금 작게) + 오른쪽 아래 알약 꼬리표.

## 움직임
- 120BPM, 빠르고 단단하게. 들어오는 움직임은 expo.out(빨리 와서 오래 미끄러지듯 멈춤).
- 카메라 이동은 0.5~0.9초, M.anim {d, e: 'outExpo'} 또는 'soft'.
- 고치기 묶음: 덮개 0.2초 → 뼈대 반짝이 0.6초 → 새 디자인 0.25초 페이드 + scale .98→1.
- 커서는 M.cursorAt 으로 이동(inOutCubic). AI 커서 꼬리표 글자는 반짝이 띠가 1초 주기로 지나감.

## 전환
- 같은 캔버스 안에서는 카메라로만(확대·이동·물러나기).
- 마지막 로고는 컷으로 빈 바탕에.

## 대표 장면

1. 글 상자에서 솟는 제목 (0.6초)
   ```
   // .box { overflow:hidden; outline:1px solid #A9B6E0 } 안에 .ttl
   const k = M.spring(t - t0, { f: 2.6, z: 1 });
   M.rise(ttl, k);                                        // 아래에서 올라옴
   box.style.width = M.lerp(ttlW * .7, ttlW + 2 * u, M.spring(t - t0, 'snappy')) + 'px';
   kicker: S.fx.fade(kick, t0 - .1, { d: .2 })
   ```
   - 같은 때 카메라가 위로 조금(4u) 흘러 시안이 아래에서 올라와 보이게.
2. 프롬프트 → AI 커서 고치기 (3~4초)
   - 시안 위에 흰 알약 입력창이 뜨고 M.type 으로 "어둡고 잡지처럼 바꿔 줘" 같은 한 줄 → 보내기 버튼 클릭.
   - AI 커서가 [[t, x1, y1], [t+.5, x2, y2], …] 로 구역 셋을 차례로 지나감. 구역마다:
   ```
   overlay.style.opacity = M.prog(t, ti, .2);
   skeleton bars: background-position-x = ((t * 1.2) % 1) * 200 + '%'   // 반짝이
   if (t > ti + .6) { 앞 디자인 opacity 0, 새 디자인 o = M.prog(t, ti + .6, .25), s = .98 + .02 * k }
   overlay.style.opacity = 1 - M.prog(t, ti + .8, .2);
   ```
3. 캔버스로 물러나기 → 제목 다시 쓰기
   ```
   const z = M.anim([[t3, 1], [t3 + .05, .35, { d: .9, e: 'inOutCubic' }]], t);
   M.camera(world, cx, cy, z);                            // world 는 시안 9~12장이 깔린 큰 판
   ```
   - 가운데 큰 제목을 사람 커서로 더블클릭 → 연청보라 선택 하이라이트 → 지우고 두 줄 문장 타자, 글 상자 높이가 줄 수만큼 'snappy' 로 늘어남.
