# 어둠 속 은빛 폰 매크로 (제품 UI)

한 줄: 거의 검은 어둠 속에서 은빛 테두리를 따라 빛이 미끄러지며 폰 모서리를 바짝 훑고, 천천히 물러나면 기울어 도는 폰 화면의 숫자가 자리마다 굴러 맞춰지는 차분한 다크 제품 공개예요.

## 보는 느낌
- 화면 대부분이 #111111 어둠이에요. 빛은 폰 테두리의 은빛 반사와 화면 속 흰 글씨에서만 나와요. 가장자리는 비네트로 더 가라앉고, 가운데만 살짝 밝아요.
- 처음엔 폰이 화면보다 훨씬 커서 모서리 곡선, 옆 버튼, 화면 귀퉁이 버튼 하나만 보여요. 무엇인지 다 보여 주지 않고 질감부터 보여 주는 거예요.
- 물러난 뒤에는 폰 한 대가 화면 높이의 50~70% 크기로 가운데에 떠 있어요. 둘레에 다른 요소는 거의 두지 않아요.
- 끝에 밝은 하늘빛 화면이 딱 한 장 들어와 어둠을 깨요. 그 뒤로는 다시 검은 화면에 작은 글씨만 남아요.

## 색
- 어둠 85 · 흰 글씨와 은빛 반사 12 · 초록 3.
- 바탕 #111111, 폰 화면 속 카드 #1C1D1F~#26272A, 글씨 #F2F2F2, 보조 글씨는 흰색 55%.
- 초록 #4ADE80 은 숫자가 오른 폭, 성공 표시에만. 알약 안 글씨는 짙은 초록 #0B1A10.
- 하늘빛 #8EC3E6 은 영상 끝 무렵 한 장면에만 넓게 써요. 다른 곳에는 쓰지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 제목 굵기 600, 자간 -0.01em.
- 작게 써요. 엔딩의 한 줄도 화면 높이 4% 안팎, 가운데 정렬 한 줄.
- 폰 화면 속에선 잔고 숫자만 크게(화면 폭의 25~30%), 나머지 목록은 작고 가볍게. 소수점 뒤 자리는 회색으로 한 단계 내려요.

## 질감과 모양
- 비네트 0.35 하나만. 그레인·색 번짐은 없어요. 매끈한 어둠이 이 결의 바탕이에요.
- 폰 테두리는 1~1.5u 두께의 은빛 띠. 위쪽 가장자리에 흰 반사가 가늘게 맺히고, 그 반사가 천천히 미끄러져요.
- 모서리 2.4u. 화면 속 카드는 테두리 없이 한 단계 밝은 회색 면으로만 나눠요.
- 그림자는 쓰지 않고, 폰 아래 바닥에 아주 옅은 흰빛 번짐(glow) 하나만 둬요.

## 움직임
- 84BPM, 느림. 카메라 이동은 `power3.inOut` 으로 천천히 출발해 천천히 멈춰요.
- 한 장면이 3~5초 머물러요. 큰 움직임은 한 장면에 하나만(물러나기, 돌기, 눕기 중 하나).
- 폰은 늘 아주 조금씩 떠 있어요. 4~6초 주기로 1~2도 기울었다 돌아와요.
- 숫자는 자리마다 0.6~0.9초에 굴러 멈추고, 오른쪽 자리일수록 조금 늦게 멈춰요.
- 버튼 누름은 크기 0.94까지 0.12초 눌렸다 돌아오는 정도로 작게.

## 전환
- 어둠에서 서서히 밝아지고 어둠으로 서서히 꺼지는 페이드가 기본이에요. 폰이 옆선 한 줄이 되는 순간이나 화면이 하늘빛으로 바뀌는 순간엔 컷.
- 엔딩 글씨는 흐림에서 맺혀요(blur). 장면 쌓기: fade → cut → blur.

## 대표 장면

1. 모서리 매크로와 + 버튼
   ```
   // 폰을 화면의 3배로 키워 오른쪽 위 모서리만 보이게 두고, 반사광이 곡선을 따라 흐름
   S.ambient(t => {
     const s = M.anim([[0, 3.2], [3.6, 1, {d: 3.2, e: 'inOutCubic'}]], t);   // 물러나기
     M.place(phone, cx, cy, {s, o: M.anim([[0, 0], [0, 1, {d: 1}]], t)});
     rim.style.backgroundPosition = `${M.anim([[0, -60], [.4, 140, {d: 2.6, e: 'inOutSine'}]], t)}% 0`;
   });
   // + 버튼: 1.8초에 눌림(0.94), 0.2초 뒤 메뉴 네 줄이 아래서 하나씩 0.08초 간격으로
   menuRows.forEach((r, i) => M.place(r, 0, 0, {o: M.spring(t - 2 - i * .08, 'smooth')}));
   ```
2. 어둠 속에서 몸을 돌리는 폰
   ```
   // 부모에 perspective, 폰은 rotateY → 옆선 한 줄 → rotateX 로 눕기 → 반듯하게
   const ry = M.anim([[0, -28], [1.2, 88, {d: 1.4, e: 'inOutCubic'}], [3.4, 0, {d: 1.6}]], t);
   const rx = M.anim([[0, 0], [3, 62, {d: 1.4, e: 'inOutCubic'}], [5.6, 0, {d: 1.4}]], t);
   phone.style.transform = `rotateY(${ry}deg) rotateX(${rx}deg)`;
   // 장면 사이를 잇는 건 S.tr.blur 나 어둠 페이드
   ```
3. 자리마다 굴러 맞춰지는 잔고
   - 장면 쌓기에서 `number: odometer` 로 자리마다 굴러가고, 소수점 뒤는 onBgMuted 회색.
   - 직접 만들 땐 자리마다 0~9 세로 띠를 두고 `y = -digit * h * M.ease.outCubic(M.prog(t, t0 + i * .06, .8))`. 다 멈추면 초록 알약(+%)이 `M.spring(t - t1, 'smooth')` 로 옆에 붙어요.
4. 하늘 한 장, 그리고 조용한 엔딩
   - 폰 화면을 컷으로 하늘빛 그라디언트(우리가 새로 그린 하늘과 흰 구름 덩어리 몇 개)로 바꾸고, 아래에 작은 알림 카드 하나를 `M.spring` 으로 올려요. 카메라가 화면 쪽으로 2초에 걸쳐 조금 다가가요.
   - 어둠으로 페이드한 뒤 가운데 작은 마크 → 흰 한 줄 → 주소를 각각 2초씩, `title: blur` 로 흐림에서 맺혔다 페이드로 빠져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·지갑 앱 공개, 프리미엄 폰 앱 런칭, 하드웨어 질감을 보여 주는 제품 티저, 브랜드 첫 공개 영상. 25~35초.
- 피할 것: 밝은 바탕 장면 여러 번(하늘빛은 한 번만), 빠른 컷 몽타주, 종이·손그림 질감, 강조색 여러 개(초록 하나만), 화면을 꽉 채우는 큰 제목.
- 원본의 고전 그림 컷은 따라 그리지 않아요. '어둠 사이 밝은 한 장'이라는 리듬만 가져와 우리 하늘 그라디언트로 만들어요.
