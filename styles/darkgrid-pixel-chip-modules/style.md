# 어두운 격자 원색 칩 모듈 (그래픽·도형)

한 줄: 숯빛 격자 위에서 원색 네모 칩이 한 칸씩 톡톡 켜져 무늬를 이루고, 고정폭 꼬리표가 노드 줄로 이어지다가 마젠타·노랑·연두 색면으로 컷 넘어가며 카드 판이 펼쳐지는 모듈형 도식 필름이에요.

## 보는 느낌
- 바탕은 숯빛 회색 한 장에 아주 옅은 정사각 격자. 모든 칩·상자·선이 이 격자 칸에 딱 맞춰 놓여서 설계도 같은 질서가 있어요.
- 화면 대부분은 비워 두고 가운데 작은 덩어리 하나만 움직여요. 원색 칩 몇 개, 고정폭 꼬리표 한 줄, 가는 연결선 하나 정도.
- 가끔 정반대로 꽉 채워요. 화면보다 큰 산세리프 낱말이 양옆으로 잘려 나가고, 그 위를 색 띠 글 다발이 가로질러요.
- 중간에 한두 번 화면 전체가 마젠타·연두·노랑 색면으로 바뀌어요. 색면 위에는 같은 색 계열 가로 띠가 옅게 깔리고, 어두운 세로 카드 두세 장이 나란히 서요.
- 칩은 모두 네모. 동그라미는 거의 쓰지 않고, 와이어 장면에서만 가는 대각선이 들어와요.

## 색
- 숯빛 바탕 #1F1F1F 75 · 흰 글자 #EDEDEA 15 · 원색 칩 10.
- 원색 다섯: 마젠타 #DD55E8, 노랑 #E6CC1A, 연두 #7FE83A, 주황 #E8541A, 하늘 #4BB8E8. 다섯 가지를 다 쓰되 칩 하나에는 한 색만, 넓이는 아주 작게.
- 강조(accent)는 마젠타. 색면 장면은 마젠타 → 연두 → 노랑 순으로 바꿔요. 색면 위 글자는 짙은 먹색 #1A1A1A.
- 꼬리표 상자는 칩 색의 20~30% 투명 칠 + 같은 색 1px 테두리 + 같은 색 글자. 범례처럼 줄지어 놓으면 색이 한눈에 짝지어져요.
- 격자선은 흰색 6~8%.

## 글자
- 큰 낱말·제목: Geist 500(한글 Noto Sans KR Medium), 자간 −0.03em. 크게 쓸 땐 짧은 변의 40% 이상으로 화면 밖까지 잘리게.
- 작은 꼬리표·버튼·범례: Geist Mono 대문자, 짧은 변의 1.6~2%, 자간 +0.04em. 두 줄로 끊어 쌓는 짧은 제목(예: 낱말 두세 개를 줄마다 하나씩)도 고정폭으로.
- 큰 글과 작은 꼬리표의 크기 차이를 아주 크게 둬요(20배 안팎). 중간 크기는 카드 안 제목 정도만.
- 꼬리표 글자는 기호에서 글자로 맞춰지듯(scramble) 0.4초에 들어와요.

## 질감과 모양
- 질감은 없어요. 매끈한 평면 색과 1px 선.
- 모서리는 거의 각지게(0.2u). 칩은 정사각, 막대는 얇은 가로 직사각.
- 그림자·빛 번짐 없음. 겹침은 테두리 선으로만 구분해요.
- 연결선과 와이어 선은 1px, 흰색 25~40% 또는 칩 색 50%.

## 움직임
- 120BPM. 칩은 반 박(0.25초)마다 한 칸씩 켜지고, 큰 변화는 2박(1초)마다.
- 칩은 크기 0에서 `expo.out` 으로 톡 튀어나와 바로 멈춰요. 사라질 땐 애니메이션 없이 칸째로 꺼짐.
- 띠 글은 일정한 속도로 계속 흘러요(이징 없음). 줄마다 방향과 속도를 조금씩 달리.
- 노드 줄은 세로로 미끄러지다 한 칸이 가운데에서 멈추고, 그 칸만 가로로 늘어나요(0.3초, expo.out).
- 장면 끝은 무늬가 점 하나로 줄어들고, 그 점이 다음 장면의 시작점이 돼요.

## 전환
- 컷이 기본. 색면 장면으로 들어갈 땐 박에 맞춰 컷, 큰 낱말에서 다음 문구로 갈 땐 가로 와이프.
- 노드 줄처럼 같은 판이 이어질 땐 밀어내기(push)로 세로로 넘겨요.
- 장면 쌓기: cut → wipe → cut → push.

## 대표 장면
1. **한 칸씩 켜지는 원색 칩 무늬**
   ```
   // 격자 칸 좌표 목록(체크·사선·십자)을 정해 두고 반 박마다 하나씩 켬
   const cells = pattern.map(([cx, cy], i) => ({ el: chips[i], cx, cy, t0: i * M.beat(.5) }));
   S.ambient(t => {
     cells.forEach(c => {
       const k = M.ease.outExpo(M.prog(t, c.t0, .2));
       M.place(c.el, c.cx * cell, c.cy * cell, { s: k });
     });
     // 다 켜진 뒤 한 칸만 남기고 줄어 점 하나로
     const end = M.prog(t, M.beat(cells.length * .5 + 2), .4);
     cells.slice(1).forEach(c => c.el.style.opacity = end < 1 ? 1 - end : 0);
   });
   ```
2. **잘린 큰 낱말 위 띠 글 다발**
   - 큰 낱말을 짧은 변의 45% 크기로 가운데 두고 양옆이 잘리게. 그 위에 띠 4~5줄(마젠타·노랑·연두·하늘 칠, 고정폭 대문자 먹색 글자)을 한 줄씩 x 를 어긋나게 쌓아요.
   - 띠마다 `x = x0 + dir * speed * t` 로 계속 흘리고, 들어올 때만 `M.box(band, {w: M.anim([[t0, 0], [t0, W, {d: .3, e: 'outExpo'}]], t)})` 로 펼쳐요. 장면 쌓기에서는 deco ticker 가 이 띠 글을 깔아 줘요.
   - 2박 뒤 컷으로 마젠타 색면 장면. 옅은 가로 띠 위로 어두운 세로 카드 2~3장이 한 박 간격으로 아래에서 툭 올라와요.
3. **노드 줄과 연결 막대**
   ```
   // 아이콘 칩 세로 줄이 흐르다 가운데 칸에서 멈추고, 그 칸이 막대로 늘어남
   const y = M.anim([[0, H * .6], [M.beat(1), 0, { d: .5, e: 'outExpo' }]], t);
   rows.forEach((r, i) => M.place(r, cx, cy + y + (i - mid) * gap));
   M.draw(linkPath, M.ease.outCubic(M.prog(t, M.beat(1.5), .3)));        // 왼쪽에서 가는 선이 닿음
   M.box(bar, { x: cx, y: cy, w: M.anim([[M.beat(2), gap], [M.beat(2), W * .35, { d: .3, e: 'outExpo' }]], t), h: gap * .8 });
   tag.style.opacity = t > M.beat(2.5) ? 1 : 0;                           // 연두 고정폭 꼬리표
   ```
   - 다음 칸으로 넘어갈 땐 `S.tr` push 로 줄 전체를 한 칸 위로, 막대 색만 마젠타 → 주황으로 바꿔요.
4. **와이어 정사각형과 범례 마무리**
   - 점 하나에서 가는 대각선 8개를 `M.draw` 로 바깥 정사각형 꼭짓점·변 가운데까지 뻗고, 한 귀퉁이 작은 정사각형을 칩 색으로 채워요(노랑, 다음 판은 하늘).
   - 끝은 범례 다섯 줄. 줄마다 왼쪽 색 꼬리표(고정폭, scramble 로 맞춰짐) → 가운데 칩 → 오른쪽 외곽선 막대 순으로 반 박씩 늦게 켜고, 막대 길이는 `M.box` 로 0에서 값까지 0.3초에.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발 도구·데이터 플랫폼 소개, 기능 묶음·제품군 정리, 연동·연결 기능 설명, 기술 행사 오프닝, 숫자 하나를 내세우는 성능 자랑.
- 피할 것: 흐릿한 그라디언트 덩어리, 둥근 모서리와 부드러운 그림자, 손그림 선, 느린 서서히 전환, 한 화면에 긴 문단.
- 한글 꼬리표는 고정폭 글꼴에 없는 글자라 Noto Sans KR 로 보여요. 짧은 낱말(2~5자)로 줄여 쓰면 칩 리듬이 살아요.
