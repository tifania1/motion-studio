# 라임 막대 가림 쓸기 (타이포)

한 줄: 거의 검은 화면 위로 형광 라임 판과 흰 막대가 번갈아 쓸고 지나가요. 굵고 빽빽한 그로테스크 문장은 검은 상자 안이나 라임 바탕 위에 쳐지는 보안 런칭 필름이에요.

## 보는 느낌
- 바탕은 숯빛 검정이고, 서너 장면마다 화면 전체가 형광 라임으로 뒤집혀요. 라임 판에는 아주 가는 검은 작도선(큰 원, 십자, 가로세로 기준선)과 모서리마다 작은 고정폭 꼬리표가 깔려요.
- 큰 문장은 두 줄로 왼쪽에 정렬하거나 가운데 한 줄로 두고, 크기는 화면 높이의 10~14%예요. 한 문장에서 라임으로 칠하는 낱말은 하나뿐이에요.
- 흰 가로 막대(화면 높이 7~8%)가 화면을 가로질러 문장 상자를 꿰고, 막대 끝에는 라임 정사각 표지판이 달려 들어와요. 막대가 대각선으로 기울어 지나가는 장면도 있어요.
- 고정폭 대문자 문구가 한 줄씩 늘어나 화면을 벽처럼 채워요. 줄마다 글자 수가 조금씩 달라 계단처럼 보이고, 라임 세로 막대가 그 위를 쓸어요.
- 후반에는 비스듬히 누운 회색 꼬리표 도식이 나오고, 연결선 한 갈래만 라임으로 빛나요. 그 앞 왼쪽 아래에 흰 큰 문장이 놓여요.
- 사이사이 대화 UI 조각(메시지 줄, 생각 중 표시, 요청을 보내는 흰 막대와 작은 라임 고정폭 글씨)이 짧게 끼어들어 상황을 알려 줘요.

## 색
- 검정 #111111 60 · 라임 #E3F26B 25 · 흰 #F2F2F0 12 · 회색과 빨강 3.
- 라임 판 위 글자는 검정, 검정 위 강조 낱말은 라임으로 칠해요. 흰 막대나 흰 상자 위 글자도 검정이에요.
- 회색 #6E6E6A 는 도식 꼬리표와 작은 시간 표시에, 빨강 #D9443A 는 경고 아이콘과 모서리 꼬리표의 작은 점에만 써요.
- 라임 빛 번짐은 도식의 켜진 선에만 한 겹 얹어요.

## 글자
- 큰 문장: Archivo 600(stretch 100%), 자간 -0.04em, 줄 간격 0.95. 한글은 Noto Sans KR Bold 로 써요.
- 꼬리표, 도식 이름, 벽 문구: Geist Mono 500 대문자, 자간 0.02em, 짧은 변의 2~3%.
- UI 메시지 본문: Geist 400, 작고 옅게.
- 큰 글과 꼬리표의 크기가 다섯 배쯤 차이 나게 잡아서 대비를 세게 줘요.
- 첫 장면에서는 큰 제목 뒤에 라임 형광펜 띠를 깔고 살짝 기울여 둬요.

## 질감과 모양
- 표면은 매끈하게 두고, 도식 장면에만 비네트 0.2 를 넣어 가장자리를 눌러 줘요. 그러면 라임 빛 선이 더 또렷해져요.
- 모서리는 거의 직각(0.3u)이에요. 문장 상자는 검정으로 칠하고 짧은 변의 1.5% 두께 흰 테두리를 둘러 이중 틀로 만들어요.
- 대화 카드는 1px 회색 테두리만 있는 어두운 상자예요.
- 켜진 연결선은 2px 라임에 바깥 빛 번짐 한 겹을 얹어요.

## 움직임
- 120BPM, 빠르게 가요. 쓸기와 컷이 박에 맞춰 일어나요.
- 막대와 판은 expo.out 으로 확 들어와 바로 멈춰요. 나갈 때는 반대편으로 쓸려 빠지거나 컷으로 사라져요.
- 큰 문장은 커서 없이 글자 단위로 빠르게(초당 25자 안팎) 쳐지고, 다 쳐지면 한 박 반 머물러요.
- 벽 문구는 0.04초 간격으로 한 줄씩 늘어나요.
- 도식 장면에서는 카메라가 아주 천천히(4초에 3%쯤) 밀고 들어가요.
- 체크 획은 0.45초에 한 번에 그어지고, 그 뒤로는 움직이지 않아요.

## 전환
- 기본은 라임 판이 한쪽에서 쓸고 들어오는 와이프예요. 여기에 컷, 그리고 흰 막대가 장면을 끌고 가는 밀어내기를 섞어요.
- 장면 쌓기: wipe → cut → push.

## 대표 장면
1. **라임 판 와이프와 쳐지는 문장**
   ```
   // 라임 판이 왼쪽에서 화면을 덮은 뒤 검정 문장이 쳐짐
   const k = M.ease.outExpo(M.prog(t, t0, .35));
   M.box(limePanel, {x: 0, y: 0, w: W * k, h: H});
   title.textContent = M.type(text, t, t0 + .3, 25);
   // 작도선(SVG circle·line)과 모서리 꼬리표는 판과 함께 드러나게 판 안에 둠
   // 장면 쌓기에서는 schemes 의 accent 장면 + title: type
   ```
2. **흰 막대가 문장 상자를 꿰고 표지판이 밀려옴**
   ```
   const k = M.ease.outExpo(M.prog(t, t0, .4));
   M.box(bar, {x: 0, y: H * .42, w: W * k, h: H * .075});
   // 상자: 검정 칠 + 흰 테두리, 강조 낱말만 라임
   const sx = M.anim([[0, W * 1.2], [t0 + .3, W * .78, {d: .4, e: 'outExpo'}]], t);
   M.place(sign, sx, H * .45);   // 라임 정사각 표지판 + 아래로 뻗은 막대
   ```
   다음 장면으로 넘어갈 때는 막대째 옆으로 밀어내요(S.tr push).
3. **고정폭 문구 벽과 라임 세로 막대**
   ```
   rows.forEach((r, i) => r.style.visibility = t > t0 + i * .04 ? 'visible' : 'hidden');
   const x = M.anim([[0, -W * .1], [t0 + .6, W * 1.1, {d: .5, e: 'inOutQuart'}]], t);
   M.box(sweep, {x, y: 0, w: W * .08, h: H});
   ```
   줄마다 문구를 앞에서부터 1~4글자씩 잘라 계단처럼 만들어요. 숫자 장면은 number: scramble 로 고정폭 숫자가 섞이다 맞춰지게 해요.
4. **기운 도식에 라임 길이 켜지고, 큰 체크 획**
   ```
   stage.style.transform = `perspective(1400px) rotateX(28deg) rotateZ(-8deg) scale(${1 + t * .008})`;
   M.draw(litPath, M.ease.outCubic(M.prog(t, t0 + .4, .6)));   // 라임 + 빛 번짐 한 겹
   M.draw(check, M.ease.outCubic(M.prog(t, t1, .45)));          // 화면보다 큰 라임 체크
   ```
   회색 꼬리표 상자들은 미리 깔아 두고, 켜진 갈래 끝 꼬리표만 라임 테두리로 바꿔요. 흰 큰 문장은 왼쪽 아래에서 쳐져요.
