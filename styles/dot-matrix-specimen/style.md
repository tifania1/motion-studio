# 점 활자 견본 (레트로·픽셀)

한 줄: 검은 화면에 점과 네모로 짠 픽셀 글자. 흩어진 기호 가루가 모여 큰 글자가 되고, 점 몇 개만 하얗게 켜며 가는 지시선으로 주석을 다는 활자 견본집 같은 흑백 화면.

## 보는 느낌
- 거의 검은 화면에 아주 옅은 점 격자. 화면 아래 양 귀퉁이에 작은 고정폭 캡션(왼쪽 두 줄, 오른쪽 한 줄)이 처음부터 끝까지 떠 있어 견본집 한 쪽처럼 보여요.
- 가운데에는 한 번에 하나만: 큰 픽셀 글자, 기호 격자, 점 묶음 아이콘, 터미널 한 줄.
- 중간에 한 번 화면이 흰색으로 뒤집혀 검은 고정폭 글이 크게 타자돼요. 흑백만 쓰고 색은 없어요.

## 색
- 검정 #111111 80 · 밝은 회색 글 #EDEDED 12 · 꺼진 점 회색 #6B6B6B 6 · 켜진 점 흰색 #FFFFFF 2.
- 흰 화면 장면: 바탕 #EBEBEB, 글 #111111, 점 그림자 #BDBDBD.
- 강조는 색 대신 "켜짐": 같은 점 글자에서 강조할 부분만 흰색, 나머지는 회색.

## 글자
- 큰 글: 영문 Silkscreen(픽셀 대문자) + 한글 Galmuri11. 크기는 짧은 변의 14~22%, 자간 0.02em.
- 작은 글·캡션·로그: Geist Mono 400, 대문자, 짧은 변의 1.4~1.8%. 한글은 Galmuri11.
- 큰 글자를 점(원)으로 다시 그리고 싶으면 Galmuri11 로 쓴 글자를 캔버스에 그려 칸마다 표본을 떠서 원·네모·세모를 찍어요(아래 대표 장면 1).

## 질감과 모양
- 질감 없음. 모서리 0, 그림자 없음.
- 점 격자 바탕: 4u 간격 0.15u 점, 흰색 10%.
- 세로 실선 바탕(가루 장면): 3u 간격 1px 흰색 6%.
- 점 그림자: 같은 글자를 점 패턴으로 그려 오른쪽 아래(0.6u, 0.6u)로 밀고 회색.

## 움직임
- 112BPM. 픽셀 결이라 움직임은 짧고 단단하게(expo.out, 0.2~0.35초). 넘침 없음.
- 기호 격자는 반 박마다 글자를 무작위로 바꾸며(시드 난수) 5×5 → 화면 가득으로 퍼짐.
- 해상도 내리기: 매끈한 도형이 박마다 칸 크기 1u → 2u → 4u 로 계단처럼 거칠어지며 작아짐.
- 타자는 초당 10~12자, 블록 커서는 반 박마다 깜빡임.

## 전환
- 컷이 기본. 그다음 칸 덮기(blocks, 흑백 칸), 흰 화면이 작은 네모로 줄어들며 빠지는 확대(zoom) 반대 방향.

## 대표 장면

1. **가루가 모여 점 글자**
   ```
   // 글자를 오프스크린 canvas 에 Galmuri11 로 그려 cell 간격마다 표본 → 켜진 칸 목록 P[{x,y}]
   const R = M.rng(3);
   parts.forEach((p, i) => {                    // 가루 i 는 칸 P[i] 로 감
     const k = M.spring(t - (tGather + R() * .15), 'snappy');
     M.place(p.el, M.lerp(p.x0, P[i].x, k), M.lerp(p.y0 + fall(t), P[i].y, k));
     p.el.dataset.shape = M.at([[tGather, p.sym], [tGather + .3, 'circle'], [tGather + .45, 'square'], [tGather + .6, 'circle']], t);
   });
   ```
   떨어지는 동안 모양은 0·1·네모·세모·원 중 하나(시드 고정). 장면 쌓기 `title: scramble`, `number: scramble` 과 같은 결.
2. **지시선 주석**
   - 큰 점 글자를 회색으로 두고, 강조 칸 목록을 0.04초 간격으로 흰색. 그다음 SVG 가는 선을 `M.draw` 0.25초로 바깥으로 뻗고 끝에 고정폭 이름표를 `M.type` 으로.
   - 같은 글자 변형을 아래로 한 줄씩 쌓을 때는 위 줄이 회색으로 물러나고 새 줄만 밝게.
3. **흰 화면 고정폭 타자 + 점 그림자**
   ```
   line.textContent = M.type(txt, t, t0, 11);  caret: 글자 높이만 한 검은 네모, 반 박마다 깜빡
   shadow: 같은 글을 점 패턴(background radial-gradient 0.5u)으로 채워 translate(.6u,.6u)
   다음 줄: x 를 +W 에서 M.anim(... {d:.35, e:'outExpo'}) 로, 뒤에 가로 줄무늬(1px 선 6개) 잔상이 0.3초 남음
   ```
4. **터미널 로그 → 한 줄**
   - `frame: terminal` 창에 시각·[꼬리표]·내용 세 칸 로그를 줄당 0.05초로 흘려 화면을 채운 뒤, 카메라가 빠지며 작아지고 컷 → `$ 명령` 한 줄만 크게 타자. 마지막에 픽셀 가루 장이 작은 아이콘 네모로 오므라듦.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발자 도구·오픈소스 소개, 글꼴·디자인 자산 출시, 기술 회사 채용, 게임·레트로 브랜드.
- 피할 것: 컬러 그라디언트, 둥근 카드와 그림자, 손글씨, 사진 배경. 로그 화면은 분위기용 연출이라 실제 서버 주소나 계정 정보 같은 값은 넣지 않아요.
