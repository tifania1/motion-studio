# 옅은 회색 마크와 흘러드는 사진 타일 (콜라주·사진)

한 줄: 옅은 회색 위에 작은 마크 하나가 생기고, 화면보다 큰 소문자 글자 외곽선과 옅게 눌린 무늬가 그 뒤를 이어요. 사진 타일이 흐림을 끌며 미끄러져 와 한 장으로 멈추고, 어두운 판에서는 색 견본 사다리와 유화 결 카드가 차분히 흐르는 브랜드 필름.

## 보는 느낌
- 바탕은 거의 흰 옅은 회색이고 여백을 아주 넓게 써요. 한 화면에는 마크 하나, 낱말 한 줄, 사진 한 장처럼 주인공을 하나만 둬요.
- 크기를 크게 벌려요. 화면 높이만 한 글자 조각(점 두 개와 기둥 두 개처럼 단순한 획)이 나온 바로 다음 컷에는 작고 가는 낱말 한 줄만 남겨요.
- 앞부분은 아이덴티티를 보여 줘요. 마크, 앵커 점으로 그린 글자 외곽선, 옅은 엠보스 무늬, 색 견본 사다리, 숫자 벤토 카드가 이어져요.
- 뒷부분은 사진 콜라주예요. 가운데 사진 한 장 둘레 가장자리에 작은 사진과 캡션이 붙고, 거리 광고판이나 정류장 포스터 같은 실제 쓰임 장면으로 넓혀 가요.
- 중간중간 숯빛 판으로 바뀌어 앱 화면 폰 여러 대, 유화 결 카드 줄, 시안 모음을 보여 줘요.

## 색
- 옅은 회색 70 · 먹색 글자와 사진 25 · 라벤더 5.
- 바탕 #EBEBEA, 글자 #151515. 어두운 판은 #151515 바탕에 #EBEBEA 글자.
- 라벤더 #9C98E8 은 문장 한 줄 안에서 뒤쪽 낱말 하나에만 써요. 라벤더 바탕에 글자를 올리면 먹색.
- 색 견본 장면에서만 색을 활짝 열어요. 노랑 #F1C232, 분홍 #E2558C, 초록 #2FA57E, 파랑, 보라를 각각 진한 데서 옅은 데로 5~7칸 사다리로 놓아요.
- 엠보스 무늬는 바탕보다 5~6%만 밝고 어두운 선이라 거의 안 보일 만큼 옅어요.

## 글자
- Geist 하나로 다 해요(한글은 Noto Sans KR Medium·Bold). 낱말은 소문자를 기본으로 써요.
- 마크 옆 이름은 Geist 700, 자간 -0.02em.
- 조용한 낱말 한 줄은 Geist 300, 자간을 0.12~0.2em 으로 넓게 띄우고 짧은 변의 5% 안팎으로 작게.
- 소식·문장은 Geist 300~400, 왼쪽 정렬. 제목은 짧은 변의 7%, 아래 설명은 2% 로 작게 두 줄.
- 거대한 글자 조각은 Geist 900 을 화면 높이의 80~110% 로 키워 가장자리에서 잘려도 괜찮아요.
- 캡션은 짧은 변의 1.4% 정도로 아주 작게, 사진 옆 빈자리에 붙여요.

## 질감과 모양
- 질감 없이 매끈하게. 거친 맛은 움직이는 순간의 방향 흐림으로만 줘요.
- 사진 카드는 모서리 0.6u, 테두리와 그림자 없이 사진 그대로.
- 외곽선은 1px 먹색 머리카락 선. 꺾이는 곳마다 지름 0.5u 검은 앵커 점.
- 엠보스 무늬는 마크 모양을 크게 겹쳐 반복하고, 위쪽에 흰 1px, 아래쪽에 먹색 6% 1px 를 엇갈려 눌린 느낌을 내요.

## 움직임
- 96BPM, 차분하게. 한 장면에 2~3초 머물러요.
- 들어올 때는 power3.out 으로 빠르게 와서 길게 멈춰요. 나갈 때는 대부분 컷이에요.
- 사진 타일이 미끄러질 때만 이동 방향으로 흐림 6~10px 을 얹었다가 멈추면서 0으로 풀어요.
- 기호가 글자로 맞춰지는 장면은 세로 흐림을 끌며 0.5초 동안 기호를 갈아 끼우고, 왼쪽 글자부터 차례로 제자리에 멈춰요.
- 유화 결 카드 줄은 4초에 카드 한 장 너비만큼 아주 천천히 옆으로 흘러요.

## 전환
- 컷이 기본이에요. 사진 장면끼리는 흐림을 끄는 휙 밀기(whip)로 잇고, 마지막 마크 장면만 페이드로 들어와요.
- 장면 쌓기: cut → whip → fade.

## 대표 장면

1. 마크에서 외곽선, 엠보스 무늬로
   ```js
   // 작은 마크가 톡 → 이름 한 줄 → 거대한 외곽선 → 옅은 엠보스 무늬
   const k = M.spring(t - .2, 'snappy');
   M.place(mark, cx, cy, {s: k, o: Math.min(1, k * 2)});
   M.draw(outline, M.ease.inOutCubic(M.prog(t, M.beat(4), 1.6)));   // 머리카락 선
   anchors.forEach((a, i) => M.place(a, a._x, a._y, {s: M.spring(t - M.beat(4) - i * .08, 'snappy')}));
   // 엠보스 무늬는 S.ambient 에서 아주 느리게 돌기만
   S.ambient(t => M.place(emboss, cx, cy, {r: t * .6, o: .9}));
   ```
2. 기호에서 맞춰지는 낱말
   - 장면 쌓기에서는 title: scramble 로 큰 글이 기호에서 글자로 맞춰져요. 직접 만들 때는 이렇게:
   ```js
   const chars = S.chars(word), rnd = M.rng(7), sym = '?#$%&@!';
   chars.forEach((c, i) => {
     const lock = t0 + .25 + i * .05;
     c.textContent = t < lock ? sym[Math.floor(rnd() * sym.length + t * 30) % sym.length] : c.dataset.ch;
     c.style.filter = t < lock ? 'blur(0 6px)' : 'none';   // 세로 흐림 느낌은 scaleY + blur 로
   });
   ```
   - 맞춰진 다음 컷은 같은 화면에 자간 0.16em 의 가는 낱말 한 줄만 남겨요.
3. 흘러드는 사진 타일과 가장자리 캡션
   ```js
   tiles.forEach((p, i) => {
     const x = M.anim([[0, p._from], [t0 + i * .1, p._to, {d: .7, e: 'outCubic'}]], t);
     const v = Math.abs(x - M.anim([[0, p._from], [t0 + i * .1, p._to, {d: .7, e: 'outCubic'}]], t - 1/30));
     M.place(p, x, p._y, {blur: Math.min(10, v * .4)});
   });
   // 나머지 타일이 밖으로 빠지면 가운데 한 장만 남기고, 모서리에 작은 사진과 캡션을 0.3초 늦게 붙여요
   ```
   - 장면 전환은 `S.tr.whip` 으로 같은 흐림 결을 이어요.
4. 어두운 판의 색 사다리와 유화 카드 줄
   - s-paper 장면(숯빛)에 색 견본 사다리를 칸마다 0.04초씩 늦게 `M.box` 로 위에서 아래로 펼치고, 다음 컷에 숫자 벤토 카드(number: scramble)를 둬요.
   - 이어 키 큰 카드 5~6장을 한 줄로 세우고 `S.ambient(t => row.style.transform = `translateX(${-t * cardW / 4}px)`)` 로 천천히 흘려요. 가운데 카드 위에만 작은 흰 종이 한 장을 띄워요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 리뉴얼·아이덴티티 소개, 금융·생활 서비스 브랜드 필름, 투자 유치·출시 소식, 캠페인 사진과 앱 화면을 함께 보여 줄 때, 옥외 광고·포스터 시안 공개. 40~70초의 긴 호흡에 잘 맞아요.
- 피할 것: 종이·그레인 같은 거친 질감, 손그림 선, 굵고 빽빽한 대문자 제목, 한 장면에 강조색 여러 개(색 견본 장면은 예외), 반 박마다 몰아치는 컷, 사진에 두꺼운 테두리나 기울인 배치.
- 한글 낱말도 2~4자로 짧게 쓰면 넓은 자간의 가는 줄이 잘 살아요.
