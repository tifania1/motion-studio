# 접사 챕터 노드 캔버스 (제품 UI)

한 줄: 그레인 낀 흐릿한 자연 접사 사진 위에 작은 흰 글씨로 '#번호 단계 이름'이 뜨고, 컷 한 번에 어두운 노드 캔버스로 들어가 카드가 풀리고 복제되고 민트 선으로 이어지는 단계별 사용법 필름.

## 보는 느낌
- 두 가지 판이 번갈아 와요. 하나는 화면을 꽉 채운 자연 접사 사진(날개 무늬처럼 큰 색 덩어리와 굵은 검은 맥) 위 작은 흰 글씨 한 줄, 다른 하나는 거의 검은 노드 캔버스예요.
- 접사 사진은 초점이 일부러 빗나가 있고 그레인이 굵게 껴서 물감 같은 질감으로 보여요. 글씨는 화면 높이 4% 안팎으로 작게, 한가운데.
- 캔버스는 왼쪽에 얇은 아이콘 막대, 위에 작은 탭과 알약 버튼, 아래 가운데 작은 도구 막대가 깔린 앱 창이에요. 가운데에 노드 카드가 한 장에서 시작해 넷, 여럿으로 늘어나요.
- 챕터 사진의 색이 다음 캔버스 속 그림 카드의 색과 같아요. 주황 사진 다음엔 주황 그림, 파랑·주황 사진 다음엔 파랑·주황 그림, 초록 사진 다음엔 초록 그림. 색으로 단계를 묶어요.

## 색
- 캔버스 장면: 검정 #131313 70 · 카드 회색 #2A2A2C 20 · 카드 속 그림과 글자 10.
- 연결선과 출력 점은 민트 #8ED6B4, 입력 점은 분홍 #E07BE0. 도구 막대의 고른 도구 하나만 옅은 연두로 켜요.
- 챕터 사진 팔레트(단계마다 하나): 분홍 #D99AAE·갈색 #5A3A2A / 주황 #F0A23A·연두 #9FC79A / 파랑 #3D74C8·녹슨 주황 #E0662A·크림 / 초록 #4E9B4E·연두.
- 글자는 늘 흰색 #ECECEA, 흐린 글자는 56%.

## 글자
- 산세리프 Geist(한글 Noto Sans KR Medium), 굵기 400~500, 자간 −0.01em. 큰 제목은 쓰지 않아요.
- 챕터 글씨: '#번호' 다음 낱말 하나 또는 둘. 첫 낱말이 뜨고 한 박(0.6초) 뒤 둘째 낱말이 옆에 붙어요.
- 카드 안 이름표·메뉴 항목은 짧은 변의 1.6~2%로 아주 작게. 해상도 같은 숫자는 Geist Mono.

## 질감과 모양
- 그레인 0.12(초당 12번). 접사 사진 판에서 가장 잘 보이고, 캔버스 위에서도 아주 옅게 남아 두 판을 이어 줘요.
- 노드 카드: #2A2A2C, 1px 밝은 회색 테두리(흰색 10%), 모서리 1.2u, 위에 작은 이름 줄, 가운데 그림, 아래 '+ 입력 추가'와 테두리 버튼.
- 카드 양옆에 작은 원 점(입력 분홍, 출력 민트). 연결선은 2px 민트 곡선, 끝이 점에 붙어요.
- 오른쪽 클릭 메뉴: 더 짙은 회색, 모서리 0.8u, 항목 5~6줄, 커서가 올라간 줄만 살짝 밝아짐.

## 움직임
- 96BPM, 보통 속도. 들어오는 건 power3.out 으로 부드럽게 멈춰요.
- 챕터 판은 2~3초. 사진은 그 동안 1.04배쯤 아주 천천히 다가가고 옆으로 조금 흘러요.
- 캔버스 장면은 4~5초. 커서는 매끈한 곡선으로 움직이고 누를 때 0.1초 작아졌다 돌아와요.
- 카드가 늘어날 땐 한 장씩 0.08초 간격으로 톡톡 생기고, 격자 판은 원래 카드 옆에서 가로로 열려요.
- 마지막에 카메라가 캔버스 쪽으로 1.3배쯤 천천히 다가가요.

## 전환
- 챕터 판과 캔버스 사이는 컷. 단계 이름이 장면을 갈라 주니 따로 꾸미지 않아요.
- 캔버스 안에서 상태가 바뀔 때(카드 넷 → 확대된 넷)는 흐림 전환을 짧게. 장면 쌓기: cut → cut → blur.

## 대표 장면
1. **접사 챕터 판**
   ```
   // 흐린 접사 사진을 꽉 채우고 아주 천천히 다가감, 글씨는 낱말씩 붙음
   S.ambient(t => {
     M.place(photo, cx, cy, { s: 1 + t * .015, x: t * -4 });   // 3초에 4% 남짓
     photo.style.filter = 'blur(calc(var(--u) * .6)) saturate(1.1)';
   });
   const w = S.$$('.chapter .word');                          // ['#1', '낱말', '낱말']
   w.forEach((el, i) => M.place(el, null, null, { o: M.prog(t, i < 2 ? .2 : .2 + M.beat(1), .3) }));
   // 질감은 스타일 look 의 그레인이 덮어 줘요
   ```
2. **메뉴로 풀리는 카드**
   - 가운데 노드 카드 한 장(`M.spring(t, 'smooth')` 로 살짝 커지며 등장). `M.Cursor` 를 카드 그림 위로 옮겨 `M.cursorAt` 에서 메뉴를 톡 열어요(`s: .96 → 1`, `o: 0 → 1`, 0.15초).
   - 마지막 항목을 누르면 카드 오른쪽에 반투명 회색 판이 `M.box` 로 너비 0에서 열리고, 그 안에 그림 카드 6장이 2×3 으로 0.08초 간격 등장. 그림 색은 앞 챕터 사진 색에 맞춰요.
3. **넷으로 늘어난 카드와 오른쪽 클릭**
   - 카드 넷을 2×2 로 두고 `S.tr.blur` 로 한 단계 가까이 다가간 장면으로 넘어가요. 커서가 카드 하나를 누르면 긴 메뉴가 열리고, 고른 줄 끝 작은 화살표에서 하위 메뉴가 옆으로 열려요.
4. **민트 선으로 이어지는 흐름**
   ```
   // 출력 점에서 오른쪽 카드들로 곡선을 차례로 그림
   links.forEach((p, i) => M.draw(p, M.ease.outCubic(M.prog(t, .3 + i * .25, .5))));
   cards.forEach((c, i) => M.place(c, null, null, { o: M.prog(t, .6 + i * .25, .3) }));
   M.place(canvas, cx, cy, { s: M.anim([[0, 1], [.4, 1.3, { d: 2.4, e: 'inOutCubic' }]], t) });
   ```
   - 아래에 키캡 버튼 둘(짙은 회색, 모서리 0.8u)이 떠서 하나가 눌리면 카드 하나가 흐려지며 빠지고 남은 선이 다시 그어져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 단계별 기능 사용법, 노드·워크플로 도구 소개, 이미지 생성 도구 시연, 업데이트 노트 영상, 튜토리얼 시리즈 오프닝. 단계 셋 안팎, 20초 남짓.
- 피할 것: 큰 굵은 제목, 밝은 흰 바탕 UI, 강조색 여러 개(민트 선과 분홍 입력 점만), 선명하고 매끈한 사진을 챕터 판에 쓰기, 빠른 몽타주 컷.
- 챕터 사진은 원본을 따라 하지 말고 꽃잎·잎맥·깃털·물결처럼 큰 색 덩어리가 있는 접사를 새로 골라 흐리게 써요.
