# 스프레이 점묘 색면 (그래픽·도형)

한 줄: 검은 화면 위로 하늘색 점묘 가루가 스프레이처럼 쓸고 지나가고, 색 네모 조각이 글 위에 툭툭 겹쳐 쌓이다 한 색이 화면을 덮어요. 색면 위엔 큰 숫자와 회색 에어브러시 획.

## 보는 느낌
- 두 가지 화면이 번갈아 나와요. 검은 화면(점묘 가루·굵은 도형·하늘색 글)과, 꽉 찬 원색 색면(큰 숫자·회색 에어브러시 획).
- 글은 왼쪽 정렬로 화면 폭을 거의 다 쓰고, 도형과 색 조각은 글을 일부러 가리며 겹쳐요. 깔끔함보다 거리 포스터 같은 거친 결.
- 매끈한 디지털 도형(네모·타원)과 지저분한 점묘·스프레이가 한 화면에 같이 있어요.

## 색
- 검은 장면: 검정 #111111 55 · 하늘 점묘 #35B8EA 25 · 회색 글·도형 #D9D9D9 20.
- 색면 장면: 바탕 한 색 80(노랑 #E6F25A, 초록 #48D06A, 하늘 #35B8EA) · 회색 에어브러시 12 · 검정 글자 8.
- 주황 #E8693F 은 색 네모 조각에만.
- 새로 들어온 글은 하늘색, 반 박 뒤 회색(검은 장면) 또는 검정(색면 장면)으로 가라앉아요.

## 글자
- 그로테스크 500(Archivo 폭 95% + Noto Sans KR 500). 굵게 쓰지 않고 크기로만 밀어붙여요.
- 자간 −0.04em, 줄 간격 0.95. 제목은 짧은 변의 13% 이상, 숫자는 화면 폭의 80%까지.
- 위쪽 작은 정보 줄은 대문자 + 작은 네모·동그라미 기호를 글머리처럼(■ 날짜 ● 주소).

## 질감과 모양
- 그레인 0.08(초당 12번 바뀜). 화면 전체는 거의 매끈하고 거친 결은 점묘·에어브러시에만.
- 점묘: 지름 0.4~0.9u 타원 점(조금씩 기울임)을 시드 난수로 수천 개, 덩어리 가운데는 빽빽하고 가장자리는 성기게.
- 에어브러시 획: 굵기 6~10u 선을 `blur(1.5u)` 로 흐리고 가장자리에 같은 색 점묘를 흩뿌림.
- 모서리 0. 색 네모는 각지고 그림자 없음.

## 움직임
- 124BPM, 빠름. 도형·네모는 박이나 반 박에 맞춰 0.15초 만에 툭(expo.out, 크기 0.85 → 1).
- 점묘 덩어리는 박과 상관없이 일정 속도로 흐름(화면을 2~3초에 가로지름).
- 큰 숫자: 반 박 동안 화면을 채운 뒤 0.4초에 위로 작아지며 설명 줄 자리를 만듦.
- 글줄은 아래에서 올라오며(rise) 하늘색으로 들어오고 0.3초 뒤 색이 가라앉음.

## 전환
- 칸 덮기(blocks)가 기본: 색 네모들이 차례로 덮었다 걷힘. 그다음 컷, 그리고 한 색이 화면을 덮는 플러드(flood).

## 대표 장면

1. **스프레이 점묘가 쓸고 지나감 + 도형 찍기**
   ```
   const R = M.rng(11); const dots = 한 덩어리당 1500개 {x, y, r, rot} (가우시안처럼 가운데 몰림)
   // canvas 하나에 S.ambient 로 매 프레임 다시 그림. 덩어리 중심 x = -0.3W + (t - t0) * .45W
   S.ambient(t => { ctx.clearRect(...); dots.forEach(d => ellipse(cx(t) + d.x, d.y, d.r, d.r * .7, d.rot)); });
   // 도형: 박마다 하나씩 M.place(shape, x, y, { s: .85 + .15 * M.spring(t - tb, 'snappy') })
   // 색: M.color('#35B8EA', '#D9D9D9', M.prog(t, tb + M.beat(1), .25))
   ```
   도형은 원·네모·소용돌이·물방울 같은 기본 도형으로만 짜요. 영상 속 워드마크 모양을 따라 그리지 않아요.
2. **색 네모가 쌓이다 화면을 덮음**
   - 네모 6~10개를 시드 난수 자리·크기로 정하고 반 박마다 하나씩 `scale(.85 → 1)` 0.15초. 안에는 회색 점묘 또는 짧은 굵은 획 무늬.
   - 마지막 네모는 `M.box(el, {w: M.anim(...W*1.1), h: ...H*1.1})` 로 화면을 덮고 바로 그 색면 장면이 시작. 장면 쌓기에서는 `S.tr.blocks` 로 같은 결.
3. **색면 위 큰 숫자**
   ```
   num: S.fit 로 화면 폭 80% → tB + M.beat(1) 에 M.anim 으로 크기 .45배, y 를 위로
   label: S.fx.rise(label, tB + M.beat(1) + .1)
   // 10k+ → 100k+: '0' 하나를 span 으로 끼워 폭을 0 → 제 폭 M.spring('snappy'), 색은 #D9D9D9 → #111
   // 에어브러시 획: 큰 SVG path 2~3개에 blur, M.drift 처럼 천천히 x·회전만
   ```
   다음 숫자는 아래에서 올라오고(`M.rise`), 같은 순간 바탕색을 컷으로 바꿔요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 행사·컨퍼런스 안내, 숫자로 보는 성과, 페스티벌·전시 홍보, 젊은 브랜드 런칭.
- 피할 것: 세리프 글꼴, 부드러운 그라디언트, 둥근 모서리 카드, 밝은 바탕으로만 짜기. 숫자(참가자·연사 수 등)는 확인된 값만 써요.
