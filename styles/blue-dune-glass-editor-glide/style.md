# 푸른 언덕 편집기 활공 (제품 UI)

한 줄: 옅은 하늘 아래 코발트 물결 언덕이 겹겹이 누운 바탕 위에 밝은 디자인 편집기가 비스듬히 떠 있고, 카메라가 레이어 목록에서 캔버스, 속성 패널로 천천히 미끄러지며 파고드는 차분한 제품 투어예요.

## 보는 느낌
- 바탕은 위쪽이 아주 옅은 회청색 하늘이고, 아래로 코발트·청보라 물결 언덕이 서너 겹 겹쳐 흘러요. 지평선 근처엔 연두·연노랑 빛이 살짝 비쳐요.
- 그 위에 밝은 편집기 창 하나가 비스듬히 기운 채 떠 있어요. 왼쪽엔 레이어 목록, 가운데엔 달력 같은 카드 시안 여러 장, 오른쪽엔 속성 패널.
- 카메라는 늘 창에 가까이 있어서 화면 안에 창 전체가 다 들어오는 일이 드물어요. 한쪽 가장자리는 잘리고, 초점 밖은 부드럽게 흐려요.
- 장면 사이에 창을 치우고 언덕만 남긴 숨 고르는 컷을 넣어요. 그때 유리 알약 도구 막대 하나나 펜 곡선 하나만 떠요.

## 색
- 하늘·언덕 바탕 60 · 흰 패널 30 · 먹색 글자 8 · 남보라 2.
- 하늘 #E8EBF2, 언덕 코발트 #2E4BC6, 청보라 #8FA6E4, 지평선 빛은 연두 #BFE0CF·연노랑 #EDE6B8 를 아주 옅게.
- 패널 #F8F8FA, 글자 #1C1E26, 칸 바탕은 #EEEFF3.
- 남보라 #5A57E6 은 고른 줄, 켜진 토글, 선택 칸, 앵커 점에만. 고른 줄 글자는 흰색.

## 글자
- Geist 와 Noto Sans KR. 대부분 작은 UI 글씨(400~500)이고, 창 밖에 띄우는 문구도 600 정도로 차분하게.
- 자간 −0.02em, 문구는 한 줄 짧게. 크기는 짧은 변의 4~6%.
- 패널 안 수치·이름표는 짧은 변의 1.5~2%로 작게, 숫자는 고른 폭으로 보이게 `font-variant-numeric: tabular-nums`.

## 질감과 모양
- 그레인이나 종이 질감 없이 매끈해요. 깊이는 초점 흐림과 부드러운 그림자로 내요.
- 패널·팝오버: 흰 바탕, 모서리 1.6u, 아주 옅은 회색 테두리 1px, 넓고 옅은 그림자 한 겹.
- 도구 막대: 흰색 70% 반투명 유리 알약 + 블러, 아이콘은 둘씩 묶어 작은 알약 안에. 고른 아이콘 둘레엔 남보라 빛이 살짝 번져요.
- 펜 곡선: 1.5px 먹색 선, 앵커는 흰 속 남보라 테두리 작은 정사각형, 핸들 끝은 작은 원.

## 움직임
- 96BPM, 느림. 카메라 이동은 `power3.inOut` 으로 4~6초에 걸쳐 한 번, 멈춤 없이 천천히 감속해요.
- 창은 3D 로 기운 채(rotateY −16°, rotateX 6° 안팎) 카메라 이동과 함께 기울기가 조금씩 풀려요(−16° → −8°).
- 팝오버·도구 막대는 0.4초에 흐림 6px → 0, 크기 0.94 → 1 로 맺혀요. 닫힐 땐 0.25초 페이드.
- 언덕은 따로 계속 움직여요. 겹마다 다른 속도로 아주 천천히 일렁여요(8~12초 주기).

## 전환
- 흐림 전환(blur)이 기본. 카메라가 창 깊숙이 들어가다 흐려지면 다음 장면이 흐림에서 맺혀요.
- 옆 패널로 넘어갈 땐 밀어내기(push), 마지막 마크 장면만 느린 페이드. 장면 쌓기: blur → push → fade.

## 대표 장면

1. **비스듬한 편집기를 훑으며 파고들기**
   ```
   // 창은 perspective 부모 안에서 기울이고, 카메라 대신 창을 움직여요
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, 0, 5));
     win.style.transform = `translate(${M.lerp(18, -22, k)}%, ${M.lerp(6, -4, k)}%)`
       + ` scale(${M.lerp(1.1, 1.7, k)}) rotateY(${M.lerp(-16, -8, k)}deg) rotateX(6deg)`;
     edgeBlur.style.opacity = .5 + k * .4;   // 화면 가장자리 초점 흐림
   });
   ```
   레이어 목록에서 커서(`M.Cursor`)가 한 줄을 누르면(`M.cursorAt`) 그 줄이 남보라로 칠해지고, 카메라는 그 줄에 맞는 캔버스 카드 쪽으로 계속 흘러가요.

2. **유리 도구 막대와 펜 곡선**
   ```
   const k = M.spring(t - t0, 'smooth');
   M.place(bar, cx, cy * .55, {o: k, s: .94 + k * .06, blur: (1 - k) * 6});
   icons.forEach((ic, i) => M.place(ic, 0, 0, {o: M.prog(t, t0 + .3 + i * M.beat(.5), .25)}));
   M.draw(curve, M.ease.inOutCubic(M.prog(t, t1, 1.2)));   // 앵커·핸들은 선 끝을 따라 톡톡
   ```
   펜 아이콘이 눌리면 막대 안 아이콘 묶음을 0.3초 흐림 교차로 다른 도구 묶음으로 바꿔요. 언덕 위 빈 하늘에 막대 하나만 두는 게 이 장면의 숨이에요.

3. **속성 패널 팝오버와 굴러가는 수치**
   - 속성 패널에 바짝 붙은 채(scale 2 안팎) 색 고르기나 효과 팝오버를 `M.spring(t - ti, 'snappy')` 로 0.4초에 열어요.
   - 커서가 슬라이더 손잡이를 끌면 채운 막대를 `M.box(fill, {w: W * v})` 로 늘리고, 옆 수치는 `Math.round(M.lerp(a, b, v))` 로 같이 바뀌어요. 장면 쌓기에서는 number: count 로 같은 결이 나요.
   - 색 견본 판은 칸마다 `M.prog(t, ti + i * .02, .2)` 로 물결처럼 켜요.

4. **언덕 위 마크 하나로 닫기**
   - 창이 흐림 전환(`S.tr.blur`)으로 빠지면 언덕만 남고, 가운데 둥근 사각 마크 타일이 아래에서 2u 올라오며 맺혀요(그림자 한 겹). 2초쯤 그대로 머물러요.
   - 언덕 바탕: SVG path 4겹을 `linear-gradient` 로 칠하고 `S.ambient` 안에서 겹마다 `y = Math.sin(t * .6 + i) * u * .6` 로 일렁이게.
