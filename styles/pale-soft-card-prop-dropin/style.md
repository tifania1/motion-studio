# 소품이 내려앉는 여행 카드 (3D·사물)

한 줄: 옅은 회색 위에 그림자가 부드러운 흰 카드와 폰 화면이 차분히 떠 있고, 사이사이 3D 소품이 화면 한가운데로 커졌다가 카드 아이콘 크기로 쏙 줄어들어 자리를 찾아요. 장면은 물결 한 번이나 흙먼지 한 줄기로 넘어가요.

## 보는 느낌
- 바탕은 옅은 회색 하나로 끝까지 가요. 무늬도 질감도 없고, 깊이는 카드와 소품 아래 넓고 흐린 그림자로만 만들어요.
- 장면은 두 크기를 오가요. 하나는 소품 한 개가 화면 한가운데에서 짧은 변의 40~60%만큼 크게 보이는 장면, 다른 하나는 작은 카드 목록이나 폰 한 대가 여백 많이 남기고 놓인 장면이에요.
- 소품은 늘 카드 아이콘과 같은 물건이에요. 크게 보였다가 줄어 카드 왼쪽 아이콘 자리에 앉거나, 반대로 카드 아이콘에서 커져 나와요. 이 크기 오가기가 장면을 이어 줘요.
- 폰은 화면 높이의 80% 안팎, 정면으로 반듯하게 서 있어요. 기울이거나 돌리지 않아요.
- 한 화면에 글은 카드 안 짧은 한 줄이나 소품 아래 두 줄 설명 정도만 둬요.

## 색
- 회색 바탕 75 · 흰 카드 15 · 먹색 글자 7 · 진분홍 3.
- 바탕 #ECEBEC, 카드 #F7F6F7, 글자 #222222, 보조 글자는 먹색 60%.
- 진분홍 #D52458 은 오늘 날짜 점, 선택된 탭 같은 아주 작은 표시에만 써요. 그 위 글자는 흰색.
- 나머지 색은 소품이 데려와요: 물결 청록 #2FA7A0, 종이봉투·지구본 황토 #C69A5B, 자동차 빨강. UI 에는 이 색들을 칠하지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 둥글고 담백한 산세리프예요.
- 카드 제목 600, 짧은 변의 2.5~3%. 카드 아래 설명은 400, 먹색 60%, 제목의 75% 크기.
- 큰 낱말은 볼록한 알약 버튼 속 한 낱말처럼 아껴 써요. 500 굵기로 짧은 변의 10% 안팎.
- 정렬은 가운데. 카드 안에서는 아이콘 옆 왼쪽 정렬, 줄 간격 1.3.

## 질감과 모양
- 질감은 쓰지 않아요. 매끈한 바탕에 부드러운 그림자만 둬요.
- 카드: 모서리 `--u` × 1.6, 테두리 없음, 그림자 두 겹(가깝고 옅은 것 하나, 아래로 길고 아주 흐린 것 하나).
- 알약 버튼: 바탕과 같은 회색으로 볼록하게. 왼쪽 위는 흰빛 그림자, 오른쪽 아래는 회색 그림자를 넣은 양각이에요.
- 일정 세로줄은 1px 회색 선, 날짜 점은 지름 1.6u 진분홍 원.
- 3D 소품은 반들하고 사실적인 사물(봉투, 빵, 과일, 가방, 자동차, 지구본, 작은 섬 디오라마). 바닥에 흐린 접지 그림자를 꼭 깔아요.

## 움직임
- 104BPM, 보통 빠르기. 장면 하나가 1~2초 머물러요.
- 소품이 커지고 줄어드는 건 `power3.out` 0.6초, 떨어지는 소품은 `back.out(1.3)` 으로 바닥에 닿을 때 살짝 튀어요.
- 카드 목록은 가운데 한 장에서 시작해 위아래로 0.15초 간격씩 맺혀요. 흐림 6px, 투명도 0.3에서 선명하게 바뀌어요.
- 일정 카드는 깊이(크기 0.9~1.05)와 x 위치를 조금씩 다르게 두고 떠 있다가, 1초 동안 한 줄로 모여요. 카메라는 그 사이 위로 천천히 흘러요.
- 빠른 건 소품이 지나갈 때뿐이에요. 공과 자동차는 0.4초 만에 화면을 가로지르고 뒤에 풀 자국이나 흙먼지를 끌어요.

## 전환
- 물결 와이프(wipe): 청록 물결이 옆에서 화면을 덮고 지나가면 다음 장면이 드러나요.
- 크기 오가기(iris): 소품이 줄어 카드 아이콘이 되거나, 카드 아이콘에서 소품이 커져 화면을 채워요.
- 흐림(blur): 카드 목록이 맺힐 때. 나머지는 컷.
- 장면 쌓기: wipe → iris → blur → cut.

## 대표 장면
1. **봉투에 담기고 카드가 됨**
   ```
   // 소품 i 가 위에서 떨어져 봉투 입구에 닿음
   const y = M.anim([[0, -H * .3], [t0 + i * .35, bagY, {d: .5, e: 'outBack'}]], t);
   M.place(item[i], bagX + dx[i], y, {r: M.anim([[0, -20], [t0 + i * .35, 0, {d: .5}]], t)});
   // 다 담기면 봉투가 줄어 카드 아이콘 자리로
   const k = M.ease.outCubic(M.prog(t, tShrink, .6));
   M.place(bag, M.lerp(cx, iconX, k), M.lerp(cy, iconY, k), {s: M.lerp(1, .12, k)});
   // 카드 바탕은 아이콘이 앉는 순간 흐림에서 맺힘
   M.place(card, cx, iconY, {o: k, blur: (1 - k) * 6});
   ```
   이어서 위아래 카드 셋을 같은 방식으로 0.15초씩 늦춰 맺히게 해요. 장면 쌓기에서는 title: blur 와 card: shadow 가 이 결을 따라가요.
2. **일정 세로줄 정렬**
   - 왼쪽에 날짜 칸과 1px 세로선, 오른쪽에 카드 4장. 처음엔 카드마다 `s` 0.9~1.05, x 를 ±6u 엇갈려 두고, `k = M.spring(t - t0, 'smooth')` 로 한 줄에 모아요.
   - 오늘 날짜 점은 `M.place(dot, x, y, {s: M.spring(t - t1, 'pop')})` 로 톡. 카메라는 전체를 `y -= t * H * .02` 로 천천히 올려요.
3. **물결이 소품을 남기고 폰이 감쌈**
   - 청록 물결(흐린 그라디언트 덩어리 + 흰 물보라 점)을 `S.tr.wipe` 결로 옆에서 덮고 지나가게 하고, 지나간 자리에 섬 디오라마 소품을 남겨요.
   - 소품을 0.6초에 30%로 줄여 화면 위쪽에 두고 아래 두 줄 설명을 `title: blur` 로 맺히게 한 뒤, 폰 틀을 아래에서 `M.spring(t - t2, 'smooth')` 로 올려 소품과 설명을 화면 안에 담아요(frame: phone).
4. **점이 모여 지구본, 지구본은 알약 속으로**
   - 둥근 얼굴 사진 점 12개를 `M.rng(7)` 로 흩어 놓고 나선을 그리며 가운데로 모아요(`r = M.lerp(r0, 0, k)`, `a = a0 + k * 2`). 다 모이면 그 자리에서 지구본 소품이 `S.tr.iris` 결로 커져요.
   - 지구본을 왼쪽으로 옮기며 줄이고, 볼록한 알약 버튼이 그 둘레에 맺혀 지구본이 버튼 아이콘이 돼요. 버튼 옆 낱말은 마지막에 0.3초 늦게.
   - 엔딩: 일정 카드 위로 자동차 소품이 오른쪽에서 들어와 멈췄다가, 반대쪽으로 0.4초에 빠지며 흙먼지 띠(흐린 갈색 덩어리 여러 개, 뒤로 갈수록 크고 옅게)를 남기고, 먼지가 걷히면 가운데에 마크가 남아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 여행·예약 앱 소개, 일정·예약 관리 기능 투어, 부가 서비스 여러 개를 하나씩 훑을 때, 생활 서비스 업데이트 소식, 친근한 앱 런칭.
- 피할 것: 어두운 바탕, 네온이나 빛 번짐, 굵고 큰 제목만으로 화면 채우기, 거친 질감·그레인, 진분홍을 넓게 칠하기.
- 소품은 장면마다 하나만 크게 보여 줘요. 여러 개가 함께 나올 땐 작게 흩어 두거나 봉투처럼 한 그릇에 담아요.
