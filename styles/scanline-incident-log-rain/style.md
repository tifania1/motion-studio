# 주사선 장애 로그 (시네마틱)

한 줄: 주사선이 낀 어두운 로그 화면을 파란 검사 띠가 한 줄씩 훑고, 오류가 잡히면 화면이 붉게 물들며 유리 알림이 떠요. 넓은 대문자 제목은 TV 잡음 위에서 쳐지고, 끝에는 초록 코드 조각이 비처럼 흩어지는 장애 모니터링 필름이에요.

## 보는 느낌
- 거의 검은 바탕에 회색 고정폭 로그가 빽빽하게 깔려요. 화면은 살짝 기울어 있고, 카메라가 아주 천천히 위로 흘러요. 늘 주사선과 옅은 그레인이 덮여 있어 오래된 감시 모니터를 들여다보는 기분이에요.
- 이야기는 색으로 흘러가요: 회색 로그 → 파란 검사 → 붉은 오류 → 초록 코드 비 → 파란 코드 → 어둠 속 마무리.
- 큰 글은 한 화면에 한 줄만. 로그 장면 사이사이 TV 잡음 화면에 넓은 대문자 제목, 어둠 속 가는 산세리프 두 낱말이 끼어들어요.
- 알림·버튼 같은 UI 는 딱 하나만 화면 가운데 띄워요. 둘레는 로그가 꽉 채우고 있어요.

## 색
- 검정 바탕 #0F1012 65 · 회색 로그 글자 20 · 신호색 15.
- 글자 흰빛 #E4E6E8, 로그는 같은 흰빛 55~70%.
- 파랑 #4DA8E8: 검사 띠, 강조 줄, 파란 코드 장면. 띠는 18~25% 투명에 1px 선 두 줄로 위아래를 그어요.
- 빨강 #E5483D(accent): 오류 줄 띠, 낱말을 덮는 상자, 괄호 테두리, 거절 버튼. 오류 장면 바탕은 붉은 밤색 #2B1814(paper).
- 초록 #3DD66B 는 코드 비와 수락 버튼에만, 노랑 #F2B33D 는 오류 창 속 작은 버튼 하나에만 써요.
- 한 장면에 신호색은 한 가지만 주인공으로.

## 글자
- 로그·코드: Geist Mono 400, 짧은 변의 3~4%. 줄 간격 1.7 로 넉넉하게, 왼쪽 정렬.
- 넓은 대문자 제목: Archivo 700, 너비 125%(가장 넓게), 자간 +0.08em. 짧은 변의 6~8%로 화면 가운데. 한글은 Noto Sans KR Bold.
- 마무리 문구: Geist 400~500, 자간 −0.02em, 짧은 변의 6%. 흰색에 살짝 색 번짐이 남아요.
- 강조 낱말은 같은 문장 안에서 빨강으로 바뀌고 한두 프레임 가로로 찢어졌다 붙어요.

## 질감과 모양
- 주사선 0.3, 그레인 0.1(초당 12번), 비네트 0.4, 색 번짐(rgbSplit) 1.2. 컷 순간에는 가로 노이즈 줄이 한두 프레임 화면을 가로질러요.
- 알약 알림은 어두운 유리(흰색 8% + 블러 + 1px 흰 테두리 20%), 모서리 2.4u 로 완전히 둥글게.
- 상자·괄호는 2px 선. 오류 괄호는 네 귀퉁이만 꺾인 선으로 남기고, 강조 줄 띠 안에는 아주 옅은 사선 빗금을 깔아요.
- 그림자는 쓰지 않아요. 빛은 파란 검사 띠 둘레의 옅은 번짐 하나뿐.

## 움직임
- 120BPM. 장면은 1~2박마다 바뀌고, 로그 장면만 3~4박 머물러요.
- 로그는 계속 위로 흘러요(초당 짧은 변의 2%). 그 위 검사 띠는 반 박마다 한 줄씩 계단처럼 내려가요.
- 제목은 초당 14자로 쳐지고, 기호 맞추기는 0.6초. 알림 알약은 `power3.out` 으로 0.3초에 커지며 떠요.
- 나갈 때는 거의 다 컷. 가로 노이즈 한 프레임이 컷 자리를 가려 줘요.

## 전환
- 컷이 기본, 화면이 가로 조각으로 찢겨 넘어가는 블록(blocks), 흐림에서 맺히는 blur 를 섞어요.
- 장면 쌓기: cut → blocks → blur.

## 대표 장면
1. **파란 검사 띠가 훑는 로그**
   ```js
   const M = Studio.M;
   S.ambient(t => {
     M.place(log, W * .5, H * .5 - t * H * .02, { r: -3 });          // 기운 로그가 천천히 위로
     const row = M.at([[0, 2], [M.beat(.5), 3], [M.beat(1), 4], [M.beat(1.5), 5]], t);
     M.box(band, { x: 0, y: row * lineH, w: W, h: lineH });          // 반 박마다 한 줄씩
     pill.style.opacity = M.spring(t - M.beat(1), 'smooth');          // '검사 중' 알약
     M.box(redact, { x: wx, y: wy, w: ww * M.prog(t, M.beat(2.5), .2), h: lineH });  // 붉은 상자가 낱말을 덮음
   });
   ```
2. **TV 잡음 위 넓은 대문자 + 기호 맞추기**
   - 회색 잡음 바탕(그레인을 장면에서만 0.3까지 올림) 가운데 Archivo 125% 대문자를 `M.type(text, t, 0, 14)` 로 쳐요.
   - 다음 장면은 `scenes.title: scramble` 로 같은 자리에서 기호 10자가 0.6초 만에 낱말로 맞춰져요. 바뀌는 순간 `S.tr.blocks` 로 가로 조각 찢김을 한 번.
3. **붉은 오류 로그 + 유리 통화 알림**
   ```js
   S.ambient(t => {
     errRows.forEach((r, i) => r.style.opacity = M.prog(t, i * M.beat(.5), .1));  // 오류 줄마다 붉은 띠
     M.place(callPill, W * .5, H * .5, { s: .6 + .4 * M.spring(t - M.beat(2), 'snappy') });
     wave.forEach((b, i) => M.box(b, { x: bx + i * gap, y: cy, w: 2, h: amp * Math.abs(Math.sin(t * 9 + i)) * M.rng(i)() }));
   });
   ```
   - 붉은 괄호는 SVG 꺾인 선 네 개를 `M.draw(path, k)` 로 0.3초에 그려요.
4. **초록 코드 비와 마무리**
   - 초록 고정폭 코드 조각 20~30개를 `M.rng(시드)` 로 흩어 두고, 조각마다 위로 반 줄씩 끊어서 떨어지게(초당 8장 느낌). 가운데 흰 두 낱말은 `S.tr.blur` 로 흐림에서 맺혀요.
   - 이어 파란 코드 판으로 컷, 마지막은 어둠 속 마크와 이름이 가로 마스크(`clipPath: inset(0 X% 0 0)`)로 왼쪽부터 열려요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발·모니터링 도구 런칭, 보안·장애 대응 서비스, AI 코딩 도우미 소개, 두 회사가 함께하는 발표 티저, 기술 블로그 예고편.
- 피할 것: 밝은 바탕, 손그림·종이 질감, 둥글고 귀여운 일러스트, 느린 페이드만 쓰기, 한 화면에 강조색을 셋 이상 섞기.
- 로그 글은 진짜처럼 보이되 직접 지어 써요. 시각·번호·짧은 상태 낱말을 섞으면 충분히 그럴듯해요.
