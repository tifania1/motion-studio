# 갈린 판 흙빛 안개 (그라디언트·빛)

한 줄: 옅은 회색 판이 베이지 판과 반씩 갈렸다 다시 이어지고, 올리브·세이지·테라코타·푸른 회색 안개 위로 작은 글자 한 줄과 흰 UI 카드가 조용히 떠올랐다 흐려지는 차분한 런칭.

## 보는 느낌
- 여백이 아주 넓어요. 화면 대부분은 비어 있고, 작은 산세리프 한 줄이나 흰 카드 한두 장만 놓여요.
- 여는 장면과 닫는 장면은 무늬 없는 옅은 회색 판이에요. 여기에 베이지 판이 반만 들어와 화면을 둘로 나누고, 양쪽에 낱말이 하나씩 서요. 갈라진 둘이 나중에 한 문장으로 이어지는 흐름이 이야기의 뼈대예요.
- 가운데 부분은 안개 색면이에요. 어둑한 올리브, 세이지 초록, 테라코타, 푸른 회색이 가장자리부터 부드럽게 번지고, 한쪽 귀퉁이에 흰빛이 고여 있어요. 색면 위의 UI 는 작고 반듯하게 떠 있어요.
- 마무리 판에는 세로로 흐린 줄이 겹겹이 일렁여요. 결 있는 유리 너머로 베이지 빛을 보는 것처럼요.

## 색
- 바탕(옅은 회색·베이지) 65 · 안개 색면 25 · 먹색 글자 8 · 테라코타 2.
- 옅은 회색 #DCDCD6, 베이지 판 #C4BBA0, 글자 먹색 #1C1C1A.
- 안개 색면: 올리브 #6E6A5C(위에 흰 글자), 세이지 #9DB78F, 테라코타 #C8663A, 푸른 회색 #A9B4B8. 한 장면엔 한 색만 써요.
- 강조색 테라코타는 바탕 한 장과 작은 깃발·아이콘 칸에만 써요. 그 위 글자는 거의 검은 갈색 #160D08.
- UI 카드는 흰색에 가까운 #F4F3EF, 경고 깃발만 붉은빛 한 점.

## 글자
- Geist 400 과 Noto Sans KR Medium. 제목도 굵히지 않아요. 큰 글도 짧은 변의 4~5% 정도로 작게 써요.
- 자간은 -0.01em, 한 줄을 넘기지 않아요. 가운데 정렬이 기본이고, 갈린 판에서는 양쪽 판 가운데에 하나씩 놓아요.
- 카드 옆 문구는 카드 반대편 빈자리에 세로 가운데로 맞춰요.
- 버튼·목록 글씨는 더 작게(짧은 변의 1.5~2%) 먹색 70%.

## 질감과 모양
- 안개 색면은 큰 원 4~5개를 아주 많이 흐려서 만들어요. 그레인 0.04 만 살짝 얹어 띠 무늬를 덮어요.
- 카드는 모서리 1.2u, 얇은 흰 테두리와 아래로 길게 퍼지는 옅은 그림자 하나. 살짝 기울여(rotateY 6~10°) 두면 깊이가 생겨요.
- 알약 단추·목록은 완전히 둥근 끝, 앞에 작은 동그라미 아이콘.
- 얼굴 원은 흰 테두리 2px 에 그림자 한 겹.

## 움직임
- 80BPM, 느림. `power2.inOut` 으로 천천히 움직이기 시작해서 천천히 멈춰요.
- 글은 가는 막대 커서를 따라 초당 12~15자로 쳐지고, 다 쳐지면 커서가 두 번 깜빡이고 사라져요.
- 카드는 아래에서 2u 올라오며 흐림 6px → 0 으로 맺혀요(0.8초). 들어온 뒤에는 아주 천천히(4초에 1u) 옆으로 흘러요.
- 커서는 곡선을 그리며 1초 넘게 걸려 와서 누르고, 누른 곳이 0.95 배로 살짝 눌렸다 돌아와요.
- 한 장면은 2~3초 머물러요.

## 전환
- 판 가르기(wipe): 베이지 판이 옆에서 들어와 화면 반에서 멈추거나, 반대편까지 쓸고 지나가요.
- 안개 색면 사이는 흐림 전환(blur), 판과 판 사이 긴 숨은 페이드(fade). 카드 장면 안에서는 카드가 옆으로 밀려 나가는 밀기(push).
- 장면 쌓기: wipe → blur → fade → push.

## 대표 장면
1. **반씩 갈린 판**: 옅은 회색 판에 낱말 둘을 양쪽에 두고, 베이지 판을 오른쪽에서 반까지 밀어 넣어요.
   ```
   S.ambient(t => {
     const k = M.anim([[0, 0], [.6, 1, {d: 1.2, e: 'inOutCubic'}]], t);
     M.box(pane, {x: W - W * .5 * k, y: 0, w: W * .5, h: H});
     M.place(left, W * .25, H / 2, {o: M.prog(t, .2, .6)});
     M.place(right, W * .75, H / 2, {o: M.prog(t, 1.4, .6)});
   });
   ```
2. **안개 위 카드와 커서**: 테라코타 안개를 `blur(12u)` 원 몇 개로 깔고 `M.drift` 로 천천히. 흰 카드 둘을 `M.place(card, x, y, {o: k, blur: (1 - k) * 6})`, `k = M.spring(t - ti, 'smooth')` 로 차례로 띄워요. `M.Cursor` 가 버튼으로 와서 `M.cursorAt` 순간 버튼을 0.95 배로 눌러요. 다음 색면은 `S.tr.blur` 로 넘겨요.
3. **문장 둘레를 도는 얼굴들**: 세이지 안개 가운데 문장을 `M.type(text, t, .3, 14)` 로 쳐요. 얼굴 원 7개를 반지름 R 원 위에 두고 `a = a0 + t * .08` 로 아주 느리게 돌려요. 원마다 위아래로 `sin(t * .7 + i)` × .5u 만 흔들려요.
4. **두 낱말이 한 문장으로**: 베이지 바탕 위에 세로 띠 8~10개를 `blur(3u)`, 밝기만 조금씩 다르게 깔고 `background-position-x` 를 `sin(t * .4)` 로 일렁이게 해요. 양쪽 낱말을 `M.anim` 으로 가운데로 모아 사이 말과 함께 한 줄로 맞추고, 1초 뒤 `S.tr.fade` 로 로고 판에 넘겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 업무 도구·협업 서비스 런칭, 고객과 회사를 잇는 포털 소개, 법률·금융·컨설팅처럼 차분한 업종, 기능 서너 개를 천천히 보여 줄 때.
- 피할 것: 쨍한 원색, 굵고 큰 제목, 빠른 컷과 흔들림, 네온·빛 번짐 테두리, 한 화면에 카드 여러 장 빽빽이.
- 안개 색은 한 장면에 하나만 써요. 색이 바뀌는 건 장면이 바뀔 때뿐이에요.
