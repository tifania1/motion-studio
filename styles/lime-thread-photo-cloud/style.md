# 연두 실 사진 구름 (콜라주·사진)

한 줄: 검은 바탕에서 사진 카드끼리 가는 흰 곡선으로 이어지고, 카드 모서리마다 작은 연두 꼬리표가 붙어요. 카드는 가지를 치며 늘어나다 끝에는 깊이가 제각각인 사진 구름으로 흩어지고, 그 가운데 작은 두 줄 문장이 떠요.

## 보는 느낌
- 거의 검은 바탕에 아주 옅은 점 격자가 깔려 있어요. 주인공은 따뜻한 빛의 인물·일상 사진이고, 글자는 작게 곁들여요.
- 사진 카드들은 가는 흰 선으로 이어져요. 선은 곧게 가다가 둥근 모서리로 한 번 꺾이는 모양이라 작업 흐름도처럼 읽혀요.
- 카드마다 아래 모서리에 연두 꼬리표, 사진 귀퉁이에 연두 점 버튼이 붙어 있어요. 화면에서 밝은 색은 사진과 이 연두뿐이에요.
- 큰 사진 한 장이 화면 반을 채우거나, 같은 사진을 크게 흐려 바탕에 깔고 그 위에 선명한 카드를 띄우기도 해요.
- 문장은 늘 한 줄이나 두 줄. 화면 한가운데나 선 끝에 작게 놓여요. 빈 화면에 낱말 하나만 둔 장면도 사이사이 끼어 숨을 돌려요.

## 색
- 검정 바탕 #111111 65 · 사진 25 · 흰 글자와 선 7 · 연두 3.
- 흰 글자·선 #EDEDEA, 선은 흰색 55% 정도로 살짝 낮춰요.
- 연두 #D8E63A 는 꼬리표, 점 버튼, 프롬프트 속 형광 낱말, 버튼, 마지막 문장 한 줄에만 써요. 꼬리표 위 글자는 거의 검정 #141414.
- 입력 카드·패널은 짙은 회색 #262626.
- 전후 비교 장면 한 번만 바탕 전체를 연두 → 올리브 #9FA83A 그라디언트로 칠해요(accent 장면).
- 사진 속 진한 빨강(#B3262B 같은 배경지)은 사진 몫이라 따로 칠하지 않아요.

## 글자
- Geist(한글은 Noto Sans KR Medium) 400, 자간 −0.01em. 굵은 제목은 쓰지 않아요.
- 문장은 짧은 변의 3.5~5%. 두 줄일 땐 둘째 줄을 오른쪽으로 반 낱말쯤 밀어 계단처럼 어긋나게 둬요.
- 꼬리표 글자는 짧은 변의 1.4% 안팎, 연두 알약 안에 꽉 차게.
- 프롬프트 장면만 예외로, 입력창을 화면보다 크게 키워 글자가 화면 밖으로 잘리게 써요. 이때 이름 부르기 낱말은 회색 둥근 칩에 담아요.

## 질감과 모양
- 질감은 따로 얹지 않아요. 바탕의 점 격자(흰색 7%)와 사진의 흐림이 깊이를 대신해요.
- 사진 카드: 모서리 `--u` × 1.2, 테두리 없이 아래로 부드러운 그림자 한 겹.
- 연결선: 1~1.5px, 꺾이는 곳은 반지름이 큰 둥근 모서리.
- 꼬리표: 연두 알약, 모서리 0.4u, 카드 아래 모서리에 반쯤 걸쳐 붙어요. 점 버튼은 연두 원에 어두운 테두리.

## 움직임
- 96BPM, 보통 속도. 들어오는 건 `power3.out` 으로 부드럽게 멈추고, 카메라는 장면 내내 아주 천천히 옆이나 앞으로 흘러요.
- 선은 한 번에 0.6~0.9초 동안 그어지고, 끝에 닿는 순간 카드나 문장이 나타나요.
- 카드는 85%에서 100%로 커지며 흐림이 걷히고, 꼬리표는 0.1초 늦게 톡 붙어요.
- 문장은 아래에서 살짝 올라오며 선명해지고, 한 장면에 1.5~2.5초 머물러요.
- 사진 구름은 카드마다 깊이 값을 주어 앞쪽은 크고 빠르게, 뒤쪽은 작고 느리게 흘러요.

## 전환
- 컷이 기본이에요. 사진이 화면을 덮는 장면으로 갈 땐 흐림 전환(blur), 끝 문장으로 갈 땐 느린 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면
1. **선으로 이어지는 사진 카드**
   ```
   // 큰 사진은 왼쪽 반, 작은 카드는 오른쪽 위, 둥근 꺾임 path 하나로 문장까지 잇기
   const k = M.ease.outCubic(M.prog(t, t0, .8));
   M.draw(threadPath, k);                                   // 흰 선 0.8초
   const c = M.spring(t - (t0 + .8), 'smooth');
   M.place(card, cx, cy, {s: .85 + .15 * c, o: c, blur: (1 - c) * 6});
   M.place(tag, tx, ty, {o: M.prog(t, t0 + .9, .15)});        // 연두 꼬리표가 늦게 톡
   ```
   장면 쌓기에서는 bg dots + card shadow + title rise 로 같은 결이 나와요.
2. **가지 치는 카드 나무**: 가운데 카드에서 path 3개를 `M.draw` 로 0.15초씩 늦게 긋고, 끝마다 카드를 `M.spring` 으로 키워요. 갈래 끝 카드 중 하나는 흑백, 하나는 다른 구도로 두어 '같은 사람, 다른 사진' 느낌을 내요. 카메라는 `S.ambient` 에서 판 전체를 4초에 짧은 변의 4%만 왼쪽으로 밀어요.
3. **흐린 사진 바탕 위 카드**: 같은 사진을 화면보다 1.4배 크게 `filter: blur(6u)` 로 깔고 그 위에 선명한 카드 2장을 겹쳐 둬요(뒤 카드는 반쯤 흐리게). 장면으로 들어갈 땐 `S.tr.blur`. 카드 사이 꼬리표에는 전후를 알리는 짧은 이름을 달아요.
4. **사진 구름과 계단 문장**
   ```
   const r = M.rng(7);
   cards.forEach((c, i) => {
     const z = .3 + r() * .7;                                 // 깊이
     const x = M.drift(i, t * z * .6), y = M.drift(i + 50, t * z * .6);
     M.place(c, x, y, {s: z, blur: (1 - z) * 3});
   });
   // 가운데 두 줄 문장: 둘째 줄을 오른쪽으로 밀고 0.3초 늦게 rise
   ```
   끝은 컷으로 빈 검은 화면, 흰 한 줄과 연두 한 줄, 그 뒤 연두 점 두 개가 톡톡 켜지며 닫혀요.
