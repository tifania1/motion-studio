# 연필 콘티 (손그림)

한 줄: 흰 종이에 흑연 연필로 그린 콘티(스토리보드). 칸마다 번호, 빗금 그림자, 파란 색연필로 고친 자국이 남는 작업 노트 느낌이에요.

## 보는 느낌
- 장면 하나가 콘티 칸 하나. 손으로 그은 네모 칸 안에 그림·글이 있고, 칸 왼쪽 위에 '#1', '#2' 같은 번호.
- 칸 밖 여백에 연필 메모("줌 인", 화살표)가 작게. 화면 구성은 왼쪽 정렬, 칸은 화면 폭의 80~88%.
- 바탕에 옅은 가로줄(줄 공책). 채색은 거의 없고 회색 빗금으로 명암만.

## 색
- 바탕 80 · 흑연 17 · 파란 색연필 3.
- 바탕 흰 종이(#F7F6F2), 선과 글 흑연(#2B2B2B), 빗금은 흑연을 옅게(#9A9A96).
- 강조는 파란 색연필(#2F63C9). 고친 자국에만 빨간 색연필(#D94F3D)을 아주 조금.

## 글자
- 한글 개구(Gaegu) 굵게, 영문·숫자 큰 글은 Caveat. 콘티 메모처럼 크지 않게(제목은 짧은 변의 7~8%).
- 칸 번호와 메모는 작게(짧은 변의 3%) 흑연색, 약간 기울여.

## 질감과 모양
- 흰 종이 + 섬유 진하게(0.55) + 그레인 0.12(초당 8번 바뀜).
- 선 떨림 0.8, 초당 6번. 움직임은 초당 8장(stepped 8)으로 끊어 콘티를 넘겨 보는 느낌.
- 모서리 없음(0). 카드는 테두리만 있는 칸(outline), 손으로 그은 상자.

## 움직임
- 90BPM, 느리게. 들어올 땐 power2.out, 어절 간격 1.4배.
- 그림은 외곽선 → 0.3초 뒤 빗금 → 글 순서. 한 칸에서 1.5박쯤 머물러 읽게 해요.

## 전환
- 컷, 또는 0.4초 서서히. 다음 칸으로 넘어갈 때 칸 번호가 먼저 바뀌고 내용이 따라와요.

## 대표 장면

1. 콘티 칸
   ```
   // 장면 전체를 감싸는 칸: 세이프존 안쪽에 M.rough('rect')
   frame.setAttribute('d', M.rough('rect', { x: L, y: T, w: W, h: H, over: 1.2 * u, seed: 5 }));
   tl.fromTo(frame, { strokeDashoffset: len }, { strokeDashoffset: 0, duration: .5, ease: 'none' }, T0);
   num.textContent = '#' + (i + 1);   // 칸 번호 (Caveat, 흑연색)
   ```
2. 외곽선 → 빗금
   - 도형·아이콘 SVG 를 M.draw(path, k) 로 그은 뒤, 빗금 무늬(repeating-linear-gradient −50도, 흑연 0.35u / 빈칸 1.6u)를 clip-path 로 0.3초에 왼쪽부터 채워요.
3. 파란 연필로 고치기
   - 바꿀 말 위에 회색 가로줄(M.rough('line'))을 긋고, 반 박 뒤 옆에 파란 글씨로 새 말이 써져요. 밑줄은 marker: underline + rough.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 서비스 기획·과정 설명, 단계별 안내, 브랜드 이야기, 캠페인 예고, 제작 과정 공개.
- 피할 것: 형광색, 그림자 진한 카드, 빠른 컷 연타, 사진을 화면 가득.

## 배운 곳
- 직접 정리. 갤러리 영상에서 배운 게 아니고, 영화·광고 콘티 그림에서 널리 쓰는 방식(칸 나누기, 빗금 명암, 파란 연필 수정, 초당 8장 끊어 그리기)으로 정리했어요.
- 갤러리에서 배운 손그림 결은 따로 있어요: marker-scrawl-montage, chalk-math-board, doodle-faces-strikeout, manga-panel-bubbles, river-line-lettering, serif-marker-word, ink-gesture-blobs, navy-etching-plates.
