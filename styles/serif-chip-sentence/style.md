# 칩이 박히는 세리프 문장 (타이포)

한 줄: 따뜻한 회색 위에 책에서 본 듯한 세리프 문장 하나. 문장 속 낱말이 아이콘 칩으로 바뀌고, 끝에는 이름표 단 커서 둘이 함께 문장을 써요.

## 보는 느낌
- 왼쪽 정렬 세 줄 문장이 화면 왼쪽 위 1/3쯤에 놓여요. 오른쪽과 아래는 넉넉히 비워 둬요.
- 문장 위에 아주 작은 회색 꼬리표("베타" 같은) 하나. 그 밖의 장식은 없어요.
- 칩이 들어오면 문장이 살짝 길어지며 리듬이 생겨요. 글과 UI 사이 어디쯤에 있는 화면.

## 색
- 바탕 85 · 글자 12 · 칩·강조 3.
- 바탕은 따뜻한 회색(#E7E6E1), 글자는 먹색(#1C1B19).
- 칩은 종류마다 아주 연한 색 바탕 + 같은 계열 진한 아이콘: 파랑(#DCE6F5 / #3E6FD0), 황토(#F1E2C6 / #B9822A), 연보라(#E6DEF5 / #7A5BC9).
- 커서 이름표 두 개: 테라코타(#B5532F)와 흐린 파랑(#5B86C4). 타자 중인 글자도 그 색으로 썼다가 끝나면 먹색으로.

## 글자
- 문장은 Instrument Serif(영문·숫자) + 고운바탕(한글) 400. 대비가 낮고 글자 폭이 넉넉한 본문용 세리프라 차분하게 읽혀요.
- 칩·꼬리표·UI 글자는 작은 고딕(Geist + Noto Sans KR 500), 세리프 크기의 45% 정도.
- 문장 크기는 짧은 변의 6~7%, 줄 간격 1.15, 자간 −0.02em. 굵게 쓰지 않아요.

## 질감과 모양
- 질감 없음.
- 칩: 높이 = 세리프 x-height의 2배쯤, 모서리 0.9u, 테두리 없이 연한 바탕만. 아이콘 지름은 칩 높이의 55%.
- 커서 이름표: 작은 각진 깃발(모서리 0.3u), 흰 글자. 커서 막대는 1.5px.
- 선택 상자: 1px 분홍빛 선(#D2557F) + 모서리 네 개의 작은 흰 사각 손잡이.

## 움직임
- 90~96BPM. 차분하게, 한 박에 한 가지씩.
- 문장 첫 등장은 줄마다 아래에서 0.4초 올라오기(0.12초 간격, power3.out).
- 칩 바뀜은 0.35초 간격. 밀려나는 뒷말은 M.spring 'snappy'.
- 커서 타자는 초당 12~16자. 두 커서가 반 박씩 엇갈려 치게.
- 나갈 때는 낱말이 왼쪽으로 조금 밀리며 회색으로 옅어짐(0.3초).

## 전환
- 칩을 이어 주는 장면 전환이 핵심. 문장 → 칩만 남음 → 칩이 다음 화면 자리로 이동.
- 그 밖에는 컷, 또는 0.3초 페이드.

## 대표 장면

1. 낱말이 칩으로
   ```
   // 문장을 어절 span 으로 (S.words), 바꿀 낱말 w 와 칩 c 를 같은 자리에 겹쳐 둠
   const k = M.spring(t - tc, 'snappy');            // tc: 바뀌는 시각
   w.style.opacity = 1 - M.prog(t, tc, .1); w.style.filter = `blur(${M.prog(t, tc, .1) * 4}px)`;
   c.style.transform = `scale(${.6 + .4 * k})`; c.style.opacity = M.prog(t, tc + .05, .15);
   slot.style.width = M.lerp(wordW, chipW, k) + 'px'; // 자리 폭이 변하면 뒷말·다음 줄이 자연히 흐름
   ```
2. 칩만 남아 다음 화면으로
   - 문장 나머지 글자를 0.3초에 옅게(opacity 0). 칩은 그대로 떠 있다가 다음 화면의 메뉴 항목 좌표로 M.anim(..., 'soft').
   - 칩이 도착하는 순간 메뉴 상자가 0.2초에 펼쳐지며 칩이 항목 줄이 됨(칩 바탕만 0.15초에 사라짐).
3. 두 사람 커서 타자 → 선택 상자 → 키우기
   ```
   left.textContent  = M.type(A, t, t0, 14);  right.textContent = M.type(B, t, t0 + M.beat(.5), 14);
   // 각 커서 위에 이름표: M.place(tag, caretX, caretY - 1.2*u, {ay: 1})
   // 다 쓰면 color: M.color(이름표색, '#1C1B19', M.prog(t, t1, .3))
   // 선택 상자 등장 → M.Cursor 로 오른쪽 아래 손잡이를 잡고 끌기: 문장 scale = 1 + (커서x - 시작x) / 원래폭
   ```
4. 마무리
   - 문장이 왼쪽으로 밀리며 회색으로 옅어지고, 가운데 작은 로고 표시가 돌며 커져 워드마크 옆에 자리 잡음.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 문서·협업 도구, 새 기능 발표, 차분한 브랜드 한 줄 메시지, 기업 소개의 첫 장면.
- 피할 것: 굵은 고딕 큰 제목, 쨍한 원색 바탕, 빠른 컷 연타, 화면을 꽉 채운 사진. 칩 종류를 넷 넘게 만들지 않기.
