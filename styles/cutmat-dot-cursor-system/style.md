# 커팅 매트 점 커서 시스템 (제품 UI)

한 줄: 남보라·빨강·초록 커팅 매트와 나뭇결 책상 위에 두꺼운 흰 테두리 앱 창이 놓이고, 검은 점 커서가 버튼 가장자리에 바짝 붙어 누르는 동안 카메라가 창 모서리로 파고들어요. 사이사이 분홍·민트 판에서는 가는 줄 사이로 큰 그로테스크 목록이 흘러가요.

## 보는 느낌
- 작업대를 위에서 내려다보는 느낌이에요. 바닥은 나뭇결 책상이거나 눈금이 그어진 커팅 매트이고, 그 위에 흰 앱 창이나 빈 나무 판이 놓여 있어요. 창문 빛이 비스듬히 드리운 옅은 그림자가 매트를 가로질러요.
- 앱 창은 테두리가 아주 두껍고 모서리가 크게 둥글어요. 카메라는 창 전체를 잠깐 보여 준 다음 한 모서리로 바짝 다가가요. 그래서 화면의 절반은 UI, 나머지 절반은 매트 눈금이 차지하는 구도가 자주 나와요.
- 장면마다 왼쪽 위에 검은 알약 꼬리표 하나와 옅은 회색 낱말 하나를 붙여서 지금 무엇을 보는지 이름표를 달아 줘요(구성요소, 원칙, 상태, 동작 같은 분류).
- 사이사이 쉼표처럼 분홍이나 민트 판이 들어와요. 큰 글자 목록을 보여 주거나, 벽에 걸린 포스터 두세 장을 보여 줘요.
- 빈 나무 판 장면에서는 모서리에 아주 작은 고정폭 대문자 주석이 붙고(→ 화살표, 밑줄 커서), 가는 점선 안내선이 판을 세로로 나눠요.

## 색
- 매트·책상 50 · 흰 UI 30 · 먹색 글자와 커서 15 · 코발트 5.
- 분홍 판 #F6B3CE, 민트 판 #E3EDE6, 흰 창 #F7F6F3, 먹색 #161616.
- 커팅 매트는 장면마다 색을 바꿔요: 남보라 #5A5C9C(분홍 눈금선), 빨강 #D85A5C(흰 눈금선), 초록 #3FA88A(짙은 초록 눈금선). 책상 나뭇결 #D8B68C.
- 코발트 #1F5FE8 는 큰 색면 조각이나 강조 버튼 하나에만 써요. 글자 선택 표시는 옅은 하늘색 #CFE3FA.

## 글자
- 큰 글자는 Geist 400(한글은 Noto Sans KR 500). 굵게 누르지 않고 보통 굵기로 크게 써서 담백해요. 자간 −0.01em.
- 목록 타이포는 짧은 변의 9~11% 크기로, 줄마다 아래에 1px 가는 가로줄을 긋고 왼쪽 정렬해요.
- 동작을 이름 붙이는 장면에서만 굵기 700으로 두 줄을 크게 써요. 짧은 변의 18% 정도로, 한 낱말 앞에 앱 아이콘 같은 둥근 타일이 끼어들어요.
- 꼬리표는 Geist 500, 흰 글자에 검은 알약. 주석은 Geist Mono 대문자, 짧은 변의 1.6%.

## 질감과 모양
- 거의 매끈해요. 그레인 0.04와 비네트 0.16만 깔아서 사진 같은 공기감을 내요.
- 창 모서리는 2.4u, 흰 테두리는 1.2u 두께로 아주 두껍게. 그림자는 아래로 길고 옅게 한 겹 둘러요.
- 커팅 매트는 가는 눈금 격자(5u 간격)에 굵은 선(25u 간격)과 비스듬한 점선 몇 개, 작은 원 표시를 얹어 만들어요.
- 커서는 테두리 없는 꽉 찬 검은 원이고, 그림자는 넣지 않아요.

## 움직임
- 96BPM, 보통 빠르기. 카메라와 커서 모두 power3.inOut 으로 천천히 출발해서 부드럽게 멈춰요.
- 카메라는 한 장면에 한 번만 움직여요. 1~1.4초에 걸쳐 창 모서리로 다가가 2박쯤 머물러요.
- 커서는 한 박 안에 목표까지 가서 반 박 쉬고, 누를 때 0.12초 동안 0.9배로 줄었다 돌아와요. 눌린 항목에는 테두리 칸이 바로 생겨요.
- 목록 줄은 줄마다 0.15초씩 늦게 선 아래에서 올라오고, 다 놓이면 목록 전체가 위로 천천히 흘러요.
- 입력창 글은 커서가 깜빡이는 채로 초당 14자쯤 쳐져요.

## 전환
- 밀어내기(push)가 기본이에요. 매트 위 창이 통째로 옆으로 밀려나고 다음 창이 들어와요.
- 판 색이 바뀔 때(분홍 → 매트)는 컷, 포스터 장면 앞에서는 짧은 페이드를 써요. 장면 쌓기 순서는 push → cut → fade.

## 대표 장면
1. **점 커서가 목록에 붙어 누르기**
   ```js
   const cur = M.Cursor({ dot: true, size: S.u * 2.4, color: '#161616' });
   S.ambient(t => {
     M.cursorAt(cur, [[0, rowA], [M.beat(1), rowC, { e: 'inOutCubic' }]], t);
     const press = M.prog(t, M.beat(1.5), .12);
     M.place(cur.el, cur.x, cur.y, { s: 1 - Math.sin(press * Math.PI) * .1 });
     rowC.style.outline = t > M.beat(1.5) ? '2px solid #161616' : 'none';
   });
   ```
2. **매트 위 창 모서리로 파고들기**
   - 바탕 `scenes.bg: grid` 위에 흰 창(`frame: window`)을 두고, 래퍼에 `M.place(cam, 0, 0, { s: M.anim([[0, 1], [M.beat(1), 2.4, { d: 1.2, e: 'inOutCubic' }]], t) })` 를 걸어요. 확대 중심(`transform-origin`)은 창 오른쪽 아래 모서리로 잡아요.
   - 왼쪽 위 검은 알약 꼬리표는 `M.spring(t, 'smooth')` 로 2u 오른쪽에서 밀려 들어와요.
3. **분홍 판의 줄 목록**
   - 줄마다 `clip-path: inset(0 0 0 0)` 상자 안에서 `y = M.anim([[i * .15, 1.1], [i * .15 + .5, 0, { e: 'outCubic' }]], t)` 로 선 아래에서 올라와요(`scenes.title: mask`). 다 놓이면 목록 전체를 4초에 짧은 변의 6%만큼 위로 흘려요. 가는 줄은 `M.draw(line, k)` 로 왼쪽부터 그어요.
4. **빈 나무 판과 주석**
   - 나뭇결 바탕 가운데 빈 둥근 판 하나를 두고, 모서리 고정폭 주석은 `M.type(text, t, .3, 18)` 로 쳐요. 점선 안내선 2개는 `M.draw` 로 위에서 아래로 그어요. 판이 `S.tr.push` 로 밀려나면 그 자리에 흰 창이 들어와요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·구성요소 소개, 기능 원칙 설명, 생산성 도구 시연, 제품 철학 발표.
- 피할 것: 네온·빛 번짐, 기울인 3D 판, 손그림 선, 한 화면에 강조색 여럿, 빠른 글리치 컷. 커서에 화살표를 그리면 이 결이 흐려지니 꼭 점 하나로 두세요.
