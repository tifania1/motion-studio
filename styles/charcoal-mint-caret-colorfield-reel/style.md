# 숯빛 민트 커서 색면 릴 (제품 UI)

한 줄: 짙은 숯빛 판에 기능 이름 한 낱말이 가는 민트 커서 뒤로 쳐지고, 바짝 붙은 어두운 앱 패널에서 큰 커서가 민트 버튼을 누를 때마다 결과 그림이 옆에 갈려 들어와요. 사이사이 라임·자두 단색 판이 컷으로 끼고, 끝은 짙은 청록 판의 왼쪽 정렬 두 줄로 닫혀요.

## 보는 느낌
- 두 가지 화면이 번갈아 와요. 하나는 아무것도 없는 숯빛 단색 판에 낱말이나 문장 한 줄만 놓인 화면, 다른 하나는 어두운 앱 패널을 화면 가득 확대한 화면 녹화예요.
- 패널 화면은 늘 일부만 보여요. 입력창, 썸네일 줄, 토글, 버튼 같은 조각이 화면의 반 이상을 채우고 가장자리는 잘려 나가요.
- 결과물이 나오면 화면을 반으로 나눠 왼쪽엔 생성된 그림, 오른쪽엔 패널을 둬요. 패널은 그대로 두고 그림만 바뀌어서 '넣은 말 → 나온 그림'이 한눈에 읽혀요.
- 문장이 바뀌는 고비마다 라임이나 자두 같은 쨍한 단색 판이 한 장씩 끼어들어 숨을 끊어 줘요.
- 뒤쪽엔 결과 카드가 잔뜩 모인 장면이 와요. 프롬프트 알약 둘레로 둥근 썸네일 타일이 떠다니거나, 세로 줄마다 다른 속도로 흐르는 카드 벽이 화면을 채워요.

## 색
- 숯빛 바탕 70 · 흰·회색 UI와 글자 20 · 민트 10.
- 바탕 #222222, 패널은 조금 밝은 #2C3130, 패널 안 글자 #ECECEA.
- 민트 #4FB38E 는 버튼, 켜진 토글, 선택 테두리, 커서에만 써요. 큰 낱말은 옅은 민트 #A8E6CC 로.
- 단색 판: 라임 #C8DF1E(글자는 짙은 회색), 자두 #6B1557(글자는 연분홍). 영상 하나에 각각 한 번씩만.
- 엔딩 판은 짙은 청록 #1F4A40, 글자 흰색, 기능 이름만 민트.

## 글자
- 둥근 기하학 산세리프(Geist, 한글은 Noto Sans KR Medium). 굵기 500 안팎으로 가볍고 반듯하게, 자간 −0.015em.
- 기능 이름 낱말: 짧은 변의 12~15%로 크게, 화면 가운데에서 살짝 왼쪽에 놓고 오른쪽에 커서 자리를 남겨요.
- 문장: 짧은 변의 4~5%, 한 줄. 어절 사이를 조금 넓게 띄워요.
- 엔딩 두 줄은 왼쪽 정렬, 줄 간격 1.2.
- 패널 안 글씨는 작고 회색, 입력창 속 문장만 흰색.

## 질감과 모양
- 질감 없이 매끈한 화면. 그레인·비네트를 넣지 않아요.
- 패널 모서리 1.4u, 버튼과 알약은 완전히 둥글게. 그림자 대신 1px 옅은 회색 테두리로 칸을 나눠요.
- 첫 장면의 아이콘이나 마크에만 민트 빛 번짐(glow)을 한 겹 둘러요. 다른 곳엔 빛을 쓰지 않아요.
- 커서: 텍스트 커서는 가는 민트 세로선, 화살표 커서는 화면 높이 8~10%짜리 흰 화살표에 얇은 검은 테두리.

## 움직임
- 100BPM, 보통 빠르기. 들어오는 움직임은 power3.out 으로 부드럽게 멈춰요.
- 낱말 타이핑은 초당 12자 안팎. 커서는 0.5초 주기로 깜빡이고, 치기 전과 다 친 뒤에 한 박씩 혼자 깜빡여요.
- 문장은 어절마다 0.1초 간격으로 옅게 떠올라요(아래에서 0.5u).
- 화살표 커서는 목적지까지 0.6초에 미끄러지고, 누를 때 0.1초 동안 0.9배로 작아졌다 돌아와요. 카메라는 커서를 따라 천천히 패닝해요.
- 결과 그림은 2박(1.2초)쯤 머물고, 다음 문장이 쳐지면 컷으로 바뀌어요.
- 카드 벽은 세로 줄마다 다른 속도(짧은 변의 3~6%/초)로 위아래 엇갈려 흘러요.

## 전환
- 컷이 기본. 단색 판과 타이핑 장면 사이는 모두 컷이에요.
- 첫 마크가 사라질 때와 엔딩으로 들어갈 때만 짧은 페이드(0.4초).
- 카드 벽 장면은 옆으로 밀어내기(push). 장면 쌓기: cut → fade → push.

## 대표 장면

1. 빈 판의 낱말 타이핑
   ```
   // 커서 혼자 한 박 → 낱말이 쳐짐 → 다 친 뒤 두 번 깜빡이고 컷
   const t0 = M.beat(1);
   S.ambient(t => {
     word.textContent = M.type('편집', t, t0, 12);
     const typing = t > t0 && t < t0 + 2 / 12;
     caret.style.opacity = typing ? 1 : (Math.floor(t / .5) % 2 ? 0 : 1);
   });
   // 장면 쌓기에서는 title: 'type' 이 같은 결을 내요
   ```
2. 바짝 붙은 패널과 큰 커서
   ```
   // 패널을 1.8배로 키워 일부만 보이게, 커서를 따라 카메라가 흐름
   const cur = new M.Cursor(S.$('.cursor'), [
     [.4, inputX, inputY], [1.4, thumbX, thumbY, {click: true}], [2.4, btnX, btnY, {click: true}]
   ]);
   S.ambient(t => {
     const p = M.cursorAt(cur, t);
     M.place(panel, -p.x * .4, -p.y * .3, {s: 1.8});
     btn.style.background = M.color('#2C3130', '#4FB38E', M.prog(t, 2.4, .15));
   });
   ```
3. 결과 그림과 패널 반반, 그림만 갈림
   - 왼쪽 반에 그림 3장을 겹쳐 두고 `M.at([[0, 0], [1.5, 1], [3, 2]], t)` 로 하나만 보이게 해요. 바뀌기 0.6초 전부터 패널 입력창 문장을 `M.type` 으로 다시 쳐서 '말을 바꾸면 그림이 바뀐다'를 보여 줘요. 버튼 위 화살표 커서는 그림이 바뀌는 순간마다 한 번씩 눌러요.
4. 색면 컷과 카드 벽, 엔딩
   - 라임 판(scheme accent에 가깝게): 가운데 문장 한 줄이 어절마다 떠오르고 1.5초 뒤 컷.
   - 카드 벽: 둥근 카드 4줄, 줄마다 `M.place(col, x, y0 + t * v_i)` 로 엇갈려 흐르게 하고 `S.tr.push` 로 들어와요.
   - 엔딩(paper = 짙은 청록): 왼쪽 정렬 두 줄을 `S.fx` 로 어절씩 올리고, 기능 이름만 `M.color('#E8F2EE', '#4FB38E', k)` 로 물들인 뒤, 아래 민트 테두리 알약과 화살표 커서가 0.4초 늦게 들어와요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱 기능 소개, 새 버전 공개, AI 생성 도구 시연, 제작 도구 사용법 하이라이트, 30~60초 제품 영상.
- 피할 것: 밝은 흰 바탕 위주 구성, 손그림 선이나 종이 질감, 굵고 꽉 찬 대문자 제목, 강조색 여러 개를 한 화면에, 빠른 글리치·깜빡임.
- 단색 판은 영상 하나에 두세 장이면 충분해요. 너무 자주 끼우면 숯빛과 민트의 차분함이 흐려져요.
