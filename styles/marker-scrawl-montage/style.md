# 마커 낙서 몽타주 (손그림)

한 줄: 결 있는 회색 종이 위로 화면보다 큰 마커 낙서와 잘린 세리프 글자가 4분의 1초마다 바뀌고, 가운데 세리프 한 줄 둘레로 손글씨 낱말이 박자마다 돋아나요.

## 보는 느낌
- 바탕은 섬유 결이 보이는 옅은 회색 종이. 그 위에 아주 가는 연필 선이 크게 고리를 그리며 화면을 가로질러요(먹색 15~25%).
- 주인공은 거대한 마커 글자예요. 글자 높이가 화면의 60~120%라서 늘 가장자리에서 잘려 보이고, 90도 돌아가거나 좌우가 뒤집힌 채 놓이기도 해요. 읽히기보다 무늬처럼 보이는 크기.
- 조용한 장면에서는 가운데 세리프 한 줄만 반듯하게 두고, 둘레 빈자리에 작은 마커 손글씨 대문자 낱말이 하나씩 돋아나요.
- 바탕색을 장면마다 바꿔요: 회색 종이 → 파란 종이 → 회색 → 라임. 파란 종이에도 같은 연필 고리 선과 거대한 검정 마커 글자를 깔아요.
- 사진·UI 를 넣을 땐 둥근 카드나 폰 한 대를 낙서 바탕 위에 띄워요. 낙서가 카드 뒤를 지나가요.

## 색
- 종이 75 · 먹(마커) 20 · 라임 5.
- 회색 종이 #E0DDD7, 마커·글자 먹색 #222222.
- 파란 종이 #5A8DCE(장면 바탕), 옅은 청보라 #A9BAD8(조용한 장면 바탕).
- 라임 #C5D94B 는 마지막 한 장이나 로고 판에만, 넓게 칠해요.
- 연필 고리 선: 회색 종이 위에선 먹색 20%, 파란 종이 위에선 흰색 35%.

## 글자
- 거대한 낙서·큰 제목: 영문은 Caveat 700, 한글은 나눔손글씨 붓. 대문자, 자간 −0.01em. 크기는 짧은 변의 30~70%로 아주 크게, 일부는 화면 밖으로 잘리게.
- 가운데 문장: 고운바탕 400, 짧은 변의 7% 안팎, 가운데 정렬 두 줄.
- 둘레 작은 손글씨 낱말: 나눔손글씨 펜(한글)·Caveat 700(영문) 대문자, 짧은 변의 5~6%, −8~+6도로 제각각 기울여요.
- 세리프 조각(오프닝): 고운바탕 700 을 아주 크게 잘라 90도 돌리거나 좌우 뒤집어 무늬로.

## 질감과 모양
- 종이(gray) + 섬유 0.55 + 그레인 0.12(초당 12번). 바탕 결이 늘 살아 있어요.
- 마커 획은 끝이 둥글고 두께가 거의 고른 굵은 선(짧은 변의 2~4%). 붓 획은 시작이 두껍고 끝이 갈라져요.
- 카드·폰은 모서리 1.6u, 아주 옅은 그림자 하나.
- 선 떨림(boil)은 쓰지 않아요. 대신 판 자체를 반 박마다 갈아 끼워 손맛을 내요.

## 움직임
- 120BPM. 오프닝 몽타주는 반 박(0.25초)마다 컷, 본 장면은 2박(1초)마다 낱말 하나.
- 거대한 마커 획은 왼쪽 위부터 0.4~0.5초에 그어지고(power2.out), 다 그려지기 전에 잘려 나가도 괜찮아요.
- 작은 손글씨 낱말은 0.4초에 왼쪽부터 써지고, 다음 낱말이 오면 컷으로 사라져요(서서히 빠지지 않음).
- 카드·폰은 옆에서 밀려 들어와(스프링 'smooth') 천천히 떠 있어요.

## 전환
- 컷이 기본. 카드·폰 장면만 밀어내기(push). 서서히·흐림 전환은 쓰지 않아요.

## 대표 장면

1. 반 박 몽타주 오프닝
   ```
   // 판 6장을 미리 만들어 겹쳐 두고, 반 박마다 하나만 보이게 (t 의 순수 함수)
   const boards = S.$$('.board');           // 잘린 마커 낙서 · 뒤집힌 세리프 조각 · 빈 종이 …
   S.ambient(t => {
     const i = M.at(boards.map((_, k) => [k * M.beat(.5), k]), t);
     boards.forEach((b, k) => b.style.visibility = k === i ? 'visible' : 'hidden');
     M.draw(brushPath, M.ease.outCubic(M.prog(t, M.beat(3), .4)));   // 마지막에 굵은 붓 획 하나
   });
   // 연필 고리 선(가는 SVG path 3~4개)은 모든 판 아래에 고정
   ```
2. 가운데 세리프 + 돋아나는 손글씨 낱말
   - 세리프 두 줄은 가운데 고정. 2박마다: 화면 가장자리에 거대한 마커 낱말(Caveat 700, 짧은 변의 60%)을 clipPath 로 0.5초 드러냈다가 컷으로 지움 → 바로 같은 낱말을 작은 손글씨로 세리프 위(또는 아래) 빈자리에 `clipPath: inset(0 X% 0 0)` 0.4초. 앞 낱말은 컷으로 사라져요.
   - 장면 쌓기에서는 title: write + scale 1.3 으로 큰 제목이 손으로 쓰듯 끊어서 써지고, deco scribble 이 큰 마커 낙서를 깔아요.
3. 파란 종이 위 카드
   - s-paper 장면(파란 종이)에 90도 돌린 거대한 마커 글자와 흰 연필 고리 선을 깔고, 둥근 카드(알림·폰)를 옆에서 M.spring 'smooth' 로 밀어 넣어요. 글자 판은 아주 천천히(4초에 짧은 변의 3%) 아래로 흘러요.
4. 라임 한 장 마무리
   - 컷으로 라임 바탕, 가운데 로고와 세리프 한마디. 첫 장면의 굵은 붓 획 하나를 로고 옆에 다시 0.4초에 그어 처음과 끝을 이어요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 리브랜딩·런칭 티저, 창작·메모 도구, 캠페인 오프닝, 젊은 브랜드 소개, 기능 여러 개를 낱말로 훑을 때.
- 피할 것: 매끈한 그라디언트, 유리처럼 반짝이는 질감, 한 화면에 문장 여러 줄, 느린 서서히 전환, 작은 손글씨만 쓰기(거대한 낙서가 있어야 이 결이 살아요).
