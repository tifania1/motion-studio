# 궤도 고리 작업 흐름 (다이어그램·데이터)

한 줄: 어두운 회색 공간에 비스듬히 누운 빛나는 궤도 고리가 떠 있고, 빛 점이 고리를 따라 돌 때마다 마디에 고정폭 대문자 꼬리표가 켜지는 HUD풍 작업 흐름 필름.

## 보는 느낌
- 거의 검은 짙은 회색 공간 한 장. 가운데가 살짝 밝고 가장자리는 비네트로 가라앉아 있어요.
- 주인공은 원근으로 눕힌 타원 고리 하나. 아주 가는 흰 선이고 바깥쪽에 시계 눈금 같은 짧은 선이 촘촘히 둘러 있어요. 고리 위 마디마다 작은 점과 짧은 꼬리표가 붙어요.
- 카메라가 가까이 붙은 장면에서는 호 하나가 화면을 대각선으로 가르고, 꼬리표 두세 개만 또렷해요. 나머지는 초점 밖으로 뿌옇게 흐려 깊이를 만들어요.
- 넓게 보는 장면에서는 고리 전체와 엇갈린 두 번째 고리, 둘레의 꼬리표 열 개 남짓이 한눈에 들어와요. 그래도 글은 작고 여백이 넓어요.
- 끝은 텅 빈 회색 화면에 작은 매듭 마크와 산세리프 한 줄.

## 색
- 짙은 회색 바탕 #151617 80 · 회색 선과 흐린 꼬리표 #8E9194 15 · 흰 빛 5.
- 색은 거의 흑백이에요. 강조는 밝기로만: 빛 점과 막 켜진 꼬리표는 흰색 #FFFFFF, 지나간 것은 회색으로 식어요.
- 강조 낱말 뒤 칸은 흰색 12~18% 의 옅은 회색 사각. 장면 쌓기의 accent 바탕을 쓸 땐 밝은 회색 #F2F3F4 위에 짙은 회색 글자.

## 글자
- 꼬리표: Geist Mono(한글은 Noto Sans KR Medium), 400, 대문자, 자간 0.12em. 크기는 짧은 변의 2~3.5%로 작게. 가까이 붙은 장면에서만 5% 안팎.
- 고리 안쪽 보조 꼬리표는 90도 돌려 호를 따라 세로로 놓고, 더 작고 더 흐리게(50%).
- 엔딩 문장: Geist 400~500, 짧은 변의 6%, 가운데 정렬 한 줄, 밝은 회색.
- 큰 제목은 쓰지 않아요. 정보는 작은 꼬리표 여러 개로 나눠 담아요.

## 질감과 모양
- 그레인 0.08(초당 12번), 비네트 0.42. 어둠 속 선이 살짝 거칠게 보여요.
- 선은 모두 1px 안팎 흰색 20~45%. 빛 점이 지나간 호만 2px 흰색에 얇은 빛 번짐(`--glow`).
- 마디 표시: 지름 1.2u 원 테두리 + 가운데 작은 흰 점. 막 켜질 때 한 번 빛나요.
- 얕은 초점: 가까운 것·먼 것은 `blur` 3~8px, 초점이 맞는 층만 또렷하게.
- 카드는 쓴다면 얇은 회색 테두리만(outline), 모서리 0.6u.

## 움직임
- 80BPM, 느림. 이징은 `power2.inOut` 으로 미끄러지듯 시작하고 멈춰요.
- 빛 점은 고리 한 바퀴를 6~8초에 돌고, 마디 사이에서 아주 살짝 빨라졌다 마디에서 멈칫해요.
- 꼬리표는 마디 표시가 켜진 뒤 0.1초 늦게 초당 30자쯤으로 쳐지고, 핵심 낱말 뒤 회색 칸은 쳐진 뒤 0.2초에 왼쪽부터 깔려요.
- 카메라는 늘 천천히 돌거나 다가가요. 한 장면 3~5초, 그동안 고리 기울기·회전이 몇 도씩 계속 바뀌어요.

## 전환
- 흐림(blur)이 기본: 초점이 확 빠지며 화면이 뿌옇게 되고, 그 속에서 다음 장면 고리가 맺혀요.
- 엔딩 쪽은 느린 페이드. 장면 쌓기: blur → fade. 컷은 쓰지 않아요.

## 대표 장면
1. **누운 고리 위를 도는 빛 점과 켜지는 꼬리표**
   ```
   // 고리: SVG ellipse 를 rotateX(68deg) rotateZ(-18deg) 로 눕힌 판 위에, 눈금은 짧은 line 120개
   S.ambient(t => {
     const a = M.anim([[0, 0], [.5, Math.PI * 2, {d: 7, e: 'inOutQuad'}]], t);   // 빛 점 각도
     M.place(dot, cx + rx * Math.cos(a), cy + ry * Math.sin(a));
     M.draw(trail, M.prog(t, .5, 7));                                         // 지나간 밝은 호
     nodes.forEach((n, i) => {
       const on = M.prog(t, n.at, .3);
       M.place(n.mark, n.x, n.y, {s: .6 + .4 * on, o: on});
       n.label.textContent = M.type(n.text, t, n.at + .1, 30);                 // 고정폭 대문자
     });
   });
   ```
2. **바짝 붙은 호와 얕은 초점**
   - 고리 판을 `scale 3.5` 로 키워 호 하나가 대각으로 지나가게 두고, 판 회전을 `M.anim` 으로 4초에 6도만 돌려요.
   - 꼬리표 층을 셋으로 나눠 앞·뒤 층에 `blur` 4~8px, 가운데 층만 또렷하게. 핵심 낱말 뒤 회색 칸은 `clipPath: inset(0 X% 0 0)` 으로 0.2초에 깔아요(장면 쌓기 marker: highlight).
   - 고리 안쪽엔 90도 돌린 보조 꼬리표를 호를 따라 놓고 흐리게.
3. **물러나며 드러나는 두 고리**
   - 판 크기를 `M.anim([[0, 3.5], [0, 1, {d: 4, e: 'inOutCubic'}]], t)` 로 줄이면서 엇갈린 두 번째 고리를 `M.draw` 로 1.5초에 그어요. 둘레 꼬리표는 마디 순서대로 0.25초 간격으로 켜고, 이미 켜진 것은 흰색에서 회색으로 식혀요.
   - 장면 사이는 `S.tr.blur` 로 초점이 빠졌다 맺히게.
4. **매듭으로 오므라드는 엔딩**
   - 고리 2~3개를 각자 다른 축으로 돌리며 지름을 화면의 15%까지 줄여 작은 매듭 마크로 모으고(`M.spring(t - t0, 'smooth')`), 꼬리표는 모두 페이드. 이어 산세리프 한 줄을 `blur` 10px → 0 으로 맺히게 했다가 2초 뒤 다시 흐려지며 빠져요.
