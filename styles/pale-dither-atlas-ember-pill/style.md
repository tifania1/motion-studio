# 점지도 회색판 주황 알약 입력 (제품 UI)

한 줄: 가는 격자와 점으로 찍은 지도 조각이 옅게 깔린 회색 판에서 문장 끝말만 주황으로 물들고, 흰 알약 입력창에 부탁이 쳐지면 주황 버튼이 눌리며 결과가 차오르는 AI 도구 런칭이에요. 사이사이 같은 무늬의 숯빛 판으로 컷 돼요.

## 보는 느낌
- 바탕은 아주 옅은 회색 판이에요. 그 위에 화면을 크게 나누는 머리카락 같은 격자선 몇 줄과, 작은 점을 촘촘히 찍어 만든 지도 조각 같은 덩어리가 가장자리 쪽에 흩어져 있어요(먹색 6~10%). 덩어리는 아주 천천히 흘러요.
- 네 귀퉁이에 작은 주황 십자 표시가 찍혀 판을 잡아 주고, 오른쪽 위에는 아주 작은 회색 꼬리표 하나가 늘 떠 있어요.
- 한 장면에 하나만 보여요. 가운데 한 줄 문장, 또는 흰 알약 입력창 하나, 또는 주황 버튼 하나. 여백이 화면의 80% 이상이에요.
- 기능을 보여 줄 땐 화면 아래에 작은 알약 입력창을 깔아 두고 위쪽에 대화 말풍선, 고정폭 결과 줄, 비스듬히 누운 상품 타일 격자가 차례로 놓여요.
- 몇 장면마다 바탕이 숯빛으로 뒤집혀요. 격자와 점 지도는 같은 자리에 흰색으로 남아요.

## 색
- 회색 판 80 · 먹 글자 15 · 주황 5.
- 바탕 #EBEBEA, 글자 #262626, 흐린 글자는 먹색 58%.
- 주황 #E8572A 는 문장 끝 낱말, 커서, 보내기 버튼, 귀퉁이 십자, 결과 줄 앞 작은 네모에만 써요. 주황 바탕 위 기호는 아주 짙은 갈색.
- 숯빛 판 #232323, 그 위 글자 #ECECEA. 숯빛 판에서도 강조는 주황 하나.
- 입력창은 #FAFAF9 흰빛, 그 안 칩은 연회색 #DADAD7.

## 글자
- Geist 500(한글은 Noto Sans KR Medium), 자간 −0.02em. 문장은 짧은 변의 7~8% 크기로 가운데 한 줄.
- 끝말 하나만 주황. 앞말과 끝말 사이를 살짝 띄워 끝말이 따로 들어오는 자리를 만들어요.
- 엔딩에서는 두 낱말을 짧은 변의 12% 정도로 키워 하나는 작게 하나는 크게 붙여요.
- 입력창 글은 Geist 500, 짧은 변의 4.5%. 결과 줄은 Geist Mono 400, 아주 작게(2.2%), 키는 회색·값은 주황.

## 질감과 모양
- 질감 필터 없이 매끈하게. 결은 바탕의 점 지도 조각과 가는 격자선이 맡아요.
- 입력창은 완전한 알약 모양(모서리 3u 이상), 아래로 넓고 아주 옅은 그림자 한 겹.
- 보내기 버튼은 주황 동그라미에 가는 위쪽 화살표, 그림자 아주 약하게.
- 상품 타일은 흰 둥근 사각(1u), 판 전체를 rotateX 45°·rotateZ −20° 쯤 눕혀요.

## 움직임
- 104BPM, 차분한 보통 속도. 장면은 2~2.5초씩 머물러요.
- 문장은 아래에서 1u 올라오며 흐림이 걷히고(power3.out, 0.5초), 주황 끝말은 한 박 늦게 같은 방식으로 붙어요.
- 입력창은 화면 밖에서 밀려 들어와 멈춘 뒤 타이핑, 끝나면 옆으로 빠지거나 아래로 작아져 화면 아래 자리에 앉아요.
- 주황 버튼은 스프링으로 튀어나오고 눌릴 때 0.92까지 줄었다 돌아와요.
- 결과 줄은 0.12초 간격으로 한 줄씩 생기고, 줄 끝 주황 네모가 톡 켜져요.
- 엔딩 두 낱말은 양쪽에서 미끄러져 와 가운데서 딱 맞붙어요. 마지막 마크는 아주 옅은 회색으로 서서히 떠올라요.

## 전환
- 회색 ↔ 숯빛은 컷. 같은 판 안에서 장면이 바뀔 땐 짧은 페이드나 흐림(S.tr.blur).
- 장면 쌓기 순서: cut → fade → cut → blur.

## 대표 장면
1. **밀려 들어오는 알약 입력창**
   ```js
   const k = M.spring(t - t0, 'smooth');
   M.place(pill, M.lerp(-W * .6, W * .5, k), H * .5);
   typed.textContent = M.type('사이트의 신발을 모두 가져와 줘', t, t0 + .5, 18);
   chip.style.opacity = M.prog(t, t0 + 1.4, .2);      // 사이트 이름을 회색 칩으로 감싸기
   caret.style.opacity = Math.floor(t * 2.6) % 2;      // 주황 세로 커서
   ```
2. **한가운데 주황 버튼 누르기**
   ```js
   const s = M.anim([[0, 0], [t1, 1.08, {d: .25, e: 'outBack'}], [t1 + .25, 1, {d: .15}],
                     [t1 + .8, .92, {d: .08}], [t1 + .88, 1, {d: .15}]], t);
   M.place(sendBtn, W / 2, H / 2, {s});
   // deco cursor 가 버튼으로 와서 누르는 순간과 맞춰요
   ```
3. **끝말만 주황 + 숯빛 판 컷**
   ```js
   S.chars(head);                                  // 앞말은 rise, 주황 끝말은 한 박 늦게
   const kw = M.ease.outCubic(M.prog(t, t0 + M.beat(1), .5));
   M.place(lastWord, x, y, {y: (1 - kw) * U, o: kw, blur: (1 - kw) * 3});
   // 다음 장면은 scheme 'paper'(숯빛)로 컷, 점 지도·격자는 같은 자리에 흰색으로
   ```
4. **결과 줄과 기울어진 타일 판**
   ```js
   rows.forEach((r, i) => {
     const k = M.prog(t, t2 + i * .12, .2);
     M.place(r, x0, y0 + i * lh, {o: k, x: (1 - k) * U});
     r.querySelector('.sq').style.opacity = k > .9 ? 1 : 0;   // 줄 끝 주황 네모
   });
   tiles.style.transform = `rotateX(45deg) rotateZ(-20deg) translateY(${M.drift(t, .02) * H}px)`;
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 도구·API 런칭, 개발자 서비스 소개, 검색·수집·자동화 기능 시연, 부탁 한 줄로 결과가 나오는 흐름, 기능 업데이트 공지.
- 피할 것: 주황 말고 다른 강조색, 굵은 블랙 제목, 그라디언트 빛 번짐, 손그림 선, 한 화면에 문장 두 줄 넘게, 빠른 글리치 컷.
- 입력창 옆 작은 기호는 브랜드 마크 대신 우리 쪽 간단한 주황 도형(점이나 불꽃 모양 선)을 새로 그려 써요.
