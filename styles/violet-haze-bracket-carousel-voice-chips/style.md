# 보랏빛 안개 괄호 진열과 말 입력 칩 (제품 UI)

한 줄: 숯빛 어둠 아래로 보랏빛 안개가 깔리고, 가는 흰 괄호 틀에 담긴 라벤더빛 사물들이 회전 진열대처럼 한 칸씩 넘어가요. 어두운 입력창에 말하듯 문장이 쳐지면 낱말 몇 개가 파스텔 칩으로 바뀌고, 끝은 옅은 회색 판의 보라 아이콘 타일과 그라디언트 낱말로 닫혀요.

## 보는 느낌
- 옅은 회색 판에 작은 글 한 줄로 조용히 열고, 곧 숯빛 판으로 넘어가요. 숯빛 판은 화면 아래 3분의 1에 보랏빛 안개가 낮게 깔려서 바닥이 있는 어두운 방처럼 보여요.
- 사물 장면은 가는 흰 선 틀 세 개가 원근을 두고 늘어선 진열대예요. 가운데 틀은 정면, 양옆 틀은 안쪽으로 돌아가 화면 가장자리에서 잘려요. 틀 속 사물은 색을 빼고 라벤더빛으로 물들여 한 식구처럼 보이게 해요.
- UI 장면은 화면 가운데 어두운 입력창 하나, 또는 비스듬히 뜬 어두운 편집 창 하나. 둘레는 비워 두고 뒤에서 보랏빛이 번져요.
- 중간에 한 번 부드러운 그림(수채 풍경 같은) 바탕 위에 알약 입력창을 띄우고, 그 창이 젖빛 보라 카드로 번지며 다음 장면이 열려요.
- 끝은 다시 옅은 회색 판. 가운데 보라 아이콘 타일과 작은 한 줄, 맨 아래 아주 작은 주소 한 줄.

## 색
- 숯빛 바탕 70 · 흰 글자와 선 15 · 보라 안개와 보라 타일 10 · 파스텔 칩 5.
- 바탕 #16151C, 글자 #E6E4EE, 흐린 글자는 같은 색 56%.
- 보라 강조 #5B4BC4(아이콘 타일, 버튼). 위 글자는 흰색. 안개와 엔딩 그라디언트는 #5B4BC4 → #B7A6F2.
- 칩 세 색: 민트 #9FDDB2, 라벤더 #B7A6F2, 살구 #F2C98A. 칩 글자는 짙은 숯빛 #1D1C24. 한 문장에 칩은 많아야 셋, 색은 칩마다 하나씩.
- 옅은 판 #E9E8EC(오프닝·엔딩), 그 위 글자 #1D1C24.

## 글자
- Geist 400 과 Noto Sans KR Medium. 작고 가볍게, 짧은 변의 3.5~5% 정도. 큰 제목을 쓰지 않아요.
- 입력창 글씨는 본문 크기, 칩 안 낱말과 파일 꼬리표·틀 좌표는 Geist Mono 로 더 작게(짧은 변의 1.6~2.2%).
- 엔딩 한 줄만 이름 부분을 보라 그라디언트 글자로 칠하고, 나머지 말은 흐린 회색.
- 가운데 정렬, 한 줄을 넘기지 않아요. 입력창 안 문장만 왼쪽 정렬로 두세 줄까지.

## 질감과 모양
- 비네트 0.25 하나만. 그레인 없이 매끈하게, 어둠은 보랏빛 안개로만 깊이를 줘요.
- 괄호 틀: 1px 흰 선 70%. 네 모서리 L자 괄호는 굵게, 사이 변은 30%로 옅게, 변 가운데 짧은 눈금 하나, 구석에 아주 작은 고정폭 숫자.
- 입력창: 바탕보다 한 단 밝은 숯빛 #26252D, 1px 흰 테두리 10%, 모서리 1.4u, 그림자는 거의 없이.
- 아이콘 타일: 둥근 정사각 안에 짙은 보라 면, 바깥에 연라벤더 테두리 한 겹과 아주 옅은 보라 빛.

## 움직임
- 96BPM, 보통 빠르기. 들어올 땐 power3.out, 진열대가 넘어갈 땐 power3.inOut.
- 작은 문장은 흐림 없이 타자로 쳐지고(초당 18~22자), 다 쳐지면 한 박 반쯤 머물러요.
- 진열대는 2박마다 한 칸. 머무는 동안 가운데 사물은 아주 천천히 돌고(4초에 20도), 틀은 그대로예요.
- 파형 막대는 말하는 동안만 출렁이고, 문장이 끝나면 낮게 가라앉아요.
- 카메라는 노트북·편집 창에서 천천히 물러나거나 다가가요. 갑자기 튀는 움직임은 없어요.

## 전환
- 옅은 판 ↔ 숯빛 판은 서서히(fade). 진열대 칸 넘김은 밀어내기(push). UI 장면에서 그림 바탕으로 갈 땐 흐림(blur).
- 장면 쌓기: fade → push → blur.

## 대표 장면
1. **괄호 틀 회전 진열대**
   ```
   // 틀 i 를 원통 둘레에 놓고, 2박마다 한 칸씩 돌림 (t 의 순수 함수)
   const step = M.at([[0, 0], [M.beat(2), 1], [M.beat(4), 2], [M.beat(6), 3]], t);
   const k = M.ease.inOutCubic(M.prog(t, M.beat(2) * step - .8, .8));
   frames.forEach((f, i) => {
     const a = (i - step + 1 - k) * 40;              // 각도(도)
     M.place(f, cx + Math.sin(a * Math.PI / 180) * W * .42, cy,
             { ry: -a, s: 1 - Math.abs(a) / 300, o: 1 - Math.abs(a) / 120 });
   });
   M.place(prop, cx, cy, { ry: t * 5 });               // 가운데 사물은 천천히 돎
   ```
   틀은 SVG `path` 로 모서리 괄호만 굵게, 변은 옅게. 사물 사진에는 `filter: grayscale(1)` 위에 라벤더 `mix-blend-mode: color` 한 겹.
2. **말 입력창과 칩**
   - 어두운 입력창을 `M.spring(t - t0, 'smooth')` 로 아래에서 1u 올리며 띄우고, 글은 `M.type(text, t, t0 + .3, 20)`.
   - 칩 낱말은 쳐지는 시각 `tc` 에 바탕 너비를 `M.box(chip, { w: chipW * M.ease.outCubic(M.prog(t, tc, .2)) })` 로 차오르게 하고 글꼴을 Geist Mono 로 바꿔요.
   - 파형 막대 12개는 `S.ambient` 안에서 높이 `h = .3 + .7 * Math.abs(Math.sin(t * 9 + i * 1.7))`, 문장이 끝나면 `* (1 - k)` 로 가라앉힘.
   - 장면 쌓기에서는 title: type 과 marker: color 로 강조 낱말에 칩 색이 깔려요.
3. **그림 바탕 위 알약이 보라 카드로 번짐**
   - 부드러운 그림 바탕 가운데 알약 입력창(흰 반투명 + 블러)에 짧은 말을 쳐요. 이어 알약을 `M.box` 로 화면 60% 크기의 둥근 카드로 늘리고, 안쪽을 보라 → 연분홍 세로 그라디언트로 `o` 0 → 1. 카드 테두리 밖 그림은 그대로 두고 뒤의 전환은 `S.tr.blur` 로 이어요.
4. **보라 타일과 물드는 한 줄 엔딩**
   - 옅은 판 가운데 아이콘 타일을 `M.spring` 으로 0.9 → 1, 연라벤더 테두리는 0.1초 늦게. 아래 한 줄은 어절마다 `background: linear-gradient(90deg, #5B4BC4, #B7A6F2)` + `background-clip: text`, `clipPath: inset(0 X% 0 0)` 을 0.5초에 걷어 내고, 앞 어절은 `M.color('#5B4BC4', '#C9C0EE', k)` 로 옅어지게 해요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발 도구·코딩 보조 런칭, 음성 입력·받아쓰기 기능 소개, 주변기기와 소프트웨어를 잇는 이야기, 차분한 다크 제품 소개.
