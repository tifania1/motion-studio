# 낙서 얼굴과 지우는 말 (손그림)

한 줄: 옅은 회색 위 굵은 고딕 문장. 줄마다 펜으로 그린 얼굴 낙서가 옆에 붙고, 줄 끝 칩이 체크에서 X 로 뒤집히거나 취소선으로 지워지며 말이 바뀌어요.

## 보는 느낌
- 가운데 정렬로 짧은 문장 줄이 위에서부터 하나씩 쌓여요. 줄은 많아야 셋, 줄 사이는 글자 높이의 1.3배.
- 줄마다 사람 얼굴 낙서 하나. 첫 줄은 왼쪽, 둘째 줄은 오른쪽, 셋째 줄은 다시 왼쪽처럼 번갈아 붙어 지그재그 리듬이 생겨요.
- 줄 끝에는 재질이 다른 칩 하나: 연파랑 알약(그라디언트 + 동그란 화살표 단추), 연초록 체크 상자(얇은 테두리), 위에 노란 띠가 있는 흰 메모 카드. 칩은 글자 크기와 같은 높이로 문장에 붙어 있어요.
- 매끈한 UI 칩과 손으로 그린 얼굴이 한 화면에 섞이는 게 이 결의 맛이에요. 바탕엔 아무것도 깔지 않아요.

## 색
- 바탕 80 · 글자 15 · 칩 색 5.
- 바탕 #EBEBEB, 글자 거의 검정 #111111. 얼굴 낙서도 같은 먹색 하나.
- 칩마다 연한 바탕 + 같은 계열 진한 글자: 파랑(#CFE2F7 / #2F74D0), 초록(#D3EBCB / #4FA05A), 빨강(#F2DADA / #C94A4A), 메모 띠 노랑(#F1E2A0). 지운 글은 회색 #8A8A8A.
- 생각 중 표시의 점 셋만 노랑·빨강·파랑을 조금씩.

## 글자
- Geist + Noto Sans KR, 굵게(700). 마무리의 한 단어 큰 장면만 900 으로 화면 높이의 30%.
- 문장 크기는 짧은 변의 5.5~6.5%, 자간 −0.02em. 칩 안 글자는 같은 크기, 굵기 500~600.
- 문장은 짧게(한국어 8~12자) 같은 틀을 줄마다 반복하고 칩 말만 바꿔요.

## 질감과 모양
- 질감 없음. 화면은 매끈하고, 손맛은 얼굴 낙서에만 둬요.
- 얼굴 낙서: 펜 선 굵기 0.3u, 머리카락은 먹으로 꽉 칠한 덩어리(곱슬·단발·짧은 머리처럼 실루엣이 다르게), 얼굴은 가는 선으로 눈·코·입만, 안경 하나쯤. 볼·턱 그늘에 점묘 몇 개. 표정은 무심하거나 살짝 웃음.
- 생각 중 표시: 동그라미 테두리 안에 한 줄 선으로 그린 옆얼굴. 선 굵기 0.35u.
- 칩 모서리: 알약은 완전히 둥글게, 상자는 0.4u, 메모는 1u. 칩 아래 부드러운 그림자 하나(장면 쌓기 card: shadow).

## 움직임
- 100BPM. 칩·얼굴은 back.out(1.3) 으로 아주 조금 넘쳤다 자리 잡아요.
- 줄 하나의 순서: 문장 0.3초 rise → 칩 0.25초 pop → 반 박 뒤 얼굴 0.25초 pop → 1박 뒤 칩 상태 바뀜 → 반 박 쉬고 다음 줄.
- 타자는 초당 14자, 굵은 세로 커서가 0.5초 주기로 깜빡여요. 지울 때는 초당 20자로 뒤에서부터.
- 숫자 칩(반응 수 같은 것)은 자리마다 위로 굴러 바뀌어요(number: odometer).

## 전환
- 밀어내기(push): 다 쌓인 줄들이 줄마다 반대 방향(홀수 줄 왼쪽, 짝수 줄 오른쪽)으로 0.5초에 빠지고, 가운데에 다음 장면이 남아요.
- 그 밖에는 컷. 둥근 조리개나 흐림 겹침은 쓰지 않아요.

## 대표 장면

1. 쌓이는 줄과 낙서 얼굴
   ```
   rows.forEach((r, i) => {
     const t = T0 + i * M.beat(4);
     S.fx.rise(r.text, t, { d: .3, y: 30, ease: 'power3.out' });
     S.fx.pop(r.chip, t + .3, { ease: 'back.out(1.3)' });
     S.fx.pop(r.face, t + .3 + M.beat(.5), { ease: 'back.out(1.3)' });   // r.face 는 줄 왼쪽/오른쪽 번갈아
     flip(r.chip, t + .3 + M.beat(1.5));                                   // 2번
   });
   ```
   - 얼굴 SVG 는 직접 그린 단순한 낙서로(머리 실루엣 path 하나 + 얼굴 선 몇 개). 실제 브랜드 캐릭터를 따라 그리지 않아요.
2. 칩이 뒤집힘
   - 화살표: 단추 안 화살표 rotate 0 → 180도, 0.25초 back.out.
   - 체크 → X: 체크 path 를 M.draw(path, 1 → 0) 로 0.12초에 거두고 X 두 획을 M.draw 로 0.1초씩. 칩 바탕·테두리·글자는 M.color(초록, 빨강, k) 로 0.2초.
   - 취소선: 글 가운데 높이에 2px 회색 선, scaleX 0 → 1 (transform-origin 왼쪽, 0.3초 power2.out), 글자는 #8A8A8A 로.
3. 말줄임 점이 칩이 됨
   ```
   // '…' 뒤로 점 n 개를 이어 붙임: i 번째 점 지름 = d0 * (1 + .18 * i), 오른쪽으로 갈수록 커짐
   // t1 부터 마지막 점 4개의 폭을 M.spring(t - t1 - j*.05, 'snappy') 로 지름 → 칩 폭까지 늘려 알약으로
   // 알약이 칩 자리에 닿으면 색이 먹색 → 칩 바탕색으로 0.2초, 안에 칩 글자가 fade
   ```
4. 체크 목록 지우기 (마무리)
   - 흰 카드 안 체크 목록이 아래에서 한 줄씩 올라오고 0.2초 간격으로 네모가 파랑으로 차며 체크, 동시에 글에 취소선 + 회색. 목록이 위로 흘러 넘치면 마지막 빈 칸 하나만 크게 남고 커서(M.Cursor)가 와서 눌러요.

## 문구 쓰는 법
- 원본은 같은 틀을 반복하는 부정문으로 리듬을 만들었지만, 우리 문구 원칙에 따라 대조 구문은 쓰지 않아요.
- 대신 "할 일을 지우는" 쪽으로 써요. 예: 줄마다 "회의 메모 정리 [☐]", "주간 보고 [☐]", "일정 맞추기 [☐]" → 칩이 차례로 체크되며 지워지고, 끝에 "이제 손이 비었어요".
- 얼굴 낙서는 그 일을 하던 사람들처럼 보이게 줄마다 다르게.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 서비스 재소개·리브랜딩, 해야 할 일을 덜어 주는 도구, 팀 협업 도구, 체크리스트·꿀팁, 고객 여러 명의 목소리를 모은 장면.
- 피할 것: 대조 구문 문구, 세리프·손글씨 글꼴, 그라디언트 바탕, 한 화면에 얼굴 셋 넘게, 얼굴에 색 칠하기.

## 배운 곳
- keyframe.gallery, mux 재생 ID aGYHpWNR1F9RzyvuWr1WBmphfZgVNFgkwXUjw101v1PQ.
- 0~8.4초: 깜빡이는 커서, 문장 타자, 말줄임 점이 커지며 알약으로 늘어나는 이음.
- 8.8~17초: 같은 틀의 문장 세 줄이 쌓이며 얼굴 낙서가 번갈아 붙고, 칩이 뒤집히는(화살표, 체크 → X, 취소선) 장면, 줄마다 반대로 빠지는 전환.
- 29~40초: 동그라미 속 한 줄 얼굴의 '생각 중', 낙서 얼굴 셋이 모인 회의 장면. 63~86초: 반응 수가 굴러 오르는 칩, 체크 목록이 한 칸씩 체크되며 지워지는 마무리.
