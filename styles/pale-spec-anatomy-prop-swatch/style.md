# 옅은 회색 명세 진열 (3D·사물)

한 줄: 옅은 회색 판 위에 글꼴, 모서리, 아이콘, 색을 하나씩 떼어 보여 주는 차분한 디자인 시스템 소개예요. 주황·황토 색면이 박자를 끊고, 납작한 아이콘은 반들한 3D 소품으로 자라 흰 카드 속에 들어가요.

## 보는 느낌
- 바탕은 거의 흰 옅은 회색 한 가지예요. 첫 장면은 아무것도 없이 1초 넘게 비워 두고, 작은 글 한 줄로 조용히 시작해요.
- 한 장면에서는 하나만 떼어 보여 줘요. 글꼴 하나, 모서리 하나, 아이콘 하나, 색표 하나. 둘레는 넉넉하게 비워요.
- 명세를 보여 줄 땐 화면보다 크게 잘라요. 글자 두 자나 둥근 귀퉁이 하나가 화면 절반 넘게 차고, 그 위에 앵커 점, 점선 안내선, 작은 수치 꼬리표가 붙어요.
- 회색 장면 사이에 주황·황토 색면이 한 장씩 끼어들어요. 황토 판에는 가는 기준 격자를 깔고 굵은 흰 선 아이콘을 올려요.
- 3D 소품(가방, 보석, 침대, 소파, 빵)은 부드러운 조명에 반들반들해요. 한가운데 하나만 두거나, 흰 카드 속 작은 아이콘으로 넣어요.
- UI 는 흰 카드와 폰 화면으로 보여 주고, 넓고 옅은 그림자로 바탕에서 살짝 띄워요. 화면 여러 장을 비스듬히 펼쳐 벽처럼 보여 주는 장면도 한 번쯤 넣어요.

## 색
- 회색 바탕 70 · 먹 글자와 선 15 · 색면과 소품 15.
- 바탕 #EDEDED, 글자 #222222, 보조 글자는 먹 55%, 안내선은 먹 15~25%.
- 명세 도형(모서리 덩어리)은 숯빛 #2B2B2B 로 꽉 칠해요.
- 색면 장면은 주황 #D8621C(글자 해부)와 황토 #D9992B(아이콘 격자). 각각 한 영상에 한두 장씩만 써요. 주황 위 글자는 거의 검정.
- 소품 색이 강조 역할을 해요: 분홍 보석 #E8478E, 테라코타 가죽 #B86A55, 청록 소파 #4E9C8A. 그래서 글자에는 색을 거의 넣지 않아요.
- 색표 장면은 색상 열 × 명도 행 격자로 화면을 꽉 채우고(위는 짙게, 아래로 갈수록 파스텔), 이름 머리글자 동그라미는 파스텔 바탕에 같은 계열 짙은 글자를 써요.

## 글자
- 둥근 기하 산세리프 한 가족(Geist, 한글은 Noto Sans KR Medium). 제목 굵기 500, 자간 -0.01em, 가운데 정렬.
- 크기 대비를 크게 둬요. 보통 문구는 짧은 변의 4~5%로 작게, 해부 장면 글자는 화면 높이의 80~120%로 잘리게.
- 굵기 목록 장면은 같은 글자 줄을 가는 굵기부터 아주 굵은 굵기까지 일곱 줄 쌓고, 줄 끝에 아주 작은 굵기 숫자, 줄 사이에 머리카락 같은 선을 그어요.
- 카드 속 글은 진한 제목 한 줄과 회색 보조 한 줄. 버튼은 검은 알약에 흰 글자.
- 꼬리표 칩은 작은 선 아이콘 + 낱말 하나, 옅은 회색 알약 안에.

## 질감과 모양
- 질감 없이 매끈하게 두고, 깊이는 그림자로만 내요. 카드 그림자는 크고 옅게(흐림 4u 안팎, 먹 10~14%).
- 카드·폰 모서리는 2.4u 로 넉넉하게 둥글려요.
- 안내선은 1px 점선, 앵커는 회색 테두리를 두른 작은 흰 원과 마름모.
- 황토 판 기준 격자는 1px 선 촘촘히, 가장자리에 아주 작은 눈금 숫자.
- 엔딩 타일은 두께가 있는 둥근 사각 판이에요. 옆면은 윗면보다 한 톤 어둡고, 위에서 비스듬히 내려다봐요.

## 움직임
- 96BPM, 장면마다 2~3초. 한 박에 한 가지만 바뀌어요.
- 들어올 땐 power3.out 으로 살짝 큰 데서 제자리로(1.04 → 1) 멈추고, 머무는 동안 카메라가 아주 천천히 다가가요(3초에 3% 안팎).
- 글은 한 글자씩 쳐지고(초당 12~14자), 가는 선은 0.6초에 그어져요.
- 수치는 정해진 값까지 부드럽게 굴러 올라가고(40% → 60%), 모양도 그 값을 따라 함께 바뀌어요.
- 3D 소품은 제자리에서 아주 느리게 몸을 돌려요(5초에 15도 안팎). 튀거나 흔들리지 않아요.

## 전환
- 컷이 기본이에요. 회색 장면 사이에 색면 장면을 컷으로 끼워 박자를 만들어요.
- 화면 벽에서 폰 한 대로 들어가거나 소품이 카드로 들어갈 때만 짧은 흐림 전환(`S.tr.blur`, 0.4초)이나 페이드를 써요. 장면 쌓기: cut → fade → push.

## 대표 장면

1. 글자 해부 오프닝
   ```
   // 빈 회색 1초 → 작은 이름 타자 → 가는 선이 왼쪽 끝에서 키높이까지
   name.textContent = M.type('글꼴 이름', t, 1.2, 13);
   M.draw(hair, M.ease.outCubic(M.prog(t, 2.4, .6)));
   // 컷 → 주황 판: 화면보다 큰 글자 두 자를 잘리게 두고 천천히 다가감
   M.place(glyph, W * .42, H * .5, {s: M.anim([[3.6, 1.04], [3.6, 1, {d: .5, e: 'outCubic'}], [4.1, 1.03, {d: 2.4, e: 'inOutSine'}]], t)});
   anchors.forEach((a, i) => a.style.opacity = M.prog(t, 3.9 + i * .04, .2));
   // 이어 굵기 목록: 일곱 줄을 한 덩어리로 위로 흘림
   list.style.transform = `translateY(${-M.anim([[6, 0], [6, rowH * 4, {d: 2.4, e: 'inOutCubic'}]], t)}px)`;
   ```
2. 모서리 다이얼과 아이콘 격자
   ```
   const pct = M.anim([[0, 40], [.4, 60, {d: 1.8, e: 'inOutCubic'}]], t);
   label.textContent = Math.round(pct) + '%';
   const r = size * pct / 100;
   corner.setAttribute('d', `M ${x} ${H} V ${y + r} Q ${x} ${y} ${x + r} ${y} H ${W}`);
   M.place(hA, x, y + r); M.place(hB, x + r, y);   // 핸들이 곡선 끝을 따라 미끄러짐
   ```
   - 점선 안내선 두 줄은 곡선 시작점을 지나 화면 끝까지 고정. 이어 황토 판으로 컷하고, 기준 격자 위 흰 선 아이콘을 `M.draw` 로 0.6초에 그은 뒤 한 박 뒤 다른 아이콘으로 컷해요.
   - 장면 쌓기에서는 deco handles·marks 가 제목 둘레에 선택 상자와 재단 표시를 깔고, number count 가 숫자를 굴려요.
3. 아이콘이 소품으로, 소품이 카드로
   ```
   const steps = S.$$('.step');   // 픽셀 아이콘 · 선 아이콘 · 3D 소품
   steps.forEach((el, i) => {
     const k = M.spring(t - i * M.beat(1), 'smooth');
     M.place(el, W * (.2 + i * .22), H * .55, {s: .3 + i * .35 * k, o: k});
   });
   row.style.transform = `translateX(${-M.anim([[0, 0], [0, W * .18, {d: 4, e: 'inOutSine'}]], t)}px)`;
   ```
   - 마지막 소품은 다음 장면에서 흰 카드(그림자 넓게, 모서리 2.4u)의 왼쪽 아이콘 자리로 `M.anim` 0.6초에 줄어들어 앉고, 카드 제목과 회색 보조 글이 차례로 쳐져요.
4. 색 견본과 두꺼운 타일 마무리
   - 색표 격자는 칸마다 `M.prog(t, (col + row) * .03, .25)` 로 왼쪽 위에서 물결처럼 켜져요. 이어 사진 한 장을 화면 가득 깔고, 그 사진에서 뽑은 색 견본 카드를 아래에서 하나씩 올려요.
   ```
   sw.forEach((c, i) => {
     const k = M.spring(t - .3 - i * .12, 'smooth');
     M.place(c, c.dataset.x * W, c.dataset.y * H + (1 - k) * H * .06, {o: k});
   });
   ```
   - 끝은 판에 `perspective` 를 주고 `rotateX(55deg) rotateZ(-35deg)` 로 눕힌 뒤, 주황·노랑·초록·분홍 그라디언트 두꺼운 타일을 위에서 0.12초 간격으로 내려놓아요. 타일 위엔 큰 아이콘이나 짧은 낱말 하나, `S.ambient` 로 아주 천천히 떠돌게 해요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·브랜드 가이드 공개, 앱 리뉴얼 소개, 여행·숙박·예약 서비스, 아이콘·3D 소품 세트 발표, 글꼴·색 체계 설명. 40초 이상 차분하게 훑는 영상.
- 피할 것: 그레인·종이 같은 거친 질감, 네온 빛 번짐, 빠른 글리치 컷, 굵고 빽빽한 제목, 한 화면에 강조색 여러 개.
- 색면 장면이 너무 자주 나오면 차분한 결이 깨져요. 회색 장면 서너 개에 색면 한 장 정도가 알맞아요.
