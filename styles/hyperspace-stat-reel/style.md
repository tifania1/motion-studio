# 초공간 숫자 결산 (시네마틱)

한 줄: 검은 화면에 흰 글이 왼쪽부터 쓸려 나오고, 큰 숫자 뒤로 파란 빛줄기가 쏟아지는 초공간. 글은 카메라 뒤로 지나가듯 커지며 빠지는 한 해 결산.

## 보는 느낌
- 거의 검은 바탕 한가운데 흰 글 한 줄. 장식 없이 글과 빛만 있는 영화 예고편 같은 화면이에요.
- 숫자 장면에서만 배경이 살아나요. 가장자리부터 파랑·흰 빛줄기가 가운데 어둠을 남기고 바깥으로 쏟아지고(초공간), 숫자는 그 어둠 한가운데에 놓여요.
- 사진 장면은 검은 바탕 위 떠 있는 사진 몇 장(가운데 한 장이 조금 크고 앞에), 그 위에 흰 글 한 줄.
- 오프닝은 한 낱말이 화면을 채울 듯 크게 떴다가 작아지며 다음 말이 붙고, 이어서 아주 굵은 대문자 두 줄이 쾅 쌓여요.

## 색
- 검정 #0E0E10 80 · 흰 글 12 · 빛(파랑 #3B66FF, 하늘 #9DB8FF, 흰빛) 8.
- 빛줄기는 파랑과 흰색을 7:3쯤 섞고, 가운데는 늘 어둡게 비워 둬요.
- 금빛(#D9B25A)은 돈·상 같은 장면에 한 번만, 빛 덩어리 하나로.

## 글자
- 둥근 기하 산세리프 600(Geist + Noto Sans KR). 문장은 짧은 변의 6~7%, 숫자는 14~18%.
- 단위 말(만, 건, 개국)은 숫자 아래에 숫자 크기 45%, 옅은 회색(onBgMuted)으로 붙여요.
- 오프닝의 굵은 두 줄만 Noto Sans KR Black 900 대문자, 줄 간격 0.9로 바짝.
- 자간 −0.02em, 가운데 정렬.

## 질감과 모양
- 그레인 0.05, 비네트 0.4. 화면 가장자리가 살짝 어두워 빛이 가운데로 모여 보이게.
- 사진 카드는 모서리 1.2u, 짙은 그림자 한 겹. 테두리 없음.

## 움직임
- 120BPM, 빠름. 한 박(0.5초)마다 낱말 하나나 숫자 한 단계.
- 들어오기: 왼쪽부터 부드러운 경계로 쓸려 나옴(expo.out, 초당 14자쯤). 글자 서너 자 폭으로 옅은 그라디언트가 앞장서요.
- 나가기: 반 박 머문 뒤 0.25초 만에 8% 커지며 블러 1.5u, 투명. 카메라가 글을 지나쳐 가는 느낌.
- 숫자: 0.6초 안에 확 올라가고(처음 빠르고 끝 느리게) 마지막 한 자리에서 딱 멈춤.

## 전환
- 컷이 기본. 숫자 장면 들어갈 때 줌(zoom), 문장끼리는 커지며 흐려지는 퇴장 덕에 blur 로 이어요.
- 장면 쌓기: cut → zoom → blur → cut.

## 대표 장면
1. **왼쪽부터 쓸려 나오는 문장**
   ```
   const cs = S.chars(line);                        // 글자 span
   cs.forEach((c, i) => {
     const k = M.clamp((t - t0) * 14 - i, 0, 3) / 3; // 초당 14자, 서너 자 폭의 부드러운 경계
     c.style.opacity = k; c.style.filter = `blur(${(1 - k) * .8 * u}px)`;
   });
   // 나가기: const e = M.prog(t, t1, .25); line.style.transform = `scale(${1 + .08 * e})`; line.style.filter = `blur(${e * 1.5 * u}px)`; line.style.opacity = 1 - e;
   ```
   장면 쌓기에서는 `title: fade` 에 스타일 stagger 0.7 이 붙어 비슷하게 따라가요.
2. **초공간 위 숫자**
   - 빛줄기: SVG 선 120개를 시드 고정 난수 `M.rng(7)` 로 각도·길이·색(파랑/흰)을 정하고, `S.ambient` 에서 선마다 `r = (r0 + t * v) % 1` 로 가운데에서 바깥으로 흘림. 선 길이는 r 에 비례해 길어지게(원근), 안쪽 15%는 비움. 장면 쌓기 `deco: streaks` 가 이 몫이에요.
   - 숫자: `S.fx.counter(num, t0, .6, 20, 100, {format: n => n + '+'})`, 단위 말은 `S.fx.fade(unit, t0 + .3)`.
3. **단어 바꾸기 (숫자 → 동사)**
   - 두 낱말을 같은 자리에 겹쳐 두고 글자 i 마다 `k = M.prog(t, tA + i * .03, .2)`. 앞 낱말 글자 opacity 1 − k, 뒤 낱말 글자 opacity k. 0.4초 안에 끝나요.
4. **오프닝: 크게 떴다 작아지는 낱말 + 굵은 두 줄**
   - 첫 낱말 scale 2.2 → 1 (`M.spring(t - t0, 'snappy')`) 뒤에 `M.type` 으로 다음 말이 붙음. 한 박 뒤 컷, Black 900 대문자 첫 줄 `S.fx.stamp`, 반 박 뒤 둘째 줄 `S.fx.stamp`.

## 어울리는 곳 / 피할 것
- 어울림: 연말 결산·한 해 돌아보기, 성과·마일스톤, 투자·수상 소식, 런칭 티저, 행사 하이라이트.
- 피할 것: 밝은 바탕, 손글씨·낙서 장식, 한 화면에 긴 문장, 알록달록한 원색. 빛줄기는 숫자 장면에만 써야 힘이 있어요.
