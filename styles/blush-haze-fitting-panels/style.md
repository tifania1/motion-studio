# 분홍 안개 속 폰 카드 (그라디언트·빛)

한 줄: 옅은 분홍 바탕 아래로 라벤더·분홍·주황 안개가 천천히 번지고, 가는 글씨 한 줄과 폰 화면, 오려낸 인물 사진이 숨 쉬듯 떠올랐다 사라지는 조용한 패션 쇼핑 무드예요.

## 보는 느낌
- 바탕은 거의 흰빛에 가까운 옅은 분홍이에요. 그 위로 아주 흐린 색 덩어리가 안개처럼 깔려요. 덩어리는 경계가 하나도 보이지 않을 만큼 흐리고, 장면마다 자리가 바뀌어요.
- 화면 한가운데에는 늘 한 가지만 둬요. 가는 글씨 한 줄, 폰 한 대, 카드 한 장, 오려낸 인물 하나. 둘레는 넓게 비워요.
- 안개는 화면 전체를 덮기도 하고(라벤더·하늘 덩어리), 왼쪽 아래 귀퉁이에서만 분홍·주황·노랑으로 피어오르기도 해요. 귀퉁이 안개 장면에서는 폰이나 글씨를 가운데에 두고 나머지는 맑은 분홍으로 남겨요.
- 중간에 바탕이 라벤더 단색으로 짙어지는 구간이 한 번 있어요. 이 구간에는 사진 카드와 반투명 패널이 떠요.

## 색
- 옅은 분홍 바탕 70 · 안개 덩어리 20 · 글자 7 · 강조 3.
- 바탕 #EBDDE8. 짙은 글자는 자두빛 회색 #3A2A3E, 보조 글자는 62% 투명.
- 안개: 라벤더 #B7A0CF, 하늘빛 회보라 #9FA3CF, 진분홍 #E56A9A, 주황 #F29A62, 노랑 #F6CB7E. 주황·노랑은 덩어리 한가운데에만 작게, 바깥은 분홍으로 풀어요.
- 라벤더 단색 판 #A88DBA 위 글자는 #20172A.
- 강조(accent) 산호 #EE7A6A 는 버튼 하나, 앱 아이콘 같은 작은 조각에만 써요. 글자 강조는 색 대신 흰 알약 상자로 해요.
- 안개 위 글씨는 흰색, 맑은 바탕 위 글씨는 자두빛 회색.

## 글자
- Geist 300 에 한글은 Noto Sans KR 500 을 받쳐 써요. 가늘고 둥근 기하 산세리프 느낌이에요.
- 크기는 작게. 문장은 화면 높이의 3~4%, 한 줄, 가운데 정렬. 제목도 크게 키우지 않아요(scale 0.85).
- 강조 낱말 하나는 흰 알약 상자 안에 넣어요. 상자 높이는 글자 높이의 1.6배, 모서리는 완전히 둥글게, 상자 안 글자는 짙은 색.
- 마지막 문장에 덧붙는 한 낱말(예: '드디어')은 문장보다 한 단계 작게, 반 박 늦게 오른쪽에 붙여요.
- 꼬리표(지시선 끝)는 아주 작은 300 굵기, 화면 높이의 1.4% 안팎.

## 질감과 모양
- 그레인·비네트 같은 질감은 얹지 않아요. 매끈한 안개 자체가 질감이에요.
- 폰·패널 카드: 흰색 70~85% 반투명 + 뒤 흐림(유리), 모서리 `--u` × 1.6, 그림자는 거의 없이 아주 옅게 한 겹.
- 사진 카드는 모서리 각진 네모, 테두리 없이 사진만.
- 지시선은 1px 자두빛 회색 50%, 끝에 지름 3px 점.

## 움직임
- 80BPM, 느림. 모든 이징은 `sine.inOut` 처럼 시작과 끝이 부드러워요.
- 글씨는 흐림 8px·투명에서 1초에 걸쳐 선명해지고, 머무는 시간은 2~3초. 나갈 때도 흐려지며 사라져요.
- 안개 덩어리는 늘 아주 천천히 흘러요(8초에 짧은 변의 5~8% 정도). 장면이 바뀌면 덩어리 색이 2초에 걸쳐 갈아입어요.
- 카드·폰은 크기 0.94 → 1 로 아주 살짝 커지며 나타나고, 확대 장면은 3~4초에 걸쳐 화면을 넘을 만큼 커져요.
- 지시선은 0.5초씩 하나하나 그어지고, 다음 선은 반 박 뒤에 시작해요.

## 전환
- 느린 페이드와 흐림 전환만 써요. 앞 장면이 흐려지며 빠지는 동안 다음 장면이 흐림에서 맺혀요.
- 바탕색이 분홍 → 라벤더로 바뀔 땐 컷 없이 2~3초에 걸쳐 색이 짙어져요.
- 장면 쌓기: fade → blur.

## 대표 장면
1. **안개 위 한 줄과 알약 낱말**
   ```js
   // 큰 원 4~5개를 blur(12u) 로 흐려 안개, 천천히 흘림
   S.ambient(t => blobs.forEach((b, i) => M.place(b, ...M.drift(i, t, {amp: W * .06, period: 9}))));
   // 글씨는 흐림에서 맺힘
   const k = M.ease.inOutSine(M.prog(t, t0, 1));
   M.place(line, cx, cy, {o: k, blur: (1 - k) * 8});
   // 강조 낱말 뒤 흰 알약이 0.6초에 펴짐
   pill.style.clipPath = `inset(0 ${(1 - M.prog(t, t0 + .8, .6)) * 50}% round 999px)`;
   ```
   장면 쌓기에서는 bg: aurora + title: blur + marker: highlight 로 같은 결이 나와요.
2. **빈 카드가 커져 상품 화면으로**
   ```js
   // 가운데 옅은 네모(화면 짧은 변의 22%)가 떠 있다가 3.5초에 화면을 넘게 커짐
   const s = M.anim([[0, 1], [tA, 5.2, {d: 3.5, e: 'inOutSine'}]], t);
   M.place(card, cx, cy, {s});
   // 커지는 동안 카드 안 상품 사진·이름·값이 o 0 → 1
   inner.style.opacity = M.prog(t, tA + 1.6, 1.2);
   ```
   끝 무렵엔 `S.tr.blur` 로 다음 장면에 넘겨요.
3. **귀퉁이 안개와 폰**
   - 왼쪽 아래에 분홍·주황·노랑 원 셋을 겹쳐 흐리고(가운데가 노랑), 나머지는 맑은 분홍. 가운데 유리 폰(frame: phone)이 `M.spring(t - t0, 'smooth')` 로 0.94 → 1 커지며 나타나요.
   - 폰 둘레로 아주 작은 흰 점 20~30개가 `M.rng(7)` 자리로 흩어져 천천히 떠다니면 공기감이 살아요.
4. **인물 지시선 → 라벤더 사진 카드**
   ```js
   // 오려낸 인물 둘레 지시선을 반 박 간격으로 하나씩
   leaders.forEach((p, i) => M.draw(p, M.ease.outCubic(M.prog(t, t0 + i * M.beat(.5), .5))));
   // 그동안 바탕이 분홍에서 라벤더로
   S.root.style.background = M.color('#EBDDE8', '#A88DBA', M.prog(t, t0 + 1, 2.5));
   ```
   이어 사진 카드 3장을 높낮이 다르게(가운데만 위로) `M.place(c, x, y, {o: k, blur: (1 - k) * 6})` 로 하나씩 띄우고, 유리 패널 하나를 작게 띄웠다가 화면을 넘게 키워 목록을 보여 줘요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 패션·뷰티 쇼핑 서비스, 개인 맞춤 추천 기능 소개, 가상 착용·카메라 기능, 초대제·멤버십 런칭 티저, 차분한 브랜드 무드 필름.
- 피할 것: 빠른 컷과 박자 맞춘 몰아치기, 굵고 큰 제목, 강한 원색 면을 넓게 칠하기, 손그림 선·종이 질감, 한 화면에 문장 여러 줄.
- 비슷한 '흐릿한 주황 바탕 위 입력창·폰' 결보다 바탕이 훨씬 옅고, 안개가 귀퉁이에만 피어오르는 장면이 많아 여백이 넓어요.
