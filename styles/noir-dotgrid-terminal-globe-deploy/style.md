# 검은 점판 배포 데모 (제품 UI)

한 줄: 검은 점 격자 위에서 청록 블록 커서가 명령을 치고, 비스듬한 코드 창에는 문장이 흰 반전 상자째 쳐져요. 빌드 로그가 쏟아진 뒤 점 지구본에 초록 점이 켜지고, 청록 막대가 차오르는 대시보드로 이어지는 개발자 데모.

## 보는 느낌
- 거의 검은 바탕. 화면 가장자리에 아주 흐린 점이 세로 기둥처럼 깔려 있고, 가운데는 비워 둬요. 한 화면에 창이나 사물 하나만 놓아요.
- 흐름은 명령 → 코드 → 소리 → 배포 → 지구 → 대시보드 순서로, 장면마다 개발자가 실제로 밟는 한 단계를 보여 줘요.
- 창과 노트북, 대시보드는 대개 살짝 비스듬히 누워 있고, 카메라가 천천히 다가가거나 미끄러지며 훑어요. 가장자리는 비네트로 어둑하게 가라앉아요.
- 지구본은 경도·위도 선 대신 작은 점을 촘촘히 박아 만든 어두운 공이에요. 그 위에 얇은 테두리 카드와 초록 점이 떠요.

## 색
- 검정 바탕 #0B0C0D 75 · 밝은 회색 글자 #E8EAEA 18 · 청록 #1FD5F9 5 · 초록 #35E07A 2.
- 청록은 커서, 빌드 로그 글자, 보내기 버튼에만 써요. 대시보드 막대는 가라앉은 청록 #2A6E73.
- 초록은 '연결됨·실행 중' 표시에만 써요(지구본 위 점과 네모, 상태 꼬리표). 노랑·회색 꼬리표는 시작 중·잠듦 같은 다른 상태에 아주 작게.
- 카드와 창 면은 #16181A, 테두리는 흰색 10~14%.

## 글자
- 명령, 코드, 꼬리표, 로그는 Geist Mono(한글은 Noto Sans KR 500). 화면 높이 2.5~3.5%로 작게, 왼쪽 정렬.
- 대시보드 제목과 카드 이름은 Geist 500. 굵기 대비보다 크기와 밝기 차이로 위계를 만들어요.
- 상태 꼬리표와 칸 이름은 고정폭 대문자, 자간 +0.06em, 아주 작게.
- 코드 줄 번호는 옅은 회색 35%. 강조할 문장은 흰 반전 상자(바탕 흰색, 글자 검정)로 띄워요.

## 질감과 모양
- 비네트 0.35. 그 밖의 질감은 쓰지 않고 화면을 맑게 둬요.
- 창과 카드는 모서리 `--u` × 0.8, 1px 흰 테두리, 그림자는 거의 없음. 터미널 창 위에는 회색 점 세 개.
- 점 격자는 흰색 8% 점, 간격 1.2u 안팎. 지구본 점은 가장자리로 갈수록 옅어져 둥근 부피를 만들어요.
- 연결 표시는 초록 네모(모서리 0.3u)와 그 둘레 네 귀퉁이 꺾쇠.

## 움직임
- 100BPM, 보통 빠르기. 카메라 이동은 `power3.inOut` 으로 느리게 다가가고 느리게 멈춰요.
- 타자는 초당 18~24자, 블록 커서는 0.5초 주기로 깜빡여요.
- 빌드 로그는 줄이 0.05~0.08초마다 하나씩 붙고, 화면이 차면 위로 밀려 올라가요.
- 음성 파형은 흰 알약 막대 다섯 개가 박자에 맞춰 키가 오르내려요. 가운데 막대가 가장 크게.
- 지구본은 20초에 한 바퀴 남짓, 거의 멈춘 듯 천천히 돌아요.

## 전환
- 컷이 기본. 창에서 지구본으로 넘어갈 때처럼 공간이 바뀌면 흐림(blur)으로 녹이고, 끝 로고 판으로는 느린 페이드.
- 장면 쌓기: cut → blur → fade.

## 대표 장면

1. 커서와 굴러가는 자동완성 목록
   ```js
   // 블록 커서 깜빡임 → 명령 타자 → 옆 목록이 원통처럼 굴러 한 줄에서 멈춤
   S.ambient(t => {
     cursor.style.opacity = (t < 1.2 && Math.floor(t * 2) % 2) ? 0 : 1;
     cmd.textContent = M.type(cmdText, t, 1.2, 20);
     const roll = M.anim([[0, 0], [2.2, picked, {d: 1.4, e: 'inOutCubic'}]], t);
     items.forEach((el, i) => {
       const d = i - roll;                       // 고른 줄과의 거리
       M.place(el, x, cy + d * lineH, {o: Math.max(0, 1 - Math.abs(d) * .28)});
     });
   });
   ```
2. 흰 반전 상자로 쳐지는 코드 문장
   ```js
   // 비스듬한 코드 창으로 다가가며 줄마다 흰 상자를 깔고 타자, 다 쳐지면 상자를 걷음
   S.ambient(t => {
     const z = M.anim([[0, 1], [0, 1.6, {d: 2.5, e: 'inOutCubic'}]], t);
     M.place(editor, cx, cy, {s: z, rx: 18, rz: -6});
     lines.forEach((ln, i) => {
       ln.textContent = M.type(texts[i], t, .8 + i * .9, 22);
       ln.classList.toggle('inverse', t < 3.8);     // 흰 바탕 · 검정 글자
     });
   });
   ```
   장면 쌓기에서는 marker: highlight 로 강조 말에 같은 반전 상자가 깔려요.
3. 빌드 로그에서 점 지구본으로
   ```js
   // 청록 로그가 쏟아진 뒤 흐림 전환, 지구본 위 카드에서 초록 선이 내려와 네모를 켬
   S.ambient(t => {
     log.style.transform = `translateY(${-Math.max(0, M.prog(t, 0, 4) * logH - viewH)}px)`;
     globe.style.transform = `rotate(${t * 18}deg)`;      // 점 무늬만 천천히 돌림
     M.draw(dropLine, M.ease.outCubic(M.prog(t, 5.2, .6)));
     M.place(node, nx, ny, {s: M.spring(t - 5.8, 'snappy'), o: t > 5.8 ? 1 : 0});
   });
   // 장면 사이: S.tr.blur
   ```
   이어서 `M.rng(시드)` 로 고른 표면 자리 8~12곳에 초록 점을 0.3초 간격으로 켜고, 몇 개에만 고정폭 꼬리표를 붙여요.
4. 비스듬한 대시보드
   - 어두운 대시보드를 rotateX 14° 로 눕혀 두고 카메라가 왼쪽 위에서 오른쪽 아래로 천천히 미끄러져요(`M.anim`, 4초, inOutCubic).
   - 막대는 아래에서 위로 차례로 차오르고(`M.box` 높이, 0.08초씩 늦게), 카드의 상태 꼬리표는 초록·노랑·회색 점과 고정폭 대문자로 하나씩 켜져요. 숫자는 장면 쌓기 number: count 로 올라가요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발자 도구·API 런칭, 배포·인프라 서비스 소개, 음성·실시간 기능 데모, SDK 사용법 짧은 투어, 운영 대시보드 소개.
- 피할 것: 밝은 바탕, 손그림 선과 종이 질감, 강조색 여러 개(청록 하나와 상태용 초록만), 통통 튀는 이징, 큰 굵은 제목으로 화면 채우기.
