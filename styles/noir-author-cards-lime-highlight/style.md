# 이름표 카드와 연두 형광펜 (제품 UI)

한 줄: 점 격자가 옅게 깔린 검은 바탕에 어두운 둥근 카드가 하나씩 떠요. 카드 위 작은 이름표 아래로 문장이 흐린 회색으로 써진 뒤 핵심 낱말에 연두 형광펜이 칠해지고, 그 아래 가는 선과 연두 점으로 그린 작은 도식이 이어지는 협업 리서치 UI 필름이에요.

## 보는 느낌
- 거의 검은 바탕에 아주 옅은 점 격자. 화면 한가운데 어두운 회색 카드 한 장이 놓이고, 둘레는 넉넉하게 비워 둬요.
- 카드 왼쪽 위 바깥에 누가 쓴 글인지 알려 주는 작은 회색 이름표, 카드 안 오른쪽 위에 작은 복사 아이콘. 카드 위쪽 절반엔 문장 세 줄 안팎, 아래쪽 절반엔 작은 선 도식이 들어가요. 카드 아래 끝은 바탕으로 살짝 어둡게 녹아요.
- 카드마다 이름표 주인이 바뀌어서 여러 사람이 차례로 답을 다는 흐름처럼 보여요.
- 중반에는 카메라가 물러나 노드 캔버스가 돼요. 왼쪽에 작은 카드들이 세로로 쌓이고, 가는 곡선들이 더하기 동그라미 하나로 모여 오른쪽 큰 입력 카드로 이어져요.
- 끝은 카드 없이 검은 바탕에 문장 한 줄만 남아요.

## 색
- 검정 바탕 #111211 70 · 카드 회색 #232423 20 · 글자 흰빛 #ECECEA 7 · 연두 #B8E06A 3.
- 연두는 형광 상자(25~30% 투명), 도식의 점, 커서 화살표에만 써요. 커서 이름표는 짙은 초록 알약에 연두 글씨.
- 도식에만 잠깐 연보라 #C9B8F0(반짝이)과 검붉은 #4A1C28(차오르는 덩어리)이 들어가요. 마지막 문장 한 줄도 연보라로 칠해요.
- 연결 곡선과 쓰는 중인 글자는 흰빛 35~45%.

## 글자
- Geist 400 하나로 갑니다(한글은 Noto Sans KR Medium). 카드 안 문장은 짧은 변의 3.5~4%, 줄 간격 1.3, 왼쪽 정렬.
- 이름표·꼬리표·문서 본문은 짧은 변의 1.6~2%로 아주 작게, 흰빛 55%.
- 마지막 한 줄 문장만 짧은 변의 6~7%로 키우고 가운데 정렬, 자간 −0.01em. 굵게 쓰지 않아요.

## 질감과 모양
- 질감 없이 매끈해요. 그림자도 거의 없고 카드와 바탕의 밝기 차이만으로 층을 나눠요.
- 카드 모서리는 `--u` × 2로 둥글게, 테두리는 흰빛 6% 1px.
- 형광 상자는 글자 높이보다 위아래로 조금 큰 사각형, 모서리 아주 살짝 둥글게.
- 도식 선은 1.5px 안팎, 연두 점은 짧은 변의 3% 크기의 꽉 찬 원.

## 움직임
- 96BPM, 차분한 속도. 들어오는 건 `power3.out`으로 부드럽게 멈추고, 도식 선은 `inOutCubic`으로 그어요.
- 카드 한 장에 3~4초: 문장 타이핑(1.2초) → 흰빛으로 밝아짐(0.3초) → 형광 상자 하나씩(0.25초 간격) → 도식 그리기(0.8초) → 한 박 머묾.
- 다음 카드는 아래에서 밀려 올라오며 앞 카드를 위로 밀어내요. 새 카드는 처음에 흐린 상태로 떴다가 글이 써지면서 또렷해져요.
- 커서는 곡선 경로로 미끄러지듯 다가가 누를 때 살짝 작아졌다 돌아와요.
- 긴 문서는 카드 안에서 일정한 속도로 위로 흘러요(초당 화면 높이 6~8%).

## 전환
- 카드끼리는 세로 밀어내기(push), 문장 한 줄 장면끼리는 컷, 노드 캔버스로 물러날 때와 마무리 직전에는 느린 페이드.
- 장면 쌓기: cut → push → fade.

## 대표 장면
1. **이름표 카드 타이핑과 형광펜**
   ```js
   // 카드 위 이름표, 문장은 흐린 회색으로 써진 뒤 밝아지고 낱말마다 형광 상자
   S.ambient(t => {
     txt.textContent = M.type(line, t, t0, 26);
     txt.style.opacity = .4 + .6 * M.ease.outCubic(M.prog(t, t0 + 1.2, .3));
     marks.forEach((m, i) => m.style.transform = `scaleX(${M.ease.outCubic(M.prog(t, t0 + 1.6 + i * .25, .25))})`); // transform-origin: left
   });
   ```
   장면 쌓기에서는 frame card + title type + marker highlight 로 같은 결이 나와요.
2. **카드 아래 작은 도식**
   ```js
   // 연두 점 두 개 → 가는 곡선이 한 점으로 모임
   dots.forEach((d, i) => M.place(d, x0, y0 + i * gap, { s: M.spring(t - t1 - i * .1, 'smooth') }));
   curves.forEach((p, i) => M.draw(p, M.ease.inOutCubic(M.prog(t, t1 + .3 + i * .08, .8))));
   // 변형: 교차하는 연두 선 + 연보라 반짝이가 하나씩 톡, 또는 아래에서 검붉은 덩어리가 차오르고 연두 점이 M.drift 로 떠다님
   ```
   다음 카드는 `S.tr.push` 를 위 방향으로 써서 앞 카드를 밀어내요.
3. **노드 캔버스와 이름표 커서**
   ```js
   // 왼쪽 카드들 → 곡선 → 더하기 노드 → 입력 카드, 커서가 프롬프트를 치고 전송
   links.forEach((p, i) => M.draw(p, M.prog(t, t2 + i * .1, .7)));
   const cur = new M.Cursor(el, { label: '이름', color: '#B8E06A' });
   cur.path([[t2 + 1, inputX, inputY], [t2 + 3.2, sendX, sendY]]);
   prompt.textContent = M.type(text, t, t2 + 1.2, 30);
   const k = M.cursorAt(t, t2 + 3.4);           // 누르는 순간 전송 버튼이 살짝 눌렸다 돌아옴
   ```
   누른 뒤 입력 카드가 넓어지며 긴 문서가 되고, 안쪽 글이 위로 흘러요.
4. **연보라 한 줄 마무리**
   - 카드 없이 점 격자 검은 바탕 가운데 연보라 문장 한 줄(`M.type`), 문장 끝 아래에 커서와 이름표가 멈춰 있어요. 다음 문장은 컷으로 갈아 끼우고, 마지막엔 흰빛 이름 한 줄로 바꿔요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 리서치·글쓰기 도구, 협업 노트·캔버스 앱, 노드 기반 작업 흐름 소개, 출처와 근거를 강조하는 기능 런칭, 팀원 여럿의 생각을 모으는 이야기.
- 피할 것: 밝은 바탕, 굵은 제목과 큰 글자 쇼, 연두 바탕을 넓게 칠하기, 빠른 컷 몽타주, 그라디언트 빛 번짐과 유리 질감.
- 연두는 아껴 쓸수록 형광펜이 눈에 잘 들어와요. 한 카드에 형광 상자는 세 개까지만 둬요.
