# 소품이 끼어드는 헤드라인 (3D·사물)

한 줄: 아래쪽이 라벤더로 번지는 밝은 바탕에 헤드라인 어절이 물결치듯 내려앉고, 낱말 사이로 작은 3D 소품이 비집고 들어가요. 마지막엔 문장 둘레로 소품 격자가 퍼지며 물러나요.

## 보는 느낌
- 친근하고 말랑한 앱 광고. 글자는 단정한데 사이사이 끼어든 소품이 장난스러워요.
- 바탕은 위가 거의 흰 회색, 아래로 갈수록 라벤더 빛이 번져요. 화면 아래쪽이 살짝 따뜻하게 빛나는 느낌.
- 채팅·대시보드 같은 UI 장면도 같은 바탕 위에서 둥글고 가볍게.

## 색
- 바탕 80 · 글자 10 · 소품 7 · 강조 3.
- 바탕 #E9E9EC → 아래 라벤더 #BCC4DB (아래 30%만 번지게).
- 글자 #121212. 사용자 말풍선은 연파랑 #C0CCE4 + 먹색 글자, 상대 말풍선은 #E1E1E3.
- 강조 파랑 #2563D9: 체크 표시, 도넛 차트, 링크. 소품은 자기 색 그대로(노랑 #F2C66B, 분홍, 나무색 등 부드러운 색).

## 글자
- 둥근 기하 고딕 Semibold가 가장 잘 맞아요. fonts/ 에는 그런 글꼴이 없어서 Geist 600 + Noto Sans KR 700 으로 두었어요.
- 헤드라인은 짧은 변의 7%, 두 줄, 가운데. 한 줄에 어절 셋 안팎이어야 소품이 들어갈 틈이 보기 좋아요.
- 소품 크기는 글자 높이의 1.1~1.3배.

## 질감과 모양
- 화면 질감 없음.
- 말풍선·카드 모서리 3.2u, 그림자 아주 옅게. 대시보드 카드는 흰 바탕에 연한 색 칸(파랑·초록·베이지 10%).
- 소품 3D 사진은 투명 배경. 소품끼리 각도·조명을 맞춰 만들어요(ChatGPT 웹에서 고화질로: "small cute clay 3D icon of a [물건], soft studio light, plain background, 3/4 view, no text").

## 움직임
- 108BPM. 어절과 소품은 반 박 안에 하나씩, 빠르게 쌓이고 오래 머물러요.
- 어절 정렬은 'snappy'(넘침 거의 없음), 소품은 'pop' 또는 back.out(1.2)로 아주 조금 튐.
- 머무는 동안 소품은 각자 다른 위상으로 아주 작게 떠다님(S.fx.bob 0.3u).
- 채팅: 새 말풍선이 아래에서 올라오면 이전 말풍선은 위로 밀리며 blur 2px + 옅어짐(뒤로 물러나는 깊이감).
- 대시보드: 카드가 scale .9 → 1 로 커지는 0.8초 동안 숫자가 S.fx.counter 로 같이 오름.

## 전환
- 장면 사이 대부분은 0.3초 페이드, 큰 마무리 문장만 zoom(크게 시작해 작아짐).
- 로고 엔딩은 컷으로 검은 바탕 가운데 앱 아이콘.

## 대표 장면

1. 물결 등장 + 소품 끼어들기 (2~3초)
   ```
   const R = M.rng(5), words = S.words(head);
   words.forEach((w, i) => {
     const ti = t0 + i * .1, dy = (R() - .5) * 3 * u;
     const k = M.spring(t - ti, 'snappy');
     w.style.transform = `translateY(${(dy * (1 - k)).toFixed(2)}px)`; w.style.opacity = M.prog(t, ti, .1);
   });
   gaps.forEach((g, j) => {                                 // 소품이 들어갈 틈(빈 span)
     const tj = t1 + j * .12;
     g.style.width = (M.spring(t - tj, 'snappy') * propW) + 'px';
     const p = M.spring(t - tj - .05, 'pop');
     g.firstChild.style.transform = `scale(${p}) rotate(${(-12 * (1 - p)).toFixed(2)}deg)`;
   });
   ```
2. 채팅에서 대시보드로
   - 말풍선이 쌓이며 지난 것은 흐려지고, "분석 중" 상태 카드(아바타 + 작은 그래프 아이콘)가 왼쪽으로 비켜서면 오른쪽에 대시보드 카드가 커지며 숫자가 오름.
3. 앱 아이콘 궤도
   ```
   icons.forEach((ic, i) => {
     const a = t * .9 + i / n * Math.PI * 2, z = Math.sin(a);      // z: 앞(1)·뒤(−1)
     M.place(ic, cx + Math.cos(a) * rx, cy + z * ry * .35, { s: .65 + .35 * (z + 1) / 2 });
     ic.style.zIndex = Math.round((z + 1) * 50);
   });
   ```
4. 소품 격자로 물러나기 (마무리 3초)
   ```
   const s = M.anim([[t2, 4], [t2 + .02, 1, { d: .35, e: 'outCubic' }], [t2 + .6, .8, { d: 2.4, e: 'outQuad' }]], t);
   head.style.transform = `scale(${s})`; grid.style.transform = `scale(${s})`;   // 같은 배율로 함께
   props.forEach(p => p.el.style.transform = `scale(${M.spring(t - (t2 + .1 + p.ring * .1), 'pop')})`);
   ```
   - 격자 칸은 문장 둘레를 비우고 링(문장에서 칸 거리) 번호를 미리 매겨 둬요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 소상공인·자영업 대상 서비스, AI 비서·도우미 앱, 친근한 브랜드 소개, 앱 출시.
- 피할 것: 어두운 바탕(엔딩 로고 한 컷은 괜찮아요), 날카로운 대문자 그로테스크, 거친 질감, 사진을 꽉 채운 장면. 축하 장면의 색종이는 쓰더라도 한 번만, 시드 난수로.
