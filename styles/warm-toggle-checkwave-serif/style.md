# 토글 연쇄와 체크 물결 (제품 UI)

한 줄: 따뜻한 회색 바탕에서 설정 패널의 토글이 위에서부터 줄줄이 켜지고, 차분한 세리프 문장 한 줄에 테라코타 손 타원이 그어져요. 원판 격자에는 체크 표시가 물결처럼 차오르는 조용한 설정 안내 필름이에요.

## 보는 느낌
- 바탕은 따뜻한 회색 한 가지예요. 그 위에 연한 흰빛 패널 하나, 세리프 문장 한 줄 정도만 놓아서 여백이 넉넉해요.
- UI는 늘 한 덩어리만 보여 줘요. 토글 목록 패널, 인사 제목 아래 입력 카드, 대화 한 묶음 정도예요. 장면이 바뀌면 패널이 화면 가장자리로 반쯤 밀려나 가운데를 문장에 내줘요.
- 문장 장면에서는 한쪽 가장자리에 잘린 패널, 반대쪽에 사람 아이콘을 담은 원판 기둥을 두고, 가는 테라코타 가로선이 둘을 문장 양옆에서 이어 줘요.
- 절정은 화면을 꽉 채운 원판 격자예요. 원판마다 체크가 차오르고, 가운데 원판 몇 개를 비운 자리에 문장이 들어가요.

## 색
- 따뜻한 회색 #E5E1DA 70 · 먹색 글자 #2A2622 15 · 패널 흰빛 #F4F2EE 10 · 테라코타 5.
- 테라코타는 손 타원, 연결선, 체크 원판, 보내기 버튼, 진행 표시처럼 '됐다·이어졌다'는 신호에만 써요. 원판 칠은 #CB6B52, 글자를 얹는 버튼은 조금 짙은 #B5563F 에 흰 글자.
- 토글이 켜진 색만 맑은 파랑 #3B82D6. UI 안에서만 쓰고 문장이나 장식에는 쓰지 않아요.
- 말을 마친 문장은 #BDB8B0 정도의 옅은 회색으로 가라앉혀요.
- 원판 바탕은 바탕보다 살짝 밝은 #EFECE7.

## 글자
- 문장·제목: 고운바탕 400. 짧은 변의 5~6%, 가운데 정렬 두 줄, 줄 간격 1.15, 자간 −0.01em. 굵게 쓰지 않아요.
- 인사 제목은 같은 세리프로 조금 크게(짧은 변의 7%), 앞에 작은 테라코타 별 기호 하나.
- UI 글자: Geist(한글 Noto Sans KR Medium), 짧은 변의 1.6~2%. 목록 이름, 입력창 안내 문구, 작업 줄처럼 작게.
- 마무리 꼬리표는 테두리만 있는 알약 안에 작은 대문자 고정폭 느낌으로, 세리프 두 줄 위에 얹어요.

## 질감과 모양
- 질감 없이 매끈해요. 그레인이나 비네트를 넣지 않아요.
- 패널·카드: 모서리 1.2u, 아주 옅은 회색 테두리, 넓게 번지는 부드러운 그림자 한 겹.
- 손 타원은 테라코타 2~3px, 시작과 끝이 겹치지 않고 오른쪽 아래로 꼬리가 빠져요. 연결선은 1.5px 곧은 가로선.
- 원판은 그림자가 아주 옅은 납작한 원, 체크는 흰 2px 선.

## 움직임
- 96BPM, 보통 속도. 들어오는 건 `power3.out` 으로 부드럽게 멈춰요.
- 토글은 0.08초 간격으로 위에서 아래로 연쇄. 손잡이는 0.18초에 미끄러지고 바탕색이 회색에서 파랑으로 바뀌어요.
- 문장은 어절마다 0.12초 간격으로 옅게 떠올라요. 1.5~2초 머문 뒤 0.4초 동안 옅은 회색으로 가라앉아요.
- 손 타원과 연결선은 0.6초 동안 한 획으로 그어지고(`inOutCubic`), 떠날 때는 그은 방향 그대로 끝부터 걷혀요.
- 체크 물결은 열마다 0.1초씩 늦게 시작해요. 고리 0.3초 → 파이 채움 0.35초 → 체크 0.15초.
- 커서는 크게 움직이지 않아요. 목표 근처로 천천히 미끄러져 와서 한 번만 눌러요.

## 전환
- 컷이 기본이에요. 가라앉은 문장이나 패널을 그대로 둔 채 다음 요소가 들어오니까, 장면이 바뀌어도 화면이 이어져 보여요.
- 패널은 옆으로 밀려나며(push) 자리를 내주고, 대화 장면에서 마무리 문장으로 갈 때만 짧은 페이드를 써요.
- 장면 쌓기: cut → fade → push.

## 대표 장면
1. **토글 연쇄 후 패널 밀어내기**
   ```
   const rows = S.$$('.toggle');               // 맨 위 '전체 켜기' + 목록 토글들
   const cur = new M.Cursor(S.$('.cursor'));
   S.ambient(t => {
     const tc = M.cursorAt(cur, [[0, rows[0], 'move'], [.9, rows[0], 'click']], t);
     rows.forEach((r, i) => {
       const k = M.ease.outCubic(M.prog(t, 1 + i * .08, .18));
       r.style.setProperty('--on', k);          // 손잡이 x, 바탕색 M.color('#CFCBC4', '#3B82D6', k)
     });
     const px = M.anim([[0, 0], [3.4, -W * .38, {d: .7, e: 'inOutCubic'}]], t);
     M.place(S.$('.panel'), cx + px, cy);       // 가장자리로 반쯤 밀려나 가운데를 비움
   });
   ```
2. **세리프 두 줄과 손 타원, 그리고 가라앉기**
   - 장면 쌓기에서는 title: fade, marker: circle 로 어절이 옅게 떠오르고 강조 말에 손 타원이 그어져요.
   - 직접 짤 때는 어절마다 `M.place(w, x, y, {o: M.prog(t, t0 + i * .12, .3)})` 로 떠올리고, SVG 타원 path 를 `M.draw(loop, M.ease.inOutCubic(M.prog(t, t1, .6)))` 로 그어요. 머문 뒤에는 `color: M.color('#2A2622', '#BDB8B0', M.prog(t, t2, .4))` 로 가라앉히고 타원은 `M.draw(loop, 1 - …)` 로 걷어요.
   - 패널과 원판 기둥을 잇는 연결선은 문장 양옆 가로선 두 개를 바깥에서 안으로 `M.draw` 해요.
3. **체크 물결 격자**
   ```
   const discs = S.$$('.disc');                  // 9열 × 5행 원판, 가운데 몇 칸은 비움
   S.ambient(t => discs.forEach(d => {
     const t0 = 1 + d.dataset.col * .1;
     M.draw(d.ring, M.prog(t, t0, .3));                          // 테라코타 고리
     d.pie.style.setProperty('--a', M.prog(t, t0 + .25, .35) * 360 + 'deg');  // conic-gradient 파이 채움
     M.draw(d.check, M.prog(t, t0 + .6, .15));                   // 흰 체크
   }));
   ```
   격자가 다 차면 가운데 빈 자리에 세리프 한 줄을 어절씩 놓고, 1.5초 뒤 옅은 회색으로 가라앉혀요.
4. **인사 카드에서 대화로**
   - 별 기호를 단 세리프 인사 아래 입력 카드를 띄우고, 커서가 '+' 를 누르면 드롭다운 목록이 열리며 장면 1과 같은 토글 연쇄가 한 번 더 일어나요. 입력창 문장은 `M.type(text, t, t0, 24)` 로 치고, 보내기 버튼은 글이 생기는 순간 옅은 테라코타에서 진한 #B5563F 로 바뀌어요.
   - 보낸 뒤에는 카드가 컷으로 사라지고, 오른쪽 위에 회색 말풍선이 하나, 그 아래 작업 줄이 0.5초마다 하나씩 쌓여요(작은 아이콘 + 옅은 회색 글 + 줄임표). 맨 아래에는 테라코타 별 기호가 천천히 돌며 진행 중임을 알려요. 줄이 넘치면 `M.anim` 으로 목록 전체를 한 칸 위로 올려요.
   - 마무리는 `S.tr.blur` 대신 짧은 페이드로 빈 바탕에 알약 꼬리표와 세리프 두 줄을 놓아요.
