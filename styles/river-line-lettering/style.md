# 한 줄 강물 글씨 (손그림)

한 줄: 위성 사진 속 굽은 강줄기를 크림색 굵은 선이 따라 그어 낱말이 되고, 곧은 선 하나가 고리를 지으며 필기체 낱말로 휘는 한 줄 글씨.

## 보는 느낌
- 화면을 가로지르는 굵은 선 하나가 주인공이에요. 선은 끊기지 않고 화면 왼쪽 밖에서 들어와 오른쪽 밖으로 나가요.
- 그 선이 중간중간 고리를 짓고 굽이쳐 낱말(지명·브랜드 이름)이 돼요. 글자는 한 획 필기체, 높낮이가 들쭉날쭉.
- 시작은 위성 사진 속 강 위를 선이 따라가요. 카메라가 물러나면 사진 조각들이 가로 띠로 이어지고 띠 위아래로 가는 선 끝 작은 지명 꼬리표.
- 그다음부터는 단색 바탕(진초록·빨강·황토) 위 선 낱말만.

## 색
- 바탕 80 · 선 15 · 작은 글 5.
- 바탕과 선 짝: 진초록 #2F4A2C + 크림 #EFE6C2 / 빨강 #D8261C + 크림 / 황토 #D99A1E + 파랑 #3F7BD0 / 진초록 + 황토.
- 바깥 판(사진 조각 띠가 놓이는 곳)은 짙은 흙색 #3A2B1B.

## 글자
- 선 낱말은 글꼴이 아니라 SVG 선으로 그려요. 어울리는 글꼴 성격: 굵기가 일정한 한 줄 필기체, 고리가 크고 글자 사이가 선으로 이어진 모양. 글꼴로 대신할 때는 Caveat(영문)·나눔손글씨 펜(한글).
- 꼬리표·작은 글은 Archivo + Noto Sans KR Bold, 짧은 변의 1.6~2%, 대문자 영문은 자간 0.06em.
- 선 굵기는 짧은 변의 1.6~2.4%. 끝은 둥글게(round cap·join).

## 질감과 모양
- 그레인 0.06만. 선은 매끈하게, 떨림 없이.
- 위성 사진은 채도를 조금 낮추고(saturate .85) 강 부분이 잘 보이게 대비를 올려요.
- 사진 조각 띠는 크기 다른 직사각형이 살짝 겹치며 이어지고, 조각마다 얇은 밝은 테두리.

## 움직임
- 96BPM, 보통. 선이 그어지는 속도는 일정하게(초당 화면 폭의 60%쯤), 곡선은 sine.inOut.
- 곧은 선 → 낱말 모프는 1.2초, 가운데 고리부터 바깥으로 퍼지듯.
- 바탕 컷은 박마다. 컷과 함께 선 색만 바뀌고 모양은 그대로, 다음 박에 선이 옆으로 흘러가 다음 낱말로.

## 전환
- 시작은 사진에서 물러나는 줌(zoom), 그다음은 박에 맞춘 컷.
- 장면 쌓기: zoom → cut → cut, 장면 바탕은 dark(진초록) → accent(빨강) → paper(황토) → dark.

## 대표 장면
1. **강을 따라 쓰기**
   ```
   // 사진 위에 강줄기를 따라 미리 그린 SVG path (첫 글자 모양으로 이어지게)
   M.draw(river, M.prog(t, t0, 1.2));                         // 선이 강을 따라 그어짐
   // 1.2초 뒤 카메라 물러남: 사진 조각들이 띠로 이어지고 낱말 전체가 보임
   M.camera(world, cx, cy, M.anim([[0, 3.2], [t0 + 1.4, 1, { d: 1.2, e: 'inOutCubic' }]], t));
   // 꼬리표: 가는 선 M.draw + 작은 글 S.fx.fade, 0.1초 간격
   ```
2. **곧은 선이 낱말로 (모프)**
   - 곧은 선과 낱말 선을 같은 점 개수(예: 240점)로 뽑아 두고 점마다 `lerp(직선점, 낱말점, k_i)`, `k_i = M.spring(t - t0 - |i/N - .5| * .5, 'smooth')` 로 가운데부터 휘게. 매 프레임 path d 를 다시 씀.
   - 낱말 양끝 점은 화면 밖 좌우로 늘려 선이 끊기지 않게.
3. **바탕만 바꾸기**
   - 같은 path 를 두고 박마다 바탕색 컷, `stroke` 도 짝 색으로 컷. 다음 낱말로 갈 때는 2번 모프를 낱말 → 낱말로 다시 써요.
   - 장면 쌓기에서는 `title: write`(왼쪽부터 쓰듯), `marker: underline`, `deco: scribble` 이 이 결을 따라가요.

## 어울리는 곳 / 피할 것
- 어울림: 지역·관광 홍보, 자연·친환경 브랜드, 로고·레터링 공개, 여행 하이라이트, 축제.
- 피할 것: 굵은 고딕 큰 제목만으로 채우기, 유리 질감, 글리치·빠른 깜빡임, 선을 여러 획으로 끊기.
- 선 낱말은 우리 브랜드 이름·지명으로 새로 그려요. 영상 속 로고 글씨 모양을 따라 그리지 않아요.
