# 한 어절씩 문장 (타이포)

한 줄: 밝은 바탕 가운데에 문장이 한 어절씩 붙어 가고, 막 들어온 어절만 색이 깜빡이다 검정으로 가라앉는 담백한 타이포.

## 보는 느낌
- 거의 흰 회색 바탕 한가운데 문장 한두 줄. 그 밖엔 아무것도 없어요.
- 말하듯 한 어절씩 늘어나서, 내레이션 없이도 목소리가 들리는 것 같은 영상이에요.
- 사이사이 UI 장면(입력창, 진행 단계 목록, 그래프)이 같은 바탕 위에 조용히 들어왔다 나가요.

## 색
- 바탕 #EDEDED 85 · 검정 글자 13 · 색 2.
- 색은 '막 들어온 어절'에만 잠깐: 파랑 #1F6FE5, 주황 #F07A2B, 연보라 #B79CF2, 분홍 #F2B5C4, 초록 #34C759. 끝까지 남는 건 강조 단어 하나(기본 파랑).
- 첫 장면에서 대상 이름(예: 마케터, 개발자…)을 바꿔 가며 보여 줄 때는 이름마다 다른 색을 써도 좋아요.

## 글자
- 산세리프 600(Geist + Noto Sans KR Bold), 자간 -0.015em. 크기는 화면 높이의 5~6%, 한 줄 길이는 화면 너비 55% 안쪽.
- 가운데 정렬. 어절이 붙을 때마다 줄 전체가 다시 가운데로 맞춰져요.
- 굵기·크기 대비는 쓰지 않아요. 색과 타이밍으로만 강조해요.

## 질감과 모양
- 질감 없음. 그림자도 거의 없어요(UI 카드에만 아주 옅게).
- 알약 버튼(예: 두 모드 전환 토글)은 회색 바탕에 흰 선택 칸이 미끄러져요.

## 움직임
- 90BPM. 어절은 반 박(약 0.33초)마다 하나. 문장이 다 차면 한 박 쉬고 통째로 컷.
- 어절은 제자리에서 그냥 나타나요(위치 이동·페이드 없음). 대신 이미 있던 어절들이 새 가운데 자리로 0.2초 스프링 이동.
- 색 깜빡임은 2~3프레임(0.08초)마다 한 번씩 계단으로 바뀜.

## 전환
- 문장 장면끼리는 컷. 입력창 장면으로 들어갈 땐 카메라 줌(zoom).
- 장면 쌓기: cut → zoom.

## 대표 장면
1. **한 어절씩 + 다시 가운데**: 문장을 `S.words(el)` 로 나누고, 어절 i 가 보이는 시각 `ti = t0 + i * M.beat(.5)`. 보이는 어절만 `inline` 으로 두면 브라우저가 줄을 다시 가운데로 잡는데, 그러면 위치가 툭 튀어요.
   대신 각 시각의 줄 배치(보이는 어절까지만 넣었을 때의 x, y)를 미리 재 두고, 어절마다 `M.anim([[t_i, [x_i, y_i]], [t_{i+1}, [x', y'], 'snappy'], …], t)` 로 새 자리까지 스프링 이동시켜요.
2. **새 어절 색 깜빡임**: 막 들어온 어절의 색을 `M.at([[ti, '#1F6FE5'], [ti + .08, '#F07A2B'], [ti + .16, '#B79CF2'], [ti + .24, '#F2B5C4'], [ti + .32, '#34C759'], [t_{i+1}, '#0D0D0D']], t)` 로 고름. 강조 단어는 마지막 값을 accent 로.
   시작 색 순서는 어절마다 `M.rng(i)` 로 섞어 매번 다르게.
3. **한 글자 늘이기**: '왜' 다음에 '애' 를 0.06초마다 하나씩 덧붙이고(`M.type('애애애애애애애애', t, t0, 16)`), 이때 어절 색을 반 박마다 바꿈. 줄이 화면 밖으로 넘쳐도 그대로 두고 컷.
4. **입력창 속으로 들어가 타이핑**: 입력 카드를 `M.camera(world, cx, cy, zoom)` 로 잡고 `zoom` 을 1 → 3.5 로 `soft` 스프링. `cx` 는 타이핑 커서 위치를 따라가게 `M.anim` 으로 계속 갱신, 글은 `M.type`. 다 치면 다시 1로 물러남.
   '생각 중' 같은 대기 문구에는 밝은 띠가 왼→오로 훑게: 글자에 `background: linear-gradient(90deg, #999 40%, #fff 50%, #999 60%)` + `background-clip: text`, `background-position` 을 t 로.

## 어울리는 곳 / 피할 것
- 어울림: 서비스 소개 내레이션, 브랜드 철학 한 줄, AI·생산성 도구, 질문으로 여는 광고.
- 피할 것: 사진 바탕, 아주 굵은 블랙 제목, 장면마다 다른 글꼴, 빠른 컷 연속.
- 한국어는 어절 단위로 끊으면 자연스러워요. 조사만 따로 떨어지지 않게.
