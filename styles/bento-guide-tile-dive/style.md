# 가이드 타일 벤토 (그래픽·도형)

한 줄: 브랜드 가이드 조각을 둥근 타일로 짠 벤토 보드를 카메라가 비스듬히 훑다가 한 타일로 파고들고, 끝에는 타일 벽 전체가 보이도록 빠지는 아이덴티티 쇼케이스.

## 보는 느낌
- 화면 전체가 크기가 제각각인 둥근 타일로 빈틈없이 짜인 보드예요. 타일 사이 틈은 짧은 변의 1.5% 안팎으로 고르게.
- 타일마다 가이드 한 조각만 담아요: 색 견본 띠(세로 막대 4칸 + 고정폭 색 코드), 글꼴 견본(aA bB cC… 두세 줄), 마크 하나, 반복 무늬, 아이콘 틀, 작은 앱 창.
- 판이 두 벌이에요. 밝은 판은 옅은 회청 바탕에 흰 타일과 보라 타일, 어두운 판은 숯빛 격자 바탕에 짙은 회색 타일과 청록 타일. 장면마다 두 판을 오가요.
- 카메라는 보드를 정면에서 보지 않고 살짝 기울여 훑어요. 화면 가장자리의 타일은 늘 잘려 있어서 보드가 화면 밖으로 이어지는 느낌이 나요.
- 사이사이 타일 하나가 화면을 다 채운 장면이 끼어들어요: 빈 회색 위 점 릴레이, 유리 독 클로즈업, 어두운 격자 위 띄엄띄엄 쳐지는 글자.

## 색
- 바탕(밝은 회청 #EEEFF3 또는 숯빛 #1D1E22) 60 · 흰·회색 타일 25 · 보라 계열 10 · 원색 점 5.
- 보라 #5B3DF5 가 주인공 강조색. 큰 타일 한두 장을 통째로 칠하고 글자는 흰색.
- 색 견본 띠는 보라 → 파랑 #4F75FF → 청록 #00C9CC → 민트 #7CF0F5 처럼 한 계열로 이어지게.
- 코발트 #2A2BE0 는 '마크·색·글꼴' 같은 목차 타일에만. 빨강 #E8344A·노랑 #F2C200 은 점 릴레이와 색 쌓기 타일에만 조금.
- 어두운 판에서는 짙은 청록 #2F7F72 와 흰색만 써요.

## 글자
- Geist(한글 Noto Sans KR Medium·Bold). 타일 제목 600, 짧은 변의 3~4%, 왼쪽 위 정렬, 자간 −0.02em.
- 타일 안 큰 글(글꼴 이름, 한마디)은 600~700, 짧은 변의 8~12% 로 타일 아래쪽에 크게 앉혀요. 제목은 작게 위, 큰 글은 아래로 크기 대비를 세게.
- 색 코드·크기·꼬리표는 Geist Mono 400, 아주 작게(짧은 변의 1.6%), 회색 60%.
- 마크 옆 워드마크는 Archivo 를 넓게(stretch 120%, weight 800) 대문자로.

## 질감과 모양
- 질감 없이 매끈하게. 깊이는 카메라 초점으로만 줘요(먼 타일은 살짝 흐림).
- 타일: 모서리 `--u` × 1.6, 아주 옅은 그림자 한 겹(밝은 판), 1px 흰 10% 테두리(어두운 판).
- 아이콘 틀: 둥근 사각 안에 가는 보라 가이드선(원, 대각선, 격자) 1px.
- 유리 독: 흰 15% 반투명 + 블러 + 위쪽 가장자리 흰 하이라이트.

## 움직임
- 100BPM, 보통 속도. 카메라 이동은 `power3.inOut` 으로 천천히 출발해 미끄러지다 부드럽게 멈춰요.
- 훑기 한 번에 2~3초, 파고들기 0.8~1초. 타일 안 요소는 카메라가 멈춘 뒤 0.8배 간격으로 하나씩 들어와요.
- 어두운 판은 흐림 8px 에서 선명하게 맺히며 시작해요(0.6초).
- 점은 굴러오듯 들어와 살짝 튀고 멈춤, 합쳐질 땐 `back.out(1.3)` 으로 부풀어요.

## 전환
- 파고들기가 기본: 카메라가 타일 하나로 다가가 타일이 화면을 채우면 그 안이 다음 장면. 장면 쌓기에서는 push → blur → cut.
- 밝은 판 ↔ 어두운 판은 컷. 마지막 장면만 크게 빠지는 줌아웃.

## 대표 장면
1. **타일 벽 훑고 파고들기**
   ```
   // 보드(타일 그리드)를 한 덩어리로 두고 카메라 값만 t 로 움직임
   S.ambient(t => {
     const cam = M.anim([[0, {x: 0, y: 0, s: 1.1}],
       [.2, {x: -W * .25, y: H * .05, s: 1.1}, {d: 2.4, e: 'inOutCubic'}],
       [2.8, {x: -tile.cx, y: -tile.cy, s: W / tile.w}, {d: .9, e: 'inOutCubic'}]], t);
     board.style.transform = `perspective(1600px) rotateX(8deg) rotateZ(-3deg) translate(${cam.x}px, ${cam.y}px) scale(${cam.s})`;
   });
   // 다 파고들면 S.tr.blur 로 타일 속 장면에 넘김
   ```
2. **흐림에서 맺히는 어두운 판**
   - 숯빛 격자 위 타일들을 `M.place(tile_i, x, y, {blur: (1 - k) * 8, o: .4 + k * .6})`, `k = M.ease.outCubic(M.prog(t, i * M.beat(.5), .6))`. 맺히는 순서는 큰 타일 → 작은 타일.
   - 장면 쌓기에서는 title: blur + card: shadow + frame: card 로 같은 결이 나와요.
3. **점 릴레이에서 겹친 원 마크로**
   ```
   const dots = S.$$('.dot');   // 검정·파랑·빨강·파랑·반반 점 5개
   dots.forEach((d, i) => {
     const k = M.spring(t - i * .12, 'bouncy');
     M.place(d, M.lerp(W * 1.1, cx + i * gap, k), cy);
   });
   // 2박 뒤 앞 점부터 부풀어 왼쪽으로 겹침
   const g = M.anim([[M.beat(2), 1], [M.beat(2) + .1, 9, {d: .6, e: 'outBack'}]], t);
   ```
4. **유리 독에 아이콘 틀 끼우기**
   - 흐린 파랑 물결 바탕(큰 원 3개 `blur(10u)` + `M.drift`) 위에 유리 독, 큰 아이콘 2~3개를 화면보다 크게 클로즈업.
   - `M.Cursor` 로 가이드선 아이콘 틀을 집어 끌어오고(`M.cursorAt`), 놓는 순간 옆 아이콘들이 `M.spring 'smooth'` 로 한 칸 비켜요. 틀 안 고정폭 크기 꼬리표는 number: scramble 처럼 숫자가 맞춰지며 나타나요.
5. **타일 벽 전체로 빠지는 마무리**
   - 앞에서 본 타일들을 한 보드에 모아 두고 카메라 scale 을 2.2 → 0.9 로 1.5초에 빼요. 이어 컷으로 옅은 라벤더 바탕 가운데 작은 마크와 한 줄.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 리뉴얼·아이덴티티 공개, 디자인 시스템·가이드 소개, 디자인 도구·에셋 서비스 런칭, 포트폴리오 쇼릴, 앱 아이콘·기능 여러 개를 한 판에 보여 줄 때.
- 피할 것: 손그림 선·종이 질감, 타일 없이 글만 있는 장면, 강조색 여러 개를 한 타일에 섞기, 빠른 깜빡임 컷 연속, 화면 전체를 덮는 빛 번짐.
- 타일 하나에 한 가지 정보만 담아야 보드가 정돈돼 보여요.
