# 숯빛 비스듬 판 위 보라 네온 곡선 (제품 UI)

한 줄: 숯빛 어둠 속에 비스듬히 누운 어두운 UI 판을 카메라가 천천히 미끄러지며 훑어요. 큰 숫자가 올라가는 동안 보라 네온 선이 판 모서리에서 뻗어 나오고, 회색 곡선 다발 사이로 바짝 파고들었다가 흰 두 줄 문장으로 조용히 닫혀요.

## 보는 느낌
- 바탕은 거의 검은 숯빛이고 가장자리로 갈수록 더 어두워져요. 그 위에 바탕보다 한 톤 밝은 어두운 판이 크게 기울어 누워 있어요. 판은 늘 화면 밖으로 잘려서 끝이 보이지 않아요.
- 카메라는 판 위를 한 방향으로 계속 흘러가요. 정면에서 반듯하게 보는 장면은 마지막 문장 하나뿐이에요.
- 초점이 얕아요. 가까운 모서리의 글줄만 선명하고 먼 쪽은 뭉개져서, 어두운 화면인데도 깊이가 느껴져요.
- 한 장면에 보여 주는 건 하나씩이에요: 큰 숫자 하나, 설정 글줄 몇 개, 드롭다운 목록 하나, 곡선 그래프 하나. 판 위에 여백이 넓어요.
- 빛나는 건 보라 선 하나예요. 회색 곡선과 흰 글자는 조용히 깔리고, 보라 선만 빛 번짐을 둘러요.

## 색
- 숯빛 바탕 70 · 어두운 판 18 · 흰 글자 8 · 보라 4.
- 바탕 #161618, 판 #242428(아주 얇은 밝은 테두리 한 줄).
- 큰 숫자·제목은 흰색 #F2F2F4, 보조 글(기간, 설명)은 흰색 50%.
- 곡선: 보라 #8B6CFF 한 가닥이 주인공, 나머지는 회색 #6E6E76 을 30~60% 로 여러 가닥. 목표선은 흰색 70% 점선.
- 보라 칠 위에 글을 얹을 때는 아주 짙은 남보라 #120B26.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold). 제목·숫자는 600, 자간 −0.02em.
- 큰 숫자는 판 위에서 짧은 변의 12~16%, 그 위 꼬리 글은 4%, 아래 기간 글은 3.5% 옅은 흰색. 세 줄을 왼쪽 정렬로 촘촘히 쌓아요.
- 설정 글줄은 제목 600 · 설명 400 두 단계로만. 판과 함께 기울어 있어서 글줄도 비스듬히 누워요.
- 흰 글자에 아주 옅은 빛 번짐이 있어서 어둠 속에서 살짝 떠 보여요.
- 엔딩 문장은 평면 정면, 왼쪽 정렬 두 줄, 짧은 변의 6% 안팎, 600.

## 질감과 모양
- 그레인 0.05, 비네트 0.35. 매끈하지만 어둠이 너무 판판하지 않게.
- 판: 모서리 `--u` × 1.6, 1px 흰색 6% 테두리, 그림자 없이 바탕과 명도 차로만 구분.
- 보라 선: 굵기 짧은 변의 0.4~0.6%, 같은 색 `drop-shadow` 두 겹(가까이 진하게, 멀리 넓게).
- 드롭다운 선택 막대와 입력칸은 판보다 한 톤 밝은 회색 #34343A, 모서리 1u.

## 움직임
- 84BPM, 느림. 카메라는 `power2.inOut` 으로 출발과 멈춤을 부드럽게, 중간엔 거의 등속으로 흘러요.
- 한 장면에 4~6초 머물고 그동안 카메라는 멈추지 않아요(짧은 변의 10~20% 쯤 이동).
- 숫자는 2~3초에 걸쳐 천천히 올라가고, 보라 선은 숫자와 같은 시간 동안 그어져요.
- 글줄은 카메라가 다가가는 순서대로 흐림 6px → 0 으로 맺혀요(0.6초).
- 드롭다운 선택 막대는 한 박마다 한 칸씩 미끄러져 내려가요(0.35초, 스프링 없이).

## 전환
- 흐림 전환이 기본이에요. 앞 장면이 초점 밖으로 뭉개지는 사이 다음 판이 흐림에서 맺혀요. 카메라는 전환 중에도 계속 같은 방향으로 흘러서 한 장의 큰 판을 이어 훑는 것처럼 보여요.
- 엔딩 문장은 느린 페이드. 장면 쌓기: blur → fade.

## 대표 장면
1. **올라가는 숫자와 뻗는 네온 선**: 판을 부모 `perspective: 1400px` 안에 `rotateX(52deg) rotateZ(-24deg)` 로 눕히고, 카메라 이동은 판의 translate 로.
   ```
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, .4, 2.6));
     num.textContent = Math.round(M.lerp(6, 24, k)) + '%';
     M.draw(violetPath, k);                       // 보라 선, filter: drop-shadow(0 0 .6u var(--glow))
     grayPaths.forEach((p, i) => M.draw(p, M.prog(t, .6 + i * .15, 2.4)));
     M.place(board, M.lerp(0, -W * .08, M.prog(t, 0, 6)), 0);   // 카메라는 멈추지 않음
     focusLayer.style.filter = `blur(${M.lerp(0, 5, depth)}px)`; // 먼 쪽 층만 흐리게
   });
   ```
2. **곡선 다발 속으로 파고들기**: 같은 곡선을 판 크기의 3배로 키워 놓고, `M.anim([[0, 1], [t0, 3.2, {d: 2.5, e: 'inOutCubic'}]], t)` 로 크기를 올리며 보라 선 쪽으로 다가가요. 앞쪽 회색 선은 `blur(4~8px)` 로 화면을 가로질러 지나가고, 보라 선만 선명하게 휘어 흘러요(`stroke-dashoffset` 을 천천히 계속 줄여 흐르는 느낌).
3. **차례로 맺히는 설정 글줄과 드롭다운**: 글줄마다 `k = M.prog(t, t0 + i * .5, .6)` 로 `M.place(line, x, y, {o: k, blur: (1 - k) * 6})`. 드롭다운은 `M.box(list, {h: M.anim(...)})` 로 아래로 펼치고, 선택 막대 y 는 `M.at([[tA, 0], [tA + M.beat(1), 1], [tA + M.beat(2), 2]…], t)` 위치로 `M.anim` 0.35초씩 미끄러짐. 판 아래 모서리 보라 막대는 `scaleX` 0 → 1.
4. **목표선과 미끄러지는 점, 그리고 엔딩**: 흰 점선 path 를 `M.draw` 로 왼쪽부터 1.5초에 긋고, 보라 곡선 위 고리 점은 `path.getPointAtLength(L * k)` 로 옮겨요. 옆 값 목록 숫자는 점의 위치에 맞춰 `M.at` 으로 바꿔 끼워요. 마지막은 `S.tr.blur` 로 판을 흐리게 지우고 평면 정면 화면에 흰 두 줄 문장을 0.8초 페이드로 올려요. 바탕엔 왼쪽 위가 아주 살짝 밝은 `radial-gradient` 하나.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 분석·대시보드 기능 소개, 개발자 도구 런칭, 성과 지표 설명, 설정 화면 사용법, 밤 분위기의 제품 티저. 30~45초쯤 천천히 보여 주는 영상.
- 피할 것: 밝은 바탕, 빠른 컷, 보라 말고 다른 강조색, 평면으로 정면에서 본 UI만 쓰기, 글이 많은 장면, 손그림 선.
- 빛 번짐은 보라 선과 흰 글자에만 아주 옅게 둬요. 판이나 카드에는 빛을 두르지 않아요.
