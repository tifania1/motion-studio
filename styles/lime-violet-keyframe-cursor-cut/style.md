# 라임·보라 키프레임 커서 컷 (제품 UI)

한 줄: 라임, 보라, 주황, 검정 색면이 컷마다 갈려요. 그 위에서 큰 검은 커서가 타임라인의 키프레임 마름모와 곡선 손잡이를 끌면 위의 도형이 그대로 따라 움직이고, 사진 판은 비스듬히 겹겹이 펼쳐지는 편집 도구 런칭이에요.

## 보는 느낌
- 장면마다 화면 전체를 한 가지 색면으로 칠해요. 라임 → 검정 → 보라 → 옅은 회색 → 주황 → 푸른 회색 → 연두 → 검정 순으로, 2~3초마다 컷으로 바뀌어요.
- 색면 위엔 늘 커다란 '작업 중' 조각이 하나 떠 있어요: 앱 창, 타임라인 띠, 곡선 패널, 폰, 메뉴 팝오버. 화면의 절반 이상을 차지할 만큼 크게 잡고 가장자리는 잘려도 괜찮아요.
- 주인공은 검은 화살표 커서예요. 화면 높이의 8~10% 정도로 크게, 흰 테두리를 둘러 어느 색면 위에서도 또렷해요.
- 타임라인 장면은 화면 아래 3분의 1에 흰 눈금 띠를 깔고, 그 위 색면 가운데에 움직이는 도형을 둬요. 위와 아래가 한 화면에서 같이 움직이는 게 이 결의 핵심이에요.
- 제목 장면은 검은 화면 가운데 주황 산세리프 두 줄, 둘레 네 귀퉁이에 작은 사진·무늬 타일이 비껴 걸쳐 있어요.

## 색
- 색면 70 · UI(흰 패널·회색 선) 20 · 커서와 선택 파랑 10.
- 라임 #D6EE5E(여는 장면·아이콘 격자), 보라 #5B34E6(타임라인 장면), 연보라 #C9C2F2(보라 위 도형), 주황 #EE7A3C(제목 글자·폰 장면 바탕), 검정 #121212(제목·엔딩).
- 선택 상자, 재생 막대, 키프레임 마름모는 모두 파랑 #2F7BF5 하나로.
- 연두 계열 장면에서는 짙은 숲초록 #1F5A14 아이콘을 옅은 연두 #E6F2C8 위에 둬요.
- 한 화면에 색면은 하나. 강조색이 필요하면 그 장면 색면과 다른 색을 작은 조각(노드 동그라미, 꼬리표)에만 써요.

## 글자
- Geist(한글 Noto Sans KR Medium·Bold). 제목은 굵기 500, 자간 −0.02em. 둥글고 담백한 산세리프를 크게.
- 제목 크기는 짧은 변의 14~18%, 두 줄, 가운데 정렬. 검은 바탕에서는 주황, 색면 위에서는 검정.
- 타임라인 눈금 숫자(0, 0.2, 0.4 …)와 속성 값은 Geist Mono, 짧은 변의 2% 안팎, 회색.
- 메뉴·패널 글씨는 아주 작게(짧은 변의 2.5%), 아이콘 하나와 이름 하나씩 줄 세워요.

## 질감과 모양
- 질감 없이 매끈하게. 그레인·종이·비네트 없이 평평한 색면.
- 패널·메뉴는 흰색, 모서리 `--u` × 1.6, 아주 옅은 그림자 하나. 알약 도형은 끝이 완전히 둥글어요.
- 선택 상자는 파랑 1.5px 선, 네 귀퉁이에 흰 속 작은 정사각 핸들.
- 길(트랙) 선은 짙은 회색, 짧은 변의 1% 두께, 꺾이는 곳은 모두 둥글게.
- 사진 판 쌓기만 원근(perspective)을 써요. 나머지는 납작한 평면.

## 움직임
- 112BPM. 장면 하나가 4~6박, 커서 동작 하나가 1~2박.
- 커서는 `power3.inOut` 으로 미끄러져 목표에 닿고, 누를 때 0.1초 동안 0.9배로 줄었다 돌아와요.
- 커서가 끄는 동안 연결된 도형은 같은 곡선으로 따라 움직여요. 손을 놓으면 도형이 스프링('smooth')으로 살짝 넘쳤다 자리 잡아요.
- 팝오버·메뉴는 커서 옆에서 0.2초에 0.92배 → 1배로 톡 열려요.
- 여는 장면의 흰 원은 라임 위에서 흐린 가장자리를 단 채 천천히 부풀어 화면을 채우고, 그 안에서 앱 창이 드러나요.

## 전환
- 컷이 기본이에요. 색면이 통째로 바뀌는 컷이 리듬을 만들어요.
- 앱 창·폰이 들어올 땐 옆에서 밀어내기(push), 장면 묶음이 바뀌는 곳에만 한 번 쓸어내기(wipe).
- 장면 쌓기: cut → push → cut → wipe.

## 대표 장면

1. **키프레임 끌기**: 보라 색면, 위엔 연보라 알약, 아래엔 흰 타임라인 띠.
   ```
   const M = Studio.M;
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, M.beat(1), M.beat(1.5)));   // 커서가 마름모를 끄는 구간
     const kx = M.anim([[0, W * .45], [M.beat(1), W * .72, {d: M.beat(1.5), e: 'inOutCubic'}]], t);
     M.place(diamond, kx, H * .82);                                    // 파랑 키프레임 마름모
     M.box(pill, {x: W * .2, y: H * .3, w: W * .25 + (kx - W * .45), h: H * .2});  // 알약이 같은 만큼 늘어남
     cursor.at(kx, H * .82, t);                                        // M.Cursor 가 마름모를 잡고 끌기
   });
   ```
   이어 곡선 패널을 push 로 밀어 넣고, 베지어 손잡이 path 를 `M.draw` 로 다시 그려 곡선이 휘는 걸 보여 줘요.
2. **둥근 길 위 노드**: 옅은 회색 판에 둥글게 꺾인 SVG path 3~4개를 `M.draw(path, k)` 로 0.6초에 깔고, 글자 동그라미 노드를 `path.getPointAtLength(len * k)` 로 길을 따라 보내요. 노드마다 장면 쌓기의 deco `handles` 같은 파랑 선택 상자를 달고, 커서가 누르는 순간(`M.cursorAt`) 흰 메뉴를 `M.spring(t - tClick, 'snappy')` 로 열어요.
3. **사진 판 부채**: 부모에 `perspective`, 사진 판 5~6장을 `rotateY(-35deg)` 로 눕혀 x 를 판마다 0.08W 씩 벌려요. 판 i 는 `M.anim` 으로 0.1초씩 늦게 오른쪽에서 들어와 멈추고, 그 뒤 이름표 단 커서 둘이 서로 다른 박에 들어와 맨 앞 판을 가리켜요. 초록 댓글 말풍선은 `M.type(text, t, t0, 18)`.
4. **검은 화면 도형 엔딩**: 원·네모·작은 원 4~5개에 파랑 선택 핸들을 달아 두고, 박마다 `M.at([[M.beat(0), A], [M.beat(1), B], [M.beat(2), C]], t)` 로 자리 묶음을 갈아 끼우되 옮겨 갈 땐 `M.spring` 으로 톡. 마지막 박에 핸들이 사라지며 도형만 남아요. 전환은 `S.tr.blocks` 대신 컷.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인·모션 편집 도구 런칭, 타임라인·애니메이션 기능 소개, 협업 기능 안내, 개발·디자인 도구 업데이트 소식, 기능 여러 개를 30~70초에 훑을 때.
- 피할 것: 종이·그레인 같은 거친 질감, 손그림 선, 세리프 글꼴, 느린 서서히 전환, 한 화면에 색면 두 개 이상 섞기.
- 커서가 무언가를 끌거나 누르지 않는 장면이 길어지면 결이 흐려져요. 장면마다 커서 동작 하나는 꼭 넣어요.
