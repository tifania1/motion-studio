# 숯빛 판 키캡 메뉴 시연 (제품 UI)

한 줄: 숯빛 판 한가운데 반들한 물체 하나를 두고, 커서가 누르면 옆에 드롭다운 메뉴가 톡 열리고 아래에서 밝은 키캡이 솟아 눌리며 물체가 바뀌어요. 끝에는 밝은 캔버스 위 앱 화면들을 카메라가 옆으로 훑어요.

## 보는 느낌
- 거의 검은 숯빛 판에 주인공은 늘 하나예요. 유리처럼 반들한 아이콘, 작은 재생 카드처럼 화면 짧은 변의 30~40%쯤 되는 물체가 가운데 조금 왼쪽에 놓여요.
- 물체 오른쪽에 작은 흰 속성 패널이나 드롭다운이 붙어요. UI 는 작고 또렷하게, 둘레 여백은 넉넉하게 둬요.
- 단축키 장면은 바탕이 가운데가 밝은 회색 조명 판으로 바뀌고, 물체 아래에 밝은 키캡이 줄지어 솟아요.
- 후반은 밝은 캔버스로 넘어가요. 앱 화면 서너 장이 나란히 서 있고 오른쪽에 속성 패널 열이 붙은 편집기 창 전체가 보여요.
- 첫머리에는 무지개 그라디언트로 칠한 굵은 관 구조물에 카메라가 바짝 붙어 지나가요. 영상 전체의 색을 미리 보여 주는 숨표 같은 컷이에요.

## 색
- 숯빛 바탕 65 · 흰 UI 패널과 글자 25 · 물체의 무지개 칠 8 · 남보라 2.
- 바탕 #1C1C1E, 글자 #ECECEA, 밝은 캔버스 #F2F2F0.
- 남보라 #4B44D8 은 드롭다운의 선택 줄, 켜진 토글처럼 '지금 고른 것'에만 써요.
- 무지개 칠(연두 #B6F03C → 초록 → 분홍 #E5389A → 보라)은 물체와 재생 막대·버튼에만 둬요. 물체 둘레에 그 색의 아주 옅은 빛이 비쳐요.

## 글자
- Geist 와 Noto Sans KR. UI 안 글씨는 작고 반듯하게(짧은 변의 1.8~2.5%), 굵기 500.
- 장면 사이 짧은 문장은 600, 자간 −0.02em, 가운데 한 줄. 크게 키우지 않아요.
- 키캡 위 글자는 Geist 500 으로 기호 하나씩(⌥ ⌘ C 같은), 회색 #6A6A6A.

## 질감과 모양
- 매끈한 화면에 비네트 0.25 만 얹어요. 키캡 장면의 가운데 밝은 회색 조명을 살리는 정도예요.
- 패널·메뉴는 흰색, 모서리 1u, 아주 짧고 짙은 그림자 한 겹. 메뉴 줄 높이는 글자의 2배.
- 물체와 카드는 모서리 1.6u. 아이콘은 반투명 유리 판 안에 무지개 칠이 든 모양이에요.
- 키캡은 밝은 회색(#E4E4E2) 위면에 아래쪽 두꺼운 옆면, 부드러운 바닥 그림자.

## 움직임
- 100BPM, 보통 속도. 한 기능에 4~6초를 머물러요.
- 메뉴는 `power3.out` 으로 0.15초에 위에서 펼쳐지고, 고르면 따로 닫히는 동작 없이 컷.
- 커서는 부드럽게 미끄러져 와서 누를 때 살짝 작아졌다 돌아와요.
- 키캡은 아래에서 0.35초에 솟고(스프링), 박마다 하나씩 0.12초 눌렸다 0.2초에 올라와요.
- 카드 재배치는 모든 카드가 같은 0.6초 동안 `power3.inOut` 으로 동시에 움직여요.
- 캔버스 장면은 카메라가 3~4초에 걸쳐 천천히 옆으로 흐르다 패널 쪽으로 다가가요.

## 전환
- 컷이 기본. 같은 판 안에서 기능이 바뀔 땐 패널만 컷으로 갈려요.
- 판이 바뀔 때(숯빛 → 회색 조명 → 밝은 캔버스)는 밀어내기(push), 마지막 마크 장면만 짧은 페이드.
- 장면 쌓기: cut → push → fade.

## 대표 장면
1. **물체와 드롭다운**: 물체를 `M.place(obj, cx - W*.12, cy)` 에 두고, 패널은 오른쪽에. `M.Cursor` 로 패널 칸까지 옮겨 `M.cursorAt` 으로 누르면 메뉴를 펼쳐요.
   ```
   const k = M.ease.outCubic(M.prog(t, tOpen, .15));
   M.place(menu, mx, my, {o: k, y: (1 - k) * -8});
   menu.style.clipPath = `inset(0 0 ${(1 - k) * 100}% 0)`;
   const pick = M.at([[0, 'linear'], [tPick1, 'radial'], [tPick2, 'angular']], t);
   obj.dataset.fill = pick;          // 칠을 컷으로 바꿈, 선택 줄은 accent 띠
   ```
2. **솟아서 눌리는 키캡**: 회색 조명 판에서 키캡 3개를 물체 아래에 둬요.
   ```
   keys.forEach((key, i) => {
     const up = M.spring(t - (t0 + i * .08), 'smooth');
     const press = M.prog(t, tKey + i * M.beat(1), .12) - M.prog(t, tKey + i * M.beat(1) + .12, .2);
     M.place(key, kx + i * gap, ky + (1 - up) * H * .2 + press * U * 2, {o: up});
   });
   ```
   마지막 키가 눌리는 순간 물체 옆에 복제본이 `M.spring` 으로 툭 생기고, 선택 핸들(deco handles)이 둘레에 잡혀요.
3. **카드 격자 재배치**: 배치 A·B 의 칸 좌표를 미리 정해 두고, 키가 눌릴 때마다 `M.box(card, M.lerpBox(A[i], B[i], M.ease.inOutCubic(M.prog(t, tKey, .6))))` 로 모든 카드를 함께 옮겨요. 카드는 보라 사진 바탕에 아래 왼쪽 흰 글 두 줄.
4. **밝은 캔버스 훑기**: 앱 화면 4장을 가로로 이은 큰 판을 `M.place(board, x, cy, {s})` 로 두고 `x = M.anim([[0, 0], [1, -W*.3, {d: 3.5, e: 'inOutSine'}]], t)`, 끝에 `s` 를 1 → 1.4 로 키워 오른쪽 패널로 다가가요. 판을 바꿀 땐 `S.tr.whip` 대신 장면 쌓기의 push 를 써요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인·편집 도구 새 기능 소개, 단축키·작업 흐름 안내, 버전 업데이트 하이라이트, 앱 화면 여러 장을 한 번에 보여 줄 때.
- 피할 것: 손그림 선과 종이 질감, 화면 가득 큰 제목, 한 화면에 물체 여러 개를 동시에 움직이기, 느린 흐림 전환, 강조색 여러 개(선택 줄 남보라 하나, 무지개는 물체 칠에만).
