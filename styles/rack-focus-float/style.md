# 초점 옮기는 떠다니는 소품 (3D·사물)

한 줄: 밝은 회색 공간에 반들반들한 3D 아이콘과 사진 구슬이 깊이를 달리해 떠 있고, 큰 문장은 하늘빛으로 번져 있다가 선명한 먹색으로 맺혀요. 카메라 초점이 소품 사이를 옮겨 다녀요.

## 보는 느낌
- 화면 가운데 문장 하나(굵게 600, 짧은 변의 6~7%), 바로 아래 작은 설명 두 줄.
- 소품은 문장 둘레를 원처럼 둘러싸고, 몇 개는 화면 밖으로 반쯤 잘려요. 위아래·좌우 균형보다는 깊이(앞·중간·뒤) 균형이 중요해요.
- 깊이 세 층:
  - 뒤 층: 작고(문장 높이의 1~1.5배) 살짝 흐림(blur 1~2px).
  - 중간 층: 문장과 같은 깊이, 선명. 문장 높이의 2~3배.
  - 앞 층: 크고(화면 높이의 25~45%) 많이 흐림(blur 10~24px), 화면 가장자리에 걸침.
- 문장과 소품은 겹치지 않아요. 문장 둘레 1.5배는 늘 비워 둬요.

## 색
- 바탕 80 · 소품 15 · 글 5.
- 바탕 #ECECEE, 글 #1D1D1F, 설명 글 같은 색 85%.
- 빛 글씨: 글자 #5AC8FA, 번진 테두리 rgba(90,200,250,.6).
- 소품은 맑은 앱 아이콘 색(파랑 #2E8BF0, 초록 #34C759, 노랑 #F5C33B, 주황, 보라)과 사진. 소품 하나하나는 색 하나가 주인공.
- 사진 구슬: 사진 둘레에 그 사진과 어울리는 파스텔 테두리(0.6u)와 안쪽 하이라이트.

## 글자
- Geist 600 + Noto Sans KR 700, 자간 −0.02em, 가운데 정렬. 설명은 Geist 500 + Noto Sans KR 500, 문장의 32%.
- 문장은 짧게(한 줄, 12자 안쪽). 마침표를 찍어 단정하게 끝내요.
- 두 낱말 사이를 벌려 그 사이에 폰이나 큰 소품을 세우는 장면이 한 번쯤(낱말은 소품 양옆에 붙음).

## 질감과 모양
- 질감 없음. 깨끗한 화면.
- 소품은 반들반들한 3D: 둥근 덩어리, 위쪽 흰 반사, 아래쪽 같은 색 짙은 그늘, 바닥 그림자는 없음(떠 있으니까).
- 사진 구슬은 완전한 원. 크기가 다른 구슬이 휘어진 띠(나선)를 이루며 멀리 작게 → 가까이 크게 이어지기도 해요.

## 3D 소품을 우리 엔진에서 만드는 법
- 사진(기본): 3D 아이콘·소품은 투명 배경 PNG. 사용자는 ChatGPT 웹에서 고화질로 만드는 쪽을 좋아하니 "glossy 3D icon of …, soft studio light from top, transparent background, no shadow" 같은 프롬프트를 정리해 드리고, 받은 파일은 tools/cutout.py → photo.py add.
- CSS 구슬(대체): 원 하나에 겹친 그라디언트.
  ```
  .ball { border-radius: 50%;
    background: radial-gradient(circle at 35% 28%, #fff 0 5%, rgba(255,255,255,0) 18%),
                radial-gradient(circle at 50% 60%, var(--c1) 0 45%, var(--c2) 100%); }
  ```
  사진 구슬은 같은 원에 사진을 background-size: cover 로 넣고 위에 inset box-shadow(0 0 0 0.6u 파스텔색, inset 0 -1u 2u rgba(0,0,0,.18)) 로 테두리와 그늘.
- 둥근 사각 3D 아이콘(대체): 모서리 28% 둥근 사각 + 같은 색 위아래 그라디언트 + 위쪽 흰 반사 띠 + 가운데 흰 선 아이콘. 살짝 rotateX(12deg) rotateY(−14deg) 로 기울여야 떠 있는 물건처럼 보여요.
- 깊이: 각 소품에 z(0 가까움 ~ 1 멂)를 주고 크기 = 기준 × (1.6 − z), 흐림 = |z − 초점z| × 18px, 움직임 속도(시차) = (1.2 − z).

## 움직임
- 96BPM. 소품은 늘 아주 천천히 떠다녀요(위아래 1u, 6~8초 주기, 앞 층일수록 크게).
- 빛 글씨 맺힘 0.6초, power3.out. 설명은 0.4초 늦게.
- 초점 옮기기는 0.5초 동안 흐림 값을 M.anim 으로 바꿔요. 초점 맞은 소품은 scale 1 → 1.08.
- 장면을 바꿀 땐 앞 층 구슬이 0.4초에 카메라 쪽으로 휙(크기 1.4배, 흐림 30px). 이게 사실상 전환이에요.

## 전환
- blur: 모든 것이 흐려지며 다음 문장이 빈 바탕에서 맺혀요.
- zoom: 소품들이 카메라 쪽으로 흩어지며 화면 밖으로(가운데에서 바깥 방향).
- 컷은 쓰지 않아요.

## 대표 장면

1. 빛 글씨가 맺힘
   ```
   const k = M.ease.outCubic(M.prog(t, t0, .6));
   line.style.color = M.color('#5AC8FA', '#1D1D1F', k);
   line.style.textShadow = `0 0 ${M.lerp(18, 0, k)}px rgba(90,200,250,${(.8 * (1 - k)).toFixed(2)})`;
   line.style.filter = `blur(${M.lerp(6, 0, k)}px)`;
   line.style.opacity = M.prog(t, t0, .15);
   // 설명 두 줄: 같은 식을 t0 + .4 에, 번짐 크기는 절반
   ```
   - 나갈 때는 반대로 먹색 → 하늘빛 번짐 → 투명(0.4초).

2. 초점 옮기기
   ```
   // items: {el, z}. 초점 깊이 fz = M.anim([[t0, .5], [tFocus, hero.z]], t)  (spec {d: .5})
   items.forEach(it => {
     const b = Math.abs(it.z - fz) * 18;
     const s = (1.6 - it.z) * (it === hero ? 1 + .08 * M.prog(t, tFocus, .5) : 1);
     M.place(it.el, it.x + drift(it, t), it.y + bob(it, t), {s, blur: b});
   });
   ```

3. 사진 구슬 나선
   ```
   // 구슬 i (0 = 가장 멂): 각도 a = a0 + i * .45, 반지름 r = r0 * 1.18^i, 크기 = s0 * 1.22^i
   // 들어올 때는 i 순서로 0.05초 간격 M.spring 'smooth', 머무는 동안 전체가 천천히 a += .08 * t 로 돎
   // 가장 큰(가까운) 구슬 셋은 화면 밖으로 반쯤 나가고 blur 2~8px
   ```

4. 카메라 앞을 지나는 구슬
   - 파란 CSS 구슬 2~4개를 앞 층(z 0)에 두고, 아래 밖 → 화면 가운데 위쪽 밖으로 0.5초에 휙(M.ease.inOutCubic), 크기 1 → 1.6, 흐림 12 → 30px. 지나가는 동안 뒤 장면 소품은 흐림 +10px, 그 사이에 문장 교체.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱·구독 서비스 혜택 소개, 클라우드·저장·사진 서비스, 가족·친구 공유 기능, 부드러운 브랜드 캠페인, 기능 여러 개를 문장 하나씩 보여 줄 때.
- 피할 것: 어두운 바탕, 거친 질감, 손그림, 빠른 컷, 평면 아이콘만 쓰기. 영상 속 로고·앱 아이콘·캐릭터 얼굴은 쓰지 않아요. 깊이 세 층 배치, 초점 옮기기, 빛 글씨가 맺히는 원리만 가져와요.
- 비슷한 결의 hero-prop-bubbles(아이콘이 큰 소품으로 커지는 한 컷씩 소개)와 함께 쓰지 않아요. 이 스타일은 소품 여럿이 문장 둘레에 깊이를 두고 떠 있는 쪽이에요.
