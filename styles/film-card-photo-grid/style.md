# 필름 사진 카드와 사진 벽 (콜라주·사진)

한 줄: 검은 화면 가운데 낱말 바퀴가 굴러 한 칸에 멈추고, 필름처럼 색을 민 사진 카드 위 얇은 알약에 검색어가 빠르게 쳐져요. 카드가 하얗게 바래면 크기 다른 사진이 꽉 찬 벽이 나타나요.

## 보는 느낌
- 어두운 장면과 밝은 장면이 번갈아 숨 쉬듯 와요. 검은 화면(낱말 바퀴) → 어둠 속 사진 카드 → 밝은 종이 화면(결과·사진 벽) → 다시 검은 화면. 이 한 바퀴가 주제만 바꿔 네댓 번 되풀이돼요.
- 검은 화면에는 글자 한 줄과 얇은 알약 하나뿐. 여백이 화면의 90% 넘어요.
- 사진 카드는 화면 폭의 88~92%, 위아래 검은 여백이 조금 남아요. 카드 안 한가운데 알약 하나.
- 밝은 화면은 연회색 종이 위 작은 제목 한 줄과 사진 칸들. 사진이 주인공이고 글은 작게 물러나 있어요.

## 색
- 검정 #0F0F10 45 · 사진 35 · 종이 회색 #EDEDE8 15 · 흰 글자와 선 5.
- 사진은 필름처럼 색을 밀어요: 그늘은 청록(#2E8C84 쪽), 밝은 데는 노랑·주황(#E8B83A, #E06A2C), 채도는 살짝 높게, 대비는 낮게. 카드마다 같은 색 보정을 써야 한 영상처럼 보여요.
- 강조(accent)는 청록 #2E8C84. 종이 화면의 버튼·선택 표시에만, 글자는 흰색.
- 검은 화면의 낱말 바퀴: 알약 안 글자 100%, 위아래로 한 칸 멀어질 때마다 흰색 65 → 40 → 20%.

## 글자
- Geist 400(한글 Noto Sans KR 500) 하나. 큰 제목이 없어요. 가장 큰 글이 짧은 변의 3.5~4% 정도.
- 바퀴 장면: 왼쪽 작은 글(예: "○○로 찾기") + 오른쪽 알약 칸. 두 글 크기가 같고, 알약 안 낱말만 조금 더 밝아요.
- 알약 속 검색어: 흰색 400, 알약 높이의 50%. 왼쪽 정렬로 쳐지고 알약 폭이 글을 따라 늘어나요.
- 종이 화면 제목: 먹색 500, 짧은 변의 2.5%, 두 줄까지. 본문은 아주 작게(1.4~1.6%) 회색.

## 질감과 모양
- 그레인 0.08, 비네트 0.2. 사진 카드는 따로 그레인을 조금 더(필름 느낌).
- 사진 카드: 모서리 큰 둥근 사각(카드 짧은 변의 6% 안팎), 테두리·그림자 없음. 어둠에서 떠오를 때 가장자리가 먼저 보이지 않게 카드 전체 밝기를 0 → 1.
- 알약: 1.5px 흰 테두리(80%), 속은 비어 있거나 흰색 8% 반투명. 높이는 짧은 변의 5~6%.
- 사진 벽: 크기 다른 사진 칸(1칸·2칸·2×2칸)이 틈 0.6u 로 꽉 맞물려요. 칸 모서리는 아주 살짝(0.4u).

## 움직임
- 100BPM, 보통. 바퀴와 카드 등장은 느긋하게, 타자와 바램은 빠르게. 빠름과 느림의 대비가 이 결이에요.
- 낱말 바퀴: 목록이 위에서 아래로 흘러요. 천천히 출발해 빨라졌다가 감속하며 1.2초 동안 대여섯 칸을 지나 멈춰요(`power3.inOut`, 넘침 없음). 멈춘 뒤 1.5초 머묾.
- 바퀴가 옅어지며 사라지면 왼쪽 작은 글이 왼쪽으로 조금 밀리고, 빈 알약에 검색어가 초당 35~40자로 쳐져요. 첫 글자가 쳐질 즈음 뒤에서 사진 카드가 0.4초 동안 어둠에서 떠올라요.
- 카드 안 사진은 머무는 2초 동안 아주 천천히 다가와요(scale 1 → 1.04).
- 나갈 때 카드가 0.2초 만에 우윳빛으로 하얗게 바래요. 그 순간 컷으로 밝은 종이 화면.
- 사진 벽은 1~1.5초 동안 천천히 커져요(scale 1 → 1.05). 그중 한 칸이 크게 확대된 화면으로 컷되고, 뒤 벽은 흐리고 하얗게 깔려요.

## 전환
- 검은 화면 ↔ 사진 카드: 페이드(어둠에서 떠오름).
- 카드 → 종이 화면: 하얗게 바램 + 컷.
- 사진 벽 → 한 칸: 확대(zoom)나 컷. 종이 화면 → 다음 바퀴: 검정으로 페이드.
- 장면 쌓기: fade → zoom → cut.

## 대표 장면
1. **낱말 바퀴**
   ```
   // 낱말 목록을 세로로 쌓은 열(col) 하나, 줄 높이 h. 알약은 고정, 열만 움직임
   const k = M.ease.inOutCubic(M.prog(t, t0, 1.2));
   const y = M.lerp(-from * h, -to * h, k);   // from → to 칸 (위에서 아래로 흐르게 목록 순서를 뒤집어 둠)
   col.style.transform = `translateY(${y}px)`;
   items.forEach((el, i) => { const d = Math.abs(i * h + y) / h; el.style.opacity = Math.max(0, 1 - d * .35); });
   ```
   - 장면 쌓기에서는 scenes.number 의 odometer 가 같은 결(자리마다 굴러감)을 따라가요.
2. **필름 사진 카드 + 알약 검색어**
   ```
   card.style.opacity = M.prog(t, t1, .4);                         // 어둠에서 떠오름
   M.place(photo, cx, cy, {s: 1 + .04 * M.prog(t, t1, 2.4)});      // 천천히 다가옴
   query.textContent = M.type(q, t, t1 - .2, 38);
   pill.style.width = query.offsetWidth + 2 * u + 'px';            // 알약이 글을 따라 늘어남 (M.box 로 모서리 유지)
   ```
   - 사진 색 보정은 CSS `filter: saturate(1.15) contrast(.92)` + 청록·노랑 두 겹 `mix-blend-mode: soft-light` 색면으로. 사진은 사용자 사진이나 CC0.
3. **하얗게 바래며 사진 벽으로**
   ```
   veil.style.opacity = M.prog(t, t2, .2);                          // 카드 위 흰 막(#F1F1EE) 0 → 0.85
   // t2 + .2 에 컷 → 종이 화면. 사진 칸은 미리 정한 격자 배치(1·2·2×2칸)를 grid-template 로
   M.place(wall, S.W / 2, S.H / 2, {s: 1 + .05 * M.prog(t, t2 + .2, 1.4)});
   ```
   - 한 칸 확대는 `S.tr.zoom` 이나 `M.camera(wall, 칸x, 칸y, zoom)` 로. 뒤 벽은 `blur(1.2u)` + 흰 막 50%.

## 어울리는 곳 / 피할 것
- 어울림: 검색·추천 서비스, 쇼핑·여행 큐레이션, 메뉴·상품 여러 개 소개, 사진이 많은 브랜드. 같은 형식을 주제만 바꿔 되풀이하기 좋아서 "○○도, ○○도" 구성에 잘 맞아요.
- 피할 것: 굵은 큰 제목, 원색 바탕, 손그림 장식, 사진 없이 글만. 바퀴 낱말은 한글 2~4자 낱말로 짧게.
- 영상 속 서비스 이름과 화면은 쓰지 않고, 바퀴 → 카드 → 사진 벽으로 이어지는 리듬과 색 보정의 원리만 가져와요.
