# 연보라 토큰 갈아 끼우기 (제품 UI)

한 줄: 연보라 판에서 디자인 도구의 변수 목록에 바짝 붙어요. 행이 연두·연보라 알약으로 켜지고, 값 칩의 색과 이름이 한 줄씩 다시 쳐져요. 이어 빽빽한 컴포넌트 벽의 테마가 통째로 갈리고, 검은 화면에서 글자 견본과 색 칩이 모여 작은 도형 마크로 맺어요.

## 보는 느낌
- 처음은 아무것도 없는 연보라 판 한 장. 곧 그 위에 보라 점선 칸으로 묶인 컴포넌트 변형들(아이콘+이름 줄, 아이콘 줄, 버튼 칸)이 격자로 깔려요.
- 카메라는 거의 늘 UI 하나에 바짝 붙어 있어요. 패널이 화면 높이의 절반 넘게 차고, 가장자리는 화면 밖으로 잘려요. 넓게 보는 순간은 테마 벽 장면뿐이에요.
- 가운데 부분은 옅은 회색 판 위 목록과 표예요. 줄 사이 가는 회색 구분선, 왼쪽 나무 가지 선, 오른쪽 끝 작은 회색 숫자로 정리된 아주 담백한 화면이에요.
- 이어 화면을 꽉 채운 컴포넌트 벽(카드, 슬라이더, 토글, 버튼, 사진 타일)이 깔리고 가운데 드롭다운 두 개가 떠요. 벽은 움직이지 않고 색만 갈려요.
- 끝은 새까만 화면. 흰 두 줄 문장, 이어 빨강 글자 견본 타일과 점선 선택 상자, 고정폭 글씨를 단 색 칩 줄이 흩어졌다 작은 마크 하나로 모여요.

## 색
- 옅은 회색 판 60 · 연보라 판 20 · 먹색 글자 12 · 강조 8.
- 연보라 #B8ACE8 은 여는 판과 강조 알약에, 옅은 회색 #EDEDEC 는 목록·표 판에 써요. 글자는 먹색 #1C1B22, 보조 글은 62%.
- 고른 행은 연두 #C6E79C 또는 연보라 알약으로 켜요. 값 칩의 견본은 보라 #6E56E8 → 초록 → 분홍 → 라임처럼 장면마다 한 계열만.
- 테마 벽은 장면 하나에 한 계열만 써요: 올리브(#7A9A2E·#E3E8CF), 테라코타(#D9532B·#E9CFC4), 보라(#7B61F0·#D9D2F5), 어둠(#2A2A33·#4A3FA0).
- 엔딩은 검정 #141414 위에 흰 글자, 빨강 #E0343F 글자 견본, 초록·하늘·자홍·주황 칩. 원색이 여럿 나오는 건 이 엔딩 한 장면뿐이에요.

## 글자
- UI 글은 Geist 500(한글 Noto Sans KR Medium). 패널 제목은 700, 목록 행은 500, 오른쪽 숫자는 회색 400.
- 값 칩 이름과 색 번호는 Geist Mono 500. 색 번호는 `#EE67C` 처럼 짧게 붙여 칩 위아래에 둬요.
- 큰 숫자(예: 100+)도 Geist Mono 로, 짧은 변의 12% 안팎.
- 엔딩 문장은 Geist 400, 왼쪽 정렬 두 줄, 짧은 변의 9% 안팎, 자간 −0.02em, 줄 간격 1.0으로 촘촘하게.
- 글자 견본 타일은 Geist 600 의 'Aa' 같은 두 글자를 칸보다 크게 넣어 아래가 잘리게, 크기를 셋으로 계단처럼 쌓아요.

## 질감과 모양
- 질감 없이 매끈한 화면이에요.
- 패널은 흰빛 회색, 모서리 1.2u, 아주 옅은 그림자 하나. 고른 행 알약은 모서리 0.8u.
- 값 칩은 1px 회색 테두리 둥근 사각 안에 작은 색 견본 네모(0.5u 모서리)와 고정폭 이름.
- 변형 묶음 칸은 보라 1px 점선. 엔딩 선택 상자는 하늘·연보라가 번갈아 칠해진 두꺼운 점선 테두리이고, 위 가운데에 작은 마름모 손잡이가 달려요.
- 커서는 흰 테두리를 두른 큰 검은 화살표(짧은 변의 7%).

## 움직임
- 104BPM, 보통 빠르기. 카메라 이동과 확대는 `power3.inOut` 으로 미끄러지듯, UI 안 변화(알약, 견본, 글자)는 짧고 또렷하게 0.2~0.3초.
- 목록 장면은 1박마다 한 행씩: 커서 이동 → 누름 → 알약 차오름 → 목록 한 칸 스크롤.
- 값 표는 2박마다 한 번 갈리고, 줄 사이 0.1초씩 엇갈려요.
- 테마 벽은 1박에 한 번, 0.15초 짧은 페이드로 색만 바뀌고 자리는 꼼짝 않아요.
- 엔딩 조각들은 박마다 톡 놓이고(back.out 아주 약하게), 마지막엔 한가운데로 모여 작아져요.

## 전환
- 장면 사이는 대부분 컷. 패널에서 패널로 옮길 땐 카메라가 확대한 채 옆으로 밀어내요(push).
- 테마 벽의 색 바꿈과 검은 화면으로 넘어가는 순간만 짧은 페이드. 장면 쌓기: cut → push → fade.

## 대표 장면

1. **목록 행이 알약으로 켜짐**
   ```js
   // 패널을 1.8배 확대해 왼쪽 위를 화면 가운데로
   M.place(panel, cx, cy, {s: M.anim([[0, 1], [.2, 1.8, {d: .9, e: 'inOutCubic'}]], t)});
   rows.forEach((r, i) => {
     const ti = 1 + i * M.beat(1);
     const k = M.ease.outCubic(M.prog(t, ti + .15, .25));      // 커서가 누른 뒤 알약 차오름
     r.pill.style.clipPath = `inset(0 ${(1 - k) * 100}% 0 0)`;
     M.draw(r.branch, M.prog(t, ti, .3));                       // 나무 가지 선
   });
   list.style.transform = `translateY(${-M.at(rows.map((_, i) => [1.5 + i * M.beat(1), i]), t) * rowH}px)`;
   // 커서: M.Cursor 로 행마다 옮기고 M.cursorAt 으로 누름
   ```
2. **값 칩 다시 쳐지기**
   - 표 세 줄을 그대로 두고 2박마다 이름 교체. 줄 i 는 `ti = t0 + i * .1`.
   ```js
   swatch.style.background = M.color(prev, next, M.prog(t, ti, .2));
   const out = M.prog(t, ti, .25), inn = M.prog(t, ti + .25, .4);
   chip.textContent = inn > 0 ? M.type(nextName, t, ti + .25, 24) : prevName;
   S.chars(chip).forEach((c, j, a) => c.style.opacity = inn > 0 ? 1 : 1 - M.prog(out, j / a.length, .3)); // 앞 글자부터 옅어짐
   ```
   표 이름은 `S.fx` 로 낱말 하나만 새 색으로 바꿔요.
3. **테마 벽 통째로 갈기**
   - 컴포넌트 벽을 한 번만 짓고 색은 CSS 변수로. `S.ambient(t => { const th = M.at([[0,'olive'],[M.beat(1),'clay'],[M.beat(2),'violet'],[M.beat(3),'night']], t); wall.dataset.theme = th; })` 에 0.15초 `transition: background, color`.
   - 가운데 드롭다운 두 개는 같은 시각에 글만 바꿔요(예: 교육/밝음 → 기업/어둠). 벽 위치는 꼼짝 않아요.
4. **검은 화면 견본과 마크로 접기**
   - 문장은 어절마다 `M.place(w, x, y, {o: k})` 로 붙이고, 첫 어절은 잠깐 연두였다가 흰색으로.
   - 이어 박마다 조각 하나씩: 빨강 글자 견본 타일 셋(크기 계단), 점선 선택 상자와 마름모 손잡이(`M.draw` 로 테두리를 0.3초), 색 칩 줄과 고정폭 번호(`S.tr.blocks` 로 번호 바탕이 한 프레임씩 깜빡). 마지막 1초에 모든 조각을 `M.anim` 으로 가운데로 모으며 0.2배까지 줄이고, 우리 브랜드 도형 마크 하나로 바꿔 끼워요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 디자인 시스템·토큰 도구 소개, 여러 브랜드·테마를 한 곳에서 관리하는 기능, 설정값이 화면에 바로 반영되는 기능 시연, 디자인·개발 협업 도구 런칭.
- 피할 것: 손그림 선과 종이 질감, 그레인·비네트 같은 필름 질감, 화면 전체를 넓게 보여 주기만 하는 구성, 느리게 번지는 그라디언트 바탕, 한 화면에 강조색 셋 이상(테마 벽 장면만 예외).
- 원본의 이름·로고·마크는 쓰지 않고, 목록 이름과 마크는 우리 브랜드 것으로 새로 지어요.
