# 세이지 색 갈아입기 창 (제품 UI)

한 줄: 옅은 세이지 바탕에 올리브 문장이 한 토막씩 이어지고, 그 사이 앱 창과 색 편집 패널이 번갈아 커지며 박자마다 창의 색, 글꼴, 군더더기가 바뀌는 차분한 기능 소개예요.

## 보는 느낌
- 기본 화면은 아무것도 없는 옅은 세이지 판 한가운데 올리브 문장 한 줄. 여백이 넓고, 글자는 화면 너비의 30~45%만 차지해요.
- 문장 장면과 시연 장면이 번갈아 와요. 문장 → 색 판 → 문장 → 앱 창 연속 → 문장 → 창과 옆 패널 → 팝업 더미 → 문장 → 마크.
- 시연 장면에서는 바탕 자체가 움직임의 주인공이에요. 색을 고르면 화면 전체가 그 색으로 바뀌고, 앱 창은 박자마다 통째로 다른 색을 입어요.
- 첫 장면만 진한 올리브 판 위에 흰 낱말 하나. 마지막은 다시 세이지 판에 올리브 마크 한 줄로 닫아요.

## 색
- 세이지 바탕 70 · 올리브 글자 15 · 시연 색 15.
- 바탕 #DFE7D6, 글자 올리브 #4A6236(흐린 말은 66%). 올리브 판은 #62784A, 그 위 글자는 흰색.
- 시연 색은 장면 안에서만 잠깐씩: 하늘 #5E9BB5(바뀐 낱말), 자홍 #C8338E, 남보라 #4E4A72, 팥색 #7A4A4A. 바탕 전체를 이 색으로 컷해도 괜찮지만 한 박 넘게 머물지 않아요.
- 패널·카드 바탕은 따뜻한 미색 #F7F5EC, 그림자는 아주 옅게.

## 글자
- 둥근 기하 산세리프(Geist, 한글은 Noto Sans KR). 문장의 첫 낱말만 700, 나머지는 500으로 같은 크기에 굵기만 달라요.
- 문장 글자 크기는 짧은 변의 6~7%. 가운데 정렬 한 줄, 끝에 마침표를 찍어 말을 맺어요.
- 오프닝 낱말은 900에 가깝게 굵고 동글게, 흰색에 아주 옅은 그림자. 가운데 글자가 여러 번 늘어나며 낱말이 옆으로 길어져요.
- 바뀐 낱말 하나만 시연 색으로 칠하고(marker: color), 나머지는 그대로 올리브.

## 질감과 모양
- 질감 없이 매끈한 평면. 그레인·비네트를 쓰지 않아요.
- 앱 창·패널은 모서리 1.6u, 흐린 그림자 한 겹(아래로 2u, 18% 정도).
- 색 판: 둥근 사각 안을 무지개 테두리(빨강→노랑→초록→파랑→자홍)가 감싸고, 안에 흰 테를 두른 색 점 둘. 점 지름은 판의 12%.
- 팝업 카드는 파랑·주황·연보라 둥근 카드가 비스듬히 겹쳐, 연한 미색 판 위에 놓여요.

## 움직임
- 104BPM, 보통 빠르기. 문장 낱말은 한 박에 하나씩 붙고, 앱 창 색은 한 박마다 갈려요.
- 들어오는 건 power3.out 으로 빨리 와서 부드럽게 멈추고, 카메라는 power2.inOut 으로 천천히 다가가며 3~5도 기울어요.
- 바탕색 바뀜은 서서히 번지지 않고 컷이에요. 대신 창과 카메라가 계속 흐르고 있어서 거칠지 않아요.
- 문장은 1.5~2박 머물고, 시연 장면은 4~8박.

## 전환
- 컷이 기본. 앱 창이 들어올 땐 옆에서 밀어내기(push), 팝업이 사라질 땐 흐림(blur)으로 녹여요.
- 장면 쌓기: cut → push → blur.

## 대표 장면

1. 늘어나는 낱말 오프닝
   ```
   // 올리브 판(s-accent), 가운데 글자를 박마다 하나씩 복제해 낱말이 옆으로 길어짐
   const n = Math.floor(M.prog(t, .3, M.beat(4)) * 6);
   word.textContent = head + mid.repeat(1 + n) + tail;
   M.place(word, cx, cy, {s: 1 + .03 * Math.sin(t * 6)});   // 말랑하게 살짝 출렁
   // 4박째 컷 → 세이지 판 문장 장면
   ```
2. 토막으로 이어지는 문장
   ```
   const words = S.$$('.w');                    // 첫 낱말만 700
   words.forEach((w, i) => {
     const k = M.ease.outCubic(M.prog(t, i * M.beat(1), .35));
     M.place(w, x[i], cy + (1 - k) * u * 1.2, {o: k});
   });
   swap.style.color = 'var(--pal1)';              // 바뀐 낱말 하나만 시연 색
   ```
   - 장면 쌓기에서는 title: pop 과 marker: color 로 같은 결이 나와요.
3. 색 판 점 끌기 → 바탕 컷
   ```
   const p = M.anim([[0, A], [M.beat(1), B, {d: .6, e: 'inOutCubic'}]], t);
   M.place(dot, p.x, p.y);
   stage.style.background = M.at([[0, '#7A4A4A'], [M.beat(2), '#4E4A72']], t);
   ```
   - 이어서 앱 창 장면은 `frame: window` 로 띄우고, 창 바탕을 `M.at` 으로 한 박마다 남색 → 보라 → 자홍 → 숯빛 컷. 창은 `M.place(win, cx, cy, {s: 1 + t * .02, rotate: -3 + t * .5})` 로 계속 다가가요.
4. 옆 패널 누르기와 팝업 녹이기
   - `M.Cursor` 를 패널 칸으로 옮겨 `M.cursorAt` 순간에 창 글꼴을 굵게 바꾸고 카메라를 1.4배로. 팝업 더미는 커서가 아래 버튼을 누르면 카드마다 `{o: 1 - k, blur: k * 12, y: -k * u * 3}` 로 0.1초씩 엇갈려 녹이고, `S.tr.blur` 로 문장 장면에 이어요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브라우저 확장·꾸미기 도구 소개, 테마·색 설정 기능 런칭, 웹페이지 편집 기능 안내, 개인화 기능을 낱말 셋으로 훑을 때.
- 피할 것: 그레인·종이 질감, 손그림 선, 네온 빛 번짐, 글리치처럼 빠른 깜빡임, 한 화면에 문장 여러 줄.
- 한글은 문장 토막을 2~4어절로 짧게 잘라야 한 박 리듬이 살아요.
