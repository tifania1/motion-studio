# 유화와 편집 화면 교차 (제품 UI)

한 줄: 어둑한 고전 유화 장면을 천천히 다가가다 컷으로 밝은 상점 편집 화면에 들어가요. 그림 속 인물 뒤로 흰 고딕 제목이 숨고, 낱말 한 토막만 이탤릭 세리프로 바뀌는 런칭 필름이에요.

## 보는 느낌
- 두 세계를 번갈아 보여 줘요. 하나는 짙은 초록 숲과 흐린 청회색 하늘, 붉은 천이 드리운 유화 장면이고, 다른 하나는 미색 바탕의 깔끔한 상점 화면·폰 채팅·숫자판이에요.
- 그림 장면에서는 글을 왼쪽 위에 두고 넓은 여백을 남겨요. 숫자나 제목은 그림 앞쪽 사물(꽃, 인물의 팔) 뒤에 깔려서 일부가 가려져요.
- 화면 장면에서는 미색 판 한가운데 기능 이름 한 줄만 두거나, 상점 페이지 한 장을 크게 띄우고 한 구역만 손봐요.
- 둘 사이를 잇는 건 제품 하나예요. 상품 사진이 그림 위를 가로지르고, 그림 속 인물이 화면 시안을 들여다보는 식으로 두 세계가 섞여요.
- 그림은 우리 영상에서 직접 그리지 않아요. 브랜드가 준 사진에 유화 결을 입히거나, 흐린 하늘 그라디언트와 구름 덩어리로 분위기만 잡아요.

## 색
- 그림 장면: 짙은 청록 #24302D 65 · 하늘 청회색 #6F8A8F 20 · 붉은 천 #9A3E2E 10 · 흰 글자 5.
- 화면 장면: 미색 #ECEAE3 80 · 먹색 글자 #1E1E1C 15 · 보라 #6B4EF0 5(선택 상자·꼬리표만).
- 강조 노랑 #E3C35A 는 엔딩 문장의 어절, 승자 꼬리표 테두리에만 써요. 노랑 위 글자는 짙은 갈색 #1E1A0E.
- 버튼은 반투명 짙은 회색 알약에 흰 글자.

## 글자
- 기본은 Geist(한글은 Noto Sans KR Medium·Bold). 제목 600, 자간 −0.025em, 줄 간격 1.0 으로 붙여 써요.
- 그림 위 제목은 짧은 변의 8~10%, 왼쪽 정렬 두세 줄. 미색 판의 기능 이름은 5~6%, 가운데 한 줄.
- 낱말 속 한 토막만 Instrument Serif 이탤릭(한글은 고운바탕)으로 바꿔 박아요. 한 영상에 한두 번만.
- 숫자(+150, 1.52%)는 Geist 600, 아주 크게. 아래 작은 설명은 400.
- 입력 알약 속 글은 Geist 400, 짧은 변의 3.5%.

## 질감과 모양
- 그레인 0.06(초당 12번), 비네트 0.28. 그림 장면이 오래된 캔버스처럼 살짝 거칠고 가장자리가 어둡게.
- 화면 장면도 같은 그레인을 그대로 둬서 두 세계가 한 필름처럼 이어지게 해요.
- 상점 페이지·폰은 모서리 1.6u, 부드럽고 넓은 그림자 하나.
- 선택 상자는 2px 보라 선, 왼쪽 위에 보라 꼬리표. 입력 알약은 흰색, 그림자 깊게, 왼쪽에 둥근 아이콘.
- 버튼 알약 둘레에 가는 가로선 두세 줄이 화면 끝까지 그어져 있어요.

## 움직임
- 100BPM. 그림 장면은 1.5~3초 머물고, 화면 장면은 1초 안팎으로 끊어요.
- 그림 장면에서는 카메라가 계속 아주 천천히 다가가요(5~6초에 4%, linear). 글은 power3.out 으로 줄마다 0.5초에 올라와요.
- 숫자는 흐림에서 선명해지며 세어 올라가요(106+ → 150+ 처럼 0.8초).
- 입력 알약 타이핑은 초당 18~22자, 끝에 커서가 한 박 깜빡여요. 그다음 구역 변화는 컷.
- 제품은 그림 위를 0.6초에 비스듬히 가로질러 날아들어 버튼 뒤에 멈춰요.

## 전환
- 컷이 기본이에요. 그림에서 그림으로 갈 땐 짧은 페이드(0.4초), 화면 페이지가 바뀔 땐 옆으로 밀어내기.
- 장면 쌓기: cut → fade → push.

## 대표 장면
1. **그림 속에 끼어든 제목**
   ```
   // 바탕 그림 · 제목 · 앞쪽 오림(인물·꽃) 세 겹
   S.ambient(t => M.place(bgImg, cx, cy, {s: 1 + t / 6 * .04}));
   S.fx.mask(title, {at: .4, stagger: .12});   // 줄마다 선 아래에서
   M.place(foreCut, cx, cy, {s: 1 + t / 6 * .05}); // 앞 겹은 조금 더 빨리 다가와 깊이감
   ```
   숫자 장면은 같은 구성에 `S.fx.count` 와 `blur` 6px → 0 을 같이 걸어요.
2. **선택 상자와 입력 알약으로 고치기**
   - 상점 페이지(frame browser) 한 구역에 `Studio.M.box(sel, rect)` 로 보라 선택 상자를 0.3초에 펼쳐요. 그 위에 흰 알약을 `M.spring(t - t0, 'smooth')` 로 띄우고, 안의 글은 `M.type(text, t, t0 + .3, 20)`.
   - 타이핑이 끝나는 박에 `M.at` 으로 구역 안 내용을 컷으로 바꿔요(제목 굵게, 바탕 어둡게). 장면 쌓기에서는 deco handles 가 상자를, cursor 가 누르는 손을 맡아요.
3. **그림 위를 지나가는 제품과 버튼**
   ```
   const k = M.ease.outCubic(M.prog(t, t0, .6));
   M.place(product, M.mix(W * 1.1, cx, k), M.mix(-H * .2, cy, k), {r: M.mix(-35, -8, k)});
   M.place(buyPill, cx, cy + H * .05, {o: M.prog(t, t0 + .5, .3)});  // 짙은 반투명 알약
   lines.forEach((l, i) => M.draw(l, M.prog(t, t0 + .4 + i * .08, .5)));
   ```
4. **두 안 나란히, 그리고 세리프 한 토막 엔딩**
   - 미색 판에 상점 시안 두 장을 나란히 두고 위에 큰 숫자를 `S.fx.count`(0.98% → 1.52%, 0.30% → 2.17%). 다음 박에 이긴 쪽만 남기고 아래에 노랑 테두리 꼬리표를 `M.spring` 으로.
   - 엔딩은 어두운 하늘 그림 위 세 줄. 낱말 속 두세 글자 span 에 이탤릭 세리프를 주고, 한 박 뒤 뒤쪽 어절을 `M.color(onBg, accent, k)` 로 노랑으로 물들여요. `S.tr.blur` 로 빠지면 가운데 마크 하나만 남겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 기능 묶음 발표·시즌 업데이트, 상점·커머스 도구 런칭, AI 편집 기능 소개, 격 있는 브랜드 캠페인.
- 피할 것: 형광 그라디언트, 손그림 선, 빠른 글리치 컷, 그림 위에 문장 여러 줄, 강조색 여러 개(노랑 하나와 편집 표시용 보라만).
- 그림 장면과 화면 장면을 둘 다 써야 이 결이 살아요. 한쪽만 이어지면 평범한 화면 시연이 돼요.
