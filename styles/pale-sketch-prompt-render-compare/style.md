# 스케치에서 결과로, 나란히 견주기 (제품 UI)

한 줄: 옅은 회색 판에 손 스케치 카드가 놓이고, 흰 입력 카드에 부탁이 쳐지며 핵심 문장만 파랗게 물들어요. 결과 카드는 비스듬히 돌아 들어와 파란 빛 테두리를 켜고, 끝에는 두 결과를 나란히 두고 조건을 박자마다 바꿔 견주는 차분한 비교 데모예요.

## 보는 느낌
- 무늬 없는 옅은 회색 판 하나로 끝까지 가요. 화면에는 늘 카드 하나, 많아야 둘만 떠 있어서 여백이 넉넉해요.
- 이야기는 한 방향으로 흘러요: 제목 → 입력 재료(스케치) → 부탁(입력 카드) → 결과(빛 테두리 카드) → 견주기(카드 둘) → 주소 한 줄.
- 주인공 카드에만 파란 빛 테두리가 붙어요. 그래서 둘을 나란히 놓았을 때 어느 쪽이 '우리 쪽'인지 말없이 보여요.
- 마지막엔 파랑 점과 약간의 초록 점이 물결 모양으로 흩어진 띠 위에 흐린 글씨가 맺혀요.

## 색
- 회색 판 #EDEDEC 75 · 흰 카드 15 · 파랑 7 · 먹 글자 3.
- 제목은 파랑 #3462D9 에서 하늘빛 #8FB0F2 로 흐르는 그라디언트 글씨.
- 입력 카드 문장은 회색(먹 56%), 요구 대목만 파랑. 빛 테두리와 알약 둘레의 번짐은 rgba(110,155,240,.45).
- 비교 장면의 조건 색(밤 남색, 노을 적갈, 연분홍, 하늘)은 카드 속 그림 바탕에만 쓰고 판에는 번지지 않게 해요.
- 초록 #3FA35A 은 마무리 점 물결의 한 무리에만.

## 글자
- Geist(한글은 Noto Sans KR Medium). 제목은 500 굵기, 짧은 변의 6~7%, 가운데 정렬 한 줄. 크지도 굵지도 않게.
- 입력 카드 글은 짧은 변의 2.2% 안팎, 왼쪽 정렬, 줄 간격 1.6. 다섯 줄 남짓.
- 카드 아래 이름표는 짧은 변의 2%, 왼쪽 카드는 맨 글자, 오른쪽 카드는 흰 알약 속 글자 + 작은 아이콘.
- 마지막 주소 글씨는 제목과 같은 파랑 그라디언트, 아래 아주 작은 회색 안내문 한 줄.

## 질감과 모양
- 질감 없이 매끈하게. 흐림은 등장과 마무리 때만 써요.
- 카드: 흰색, 모서리 2u, 아주 옅은 그림자 하나와 1px 회색 테두리.
- 빛 테두리: 2px 파랑 선 + 바깥 1.5u 번짐. 알약도 같은 선과 번짐을 두르고 안은 흰색.
- 스케치·결과 그림은 카드 안을 꽉 채우고 모서리만 둥글게 잘라요.

## 움직임
- 96BPM, 보통 빠르기. 들어올 땐 power3.out 으로 부드럽게 멈추고, 장면 하나가 2~3초 머물러요.
- 제목·스케치 카드는 살짝 작게(0.96) 흐림에서 맺히며 0.6초에 들어와요.
- 입력 카드는 아래에서 2u 올라와 자리를 잡고, 글은 초당 40자쯤. 파랑 대목은 쳐지는 그 자리에서 색이 바뀌어요.
- 결과 카드는 rotateY −35° → 0, 0.9초. 펴진 뒤 4초 동안 1.0 → 1.08 로 천천히 다가와요.
- 비교 장면은 1초마다 조건이 바뀌고, 바뀔 때 카드 속 그림만 0.3초 교차로 넘어가요. 카드 틀은 움직이지 않아요.

## 전환
- 기본은 페이드. 제목이나 주소처럼 글만 있는 장면은 흐림(blur)으로 들고 나요.
- 한 카드에서 두 카드로 갈 땐 결과 카드가 오른쪽 자리로 미끄러지고 왼쪽 카드가 페이드로 생겨 이어 붙어요. 장면 쌓기: fade → blur → cut.

## 대표 장면
1. **핵심 대목만 파랗게 쳐지는 입력 카드**
   ```js
   const full = before + key + after;            // key 가 요구 대목
   S.ambient(t => {
     const n = M.type(full, t, t0, 40).length;   // 지금까지 쳐진 글자 수
     txtA.textContent = full.slice(0, Math.min(n, before.length));
     txtK.textContent = key.slice(0, M.clamp(n - before.length, 0, key.length));   // 파랑 span
     txtB.textContent = after.slice(0, Math.max(0, n - before.length - key.length));
   });
   M.place(card, cx, cy, {y: (1 - M.spring(t - t0 + .4, 'smooth')) * u * 2});
   ```
   장면 쌓기에서는 frame: card + marker: color 로 같은 결이 나와요.
2. **비스듬히 돌아 들어와 빛이 켜지는 결과 카드**
   ```js
   const k = M.ease.outCubic(M.prog(t, t1, .9));
   card.style.transform = `perspective(1400px) rotateY(${(1 - k) * -35}deg) scale(${1 + M.prog(t, t1 + .9, 4) * .08})`;
   card.style.boxShadow = `0 0 0 2px rgba(52,98,217,${k}), 0 0 ${u * 1.5}px var(--glow)`;
   M.place(pill, cx, cy + h * .6, {o: M.spring(t - t1 - .6, 'smooth')});
   ```
3. **나란히 견주기, 조건이 박자마다 함께 바뀜**
   - 카드 둘을 가로로 두고 오른쪽에만 빛 테두리와 알약. 조건 목록 `['#1E2233', '#A8584A', '#E9A9A4', '#9FCBE6']` 을 `M.at(conds.map((c, i) => [t2 + i * M.beat(1.6), c]), t)` 로 고르고, 두 카드 속 그림 바탕을 동시에 0.3초 교차로 바꿔요. 왼쪽 그림은 밋밋하게, 오른쪽 그림은 그림자와 빛이 살아 있게 만들어 차이를 보여요.
4. **점 물결 위 흐린 주소가 맺히는 마무리**
   - 점 200여 개를 사인 물결 두 줄 위에 흩어 놓고(대부분 파랑, 한 무리만 초록) `S.ambient` 안에서 x 를 천천히 흘려요. 가운데 글씨는 `S.tr.blur` 결 그대로 `blur 1.2u → 0`, 1.2초. 장면 쌓기에서는 title: blur + deco: dots.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 새 모델·새 버전 비교, 입력에서 결과까지 보여 주는 기능 소개, 만들기·생성 도구 데모, 전후 비교가 핵심인 업데이트 공지.
- 피할 것: 어두운 바탕, 빠른 컷 몽타주, 굵고 큰 제목, 강조색 여러 개(파랑 하나, 마무리 점에만 초록), 거친 질감·그레인.
- 빛 테두리는 '우리 쪽' 한 카드에만 붙여야 비교가 또렷해요.
