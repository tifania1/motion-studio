# 폰 속으로 들어가는 투어 (제품 UI)

한 줄: 밝은 회색 위 폰 한 대로 시작해 화면 안으로 쑥 들어가요. 지도와 사진 핀, 바텀시트를 지나 사진들이 흐림 속에 세로로 휙 지나가요.

## 보는 느낌
- 세로 영상에 잘 맞는 구성. 폰이 화면 가운데 세로 75%를 차지하거나, 아예 폰 속 화면이 영상 화면이 돼요.
- 바탕과 폰 둘레는 아무것도 없는 밝은 회색. 시선은 늘 폰 화면 한 곳에.
- 사진이 많아도 둥근 모서리와 흰 테두리 덕에 정돈돼 보여요.

## 색
- 바탕 55 · 흰 UI 25 · 사진·지도 15 · 강조 5.
- 바탕 #ECECEC, UI #FFFFFF, 글자 #161616.
- 강조는 진한 분홍 하나(#D0245A): 버튼, 토글, 검색 아이콘에만.
- 지도는 옅은 베이지(#E9E4D8) + 연두 공원(#BFD9B0) + 연파랑 물길 정도로 아주 흐리게.

## 글자
- 둥글고 친근한 기하 고딕이 가장 잘 어울려요. fonts/ 에는 그런 글꼴이 없어서 Geist + Noto Sans KR 500/700 으로 두었어요.
- UI 안 제목은 짧은 변의 4%, Bold. 설명은 2.2%, 회색.
- 화면 밖 자막은 거의 쓰지 않아요. 써야 하면 사진 아래 가운데 한 줄.

## 질감과 모양
- 질감 없음.
- 폰: 검은 테두리(두께 1.2u), 모서리 7u, 아주 옅은 그림자. 다이내믹 아일랜드 같은 위쪽 알약 하나.
- UI 카드·바텀시트 모서리 3u. 사진 썸네일 모서리 1.6u + 흰 테두리 0.5u + 그림자 0 .8u 2u rgba(0,0,0,.15).
- 알약 버튼: 흰 바탕, 그림자, 글자 + 작은 아이콘.

## 움직임
- 104BPM. 들어갈 때는 빠르게(0.25초), 화면 안에서는 천천히 둘러보기.
- 화면 안 스크롤은 power2.inOut 0.6~0.8초. 바텀시트와 팝업은 M.spring 'snappy'.
- 사진 핀·썸네일은 'pop' (조금 넘침) 0.06초 간격.
- 사진 릴: 0.6초 동안 빠르게, 끝 0.15초에 확 감속하며 멈춤(expo.out).

## 전환
- 폰 밖 → 안: 흐림 디졸브 + 확대(zoom). 이 스타일의 기본 전환이에요.
- 화면 안 장면끼리: 흐림 디졸브(앞 장면 blur 0→14px + 옅어짐, 뒤 장면 선명하게 나타남) 0.2초.
- 기능 묶음이 바뀔 때는 컷.

## 대표 장면

1. 카드 하나 → 폰
   - 가운데 프로필 카드가 pop. 0.3초 뒤 카드 둘레에 폰 테두리와 화면 UI 가 생기며(테두리 scale 1.15→1, 투명 → 진하게) 카드가 화면 속 팝업이 됨.
2. 폰 속으로 들어가기
   ```
   // 화면 내용 바꾸기: 앞 내용 blur·옅게, 뒤 내용 선명하게 (0.12초)
   a.style.filter = `blur(${M.prog(t, t0, .12) * 14}px)`; a.style.opacity = 1 - M.prog(t, t0 + .06, .1);
   // 폰 전체 확대: 테두리가 화면 밖으로 나갈 때까지
   const z = M.anim([[t0 + .1, 1], [t0 + .35, 2.4, { d: .25, e: 'inOutCubic' }]], t);
   M.camera(world, phoneCx, phoneCy, z);
   ```
3. 지도 사진 핀 → 바텀시트
   - 핀 5~6개를 시드 난수로 흩되 가운데에 모이게. 각 핀 M.place(p, x, y, { s: M.spring(t - (t1 + i * .06), 'pop') }).
   - 1박 뒤 바텀시트가 아래에서 올라오고(지도는 살짝 위로 밀림), 핀 하나를 누르면 그 핀 자리로 지도가 확대되며 시트 내용이 바뀜.
4. 세로 사진 릴 → 스티커
   ```
   const pos = tt => M.anim([[t2, 0], [t2 + .6, -reelH, { d: .6, e: 'outExpo' }]], tt);
   const y = pos(t), v = (pos(t) - pos(t - 1 / 60)) * 60;      // 속도도 t 만으로 계산
   const blur = Math.min(18, Math.abs(v) / reelH * 6);
   reel.style.transform = `translateY(${y}px) scaleY(${1 + blur * .003})`; reel.style.filter = `blur(${blur}px)`;
   // 멈춘 사진 한 장: 크기 1 → .45, 흰 테두리 0 → .6u, 모서리 1.6u → 3u (M.spring 'snappy')
   // 뒤로 두 번째 사진이 4° 돌아간 채 겹쳐 나타나고, 아래 알약 버튼이 위로 올라옴
   ```
   - 흐림 세기는 앞 프레임을 기억하지 않고 t 와 t−1/60 의 위치 차로 계산해요(렌더러가 아무 시각이나 찍어도 같은 그림).
