# 별가루 낱말 카드 모자이크 (제품 UI)

한 줄: 푸른 별가루가 흩날리는 검은 화면 가운데 흰 낱말 하나가 쳐지고, 둘레로 앱 결과물 카드가 박자마다 칸칸이 채워지는 기능 묶음 소개.

## 보는 느낌
- 바탕은 거의 검은색이에요. 그 위에 아주 작은 푸른 점과 짧은 대시가 흩어져 있고, 가운데에서 바깥으로 아주 천천히 흘러요. 우주 먼지처럼 옅게 깔리고 화면을 채우지 않아요.
- 주인공은 가운데 흰 낱말 하나예요. 동사 하나(배우기, 짓기, 계획하기 같은)를 크게 두고, 그 낱말이 무엇을 할 수 있는지 결과물 카드로 둘레를 채워 보여 줘요.
- 카드는 3×3 칸 모자이크로 쌓여요. 가운데 세로 칸은 비워 낱말을 두고, 나머지 칸에 웹 화면, 레시피 카드, 3D 장면, 사진, 코드 결과가 한 장씩 들어와요. 카드 사이 간격은 짧은 변의 1.5% 안팎으로 좁아요.
- 가끔 밝은 판(옅은 하늘빛 회색)으로 컷해서 앱 창이나 완료 목록을 크게 보여 주고, 곧 다시 검은 화면으로 돌아와요.
- 문장을 위아래로 갈라 그 사이에 입력 알약을 끼우는 구성이 자주 나와요. 글과 UI 가 한 문장처럼 읽혀요.

## 색
- 검정 바탕 70 · 카드와 UI 20 · 흰 글자 8 · 파랑 2.
- 바탕 #0E0E10, 글자 #ECEDEF, 흐린 글자는 흰색 60%.
- 파랑 #5B8DEF 는 낱말 옆 작은 설명 한 토막과 별가루에만 써요. 별가루는 파랑 18~40%, 몇 개만 흰색.
- 밝은 판은 #F3F5F8, 그 위 글자는 #1C1D20. 완료 칩만 연한 초록 #8FD3A8 바탕에 짙은 초록 글자.

## 글자
- Geist 500(한글은 Noto Sans KR Medium). 둥글고 담백한 산세리프, 자간 −0.02em.
- 가운데 낱말은 짧은 변의 9~11%. 문장을 위아래로 가를 때는 낱말을 15~18% 로 크게 키워요.
- 낱말 옆 파란 설명은 짧은 변의 4% 안팎, 왼쪽 정렬 두 줄.
- 한 화면에 낱말 하나나 짧은 구 하나만. 엔딩에서만 동사 셋을 한 줄로 나란히 둬요.

## 질감과 모양
- 화면 질감은 없어요. 매끈한 검정에 별가루만 깔아요.
- 카드: 모서리 `--u` × 1.4, 아주 얇은 흰 테두리(8%)와 부드러운 그림자. 어두운 카드와 밝은 카드가 섞여요.
- 입력 알약: 밝은 회색 #EEF0F3, 모서리는 높이의 절반, 안에 작은 + 아이콘과 알약 칩 하나, 오른쪽 끝에 보내기 단추.

## 움직임
- 116BPM, 보통 빠르기. 낱말은 한 박 안에 다 쳐지고, 카드는 반 박마다 한 장씩 들어와요.
- 카드는 칸 가운데에서 92% 크기로 나타나 `power3.out` 으로 0.35초 만에 제자리 크기로 멈춰요. 흐림 4px 에서 선명해지며 들어와요.
- 낱말은 글자마다 쳐지되 커서는 짧게 깜빡이고 사라져요. 반쯤 쳐진 상태(두 글자만 보이는 순간)를 컷으로 보여 주기도 해요.
- 별가루는 늘 움직여요. 반지름 방향으로 초당 짧은 변의 1% 정도 흘러나가고, 깊이마다 속도가 달라요.
- 장면 하나는 2~4박 머물러요.

## 전환
- 컷이 기본. 검은 화면끼리는 카드가 사라지고 낱말만 남았다가 다음 낱말로 컷.
- 밝은 판으로 들어갈 때는 앱 창이 밀려 들어오는 push, 엔딩 쪽은 느린 fade.
- 장면 쌓기: cut → fade → push.

## 대표 장면
1. **낱말 둘레 카드 모자이크**
   ```
   // 3x3 칸, 가운데 세로 칸(1,4,7)은 낱말 자리
   const cells = [0,2,3,5,6,8];
   M.type(word, t, 0, 14);                         // 낱말 먼저 쳐짐
   cards.forEach((c, i) => {
     const k = M.ease.outCubic(M.prog(t, M.beat(1) + i * M.beat(.5), .35));
     M.place(c, gx(cells[i]), gy(cells[i]), {s: .92 + .08 * k, o: k, blur: (1 - k) * 4});
   });
   ```
   장면 쌓기에서는 title: type 으로 낱말이 쳐지고, 카드는 card: shadow 로 둘레에 놓여요.
2. **문장 사이 입력 알약**
   - 첫 낱말을 위 30% 자리에, 끝 낱말을 아래 75% 자리에 크게 두고, 가운데에 알약을 `x = M.anim([[0, W * 1.1], [M.beat(1), W/2, {d: .5, e: 'outCubic'}]], t)` 로 밀어 넣어요. 멈추면 안의 부탁을 `M.type(text, t, M.beat(1.5), 22)`.
   - 다음 컷은 밝은 판(s-paper). 목록 줄 오른쪽 칩을 `M.color('#E4E6EA', '#8FD3A8', k)` 로 위에서부터 0.15초 간격으로 켜요.
3. **비스듬히 돌아 들어오는 카드**
   - 왼쪽에 반쯤 쳐진 구, 오른쪽에 카드 한 장. 부모에 `perspective`, 카드는 `rotateY` 35° → −8°, `rotateZ` −6° 로 0.6초에 돌며 다가와 멈추고, 머무는 동안 `M.drift` 로 아주 조금 흔들려요.
4. **동사 셋 한 줄과 별가루 모으기**
   ```
   S.ambient(t => {
     const pull = M.ease.inCubic(M.prog(t, tEnd - 1.2, 1.2));   // 끝에서 가운데로 빨려 듦
     dots.forEach(d => M.place(d.el, cx + d.dx * (1 - pull) + d.vx * t,
                                      cy + d.dy * (1 - pull) + d.vy * t, {o: d.o * (1 - pull * .6)}));
   });
   ```
   동사 셋은 가운데 한 줄에 어절씩 0.2초 간격으로 놓이고, 별가루가 다 모이면 그 자리에 작은 마크가 `M.spring(t - tEnd, 'smooth')` 로 맺혀요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 도구 기능 묶음 소개, 여러 쓰임새를 동사로 훑는 런칭, 키노트 오프닝, 업데이트 하이라이트 릴. 30~60초 영상.
- 피할 것: 밝은 바탕이 주가 되는 구성(밝은 판은 사이사이 한두 번만), 손그림 선, 굵고 빽빽한 제목, 강조색 여러 개(파랑 하나와 완료용 초록만), 한 화면에 문장 여러 줄.
- 한글은 두세 글자 동사(배우다, 짓다, 풀다)를 크게 쓰면 이 결이 잘 살아요.
