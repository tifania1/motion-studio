# 세리프 속 마커 낱말 (손그림)

한 줄: 차분한 세리프 문장이 타자되다가 딱 한 낱말만 굵은 마커 손글씨 대문자로 써져요. 숫자는 손 타원이 감고, 마지막 말엔 붓 밑줄이 그어지는 메모 결이에요.

## 보는 느낌
- 화면 가운데 세리프 문장 한두 줄, 가운데 정렬. 둘레는 넉넉히 비워 둬요.
- 문장 속 낱말 하나만 손으로 쓴 마커 대문자예요. 반듯한 활자 사이에 사람 손이 한 번 끼어든 느낌이 이 결의 전부라서, 손글씨는 장면마다 하나만.
- 손으로 그은 선은 세 가지뿐: 숫자를 감는 타원, 끝 낱말 아래 붓 밑줄, 그리고 마커 낱말. 별·화살표 같은 낙서는 더하지 않아요.
- 밤 장면은 숯색 바탕에 크림색 글자, 낮 장면은 옅은 회색 바탕에 먹색 글자. 마지막은 라임 한 장.
- UI 화면이 나올 땐 얇은 테두리만 있는 어두운 카드 하나(달력, 목록)를 문장 아래에 두고 천천히 위로 흘려요.

## 색
- 바탕 85 · 글자 13 · 라임 2.
- 낮: 옅은 회색 #DFE0DA 위 먹색 #333333. 밤: 숯색 #333333 위 크림 #ECEBE4.
- 라임 #A9BD4E 는 숫자가 켜지는 순간, 날짜 같은 작은 강조, 마지막 한 장에만.
- 타자 색 물결용 보조색: 분홍 #D88BD3, 하늘 #9AA6E6, 연두 #8FAE3A. 막 친 글자에만 잠깐 스쳐요.

## 글자
- 문장: 본문용 세리프 400. 지금은 고운바탕(Gowun Batang)으로 한글·영문 모두. 어울리는 글꼴 성격은 글자 폭이 넉넉하고 획 대비가 낮은, 타자기 기운이 살짝 있는 세리프예요.
- 크기는 짧은 변의 6.5~8%, 줄 간격 1.1, 자간 −0.01em. 굵게 쓰지 않아요.
- 마커 낱말: 한글은 나눔손글씨 펜, 영문은 Caveat 700 을 대문자로. 세리프보다 1.2배 크게, −3도 안팎으로 기울이고, `-webkit-text-stroke: .025em currentColor` 로 획을 두툼하게 해 마커처럼 보이게.
- 숫자도 세리프. 단위(시·분, am)는 같은 크기로 띄어 써요.

## 질감과 모양
- 질감 없음. 매끈한 바탕 그대로.
- 손 타원: 크림색(밤) 또는 먹색(낮) 2~3px 한 획, 시작과 끝이 살짝 겹치고 위쪽에 짧은 꼬리.
- 붓 밑줄: 두께 0.8~1.2u, 왼쪽이 두껍고 오른쪽 끝이 갈라지며 가늘어지는 한 획, 바로 아래 가는 두 번째 획이 겹쳐요.
- UI 카드는 모서리 1u, 1px 테두리만. 그림자 없음.

## 움직임
- 96BPM. 문장 하나에 3~4박.
- 타자: 초당 25자 안팎, 커서(I 모양)가 앞장서요. 막 친 글자 5~8개가 색 물결로 물들었다 0.4초 안에 먹색으로.
- 마커 낱말은 타자가 그 자리에 오면 멈추고 0.6초에 왼쪽부터 써진 뒤 타자가 이어져요.
- 문장은 머무는 동안 위로 아주 천천히 흘러요(4초에 짧은 변의 1.5%).
- 손 타원 0.7초, 붓 밑줄 0.3초. 이징은 power3.out, 넘침 없음.

## 전환
- 컷이 기본. 밤 → 낮처럼 바탕이 바뀔 때도 그냥 잘라요. 숨 고르는 자리만 서서히(fade). 마지막은 라임 한 장으로 컷.

## 대표 장면

1. 마커 낱말이 끼어드는 문장
   ```
   // 문장을 앞부분 · 낱말 · 뒷부분 세 덩어리로. 앞뒤는 세리프 span, 낱말은 .hand span(Nanum Pen/Caveat, 1.2em, rotate -3deg)
   S.ambient(t => {
     pre.textContent = M.type(preText, t, T0, 25);                        // 앞부분 타자
     const tw = T0 + preText.length / 25;
     hand.style.clipPath = `inset(0 ${100 - 100 * M.prog(t, tw, .6)}% 0 0)`;   // 낱말 0.6초 왼쪽부터
     post.textContent = M.type(postText, t, tw + .65, 25);                // 뒷부분 이어서
     // 색 물결: 마지막으로 친 글자에서 거리 d 인 글자 색 = M.color(물결색[d % 3], 먹색, d / 6)
   });
   ```
2. 손 타원 속 올라가는 숫자
   - 숫자는 S.fx.counter(el, T0, .9, 50, 59) 처럼 하나씩 올리고, 동시에 `M.rough('ellipse', { turns: 1.1 })` 를 M.draw 로 0.7초. 마지막 값으로 바뀌는 순간 글자를 라임으로 바꾸고, 글자마다 0.05초 늦게 원래 색으로 되돌려 왼쪽부터 색이 빠지게.
3. 붓 밑줄로 닫기
   - 끝 낱말 아래에 붓 획 path 두 개(두꺼운 것, 가는 것)를 M.draw 로 0.3초, 두 번째는 0.06초 늦게. 반 박 뒤 S.tr.cut 으로 라임 바탕 한 장: 로고 + 세리프 한마디가 타자로.
4. 문장 아래 떠오르는 UI 카드
   - 문장을 위쪽으로 올리며 그 아래로 얇은 테두리 카드(달력·목록)를 M.spring 'smooth' 로 올림. 카드 안 한 줄이 라임 띠로 칠해지며 선택됨.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 앱·서비스 새 기능 소개, 메모·생산성 도구, 브랜드 한 줄 메시지, 차분한 기업 소식, 뉴스레터 예고.
- 피할 것: 굵은 고딕 제목, 종이·그레인 질감, 한 장면에 손글씨 낱말 둘 이상, 빠른 컷 연타, 원색 여러 개.
