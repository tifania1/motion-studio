# 라임 숲 대문자 컷 (타이포)

한 줄: 형광 라임과 버터 노랑 색면 위에 짙은 숲색의 꽉 찬 굵은 대문자가 컷으로 갈리고, 사이사이 국기 원이 줄지어 굴러가며 폰·카드 UI가 밝은 회색 판 가운데 떠서 숫자를 굴리는 송금 앱 런칭 필름.

## 보는 느낌
- 화면 전체를 한 색으로 칠한 판 위에 큰 글자 한두 줄만 둬요. 글자 판은 라임이 기본이고 가끔 버터 노랑으로 바뀌어 박자를 줘요.
- 한 문장을 두세 낱말씩 끊어 여러 컷에 나눠 말해요. 컷마다 글자 덩어리가 화면 너비의 60~75%를 차지하고, 둘레는 텅 비워 둬요.
- 글자 컷 사이에는 밝은 회색(#ECECEA) 판이 끼어들어요. 그 위엔 원 몇 개, 폰 한 대, 카드 한 장, 말풍선 하나처럼 늘 한 가지만 가운데 놓여요.
- 무게를 바꿔 줄 땐 판 전체를 짙은 숲색으로 칠하고 라임 글자나 라임 테두리 폰을 올려요. 끝 무렵엔 사람들이 웃고 있는 따뜻한 실사 사진 컷이 두세 장 지나가요.

## 색
- 라임 바탕 55 · 밝은 회색 판 25 · 숲색 글자와 숲색 판 15 · 노랑·청록·파랑 5.
- 라임 #9FE870, 숲색 #163300. 글자는 언제나 숲색이고, 숲색 판 위에서만 라임으로 뒤집혀요.
- 버터 노랑 #EAE27A 는 글자 판의 쉼표 같은 색이라 영상에 두세 번만. 옅은 청록 #A3D9D3 은 카드 한 장을 띄우는 바탕으로 한 번쯤.
- 파랑 #7F96E0 · 노랑 · 초록은 겹친 원 셋에만 써요. 장면 쌓기의 `--pal1~3` 으로 들어가요.

## 글자
- 큰 글: Archivo 900, 너비 85~90%로 살짝 좁혀 빽빽하게(한글은 Noto Sans KR Black). 대문자, 자간 −0.03em, 줄 간격 0.9.
- 크기는 짧은 변의 18~24%. 두 줄일 땐 위아래 줄 길이를 비슷하게 맞춰 네모난 덩어리로 보이게 해요.
- UI 안 글: Geist 500~600 + Noto Sans KR Medium. 금액만 Archivo 800으로 크게(카드 높이의 20%).
- 타임라인·말풍선 같은 작은 장면은 산세리프 400을 크게(짧은 변의 6~8%) 써서 조용하게.

## 질감과 모양
- 질감 없이 매끈한 색면이에요. 그레인·비네트를 넣지 않아요.
- 카드·폰 화면: 밝은 흰빛, 모서리 `--u` × 1.6, 아래로 아주 부드러운 그림자 한 겹.
- 원은 테두리 없는 꽉 찬 원. 타임라인은 숲색 2px 선에 속 빈 숲색 고리 점.
- 막대그래프 막대는 위가 둥근 알약 모양, 옅은 연두 회색(#DCE6D6)에 마지막 하나만 숲색.

## 움직임
- 100BPM(한 박 0.6초). 글자 컷은 대개 3~6박 머물고, 박 앞머리에 컷이 떨어져요.
- 큰 글은 줄마다 선 아래에서 0.4초에 올라와(`power3.out`) 그대로 멈춰 있어요. 나갈 땐 따로 움직이지 않고 컷.
- 원·카드·아이콘은 0.85에서 1로 톡 커지며 들어와요(스프링 'snappy'). 폰과 카드는 들어온 뒤 4~6초에 걸쳐 y축으로 8~12도 천천히 돌아요.
- 숫자는 자리마다 굴러 0.8초에 맞춰지고, 막대는 왼쪽부터 0.08초 간격으로 차올라요.

## 전환
- 컷이 기본. 원 행렬 장면은 밀어내기(push)로 이어 굴러가는 느낌을 살려요.
- 숲색 판으로 들어갈 땐 숲색이 한쪽에서 쓸고 들어오는 와이프(wipe) 한 번.
- 장면 쌓기: cut → push → cut → wipe. 페이드는 쓰지 않아요.

## 대표 장면

1. **색면 위 끊어 말하기**
   ```
   // 문장을 컷 3~4장으로 나눔. 판마다 바탕색과 낱말 덩어리만 바뀜
   const cuts = [['#9FE870', '우리가 하는 일'], ['#9FE870', '매일'], ['#EAE27A', '어디서나']];
   S.ambient(t => {
     const i = M.at(cuts.map((_, k) => [k * M.beat(4), k]), t);
     stage.style.background = cuts[i][0];
     lines.forEach((ln, j) => {                     // 줄마다 mask 안에서 올라옴
       const k = M.ease.outCubic(M.prog(t, i * M.beat(4) + j * .08, .4));
       M.place(ln, cx, cy + j * lh, {y: (1 - k) * lh});
     });
   });
   ```
   장면 쌓기에서는 title: mask + scale 1.3 + case upper 로 같은 결이 나와요.
2. **원 셋이 국기 행렬로 굴러가기**
   - 밝은 회색 판에 파랑·노랑·초록 원 셋을 겹치듯 나란히 `M.spring(t - ti, 'snappy')` 로 톡톡 놓아요(0.12초 간격).
   - 2박 뒤 원 속을 오려 둔 국기 무늬(기하 도형으로 새로 그린 줄·별 무늬)로 컷 바꾸고, 원 지름을 짧은 변의 35%로 키운 행렬을 `x = M.anim([[t0, 0], [t0 + .7, -gap, {e: 'inOutCubic'}]], t)` 로 한 칸씩 옆으로 굴려요. 가운데 원만 화면에 다 들어오고 양옆은 잘려요.
   - 장면 사이는 `S.tr.push` 로 이어요.
3. **떠 도는 폰과 굴러 맞춰지는 금액**
   - 폰이나 잔액 카드를 가운데 `M.place(card, cx, cy, {s: M.spring(t - t0, 'smooth')})`, 부모에 `perspective`, `rotateY = -10 + 20 * M.prog(t, t0, 5)` 로 천천히 돌려요.
   - 큰 금액은 장면 쌓기 number: odometer, 직접 만들 땐 자리마다 `M.anim` 으로 0~9 띠를 굴려 0.8초에 멈춤. 숲색 판 버전은 테두리만 라임.
4. **마지막 막대만 숲색**
   - 위가 둥근 막대 8~9개를 `M.box(bar, {h: H_i * M.ease.outCubic(M.prog(t, t0 + i * .08, .5))})` 로 왼쪽부터 차올리고, 마지막 막대만 숲색으로 한 박 늦게 올라와요. 그 위에 라임 동그라미와 숲색 화살표가 스프링으로 톡.
   - 같은 판에서 작은 장면으로: 말풍선 하나가 아래에서 2u 올라오거나, 숲색 점 타임라인 선을 `M.draw(path, k)` 로 그으며 고리 점과 글이 차례로 켜져요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 송금·결제·핀테크 앱 런칭, 해외 서비스·여러 나라 지원 소개, 브랜드 미션·비전 영상, 앱 기능 여러 개를 묶어 훑을 때, 고객 지원·상담 기능 소개. 60~90초 긴 브랜드 영상에도 잘 버텨요.
- 피할 것: 종이·그레인 같은 거친 질감, 세리프나 손글씨 글꼴, 검정 바탕과 네온 빛 번짐, 기울이거나 흩어 놓은 글자, 한 화면에 문장 세 줄 이상.
- 한글은 2~5자 낱말 한두 줄일 때 가장 힘 있게 보여요. 문장이 길면 컷을 더 잘게 나눠요.
