# 귀리빛 세리프 답장 (제품 UI)

한 줄: 귀리빛 베이지와 옅은 미색 판을 오가며, 짧은 질문 말풍선이 쳐지면 왼쪽 정렬 세리프 답이 어절마다 옅은 회색에서 먹색으로 차오르는 조용한 대화형 AI 소개예요.

## 보는 느낌
- 화면에 요소가 거의 없어요. 장면마다 말풍선 하나, 세리프 문단 하나, 폰 한 대, 카드 하나 정도만 두고 나머지는 넉넉한 여백으로 남겨요.
- 바탕은 귀리빛 베이지 판과 그보다 밝은 미색 판이 번갈아 나와요. 질문 장면은 베이지, 답이 흐르는 장면은 미색으로 두면 묻고 답하는 리듬이 색으로도 보여요.
- 답 문단은 화면 왼쪽 3분의 1 지점에서 시작하는 왼쪽 정렬. 마무리 약속 문장만 한가운데 한 줄로 둬요.
- UI 는 부드러운 그림자의 둥근 카드와 테두리가 두꺼운 밝은 폰. 카메라가 폰에 다가가거나 그래프 카드 하나를 화면 가득 키워요.

## 색
- 바탕(베이지 #D8D1C7 · 미색 #ECEAE6) 80 · 먹색 글자 #2A2622 15 · 테라코타 #C8664A 3 · 그래프 파랑·라벤더 2.
- 질문 말풍선은 바탕보다 한 단계 짙은 베이지(#C9C1B5 정도)에 먹색 글자.
- 테라코타는 로더, 선그래프, 작은 아이콘 점에만 써요. 버튼이나 꼬리표를 칠할 땐 글자를 아주 짙은 갈색 #150E0A 로.
- 막대그래프는 진한 파랑 #5B6FD6 · 라벤더 #A9B4F0 · 옅은 하늘 세 단. 토글이 켜질 때도 같은 파랑.

## 글자
- 답 문단과 마무리 문장은 세리프 400(고운바탕). 짧은 변의 4~5%, 줄 간격 1.45, 자간 -0.01em. 문단 첫 마디만 700 으로 굵게 해서 강조해요.
- '찾는 중…' 상태 문구는 이탤릭 세리프(Instrument Serif Italic, 한글은 고운바탕), 문단보다 조금 작고 회색.
- 질문 말풍선과 UI 글씨는 산세리프 500(Geist + Noto Sans KR Medium), 작게.
- 큰 제목은 쓰지 않아요. 가장 큰 글자도 짧은 변의 5% 안쪽.

## 질감과 모양
- 질감 없이 매끈하게. 판 사이에 아주 옅은 흰 안개가 번졌다 걷히는 정도만.
- 카드·말풍선 모서리 `--u` × 1.6, 폰은 그보다 훨씬 둥글게. 그림자는 크고 옅은 것 한 겹(아래로 2u, 흐림 6u, 먹색 8%).
- 로더는 작은 점선 고리(지름이 글자 높이만큼). 원본의 고유 기호는 쓰지 않아요.

## 움직임
- 80BPM, 느림. 들어오는 건 `power2.out`, 카메라 이동은 `sine.inOut` 으로 3~4초에 걸쳐.
- 질문은 초당 18자 안팎으로 쳐지고, 답은 어절마다 0.12초 간격으로 옅은 회색에서 먹색으로 0.4초에 차올라요.
- 카드와 시트는 아래에서 3u 올라오며 흐림이 걷혀요. 나갈 땐 따로 움직이지 않고 흐려지며 사라져요.
- 한 장면은 3~5초 머물러요. 문장이 다 차오른 뒤 한 박 반은 그대로 두고 읽을 시간을 줘요.

## 전환
- 페이드가 기본이고, 폰에서 카드로 들어갈 때만 흐림 전환(blur). 장면 쌓기: fade → blur.
- 베이지 판과 미색 판이 바뀔 땐 바탕색만 1초에 걸쳐 서서히 바뀌어요.

## 대표 장면
1. **질문 말풍선 → 차오르는 세리프 답**
   ```
   // 질문: 짙은 베이지 말풍선에 타자
   bubble.textContent = M.type(q, t, 0.3, 18);
   const out = M.prog(t, tQ, .5);
   M.place(bubble, cx, cy, { o: 1 - out, blur: out * 4 });
   // 답: 어절마다 회색에서 먹색으로
   S.words(answer).forEach((w, i) => {
     const k = M.ease.outCubic(M.prog(t, tA + i * .12, .4));
     w.style.color = M.color('rgba(42,38,34,.25)', '#2A2622', k);
   });
   // 아래 점선 고리 로더: 문장이 끝나면 멈춰 사라짐
   loader.style.transform = `rotate(${t * 220}deg)`;
   loader.style.opacity = 1 - M.prog(t, tEnd, .4);
   ```
2. **'찾는 중…' 반짝임**
   - 이탤릭 세리프 한 줄을 회색으로 두고, `background: linear-gradient(90deg, 회색, 흰빛, 회색)` 을 글자에 `background-clip: text` 로 입혀요.
   - `S.ambient(t => line.style.backgroundPosition = `${((t % 1.6) / 1.6) * 200 - 50}% 0`)` 로 1.6초마다 왼쪽에서 오른쪽으로 훑어요. 옆에 테라코타 로더.
3. **폰에 다가가 그래프 카드로**
   - 폰을 화면 가운데 두고 `s = M.anim([[0, 1], [.5, 1.35, { d: 3.5, e: 'inOutSine' }]], t)` 로 천천히 다가가요.
   - 그래프 카드 장면은 `S.tr.blur` 로 이어 붙이고, 막대는 왼쪽부터 0.06초씩 늦게 `scaleY` 0 → 1(`M.spring(t - ti, 'smooth')`), 선그래프는 `M.draw(path, M.prog(t, t0, 1.2))` 로 테라코타 선을 그어요.
   - 계획 장면은 폰 아래에서 둥근 시트가 `y = M.anim([[0, H], [t0, H * .45, { d: .9, e: 'outCubic' }]], t)` 로 올라오고, 위의 답 문단은 같은 동안 40% 투명해져요.
4. **연결 카드 토글과 약속 문장 마무리**
   - 둥근 카드 둘을 비스듬히 엇갈려 띄우고, 토글 손잡이를 `M.anim` 으로 옮기며 배경을 `M.color('#CFC9C0', '#5B6FD6', k)` 로 바꿔요(두 번째는 0.4초 늦게).
   - 마지막은 베이지 판 가운데 세리프 한 줄. 문장 셋을 같은 자리에서 1.2초 페이드로 갈아 끼우고, 각각 2.5초 머물러요.
