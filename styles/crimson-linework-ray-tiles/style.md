# 진홍 선 도형과 모이는 빛살 (그래픽·도형)

한 줄: 진홍 한 색 바탕에 흰 가는 선으로 원과 네모, 안내선이 그어지며 말을 감싸요. 짧은 막대들이 가장자리에서 모여 빛살 기호가 되고, 그 기호가 사진 틀과 둥근 아이콘 타일 위로 번져 가는 브랜드 소개예요.

## 보는 느낌
- 화면 대부분이 진홍 한 색이에요. 그 위에 흰 글자 한 줄과 흰 가는 선 몇 가닥만 올려서 아주 깨끗해요.
- 여는 부분은 문장 하나가 화면 가운데에 조용히 떠 있고, 이어서 원과 네모 같은 기본 도형이 낱말을 감싸며 브랜드의 성격을 설명해요.
- 설계를 보여 주는 장면은 한 톤 어두운 적갈색 판으로 넘어가요. 흰 안내선과 작은 네모 마디가 도면처럼 깔려요.
- 중반에는 연회색 판에 둥근 아이콘 타일이 벤토처럼 짜이고, 후반에는 사진(사람, 풍경)이 들어와요. 사진 위에는 늘 흰색이나 진홍 빛살 기호가 하나 얹혀요.
- 끝은 앞에서 나온 타일, 사진 카드, 큰 숫자가 한 판에 모였다가 진홍 바탕 위 흰 이름 하나로 맺혀요.

## 색
- 진홍 65 · 흰 글자와 선 20 · 적갈색 10 · 연회색 5(타일 판일 때는 연회색이 바탕이 되고 진홍이 글자로 바뀌어요).
- 진홍 #C40A1E 가 주인공. 적갈색 #5C0811 은 설계 장면 바탕과 짙은 타일에, 중간 붉은색 #8E0C18 은 그림자 쪽 면에만 써요.
- 연회색 #E6E5E3 판 위 글자와 아이콘은 진홍 #B30A1C.
- 빨강 계열 밖의 색은 사진 속 색뿐이에요. 하늘색, 살구색 같은 사진의 색이 붉은 판과 맞부딪혀 생기를 내요.

## 글자
- 둥근 기운이 도는 기하 산세리프(Geist, 한글은 Noto Sans KR). 제목은 600~700, 자간 -0.02em.
- 문장 장면은 작게, 짧은 변의 4~5%로 가운데 두 줄. 서체를 소개하는 장면만 화면 왼쪽 위에 아주 크게(짧은 변의 15% 이상) 굵은 이름을 두고 아래에 숫자·글자 견본을 작게 깔아요.
- 타일 안 글자는 소문자 위주로 두 줄, 줄 간격을 좁게(0.95) 잡아 덩어리처럼 보이게 해요.
- 사진 카드 아래 글은 진홍 굵은 글자 두 줄, 카드와 같은 각도로 기울어요.

## 질감과 모양
- 질감은 없어요. 납작한 단색 면과 선으로만 그려요.
- 선은 2px 흰색, 끝은 각지게. 안내선 마디는 선 두께의 4배쯤 되는 작은 속 빈 네모.
- 타일과 사진 카드는 모서리가 둥글어요(`--u` × 2.4). 그림자는 사진 카드에만 아주 옅게 깔아요.
- 빛살 기호는 끝이 뭉툭한 짧고 굵은 막대를 가운데로 모아 만들어요. 우리 브랜드에 맞춰 막대 수와 길이를 새로 정해서 그려요.

## 움직임
- 100BPM, 보통 빠르기. 들어오는 움직임은 `power3.out` 으로 시원하게 들어와 부드럽게 멈춰요.
- 선은 0.6~0.9초에 그어지고, 다 그려진 뒤 마디 네모가 0.1초 간격으로 톡톡 찍혀요.
- 문장은 아래에서 살짝 올라오며 나타나고 2~3초 머물러요. 그동안 화면 아래쪽 짧은 가로 막대가 천천히 늘어나 시간이 흐르는 걸 보여 줘요.
- 빛살 막대는 가장자리에서 0.5초에 모이고 각자 0.04초씩 늦게 도착해요. 모인 뒤 한 박 동안 아주 천천히 돌아요.
- 큰 붉은 띠는 화면 밖에서 0.7초에 쓸고 들어와 비스듬히 멈추고, 사람 사진이 띠 사이에 끼어요.

## 전환
- 컷이 기본이에요. 진홍에서 적갈색, 연회색으로 넘어갈 때는 한 색 면이 옆에서 쓸고 지나가는 와이프(wipe).
- 타일 판, 사진 카드 장면은 밀어내기(push). 장면 쌓기: cut → wipe → push.

## 대표 장면
1. **원과 네모가 두 낱말을 감쌈**: 낱말 둘을 `M.place` 로 좌우에 두고, SVG `circle` 과 `rect`(속 빈 2px 흰 선)를 각 낱말 둘레에 겹치게 둬요.
   ```
   S.ambient(t => {
     M.draw(circlePath, M.ease.outCubic(M.prog(t, M.beat(1), .8)));
     M.draw(rectPath,   M.ease.outCubic(M.prog(t, M.beat(1.5), .8)));
   });
   ```
   장면 쌓기에서는 deco `rings` 가 원 선을 깔아 줘요.
2. **안내선 도면**: 적갈색(accent) 판에 가는 흰 `path` 여러 개를 하나씩 `M.draw` 로 긋고, 꺾이는 자리마다 작은 네모를 `M.place(node, x, y, {s: M.spring(t - ti, 'snappy')})` 로 찍어요. 낱말 옆 곡선 화살표는 마지막에 0.5초. deco `marks` 를 쓰면 눈금과 마디가 같이 깔려요.
3. **아이콘 타일 벤토**: 연회색(paper) 판에 둥근 타일 6~8개를 `M.box(tile, {x, y, w, h})` 로 배치하고, 각 타일이 0.08초씩 늦게 `{s: .92 → 1, o: 0 → 1}` 로 떠요. 짙은 타일은 적갈색 바탕에 흰 아이콘, 옅은 타일은 흰 바탕에 진홍 글자. card `flat`, radius 2.4u.
4. **모이는 빛살과 사진**: 막대 n 개를 각도 `a_i` 로 두고 `r = M.anim([[0, W * .7], [t0 + i * .04, R0, {d: .5, e: 'outCubic'}]], t)` 로 가장자리에서 가운데로 모아요. 모인 기호를 사진 카드 위에 얹고 카드는 `M.spring(t - t1, 'smooth')` 로 -6~+5도 기울며 밀려 들어와요.
   끝에는 막대 하나의 길이를 `M.anim` 으로 화면보다 크게 늘려 붉은 띠로 화면을 가로지르게 하고, 이어서 `S.tr.wipe` 같은 결의 와이프로 다음 판에 넘겨요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 브랜드 리뉴얼 소개, 통신·생활 서비스 브랜드, 디자인 시스템·가이드 공개, 서비스 여러 개를 아이콘으로 훑을 때, 지역·여행 캠페인.
- 피할 것: 여러 색 그라디언트, 손그림 선이나 떨림, 그레인·종이 질감, 강조색을 빨강 계열 밖으로 늘리기, 한 화면에 긴 문장 여러 줄.
- 사진은 밝고 하늘이 많이 보이는 것이 붉은 판과 잘 어울려요.
