# 등각 유리판 시각화 조율 (다이어그램·데이터)

한 줄: 어두운 등각 격자 판 위로 카메라가 미끄러지고, 가운데 유리판 둘레 칸마다 청록 시각화 조각이 하나씩 켜져요. 고정폭 명령어가 빛 블록에 덮이며 쳐지고, 가는 선 리본은 슬라이더를 밀 때마다 색을 갈아입어요.

## 보는 느낌
- 거의 검은 바탕에 가는 흰 선(7% 안팎)으로 그은 등각 격자 판이 깔려 있어요. 판 칸은 살짝 밝은 회색 타일이고, 몇몇 선은 점선이에요.
- 가운데에는 두께가 보이는 유리판 하나. 테두리만 은은하게 빛나고 아래로 흰 빛이 새요. 둘레 칸에 물결선, 점 행렬, 점선 고리, 알약 막대 같은 작은 시각화 조각이 놓여요.
- 판 장면이 끝나면 화면을 비우고 가운데 한 줄만 둬요. 큰 고정폭 명령어, 흐린 코드 몇 줄, 슬라이더 하나와 빛 리본처럼 한 번에 하나씩 보여 줘요.
- 마무리는 가는 선으로 3×3 칸을 나눈 판이에요. 칸마다 앞에서 본 조각이 하나씩 들어 있고, 가운데 칸에 이름이 빛나요.

## 색
- 검정 바탕 70 · 회색 선과 타일 15 · 청록 빛 10 · 흰 글자 5.
- 바탕 #111213, 판 타일 #1B1F22, 글자 #E8ECEC.
- 강조는 청록 #3FE3E0 하나예요. 시각화 조각, 명령어 블록, 코드 낱말에 써요. 블록 위 글자는 거의 검은 #061716.
- 슬라이더 장면에서만 리본 색이 초록 #2FD39A → 하늘 #1FD5F9 → 파랑 #2C4BF2 → 보라 #8B4DFF 로 이어지고, 슬라이더 길도 같은 그라디언트로 칠해요.
- 유리판을 빛이 지나는 순간에는 분홍·노랑·초록 무지개 빛줄기가 잠깐 넓게 번져요. 영상 전체에서 한 번만 써요.

## 글자
- 명령어와 코드, 색 코드, 파라미터 값은 Geist Mono 400~500(한글은 Noto Sans KR Medium)이에요. 명령어는 짧은 변의 9~10%로 아주 크게, 코드는 2.5% 정도로 작게 써요.
- 이름과 제목은 Geist 500, 자간 −0.01em. 크게 쓰지 않고 짧은 변의 6~8%에 흰 빛 번짐(text-shadow) 한 겹을 줘요.
- 정렬은 가운데. 파라미터 꼬리표(이름 + 값)만 화면 오른쪽 아래 구석에 작게 붙여요.

## 질감과 모양
- 그레인 0.05와 비네트 0.35를 깔아 가장자리를 어둡게 눌러요. 빛이 있는 곳만 떠 보여요.
- 유리판은 흰색 6~10% 반투명에 블러를 주고, 1px 흰 테두리(35%)를 둘러요. 아랫면에 두께 2u 정도의 옆면을 보이게 해요.
- 시각화 조각은 청록 선이나 점에 `drop-shadow(0 0 1u var(--glow))` 를 한 겹 줘요.
- 모서리는 1.2u, 패널 카드는 테두리만 있고 그림자는 없어요.

## 움직임
- 100BPM에 보통 빠르기예요. 카메라 이동은 `power3.inOut` 으로 길게, 조각이 켜지는 건 반 박 안에 끝나요.
- 판 장면에서는 카메라가 4~6초 동안 대각선으로 짧은 변의 10%쯤 흘러요. 조각은 한 박 간격으로 켜지고, 켜진 뒤에는 계속 숨 쉬듯 움직여요(물결이 흐르고, 고리가 돌고, 막대가 오르내림).
- 타이핑은 초당 12~14자예요. 청록 블록은 커서보다 0.2초 늦게 따라와요.
- 리본은 3~4초에 걸쳐 천천히 휘어 들어오고, 슬라이더 손잡이는 반 박에 탁 옮겨진 뒤 리본 색이 0.6초 동안 번져 바뀌어요.

## 전환
- 판 → 유리판 속으로는 확대하며 흐려지는 전환(blur)을 써요. 화면이 청록으로 차오른 뒤 걷혀요.
- 텍스트 장면끼리는 컷, 마지막 판과 끝 화면은 느린 페이드로 이어요. 장면 쌓기 순서는 blur → cut → fade.

## 대표 장면
1. **등각 판 위 조각 켜기**
   ```js
   // 판 전체를 등각으로 눕히고 카메라처럼 천천히 흘림
   board.style.transform = 'rotateX(60deg) rotateZ(45deg)';
   S.ambient(t => {
     M.place(board, cx - t * W * .015, cy + t * H * .01);
     tiles.forEach((tile, i) => {                       // 한 박 간격으로 켜짐
       const k = M.ease.outCubic(M.prog(t, 1 + M.beat(i), M.beat(.5)));
       tile.style.opacity = k;
     });
     M.draw(wavePath, 1); wavePath.style.strokeDashoffset = -t * 40;   // 물결 흐름
     ring.style.transform = `rotate(${t * 60}deg)`;                    // 점선 고리 회전
   });
   ```
   유리판 아래 빛은 `radial-gradient` 하나를 `M.place(glow, cx, cy, {s: 1 + Math.sin(t * 1.6) * .05})` 로 숨 쉬게 해요. 마지막에는 `S.tr.blur` 로 판 속으로 파고들어요.
2. **빛 블록이 따라오는 명령어**
   ```js
   const txt = M.type(cmd, t, .3, 13);
   line.textContent = txt;
   const w = measure(txt.slice(0, Math.max(0, txt.length - 3)));   // 커서보다 몇 글자 뒤
   M.box(block, {x: x0, y: y0, w, h: lineH});                     // 청록 칠, 글자는 accentInk
   M.place(line, cx - Math.max(0, totalW(txt) - W * .7), cy);      // 길어지면 왼쪽으로 밀림
   ```
   장면 쌓기에서는 title: type 과 marker: highlight 로 같은 결을 내요.
3. **슬라이더로 색 바꾸는 빛 리본**
   ```js
   S.ambient(t => {
     const v = M.at([[0, .1], [M.beat(4), .5], [M.beat(8), .8]], t);
     knob.style.left = M.anim([[0, 0], [M.beat(4), v, {d: M.beat(.5), e: 'outCubic'}]], t) * trackW + 'px';
     const c = M.color('#2FD39A', '#8B4DFF', v);
     strands.forEach((p, i) => {                                   // 가는 선 30~40가닥
       p.setAttribute('d', ribbon(t * .3 + i * .02));
       p.style.stroke = c;
     });
     hex.textContent = v === lastV ? toHex(c) : scramble(toHex(c), t);   // 값이 바뀌면 글자가 맞춰짐
   });
   ```
4. **선으로 나눈 조각 판 엔딩**
   - 가는 선 4개를 `M.draw` 로 0.6초에 그어 3×3 칸을 만들고, 칸마다 앞 장면의 조각(리본 끝, 점 행렬, 물결선, 알약 막대, 코드 창)을 반 박 간격으로 페이드 인해요. 가운데 칸 이름은 흐림 4px에서 0으로 맺혀요. 이어 화면을 비우고 주소 한 줄만 남겨 페이드로 끝내요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 개발자 도구·라이브러리 소개, UI 컴포넌트 묶음 런칭, 음성·실시간 기술 시각화, 설치 명령어 안내, 파라미터를 조절하는 기능 시연.
- 피할 것: 밝은 바탕, 손그림 선과 종이 질감, 굵고 큰 제목을 꽉 채우기, 청록 말고 다른 강조색을 동시에 여러 개 쓰기(리본 색 바뀜만 예외), 빠른 컷 몽타주.
- 빛 번짐은 청록 조각과 이름에만 줘요. 바탕 격자와 타일은 늘 차분하게 둬요.
