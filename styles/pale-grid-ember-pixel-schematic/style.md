# 격자 위 주황 픽셀 도식 (그래픽·도형)

한 줄: 옅은 회색 격자 위에서 주황·숯빛·연회색 정사각형 블록이 칸을 옮겨 다니며 도식을 짜요. 블록은 데이터 카드, 철사 입체, 3×3 픽셀 판으로 이어지고, 끝에는 계단진 주황 픽셀 쐐기가 퍼져 나가요.

## 보는 느낌
- 바탕은 아주 옅은 회색 한 장이에요. 화면을 큰 칸으로 나누는 가는 격자 선(먹색 6~8%)이 깔리고, 가운데로 십자 안내선이 희미하게 지나가요. 교차점마다 작은 + 표시가 놓여요.
- 주인공은 반듯한 정사각형 블록이에요. 주황 하나, 숯빛 하나, 연회색 몇 개가 격자 칸에 맞춰 놓이고, 장면이 바뀌어도 블록이 살아남아 다음 그림의 재료가 돼요.
- 블록 사이사이로 데이터 화면이 끼어들어요. 원근으로 쌓인 짙은 카드 더미, 흰 상품 카드, 꺾은 선으로 이어진 가격 꼬리표 노드, 주황 키가 섞인 코드 카드, 비스듬히 누운 웹 시안 뼈대 같은 것들이요.
- 가는 선으로만 그린 입체도 자주 나와요. 철사 지구본, 볼록하게 휜 격자 판, 주황 외곽선 와이어프레임 같은 것에 면 몇 장만 주황·숯빛으로 칠해요.
- 여백이 넉넉해요. 한 화면에 덩어리 하나, 많아야 셋이에요.

## 색
- 옅은 회색 70 · 숯빛·연회색 블록과 글자 20 · 주황 10.
- 바탕 #EEEEEC, 카드 흰빛 #FAFAF9, 글자 #262626, 짙은 카드·블록 #3C3C3C, 연회색 블록 #B5B5B3.
- 주황 #E8521D 는 블록 하나, 버튼 하나, 큰 숫자처럼 한 화면에 한 군데만 써요. 3×3 판과 픽셀 쐐기에서는 주황을 100·60·30% 농도로 나눠요.
- 주황 위 글자는 거의 검정 #141414 로 써요.

## 글자
- Geist(한글은 Noto Sans KR). 제목 600, 자간 −0.02em, 가운데 정렬. 문장은 짧게 한두 줄로 끝내요.
- 꼬리표와 코드는 Geist Mono. 꼬리표는 대문자로 짧은 변의 2% 크기, 얇은 알약 테두리 안에 넣어요. 코드는 키만 주황, 값은 먹색.
- 큰 숫자는 Geist 700 을 짧은 변의 25% 크기로, 주황 바탕에 망점을 얹어요. 아래에 작은 알약 버튼 하나와 주황 점 한 줄.

## 질감과 모양
- 화면 전체에 까는 질감은 없어요. 매끈한 평면이에요.
- 망점은 부분에만 써요. 큰 숫자 안, 두 블록 사이 마름모 모양, 와이어프레임 귀퉁이에 크기가 다른 주황 점이 번지듯 깔려요.
- 블록은 모서리가 거의 직각이에요. 카드·버튼은 1.2u 둥근 모서리에 아주 옅은 그림자 하나. 선은 모두 1px.
- 블록이 잠깐 정육면체로 서서 옆면을 보여 줄 때가 있어요(주황 큐브 둘레로 숯빛·연회색 픽셀 조각이 흩어짐).

## 움직임
- 100BPM, 보통 속도. 장면 하나에 4~5박(2.4~3초) 머물러요.
- 블록은 power3.inOut 으로 칸에서 칸으로 미끄러져 딱 멈춰요. 튕기거나 흔들리지 않아요.
- 카드는 아래에서 한 장씩 0.15초 간격으로 올라와 뒤로 갈수록 작아지며 쌓여요.
- 노드 선은 블록에서 블록으로 0.5초에 그어지고, 끝에 가격 꼬리표가 톡 뜨며 숫자가 굴러가요.
- 픽셀 판과 쐐기는 칸마다 0.05초 차이로 켜져요.
- 큰 숫자는 굴러 올라가고, 망점이 숫자 안에서 함께 차올라요.

## 전환
- 블록 전환이 기본이에요. 화면이 숯빛·연회색 정사각형 조각으로 덮였다가 걷히며 다음 장면이 나와요.
- 장면과 장면 사이를 블록 하나가 이어 주기도 해요. 작은 주황 점이 커져 다음 장면의 블록이 되는 식이에요.
- 그 밖에는 밀어내기와 컷. 장면 쌓기: blocks → push → cut.

## 대표 장면

1. **블록 사다리 오프닝**
   ```
   const blocks = S.$$('.blk');            // 주황 1 · 연회색 5 · 숯빛 1, 격자 한 칸 크기
   const c = Math.min(W, H) * .07;
   S.ambient(t => {
     const k = M.ease.inOutCubic(M.prog(t, M.beat(3), .7));   // 대각선 → 세로 한 줄
     blocks.forEach((b, i) => {
       const o = M.prog(t, .2 + i * .08, .3);
       M.place(b, cx + (i - 3) * c * .6 * (1 - k), cy + (i - 3) * c * .6, {o});
     });
   });
   // 십자 안내선(SVG line 2개)은 M.draw 로 먼저 0.6초에 긋고, 주황 점 2개를 위·아래 블록 모서리에 붙여요
   ```
2. **짙은 카드 더미와 노드**
   - 짙은 카드(#3C3C3C, 흰 제목, 작은 회색 칩) 4~5장을 `M.place(card, cx, cy - i * c * .9, {s: 1 - i * .06, o: k})`, `k = M.spring(t - i * .15, 'smooth')` 로 아래에서 올려 쌓아요. 부모에 `perspective` 를 주고 `rotateX(8deg)`.
   - 다음 장면에서는 같은 주황 블록 두세 개를 격자 칸에 놓고 꺾은 SVG path 를 `M.draw(path, M.ease.outCubic(M.prog(t, t0, .5)))` 로 이어요. 선 끝마다 흰 알약 꼬리표(Geist Mono)가 뜨고, 숫자는 `M.at` 으로 두세 번 바뀌다 멈춰요.
3. **3×3 픽셀 판 → 점 하나**
   ```
   const cells = S.$$('.px');               // 9칸, 처음엔 연회색
   const lv = [.3, .6, .3, .6, 1, .6, .3, .6, .3];   // 십자 무늬 농도
   S.ambient(t => {
     cells.forEach((el, i) => {
       const k = M.prog(t, M.beat(1) + i * .05, .2);
       el.style.background = M.color('#B5B5B3', `rgba(232,82,29,${lv[i]})`, k);
     });
     const s = 1 - M.ease.inOutCubic(M.prog(t, M.beat(4), .6)) * .92;   // 판 전체가 작은 점으로
     M.place(S.$('.pxgrid'), cx, cy, {s});
   });
   ```
   - 점이 된 판은 `S.tr.blocks` 로 넘어간 다음 장면에서 다시 주황 블록 하나로 커져요.
4. **철사 지구본과 픽셀 쐐기 마무리**
   - 지구본: SVG `ellipse` 경선 6개의 `rx` 를 `R * Math.cos(t * .4 + i * Math.PI / 6)` 로 돌리고, 면 두 장(주황·숯빛 path)만 칠해요. 둘레에 Geist Mono 대문자 알약 꼬리표 하나와 작은 숯빛 점 두 개가 천천히 떠돌아요.
   - 쐐기: 오른쪽 원 중심에서 열 j 마다 정사각형 `2j + 1` 개를 세로로 쌓아요. `M.place(sq, x0 + j * c, cy + (r - j) * c, {o: M.prog(t, t0 + j * .05, .1)})`. 바깥 열일수록 주황 농도를 100 → 60%로 낮추면 계단진 부채가 화면 끝까지 퍼져요.
