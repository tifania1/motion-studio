# 무지개 기호 컷 릴 (그래픽·도형)

한 줄: 검은 바탕에 무지개 그라디언트로 칠한 굵은 기호들이 1초마다 컷으로 바뀌며 흰 글자 사이로 끼어들고, 끝에는 기호들이 한 줄로 모였다가 단색 마크로 접히는 행사 티저.

## 보는 느낌
- 거의 검은 바탕에 흰 산세리프 글자, 그리고 무지개 그라디언트로 칠한 굵은 기호(핀, 화살표 커서, 구름, 지구본, 돋보기, 마이크, 중괄호, 네 꼭지 별) 몇 개가 주인공이에요.
- 기호는 평면 아이콘처럼 놓이다가도 두께 있는 3D 덩어리, 유리, 반짝이 가루, 장난감 더미, 사진 속 사물로 모습을 바꿔요. 같은 기호를 다른 재질로 다시 보여 주는 게 이 결의 재미예요.
- 오프닝은 기호를 화면보다 크게 잘라 서로 겹쳐 놓고, 겹친 부분은 색이 더 밝게 섞여요.
- 장면 사이사이 한두 번 흰 바탕으로 뒤집어(검은 글자 + 무지개 기호) 리듬을 끊어요.
- 끝은 다시 검정, 가운데 흰 단색 마크와 아주 작은 날짜 한 줄. 여백이 넓어요.

## 색
- 검정 #111111 65 · 흰 글자 20 · 무지개 기호 15.
- 무지개는 파랑 #4C7CF5 → 초록 #2FB463 → 노랑 #F7B500 → 빨강 #E8473F 를 한 기호 안에서 대각선이나 원뿔 그라디언트로 이어 칠해요. 보라·분홍이 사이에 살짝 끼어도 좋아요.
- 흰 바탕 장면은 #F2F2F0 에 글자 #111111.
- 강조(accent)는 노랑 #F7B500, 글자는 검정. 버튼·숫자 꼬리표에만 아주 조금.

## 글자
- 둥글고 반듯한 그로테스크(Geist + Noto Sans KR Medium), 굵기 500 안팎. 자간 −0.02em.
- 문장은 2~4어절, 짧은 변의 10~14%로 크게. 낱말을 네 귀퉁이에 흩어 놓기도 하고(위 왼쪽·위 오른쪽·아래 왼쪽·아래 오른쪽) 가운데 기호를 둘러싸게 해요.
- 글자 벽 장면은 같은 문구를 화면 너비 꽉 차게 네 줄, 줄 간격 0.95.
- 엔딩 날짜는 짧은 변의 3% 안팎, 아주 작게.

## 질감과 모양
- 질감 없이 매끈하게. 그레인·비네트를 쓰지 않아요.
- 기호 선 두께는 짧은 변의 4~6%로 아주 굵고 끝이 둥글어요. 모서리 2u.
- 3D 기호는 앞면 그라디언트 + 옆면은 같은 색을 30% 어둡게, 부드러운 반사 하나. 유리 버전은 안에서 빛이 번지게(glow 색).

## 움직임
- 120BPM, 빠름. 대부분 한 장면이 2박(1초), 기호 판 컷은 반 박도 써요.
- 기호는 `expo.out` 으로 0.4초에 1.3배에서 1배로 확 들어와 멈추고, 머무는 동안 아주 천천히(초당 3~5도) 돌아요.
- 글자는 줄마다 선 아래에서 올라오고(mask), 나갈 때는 컷.
- 엔딩 모임은 0.6초 `inOutCubic`, 접히는 마크는 3D 로 반 바퀴 돌며 평면으로 눕혀요.

## 전환
- 컷이 기본. 흰 바탕으로 뒤집는 순간도 컷.
- 기호가 화면을 가득 채우며 지나가는 순간엔 휙 밀기(whip), 마지막 마크 등장은 원형 열림(iris).
- 장면 쌓기: cut → cut → whip → iris.

## 대표 장면
1. **글자 사이로 끼어드는 기호**
   ```
   // 문장을 두 층으로 복제: 뒤층(전체) · 앞층(일부 글자만 보이게 clip)
   const k = M.ease.outExpo(M.prog(t, t0, .4));
   M.place(glyph, cx, cy, {s: 1.3 - .3 * k, r: -8 + t * 4, o: k});
   front.style.clipPath = 'inset(0 0 0 55%)';   // 오른쪽 글자는 기호 앞에 남김
   ```
   기호는 SVG path 에 `linearGradient` 4색, 옆면은 같은 path 를 2u 아래로 복제해 어둡게.
2. **네 줄 글자 벽**
   - 같은 문구 네 줄을 `S.ambient(t => M.place(wall, cx, cy - t * H * .04))` 로 위로 흘리고, 큰 마이크·알약 기호를 가운데에 띄워요. 맨 아래 줄만 `background-clip: text` 로 그라디언트를 입혀요.
3. **기호 3×3 판과 재질 바꾸기**
   - 기호 9개를 격자로 두고 `M.at([[t0, 0], [t0 + M.beat(.5), 1], …], t)` 로 반 박마다 하나씩 화면 꽉 채우게 확대 컷. 다음 박엔 같은 기호를 유리(`backdrop-filter` + glow)나 사진 소품으로 바꿔 흰 바탕 장면에.
4. **한 줄로 모여 마크로 접힘**
   ```
   glyphs.forEach((g, i) => {
     const k = M.ease.inOutCubic(M.prog(t, tM + i * .03, .6));
     M.place(g, M.mix(g.x0, rowX(i), k), M.mix(g.y0, cy, k), {s: M.mix(1, .25, k)});
   });
   // 다음 박: 막대·사선·원 세 조각만 남기고 rotateY 180→0, 그다음 컷으로 흰 단색 + 날짜
   ```
   장면 쌓기에서는 deco shapes 로 원·네모·세모를 흩고 마지막 장면에 S.tr.iris.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 행사·컨퍼런스 티저, 개발자 행사 예고, 기능 여러 개를 기호로 훑는 런칭, 날짜 공지가 있는 카운트다운.
- 피할 것: 손그림 선, 종이·그레인 질감, 느린 서서히 전환, 단색 기호(무지개가 빠지면 결이 사라져요), 한 화면에 긴 문장.
- 원본의 마크·캐릭터 모양은 쓰지 않아요. 우리 브랜드 기호를 세 조각 도형으로 단순하게 만들어 접히게 해요.
