# 현장 자막과 픽셀 노드판 (다이어그램·데이터)

한 줄: 작업 현장 실사 위에 흰 고딕 자막이 어절마다 흐림에서 맺히며 한 문장을 여러 컷에 걸쳐 이어 가고, 화면이 픽셀 조각으로 부서지면 숯빛 격자판에서 원색 픽셀 막대와 픽셀 아이콘이 가는 직각 선으로 이어져요.

## 보는 느낌
- 영상이 두 막으로 나뉘어요. 앞 막은 사람이 일하는 현장 실사(작업실, 공장, 연구실, 들판 드론 샷)가 화면을 가득 채우고, 가운데에 흰 자막 한 줄만 떠요.
- 자막 한 문장이 컷 서너 개를 건너며 이어져요. 그림이 바뀌어도 글은 제자리에 있어서 문장이 영상의 등뼈가 돼요.
- 뒤 막은 숯빛 바탕에 아주 옅은 격자선과 큰 칸을 나누는 가는 선이 깔린 판이에요. 그 위의 요소는 작고 드문드문 놓여서 여백이 넓어요.
- 격자판의 주인공은 픽셀이에요. 줄마다 미끄러지는 원색 막대, 칸칸이 채워지는 아이콘, 세로로 늘어선 주황 점 기둥, 계단처럼 쌓이는 막대가 모두 네모 칸 단위로 움직여요.
- 두 막 사이에는 실사가 큰 네모 픽셀로 부서지는 모자이크가 한 번 끼어들어요. 사람의 일이 데이터로 바뀌는 순간처럼 보여요.

## 색
- 격자판: 숯빛 #262626 80 · 흰 글자와 선 12 · 주황 계열 8.
- 글자와 점은 따뜻한 흰색 #ECE8E1. 격자선은 같은 흰색 8%, 큰 칸을 나누는 선은 15%.
- 강조는 주황 #F0641E. 화살표, 노드 네모, 아이콘 몸통에 써요. 주황 위 글자는 거의 검정 #1A1A1A.
- 픽셀 조각에만 노랑 #F7B52C, 빨강 #E2401C, 분홍 #E58FD0 을 더해요. 셋 다 막대·아이콘 칸 안에서만.
- 실사 장면은 색을 따로 입히지 않아요. 자막은 흰색 하나, 그림자나 띠 없이 그대로 얹어요.

## 글자
- 자막과 격자판 문장 모두 담백한 산세리프 400(Geist + Noto Sans KR Medium). 굵게 쓰지 않아요.
- 자막 크기는 화면 높이의 4~5%, 가운데 한 줄. 자간 −0.01em.
- 노드 꼬리표와 이름표는 고정폭(Geist Mono, 한글은 Galmuri11), 화면 높이의 1.6% 안팎으로 아주 작게, 연한 흰색.
- 로고처럼 크게 쓰는 순간도 같은 400 굵기로, 크기만 화면 높이의 9~10%로 키워요.

## 질감과 모양
- 실사 장면에는 아주 옅은 그레인(0.04)과 비네트(0.15). 격자판은 매끈하게 둬요.
- 선은 모두 1px 머리카락 굵기. 연결선은 직각으로 꺾이고 꺾인 자리만 살짝 둥글어요.
- 상자 모서리는 거의 각진 0.4u. 아이콘 상자는 안에 촘촘한 점 격자를 깔고, 네 귀퉁이와 변 가운데에 작은 흰 네모 점을 달아요.
- 그림자·빛 번짐은 쓰지 않아요. 주황 빛줄기 장면 하나만 예외로 glow 를 써요.

## 움직임
- 90BPM, 차분하게. 자막 어절은 1~1.5박마다 하나, 흐림에서 0.6초에 선명해져요(power2.out).
- 픽셀 막대는 줄마다 엇갈려 옆으로 미끄러지다 칸에 딱 맞게 멈춰요. 멈출 때 튀지 않아요.
- 픽셀 아이콘은 칸 하나에 한 프레임쯤, 무작위 순서로 켜져 0.6초 안에 다 차요.
- 연결선은 상자에서 노드 쪽으로 0.5초에 그어지고, 닿는 순간 노드 네모가 톡 켜져요.
- 문장 속 주황 픽셀 화살표 뒤 낱말은 옆에서 흘러 들어와 앞 문장을 왼쪽으로 밀어내요.

## 전환
- 실사끼리는 컷. 자막은 컷을 넘어 그대로 남아요.
- 실사에서 격자판으로 갈 땐 픽셀 모자이크(blocks). 격자판 안에서는 컷이 기본이고, 마지막 마크로 갈 때만 짧은 페이드.
- 장면 쌓기: cut → blocks → cut → fade.

## 대표 장면

1. 컷을 건너는 자막
   ```
   // 실사 영상 여러 개를 컷으로 바꾸고, 자막 한 줄은 맨 위 층에 고정
   const words = S.$$('.cap span');               // 어절마다 span
   S.ambient(t => words.forEach((w, i) => {
     const t0 = i * M.beat(1.5);
     const pre = M.prog(t, t0 - .4, .4);         // 먼저 옅게 비치고
     const k = M.ease.outCubic(M.prog(t, t0, .6)); // 선명하게 맺힘
     M.place(w, 0, 0, {o: pre * .3 + k * .7, blur: (1 - k) * 6});
   }));
   // 장면 쌓기라면 title: 'blur' 가 같은 결이에요
   ```
2. 픽셀 모자이크 전환과 피아노 롤 막대
   ```
   S.tr.blocks(prev, next, {d: .5});             // 실사가 큰 네모로 부서지며 격자판으로
   // 격자 줄마다 원색 막대(칸 단위 너비)를 엇갈려 미끄러뜨림
   bars.forEach((b, i) => {
     const x = M.anim([[0, b.x0 + W * .3], [i * .06, b.x0, {d: .9, e: 'outCubic'}]], t);
     M.box(b.el, {x: Math.round(x / cell) * cell, y: b.row * cell, w: b.len * cell, h: cell});
   });
   ```
3. 점 격자 상자 속 픽셀 아이콘과 직각 연결선
   ```
   const order = M.rng(7).shuffle(cells);        // 아이콘 칸을 무작위 순서로
   order.forEach((c, k) => c.style.opacity = t > t0 + k * .02 ? 1 : 0);
   wires.forEach((p, i) => M.draw(p, M.ease.outCubic(M.prog(t, t0 + .7 + i * .15, .5))));
   nodes.forEach((n, i) => M.place(n, n.x, n.y, {s: M.spring(t - (t0 + 1.2 + i * .15), 'snappy')}));
   // 장면 쌓기: deco handles 가 귀퉁이 흰 점, marks 가 눈금을 깔아요
   ```
4. 쌓이는 주황 막대와 픽셀 마크 엔딩
   - 주황·빨강·노랑 가로 막대 5~6개를 아래에서 한 줄씩 `M.box` 로 왼쪽부터 늘려 계단처럼 쌓고, 맨 위 한 줄만 더 길게 뻗어요.
   - 컷으로 빈 숯빛 판, 가운데 흰 픽셀 마크가 칸칸이 켜지며 끝나요. 마지막만 `S.tr.fade` 로 조용히.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 모델·학습 플랫폼 런칭, 제조·건설·연구 현장 이야기, 기업용 도구 브랜드 필름, 데이터가 모델이 되는 과정 설명, 선언문처럼 한 문장을 길게 끌고 가는 영상.
- 피할 것: 밝은 바탕, 손그림 선, 굵고 큰 제목, 부드러운 그라디언트 바탕, 한 화면에 자막 여러 줄, 강조색 여러 개를 한꺼번에 쓰기(주황 하나를 중심으로 두고 노랑·분홍·빨강은 픽셀 조각에만).
- 실사가 없으면 앞 막을 어두운 사진 한두 장으로 줄이고 격자판 장면을 늘려도 결이 살아요.
