# 올리브 안개 유리 세리프 (그라디언트·빛)

한 줄: 어둑한 올리브 안개 속에서 빛이 번진 흰 이탤릭 세리프가 일렁이며 맺혀요. 젖빛 유리 카드와 가는 빛 테두리 도형이 그 둘레를 떠다니고, 연두 버튼 하나가 다음 장면을 여는 차분한 AI 캠페인 UI예요.

## 보는 느낌
- 바탕은 거의 검은 올리브색이에요. 그 위로 연두·노랑 빛 덩어리가 아주 흐릿하게 번져 있고, 가장자리는 비네트로 어둡게 가라앉아요. 초점이 나간 숲 사진처럼 보이는 안개예요.
- 한 장면에는 주인공 하나만 둬요. 흰 이탤릭 세리프 한 줄이거나, 젖빛 유리 카드 한 장이거나, 유리 카드 한 줄이에요.
- 유리 카드 둘레에는 가는 빛 선으로 그린 오각형·육각형·둥근 사각형·원이 서너 개 떠 있어요. 속은 비어 있고 테두리만 연두빛으로 은은하게 빛나요.
- 중간에 한두 번 안개가 밝아져요. 옅은 하늘·연두 안개 위에서는 글자가 짙은 먹색 세리프로 바뀌어요.
- 제품 사진을 보여 줄 때만 단색 초록 판이나 옅은 하늘 판으로 넘어가요. 그 위에서도 유리 말풍선은 똑같은 젖빛이에요.
- 끝은 다시 어두운 올리브 판이에요. 작은 산세리프 이름 하나와 알약 테두리 꼬리표로 조용히 닫아요.

## 색
- 어두운 올리브 바탕 60 · 안개 빛 덩어리 25 · 흰 글자와 유리 10 · 연두 강조 5.
- 바탕 #1E2019. 안개는 올리브 #6B7638, 연두 #C9D96A, 빛 가운데는 미색 #ECF0D6 으로 번져요.
- 유리 카드는 흰색 10~16% 에 블러를 주고 테두리 1px 를 미색 30% 로 둬요. 어두운 입력창은 #1E2019 85% 예요.
- 강조색 연두 #D6E68C 는 버튼과 빛 테두리에만 써요. 버튼 글자는 짙은 #1A1D12 예요.
- 제품 판에는 짙은 초록 #2E6A46 이나 옅은 하늘 #A8D2DA 를 화면 가득 칠해요.

## 글자
- 큰 글은 Instrument Serif 이탤릭이고, 한글은 고운바탕 400 이에요. 굵기 400 그대로, 자간 −0.01em. 크기는 짧은 변의 8~12% 정도로 아담하게 둬요.
- 흰 글자에는 늘 은은한 빛 번짐을 둘러요(text-shadow 0 0 1.2u, 미색 50%).
- 두 줄 문장은 첫 줄을 왼쪽에, 둘째 줄을 오른쪽으로 비켜서 계단처럼 놓아요.
- UI 안 글씨와 끝 이름은 Geist(한글은 Noto Sans KR Medium)로 작게 써요. 세리프와 산세리프가 한 화면에서 섞이지 않게 해요.

## 질감과 모양
- 그레인 0.05, 비네트 0.38. 안개가 살짝 거칠어 보이고 가장자리는 어두워요.
- 유리 카드 모서리는 `--u` × 2.2 로 둥글어요. 그림자 대신 테두리 안쪽에 미색 빛을 한 겹 넣어요.
- 빛 테두리 도형은 1.5px 연두 선에 2u 짜리 바깥 빛을 둘러요.
- 폰이나 카드가 들어올 때는 3D 로 살짝 비스듬히 눕혀요(rotateY 15~25°).

## 움직임
- 84BPM, 느림. 들어올 때는 `power3.out` 으로 부드럽게 멈추고, 머무는 동안에는 아주 천천히 떠다녀요.
- 글자는 흐림과 세로 늘어짐에서 제자리로 0.6~0.8초에 가라앉아요. 글자마다 0.04초씩 늦게 오고, 위아래 방향이 번갈아 출렁여요.
- 장면 하나가 2.5~4초쯤 머물러요. 안개 덩어리는 늘 6~10초 주기로 천천히 흘러요.
- 유리 카드는 흐린 덩어리로 먼저 나타나 0.8초에 또렷해지고, 둘레 도형은 각자 다른 속도로 회전하며 떠다녀요.

## 전환
- 흐림 전환(blur)이 기본이에요. 앞 장면이 흐려지며 녹아들고, 그 흐림 속에서 다음 장면이 맺혀요.
- 차분한 페이드도 섞고, 단색 제품 판으로 넘어갈 때만 원형 열림(iris)을 써요. 장면 쌓기 순서는 blur → fade → iris 예요.

## 대표 장면
1. **안개 위 빛 세리프**: 큰 원 4~5개를 `blur(10u)` 로 흐리게 하고 `M.drift` 로 천천히 흘려 안개를 만들어요. 그 위에 이탤릭 세리프 한 줄을 놓아요.
   ```
   const chars = S.chars(S.$('.line'));          // Instrument Serif 이탤릭, 흰색 + 빛 번짐
   S.ambient(t => chars.forEach((c, i) => {
     const k = M.ease.outCubic(M.prog(t, .3 + i * .04, .7));
     const dir = i % 2 ? -1 : 1;
     M.place(c, 0, dir * (1 - k) * 1.5 * u, { o: k, blur: (1 - k) * 6, sy: 1 + (1 - k) * .6 });
   }));
   ```
   장면 쌓기에서는 title: blur 와 bg: aurora 로 같은 결이 나와요.
2. **글이 녹아 유리 입력창으로**: 문장 글자들을 위 식을 거꾸로 돌려 세로로 번지며 흐리게 해요. 같은 시각에 그 자리에서 어두운 입력창을 맺어요.
   `k = M.spring(t - t0, 'smooth')`, `M.place(pill, cx, cy, { o: k, blur: (1 - k) * 10, s: .96 + k * .04 })`. 안의 글은 `M.type(text, t, t0 + .4, 20)` 로 쳐요. 끝의 연두 알약 버튼은 한 박 늦게 `o` 0 → 1 로 켜요.
3. **빛 테두리 카드 줄**: 카드 4장을 뒤로 갈수록 0.85배씩 작게 줄 세워요. 카드마다 SVG 둥근 사각 `path` 를 `M.draw(path, M.prog(t, t0 + i * .3, .6))` 로 그어 연두빛 테두리를 먼저 만들어요. 그다음 유리 채움을 `o` 0 → 1 로 하나씩 채우고, 채워진 카드 안에 사진과 캡션을 흐림에서 맺어요.
   둘레 도형은 `Studio.M` 으로 오각형·육각형 path 를 만들고 `M.drift` 와 느린 회전(10초에 30°)을 걸어요. deco shapes 를 쓰면 장면 쌓기에서도 깔려요.
4. **단색 판 위 프롬프트와 하늘빛**: `S.tr.iris` 로 짙은 초록 판을 열고 가운데에 제품 사진을 둬요. 흐린 유리 알약이 먼저 나타났다가 넓어지며 또렷한 말풍선이 되고, 문장이 쳐지면 연두 버튼을 눌러요.
   누르는 순간 `S.tr.blur` 로 옅은 하늘 판으로 넘어가고, 제품은 비스듬히 떠올라 천천히 돌아요. 이어서 어두운 안개로 돌아와 산세리프 이름과 알약 테두리 꼬리표로 닫아요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 생성·자동화 도구 소개, 마케팅·캠페인 제작 도구, 브랜드 키트·디자인 도우미, 차분한 기능 런칭, 실험적 서비스 공개.
- 피할 것: 굵은 고딕 큰 제목, 빠른 컷 연타, 손그림 선과 떨림, 강조색 여러 개(연두 하나만), 쨍한 원색 바탕을 오래 두기.
- 한글 세리프는 이탤릭이 없으니, 고운바탕을 작게 쓰고 빛 번짐과 세로 일렁임으로 결을 맞춰요.
