# 소품 한 컷과 비눗방울 (3D·사물)

한 줄: 작은 목록 카드의 아이콘이 커다란 3D 소품으로 커지고, 아래엔 한 줄 설명. 소품을 하나씩 바꿔 보여 주다 마지막엔 비눗방울이 떠올라 로고로 맺혀요.

## 보는 느낌
- 밝은 회색 바탕 가운데 소품 하나, 그 아래 설명 한 줄. 정말 그것뿐이라 소품이 장난감처럼 또렷해 보여요.
- 소품은 말랑하고 부드러운 3D 렌더(점토·펠트 느낌, 부드러운 그림자). 서비스 하나 = 소품 하나.
- 마지막 비눗방울 장면이 전체를 가볍고 깨끗하게 마무리해요(세탁·청소·생활 서비스와 특히 잘 맞아요).

## 색
- 바탕 80 · 소품 15 · 글자 5.
- 바탕 #E6E6E6, 글자 #1E1E1E. 소품은 자기 색 그대로(나무·종이·패브릭 색).
- 강조는 거의 쓰지 않아요. 방울의 무지갯빛 테두리(연파랑 #9FC3F0 → 연분홍 → 연노랑)가 유일한 색 놀이.
- style.json 의 accent(#4A5BC8)는 버튼·로고 자리에만.

## 글자
- 반듯한 고딕 Medium~Bold(Geist + Noto Sans KR). 둥근 기하 고딕이 있으면 더 잘 어울려요.
- 설명은 짧은 변의 3.6%, 한 줄, 가운데. "음식 배달 받기"처럼 동사로 끝나는 8~12자.
- 목록 카드 속 글은 작게(제목 2.2% Bold, 설명 1.8% 회색).

## 질감과 모양
- 화면 질감 없음. 질감은 소품 렌더 안에만.
- 목록 카드: 흰 바탕, 모서리 2.4u, 그림자 0 1.2u 3.6u rgba(0,0,0,.10).
- 소품 사진은 투명 배경 PNG(tools/cutout.py). 아래에 아주 옅은 둥근 그림자 하나(바닥 그림자)를 따로 깔면 떠 보이지 않아요.
- 방울: border-radius 50%, 안은 거의 투명(흰 4%), 테두리 쪽에 conic-gradient 무지갯빛 0.4u 띠 + 왼쪽 위 흰 반사점.

## 소품 이미지 준비
- 사용자는 ChatGPT 웹에서 고화질로 만드는 쪽을 좋아해요. 예시 프롬프트:
  "soft clay 3D render of a [물건], pastel natural colors, studio lighting, plain light gray background, centered, no text, isometric 3/4 view"
- 모든 소품을 같은 각도·조명·크기 비율로 만들어야 컷으로 바꿀 때 튀지 않아요. 받은 파일은 photo.py add → cutout.py.

## 움직임
- 96BPM, 느긋하게. 소품 하나에 1.1~1.4초(2박 남짓).
- 커지는 순간만 'pop'(넘침 조금), 나머지는 'snappy'·'soft'.
- 머무는 동안 소품이 아주 천천히 위아래로(S.fx.bob 0.4u, 0.5Hz) 또는 2° 안에서 좌우로 흔들림.
- 방울: 아래에서 위로 2~3초, 크기는 올라가며 1.0 → 1.3배, 옆으로 사인 곡선 흔들림 1u.

## 전환
- 소품끼리는 컷. 컷 직후 새 소품이 살짝 튀어 올라오는 것만으로 충분해요.
- 목록 카드 → 소품은 썸네일 자리에서 커지는 zoom.

## 대표 장면

1. 카드 아이콘 → 큰 소품 (1초)
   ```
   card: o = 1 - M.prog(t, t0, .2), blur = M.prog(t, t0, .2) * 8
   const k = M.spring(t - t0, 'pop');
   M.place(prop, lerp(thumbX, cx, k), lerp(thumbY, cy, k), { s: lerp(thumbW / propW, 1, k) });
   caption: M.place(cap, cx, capY + (1 - M.spring(t - t0 - .2, 'snappy')) * 2 * u, { o: M.prog(t, t0 + .2, .15) })
   ```
2. 소품 바꾸기 (소품 3~4개)
   - tl.set 으로 컷, 새 소품 S.fx.rise(prop, t, { y: 2 * u, d: .35, ease: 'power3.out' }) 와 함께 설명 글도 바꿈(같은 시각에).
3. 비눗방울 → 로고 (2초)
   ```
   const R = M.rng(11); const bubbles = [...Array(24)].map(() => ({ x: R(), r: .04 + R() * .16, d: R() * .6, sp: .8 + R() * .6 }));
   S.ambient(t => bubbles.forEach((b, i) => {
     const k = M.prog(t, tb + b.d, 2.2 / b.sp);
     M.place(el[i], b.x * S.W + Math.sin(t * 2 + i) * u, S.H * (1.1 - 1.3 * k), { s: 1 + .3 * k, o: k > 0 && k < 1 ? 1 : 0 });
   }));
   // 가운데 큰 방울 하나: 로고가 안에 비쳐 보이다가(로고 opacity .6 + blur 2px) 방울 테두리가 0.2초에 사라지며 로고가 또렷해짐
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: 부가 서비스 여러 개 나열, 생활·배달·세탁·대여 서비스, 부드러운 브랜드 마무리, 가족·아이 대상 서비스.
- 피할 것: 평면 아이콘만으로 만들기(3D 소품이 이 스타일의 전부), 어두운 바탕, 글 많은 장면, 빠른 컷 연타.
