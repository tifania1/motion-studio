# 빛 고리 동전 쌓기 (3D·사물)

한 줄: 짙은 청회색 바탕에 속이 어둡고 테두리가 빛나는 도넛 고리. 고리가 물결처럼 퍼지고, 동전처럼 쌓여 그래프가 되고, 원을 그리며 모였다 흩어져요. 글은 늘 작은 한 줄.

## 보는 느낌
- 주인공은 고리 하나의 모양뿐이에요. 크기·색·개수·배치만 바꿔 장면마다 다른 그림(물결, 눈사람, 별자리, 막대그래프, 원진)을 만들어요.
- 글은 화면 가운데 작은 한 줄(짧은 변의 4~5%). 고리 위에 겹쳐도 읽히게 흰 글자.
- 바탕은 거의 평평한 짙은 청회색, 화면 아래 가장자리에만 청록 안개가 옅게 깔려요.
- 고리가 화면을 꽉 채우는 장면(파랑으로 가득)과 고리 몇 개만 떠 있는 빈 장면을 번갈아 써서 밀도를 오르내려요.

## 색
- 바탕 70 · 고리 25 · 글 5. 고리가 화면을 채우는 장면은 고리 85.
- 고리 기본: 속 #0E1626 → 파랑 #2253E8 → 하늘 #3FC6E8 → 테두리 민트 #9BF0C9.
- 다른 고리: 보라 테두리(#B07BE0), 크림 테두리(#F2E6A6). 막대그래프·흩어진 장면에서만 섞어요.
- 도는 고리 장면만 형광 초록 → 노랑 → 주황 → 분홍으로 한 바퀴. 글 색도 그 색을 30% 섞어 따라가요.

## 글자
- Geist 400 + Noto Sans KR 500. 굵게 쓰지 않아요. 자간 −0.01em.
- 한 장면 한 문구, 3~4어절. 낱말 둘을 고리 양옆에 나눠 둘 수도 있어요(가운데 고리 원진이 둘을 밀어냄).
- 들어올 때 흐림에서 선명으로 0.3초, 살짝 기울어(−4°) 들어와 0°로 서는 경우도 한 번쯤.

## 질감과 모양
- 질감 없음, 아주 옅은 비네트(0.2)만.
- 고리 두께는 지름의 22~28%. 속 구멍은 완전히 어둡지 않고 바탕보다 조금 더 짙은 남색.
- 빛은 고리 안쪽 그라디언트로만 표현해요. 고리 밖으로 번지는 빛(box-shadow)은 테두리 바깥 0.5u 이내로 아주 조금.
- 막대그래프의 고리는 위에서 비스듬히 본 납작한 타원(세로 0.35배)으로 바꿔 쌓아요.

## 3D 고리를 우리 엔진에서 만드는 법
- CSS 도형(기본): 정원 div 하나에 겹친 radial-gradient.
  ```
  .ring { border-radius: 50%;
    background: radial-gradient(circle, #0E1626 0 30%, #13265A 38%, #2253E8 50%, #3FC6E8 62%, #9BF0C9 68%, rgba(155,240,201,0) 72%); }
  .ring::after { /* 위쪽에 아주 옅은 반사: 같은 원에 conic-gradient(from 200deg, transparent, rgba(255,255,255,.18), transparent 30%) 를 mask 로 고리 띠만 */ }
  ```
  색만 바꾼 변형은 CSS 변수 --r1(파랑) --r2(하늘) --r3(테두리) 로.
- 비스듬한 동전: 같은 .ring 에 transform: scaleY(.35). 쌓을 때는 위로 0.9u 씩, 뒤로 갈수록 아래 고리가 위 고리에 가려지게 z-index 를 위로 갈수록 크게.
- 사진(선택): 진짜 유리·금속 느낌이 필요하면 고리 PNG(투명 배경, 정면·45° 두 장)를 ChatGPT 웹에서 고화질로 만들어 photo.py add 로 넣고, 색 변형은 CSS filter: hue-rotate() 로.

## 움직임
- 100BPM. 고리 물결은 빠르게 퍼지고(expo.out), 머무는 동안은 아주 느리게 숨 쉬듯(scale ±2%, 4초 주기).
- 고리가 생길 때 0.1~0.12초 간격의 빠른 연타, 멈춰 있을 때는 느림. 이 대비가 이 결의 리듬이에요.
- 흩어질 땐 각 고리가 서로 다른 방향·속도로 떠다녀요(시드 난수 M.rng, 속도 1~4u/초).
- 넘침 없이. 바운스 이징은 쓰지 않아요.

## 전환
- iris: 가운데 고리가 커지며 다음 장면을 열어요(고리 물결과 같은 말).
- zoom: 고리 원진이 커지며 화면 밖으로 나가면 가운데 고리 하나만 남는 식으로.
- 같은 장면 안 배치 바꾸기는 컷 없이 고리들이 새 자리로 M.anim.

## 대표 장면

1. 고리 물결
   ```
   // 고리 n 개를 같은 가운데에. 고리 i 는 t0 + i*.1 에 태어남
   rings.forEach((r, i) => {
     const k = M.ease.outExpo(M.prog(t, t0 + i * .1, 1.2));
     const D = M.lerp(0, (n - i) * 0.45 * S.W, k);            // 먼저 난 고리가 더 크게
     M.place(r, S.W / 2, S.H / 2, {s: D / base, o: k > 0 ? 1 : 0});
   });
   // t0 + 1.4 이후: 큰 고리 셋만 남기고 나머지는 M.anim 으로 지름 → 화면 밖, 느리게 가라앉음
   ```
   - 시작 전에 로고(또는 작은 고리)가 0.3초 동안 90%로 살짝 작아졌다가 물결이 터지면 힘이 붙어요.

2. 동전 쌓기 막대그래프
   ```
   // 바닥 줄 고리 9개(정면). 막대 b 의 목표 높이 hb(겹 수)
   for (let j = 1; j <= hb; j++) {
     const tj = t1 + j * .12 + b * .05;                       // 위로 한 겹씩, 막대끼리 조금 엇갈림
     const k = M.spring(t - tj, {f: 5, z: .9});
     M.place(coin[b][j], x[b], baseY - j * .9 * S.W / 100 + (1 - k) * 2 * S.W / 100, {sy: .35, o: k > 0 ? 1 : 0});
   }
   // 꼭대기 고리는 정면(sy 1)으로 막대 위에 얹음. 다 쌓인 뒤 1박 지나 겹마다 다른 방향으로 흩어짐
   ```

3. 고리 원진과 도는 고리
   - 고리 8개를 반지름 R 원 위에 두고 각도 = 2π·i/8 + 0.4·t 로 천천히 돌림. 양옆 낱말 x = 가운데 ± (R + 고리 반지름 + 2u) 라서 R 이 커지면 낱말이 밀려나요.
   - R 을 M.anim 으로 화면 대각선보다 크게 → 가운데 작은 고리 하나가 M.spring 'pop' 으로 커지며 낱말을 품음.
   - 도는 고리: 중심을 화면 밖 위쪽 큰 원 궤도로 시계 방향 한 바퀴(2초), --r1~r3 를 M.color 로 초록→노랑→주황→분홍. 가운데 글 color = M.color('#E8F1F5', 현재 고리색, .3).

## 어울리는 곳 / 피할 것
- 어울리는 곳: 금융·결제·지갑 앱, 실시간 데이터·대시보드 서비스, 포인트·리워드 안내, 음악·오디오 서비스, 밤 분위기 런칭 티저.
- 피할 것: 밝은 바탕, 굵고 큰 제목, 사진, 손그림, 고리 말고 다른 3D 사물 섞기, 파티클. 영상 속 로고 모양은 쓰지 않아요. 고리라는 한 가지 사물로 여러 그림을 만드는 원리만 가져와요.
