# 초근접 타이핑 (타이포)

한 줄: 검색창이나 말풍선 하나를 화면보다 크게 키워 바짝 붙어요. 카메라가 커서를 따라 옆으로 흐르며 문장이 써지고, 둘레엔 옅은 색 안개가 깔려요.

## 보는 느낌
- 화면 가득 글자 한 줄. 입력창 테두리는 위아래 가장자리에만 살짝 보이고, 글의 앞부분은 왼쪽 밖으로 흘러 나가요.
- 사람이 지금 막 치고 있는 문장을 어깨 너머로 보는 느낌. "이렇게 말하면 돼요"를 가장 크게 보여 주는 방법이에요.
- 다 쓰고 나면 뒤로 물러나며 입력창 전체와 버튼이 드러나요. 크기 차이가 커서 마무리가 시원해요.

## 색
- 바탕 60 · 흰 입력창 30 · 글자 7 · 강조 3.
- 바탕은 분홍 기운 도는 아주 옅은 회색(#F1EEF0), 입력창 흰색, 글자 #1A1A1A.
- 강조는 진한 자홍(#C2185B) 하나: 커서 막대, 검색 버튼, 입력창 아랫선의 가는 빛.
- 안개는 강조색을 아주 옅게(#EDB7D3, 투명도 40% 안팎). 말풍선 버전이면 연파랑(#C0CCE4)으로 바꿔도 잘 어울려요.

## 글자
- 반듯한 고딕 Regular~Medium(Geist + Noto Sans KR 500). 크기는 화면 짧은 변의 11~13%(확대 뒤 보이는 크기).
- 한 줄로 끝나는 문장, 한국어로 20자 안팎. 띄어쓰기가 고르게 있어야 카메라 흐름이 매끄러워요.
- 커서는 강조색 세로 막대, 글자 높이의 1.1배, 두께 0.4u.

## 질감과 모양
- 질감 없음. 안개는 흐린 그라디언트로만.
- 입력창은 알약(모서리 999px), 흰 바탕, 아주 넓고 옅은 그림자(0 2u 8u rgba(0,0,0,.08)).
- 검색 버튼: 강조색 원 + 흰 아이콘, 원 둘레에 같은 색 아주 옅은 번짐 하나(빛나는 효과는 이 버튼 한 곳만).

## 움직임
- 108BPM. 타자는 초당 12~14자로 일정하게, 어절 끝에서 0.08초쯤 쉬면 사람 손 같아요.
- 카메라 x 는 커서를 늦게 따라가는 부드러운 추적(스프링 'soft'), y 는 고정. zoom 은 들어올 때 0.4초, 나갈 때 0.5초(power2.inOut).
- 버튼 누르기: 0.08초에 .92, 놓으면 'snappy' 로 1.
- 말풍선 버전: 다 치면 반 박 쉬고 답 말풍선이 오른쪽 아래에서 위로 'snappy' 로 올라오며, 앞 말풍선은 위로 밀림.

## 전환
- 들어올 때: 앞 장면(작은 문구나 토글)에서 입력창으로 zoom 확대.
- 나갈 때: 뒤로 빠진 뒤 화면 전체 흐림 디졸브(0.25초)로 결과 장면.

## 대표 장면

1. 들어오기 (0.6초)
   - 앞 장면의 강조 문구 아래 작은 토글이 켜지고(토글 원이 오른쪽으로, 바탕 강조색), 그 토글 쪽으로 zoom 5배 확대하며 입력창이 화면을 채움.
2. 커서를 따라가는 타자 (3~4초)
   ```
   S.ambient(t => {
     txt.textContent = M.type(Q, t, t0, 13);
     const cx = txt.offsetLeft + txt.offsetWidth;               // 커서 위치(판 좌표)
     const target = Math.max(S.W * .5, cx - S.W * .12 / Z);     // 커서가 화면 가운데보다 약간 오른쪽
     // 시간의 순수 함수로 따라가기: 어절마다 키를 만들어 M.anim 으로
     const camX = M.anim(wordKeys /* [[어절이 끝나는 시각, 그때의 target], ...] */, t, 'soft');
     M.camera(world, camX, cy, Z);
   });
   ```
   - wordKeys 는 compose 할 때 한 번 계산: 어절마다 끝나는 시각과 그때의 커서 x 를 미리 재 둬요.
3. 안개 바탕
   ```
   .haze { position:absolute; inset:-20%; background:
     radial-gradient(60% 18% at 50% 22%, var(--glow), transparent 70%),
     radial-gradient(60% 18% at 50% 78%, var(--glow), transparent 70%); filter: blur(calc(var(--u) * 6)); }
   ```
   - S.ambient 로 두 띠의 x 를 반대 방향으로 아주 천천히(초당 0.3u) 흘리면 살아 있어 보여요.
4. 뒤로 빠지며 버튼
   - Z 를 5 → 2.2 로 0.5초. 마이크 아이콘, 강조색 버튼이 차례로 보이고, 커서 없이 버튼만 눌림(scale .92 → 1) → 0.15초 뒤 흐림 디졸브.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 검색·추천 기능, AI 비서에게 말 거는 장면, 첫 3초 훅, "이렇게 물어보세요" 안내.
- 피할 것: 여러 줄 긴 문장, 작은 글씨, 빽빽한 UI, 어두운 바탕. 한 영상에서 두 번 넘게 쓰지 않기(초근접은 한 번일 때 세요).
