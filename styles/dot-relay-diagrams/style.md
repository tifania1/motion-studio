# 점으로 잇는 데이터 그림 (다이어그램·데이터)

한 줄: 옅은 회색 바탕에 가는 선과 점만으로 데이터를 그려요. 그림 하나가 점 하나로 오므라들고, 그 점에서 다음 그림이 퍼져 나와요.

## 보는 느낌
- 화면 대부분이 비어 있어요. 그림은 가운데에 화면 폭의 40% 안팎으로 작게 두고, 자막은 왼쪽 아래 구석에 작게 한 줄.
- 실험 노트나 논문 그림처럼 차분하고 정확한 느낌. 장식은 없고, 점·선·원 세 가지로 다 해결해요.
- 한 장면에 그림 하나, 자막 하나. 그림이 바뀌어도 자막 자리는 그대로라 눈이 편해요.

## 색
- 바탕 85 · 먹색(점·선·글자) 10 · 강조 5.
- 바탕은 살짝 초록 기운이 도는 옅은 회색(#E3E4DF), 점과 글자는 거의 검정.
- 강조는 주황 하나(#C2410C)를 기본으로, 무리를 나눌 때만 파랑(#2478C0)·보라(#6C6CC0)를 더해요. 셋을 넘기지 않아요.
- 보조선(연결선, 눈금)은 먹색 15~25% 정도로 아주 옅게.

## 글자
- 반듯한 그로테스크 고딕 Medium(Geist + Noto Sans KR 500). 굵게 쓰지 않아요.
- 자막은 짧은 영어 한 문장 길이, 한국어로는 10자 안팎("데이터를 보고", "원인을 찾고"). 크기는 화면 짧은 변의 3.5% 정도.
- 첫 장면의 타자 문장만 조금 더 크게(4.5%), 왼쪽 정렬, 화면 세로 40% 높이.

## 질감과 모양
- 질감 없음. 매끈한 디지털 화면.
- 선 굵기 1~1.5px(1080 기준), 점 지름 0.6~1u. 원은 테두리만, 선택된 점은 점 + 바깥 고리.
- 모서리 둥글림 없음. 카드나 그림자는 쓰지 않아요.

## 움직임
- 100BPM 안팎, 장면 하나에 5~6초(8~10박). 그림이 만들어지는 데 2~3박, 머무는 동안 아주 느리게 계속 변하고(회전, 흐름), 마지막 1박에 점으로 오므라들어요.
- 점들이 자리를 찾아갈 때는 M.spring 'snappy', 무리 지어 이동할 때는 'soft'. 넘침은 거의 없게.
- 곡선·연결선은 M.draw 로 0.4~0.6초.
- 자막: 글자 단위 0.03초 간격, 0.25초 길이로 아래(1.2em)에서 올라오기. 나갈 때도 같은 간격으로 아래로 빠지기.

## 전환
- 기본은 "점 이음" 하나만 써요. 앞 그림 → 점 → 다음 그림. 컷이나 페이드를 섞지 않아요.
- 장면 쌓기 템플릿에서는 cut 다음 iris(작은 원으로 열기)가 가장 가까워요.

## 대표 장면

1. 문장 치고 지우기 (0~4초)
   ```
   S.ambient(t => {
     const A = '어떤 말은 그림이 더 빨라요', B = '/그림으로 보기';
     if (t < 1.6) txt.textContent = M.type(A, t, .2, 30);
     // 1.6초부터 0.3초 동안 오른쪽에서 왼쪽으로 선택 (연파랑 덮개 폭 = 글 폭 × k)
     sel.style.width = (M.prog(t, 1.6, .3) * txtW) + 'px';
     if (t >= 1.95) { sel.style.width = 0; txt.textContent = M.type(B, t, 2.1, 24); }
     caret.style.opacity = (t > 1.9 && t < 2.1) || Math.floor(t * 2.4) % 2 ? 1 : 0;  // 강조색 세로 막대
   });
   ```
2. 점이 쌓여 분포 → 곡선 (4~7초)
   - 점 120개를 기준선 위 칸에 배정(가운데 칸이 가장 높게). i번째 점 k = M.spring(t − (t0 + 순서×0.004), 'snappy').
   - M.place(점, x, lerp(기준선, 목표y, k), {o: k}). 1.2초 뒤 곡선 path 를 M.draw(path, M.prog(t, t0+1.2, .5)).
   - 나갈 때는 점들이 살짝 흩어지며(시드 난수 M.rng) 위로 떠오르다 하나로 모임.
3. 연결망이 무리로 갈라짐 (7~10초)
   - 점 30개를 M.rng(7) 로 흩고, 가까운 점끼리 옅은 선. t1 에 무리별 목표 자리로 M.anim([[t0,[x,y]],[t1,[x1,y1],'soft']], t).
   - 선 색은 M.color('#B9BAB4', 무리색, k). 무리 사이 선은 점선으로 남겨 관계를 보여 줌.
   - 끝에 무리마다 중심점 하나로 모였다가 그 세 점이 다음 장면(원 세 개)의 중심이 됨.
4. 점 이음 (장면 사이 0.8초)
   ```
   const r = M.anim([[0, R], [tc, R*.35, {d:.1, e:'inCubic'}], [tc+.1, R*.12, {d:.1}], [tc+.25, R*.04, {d:.15}]], t);
   dot.style.background = t < tc ? 'transparent' : M.color('#B9BAB4', '#141414', M.prog(t, tc, .1));
   if (t > tc + .35) dot.style.background = 'var(--accent)';
   // tc+.4 부터 다음 그림의 점들: 위치 = lerp(점 중심, 목표, M.spring(t - tc - .4 - i*.01, 'pop'))
   ```

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI·데이터 서비스, 연구소·교육 기관, "이런 것도 돼요"를 차례로 보여 주는 기능 나열, 숫자 중심 공지.
- 피할 것: 사진 위주 광고, 두꺼운 카드·그림자, 넓은 원색 바탕, 한 화면에 글이 많은 장면. 강조색을 셋 넘게 쓰지 않기.
