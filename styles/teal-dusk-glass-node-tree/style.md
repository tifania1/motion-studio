# 청록 어둠 유리 노드 갈래 (다이어그램·데이터)

한 줄: 청록이 살짝 도는 어둠 속으로 가는 빛 선이 내려와 유리 노드 카드를 켜고, 카드 아래에서 선이 둥글게 갈라져 다음 카드로 이어져요. 뒤로 푸른 안개가 번지고, 마지막은 점 가루와 유리 구슬로 조용히 닫혀요.

## 보는 느낌
- 바탕은 거의 검은색인데 아주 살짝 청록이 돌아요. 한 화면에는 노드 카드 하나, 문구 한 줄, 갈래 선 몇 가닥 정도만 올려요.
- 가는 청록 선(1.5px 안팎)이 위에서 내려와 작은 화살촉으로 카드에 닿고, 카드 아래에서 큰 곡선으로 휘며 둘이나 셋으로 갈라져요.
- 카드는 어두운 유리판이에요. 테두리가 청록으로 빛나고, 안쪽 아래가 은은하게 밝아요. 왼쪽 위에 작은 선 아이콘과 흰 제목, 그 아래 청록 그라디언트 설명 글씨가 놓여요.
- 중반부터는 카드 뒤로 푸른 안개 덩어리가 번져 깊이가 생겨요. 후반에는 안개 속 큰 그라디언트 낱말, 점 가루 판, 유리 구슬로 이어지며 끝나요.
- 여백이 넓어요. 카드는 화면 너비의 35~45%쯤이고, 나머지는 어둠과 선이 차지해요.

## 색
- 바탕 80 · 선과 카드 테두리 10 · 글자 7 · 푸른 안개 3. 안개는 면적이 커도 아주 옅게 깔아요.
- 바탕 #0E1213, 유리 카드 #142629(불투명 70% 안팎), 선·테두리 #6FD3E8(선은 60~80%).
- 그라디언트 글씨는 왼쪽 짙은 청록 #2E8FA0 에서 오른쪽 밝은 청록 #6FD3E8 로 번져요.
- 안개는 #3A7BD5 에서 #1A3438 로 흐려지고, 불투명 20~35%.
- 제목은 거의 흰 #E8EEF0. 강조는 한 장면에 청록 하나만 써요.

## 글자
- Geist, 한글은 Noto Sans KR Medium·Bold. 제목 굵기 500, 자간 -0.01em 으로 단정하게.
- 카드 제목은 짧은 변의 4~5%, 흰색. 설명은 3% 안팎, 청록 그라디언트로 두 줄까지만.
- 큰 문구 장면은 짧은 변의 8~10%, 가운데 한 줄. 앞 낱말은 짙은 청록, 뒤 낱말은 밝은 청록으로 번지게 칠해요.
- 탭 줄 같은 작은 고딕은 흰색 50%로 두고, 고른 것만 흰색에 아래 빛 밑줄을 달아요.

## 질감과 모양
- 비네트 0.25 하나만. 그레인 없이 매끈하게 둬요.
- 카드 모서리 `--u` × 1.4, 테두리 1px 청록 40%. 켜진 카드는 테두리 85% 에 바깥 빛 한 겹(`box-shadow: 0 0 3u var(--glow)`).
- 선 끝은 둥글고, 꺾이는 곳은 모두 반지름이 큰 곡선이에요. 화살촉은 작은 V 자.
- 흐름의 시작은 알약 모양 노드, 그 아래 작은 + 동그라미 하나.

## 움직임
- 84BPM, 느림. 들어오는 건 `power3.out`, 카메라 이동은 `sine.inOut`.
- 선은 0.6~1초에 그어지고, 선 끝이 카드에 닿는 순간 테두리가 0.3초에 밝아져요.
- 카메라는 선을 따라 아래로 천천히 내려가요(장면 하나 2.4초 안팎). 흐름 끝에서 한 번 크게 물러나 나무 전체를 보여 줘요.
- 문구는 흐림 6px 에서 선명해지며 왼쪽부터 열리고, 오른쪽으로 2u 미끄러지다 멈춰요.
- 설정 패널은 옆에서 밀려 들어오고, 뒤에 고를 거리 목록이 흐리게 겹쳐 위로 흘러가요.
- 안개와 구슬은 4~5초 주기로 아주 조금씩 숨 쉬어요.

## 전환
- 페이드와 흐림 전환이 기본이에요. 카메라가 선을 따라 내려가는 곳은 위로 밀어내기(push). 컷은 거의 쓰지 않아요.
- 장면 쌓기: fade → blur → push.

## 대표 장면
1. **선이 내려와 노드를 켜고 갈라짐**
   ```
   // world 안에 시작 노드, 선, 카드, 갈래 선을 세로로 길게 배치
   S.ambient(t => {
     M.draw(wire, M.ease.outCubic(M.prog(t, 0, .8)));
     const k = M.spring(t - .8, 'smooth');
     M.place(card, cx, cy, {o: k, s: .96 + k * .04});
     card.style.borderColor = M.color('rgba(111,211,232,.35)', '#6FD3E8', M.prog(t, .8, .3));
     M.draw(branchL, M.ease.outCubic(M.prog(t, 1.4, .9)));
     M.draw(branchR, M.ease.outCubic(M.prog(t, 1.5, .9)));
     M.place(world, 0, M.anim([[0, 0], [1.8, -H * .35, {d: 1.4, e: 'inOutSine'}]], t));
   });
   ```
   흐름 끝에서는 world 를 `s: .45` 까지 1.6초에 물려 나무 전체를 보여 줘요.
2. **세 갈래 선이 문구를 꿰뚫음**
   - 문구에 `background: linear-gradient(90deg, #2E8FA0, #6FD3E8); -webkit-background-clip: text; color: transparent`.
   - `clipPath: inset(0 X% 0 0)` 의 X 를 `M.anim([[0, 100], [.2, 0, {d: 1.2, e: 'outCubic'}]], t)` 로 열고, 같은 시간에 `blur` 6px → 0, x 는 -2u → 0.
   - 아래 가운데에서 SVG path 세 개를 `M.draw` 로 0.1초씩 엇갈려 그어 올리고, 다 그려지면 끝마다 화살촉을 `o` 0 → 1.
   - 장면 쌓기에서는 title: blur 가 이 결을 맡아요.
3. **안개 위 큰 카드 넘기기**
   - 큰 유리 카드 하나를 가운데 두고, 아래로 휘어 화면 가장자리로 빠지는 선 4~5가닥을 `M.draw` 로 깔아요.
   - 카드 뒤 안개는 큰 원 두세 개를 `blur(10u)` 로 흐리고 `M.drift` 로 천천히 흘려요.
   - 다음 카드로는 `S.tr.blur` 로 넘겨요. 카드 내용만 바뀌고 안개는 그대로 이어져요.
4. **안개 → 점 → 구슬 엔딩**
   - 안개 속 큰 그라디언트 낱말이 흐림으로 빠지면, 안개를 `M.anim` 으로 지름 2u 의 점까지 오므려요.
   - 그 점에서 점 판(deco dots)이 퍼지고, 1.5초 뒤 다시 모여 유리 구슬이 돼요.
   - 구슬은 `conic-gradient` 푸른 결을 `S.ambient` 안에서 `rotate(t * 20deg)` 로 돌리고, 테두리에 흰 빛 한 겹. `M.place(orb, cx, cy, {s: 1 + Math.sin(t * Math.PI / 2.5) * .03})` 로 숨쉬기.
