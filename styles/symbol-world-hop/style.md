# 기호 하나, 바뀌는 세계 (시네마틱)

한 줄: 가운데 흰 기호는 그대로 두고, 위의 점이 튀어 내려앉을 때마다 뒤 세계가 성운·하늘·바위·별밭으로 컷. 보라 빛무리가 기호 모양을 따라 번지는 브랜드 공개.

## 보는 느낌
- 화면 정가운데 흰 기호 하나(또는 아주 짧은 낱말). 크기는 짧은 변의 30~40%, 자리는 영상 내내 그대로예요.
- 바뀌는 건 뒤의 세계뿐. 짙은 성운, 노을 하늘 사진, 흑백 바위, 형광 그라디언트, 푸른 별밭이 한 박씩 컷으로 지나가요.
- 중간에 한 번은 짙은 자두색 바탕에서 기호 둘레로 보라 빛무리가 겹겹이 번지는 장면이 들어가요.
- 공개 장면은 연보라 구름 바탕에 작은 마크와 자간 넓은 대문자 이름.

## 색
- 세계(바탕) 75 · 흰 기호 15 · 빛무리·강조 10.
- 기본 바탕 #1B1022(자두빛 검정), 기호 #F4F1F6. 빛무리는 보라 #9B8CF7 → 연보라 #CFC5FB.
- 세계 색은 장면마다 하나씩: 성운 분홍 #D9467A, 청록 #3FC1A8, 하늘 #5B8FE0, 밝은 미색 #ECE9E4(이때 기호는 짙은 자두 #3A1A26).

## 글자
- 산세리프 700(Geist + Noto Sans KR Bold). 이름·꼬리표는 대문자, 자간 0.04~0.12em으로 넓게.
- 글은 기호 아래 한 줄만. 크기는 짧은 변의 4~5%. 문장 장면은 거의 두지 않아요.

## 질감과 모양
- 그레인 0.06, 비네트 0.3. 사진 세계는 살짝 어둡게 눌러 흰 기호가 떠 보이게.
- 기호는 평평한 흰색. 모서리를 둥글린 도형(원, 둥근 삼각형, 알약)으로 짜면 잘 어울려요.
- 빛무리: 기호를 복제해 `blur` 2u·5u·9u 세 겹, 각각 보라 농도를 다르게.

## 움직임
- 92BPM(한 박 약 0.65초). 박마다 점이 한 번 튀고, 내려앉는 순간 컷.
- 점: 위로 올라갈 때 세로로 길쭉, 내려앉는 순간 가로로 납작(알약), 0.15초 뒤 둥글게. 넘침은 작게.
- 기호 회전: 빛무리 장면에서 0.3초에 휙 돌아 뒤집히고, 빛무리는 반 박 늦게 따라 돎.
- 공개: 흐린 마크가 0.3초에 선명해지고, 이름이 흐림에서 0.4초에 맺힘.

## 전환
- 박에 맞춘 하드 컷이 핵심이에요. 페이드로 세계를 섞지 않아요.
- 큰 장면이 바뀔 때만 원형 열림(iris). 장면 쌓기: cut → cut → iris → cut, 장면 바탕은 dark → accent → dark → paper 로 세계가 바뀌는 느낌을 줘요.

## 대표 장면
1. **박마다 튀는 점과 세계 컷**
   ```
   const b = M.beat(1), n = Math.floor((t - t0) / b), p = ((t - t0) / b) % 1;   // 박 번호, 박 안의 위치
   const h = 4 * p * (1 - p);                       // 0 → 1 → 0 포물선 (튀어 올랐다 내려옴)
   const sq = Math.exp(-p * 18);                    // 내려앉은 직후만 납작
   M.place(dot, cx, cy - gap - h * jump, { sx: 1 + .5 * sq - .15 * h, sy: 1 - .4 * sq + .2 * h });
   worlds.forEach((w, i) => w.style.opacity = i === n % worlds.length ? 1 : 0);   // 컷
   ```
   세계는 `S.img(key)` 사진, 큰 원 너덧 개를 흐린 성운(`radial-gradient` + blur 8u), 별밭(시드 고정 점 200개) 같은 걸로 섞어 짜요.
2. **보라 빛무리 속 뒤집기**
   - 기호 SVG 를 세 번 복제(blur 2u·5u·9u, 보라 투명도 .9·.6·.35)해 뒤에 깔고, 기호 각도 `a = M.anim([[t0, 0], [t1, 180, {d: .3, e: 'inOutCubic'}], [t2, 0, {d: .3, e: 'inOutCubic'}]], t)`.
   - 빛무리 각도는 `M.anim` 같은 키에 0.25초씩 늦춰 따라오게. 장면 쌓기 `deco: orb, rings` 가 이 몫이에요.
3. **흐림에서 맺히는 공개**
   - 연보라 구름 바탕(`bg: aurora`), 마크 `filter: blur((1 - k) * 3u)`, `k = M.spring(t - t0, 'smooth')`. 반 박 뒤 대문자 이름도 같은 방식으로.
   - 장면 쌓기 `title: stamp` 는 기호가 내려앉는 무게감을 글에 옮긴 값이에요.

## 어울리는 곳 / 피할 것
- 어울림: 브랜드 리뉴얼·새 로고 공개, 앱 아이콘·상징 소개, 런칭 티저, 굿즈·캠페인 키 비주얼.
- 피할 것: 글이 많은 장면, 기호를 장면마다 다른 자리로 옮기기, 페이드로만 잇기, 작은 UI 화면.
- 쓰는 기호는 브랜드 자신의 마크로. 다른 회사 마크 모양을 흉내 내지 않아요.
