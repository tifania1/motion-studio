# 낱말 알약 쏟아짐 (타이포)

한 줄: 크림색 바탕에 책에서 본 듯한 세리프 문장. 기울어진 짙은 띠 위로 글이 흘러가고, 흰 낱말 알약이 위에서 쏟아져 비스듬히 쌓이며, 강조 낱말엔 분홍 밑줄이 가운데서 양쪽으로 그어져요.

## 보는 느낌
- 바탕은 따뜻한 크림 회색 한 가지. 무늬 없이 넓게 비워 두고 가운데에 세리프 한두 줄만 둬요.
- 장면마다 소품이 하나씩 바뀌어요: 가로지르는 짙은 띠, 쏟아져 쌓이는 낱말 알약, 3D로 기운 인용 카드.
- 글은 조용하고, 움직임은 소품이 맡아요. 문장 자체는 차분하게 들어오고 알약·띠가 리듬을 만들어요.

## 색
- 바탕 75 · 글자 15 · 짙은 띠와 알약 8 · 분홍 2.
- 바탕 크림 #E3E0D5, 세리프 글자 짙은 먹색 #33322F(진해지기 전엔 40% 회색).
- 띠는 #3A3A3A, 띠 위 글자는 #E8E6E0. 알약은 거의 흰색 #F8F7F3 + 글자 #2A2927.
- 분홍 #B5318C 은 밑줄·작은 아이콘·버튼 그라디언트에만. 한 장면에 한 번.
- 보조로 짙은 키캡(#2E2E2E, 옅은 회색 테두리) 안에 주황 #E59A3B 글자를 한 번 쓸 수 있어요.

## 글자
- 세리프: 고운바탕(Gowun Batang) 400. 영문·한글 모두 이 글꼴로. 굵게 쓰지 않아요.
- 제목 크기는 짧은 변의 6~8%, 줄 간격 1.1, 가운데 정렬. 인용 카드 안은 같은 세리프를 브라우저 기울임으로.
- 알약·버튼·띠 위 글은 작은 산세리프(Geist + Noto Sans KR 500), 세리프 크기의 55% 정도.

## 질감과 모양
- 질감 없음. 매끈한 화면.
- 알약: 높이 = 글자 크기 × 2.2, 모서리 완전히 둥글게, 그림자 `0 0.4u 1.2u rgba(0,0,0,.12)`.
- 띠: 화면 폭의 120%, 높이 = 짧은 변의 14%, 위아래로 아주 옅은 그림자 한 줄.
- 인용 카드: 옅은 회색 #EDECE8, 모서리 1.4u, 아래쪽 그림자 짙게(바닥에 놓인 판처럼).

## 움직임
- 96BPM. 문장은 power3.out 으로 0.5초, 알약 낙하는 가속(power2.in)으로 떨어져 바닥에 닿을 때만 아주 작게 튕김(감쇠비 0.85).
- 세리프 등장: 어절마다 자간 0.25em → −0.01em, 투명도 0.3 → 1, 0.5초. 어절 간격 0.12초.
- 띠 위 문장은 초당 짧은 변의 18% 속도로 일정하게 흐름(이징 없음). 새 어절 색은 0.4초에 회색 → 흰색.
- 나갈 때는 문장이 옆으로 밀려나거나, 글자가 흩어지며 흐려져요.

## 전환
- 컷이 기본. 문장끼리는 아이콘이 밀고 들어오는 밀기(push).
- 알약 더미 속으로 파고든 뒤 컷, 글자가 흩어져 다음 장면의 버튼으로 모이는 이음(흐림 blur 전환과 같은 결).

## 대표 장면

1. **기울어진 띠 위로 흐르는 문장**
   ```
   // band: 폭 1.2W, 높이 .14*짧은변, rotate(-3deg). 아래에서 올라옴
   M.place(band, W/2, M.lerp(H*1.2, H*.5, M.spring(t - t0, 'smooth')), { rot: -3 });
   // 줄글을 어절 span 으로(S.words). 띠 안 문장 x 는 일정 속도로 흐름
   line.style.transform = `translateX(${W*.75 - (t - t0) * .18 * S.W}px)`;
   ws.forEach((w, i) => w.style.color = M.color('#7A7975', '#E8E6E0', M.prog(t, t0 + i * .25, .4)));
   ```
   띠 뒤로 앱 창 같은 짙은 판이 −3도로 기운 채 살짝 보이면 더 좋아요.
2. **낱말 알약이 쏟아져 쌓임**
   ```
   const R = M.rng(7);                       // 매번 같은 더미
   // 미리 쌓일 자리(아래 줄부터, 줄마다 4~5개, 각도 -35~35도)를 계산해 둠
   pills.forEach((p, i) => {
     const td = t0 + Math.floor(i / 4) * M.beat(.5) + R() * .1;   // 반 박마다 네 개씩
     const fall = Math.max(0, t - td), y = Math.min(p.y, -p.h + .5 * 2600 * fall * fall);
     const land = M.spring(t - (td + Math.sqrt(2 * (p.y + p.h) / 2600)), { f: 3, z: .85 });
     M.place(p.el, p.x, y, { rot: p.rot * (y < p.y ? .6 : 1) - (1 - land) * 4 });
   });
   M.camera(world, W * .5, H * .7, M.anim([[0, 1], [tEnd - .6, 1.6, { d: .6, e: 'inCubic' }]], t));
   ```
3. **자간이 좁혀지는 세리프 + 분홍 밑줄**
   - 어절 `S.fx.fade` 대신 `letterSpacing` 0.25em → −0.01em 과 투명도를 함께 0.5초.
   - 밑줄: 강조 낱말 아래 SVG 선, `M.draw` 를 가운데 기준으로 양쪽(선 두 개를 반대로) 0.6초. 장면 쌓기는 `marker: underline` 으로.
   - 다음 문장: 분홍 아이콘이 오른쪽 밖에서 `M.anim` 으로 날아와 멈추고, 앞 문장은 같은 순간 왼쪽으로 `M.spring('snappy')` 밀림.
4. **흩어진 글자가 버튼으로**
   - 제목을 `S.chars` 로 쪼개 글자마다 시드 난수로 흩어진 자리·크기(0.6~1.4)·흐림(0~6px)을 정하고 0.3초에 흩음 → 0.4초에 가운데 알약 버튼 자리로 모이며 사라지고 버튼이 커짐. 버튼 왼쪽에서 오른쪽으로 분홍 그라디언트가 한 번 쓸고 지나감.
5. **기운 인용 카드**
   - 카드를 `perspective(1200px) rotateX(18deg) rotateZ(-10deg)` 로 두고 다음 카드마다 각도를 바꿔 `M.anim` 으로 돌림. 안의 기울임 세리프는 어절마다 회색 → 먹색.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 글쓰기·출판·교육 서비스, 브랜드 철학 한 줄, 책·강의 소개, 후기·추천사 모음(인용 카드).
- 피할 것: 굵은 고딕 큰 제목, 쨍한 원색 바탕, 네온 빛, 알약을 한 화면에 마흔 개 넘게. 지어낸 추천사·언론 인용은 넣지 않아요.
