# 솔빛 세리프 픽셀 노드 (다이어그램·데이터)

한 줄: 짙은 솔빛 초록 판과 옅은 회색 판을 오가며 작은 세리프 한 줄이 뜨고, 회색 위에서는 픽셀 노이즈가 번졌다 걷히며 작은 네모 점들이 가는 선으로 이어지다 이름 표로 정렬돼요.

## 보는 느낌
- 판은 두 가지예요. 짙은 솔빛 초록 판에는 흰 세리프 한 줄만, 옅은 회색 판에는 아주 작은 점·선·글이 넓게 흩어져요. 여백이 화면의 80% 넘게 남아요.
- 회색 판의 주인공은 작은 것들이에요. 짧은 변의 0.6% 남짓한 네모 점, 1px 보다 가는 선, 작은 세리프 이름. 멀리서 보면 지도나 성좌처럼 보여요.
- 장면 사이에 픽셀 블록 노이즈가 끼어들어요. 회색 네모가 가로로 뭉쳐 번지고, 그 속에서 낱말이 맺히거나 다음 그림이 드러나요.
- 도입은 채도를 뺀 도시 사진 한 장으로 열어도 좋아요. 사진은 한 번만.

## 색
- 회색 판 70 · 초록 판 20 · 먹색 글과 점 8 · 밝은 초록 2.
- 회색 바탕 #EDEDEC, 글과 점 #1E2B26, 옅은 점·선은 같은 색 15~40%.
- 초록 판 #26332E 위 글은 #EEF0EC.
- 밝은 초록 #3FAE6B 는 점 몇 개와 '찾았다' 표시에만. 문서 속 강조는 옅은 초록 #A9D9BC 형광 칩, 인용 번호는 같은 색 작은 둥근 네모.
- 픽셀 노이즈 블록은 #C9CBC8 위주에 먹색·올리브 블록을 5% 정도 섞어요.

## 글자
- 타이틀: Instrument Serif 400(한글 고운바탕). 짧은 변의 4~6%로 작게, 가운데 한 줄. 굵게 쓰지 않아요.
- 이름·표 글: 같은 세리프, 짧은 변의 2% 안팎. 표의 앞 열은 먹색, 뒤 열로 갈수록 옅게.
- 앱 화면 글: Geist(한글 Noto Sans KR Medium), 회색 단계로 위계를 나눠요. 고른 항목만 먹색.
- 줄 간격 넉넉하게(1.5), 자간 −0.01em.

## 질감과 모양
- 질감 오버레이 없이 매끈하게. 거친 맛은 장면 안의 픽셀 블록이 맡아요.
- 점은 동그라미 대신 작은 네모. 선은 0.5~1px, 먹색 20~50%.
- 카드는 흰 바탕, 얇은 회색 테두리, 아주 옅은 그림자, 모서리 0.8u.
- 마무리 표시는 짧고 납작한 막대 여러 개로 만든 고리. 모양은 브랜드에 맞게 새로 짜요.

## 움직임
- 80BPM, 느림. 대부분 `power2.inOut` 으로 미끄러지듯.
- 타이틀은 흐림 6px 에서 선명하게 0.8초, 두 박 머문 뒤 흐려지며 빠져요.
- 픽셀 블록은 무리마다 반 박 간격으로 켜지고, 꺼질 땐 한꺼번에 2~3프레임 사이에 사라져요.
- 선은 한 가닥씩 0.6초에 그어지고 다음 선이 0.15초 늦게 따라와요. 점은 그대로 두고 선만 옅어졌다 다시 그어지며 관계가 바뀌어요.
- 표 열은 하나씩 오른쪽으로 0.5초 페이드하며 붙어요.

## 전환
- 페이드가 기본, 초록 판과 회색 판 사이는 컷, 낱말이 맺힐 때는 흐림(blur). 장면 쌓기: fade → cut → blur.
- 픽셀 노이즈가 판을 덮었다 걷히는 것도 전환처럼 써요.

## 대표 장면
1. **픽셀 노이즈 속 낱말**
   ```js
   const R = M.rng(7), cells = S.$$('.px');   // 회색 네모 블록 수백 개, 가로로 뭉친 무리
   cells.forEach(c => c.t0 = 0.2 + Math.floor(R() * 6) * M.beat(.5));
   S.ambient(t => {
     cells.forEach(c => c.style.opacity = (t > c.t0 && t < M.beat(6)) ? 1 : 0);
     const k = M.prog(t, M.beat(2), .8);
     M.place(word, cx, cy, { o: k, blur: (1 - k) * 6 });   // 세리프 낱말이 맺힘
   });
   ```
2. **관계도에서 표로**
   - 네모 점 8~10개를 흩어 두고 이름을 붙여요. 선 path 마다 `M.draw(p, M.prog(t, t0 + i * .15, .6))` 로 한 점(가운데 이름)에 모이게.
   - 다음 박에 이름들을 `M.anim([[0, 원래자리], [tB, 표자리, {d: .9, e: 'inOutCubic'}]], t)` 로 왼쪽 열에 내려앉히고, 회사·분야·도시 열을 한 박씩 늦게 `o` 0 → 1. 마지막 열일수록 글색을 옅게.
3. **문서 속 초록 칩과 인용 번호**
   - 회색 목록에서 커서가 내려가며 고른 항목만 먹색으로(`M.color`). 오른쪽 문서 문단은 아래로 갈수록 옅어지고, 숫자 구간에 옅은 초록 형광을 왼쪽부터 `clipPath: inset(0 X% 0 0)` 으로 칠한 뒤 작은 번호 칩이 톡 나타나요. 칩을 누르면 출처 카드가 살짝 떠올라요(`M.spring` 'smooth').
4. **두 줄 점 사이 선과 고리 마무리**
   - 위·아래 줄에 네모 점 6개씩. 선 3~5가닥을 엇갈려 `M.draw` 하고 옅게 지운 뒤 다른 짝으로 다시. 가운데엔 `M.type(text, t, t0, 18)` 로 작은 질문 한 줄.
   - 끝: 짧은 막대 8개를 흩어 놓고 돌며 고리 자리로 모이게 한 뒤, 컷으로 초록 판(s-paper)에서 막대가 흰색으로 바뀌고 `S.tr.blur` 로 세리프 로고타입 한 줄에 넘겨요.
