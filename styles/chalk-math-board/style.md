# 칠판 수학 노트 (손그림)

한 줄: 검은 석판 칠판에 점 격자를 깔고, 반듯한 고딕 제목과 작은 고정폭 꼬리표 옆으로 분필 손글씨 수식과 빗금 친 도형이 그려지는 연구 노트 결이에요.

## 보는 느낌
- 화면은 푸른 기가 살짝 도는 검은 칠판 한 장. 지운 자국 같은 옅은 얼룩만 남아 있어요.
- 한 장면에 그림 하나. 점 격자, 큰 원 안에 꽉 찬 동그라미 묶음, 점과 선으로 된 그래프, 빗금 친 삼각형 같은 수학 도형을 가운데나 오른쪽에 크게 둬요.
- 그림 옆 여백에는 분필로 쓴 짧은 수식·화살표 주석이 딱 하나. 그 주석을 손으로 그은 타원이 감싸요.
- 화면 위(또는 아래) 가장자리에 작은 고정폭 대문자 꼬리표 한 줄: "문제 · 번호 01/10 · 분야" 세 칸. 시험지 머리말처럼 조용히.
- 반듯한 고딕·고정폭 글자와 거친 분필 손글씨가 한 화면에 같이 있는 게 이 결의 핵심이에요. 손글씨는 주석과 숫자에만 아껴 써요.

## 색
- 칠판 80 · 분필 흰색 15 · 색 분필 5.
- 칠판 #1E2124, 분필 흰색 #ECECE6, 꼬리표 항목 이름은 흰색 60%.
- 색 분필은 점 하나, 선 몇 개에만 써요: 연보라 #B9A6F2(기본 강조), 노랑 #F2CF3C, 주황 #E27731, 분홍 #F2B8C0. 장면마다 한두 색만 고르고, 장면이 바뀔 때마다 색을 돌려 써요.
- 그래프 연결선은 색 분필을 50~70%로 옅게 깔고, 정답이 되는 선 하나만 진하게.

## 글자
- 제목: 반듯한 그로테스크 고딕 Medium(Geist + Noto Sans KR 500). 짧은 변의 8% 안팎, 자간 −0.01em, 굵게 쓰지 않아요. 두 낱말을 위아래로 떼어 놓고 그 사이에 점 무늬를 두는 배치가 잘 어울려요.
- 꼬리표: Geist Mono + Noto Sans KR, 짧은 변의 1.6~2%, 대문자, 자간 0.08em. 항목 이름은 흐리게, 값은 또렷하게.
- 손글씨 주석과 큰 숫자: Caveat(영문·숫자) + 나눔손글씨 펜(한글). −4~−6도 기울이고 짧은 변의 5~6%.
- 글은 문장보다 낱말·수식 위주. 한 장면에 제목 한 줄, 주석 하나, 꼬리표 한 줄이면 충분해요.

## 질감과 모양
- 그레인 0.16을 초당 4번만 바꿔 석판 얼룩 결만 살짝 남기고, 비네트 0.2. 선 떨림(boil)은 쓰지 않아요. 분필 선은 한 번 그어지면 가만히 있어요.
- 분필 선은 1.5~2.5px, 가장자리가 거칠고 군데군데 끊긴 결. 테두리·타원·화살표는 손으로 그은 선(rough).
- 면은 빗금으로 칠해요. 분필을 눕혀 그은 듯한 비스듬한 선(간격 0.6~0.9u, 70~80도)을 촘촘히.
- 점은 지름 0.6~0.9u 꽉 찬 흰 점. 선택된 점만 색 분필로 칠하고 1.4배 크게.
- 모서리 0. 카드·그림자는 쓰지 않아요.

## 움직임
- 102BPM, 한 장면 8박(4.7초) 안팎. 그려지는 데 2~3박, 머무는 동안 작은 변화(점 하나 색이 바뀜, 주석 한 글자 더함), 마지막 1박에 접혀 나가요.
- 점·동그라미는 가운데부터 바깥 고리 순서로 톡톡 생겨요(스프링, 넘침은 아주 조금, 고리 사이 0.05초).
- 분필 선은 power2.inOut 으로 0.6~0.9초. 빗금 칠은 한쪽 끝에서 반대쪽으로 1초에 쓸어요.
- 제목은 커서 없이 한 글자씩(초당 14자 안팎) 찍히고, 주석 손글씨는 글자 사이 0.08초로 써져요.
- 나갈 때는 그린 순서를 거꾸로 되감듯 선이 지워지고, 점들이 가운데로 모여 색 분필 점 하나만 남아요.

## 전환
- 조리개(iris)로 점 하나까지 오므렸다가 그 점에서 다음 장면을 열어요. 숨 고르는 자리는 서서히(fade). 옆으로 밀거나 번쩍이는 센 전환은 쓰지 않아요.

## 대표 장면

1. 빗금 삼각형 (점 격자 위 도형)
   ```
   // 점 격자 9×5: S.fx.pop(dots, T0, { stagger: .02 })  처음엔 연보라였다가 0.3초 뒤 흰색으로
   // 테두리: 꼭짓점 → 오른쪽 아래 → 왼쪽 아래 → 꼭짓점 을 M.rough('line', …) 세 개로 이어 한 path
   // 빗금: 비스듬한 짧은 선 30~40개를 한 <g> 에 넣고 삼각형 모양 clipPath 로 자름
   S.ambient(t => {
     M.draw(tri, M.ease.inOutCubic(M.prog(t, T0 + .3, .8)));                         // 테두리 0.8초
     const k = M.prog(t, T0 + 1.2, 1);                                                 // 빗금 1초
     hatch.style.clipPath = `inset(0 0 0 ${(100 - 100 * k).toFixed(1)}%)`;            // 오른쪽 → 왼쪽
     const out = M.prog(t, T1 - .5, .5);                                               // 나갈 때 거꾸로 (M.prog 는 시작, 길이)
     if (out > 0) { M.draw(tri, 1 - out); hatch.style.opacity = 1 - out; }
   });
   ```
2. 손글씨 주석 + 분필 타원
   - 그림 왼쪽 위 여백에 Caveat 주석을 S.chars 로 쪼개 글자 사이 0.08초로 S.fx.reveal. 다 쓰고 반 박 뒤 `M.rough('ellipse', { cx, cy, rx, ry, turns: 1.15 })` 를 M.draw 로 0.5초에 감아요. 묶음 전체는 −5도.
   - 장면 쌓기에서는 marker: circle + rough 로 강조 말에 분필 타원이 자동으로 그어져요.
3. 큰 원 안에 동그라미가 차오름
   - 큰 원 테두리(M.rough('ellipse'))를 0.6초에 먼저 긋고, 안쪽 흰 원 수십 개를 가운데 고리부터 `M.spring(t - t0 - ring * .05, 'pop')` 으로 0→1 크기. 다 차면 아래쪽 두세 개만 회색 빗금 원으로 바꿔 '빈 자리'를 보여 줘요. 원 오른쪽 아래에 손글씨 기호 하나.
4. 머리말 꼬리표와 점 하나 이음
   - 화면 위 한 줄 세 칸을 Geist Mono 로 `M.type(text, t, t0, 40)` 으로 빠르게 찍어요. 장면이 바뀔 때는 값만 다시 타자.
   - 장면 끝: 그림의 점들을 M.place 로 가운데에 모으며 크기 0, 마지막 하나만 색 분필 점(지름 1.2u)으로 남김 → 0.3초 쉬고 S.tr.iris 로 다음 장면을 그 점에서 열기.
