# 미색 판과 보석색 리본 (그래픽·도형)

한 줄: 미색 판과 보라·솔빛·남색 보석색 판이 번갈아 가며, 가는 물결 선 위로 그라디언트 리본과 색 견본 막대가 장면마다 바뀌어요. 큰 낱말 옆 숫자가 컷마다 뛰면서 둘레에 고정폭 주석이 불어나고, 끝에는 카드 구름이 한 줄기로 모여드는 제품 공개 필름이에요.

## 보는 느낌
- 기본 판은 따뜻한 미색이에요. 처음에는 거의 비어 있고, 한가운데 아주 작은 고정폭 낱말 몇 개만 떠 있어요. 여백이 넓어서 작은 글자에도 시선이 모여요.
- 장면이 바뀌면 판 하나가 보석색 하나로 꽉 차요. 보라, 짙은 솔빛 초록, 남색, 숯빛 가운데 한 판에 한 색만 써요. 그 위로 머리카락 같은 물결 선이나 점선 부채살이 화면을 가로질러요.
- 색은 그라디언트 리본과 견본 막대에 몰아 써요. 연두 → 민트 → 분홍 → 주황으로 번지는 리본이 판 모서리에서 휘어 들어오거나, 화면을 반으로 갈라 한쪽은 보석색, 한쪽은 미색으로 남겨요.
- 가운데 큰 낱말 장면에서는 둘레 빈자리에 작은 주석이 흩어져요. 고정폭 대문자 꼬리표, 토글, 점선 별자리, 선 아이콘이 박자마다 하나씩 늘어나 설계 도면처럼 빽빽해져요.
- 끝으로 갈수록 카드가 많아져요. 보석색 판 위 3D 공간에 크기가 제각각인 카드가 깊이를 달리해 떠 있다가 한 줄기로 모이고, 마지막은 숯빛 판 위 작은 흰 마크 하나로 조용히 닫혀요.

## 색
- 미색 장면은 미색 80 · 먹 15 · 그라디언트 5. 보석색 장면은 보석색 70 · 리본·카드 20 · 흰 글자 10.
- 미색 #E9E5DD, 먹 #1C1C1B, 옅은 글자 먹 62%.
- 보석색 판: 보라 #4A1C82(장면 쌓기의 paper), 솔빛 #1F4A35, 남색 #1C2B52, 숯빛 #1E1F1E. 판 위 글자는 #F3F0EA.
- 리본·견본 그라디언트: 연두 #C8F06A → 민트 #7FE3C0 → 분홍 #EFA3DC → 보라 #9B6BF2 → 주황 #F07A2E.
- 강조는 분홍 #EFA3DC 하나예요. 보석색 판 위 문장에서 뒷부분 한 토막만 분홍으로 바꾸고, 분홍 칸 위 글자는 먹색으로 써요.
- 물결 선·점선은 미색 위에선 먹 12~18%, 보석색 위에선 흰색 25~35%나 연분홍 점선으로 그어요.

## 글자
- 큰 글: Geist 400(한글은 Noto Sans KR Medium), 자간 −0.03em. 크기는 짧은 변의 18~24%로 크게 쓰고, 굵기는 가볍게 둬요. 낱말 하나에 숫자 하나 정도만.
- 문장: Geist 400, 짧은 변의 5~6%, 가운데 한 줄.
- 주석·꼬리표: Geist Mono 400 대문자, 짧은 변의 1.6~2.2%로 아주 작게. 자간 +0.06em. '처리 중..|'처럼 끝에 커서가 깜빡이는 줄도 섞어요.
- 오프닝 낱말도 고정폭 대문자로 작게 써서, 넓은 여백 속에 점처럼 놓여요.

## 질감과 모양
- 질감 없이 매끈해요. 종이·그레인·비네트는 쓰지 않아요.
- 선은 모두 1px 안팎의 가는 선이에요. 물결 선은 7~12줄 묶음으로 나란히 흐르고, 부채살은 점선으로 그어요.
- 카드는 모서리 0.8u, 그림자 없이 납작하게. 3D 카드 구름에서만 깊이에 따라 흐림을 줘요.
- 입력 알약은 옅은 회색 칠에 모서리를 크게 둥글려요.
- 마크는 굵기가 고른 두꺼운 띠 하나로 된 단순한 도형이에요. 우리 브랜드 마크나 원·물결 도형으로 바꿔 써요.

## 움직임
- 100BPM, 보통 빠르기. 장면은 4박(2.4초) 안팎으로 머물러요.
- 이징은 power3.inOut. 들어오고 멈추는 게 모두 부드럽고, 튀는 반동은 없어요.
- 오프닝 낱말은 한 박마다 하나씩 흐림에서 맺히고, 다 모이면 1초 동안 옆으로 벌어졌다 비스듬히 흩어져요.
- 물결 선은 쉬지 않고 아주 천천히 일렁여요(8초 주기). 리본도 같은 속도로 휘어요.
- 숫자는 컷으로 바뀌어요. 바뀔 때마다 주석이 반 박 간격으로 하나씩 늘어나요.
- 카드 구름은 카메라가 앞으로 천천히 밀고 들어가는 느낌이에요. 끝에는 카드들이 1.5초에 걸쳐 가운데 한 줄기로 모여요.

## 전환
- 컷이 기본이에요. 미색에서 보석색으로 갈 때는 보석색 판이 옆에서 쓸고 들어오는 와이프(wipe)를 쓰고, 화면 반쯤에서 잠깐 멈춰 두 판이 나란히 보이게 해요.
- 카드 장면 사이는 밀어내기(push). 장면 쌓기: cut → wipe → push.

## 대표 장면

1. 작은 낱말이 벌어지는 오프닝과 마크
   ```
   // 낱말 셋, 한 박마다 하나씩 맺힌 뒤 벌어지고 비스듬히 흩어짐
   const words = S.$$('.w');                 // 고정폭 대문자, 짧은 변의 1.8%
   S.ambient(t => {
     words.forEach((w, i) => {
       const k = M.ease.outCubic(M.prog(t, i * M.beat(1), .5));
       const s = M.ease.inOutCubic(M.prog(t, M.beat(4), 1));      // 벌어짐
       const f = M.ease.inOutCubic(M.prog(t, M.beat(6), 1));      // 비스듬히
       M.place(w, cx + (i - 1) * W * (.08 + .1 * s), cy + (i - 1) * H * .06 * f,
               {o: k, blur: (1 - k) * 4});
     });
     M.draw(markPath, M.ease.inOutCubic(M.prog(t, M.beat(9), .9)));  // 굵은 띠 마크 한 획
   });
   ```
2. 물결 선 + 보석색 와이프 + 리본
   - 가로선 9줄(SVG path)을 미색 위에 깔고, `S.ambient` 안에서 각 줄의 y 를 `sin(x * .004 + t * .8 + i * .3) * H * .04 * k` 로 휘게 해요. k 가 0 → 1 로 차오르면 곧은 선이 물결로 바뀌어요.
   - 보석색 판을 `S.tr.wipe` 로 쓸어 넣되 화면 60% 지점에서 한 박 멈춰요. 보석색 쪽 모서리에서 그라디언트 리본(`linear-gradient` 를 칠한 넓은 곡선 띠)이 `M.drift` 로 천천히 휘어 들어오고, 문장은 앞 토막만 흰색, 뒤 토막은 분홍으로 맺혀요.
3. 견본 막대가 색 네모 두 줄로
   ```
   const bars = S.$$('.swatch');             // 세로 그라디언트 막대, 위 귀퉁이에 고정폭 꼬리표
   const r = M.rng(7);
   S.ambient(t => bars.forEach((b, i) => {
     const up = M.spring(t - i * .06, 'smooth');
     const flat = M.ease.inOutCubic(M.prog(t, M.beat(4), .8));
     const h = M.lerp(H * (.3 + r() * .25), H * .12, flat) * up;
     const y = cy + (i % 2 ? 1 : -1) * H * .09 * flat;            // 위아래 두 줄로 갈라짐
     M.box(b, {x: x0 + i * bw, y: y - h / 2, w: bw * .9, h});
     b.style.setProperty('--flat', flat);    // 그라디언트 → 단색
   }));
   ```
4. 숫자가 뛰고 주석이 불어나는 큰 낱말
   - 가운데 큰 낱말(Geist 400, 짧은 변의 20%)은 고정하고, 숫자만 `M.at([[0, '1'], [M.beat(4), '3'], [M.beat(8), '15']], t)` 로 컷마다 갈아 끼워요. 숫자가 바뀌는 박에 판도 미색 ↔ 숯빛으로 컷.
   - 주석은 숫자마다 늘어나요: 고정폭 꼬리표는 `M.type(text, t, ti, 30)` 로 쳐지고, 점선 별자리는 `M.draw` 로 0.4초, 토글은 검은 칸이 `M.anim` 으로 한 줄 아래로 옮겨 가요. deco marks 로 눈금, rings 로 회전 고리를 깔아도 같은 결이에요.
5. 카드 구름이 한 줄기로
   - 보라 판 위 카드 20~30장을 `M.rng` 로 x·y·깊이(z)를 흩고 `perspective` 안에 띄워요. 깊이에 따라 `blur` 0~6px. 카메라는 z 를 천천히 밀고, 마지막 1.5초에 모든 카드 x 를 가운데로 모아(`M.anim`, inOutCubic) 세로 한 줄기로 쌓은 뒤 숯빛 판 위 작은 흰 마크로 컷.
