# 흑연 위 청록 물결 카드 (제품 UI)

한 줄: 짙은 흑연 회색 위에 청록 물감 결이 흐르는 둥근 카드 하나가 화면 가득에서 작은 알약까지 몸을 바꿔 가며 템포·조성·파형을 보여 주고, 끝에는 어두운 파형 카드 떼가 깊이를 달리해 떠다니는 차분한 음악 도구 런칭.

## 보는 느낌
- 바탕은 거의 검은 흑연 회색 한 장이에요. 가운데가 아주 조금 밝고 가장자리로 갈수록 어두워져요.
- 화면에는 늘 주인공 하나만 둬요. 입력 카드 하나, 구슬 버튼 하나, 청록 카드 하나. 여백이 화면의 60% 넘게 남아요.
- 색은 거의 다 카드 안에 들어 있어요. 흐린 청록 물감이 대리석 결처럼 천천히 섞이는 면이 카드 모양을 따라 잘려 있고, 그 위에 반투명 유리 버튼과 흰 글씨가 얹혀요.
- 한 번은 그 청록 결이 화면 전체로 번져 바탕이 되고, 그 위에 어두운 유리 패널이 떠요.
- 후반에는 작은 어두운 카드들(흰 파형 아이콘 하나씩)이 앞뒤 깊이를 달리해 흩어져 떠다니고, 가운데 청록 카드 하나만 밝아요.

## 색
- 흑연 #1B1C1D 70 · 청록 결 20 · 흰 글자 10.
- 카드·입력창 바탕은 한 단계 밝은 회색 #2A2C2E, 테두리는 흰색 6~8%.
- 청록 결은 짙은 청록 #1E5E66 → 청록 #3FB8C4 → 옅은 물빛 #A9E3E6 세 색을 섞어요. 흰빛이 아주 조금 비쳐요.
- 썸네일 몇 장(트랙 목록)에만 주황·파랑·크림 물감 결을 섞어 '여러 곡'임을 보여 주고, 그 밖에는 청록 한 계열만 써요.
- 강조(accent)는 청록 #3FB8C4. 그 위 글자는 짙은 청록 #0E2A2E.

## 글자
- 둥글고 담백한 산세리프(Geist 400 + Noto Sans KR Medium). 큰 제목도 굵기 400, 자간 −0.01em.
- 제품 이름 같은 낱말은 화면 높이 9~11%, UI 안 글씨는 2~3%로 작게. 크기 대비가 크고 굵기는 고르게.
- 숫자(템포 값)는 카드 안에서 크게(화면 높이 7%), 옆에 작은 단위 글씨.
- 가운데 정렬. 문장은 한두 줄, 옅은 회색 부제 한 줄을 아래에.

## 질감과 모양
- 비네트 0.25 만. 그레인·주사선 없이 매끈해요.
- 카드 모서리 `--u` × 2, 작은 카드와 알약은 완전히 둥글게.
- 유리 버튼: 흰색 12~18% + 블러 + 1px 흰 테두리 25%. 구슬 버튼은 청록 결을 원 안에 담고 위쪽에 하이라이트 한 줄.
- 둥근 사각 윤곽선은 1px 청록 40~60%, 모서리 크게.
- 그림자는 아주 옅게, 빛 번짐은 청록 카드 둘레에 한 겹만.

## 움직임
- 96BPM, 보통 속도. 모양 바꾸기는 `power3.inOut` 으로 0.8초, 떠 있는 것은 사인 곡선으로 아주 천천히.
- 청록 결 안쪽은 장면 내내 쉬지 않고 흘러요(한 바퀴 8~10초).
- 카드는 들어올 때 흐림 6px → 0 과 함께 2u 떠오르고, 나갈 때는 흐려지며 사라져요.
- 한 장면이 3~5초 머물러요. 서두르지 않고, 값이 바뀌는 순간만 또렷하게.
- 파형 막대는 박자마다 높이가 출렁이고, 떠다니는 카드 떼는 깊이에 따라 속도가 달라요(앞은 빠르게, 뒤는 느리게).

## 전환
- 흐림(blur) 전환이 기본. 앞 장면이 흐려지는 사이 다음 카드가 흐림에서 맺혀요.
- 같은 청록 카드가 이어질 때는 전환 대신 카드 자체가 모양을 바꿔 다음 장면이 돼요.
- 장면 쌓기: blur → fade → cut. 컷은 마지막 낱말·엔딩으로 넘어갈 때 한 번.

## 대표 장면

1. 청록 물감 결 카드가 모양을 바꿈
   ```
   // 결: 큰 원 4개를 radial-gradient 로 깔고 blur(4u), SVG feTurbulence + feDisplacementMap 으로 대리석처럼 휘게
   S.ambient(t => blobs.forEach((b, i) => M.drift(b, t, { seed: i, r: 0.25, speed: 0.12 })));
   // 화면 가득 → 큰 카드 → 작은 카드 → 알약 (0.8초씩)
   const k = [[0, full], [tA, big, {d: .8, e: 'inOutCubic'}], [tB, small, {d: .8, e: 'inOutCubic'}], [tC, pill, {d: .8, e: 'inOutCubic'}]];
   S.ambient(t => M.box(card, M.anim(k, t)));
   // 안의 유리 버튼·글씨는 바뀌는 순간 흐림으로 갈림
   M.place(inner, cx, cy, { o: k2, blur: (1 - k2) * 6 });
   ```
2. 굴러가는 템포 숫자와 조성 바퀴
   - 장면 쌓기 number: odometer 로 숫자가 자리마다 세로로 굴러요.
   - 조성 피커는 낱말 목록을 세로로 두고 `y = M.anim([[t0, 0], [t0 + .6, -step * 3, {d: .6, e: 'inOutCubic'}]], t)`, 가운데에서 멀수록 `o = 1 - |d| * .35`, `blur: |d| * 2`. 다 돌면 카드가 작은 알약으로 줄어들어요.
3. 파형 타임라인이 청록 카드로 접힘
   ```
   // 흰 막대 40개, 가운데 구간만 밝게. 박자마다 높이 출렁
   S.ambient(t => bars.forEach((b, i) => {
     const h = .35 + .65 * Math.abs(Math.sin(i * .7 + t * Math.PI * 96 / 60 * .5));
     b.style.transform = `scaleY(${h})`;
   }));
   // 가운데 구간 둘레로 청록 카드가 흐림에서 맺히고, 양옆 회색 막대는 흐려지며 빠짐
   ```
4. 파형 카드 떼와 맺히는 낱말, 퍼지는 윤곽선
   - 어두운 작은 카드 10~14장을 깊이 z(0~1)로 흩어 두고 `M.place(c, x + t * v * (1 - z), y, { s: 1 - z * .5, blur: z * 5, o: 1 - z * .5 })`. 가운데 청록 카드만 z 0.
   - 낱말은 title: blur 로 왼쪽부터 맺히고, 글자 채움에 `linear-gradient(90deg, #ECEEEE, #3FB8C4, #ECEEEE)` 를 `background-clip: text` 로 깔아 위치를 0.9초에 왼쪽에서 오른쪽으로 쓸어요.
   - 엔딩은 deco rings 처럼 둥근 사각 `path` 3~4겹을 `M.draw(p, k)` 로 그리고 바깥 것일수록 0.15초씩 늦게, 크기도 조금씩 크게. 전환은 `S.tr.blur`.
