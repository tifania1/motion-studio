# 라일락 기호 맺힘 줌아웃 (제품 UI)

한 줄: 옅은 라일락 회색 위로 흐릿한 숯빛 알약 덩어리들이 떠돌다 작은 선 아이콘 하나로 맺히고, 카메라가 천천히 물러나며 그 아이콘이 버튼, 로그인 폼, 폰 화면으로 넓어진 뒤 왼쪽 정렬 두 줄 문장으로 조용히 닫혀요.

## 보는 느낌
- 바탕은 아주 옅은 회색이고, 가장자리로 갈수록 라일락빛이 살짝 돌아요. 무늬나 격자 없이 비워 둬요.
- 첫 장면은 너무 가까워서 무엇인지 알 수 없는 숯빛 덩어리 몇 개뿐이에요. 덩어리가 모여 아이콘이 되는 순간 화면이 '읽히기' 시작하고, 거기서부터 카메라가 계속 물러나며 맥락을 보여 줘요.
- 한 화면에는 주인공이 하나씩만 있어요: 덩어리 → 아이콘 → 버튼 → 폼 → 폰 → 문장 → 마크. 둘레 여백이 넉넉해요.
- UI 는 흰빛 카드에 아주 얇은 회색 테두리와 부드러운 그림자만 둬서 납작하고 밝아요.

## 색
- 라일락 회색 바탕 80 · 먹색 글자와 숯빛 덩어리 15 · 보라 4 · 초록 1.
- 바탕 #ECEBF0, 카드 #F8F8FA, 글자 #1E1E24, 흐린 글자는 먹색 58%.
- 숯빛 덩어리 #3A3A40. 가운데가 조금 밝고 결이 낀 회색으로 칠해요.
- 보라 #6B4FE0 은 '계속하기' 같은 주 버튼 하나와 마크에만 써요. 버튼 글자는 흰색.
- 초록 #34C759 은 스캔이 맞았을 때 아이콘과 체크에만 아주 잠깐 써요.

## 글자
- Geist(한글은 Noto Sans KR Medium·Bold) 한 가족만 써요.
- 버튼·폼 안 글자는 400~500, 작고 가볍게. 화면 높이의 2~3%.
- 마무리 문장은 왼쪽 정렬 두 줄이에요. 첫 줄은 짧은 머리말(500, 먹색 80%), 둘째 줄은 하고 싶은 말(700, 먹색). 화면 높이의 4.5% 안팎이고 줄 간격은 1.2. 화면 가운데보다 살짝 왼쪽에서 시작해요.
- 자간은 -0.01em 으로 아주 살짝만 좁혀요.

## 질감과 모양
- 그레인 0.05, 비네트 0.12. 비네트가 가장자리 라일락빛을 조금 더 짙게 보이게 해요.
- 숯빛 덩어리는 끝이 둥근 알약과 굽은 알약이에요. `filter: blur` 1~2px 에 안쪽 결(옅은 노이즈)을 넣어 붓으로 문지른 숯처럼 보이게 해요.
- 버튼·카드 모서리는 `--u` × 1.2, 테두리 1px 먹색 8%, 그림자는 아래로 아주 옅게 한 겹.
- 폰은 흰 화면만 보이게 테두리를 얇게 두고, 위쪽 검은 알약을 남겨요(스캔이 여기서 부풀어요).

## 움직임
- 80BPM, 느리고 끊김이 적어요. 이징은 `power2.inOut` 으로 시작과 끝을 모두 부드럽게.
- 덩어리는 처음 1초 동안 각자 천천히 떠돌고(움직임 흐림 4~6px), 이어 2.5초에 걸쳐 0.12초씩 엇갈려 제자리를 찾아요. 들어올수록 흐림이 걷혀요.
- 줌아웃은 아이콘이 맺힌 직후부터 약 5초 동안 이어지는 한 번의 긴 움직임이에요. 버튼이 다 보이는 지점에서 한 박쯤 머물렀다가 다시 물러나요.
- 스캔 아이콘은 둥근 사각 안에서 0.6초 동안 초록 선이 위아래로 훑고, 체크는 0.4초에 그어져요.
- 문장은 첫 낱말이 흐림에서 0.6초에 맺히고, 반 박 뒤 나머지가 같은 방식으로 붙어요. 그대로 3초 머물러요.

## 전환
- 덩어리부터 폰 화면까지는 전환 없이 카메라 하나로 이어요.
- 폰 화면에서 문장으로, 문장에서 마크로 넘어갈 땐 느린 페이드나 흐림 전환(S.tr.blur). 장면 쌓기: fade → blur → cut.
- 컷은 같은 화면 안 상태가 바뀔 때(로그인 폼 → 계정 화면)만 써요.

## 대표 장면

1. 덩어리가 모여 아이콘으로
   ```
   // 아이콘 획 8개를 알약 div 로 만들고, 처음엔 화면이 아이콘의 12배로 확대된 상태
   const parts = S.$$('.stroke');            // 굽은 꺾쇠 넷, 눈 둘, 코, 입
   S.ambient(t => {
     parts.forEach((p, i) => {
       const k = M.ease.inOutCubic(M.prog(t, 1 + i * .12, 2.5));
       const f = drift[i](t);                 // 떠도는 자리: sin·cos 로 천천히
       const h = home[i];                     // 아이콘 안 제자리
       M.place(p, f.x + (h.x - f.x) * k, f.y + (h.y - f.y) * k,
               {r: f.r + (h.r - f.r) * k, blur: (1 - k) * 5});
     });
   });
   ```
2. 기호에서 폰 화면까지 한 번에 물러나기
   ```
   // 아이콘·버튼·폼·폰을 모두 .cam 하나 안에 실제 크기로 짜 두고 카메라만 움직임
   S.ambient(t => {
     const s = M.anim([[0, 12], [3.8, 4, {d: 1.4, e: 'inOutCubic'}],
                       [5.8, 1.8, {d: 1.2, e: 'inOutCubic'}], [7.6, 1, {d: 1.2, e: 'inOutCubic'}]], t);
     M.place(cam, W / 2, H / 2, {s});
   });
   ```
   - 아이콘 둘레의 버튼 테두리, 폼의 입력창·보라 버튼은 카메라가 물러나며 화면에 들어올 때 투명도 0 → 1 로 살짝 늦게 켜요.
3. 검은 알약이 부풀어 스캔하고 체크
   ```
   const k = M.spring(t - 9.4, 'smooth');
   M.box(island, {w: 90 + 60 * k, h: 26 + 64 * k, r: 13 + 7 * k});
   const scan = M.prog(t, 9.8, .6);           // 초록 선이 위아래로 훑음
   M.place(scanLine, cx, cy - 20 + 40 * Math.sin(scan * Math.PI), {o: scan < 1 ? 1 : 0});
   M.draw(checkPath, M.ease.outCubic(M.prog(t, 11, .4)));
   ```
   - 체크가 다 그려진 뒤 한 박 머물고, 같은 폰 안에서 계정 화면으로 컷해요.
4. 왼쪽 정렬 두 줄 문장과 마크
   - 장면 쌓기 title: blur + align: left 로 첫 줄이 흐림에서 맺히고 둘째 줄이 굵게 붙어요. 넘어갈 땐 `S.tr.blur`.
   - 끝은 가운데 작은 마크와 이름 한 줄. 보라 마크만 색을 쓰고 이름은 먹색 700, 흐림에서 0.8초에 맺힌 뒤 3초 머물러요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: 로그인·인증 기능 소개, 보안·개인정보 업데이트, 개발 도구 새 기능 알림, 앱 기능 하나를 짧게 보여 줄 때, 차분한 제품 공지.
- 피할 것: 빠른 컷 몰아치기, 진한 색면 바탕, 손그림 선, 화면을 꽉 채운 큰 글자, 강조색 여러 개(보라 하나와 확인용 초록만).
- 오프닝 덩어리는 영상에서 다루는 기능의 아이콘으로 바꿔 지어요(자물쇠, 지문, 열쇠 같은 단순한 선 아이콘). 획이 6~10개쯤 되는 아이콘이 가장 잘 맞아요.
