# 점토빛 말풍선 원격 데스크 (제품 UI)

한 줄: 따뜻한 베이지 바탕에 차분한 세리프 두 줄로 상황을 열어요. 테라코타 부탁 말풍선이 크게 떴다가 폰 대화창 속으로 들어가고, 폰에서 손그림 고리 선이 이어지면 옆에서 데스크톱이 밀려 들어와 일을 해내는 조용한 원격 데모예요.

## 보는 느낌
- 바탕은 처음부터 끝까지 같은 베이지 하나예요. 무늬도 빛도 없이 평평해서, 그 위에 놓이는 말풍선과 기기만 눈에 들어와요.
- 사례 하나는 늘 같은 순서로 흘러가요. 세리프 두 줄로 상황을 말하고, 큰 부탁 말풍선이 뜨고, 폰 대화창이 나와요. 이어서 폰과 데스크톱이 나란히 서서 일하는 장면, 다시 폰에 결과가 쌓이는 장면이에요. 이 묶음을 사례마다 되풀이해요.
- 폰과 데스크톱이 같이 나올 때는 폰이 왼쪽 4분의 1 자리에 작게 서고, 데스크톱은 오른쪽 가장자리에서 잘린 채 화면의 절반 넘게 차지해요. 둘 사이 빈자리에 테라코타 고리 선 하나가 놓여요.
- 폰 대화창만 보여 줄 때는 폰을 화면 높이보다 크게 키워 가운데 세우고, 위아래가 살짝 잘리게 둬요.

## 색
- 베이지 70 · 기기 화면의 밝은 미색 20 · 먹색 글자 7 · 테라코타 3.
- 바탕 #D8D1C6, 글자 먹색 #2B2622, 반전 문장은 먹색 55%.
- 폰 화면·답장 말풍선은 미색 #F3EFEA 에 위쪽이 희고 아래가 아주 옅게 분홍빛으로 번지는 그라디언트를 써요.
- 테라코타 #A9533D 는 사용자 말풍선, 보내기 버튼, 고리 선에만 써요. 말풍선 속 글자는 흰색이에요.
- 데스크톱 화면 안 앱은 자기 색을 써도 괜찮아요(짙은 회색 편집기, 하늘색 바탕화면 등). 바깥 장식에는 다른 색을 들이지 않아요. 상태 점만 옅은 초록 #7FA88F 이에요.

## 글자
- 상황 문장은 고운바탕 700 두 줄, 가운데 정렬이에요. 짧은 변의 6% 안팎으로 크지 않게 쓰고, 줄 간격은 1.15예요.
- 둘째 줄은 같은 글꼴, 같은 크기에 색만 옅게 해요. 굵기 대비 대신 색 대비로 반전을 보여 줘요.
- 말풍선과 UI 글씨는 Geist + Noto Sans KR 500 이에요. 큰 부탁 말풍선은 짧은 변의 5%로 세 줄을 왼쪽 정렬하고, 폰 안 글씨는 그 3분의 1 크기예요.
- 첫 장면의 꼬리표는 짧은 변의 1.6% 산세리프를 얇은 테두리 알약에 담아요.

## 질감과 모양
- 질감은 쓰지 않아요. 매끈하고 조용하게 둬요.
- 말풍선은 모서리 2.2u 의 둥근 사각이에요. 꼬리는 없고 그림자도 없어요.
- 폰은 미색 몸체에 아주 옅은 그림자 한 겹을 주고, 모서리는 화면 너비의 12%예요. 노트북·모니터도 같은 미색 몸체에 얇은 베젤을 둘러요.
- 고리 선은 둥근 끝의 테라코타 선이에요. 두께는 짧은 변의 0.5%이고, 짧은 물결에서 고리 하나를 지나 다시 물결로 끝나요.

## 움직임
- 84BPM, 느림. 카메라와 기기는 `power3.inOut` 으로 미끄러지듯 옮겨 가고 끝에서 부드럽게 멈춰요.
- 세리프 두 줄은 아래에서 1u 떠오르며 나타나요. 둘째 줄은 첫 줄보다 0.4초 늦게 와요.
- 큰 말풍선은 크기 0.96 → 1 로 피어나고 2초쯤 머물러요. 그다음 0.9초 동안 폰 속 자기 자리로 줄어들어 옮겨 가요.
- 폰 안 답장은 아래에서 올라오며 하나씩 쌓이고, 말풍선 사이는 0.6초 간격이에요. 화면 캡처 카드는 마지막에 살짝 커지며 놓여요.
- 고리 선은 0.6초에 왼쪽에서 오른쪽으로 그어지고, 장면이 넘어갈 때 반대 방향으로 지워져요.
- 한 장면은 3~5초씩 머물러요. 글을 읽을 시간을 넉넉히 줘요.

## 전환
- 사례 사이와 문장 장면 사이는 느린 페이드로 이어요.
- 폰 대화창과 폰+데스크톱 구도 사이는 컷 없이 카메라가 이어서 움직여요. 폰이 작아지며 왼쪽으로 가고, 데스크톱은 오른쪽에서 밀려 들어와요(push).
- 데스크톱 화면 안의 앱이 바뀔 때는 컷을 써요. 장면 쌓기 순서는 fade → push → cut 이에요.

## 대표 장면
1. **세리프 두 줄 상황 문장**
   ```js
   const [l1, l2] = S.$$('.line');
   S.ambient(t => {
     const k1 = M.ease.outCubic(M.prog(t, .2, .8));
     const k2 = M.ease.outCubic(M.prog(t, .6, .8));
     M.place(l1, cx, cy - lh / 2, {y: (1 - k1) * U, o: k1});
     M.place(l2, cx, cy + lh / 2, {y: (1 - k2) * U, o: k2});   // l2 는 color: var(--onBgMuted)
   });
   ```
2. **큰 부탁 말풍선이 폰 속으로**: 말풍선 하나를 화면 가운데 크게 두고, 2초 뒤 폰 화면 안 사용자 말풍선 자리(px, py, 배율 s)로 옮겨요.
   ```js
   const k = M.ease.inOutCubic(M.prog(t, 2.4, .9));
   M.place(bubble, M.mix(cx, px, k), M.mix(cy, py, k), {s: M.mix(1, s, k)});
   M.place(phone, cx, cy + H * .05, {o: k, s: M.mix(1.08, 1, k)});   // 폰은 말풍선 둘레로 함께 나타남
   ```
   장면 쌓기에서는 frame: phone + deco: bubbles 로 폰 안에 말풍선이 차례로 쌓여요.
3. **폰 → 고리 선 → 데스크톱**: 폰을 `M.anim([[0, cx], [t0, W * .22, {d: 1, e: 'inOutCubic'}]], t)` 로 왼쪽에 보내며 배율을 0.45 까지 줄여요. 오른쪽에서는 노트북을 `x = M.anim([[0, W * 1.3], [t0 + .3, W * .72, {d: 1.1, e: 'inOutCubic'}]], t)` 로 밀어 넣어 가장자리에서 잘리게 둬요. 둘 사이 SVG 고리 path 는 `M.draw(loop, M.ease.outCubic(M.prog(t, t0 + 1, .6)))` 로 그려요. 노트북 화면 속 앱은 `M.at` 으로 컷 전환하고, 대화 상자가 열리고 닫히는 정도만 움직여요.
4. **결과 답장과 캡처 카드**: 카메라가 다시 폰으로 다가가요(`S.tr.blur` 없이 같은 장면에서 배율만 키워요). 답장 말풍선 i 를 `M.place(r, x, y_i, {o: k, y: (1 - k) * 2 * U})`, `k = M.spring(t - ti, 'smooth')` 로 쌓아요. 글은 `M.type(text, t, ti + .1, 30)` 로 써요. 마지막에 짙은 앱 캡처 카드를 같은 방식으로 띄우면 '일을 끝냈다'는 인상이 남아요.
