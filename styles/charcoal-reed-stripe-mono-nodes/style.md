# 숯빛 세로줄 고정폭 노드 (다이어그램·데이터)

한 줄: 숯빛 판에서 초록·회색 세로줄 기둥이 칸칸이 켜졌다가 가는 한 줄로 접혀요. 고정폭 꼬리표를 단 노드 상자가 가는 선으로 하나씩 이어지고, 옅은 회색 판으로 넘어가면 데이터 카드의 막대와 표가 차오르는 개발 도구 흐름 필름이에요.

## 보는 느낌
- 기본 바탕은 숯빛 #222321 이에요. 서너 장에 한 번은 옅은 회색 #ECECEA 판으로 컷해서 숨을 돌려요.
- 무늬는 세로줄 하나만 써요. 가는 세로줄을 촘촘히 세운 기둥을 초록·연두·회색으로 칠하는데, 줄 굵기는 짧은 변의 0.5%, 간격은 1%쯤이에요. 이 기둥으로 화면을 바둑판처럼 채우기도 하고, 도형 속이나 카드 귀퉁이의 작은 타일에만 채워 넣기도 해요.
- 정보는 작게 두고 여백을 넓게 남겨요. 노드 상자는 화면 너비의 15~20%이고, 1px 선으로 이어지며 마디마다 작은 네모 점이 찍혀요.
- 중간에 한 번은 카메라가 크게 물러나요. 웹페이지 시안 여러 장이 벽처럼 깔린 곳을 비스듬히 훑고 지나가요.
- 끝은 데이터 카드 한 장이나 표 한 장으로 조용히 맺고, 검은 화면으로 닫아요.

## 색
- 숯빛 70 · 회색 선과 글자 20 · 초록 10.
- 초록 #3DBE8B 는 켜짐·선택·진행에 써요. 그 밖에 연두 #9CCB8E, 회녹 #8E957F, 옅은 민트 #C9E6D6, 짙은 청록 #1F4A4F 가 있고, 이 넷은 세로줄 기둥과 막대에만 칠해요.
- 세로줄의 회색은 #5A5D58, 노드 상자 속은 바탕보다 조금 밝은 #2B2D2A 예요.
- 옅은 회색 판에서는 선과 상자를 #BDBDB6 로 아주 연하게 그리고, 글자만 숯빛으로 써요.
- 실패 표시는 코드 한 줄에만 써요. 연한 빨강 바탕 #F2D4D2 위에 글자 #B8463F 예요.

## 글자
- 꼬리표·노드 이름·코드: Geist Mono 400~500 대문자, 자간 +0.04em, 짧은 변의 1.6~2%예요. 한글은 Noto Sans KR 500 으로 써요.
- 제목과 큰 숫자: Geist 300~400 으로 가볍게 써요. 숫자는 짧은 변의 8~10%, 제목은 4~5%예요. 숫자 옆에는 아주 작은 고정폭 단위나 설명을 붙여요.
- 다이어그램은 가운데 정렬로 놓고, 카드 안 글과 장면 제목은 왼쪽 위에 맞춰요.
- 질문 같은 문장은 고정폭 대문자 두세 줄로 상자 안에 넣고, 따옴표를 쳐요.

## 질감과 모양
- 질감 없이 매끈한 평면으로 둬요. 그림자와 빛 번짐도 쓰지 않아요.
- 노드 상자: 모서리는 거의 직각(0.4u), 테두리는 1px 초록이에요. 왼쪽 가장자리에는 짧은 점선 띠가 붙어요.
- 묶음 상자: 테두리는 1px 점선이에요. 안쪽 위에 초록으로 칠한 머리 막대가 있고 거기에 숯빛 꼬리표가 들어가요. 오른쪽 귀퉁이에는 작은 아이콘을 둬요.
- 연결선은 1px이고, 마디에 짧은 변의 0.6% 크기 네모 점이 찍혀요. 갈래가 나뉘는 곳은 둥글게 꺾어요.
- 데이터 카드: 숯빛 판에 모서리 0.6u, 귀퉁이에 세로줄 바둑판 타일 하나를 둬요.

## 움직임
- 100BPM, 보통 빠르기예요. 요소가 들어올 때는 power3.out 으로 0.4초에 짧게 멈추고, 카메라 이동은 inOutCubic 으로 1.5~2초 걸려요.
- 세로줄 기둥은 칸 단위로 계단처럼 켜지고 꺼져요. 칸이 바뀔 때 중간값 없이 한 프레임에 바로 갈아 끼워요.
- 노드는 박마다 하나씩 생겨요. 순서는 테두리 그리기, 꼬리표 치기(초당 30자 안팎), 선 뻗기예요.
- 막대는 아래에서 차오르고, 안의 숫자도 같은 곡선으로 올라가요. 막대끼리는 반 박씩 늦게 출발해요.
- 장면마다 2~3초 머물러요. 나갈 때는 대부분 따로 움직이지 않고 컷으로 끝내요.

## 전환
- 기본은 컷이에요. 큰 마디는 세로줄 기둥이 화면을 칸칸이 덮었다 걷히는 와이프로 나눠요(S.tr.blocks 결). 페이지 벽 장면은 카메라를 밀어서 이어요.
- 장면 쌓기 순서: cut → wipe → push.

## 대표 장면

1. 세로줄 기둥 판이 한 줄로 접히기
   ```
   // 화면을 8×2 칸으로 나누고 칸마다 repeating-linear-gradient 세로줄, 색은 --c 로
   const cells = S.$$('.stripe-cell');
   const tone = ['#3DBE8B', '#9CCB8E', '#5A5D58', 'transparent'];
   S.ambient(t => {
     cells.forEach((c, i) => {
       const r = M.rng(i + 1)();
       const k = M.at([[0, 3], [r * .6, Math.floor(r * 3)], [M.beat(1) + r * .4, (i + 1) % 3], [M.beat(2) + r * .3, 3]], t);
       c.style.setProperty('--c', tone[k]);
     });
     // 판이 걷히면 가로 띠 하나로 오므라들어요
     const h = M.anim([[M.beat(2), H * .9], [M.beat(2.4), 2, {d: .4, e: 'inOutCubic'}]], t);
     M.box(band, {x: W * .1, y: H / 2 - h / 2, w: W * .8, h});
     label.textContent = M.type('PIPELINE / 01 OF 04', t, M.beat(3), 30);
   });
   ```
   큰 마디 사이 전환으로 쓸 때는 S.tr.blocks 를 세로 칸으로 나눠 같은 결을 내요.

2. 노드 이어 붙이기와 신호
   ```
   nodes.forEach((n, i) => {
     const t0 = M.beat(i * 2);
     M.draw(n.border, M.ease.outCubic(M.prog(t, t0, .4)));
     n.label.textContent = M.type(n.text, t, t0 + .3, 30);
     if (links[i]) M.draw(links[i], M.ease.outCubic(M.prog(t, t0 + .8, .5)));
   });
   // 선이 다 그려지면 작은 초록 네모가 선을 따라 지나가요
   const k = M.prog(t, t1, .6), L = link.getTotalLength();
   const p = link.getPointAtLength(L * M.ease.inOutCubic(k));
   M.place(pulse, p.x, p.y, {o: k > 0 && k < 1 ? 1 : 0});
   ```
   마지막 상자는 점선 묶음 상자 안에 놓아요. 묶음 상자의 초록 머리 막대는 `clipPath: inset(0 X% 0 0)` 으로 왼쪽부터 0.3초에 칠해요. 장면 쌓기에서는 frame window, card outline, title type 이 이 결을 맡아요.

3. 페이지 시안 벽 훑기
   - 웹페이지 시안 6~9장을 옅은 회색 사이 틈을 두고 격자로 깔아요. 카메라는 화면 높이의 1.6배로 물러난 상태에서 대각선으로 2초 미끄러져요: `M.place(wall, x, y, {s})`, `x = M.anim([[0, 0], [.2, -W * .35, {d: 2, e: 'inOutCubic'}]], t)`.
   - 가운데 시안 안에서는 장면 2의 작은 노드 다이어그램이 계속 돌아가요. 그래서 벽을 훑는 동안에도 초록 상자 하나가 눈을 끌어요.

4. 옅은 회색 판의 데이터 카드
   ```
   bars.forEach((b, i) => {
     const k = M.ease.outCubic(M.prog(t, t0 + i * M.beat(.5), .6));
     M.box(b, {x: x0 + i * bw * 1.25, y: base - hMax[i] * k, w: bw, h: hMax[i] * k});
     b.num.textContent = Math.round(val[i] * k).toLocaleString();
   });
   // 다음 박에 표로 컷, 한 줄만 초록으로 켜기
   row.style.background = M.color('#2B2D2A', '#3DBE8B', M.prog(t, t2, .3));
   ```
   막대 색은 짙은 청록, 회녹, 옅은 민트 순서로 칠하고, 숫자는 Geist 300 흰색(옅은 막대 위에서는 숯빛)으로 막대 위쪽 안에 넣어요. 코드 단계 목록 장면에서는 실패한 한 줄만 연한 빨강 바탕으로 깜빡이고, 다음 줄에 다시 시도하는 단계가 쳐져요.
