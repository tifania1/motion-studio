# 재질 릴과 노을 입력창 (타이포)

한 줄: 어두운 화면에 분홍 털결, 바람에 눕는 풀, 부푼 연두 글자, 화면을 꽉 채운 넓은 대문자 시안이 1~2초마다 컷으로 지나가요. 이어 아래에서 노을빛이 번지는 화면 가운데 짙은 입력 카드에 문장이 쳐졌다 고쳐지는 디자인 쇼릴이에요.

## 보는 느낌
- 영상이 두 박자로 나뉘어요. 앞쪽은 '보여 주기'예요. 화면 가득 재질 하나(털, 풀, 부푼 글자, 크롬 기호)나 포스터 시안 하나만 놓고 1~2초마다 컷으로 갈아 끼워요.
- 뒤쪽은 '만들어 보기'예요. 거의 검은 바탕 아래쪽에서 분홍·주황·파랑이 섞인 노을빛이 둥글게 번지고, 그 가운데 짙은 회색 입력 카드 하나가 떠 있어요. 카드 둘레는 넉넉히 비워 두고 빛만 깔아요.
- 시안 화면은 꽉 채워요. 넓고 굵은 대문자 두 줄이 화면 너비를 거의 다 쓰고, 네 귀퉁이에만 작은 글씨 꼬리표가 붙어요.
- 사진을 쓰는 장면에서는 인물 사진 위로 거대한 연하늘 대문자가 아래가 잘린 채 깔리고, 그 위에 작은 어두운 창(댓글, 선택 판)을 하나 띄워요.
- 끝은 다시 어두운 화면. 흐림 속 둥근 빛 고리 하나와 작은 문장 한 줄로 조용히 닫아요.

## 색
- 검정 바탕 60 · 흰 글자 15 · 노을빛과 재질 색 25.
- 바탕 #121214, 글자 #EDEDEB, 입력 카드 #202024.
- 노을빛: 가운데 분홍 #F0508C → 주황 #F27A3D, 양 끝은 파랑 #4A5CF0. 늘 화면 아래쪽에서만 올라와요.
- 재질 판은 판마다 한 색이 주인공이에요: 털 분홍 #F08FB8, 풀 초록, 부푼 글자 연두 #8FD13A, 거대 대문자 연하늘 #A8DDF0.
- 강조색(accent)은 분홍 #F0508C. 버튼·꼬리표에 쓰면 글자는 아주 짙은 자줏빛 #1A0A10.

## 글자
- 큰 글자: Archivo 가변 글꼴(한글은 Noto Sans KR Black). 굵기 800~900, 자간 −0.03em.
- 가변 너비 축을 판마다 다르게 써요. 포스터 시안은 넓게(stretch 115~125%) 두 줄로 화면을 채우고, 재질 몽타주 속 낱말은 좁게(stretch 62~70%) 세로로 길게 세워 흐림을 끌어요.
- 입력 카드 글씨: Geist·Noto Sans KR Bold, 짧은 변의 6~7%, 왼쪽 정렬 두 줄. 제목처럼 크게 써서 멀리서도 읽혀요.
- 편집 화면 느낌을 낼 땐 Instrument Serif 대문자를 얇게 몇 줄 겹쳐 굵은 고딕과 대비시켜요.
- 작은 꼬리표·설명은 Geist 400, 짧은 변의 1.5~2%.

## 질감과 모양
- 화면 자체에는 질감을 거의 넣지 않아요. 비네트 0.25 만 살짝 깔아 가장자리를 어둡게.
- 질감은 '판 안의 그림'으로 보여 줘요: 털결, 풀결, 부푼 고무 같은 덩어리 글자. 엔진에서는 그라디언트·흐림·그림자를 겹쳐 비슷한 결을 새로 만들어요.
- 입력 카드: #202024, 모서리 `--u` × 2, 아주 옅은 흰 테두리 1px(8%), 아래로 짙은 그림자. 오른쪽 아래 흰 둥근 보내기 단추, 왼쪽 아래 작은 + 기호.
- 노을빛은 흐림 큰 타원 서너 개를 겹쳐 만들어요. 다른 요소에는 빛 번짐을 넣지 않아요.

## 움직임
- 110BPM. 재질 몽타주는 2~4박마다 컷, 입력 장면은 문장이 다 쳐질 때까지 머물러요.
- 판마다 아주 느린 카메라: 4초에 1.04배 다가가거나 짧은 변의 3% 옆으로 밀려요.
- 첫 낱말과 마지막 문장은 흐림 12px에서 선명으로 0.6초, 맺히는 동안 분홍·파랑 색 번짐이 글자 가장자리에 남았다 걷혀요.
- 입력 카드 글은 초당 14~18자로 쳐지고, 한 번은 뒤쪽 4~6글자를 초당 25자로 지운 뒤 다른 말로 다시 써요. 그 사이 커서 막대가 한 박 깜빡여요.
- 카드·창은 아래에서 2u 올라오며 `power3.out` 으로 들어오고, 나갈 땐 컷.

## 전환
- 컷이 기본이에요. 재질 판 사이에는 컷 직전 한두 프레임에 흐림을 얹어 넘겨요(blur).
- 거대 대문자 장면은 글자 띠가 옆으로 흐르는 방향 그대로 밀어내기(push).
- 장면 쌓기: cut → blur → cut → push.

## 대표 장면
1. **재질 몽타주 오프닝**: 판 6~8장(털·풀·부푼 글자·압축 대문자·크롬 기호)을 겹쳐 두고 2박마다 하나만 보여요.
   ```
   const boards = S.$$('.board');
   S.ambient(t => {
     const i = M.at(boards.map((_, k) => [k * M.beat(2), k]), t);
     boards.forEach((b, k) => {
       b.style.visibility = k === i ? 'visible' : 'hidden';
       const lt = t - k * M.beat(2);
       const edge = M.prog(lt, M.beat(2) - .08, .08);         // 컷 직전 흐림
       M.place(b, W / 2, H / 2, { s: 1 + lt * .01, blur: edge * 6 });
     });
   });
   ```
   털결은 분홍 바탕에 가는 밝은 줄무늬 `repeating-linear-gradient` 를 여러 각도로 겹치고 `blur(2px)` + 느린 `M.drift`. 부푼 글자는 굵은 글자에 `text-shadow` 여러 겹(밝은 위·짙은 아래)으로 둥근 부피를 줘요.
2. **넓은 대문자 포스터 시안**: 두 줄 대문자를 `font-stretch: 125%`, 굵기 900, `scenes.scale` 1.3 으로 꽉 채우고, 뒤에 파랑 빛 반원 하나(`S.fx` 빛 고리, 흐림 3u). 네 귀퉁이 작은 꼬리표는 0.1초씩 늦게 `M.spring(t - ti, 'smooth')` 로 들어와요. 장면 쌓기에선 title: blur 로 큰 글이 흐림에서 맺혀요.
3. **노을 입력 카드와 고쳐 쓰기**:
   ```
   // 바탕: 아래 가운데 분홍·주황, 양끝 파랑 타원을 흐려 겹침 (scenes.bg aurora 와 같은 결)
   const full = '첫 문장 + 다른 끝말';
   S.ambient(t => {
     const a = M.type(문장A, t, 1.0, 16);                  // 처음 쳐짐
     const del = Math.floor(M.prog(t, 3.2, .25) * 5);       // 뒤 5글자 지움
     const b = M.type(바꿀말, t, 3.8, 16);                  // 다시 씀
     field.textContent = t < 3.2 ? a : t < 3.8 ? 문장A.slice(0, -del || undefined) : 문장A.slice(0, -5) + b;
   });
   const cur = new M.Cursor(stage);                       // 커서가 보내기 단추로 와서 누름
   M.cursorAt(cur, sendBtn, t, 5.2);
   ```
   누른 다음 박에 카드를 `M.box` 로 넓혀 시안 썸네일 세 장이 든 선택 판으로 바꿔요.
4. **거대 대문자 위 댓글 창**: 인물 사진 바탕에 연하늘 대문자 띠를 아래가 잘리게 두고 `x = M.anim([[0, 0], [8, -W * .25, {d: 8, e: 'linear'}]], t)` 로 아주 천천히 흘려요. 그 위 어두운 창 안에 이름표 단 말 한 줄씩 `M.spring` 으로 쌓고, 입력칸에 `M.type`. 다음 컷(`S.tr.blur` 또는 push)에서 시안 색을 바꿔 보여 줘요.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 디자인·웹사이트 제작 도구 런칭, 크리에이티브 스튜디오 쇼릴, 포트폴리오·시안 모음 소개, 협업 피드백 기능 소개. 40~60초 길이에 잘 맞아요.
- 피할 것: 밝은 흰 바탕이 길게 이어지는 장면, 손그림 선과 종이 질감, 한 화면에 긴 문단, 노을빛 말고 다른 그라디언트 섞기, 느린 서서히 전환만 이어 쓰기.
- 한글 큰 글자는 2~4자 낱말을 넓게 펴서 쓰면 포스터 시안 결이 살아요.
