# 배지 박힌 거대 글자 (타이포)

한 줄: 연두에서 버터색으로 번지는 바탕에 톱니 배지 속 숫자가 굴러 오르고, 배지가 문장 맨 앞에 박혀요. 화면을 꽉 채운 흰 글자 벽을 카메라가 훑다가 확 빠지는 연말 결산 타이포.

## 보는 느낌
- 바탕은 처음부터 끝까지 부드러운 그라디언트 하나(왼쪽 위 민트 → 오른쪽 아래 연노랑). 그 위에 글 한 줄이나 배지 하나만 놓여서 아주 가볍게 보여요.
- 두 가지 글 크기를 크게 오가요. ① 화면 높이 4~5% 짜리 한 줄 문장(먹색), ② 화면 높이 1/4 을 넘는 거대한 흰 글자 벽(반투명 흰색, 화면 밖으로 잘림).
- 숫자는 늘 톱니처럼 둥글게 파인 배지 안에 있어요. 배지는 문장 속 낱말 하나처럼 줄에 끼어 흘러가요.
- 중간에 딱 한 번, 같은 배지를 두툼하게 세운 입체 조각들이 연보라 바탕 위로 쏟아지는 장면이 있어요. 끝은 초록 막대 더미가 납작하게 눌려 작은 스티커가 돼요.

## 색
- 그라디언트 바탕 70 · 흰 큰 글자 15 · 먹색 문장 8 · 초록 배지 7.
- 바탕: 민트 #A8EBA6 → 연두 #C4EBA4 → 버터 #E9F0B0. 아주 옅은 크림(#F5F7EE)으로 끝나는 쪽도 있어요.
- 문장 글자는 짙은 초록빛 먹색 #17301A. 큰 글자 벽은 흰색 85%(바탕이 살짝 비침).
- 배지: 진초록 #2E9A3E 바탕 + 흰 숫자, 또는 연노랑 #E9F0A0 바탕 + 먹색 숫자. 한 화면에 두 종류까지.
- 입체 장면만 연보라 #8E86E8 → 세이지 그라디언트. 다른 장면에는 보라를 쓰지 않아요.

## 글자
- Geist(한글 Noto Sans KR Bold), 둥글고 기하학적인 산세리프 느낌. 문장은 600~700, 큰 글자 벽은 700.
- 한 줄 문장: 짧은 변의 4.5%, 자간 −0.01em. 인용 구절만 기울임(Geist 는 기울임이 없으니 `transform: skewX(-10deg)`)으로 바꿔 강조해요.
- 큰 글자 벽: 짧은 변의 25~30%, 자간 −0.03em, 줄 간격 0.95. 줄마다 낱말이 끊긴 채 반복돼서 문장으로 읽히기보다 무늬처럼 보여요.
- 배지 속 숫자: 굵기 800, 배지 지름의 45%, 고정폭 숫자(`font-variant-numeric: tabular-nums`).

## 질감과 모양
- 그레인 0.08 아주 옅게. 그 밖의 질감 없음.
- 톱니 배지: 꼭짓점 7~8개 별을 둥글게 다듬은 모양(SVG path, 바깥 반지름 1, 안쪽 0.86, 꼭짓점마다 둥근 이음). 그림자 없음.
- 메시지 말풍선 하나(첫 장면): 흰 카드, 모서리 `--u` × 1.4, 아주 옅은 그림자.
- 입체 조각: 배지·동전 모양을 두께 짧은 변의 3~4% 만큼 세운 것, 옆면은 앞면보다 한 단계 진한 초록.
- 끝의 막대: 둥근 모서리 초록 그라디언트 막대(진초록 → 연두), 높이 짧은 변의 4%.

## 움직임
- 108BPM, 보통. 대부분 `power3.out`, 넘침 없음.
- 배지 등장: 카메라가 커다란 별 모양 배지 구멍을 두세 겹 통과하며(1.5초) 들어가고, 가운데 남은 배지 안 숫자가 0.4초에 굴러 올라요(208 → 236 처럼).
- 배지가 노랗게 바래며 작아져 왼쪽으로 가는 동안 그 뒤에 낱말이 초당 30자로 한 글자씩 찍혀요. 줄 전체도 같이 작아지며 가운데를 지켜요.
- 문장 갈아 끼우기: 배지가 톡 사라지고 낱말 사이가 벌어지면(0.2초) 빈 자리에 다음 문장의 낱말이 들어와 채워요. 줄은 계속 왼쪽으로 천천히 흘러요.
- 큰 글자 벽: 카메라가 벽 위를 왼쪽 위로 비스듬히 훑어요(초당 화면 폭의 10% 안팎, 2.5초). 그동안 배지 숫자는 0.3~0.4초마다 바뀌어요. 마지막 0.2초에 확 빠지며(축소) 벽 전체가 드러나요.
- 입체 조각은 움직임 흐림을 달고 0.8초 동안 쏟아진 뒤 동전 더미로 쌓이고, 막대 더미로 바뀌어 위아래로 눌려 작아져요.

## 전환
- 확대로 들어가기(zoom): 말풍선 → 별 모양 구멍 통과 → 배지.
- 컷: 큰 글자 벽이 확 빠진 직후 입체 장면으로.
- 한 줄 흐름(push): 문장이 옆으로 흘러 다음 문장이 됨.
- 장면 쌓기: zoom → cut → push.

## 대표 장면
1. **톱니 배지 숫자가 문장 맨 앞으로**
   ```
   // 별 구멍 통과: 배지 path 를 큰 테두리로 3겹, scale 을 시간차로 키움 (0.3초씩 어긋남)
   rings.forEach((r, i) => M.place(r, S.W / 2, S.H / 2, {s: Math.pow(6, M.prog(t, t0 + i * .3, 1.2)), o: 1 - M.prog(t, t0 + i * .3 + 1, .2)}));
   S.fx.num(numEl, t0 + 1.2, .4, 236, {kind: 'odometer'});
   // 배지 크기·자리: 가운데 큰 배지 → 줄 맨 앞 작은 배지
   const k = M.spring(t - t1, 'smooth');
   M.place(badge, M.lerp(S.W / 2, lineLeft, k), S.H / 2, {s: M.lerp(1, .32, k)});
   badgeFill.style.fill = M.color('#2E9A3E', '#E9F0A0', k);
   rest.textContent = M.type('번의 회의, 2025년', t, t1 + .1, 30);
   ```
2. **흰 글자 벽 훑기**
   ```
   // 벽: 흰 글자 줄 6~8개(낱말 반복, 줄마다 시작점을 어긋나게), 낱말 사이 배지 span. 벽은 화면의 3배 크기
   M.camera(wall, M.lerp(x0, x1, M.prog(t, t2, 2.5)), M.lerp(y0, y1, M.prog(t, t2, 2.5)),
            M.anim([[0, 1], [t2 + 2.4, .3, {d: .2, e: 'inCubic'}]], t));   // 끝에 확 빠짐
   badges.forEach((b, i) => b.textContent = M.at(seq[i].map((v, j) => [t2 + j * .35, v]), t));
   ```
   - 장면 쌓기에서는 scenes.deco 의 ticker 가 이 결을 작게 따라가요. 큰 글 장면은 scale 1.4 로 넘치게.
3. **한 줄 흐름과 인용 구절**
   - 문장을 `S.words` 로 쪼개고 줄 전체 x 를 `M.lerp(S.W * .6, -S.W * .4, M.prog(t, t3, 3))` 로 왼쪽으로 흘려요. 인용 구절이 가운데 오면 흐름을 `M.spring` 으로 멈춰 1박 머묾.
4. **입체 조각 → 막대 더미 → 스티커**
   - 조각은 같은 배지 path 를 6~8장 겹쳐 z 방향으로 0.4u 씩 밀어 두께를 만들고(옆면 색은 한 단계 진하게), 부모에 `perspective`. 0.8초 동안 화면 밖에서 쏟아지게 하고 이동 중 `blur` 3~6px.
   - 끝: 초록 막대 8~10개를 `M.box` 로 세로로 쌓았다가 높이를 `M.anim` 으로 1/3 로 눌러 세 줄만 남기고, 흰 둥근 사각 스티커 위에 이름 글자를 얹어 살짝 기울여(rot −4°) 마무리.

## 어울리는 곳 / 피할 것
- 어울림: 연말 결산·사용 통계, 앱 리포트·회고, 성과 공유, 커뮤니티 연말 인사. 숫자가 서너 개 있는 15~20초 영상.
- 피할 것: 어두운 바탕, 세리프, 사진 위주 장면, 글리치·번쩍임. 배지 색은 초록·연노랑 두 가지로만.
- 영상 속 로고와 스티커 모양은 따라 하지 않고, 배지가 문장 속 낱말이 되는 구성과 큰 글자 벽을 훑는 카메라만 가져와요.
