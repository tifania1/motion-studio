# 옅은 회색 위 두 빛 유리 구슬 (제품 UI)

한 줄: 옅은 회색 바탕 한가운데 붉은 주황과 하늘빛이 맴도는 젖빛 유리 구슬이 숨 쉬고, 구슬에서 설정 카드·대화창·가지 친 흐름도·알약 낱말이 차례로 피어나는 차분한 AI 런칭이에요.

## 보는 느낌
- 바탕은 거의 고른 옅은 회색이에요. 화면에는 늘 한 가지만 가운데에 두고 둘레는 넉넉히 비워요.
- 주인공은 유리 구슬이에요. 젖빛 유리 속에서 붉은 주황과 하늘빛이 반씩 맞물려 천천히 돌아요. 크게 떴다가 작아져 대화창의 작은 머리말이 되기도 하고, 점으로 오므라들어 다음 장면으로 넘어가는 문이 되기도 해요.
- UI 는 흐린 흰 카드예요. 설정 칸 몇 장, 말풍선 몇 줄, 가는 선으로 이은 카드 가지 그림처럼 작고 성기게 놓여요. 글씨가 작아서 읽기보다 분위기로 보여요.
- 중간에 한 번 어두운 화면이 끼어요. 검은 바탕에 작은 점이 고르게 깔리고, 가운데 푸른 빛 덩어리가 번졌다 사그라들어요. 밝은 회색 흐름 사이 숨 고르기 같은 장면이에요.
- 숫자를 자랑할 땐 카메라가 구슬 속으로 들어가 구슬 색이 화면을 채우고, 그 위에 흰 숫자가 화면을 넘게 커져요.

## 색
- 회색 바탕 70 · 흰 카드 15 · 먹색 글자 8 · 구슬 색(붉은 주황·하늘빛) 7.
- 바탕 #DCDCDC, 카드 #F2F2F1(테두리는 흰색 60%, 아주 옅은 그림자 하나), 글자 #1C1C1C.
- 구슬: 붉은 주황 #C9482A → 살구 #E8946E → 젖빛 흰색 → 하늘빛 #8FB2DA → 회청 #6E86A8.
- 어두운 장면: #0D0F12 바탕, 점은 흰색 35%, 빛 덩어리는 #4C8CD8 계열.
- 보낸 말풍선 하나만 아주 옅은 민트 #D6F0CF 로 칠해 주고받는 쪽을 가려요. 그 밖에 색은 구슬 두 빛만 써요.
- 강조(accent)는 붉은 주황 #C9482A, 그 위 글자는 흰색.

## 글자
- 산세리프 하나만(Geist, 한글은 Noto Sans KR Medium). 굵기 500, 자간 −0.01em.
- 크기는 작고 고르게. 문장은 화면 높이의 2.5~3.5%, 카드 속 글은 1.5% 안팎. 큰 글자는 숫자 장면에서만 화면 높이의 80% 넘게 써요(Geist 300, 흰색).
- 알약 낱말과 꼬리표는 가운데 정렬 한 줄. 줄 간격 1.4.
- 엔딩 이름은 굵기 700, 그 아래 주소는 아주 작게 옅은 먹색.

## 질감과 모양
- 질감 없이 매끈하게 둬요. 깊이는 흐림으로만 내요(멀리 있는 카드는 2~4px 흐림).
- 카드 모서리 `--u` × 1.2, 알약은 끝까지 둥글게. 테두리는 흰 1px, 그림자는 짧고 옅게 한 겹.
- 구슬은 겹친 원형 그라디언트에 젖빛 흐림을 얹고 가장자리만 살짝 밝게 해 유리처럼 보이게 해요.
- 동심원과 흐름도 연결선은 1px 먹색 15~20%.

## 움직임
- 92BPM, 느림. 들어올 땐 `power2.out`, 구슬은 `sine.inOut` 으로 숨 쉬어요.
- 카드는 아래에서 1~2u 올라오며 흐림이 걷히고, 다음 카드는 한 박 늦게 와요.
- 흐름도는 카메라가 아주 천천히 비스듬히 미끄러지며 훑어요(4초에 화면 너비의 8%).
- 장면마다 2~4초 머물러요. 나갈 땐 따로 움직이지 않고 다음 장면 전환에 맡겨요.

## 전환
- 원형 닫힘·열림(iris)이 기본이에요. 구슬이 점으로 오므라들며 화면이 닫히거나, 구슬이 커지며 그 속이 다음 장면이 돼요.
- 그 밖엔 느린 페이드와 흐림 전환. 장면 쌓기: iris → fade → blur.

## 대표 장면
1. **숨 쉬는 유리 구슬**: 원 하나에 `radial-gradient` 두 겹(붉은 주황은 왼쪽 아래, 하늘빛은 오른쪽 위)을 쌓고 `filter: blur(.6u)`, 위에 흰 반투명 하이라이트 한 겹.
   ```
   S.ambient(t => {
     M.place(orb, cx, cy, {s: 1 + Math.sin(t * Math.PI / 2) * .04});
     orb.style.setProperty('--a', (t * 18) + 'deg');   // 안쪽 두 빛이 천천히 맞물려 돎
   });
   ```
2. **구슬이 점으로 닫혀 어두운 점 격자로**: 구슬 크기를 `M.anim([[0, 1], [tB - .9, .08, {d: .9, e: 'inOutCubic'}]], t)` 로 줄이는 동안 바탕에 짙은 회색 `radial-gradient` 비네트를 0 → 1 로 올려요. 이어 `S.tr.iris` 로 검은 장면을 열고, 점 격자(SVG 점 반복) 가운데 푸른 빛 덩어리를 `M.drift` 로 천천히 흘리며 크기만 숨 쉬게 해요.
3. **구슬 머리말 대화창과 가지 친 카드**: 말풍선 i 를 `M.place(b, x, y_i, {o: k, blur: (1 - k) * 3})`, `k = M.spring(t - ti, 'smooth')`. 받는 쪽 말풍선 옆엔 작은 구슬을 달아요. 흐름도는 카드들을 먼저 놓고 연결선을 `M.draw(path, M.prog(t, t0, .6))` 로 위에서 아래로 그은 뒤, 판 전체를 `M.anim` 으로 비스듬히 아주 천천히 밀어요.
4. **알약 낱말 계단과 막대 벌어짐 엔딩**: 새 알약이 가운데 `M.spring` 으로 뜨면 앞 알약들은 `y -= 3u`, `x -= 4u`, `s *= .85` 로 한 칸씩 비스듬히 밀려 세 칸 계단이 돼요. 엔딩은 가운데 1px 세로 막대 둘을 겹쳐 두고 `x = M.anim([[t0, 0], [t0, ±W * .2, {d: .8, e: 'inOutQuart'}]], t)` 로 벌리면서, 이름을 `clipPath: inset(0 X% 0 X%)` 로 가운데부터 드러내요. 주소 한 줄은 한 박 늦게 페이드.

## 어울리는 곳 / 피할 것
- 어울리는 곳: AI 상담·음성 에이전트 런칭, 대화형 서비스 기능 소개, 다국어·통역 기능 자랑, 설정이 단순한 개발 도구, 차분한 B2B 제품 영상.
- 피할 것: 빠른 컷 몽타주, 굵고 큰 제목 여러 줄, 강조색 여러 개(붉은 주황 하나와 하늘빛 보조만), 손그림·종이 질감, 흰 바탕에 진한 그림자.
- 구슬은 영상 전체를 잇는 실이라 장면이 바뀔 때마다 한 번씩 다시 나오게 해 주세요.
