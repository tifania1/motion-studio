# 모션 스튜디오

**문구와 사진을 입력하면 릴스·쇼츠·피드·유튜브용 모션 그래픽 광고를 한 번에 제작하는 Windows 앱입니다.**<br>
여러 광고 계정의 색·글꼴·로고·말투를 계정별로 관리하고, 하나의 영상을 네 가지 화면 비율로 출력합니다.

<sub>Windows 앱 · Claude 기반 문구·구성 작성 · HTML + GSAP 엔진 · MP4 / PowerPoint / PDF 출력</sub>

## 주요 기능

- **광고 영상 제작**: 상황(신메뉴, 세일, 매장 오픈, 채용, 회사 소개 등)을 선택하고 문구와 사진을 입력하면 미리보기가 즉시 재생됩니다. **MP4 만들기**로 업로드용 영상을 출력합니다.
- **네 가지 화면 비율**: 9:16(릴스·쇼츠·틱톡), 4:5(인스타그램 피드), 1:1, 16:9(유튜브)를 동시에 제작합니다. 플랫폼 UI가 가리는 영역(세이프존)을 미리보기에서 확인할 수 있습니다.
- **Claude 연동**: 알릴 내용을 입력하면 브랜드 말투에 맞춘 문구 초안을 작성합니다. 광고에 사용 가능한 무료 사진을 검색하고, 영상과의 적합도를 점수로 평가합니다.
- **스타일 라이브러리 180종**: 프로덕트 모션 사례에서 추출한 색·글꼴·질감·움직임을 영상에 적용합니다.
- **발표 자료**: 슬라이드를 넘길 때마다 요소가 모션으로 등장하는 16:9 발표 자료를 제작합니다. 편집 가능한 PowerPoint(애니메이션·모핑 전환 포함)와 PDF로 내보낼 수 있습니다.
- **음악·업로드**: Google Gemini로 영상 길이와 박자에 맞는 배경음악을 생성합니다. 유튜브 제목·설명·해시태그를 정리하고 연결된 채널에 바로 업로드합니다.

## 설치

**요구 사항**: Windows 10/11, 인터넷 연결, Claude 계정(Claude Code 로그인 또는 Claude API 키)

1. 이 페이지 상단의 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 해제합니다.
2. 압축을 푼 폴더에서 `installer\Install_MotionStudio.cmd`를 실행합니다.
   "Windows의 PC 보호" 창이 나타나면 **추가 정보 → 실행**을 선택합니다.
3. 설치 중 질문에는 Enter(기본값)로 진행합니다. 최초 설치에는 10~20분 정도 소요됩니다.

설치가 완료되면 `문서\motion-studio`에 프로그램이 설치되고, 바탕화면에 바로가기 두 개가 생성됩니다.

- **모션 스튜디오**: 화면으로 사용하는 앱
- **모션 스튜디오 (Claude Code)**: 대화형으로 작업을 지시하는 Claude Code

설치 스크립트가 Claude Code, Python, ffmpeg, 렌더링용 Chromium을 자동으로 설치합니다. Google Gemini API 키는 음악 자동 생성에만 필요하며, 키가 없는 경우 Gemini 앱에서 무료로 생성한 곡을 앱에 끌어다 놓아 사용할 수 있습니다. API 키는 해당 PC의 사용자 폴더(`.motion-studio`)에만 저장됩니다.

## 자동 업데이트

앱 실행 시 이 저장소의 최신 버전을 확인하고, 새 버전이 있으면 자동으로 적용한 뒤 **"새 버전으로 업데이트했어요"** 창에 변경 사항을 표시합니다.

- 적용 전에 기존 파일을 백업하며, 새 버전에서 앱이 실행되지 않으면 이전 버전으로 자동 복구합니다.
- 프로그램 파일만 교체합니다. 광고 계정, 영상, 결과물, API 키는 변경하지 않습니다.
- 사용자가 직접 수정한 파일은 새 버전에서 해당 파일이 변경되지 않은 경우 그대로 유지합니다.
- 인터넷에 연결되어 있지 않으면 현재 버전으로 실행합니다. 자동 업데이트를 끄려면 사용자 폴더 `.motion-studio\update`에 `off`라는 빈 파일을 만듭니다.

```
python tools/update.py --check      새 버전 확인
python tools/update.py --rollback   직전 버전으로 복구
```

## Claude Code 사용 예시

바탕화면의 **모션 스튜디오 (Claude Code)**를 실행한 뒤 다음과 같이 지시합니다.

```
/new-brand 민트 필라테스. 로고는 바탕화면 mint-logo.png, 말투는 친근한 해요체
/new-ad 민트 필라테스 10월 체험 수업 1회 무료, 릴스와 피드용
/ad-review mint-oct-trial
/render-mp4 mint-oct-trial all
/music mint-oct-trial 밝고 경쾌한 분위기
/new-deck 3분기 성과 보고, 자료는 바탕화면 실적보고.pptx
```

슬래시 명령 없이 "하루한잔 겨울 신메뉴 광고 영상 만들어 줘"와 같이 자연어로 지시할 수도 있습니다.

## 유의 사항

- 사진은 직접 촬영한 사진, CC0·퍼블릭 도메인, CC BY(화면에 출처 표기)만 사용합니다. 광고에 사용할 수 없는 라이선스(BY-SA, NC, ND)는 제외합니다.
- "최고·1위·100%" 등 근거 없는 표현과 임의로 작성한 후기·평점이 포함되지 않도록 점검합니다.
- Gemini 음악 생성처럼 비용이 발생하는 기능은 실행 전에 예상 비용을 표시하고 확인을 받습니다.
- 필름 템플릿은 60fps와 모션 블러를 적용하므로 20초 영상 기준 렌더링에 약 10분이 소요됩니다.
- PowerPoint 글꼴 포함 기능은 PowerPoint가 설치된 PC에서만 동작합니다.
