# 올리기 (유튜브·인스타그램)

앱에서 영상을 고르고 **올리기** 탭을 열면 됩니다.

## 1. 올릴 글

- **유튜브 제목·설명, 인스타 캡션, 해시태그**를 적습니다. 비워 두면 영상 문구로 채워져요.
- **Claude에게 맡기기**를 누르면 브랜드 말투와 영상 문구를 보고 제목·설명·캡션·해시태그 초안을 써 줘요. "이 글로 채우기"로 넣은 뒤 고치면 됩니다.
- 사진 출처(CC BY)와 "협찬·유료 광고" 표시는 설명·캡션 끝에 자동으로 붙어요.
- 인스타그램은 해시태그를 한 게시물에 5개까지만 쓸 수 있어서 앞의 5개만 들어가요. 유튜브는 15개까지 넣어요.
- **이 계정 공통**에 공통 해시태그와 "설명·캡션 끝에 늘 붙일 말"을 적어 두면 그 계정의 모든 영상에 쓰여요(brand.json 의 `social`).

## 2. 업로드 안내 묶음 (유튜브·인스타 모두)

**안내 만들기**를 누르면 `out/<영상>/upload/` 에 이런 것이 생기고 브라우저로 안내 페이지가 열려요.

| 폴더 | 들어 있는 것 |
| --- | --- |
| `shorts/` | 9:16 MP4, 커버 장면, 문구.txt |
| `youtube/` | 16:9 MP4, 썸네일 1280×720 (2MB 이하 JPG), 문구.txt |
| `reels/` | 9:16 MP4, cover.jpg, 문구.txt |
| `feed/` | 4:5(없으면 1:1) MP4, cover.jpg, 문구.txt |
| `upload.html` | 플랫폼별 영상·커버 미리보기, 복사 버튼, 체크리스트, 올리러 가는 링크 |

- 커버는 "커버로 쓸 장면(초)"의 화면이에요. 비워 두면 영상 길이의 30% 지점을 써요.
- MP4가 없는 형식은 글과 커버만 들어가요. 오른쪽 아래 **MP4 만들기**로 먼저 뽑아 두세요.

## 3. 유튜브에 바로 올리기

구글이 공식으로 열어 둔 YouTube Data API 로 올려요. PC마다 한 번 준비하고, 계정(브랜드)마다 채널을 연결합니다.

### PC마다 한 번: OAuth 클라이언트 만들기

1. [구글 클라우드 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다(이름 예: motion-studio).
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 찾아 "사용"을 누릅니다.
3. **OAuth 동의 화면**: 사용자 유형 "외부", 앱 이름·이메일을 적고, 테스트 사용자에 내 구글 계정을 넣습니다.
   그다음 게시 상태를 **프로덕션으로 푸시**합니다. 테스트 상태로 두면 연결이 7일마다 끊겨요.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**, 애플리케이션 유형 **데스크톱 앱** → 만들기 → JSON 다운로드.
5. 앱의 올리기 탭에서 **JSON 파일 넣기**로 그 파일을 넣습니다. 파일은 사용자 폴더의 `.motion-studio/youtube_client.json` 에 저장되고 프로젝트 폴더에는 남지 않아요.

### 계정마다: 채널 연결

- **유튜브 채널 연결**을 누르면 브라우저가 열려요. 그 계정에 쓸 유튜브 채널(브랜드 계정)을 고르고 허용을 누르면 됩니다.
- "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (앱 이름)(으)로 이동**을 누르세요. 내가 만든 앱이라 괜찮아요.
- 연결 정보는 `.motion-studio/youtube/<브랜드>.json` 에 저장돼요. 계정마다 다른 채널을 연결할 수 있어요.

### 올리기

- 쇼츠(9:16)와 가로 영상(16:9)마다 공개 범위를 고르고 **올리기**를 누르면 MP4를 올리고, 가로 영상은 썸네일도 올려요.
- 올린 영상 주소는 video.json 의 `upload.done` 에 남고, 올리기 탭에 링크로 보여요.

### 알아 둘 것

- 구글 검수(감사)를 받지 않은 프로젝트로 올린 영상은 유튜브가 **비공개로만** 올려요. 올린 뒤 유튜브 스튜디오에서 공개로 바꾸면 돼요.
  바로 공개로 올려야 하면 구글에 YouTube API 서비스 감사(Audit)를 신청해 통과하면 풀려요.
- API로 올리는 건 하루 100번까지예요. 광고 영상을 올리기엔 넉넉해요.
- 맞춤 썸네일은 채널 전화번호 인증이 돼 있어야 올라가요. 쇼츠는 썸네일을 API로 바꿀 수 없어서 유튜브 앱·스튜디오에서 장면을 고릅니다.
- 협찬·유료 광고면 유튜브 스튜디오의 "유료 프로모션 포함"도 체크하세요.

## 4. 인스타그램

인스타그램 자동 업로드(Instagram Graph API)는 프로페셔널(비즈니스·크리에이터) 계정, Meta 개발자 앱, 페이스북 페이지 연결이 필요하고,
PC에 있는 파일을 바로 올리려면 Facebook 로그인 방식으로 앱을 만들어야 해요. 그래서 지금은 **안내 묶음**으로 올립니다.

- 휴대폰: 안내 묶음의 `reels/` 영상과 `cover.jpg` 를 휴대폰으로 옮겨(구글 드라이브, 카카오톡 나에게 보내기 등) 인스타 앱에서 릴스로 올리고 캡션을 붙여 넣어요.
- PC: instagram.com → 만들기 → 영상 선택. 9:16 영상은 릴스로 올라가요. 커버는 "커버 편집 → 카메라 롤에서 추가"로 cover.jpg.
- 협찬·제휴 광고면 "유료 파트너십 레이블"을 켜세요.

나중에 Meta 개발자 앱을 준비하면 인스타 자동 업로드도 같은 방식(계정마다 연결)으로 붙일 수 있어요.

## 명령줄

```
python tools/upload.py text <영상>                         # 플랫폼별 최종 글과 확인할 점
python tools/upload.py kit <영상>                          # 안내 묶음 만들기
python tools/upload.py youtube-client <client_secret.json>
python tools/upload.py youtube-connect <브랜드>
python tools/upload.py youtube-upload <영상> [tall|wide] [--privacy private|unlisted|public]
```
