# 영상 설정과 템플릿 항목

## video.json 공통

| 항목 | 뜻 |
|---|---|
| `title` | 영상 이름 (HTML 제목) |
| `brand` | `brands/` 아래 폴더 이름 |
| `template` | `promo`, `kinetic` 등 `templates/` 아래 폴더 이름. 직접 짠 HTML을 쓰면 대신 `src` |
| `src` | 직접 짠 HTML 파일. 형식마다 다르면 `{"tall": "tall.html", "wide": "wide.html"}` (예: `videos/bax-bangkok`) |
| `fps` | 기본 30 |
| `formats` | `tall`(1080×1920), `portrait`(1080×1350), `square`(1080×1080), `wide`(1920×1080) 중 고름 |
| `safe` | 형식별 세이프존. `{"tall": "reels"}` / `stories` / `shorts` / `feed` / `wide` / `none` / 직접 `{"top":..}` |
| `assets` | 이미지 키 → 파일(영상 폴더 기준). 형식마다 다르면 `{"common": {...}, "tall": {...}}` |
| `content` | 템플릿이 읽는 문구와 설정 (아래) |
| `music` | 배경음악 (앱이 씀). `{"file": "music.mp3", "volume": 0.8, "fadeIn": 0.5, "fadeOut": 2.5, "start": 0}` |
| `brief` | Claude에게 문구를 맡길 때 쓴 요청 메모 (영상에는 안 나옴) |
| `target` | 앱에서 고른 목표 길이(초). Claude 문구 초안을 이 길이에 맞춤 |

브랜드 이미지(`brand.json` 의 `assets`)도 같은 키 공간에 들어갑니다. 예: `brand.mascot: "front"` → `assets.front`.

공통 content 옵션: `progress: false`(아래 진행 막대 숨김), `poster: 3.2`(미리보기 표지로 쓸 초), `mascot: false`(마스코트 빼기), `ctaMascot: false`.

## promo (사진형)

훅 → 사진 장면(여러 개) → 장점 → 숫자 → CTA. 장점·숫자는 빼도 됩니다.

```json
{
  "hook": { "kicker": "이번 주 새 원두", "headline": "오늘의 첫 잔,\n천천히 내려 드려요", "highlight": "천천히", "sub": "" },
  "visuals": [
    { "image": "pour", "title": "매일 아침\n직접 내리는 라떼", "sub": "우유 거품까지 손으로",
      "credit": "Photo: 저작자 · CC BY 2.0", "focus": [0.55, 0.5], "pan": "left", "badge": "01" }
  ],
  "benefits": { "title": "하루한잔이\n다른 점", "items": ["주문하면 그때 원두를 갈아요", "..."] },
  "proof": { "number": 7, "suffix": "일", "label": "로스팅 후 이 기간 안에\n쓰는 원두만 내려요",
             "from": 0, "plain": false, "decimals": 0, "count": true },
  "cta": { "headline": "이번 주말,\n첫 잔은 하루한잔", "button": "매장 위치 보기", "sub": "@haru.roastery" },
  "durations": { "hook": 3, "visual": 2.6, "benefits": 3.2, "proof": 2.4, "cta": 3.4 },
  "transitions": { "visual": "push", "benefits": "wipe", "proof": "zoom", "cta": "iris" }
}
```

- `highlight`: 헤드라인 안의 구절에 형광펜 효과
- `focus`: 사진에서 꼭 보여야 할 지점(0~1). 9:16은 좌우가 많이 잘리니 꼭 확인
- `pan`: 사진이 천천히 움직이는 방향 (`left` 또는 기본 오른쪽)
- `proof.plain`: 1932처럼 쉼표 없는 숫자, `from`: 카운트 시작값, `count: false`: 카운트 없이 그대로
- 전환 종류: `push`, `wipe`, `zoom`, `iris`, `blades`(6장 조리개), `flood`(검은 원이 덮었다 오므라듦), `fade`, `cut`
- 기본 길이: 사진 3장 기준 약 20초

## kinetic (글자형)

짧은 문장 장면(beats)을 차례로 보여 주고 CTA로 끝납니다. 장면마다 색 조합이 바뀝니다.

```json
{
  "beats": [
    { "text": "이번 주말\n딱 이틀만", "highlight": "이틀만" },
    { "kicker": "주말 이벤트", "text": "원두 200g 사시면\n드립백을 하나 더 드려요", "highlight": "하나 더" },
    { "number": 200, "suffix": "g", "sub": "한 봉만 사셔도 받을 수 있어요", "count": false },
    { "text": "이렇게 받아 가세요", "items": ["원두 200g 고르기", "계산할 때 말씀해 주기"] }
  ],
  "cta": { "headline": "이번 주말,\n하루한잔에서 만나요", "button": "매장 위치 보기", "sub": "" },
  "schemes": ["dark", "accent", "dark", "paper"]
}
```

- 장면 종류(`type`)는 자동으로 정해집니다: `number` 가 있으면 숫자, `items` 가 있으면 목록, 18자 이하면 `big`(단어가 쾅쾅 박힘), 길면 `line`(형광펜)
  직접 `"type": "big" | "line" | "number" | "list"` 로 정해도 됩니다.
- `highlight`: big 에서는 그 단어 색이 바뀌고, line 에서는 형광펜
- 숫자 장면: `prefix`(예: "최대"), `suffix`, `from`, `plain`, `decimals`, `count`
- `scheme`: `dark`(브랜드 배경), `accent`(강조색 바탕), `paper`(밝은 바탕). `image` 를 주면 사진 위에 어둡게 깔고 글자
- `dur`: 장면 길이(초). 기본 big 1.9, line 2.6, number 2.4, list 3.4, CTA 3.4(`ctaDur`)
- `transition`: 그 장면으로 들어오는 전환. 기본은 push → wipe → zoom 순환, CTA는 `ctaTransition`(기본 iris)

## scenes (장면 쌓기)

정해진 상황 없이 장면 블록을 원하는 순서로 쌓아 만드는 영상. `scenes` 의 장면을 차례로 보여 주고 `cta` 로 끝납니다.
장면마다 바탕이 dark → accent → dark → paper 순서로 바뀌고(`scheme` 으로 직접), 전환은 밀어내기·색 막대·확대가 돌아가요(로고 장면과 마지막은 원형).
모든 장면의 큰 글은 `text` 하나에 둡니다. 그래서 종류를 바꿔도 글이 남아요.

```json
{
  "scenes": [
    { "type": "title", "kicker": "2026 하반기", "text": "현장 데이터로\n일하는 법을 바꿔요", "highlight": "바꿔요", "sub": "도입 안내" },
    { "type": "text", "text": "회의는 줄이고\n결정은 빠르게", "highlight": "빠르게" },
    { "type": "photo", "image": "photo1", "layout": "split", "text": "현장에서 바로", "sub": "태블릿 하나면 돼요", "credit": "" },
    { "type": "number", "prefix": "최대", "number": 40, "suffix": "%", "text": "보고서 쓰는 시간이 줄었어요", "sub": "시범 운영 기준" },
    { "type": "list", "text": "이렇게 달라져요", "items": ["자동 수집", "미리 알림", "자동 보고"] },
    { "type": "steps", "text": "도입은 이렇게", "items": ["상담", "연결", "시범 운영", "전체 적용"] },
    { "type": "compare", "text": "도입 전과 후", "leftLabel": "지금까지", "left": "엑셀로 모으고\n주말에 정리", "rightLabel": "이제는", "right": "자동으로 모이고\n바로 알림" },
    { "type": "quote", "text": "현장 사람들이 먼저 쓰고 싶어 한 도구예요", "by": "이름", "role": "직함" },
    { "type": "chart", "text": "연결한 설비", "unit": "대", "bars": [["2024", 410], ["2025", 860], ["2026", 1200]] },
    { "type": "gallery", "text": "함께한 현장", "images": ["photo2", "photo3", "photo4"], "credit": "" },
    { "type": "logo", "text": "데이터로 내일의 품질을" }
  ],
  "cta": { "headline": "우리 공장에 맞는지\n먼저 보여 드릴게요", "button": "도입 문의", "sub": "example.com" },
  "note": "맨 아래 작은 안내 (선택)"
}
```

| type | 이름 | 칸 | 기본 길이 |
|---|---|---|---|
| `title` | 표지 | kicker, text, highlight(색 바꿀 단어), sub, image(바탕 사진) | 2.6초 |
| `text` | 문장 | kicker, text, highlight, sub, size(`big` 단어가 쾅쾅·`line` 형광펜, 비우면 18자 기준 자동), image(바탕) | 1.9 / 2.6초 |
| `photo` | 사진 | image, layout(`split` 사진과 글 나눔, 비우면 가득), text, sub, credit, focus, pan | 2.8초 |
| `number` | 숫자 | kicker, prefix, number(글자도 됨: "1,250"), suffix, text(설명), sub, count(false 면 세지 않음), plain, image(바탕) | 2.4초 |
| `list` | 목록 | kicker, text(제목), items(6개까지) | 2초 + 항목마다 0.45초 |
| `steps` | 단계 | kicker, text(제목), items(5개까지). 9:16·4:5 는 세로, 1:1·16:9 는 가로로 이어짐 | 2초 + 단계마다 0.45초 |
| `compare` | 비교 | kicker, text(제목), leftLabel, left, rightLabel, right. 왼쪽을 비우면 오른쪽만 | 3.4초 |
| `quote` | 인용 | text(실제로 한 말만), highlight, by, role, image(얼굴 사진) | 3.6초 |
| `chart` | 막대 그래프 | kicker, text(제목), unit, bars([이름, 값] 7개까지, 마지막 막대가 강조), sub | 2.4초 + 막대마다 0.2초 |
| `gallery` | 사진 여러 장 | kicker, text(제목), images(4장까지), credit, sub | 2.2초 + 사진마다 0.35초 |
| `logo` | 로고 | text(로고 아래 한 줄), sub. 브랜드 로고 이미지(없으면 logoText)를 강조색 원 위에 | 2.2초 |

- 공통: `scheme`(`dark`·`accent`·`paper`), `dur`(초), `transition`(그 장면으로 들어오는 전환). 전체: `schemes`(바탕 순서), `ctaDur`, `ctaTransition`, `note`, `mascot: false`.
- 사진 칸이 `photo1` 처럼 아직 없는 키면 미리보기에는 빗금 자리가, MP4 에서는 글만 가운데 놓인 장면이 나와요.
- 넘치면 글자 크기를 줄이고, 그래도 크면 장면 전체를 세이프존에 맞게 줄여요.

## deck (발표 자료)

16:9 한 형식. 넘길 때마다 한 장씩 등장하고, 등장이 끝나면 멈춰요(엔진의 발표 플레이어). `content`:

- `title` 발표 제목(바닥글 가운데), `scheme` `dark`|`paper`(비우면 스타일의 첫 바탕), `footer` 바닥글 가운데 글(비우면 title)
- `slides[]` 장마다 `type` 과 칸. 모든 장에 `kicker`(작은 꼬리표)와 `notes`(발표 메모, 화면에 안 나옴)
  - `cover` title, highlight, sub(발표자·날짜) · `closing` title, sub
  - `agenda` title, items[] (10개) · `section` title, sub, number(비우면 01, 02 …)
  - `bullets` title, items[] (7개, "머리말 | 설명"), sub(출처) · `cards` title, items[] (3~6개, "제목 | 설명")
  - `statement` text, highlight, sub
  - `number` title, prefix, number(숫자만), suffix, text, sub, count(false 면 세지 않음), plain(쉼표 없이)
  - `stats` title, stats[[값, 설명]] (4개, "1,240곳" 처럼 값 안 숫자를 셈), sub · `chart` title, unit, bars[[이름, 값]] (8개), sub
  - `compare` title, leftLabel, left, rightLabel, right (줄마다 한 항목) · `steps` title, items[] (5개, "10월 | 설계")
  - `image` image, layout(`split`|`full`), focus, title, text 또는 items, credit · `quote` text, highlight, by, role, image
- 강조색 도형 하나(`#dk-mo`)가 장을 따라 모양을 바꿔요(제목 옆 막대 → 구분 장 전체 → 숫자 아래 줄). 구분 장은 강조색 바탕(스타일이 강조색 바탕을 피하면 글자색 바탕)
- 스타일: 글꼴·색·질감, `scenes.bg`(바탕 무늬·mesh·aurora), `align`(center 면 표지·한 문장·숫자 가운데), `card`, `case`, `weight`, `tracking`,
  `title`(제목 등장 방식), `number`(숫자), `frame`(window·browser·terminal·card·poster 면 화면 전체를 창 안에), `deco`(orb·rings·marks)
- 엔진: 템플릿이 `S.stops`(장마다 등장이 끝나는 시각), `S.stopEnter` 를 정하면 영상 플레이어 대신 발표 플레이어가 떠요. 멈춘 동안 움직이는 배경은 `S.idle(fn)`.
  렌더 모드에서는 `window.__STOPS` 로 장 시각을 알려 줘서 `tools/deck.py pdf|sheet` 가 장마다 찍어요
- PowerPoint: `tools/deck_pptx.py <발표>` 가 장마다 화면의 글·도형·사진 위치와 색을 읽어 진짜 PPT 개체로 옮겨요(바탕은 고해상도 그림 한 장).
  강조 도형은 `!!mo`, 바닥글은 `!!ft-*` 이름이라 모핑 전환으로 이어지고, 글·항목은 장이 열리면 저절로 나타내기+올라오기(막대·선은 닦아내기). 새 장 종류를 더하면 `deck_pptx.py` 의 `TXT`·도형 선택자에도 더해요

## 필름 템플릿 (1:1, 60fps 모션 블러, 120BPM 박자 격자)

세 가지 모두 `content.bpm`(기본 120)에 맞춰 박마다 무언가가 일어나도록 짜여 있습니다. 글자와 사진만 바꾸면 움직임은 그대로 따라옵니다.
렌더 품질은 `templates/<이름>/template.json` 의 `render`(fps 60, blur 4, scale 1.3333 → 1440×1440, loop)이고, video.json 의 `render` 로 덮어쓸 수 있습니다.
사진 키는 video.json `assets` 의 키나 브랜드 `assets` 의 키(마스코트 등)를 씁니다.

### keynote (키노트 필름)

애플 키노트처럼 한 컷으로 이어지는 루프. `film` 으로 두 가지 구성 중 고릅니다.

- 공통: 워드마크가 마침표로 접힘 → 점이 알약 → 라벨 → 6장 조리개 → 사진 원 → 사각형 → 격자가 펼쳐짐(가운데·십자·모서리) → 벤토 → 한 칸을 눌러 확대(드롭에 착지)
- `launch`(54박, 27초): 유리 글자 → 물방울 → 유리 도구 막대 → 슬라이더로 노을빛 재조명 → 렌즈 → 구슬 → 잠금 화면 → 폰 → 아일랜드가 날아가 맥 창 → 사파리에 사진 놓기 → 상품 카드(옵션 색·용량) → 주문하기 → 주문 상태 모프 → 플러드 → 벽의 액자 → 조리개 → 플러드 → 워드마크
- `channel`(40박, 20초): 유리 터미널에 명령이 타이핑 → 줄이 쏟아졌다 접혀 앱 화면 → 맥 창 → 폰 → 채널 페이지 → 구독 → 종 → 알림 → 업로드 상태 모프 → 플러드 → 책상 장면(액자) → 조리개 → 플러드 → 워드마크

주요 항목: `wordmark`(동사 하나가 좋음, 마침표 자동), `label`, `photos`(9장, 격자 순서: 가운데·위·오른쪽·아래·왼쪽·네 모서리), `hero`(확대할 칸 번호, 기본 3),
`glass`{word, next, time, date, song, artist}, `site`{logo, nav, headline, product, price, roasts[[이름,색]], sizes, cta, tab},
`build`{prompt, lines, app{title, sub, items[[이름, 설명, 사진]]}}, `channel`{name, sub, banner, avatar, videos[[제목, 사진]], subscribe, subscribed, notifyTitle, notify},
`states`([{text, icon(check·van·bulb·doc·cut) | percent | route}]), `wall`{photo}, `desk`{photo, mascot}, `credit`(CC BY 출처 줄), `note`(가상 브랜드 표시 등).
예시: `videos/haru-launch-film`, `videos/bax-channel-film`.

### uimorph (UI 모프)

도형 하나가 버튼 → 로더 → 체크 → 다이내믹 아일랜드 → 플레이어(재생·정지 모프, 진행 막대 끌기) → 볼륨 슬라이더(최대를 넘겨 늘어남) → 토글 → 탭 → 차트(툴팁) → ⌘K(타이핑으로 걸러짐) → 토스트 → 버튼으로 돌아오는 14초 루프. 흑백 + 따뜻한 회색.
항목: `button`, `island`, `track`{title, artist, art}, `tabs`, `chart`{label, number, values, tip, tipIndex}, `palette`{placeholder, steps(타이핑 순서), items}, `toast`, `note`. 예시: `videos/haru-ui-morph`.

### showreel (쇼릴)

## typeslam (타이포 쇼)

장점 3개·숫자 기준 17.5초(훅은 꼬리표 0.5초 + 어절마다 0.5초(6어절 이상이면 0.25초) + 정렬 뒤 약 2초를 0.5초 단위로 올림, 장점 하나 2초(공백 빼고 13자 이상 2.5초), 숫자 3초, 사진 장수×0.5초+1초, 끝 4초). 글자 자체가 화면의 전부예요. 꼬리표가 테두리 상자 안에 글리치 타자로 찍히는 동안 첫 어절이 윤곽선으로 다가오고, 제목 어절이 박마다 화면을 꽉 채운 채 잘려 부딪혀 들어옴(가로로 꽉 → 좁게 눌려 위에서 떨어짐(색 반전) → 세로 기둥 또는 크게 잘려 옆에서 → 작게서 커지며 기움, 강조 어절은 화면 전체 강조색) → 정상 크기 문장으로 정렬되고 강조 어절은 강조색 블록으로 반전 → 장점마다 배치를 돌려 씀: 가로 띠(위아래 거대 윤곽 글자 줄이 반대로 흐르고 가운데 문장은 블록 와이프로 드러남) / 세로 스택(폭을 맞춘 눌린 글자가 아래 줄부터 떨어져 쌓이고 둘째 줄은 반전) / 잘린 초대형 한 단어(가장 긴 어절)와 작은 글리치 타자 문장. 네 번째부터는 색을 뒤집어 다시 씀 → 화면 폭을 채우는 큰 숫자가 좁게 뭉쳐 굴러가다 멈추며 제 폭으로 풀리고, 앞말·단위는 위 모서리 꼬리표, 설명은 아래 블록, 출처는 아주 작게 → (사진이 있으면) 박 사이 0.25초 화면 가득 사진 컷과 큰 글자 속을 채운 사진 → 끝 문구가 줄마다 폭을 맞춰 쌓이고 두꺼운 테두리 버튼, 아래 띠에 로고·주소·안내. 마지막 두 박에 화면 색이 뒤집히고 버튼이 꽉 찬 블록이 됨. 9:16·4:5 는 슬램 셋째 어절과 잘린 한 단어가 세로 기둥, 1:1·16:9 는 가로로 크게 잘리고 세로 스택은 2~3줄. 끝 문구가 비면 브랜드 이름이 크게 쌓여요. 어절은 짧게(6자 안쪽) 끊을수록 크게 보여요.

## uidemo (제품 화면 시연)

브랜드 색으로 그린 단순한 앱 화면 안에서 커서가 타자 치고 누르며 카메라가 필요한 곳으로 다가가요(실제 스크린샷은 쓰지 않음). 길이: 훅(title 이 다 쳐진 뒤 0.9초, 최소 2초) + points(보내기 뒤 약 1.3초 + 항목마다 1.3초) + number 약 3.5초 + photos 약 3초(장당 +0.1초) + cta(버튼이 있으면 약 6초, 없으면 약 4초). 예시(항목 3개·숫자·사진 없음) 17.5초, 사진 2장이면 20.5초. 빈 앱 가운데 큰 입력창을 커서가 누르면 테두리가 켜지고 title 이 타자로 쳐진 뒤(기본 type) 보내기를 누름. kicker 는 창 위 탭 → 보낸 글은 말풍선으로 올라가고, 항목 수만큼 뼈대 줄이 반짝이다 강조색 AI 커서가 지나가면 point 로 바뀜. 사람 커서가 항목마다 체크하고 카메라가 그 줄로 다가감 → 메뉴의 그래프 아이콘을 누르면 대시보드가 밀려 들어와 KPI 숫자와 선 그래프, label·source 는 카드 안 작은 글 → 갤러리 아이콘을 누르면 사진이 쌓였다가 칸으로 펼쳐지고 커서가 한 장을 고름 → 깃발 아이콘을 누르면 headline 과 큰 버튼, 버튼을 누르면 체크와 토스트(sub), 카메라가 빠지며 로고·sub·note. 16:9 는 화면 80% 앱 창(위 막대·점 셋·탭, 왼쪽 메뉴), 1:1 은 거의 꽉 찬 앱 창, 9:16·4:5 는 아래가 잘린 큰 폰(9:16 은 세이프존 아래 키보드). 카메라는 초점 대상을 늘 세이프존 안에 둬요.

## sketchbook (손그림 노트)

공통 예시(장점 3개·숫자·사진 없음) 기준 19.5초, 사진 2장이면 22초. 첫 장 3.5~4초 → 체크리스트 2.5초 + 항목마다 약 1.1초 → 숫자 장 4.5~5초 → 사진 장 3초 + 장마다 0.4초 → 마지막 장 5~6초, 장 끝은 0.5초 격자. 브랜드 바탕이 책상이 되고, 위쪽을 스프링으로 묶은 노트(paper/ink)가 살짝 기울어 놓여요(머리줄 두 줄과 모눈, 스타일 scenes.bg 가 lines·dots·none 이면 그 무늬). 강조색 포스트잇(kicker)과 테이프, 제목이 손으로 쓰듯 들어오고(기본 write) 강조 어절에 한 획 동그라미(scenes.marker 를 따름), 화살표와 별 낙서. 사진이 없으면 빈자리에 전구 낙서 → 손 상자 → 체크 → 글이 써지는 체크리스트, 상자 사이 작은 화살표 → 큰 손글씨 숫자(Caveat)가 올라가고 손 타원, 화살표가 label 을 가리키고 source 는 연필 메모 → 위에서 떨어져 기울어 붙는 폴라로이드(테이프·손 테두리) → 마지막 장: 헤드라인이 써지고 button 이 도장처럼 쿵, 로고·sub(밑줄)·note. 한 장을 다 쓰면 그 장이 스프링 위로 넘어가요. 9:16 은 노트가 세이프존 위쪽에서 시작하고 아래 책상에 연필, 4:5·1:1 은 노트가 화면을 거의 채움, 16:9 는 제목 옆 전구·숫자 옆 label·헤드라인 옆 도장. 손글씨 글꼴은 글자 몸이 작아서 실제 크기를 재서 키워요.

## dataflow (데이터 흐름)

항목 3개 + 숫자 기준 17초(훅 3초 · 항목 하나에 1.5초, 마지막 항목 뒤 0.5초 · 숫자 4초 · 끝 5초). 항목 5개면 20초, 숫자를 빼면 4초 짧아져요. 아주 옅은 점 격자 위 가운데 점 하나(N00)가 켜지고 동심원이 퍼진 뒤 카메라가 물러나며 제목이 들어오고 고정폭 꼬리표가 찍힘 → 점에서 가는 선이 뻗어 나가고 머리에 신호 점이 달려, 닿는 곳마다 노드(항목마다 다른 점 무늬, 사진이 있으면 원형 썸네일)와 좌표 꼬리표·이름표가 생기고 카메라가 선을 따라 새 노드로 → 모든 노드에서 선이 빠져나와 한 점으로 모이고, 그 점에서 원형 게이지와 눈금이 그려지며 숫자, 지시선 끝에 label·source(단위가 %면 게이지가 그 비율만큼) → 선이 끝 노드에 닿아 버튼으로 커지고, 카메라가 물러나 흐름도 전체가 한 화면(전체 지도)에 들어오며 지나온 길이 강조색으로 쓸림. 맨 위에 흐름 표시줄(FLOW 02/05)과 카메라 좌표. 9:16·4:5·1:1 은 위→아래 흐름, 16:9 는 왼쪽→오른쪽 흐름에 끝 장면은 왼쪽 지도 · 오른쪽 제목·버튼.

## terminal (레트로 터미널)

장점 3개·숫자·사진 2장 기준 23초. 훅 3.5초 → `check` 장점 하나에 1.25초(4개부터 1초) + 1.25초 → `stat` 숫자 4.5초 → `view` 사진 3초 + 장마다 0.55초(사진이 없으면 `cat` 아스키 로고 약 3초) → `clear` 뒤 마지막 5초 안팎. 체크 무늬 바탕화면에서 점선 사각형이 계단처럼 커지며 터미널 창이 열림(줄무늬 제목 줄 `~/브랜드 — zsh`, tmux 같은 탭 줄) → 부팅 기록 몇 줄 뒤 프롬프트 `>` 에 title 이 크게 타자로(강조 어절은 강조색 상자), `[ OK ] kicker` → `check` 를 치면 장점마다 `[■■■□□□] 60%` 막대가 차고 `✓ 장점` 줄이 찍히며 위로 흐름 → `stat` 을 치면 점 전광판에 숫자와 단위가 픽셀 글꼴 모양 그대로 LED 점으로 켜짐(출처는 `# source:` 주석 줄) → `view 01.bmp …` 를 치면 사진 창이 겹쳐 열리고 브랜드 두 색으로 디더링한 사진이 한 줄씩 그려짐(사진이 없으면 로고 아스키 아트) → `clear` 뒤 큰 글, `> 버튼 █` 이 깜빡이다 눌림, sub·로고·note. 창 바탕은 브랜드 bg 를 따라 어두운 브랜드는 검은 터미널, 밝은 브랜드는 밝은 종이 터미널. 큰 글은 스타일 글꼴이 있으면 그 글꼴, 없으면 갈무리11. 9:16 은 세이프존 아래 칸이 막대 시각화기, 16:9 는 창 오른쪽에 상태판.

## collage (종이 콜라주)

쪽지 3장·숫자·사진 2장 기준 19.5초. 훅 3~4.5초 → 쪽지 하나에 1초(4장 0.85초, 5장 0.75초) + 1.4초 → 숫자 3.5~4초 → 사진 한 장에 0.5초 + 2초 → 마무리 4초 안팎. 화면 전체가 스크랩북 한 쪽이에요. 가장자리가 찢긴 종이판(밑에 다른 색 한 장이 비침, 재단 표시)이 깔리고, 장면이 바뀔 때마다 새 판이 날아와 앞 장면을 덮어요. 꼬리표는 둥근 스티커, 첫 문장은 어절마다 다른 색 종이 띠에 실려 하나씩 탁 붙고(강조 어절은 강조색 종이 + 망점) → 찢긴 쪽지가 테이프·번호 스티커와 함께 날아와 어긋나게 쌓임 → 톱니 원형 스티커가 쾅 붙으며 숫자, 이름은 띠 종이, 출처는 SOURCE 캡션 종이 → 찢은 사진(리소 톤)·폴라로이드·원형 오림·우표가 겹겹이 → 큰 종이 위 마무리 문장, 테이프로 붙인 로고, 알약 스티커 버튼. 미리보기의 빈 사진 칸은 점선, MP4 에서는 색 종이 도형. 판 색 순서는 스타일 scenes.schemes 를 따라요. 9:16·4:5 는 쪽지가 세로 지그재그, 1:1·16:9 는 4개부터 두 줄.

## stage (사물 무대)

장점 3개 · 숫자 기준 18.5초(훅 3.5~4초 · 장점 하나에 2초(4개 이상 1.5초) · 사진 하나에 1~1.5초 · 숫자 4초 · 마무리 4.5초). 바닥과 뒷벽이 둥글게 이어지는 촬영 무대 위로 두께 있는 로고 동전이 돌며 떠올라 자리 잡고(사진이 있으면 첫 사진 카드가 주인공), 유리 알약 꼬리표와 제목이 흐림에서 맺힘 → 항목마다 비눗방울이 떠올라 주인공 둘레 궤도를 타고 앞자리로(지금 읽는 방울만 크고 선명, 지난 방울은 뒤로 돌며 흐려짐), 두 번째 사진부터는 사진 구슬로 → 방울들이 뒤로 모이고 주인공이 동전 던지듯 돌아 앞면에 숫자, 바닥에 동전 기둥, label·source 유리 꼬리표 → 주인공이 로고 면을 보이며 문장·빛이 지나가는 유리 버튼·주소·note. 소품은 깊이만큼 크기·흐림이 다르고 카메라가 천천히 흔들려요. 9:16·4:5·1:1 은 위에 글·아래 주인공, 16:9 는 왼쪽 글·오른쪽 주인공.

## glow (빛과 그라디언트)

장점 3개·숫자·사진 2장 기준 21.5초(사진이 없으면 18초). 훅 3.5~4초 → 장점 0.9초 + 하나에 1.5초 + 0.6초 → 숫자 3.8초 → 사진 0.7초 + 한 장에 0.5초 + 1.6초 → 마무리 4.6초. 깊게 가라앉힌 바탕 위로 흐린 색 덩어리가 흐르고 가운데 작은 빛 구슬이 켜져 동심원이 퍼짐, 꼬리표가 넓은 자간에서 맺히고 제목이 흐림에서 어절마다 맺힘(강조 어절은 흐르는 빛 그라디언트) → 구슬이 원형으로 열려 색 덩어리가 바탕이 되고 유리 알약이 한 줄씩 떠오름(지금 읽는 알약만 밝음) → 색 덩어리가 빛 고리로 오므라들고 숫자가 올라가며 빛띠가 훑음 → 가장자리가 흐린 둥근 창에서 사진이 빛 번짐과 함께 → 빛이 모여 버튼이 되고 테두리를 따라 빛이 돎, 마무리 문장·주소·로고. 바탕이 밝은 브랜드는 흰 바탕에 파스텔 덩어리와 진한 글. 9:16·4:5·1:1 은 구슬이 제목 위, 16:9 는 구슬 왼쪽·제목 오른쪽.

## brandmark (도형으로 짜는 브랜드)

장점 3개·숫자·사진 칸 2개 기준 21초(훅 4~4.5초 · 장점 2초 + 개당 1초 · 숫자 4초 · 사진 3초 + 한 장마다 0.5초, 사진이 없으면 도형 무늬 2.5초 · 로고·CTA 4.5초). 브랜드 바탕에 12칸 격자와 기준선, 재단 표시 → 원·삼각·반원·사각이 선택 상자를 달고 박마다 생겨 베지어 핸들에 당겨지며 모프한 뒤 2×2 브랜드 마크로 모이고, 꼬리표는 격자 칸 라벨, 제목은 줄마다 기준선 아래에서 올라옴 → 12칸 기둥이 덮었다 걷히며 장점 칸이 박마다 와이프로 채워지고 칸 색이 돎 → 사분원 조각이 돌며 큰 고리를 채우고(단위가 %면 그 비율까지) 가운데 숫자 → 정사각 타일 격자에 사진이 원·아치·사분원 마스크로(사진이 없으면 돌고 색이 갈리는 도형 무늬) → 타일이 오그라들고 다시 마크가 됨(로고 이미지가 있으면 이미지로), 로고 락업 · 가로줄 · 헤드라인 · 버튼. 마크는 로고 글자로 고른 도형 조합이라 등록 로고처럼 쓰지 않아요. 9:16·4:5·1:1 은 세로 쌓기, 16:9 는 왼쪽 마크 · 오른쪽 글.

## cinema (시네마틱)

꼬리표·장 3개·숫자·사진 2장 기준 23.5초(훅 5초 · 장마다 3초 · 숫자 4.5초 · 남는 사진 한 장에 1.5초 · 엔딩 5초, 가장 길 때 25.5초). 화면은 늘 어둡고 위아래 레터박스, 약한 비네트와 필름 그레인(스타일 질감이 있으면 그걸 씀). 브랜드 바탕이 밝으면 어두운 짝 색을 따뜻한 회색 쪽으로. 검은 화면에 kicker 가 넓은 자간 고정폭 대문자로 떴다 사라짐 → 첫 사진이 어둠에서 떠오르며 천천히 밀려오고(사진이 없으면 깊은 그라디언트 하늘·빛줄기·먼지 빛) title 이 맺힘 → points 는 장 카드: 이탤릭 세리프 장 번호 '01 / 03' 과 가는 줄, 그 아래 자막. 장마다 사진과 켄번스 방향이 바뀌고(사진이 없으면 동심원·별밭·안개), 장 사이는 블랙 컷과 빛 번짐 → 빛줄기가 바깥으로 빨라지는 초공간 속 큰 세리프 숫자, label 자막, source 각주 → 페이드 투 블랙, 빛을 받으며 로고, headline 자막, 한 붓으로 그어지는 얇은 테두리 버튼, sub·note 엔딩 크레딧. 레터박스는 16:9 가 2.39:1, 9:16 은 아주 얇게.
