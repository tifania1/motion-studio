# 장면 쌓기 — 연출 프롬프트

정해진 상황 템플릿 없이, 장면 블록을 원하는 순서로 쌓아 만드는 영상이에요. 회사·제품·교육·행사·공지 무엇이든 내용에 맞는 장면을 골라 이어 붙여요.

## 형식
- 템플릿: `scenes` (장면 쌓기)
- 비율: 9:16 · 4:5 · 1:1 · 16:9 모두
- 길이: 장면 수와 종류로 정해져요(보통 6~8장면에 18~25초). 앱 연출 탭의 길이 슬라이드로 전체를 늘이고 줄일 수 있어요
- 장면마다 바탕이 dark → accent → dark → paper 순서로 바뀌고, 전환은 밀어내기·색 막대·확대가 돌아가요. 로고 장면과 마지막은 원형으로 열려요

## 장면 블록 (type)
| 종류 | 언제 | 칸 |
|---|---|---|
| title 표지 | 첫 장면. 무엇에 대한 영상인지 | kicker, text, highlight, sub, image(바탕) |
| text 문장 | 훅, 핵심 한 문장. 18자 안쪽이면 단어가 쾅쾅 박히고, 길면 형광펜 | kicker, text, highlight, sub, size(big·line), image(바탕) |
| photo 사진 | 사진 한 장 + 제목. 가득 채우기 또는 나눔(split) | image, layout, text, sub, credit, focus, pan |
| number 숫자 | 근거 있는 숫자 하나 | prefix, number, suffix, text, sub, count, plain |
| list 목록 | 항목 나열(최대 6개) | text, items |
| steps 단계 | 순서·절차(최대 5단계) | text, items |
| compare 비교 | 전과 후, 기존과 새것 | text, leftLabel, left, rightLabel, right |
| quote 인용 | 실제로 한 말 | text, highlight, by, role, image(얼굴) |
| chart 막대 그래프 | 기간별 값(최대 7개) | text, unit, bars[[이름, 값]] |
| gallery 사진 여러 장 | 현장·작품·제품 여러 장(2~4장) | text, images, credit |
| logo 로고 | 브랜드를 크게 한 번 | text, sub |

## 구성 고르는 법
- 첫 장면은 title 이나 짧은 text 로. 첫 2초 안에 무엇에 대한 영상인지 읽혀야 해요.
- 한 장면에 한 메시지. 같은 종류를 세 번 넘게 잇지 않아요.
- 숫자는 number, 순서는 steps, 전후는 compare, 기간별 값은 chart 처럼 내용에 맞는 블록을 골라요.
- 마지막(cta)은 보는 사람이 할 행동 하나: 헤드라인 + 버튼 + 아랫줄(계정·주소).

## 글
- 사람이 실제로 말하듯 자연스러운 한국어. 브랜드 말투(voice)를 따라요. "~가 아닙니다, ~입니다" 같은 대조 구문은 쓰지 않아요.
- 큰 글은 모든 장면에서 text 칸. 줄바꿈은 \n 으로 직접.
- 숫자·수상·고객사·후기는 근거 있는 것만. 인용은 실제로 한 말과 말한 사람의 허락이 있을 때만.

## 사진
- photo·gallery 의 사진 칸에 "photo1" 같은 값이 있으면 아직 빈 자리예요. 사진 탭의 "빈 사진 칸 자동으로 채우기"나 내 사진으로 채워요.
- 미리보기에서는 빈 사진 자리가 빗금으로 보이고, MP4 에서는 사진 없는 장면이 글만 가운데에 놓여요.

## 음악 (구글 Gemini)
- 깔끔한 미니멀 일렉트로닉, 120BPM. 장면이 바뀌는 순간을 박에 맞추려면 음악 탭의 "장면 바뀌는 순간을 박자에 맞추기".

## 확인할 것
- 숫자와 사실 정보의 출처
- 인용은 실제로 한 말인지
- 사진 출처 표시(CC BY 는 화면에 출처 줄)

## 더 나아가려면
- 여기 없는 장면이 필요하면 연출 탭에서 Claude Code에게 맡겨 이 영상만의 장면을 더할 수 있어요
- 아예 다른 연출이면 "영상 추가 → 처음부터 새로 짜기"
