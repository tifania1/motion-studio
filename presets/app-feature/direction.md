# 앱 기능 소개 — 연출 프롬프트

앱이나 웹 서비스의 기능을 모양이 계속 바뀌는(모프) UI 하나로 보여 주는 14초 루프 영상이에요.

## 형식
- 템플릿: `uimorph` (UI 모프 루프)
- 비율: 1:1 / 14초 / 120BPM 7마디(28박) / 60fps 모션 블러 / 끝 프레임 = 첫 프레임
- 흐름: 버튼 → 로더 → 체크 → 아일랜드 → 플레이어 → 볼륨 → 토글 → 탭 → 차트 → ⌘K 검색 → 토스트 → 버튼

## 보는 느낌
흑백과 따뜻한 회색. 도형 하나가 끊기지 않고 계속 모양을 바꿔요. 커서가 누르고 끌고, 카메라가 살짝 다가갔다 물러나요.
애플 키노트의 UI 데모처럼 정갈하게.

## 장면 (박)
1. 0–4박: 버튼을 누르면 로더가 돌고 체크로 바뀌어요.
2. 4–8박: 체크가 위로 올라가 다이내믹 아일랜드가 되고, 펼쳐지며 플레이어가 돼요.
3. 8–14박: 재생·정지 모프, 진행 막대를 끌고, 볼륨을 끝까지 당기면 고무줄처럼 늘어났다 돌아와요.
4. 14–20박: 토글 → 탭(물방울처럼 늘어나며 이동) → 차트에 툴팁.
5. 20–28박: ⌘K 검색창에 글자가 쳐지며 목록이 걸러지고, 엔터 → 토스트 → 처음 버튼으로.

## 움직임
- 스프링만 씀. 앞쪽 끝은 빠르게, 뒤쪽 끝은 따라오게(늘어났다 붙는 느낌).
- 흐림은 글자가 바뀌는 순간에만 짧게.

## 글
- 버튼·토스트·검색어를 내 앱의 실제 기능 이름으로 바꿔요.
- 차트 숫자와 증가율은 실제 데이터만.
- 화면 속 글자는 짧게(버튼 6자, 토스트 12자 안쪽).

## 음악 (구글 Gemini)
- 미니멀 테크 하우스, 깔끔한 킥과 하이햇, 120BPM, 루프로 이어지게
- 마디 첫 박마다 장면이 바뀌어요

## 확인할 것
- 화면 속 기능이 실제로 있는지
- 남의 앱 아이콘·로고를 쓰지 않았는지

## 더 나아가려면
- 내 앱의 실제 화면 색과 글꼴로 바꾸기
- 마지막 토스트 대신 앱 아이콘이 나타나며 다운로드 안내
