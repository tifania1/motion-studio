# 채널 홍보 — 연출 프롬프트

유튜브·인스타 채널을 브랜드 필름처럼 소개하는 20초 루프 영상이에요. 아이디어가 채널이 되기까지의 과정을 한 컷으로 이어 보여 줘요.

## 형식
- 템플릿: `keynote` (`film: channel`)
- 비율: 1:1 / 20초 / 120BPM 40박 / 60fps 모션 블러 / 끝 프레임 = 첫 프레임
- 큰 마디: 0–12박 워드마크 → 사진 격자 → 확대(드롭) / 12–30박 터미널 → 앱 → 맥 → 폰 → 채널 페이지 / 30–40박 상태 모프 → 책상 → 워드마크

## 보는 느낌
애플 키노트 필름. 장면을 자르지 않고, 앞 장면의 물건이 모양을 바꿔 다음 장면이 돼요. 검은 물결(플러드)과 6장 조리개로만 이어요.
리퀴드 글래스, 가는 글자, 박마다 정확히 움직이는 리듬.

## 장면 (박)
1. 0–12박: 채널 이름(워드마크)이 마침표로 접히고 → 알약 라벨 → 조리개 → 사진 원 → 격자가 펼쳐지고 → 한 칸을 눌러 확대(드롭).
2. 12–20박: 유리 터미널에 명령이 쳐지고 줄이 쏟아졌다 접혀 앱 화면이 돼요.
3. 20–30박: 맥 창 → 폰 → 채널 페이지(배너 · 프로필 · 영상 목록), 구독 버튼이 "구독중"으로, 종을 누르면 알림.
4. 30–40박: 업로드 단계(아이디어 · 대본 · 촬영 % · 편집 · 업로드)가 한 칸에서 모프 → 책상 위 액자 → 조리개 → 워드마크.

## 움직임
- 넘침 거의 없는 스프링(감쇠비 0.8 이상), 카메라는 부드럽게.
- 바운스·파티클·빛 번짐 금지. 모든 전환은 모프·플러드·조리개.

## 글
- 워드마크는 영어 한 단어가 가장 예뻐요 (마침표 자동).
- 터미널 명령과 줄은 채널 기획 메모처럼 (실제 영상 제목·장소).
- 채널 이름·소개·영상 제목은 실제 채널과 같게.

## 사진
격자 9장(가운데·위·오른쪽·아래·왼쪽·모서리 넷 순서), 채널 배너, 프로필, 영상 썸네일 4장, 책상 장면 1장. 브랜드 마스코트가 있으면 책상 위에.

## 음악 (구글 Gemini)
