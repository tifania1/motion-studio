# 도형으로 짜는 브랜드 — 연출 프롬프트

브랜드 아이덴티티를 처음 공개하는 영상처럼 보이게 하는 결이에요. 스위스 그래픽 포스터처럼 12칸 격자 위에서 원·사각·반원·사분원·삼각 도형이 짜 맞춰지고, 색면이 박마다 갈리다가 마지막에 로고 락업이 완성돼요.
새 기능 소개, 리브랜딩, 서비스 런칭, 디자인·크리에이티브 브랜드 홍보에 잘 맞아요. 문구 칸은 다른 결 템플릿과 같아서, 문구는 그대로 두고 템플릿만 바꿔도 돼요.

## 형식
- 템플릿: `brandmark` (도형으로 짜는 브랜드)
- 비율: 9:16 · 4:5 · 1:1 · 16:9 / 120BPM, 사건은 0.5초 단위
- 기본 스타일: `handle-shapes-merge` (연출 탭에서 바꿀 수 있어요. 짝이 좋은 스타일: `cutout-bloom-recolor`, `spray-stipple-fields`, `serif-handles-editorial`, `stripe-contour-coins`)
- 길이는 항목 수로 정해져요. 예시(장점 3개, 숫자 있음, 사진 칸 2개) 기준 21초
  - 훅 4초(제목이 세 줄이면 4.5초) → 장점 2초 + 개당 1초 → 숫자 4초 → 사진 3초 + 한 장 더할 때마다 0.5초(사진 칸이 없으면 도형 무늬 2.5초) → 로고·CTA 4.5초
  - `points` 가 비면 장점 장면이, `number.value` 가 비면 숫자 장면이 통째로 빠져요. 훅과 로고·CTA 는 늘 있어요.

## 보는 느낌
브랜드 바탕색 위에 아주 옅은 12칸 세로 격자와 가로 기준선이 깔리고, 글자 영역 네 모서리 밖에 재단 표시, 오른쪽 아래 여백에 색 막대(브랜드 색 견본)가 있어요. 브랜드 가이드북 한 장을 보는 느낌이에요.
도형은 그림자 없이 평평한 면이에요. 색은 강조색·글자색·종이색과 그 사이 색만 쓰고, 스타일 색을 켜면 스타일 팔레트의 다른 색(--pal1~3)까지 들어와 훨씬 다채로워져요.
이 영상의 핵심 소품은 편집 프로그램의 선택 상자예요. 도형이 생길 때마다 네 모서리에 작은 흰 네모 손잡이가 달린 상자가 붙고, 베지어 핸들(기준점 + 양쪽 손잡이 선)이 도형 가장자리를 당기며 모양을 바꿔요.

## 장면
1. 훅 (0–4초): 격자 선이 위에서 내려 그어지고 재단 표시가 켜져요. 도형 네 개(원·삼각·반원·사각)가 한 박 간격으로 톡 생기며 선택 상자를 달고 천천히 돌아요. 오른쪽 칸에는 꼬리표 칸(`kicker`, 윗선이 그어지고 작은 네모 + 글, 오른쪽에 01 / 05 같은 쪽 번호)이 들어와요. 0.75초에 제목(`title`)이 줄마다 기준선 아래에서 올라오고, 줄 밑에 가로 기준선이 그어져요. 강조 어절(`highlight`)은 강조색. 1초쯤 베지어 핸들이 원과 반원의 가장자리를 당기며 네 도형이 마크 모양으로 모프하고, 1.7초에 한가운데로 모여 2×2 브랜드 마크가 돼요. 다 모이면 마크 둘레에 큰 선택 상자 하나와 가장자리 기준선이 화면 끝까지 그어졌다 사라져요.
   - 마크 모양은 브랜드 로고 글자로 정해져서 같은 브랜드는 늘 같은 마크가 나와요(네 가지 중 하나).
2. 장점: 격자 칸이 항목마다 하나씩, 박에 맞춰 와이프로 채워져요. 칸마다 색면 + 도형 아이콘 + 글(`points`) + 01 / 03 번호. 새 칸이 들어올 때마다 앞 칸들의 색이 한 칸씩 돌아가며 갈리고(강조색 → 종이색 → 옅은 바탕색), 다 들어온 뒤 두 박 더 갈려요. 아이콘은 색이 갈릴 때마다 90도 돌고, 들어오는 칸의 아이콘엔 잠깐 선택 상자가 붙어요. 9:16·4:5·1:1 은 세로로 쌓고, 16:9 는 가로로 나란히.
3. 숫자: 가로·세로 기준선이 원 가운데를 지나 그어지고 원 둘레에 선택 상자가 생겨요. 사분원 조각 네 개가 위에서부터 시계 방향으로 돌며 큰 고리를 채우고, 채워지는 앞끝에 베지어 핸들이 따라가요. 고리 가운데에서 숫자가 올라가고(`number.prefix` 는 위에 작게, `suffix` 는 강조색으로 옆에), 아래(16:9 는 오른쪽)에 `label` 이 줄마다 올라오고 `source` 가 SOURCE 꼬리표와 함께 작게. 단위가 %(1~100)면 고리는 그 비율까지만 차요.
4. 사진·무늬: 정사각 타일 격자(9:16·1:1 은 3×3, 4:5 는 3×4, 16:9 는 5×3)가 가운데부터 바깥으로 번지며 채워져요. 사진(`photos`)은 가운데부터 서로 먼 자리에 원·아치·사분원·잎 마스크로 끼워지고, 마스크가 박마다 다음 모양으로 바뀌어요. 나머지 타일은 색면 위 도형이고, 박마다 반은 90도 돌고 반은 색이 와이프로 갈려요. 사진이 없으면 전부 도형 무늬예요. 미리보기에서는 빈 사진 칸이 점선 상자(PHOTO 1)로 보여요.
5. 로고·CTA (마지막 4.5초): 타일이 오그라들며 사라지고, 마크 자리에서 가까운 타일 네 개의 도형이 날아와 마크로 다시 짜여요. 로고 이미지가 있으면 마크 조각이 가운데로 빨려 들며 원형으로 열리는 로고 이미지가 돼요. 옆에 로고 글자(logoText)와 아랫줄(logoSub)이 올라오고, 가로줄이 그어진 뒤 `cta.headline` 이 줄마다 올라와요. 버튼(`cta.button`)은 강조색 면이 와이프로 채워지며 선택 상자가 한 번 붙었다 사라지고, `cta.sub` 는 버튼 오른쪽(좁으면 아래), `note` 는 맨 아래 작게. 16:9 는 왼쪽에 큰 마크와 로고, 가운데 세로줄, 오른쪽에 가로줄·헤드라인·버튼.
- 장면 사이(훅 → 장점 → 숫자 → 사진)는 격자 12칸 기둥이 차례로 내려와 화면을 덮었다가 걷혀요. 마지막 사진 → 로고만 타일이 모여 마크가 되는 모프로 이어져요.

## 움직임
- 옮기기·와이프는 정확한 inOut 이징(power3·expo). 도형 모프는 아주 조금 넘치는 스프링(감쇠비 0.78)이에요. 들어오는 이징과 간격은 고른 스타일을 따라가요.
- 선택 상자·베지어 핸들·기준선은 그 장면에서만 그어졌다 사라져요. 오래 남기지 않아요.
- 큰 글이 들어오는 방식은 기본이 '줄마다 선 아래에서'(mask)이고, 스타일의 `scenes.title`(타자·흐림·톡 등)이 있으면 그걸 따라요. 숫자도 스타일의 `scenes.number`(주행거리계 등)를 따라요.
- 손그림, 터미널, 사진 콜라주, 빛 구슬, 앱 화면, 화면을 꽉 채우는 큰 글자는 쓰지 않아요.

## 글
- 사람이 말하듯 담백하게, 브랜드 말투(해요체 등)를 따라요. "~가 아닙니다, ~입니다" 같은 대조 구문은 쓰지 않아요.
- `kicker`: 꼬리표 칸에 들어가는 짧은 말(14자 안쪽). 비우면 꼬리표 칸이 빠져요.
- `title`: 훅 문장. 24자 안쪽, `\n` 으로 2줄이 가장 보기 좋아요(3줄까지). `highlight` 는 제목 안에 그대로 있는 어절.
- `points`: 2~5개, 하나에 18자 안쪽. 16:9 는 칸이 좁아서 두세 줄로 접혀요.
- `number`: `{prefix, value, suffix, label, source}`. value 는 숫자만("4.8"처럼 소수도 돼요). source 에 근거와 기준 시점을 꼭 적어요.
- `photos`: 0~4장. 원·아치 마스크에 들어가니 주제가 가운데 있는 사진이 좋아요.
- `cta`: `headline`(두 줄 안쪽), `button`(10자 안쪽), `sub`(주소·계정). 비운 칸은 빠져요.
- `note`: 맨 끝 작은 안내 (가상 브랜드 표시, "광고" 표시, 기준일 등).
- 예시 문구의 example.com, "예시 수치", "템플릿 예시용 가상 서비스입니다"는 실제 영상에서 하나도 남지 않게 바꿔요.

## 음악 (구글 Gemini)
- 미니멀한 디자인 일렉트로닉, 박마다 또각거리는 클릭·우드블록, 깔끔한 서브 베이스, 120BPM
- 0–4초는 도형이 생길 때마다 클릭만, 제목 앞에 짧은 상승음 → 장점·숫자에서 색이 갈릴 때마다 작은 강세 → 타일이 모여 로고가 될 때 깔끔한 마지막 한 방

## 확인할 것
- 숫자 옆 출처(`number.source`)가 실제 근거와 기준 시점을 담고 있는지. 근거 없는 숫자는 넣지 않아요
- "최고·1위·최초·유일" 같은 말은 근거 자료가 있을 때만
- 로고 이미지는 배경이 투명한 PNG 가 좋아요(마크가 원형으로 열리며 이미지가 돼요)
- 사진 사용 허락과 출처 (직접 찍은 사진, CC0, CC BY 는 출처 표시)
- 9:16 에서 꼬리표·제목·버튼이 세이프존 안에 있는지 (`render.py <영상> tall sheet --safe`)
- 마크 도형은 템플릿이 만든 모양이에요. 실제 등록 로고처럼 쓰지 말고, 로고 이미지가 있으면 그걸 넣어요

## 더 나아가려면
- 마크 모양을 브랜드 로고에서 뽑은 도형으로 바꾸기 (MARKS 에 모양·색 조합 추가)
- 장점 칸마다 실제 아이콘 이미지를 도형 대신 넣는 버전
- 마지막에 마크·글자·색 견본이 한 장에 정리되는 브랜드 가이드 페이지 컷
