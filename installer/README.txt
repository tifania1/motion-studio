모션 스튜디오 설치 안내
========================

여러 광고 계정의 짧은 광고 영상을 모션 그래픽으로 만드는 작업 폴더와 Claude Code(Opus 5.5)를 설치합니다.

1. 이 압축 파일을 원하는 곳에 풉니다 (압축 안에서 바로 실행하면 안 돼요).
   GitHub 에서 Code → Download ZIP 으로 받았다면, 풀린 폴더 안 installer 폴더에서 Install_MotionStudio.cmd 를 실행하면 돼요.
2. 풀린 폴더에서 Install_MotionStudio.cmd 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
3. 질문이 나오면 Enter(=기본값)로 진행하면 됩니다. 처음 설치는 10~20분 정도 걸려요.

설치되는 것
- Claude Code (Anthropic 공식 설치 스크립트)
- Git for Windows (선택)
- Python 3.12, ffmpeg (winget)
- 렌더링용 파이썬 패키지와 크로미움, (선택) 배경 지우기 도구
- 스튜디오 폴더: 문서\motion-studio
- Claude Code 기본 모델: Opus 5.5 (claude-opus-5-5)
- 바탕화면 바로가기 두 개
    "모션 스튜디오": 화면으로 쓰는 앱 (계정·문구·사진·미리보기·MP4 만들기)
    "모션 스튜디오 (Claude Code)": 말로 시키는 Claude Code

- (선택) 구글 Gemini API 키: 앱의 "음악 만들기"를 자동으로 쓸 때만. 이 PC의 사용자 폴더(.motion-studio)에만 저장돼요.
  키가 없어도 Gemini 앱(gemini.google.com)에서 무료로 만든 곡을 앱에 끌어다 놓으면 박자를 맞춰 넣어 줘요.

이번 버전에서 새로 생긴 것
- 자동 업데이트: 앱을 켤 때마다 GitHub에서 새 버전이 있는지 보고, 있으면 받아서 바꾼 뒤 "새 버전으로 업데이트했어요" 창으로
  바뀐 점을 알려 줘요. 바꾸기 전에 백업하고, 새 버전에서 앱이 안 켜지면 저절로 이전 버전으로 되돌려요.
  내 영상·광고 계정·결과물·API 키는 건드리지 않아요. Git과 이 PC의 GitHub 로그인이 있어야 하고, 인터넷이 없으면 그냥 지금 버전으로 켜져요.
  끄려면 사용자 폴더 .motion-studio\update 안에 off 라는 이름의 빈 파일을 만들면 돼요.
- 발표 자료: 계정 아래 "발표 자료 추가"로 넘길 때마다 한 장씩 모션으로 등장하는 16:9 발표 자료를 만들어요.
  무슨 발표인지 적고, 가진 자료(PPTX·PDF·DOCX·HWPX·TXT)가 있으면 같이 넣으면 Claude가 그 내용으로 장 구성과 화면 글,
  발표 메모까지 짜요. 표지·목차·구분·글머리·카드·한 문장·숫자·숫자 여러 개·막대 그래프·비교·단계·사진·인용·마무리 장이 있고,
  강조색 도형 하나가 장을 따라다니며 제목 옆 막대 → 구분 장 전체 화면 → 숫자 아래 줄로 모양을 바꿔요.
  스타일 180가지를 그대로 고를 수 있어요(글꼴·색·바탕·카드 모양·큰 글 등장 방식이 따라가요).
  "발표 시작"을 누르면 브라우저로 열려요. 클리커(PageDown·PageUp), 방향키·스페이스·Enter로 넘기고, F5는 전체 화면,
  B나 . 은 검은 화면, W나 , 는 흰 화면, 숫자+Enter는 그 장으로 가요. 넘기는 중에 누른 키도 빠뜨리지 않고 차례로 처리해요.
  "PPT 만들기"는 PowerPoint 파일로 내보내요. 글과 도형이 진짜 PowerPoint 개체라 바로 고칠 수 있고, 장이 열리면 글과 항목이
  차례로 들어오는 애니메이션, 장 사이에 강조 도형이 모양을 바꾸는 모핑 전환, 발표 메모(슬라이드 노트)까지 들어가요.
  이 PC 에 있는 글꼴을 파일 안에 넣어서 다른 PC 에서도 같은 글꼴로 보여요.
  "PDF"는 장마다 등장이 끝난 화면을 고해상도로 모아 나눠 줄 PDF를 만들어요. 발표 화면은 인터넷 없이도 열리는 HTML 파일 하나예요.
- AI 계정: 오른쪽 위 "AI 계정"에서 Claude API 키와 Gemini API 키를 여러 개 저장해 두고, 누르기 한 번으로 쓸 계정을 바꿔요.
  Claude 기능을 "Claude Code 로그인(구독)"으로 돌릴지 "Claude API 키"로 돌릴지 고를 수 있어요. API로 두면 문구·구성 맡기기,
  업로드 글, 사진 검색어가 고른 키로 바로 돌아가고 "Claude Code 열기"도 그 키로 열려요. 작업이 끝나면 쓴 토큰과 대략의 요금이 남아요.
  키가 살아 있는지 "확인"으로 볼 수 있고(요금 없음), 키는 이 PC 사용자 폴더에만 암호화해서 저장돼요.
  API로 두면 모든 작업이 API로 돌아요. Claude Code 창 대신 앱 안 "Claude에게 부탁하기 (API)"에서 Claude가 파일을 읽고 고치고,
  빌드와 장면 모음까지 직접 보고 확인해요. 대화를 이어서 부탁할 수 있고, 부탁 한 번 예산(기본 3달러)을 넘으면 멈춰요.
  구독으로 두면 모든 작업이 이 PC의 Claude Code 로그인으로 돌아요.
- 사진 자동 찾기에 검토가 붙었어요. Claude가 후보 사진을 직접 보고 이 광고의 주제·상황과 어울리는지 점수와 이유를 달아 순서대로 놓고,
  어울리지 않는 사진은 흐리게 보여 줘요. 맞는 사진이 없는 칸은 검색어를 바꿔 한 번 더 찾아요.
- 결 템플릿 10개: 같은 문구로 화면이 통째로 다른 영상을 만들어요. 타이포 쇼, 제품 화면 시연, 손그림 노트, 데이터 흐름,
  레트로 터미널, 종이 콜라주, 사물 무대, 빛과 그라디언트, 도형으로 짜는 브랜드, 시네마틱.
  "영상 추가 → 결로 고르기"에서 고르면 어울리는 스타일까지 들어가고, 연출 탭의 "결 바꾸기"를 누르면
  문구와 사진은 그대로 둔 채 다른 결로 바로 바꿔 볼 수 있어요.
- 스타일 180가지: keyframe.gallery 의 모션 그래픽에서 배운 175가지와 직접 정리한 손그림 5가지(손그림은 모두 13가지).
  타이포·제품 UI·손그림·다이어그램·레트로·콜라주·3D 사물·빛·도형·시네마틱 열 묶음으로 나뉘어 있어요.
  영상의 연출 탭 → "스타일 고르기"에서 썸네일을 보고 고르면 종이·그레인·선 떨림 같은 질감, 글꼴, 전환 빠르기가 바뀌어요.
  결 템플릿과 장면 쌓기 영상은 큰 글이 들어오는 방식(타자·슬롯·흐림·도장·손글씨)과 숫자가 바뀌는 방식(굴러가는 숫자 등)까지
  스타일을 따라가요. 브랜드 색은 그대로 두고, "스타일 색"을 켜면 스타일 색으로 바뀌어요. Claude에게 맡길 때도 스타일 카드가 같이 가요.
- 글꼴 8개: 손글씨(나눔손글씨 펜·붓, 개구, Caveat), 세리프(고운바탕, Instrument Serif), 픽셀(갈무리11, Silkscreen).
- Claude Code 에서 /new-style 로 새 스타일을 정리해 넣을 수 있어요.
- 템플릿 없이 직접 만들기 두 가지 ("영상 추가" 아래 '직접 만들기' 줄):
  · 장면 쌓기: 표지·문장·사진·숫자·목록·단계·비교·인용·막대 그래프·사진 여러 장·로고 장면을
    원하는 순서로 쌓아요. 문구 탭에서 장면을 더하고, 옮기고, 종류를 바꿀 수 있어요.
    무엇을 알릴지 적고 "Claude에게 구성·문구 맡기기"를 누르면 장면 구성과 문구까지 짜 줘요.
  · 처음부터 새로 짜기: 원하는 영상을 글로 적으면 Claude Code가 그 영상만의 연출을 처음부터 짜요.
    다 짜면 문구 탭에서 글을 고칠 수 있어요.
- 기업용 템플릿 4개: 회사 소개(설계도 → 명함), 제품·서비스 소개(엉킨 선이 펴져 제품 창으로),
  연혁·마일스톤(연도 자 위로 연도가 굴러감), 소식 발표(업무협약·투자·수상·인증·출시를 뉴스 화면처럼).
  예시 계정 "루멘타 (가상 기업)"에 예시 영상이 들어 있어요.
- 문구 탭에서 이정표·하는 일·사실 줄 같은 목록에 줄을 더하고, 옮기고, 뺄 수 있어요.
- 영상 추가 창에서 템플릿 고르기 칸이 늘 보이던 문제를 고쳤어요.
- 오류에 강해졌어요: 배경 지우기 AI 도구가 PC에서 멈추면 단순 방식으로 대신 지우고, 인터넷·파일 잠김·깨진 설정 파일·
  아이폰 HEIC 사진 같은 경우엔 무엇을 하면 되는지 한국어로 알려 줘요. 렌더용 크로미움이 없으면 자동으로 설치해요.
- 앱 창을 내려 두거나 다른 창에 가려 있어도 앱이 저절로 꺼지지 않아요.
- MP4 만들기를 중간에 취소해도 만들어 둔 영상이 망가지지 않아요.
- 새 버전을 설치할 때 켜져 있던 예전 앱을 끄고, 앱을 열 때도 예전 버전이 떠 있으면 새 버전으로 바꿔 켜요.
- 파이썬 3.10·3.11 PC에서 미리보기를 만들 때 나던 오류(f-string ... backslash)를 고쳤어요.
- Claude Code에 로그인이 안 된 PC에서는 알아보기 쉬운 안내가 떠요 (Claude Code 열기 → /login).
- 앱 화면이 비어 있고 서버에 연결하지 못하면 안내 화면이 떠요. 원인을 보려면 StudioApp_debug.cmd 를 실행하세요.
- 영상 탭이 작업 순서대로 바뀌었어요: 1 문구 → 2 사진 → 3 음악 → 4 연출 → 5 올리기 (끝난 단계엔 체크).
- 연출 탭 맨 위에서 슬라이드로 영상 길이를 맞출 수 있어요 (15초·20초 버튼도 있어요).
- 올리기 탭에서 MP4가 없으면 바로 MP4 만들기를 누를 수 있어요.
- 맡기기 전에 Claude 모델(Opus·Sonnet·Haiku)과 노력 정도(낮음~최대)를 고를 수 있어요.
- Claude 답에 형식이 안 맞으면 한 번 더 자동으로 부탁해요("JSON을 찾지 못했습니다" 오류 줄임).
- 왼쪽 목록에서 광고 계정을 접고 펼 수 있어요. "모두 접기"로 한 번에 접혀요.
- 앱의 "올리기" 탭: 유튜브 제목·설명, 인스타 캡션, 해시태그(Claude에게 맡기기 가능)와
  플랫폼별 영상·커버·체크리스트를 모은 업로드 안내 묶음. 유튜브는 채널을 연결하면 앱에서 바로 올려요.
  준비 순서는 문서\motion-studio\docs\UPLOAD.md 에 있어요.
- 설치 파일을 스튜디오 폴더 안에서 다시 만들 수 있어요 (python tools\make_installer.py).
- 상황 프리셋 12개: 신메뉴 출시, 세일, 매장 오픈, 시즌 인사, 수강생 모집, 행사 안내, 채용,
  앱 기능 소개, 공지, 채널 홍보, 여행 하이라이트, 숫자로 보는 성과.
  앱의 "영상 추가"에서 상황을 고르면 템플릿·예시 문구·형식·길이·음악 분위기가 한 번에 들어가요.
- 상황마다 화면 구성이 따로 있는 새 템플릿 10개 (메뉴 접시, 세일 띠, 셔터와 지도, 편지 봉투, 노트,
  티켓, 메신저, 출발 안내판, 여행 지도, 대시보드). 썸네일만 봐도 어떤 영상인지 구분돼요.
- 영상마다 연출 프롬프트(direction.md)가 함께 생겨요. 앱의 "연출 프롬프트"에서 보고 고칠 수 있고,
  "Claude Code에게 이 연출로 맡기기"를 누르면 그 내용대로 Claude Code가 이어서 작업해요.
- "빈 사진 칸 자동으로 채우기"가 사진이 들어가는 모든 템플릿에서 돼요.
- 1:1 필름 템플릿 세 가지(키노트 필름, UI 모프 루프, 15초 쇼릴), 음악 만들기(구글 Gemini),
  60fps 모션 블러 렌더, 프레임 튐 검사는 지난 버전에서 이어져요.

설치가 끝나면 먼저 "모션 스튜디오 (Claude Code)"를 열고 Claude 계정(Pro·Max·Team·Enterprise)으로
로그인하세요. 앱의 "Claude에게 문구 맡기기"도 이 로그인을 씁니다.
평소에는 "모션 스튜디오" 앱으로 작업하고, 화면으로 안 되는 연출은 앱의 "Claude Code 열기"로 부탁하면 돼요.

Claude Code에서는 이렇게 시작할 수 있어요.
  /new-brand   광고 계정(브랜드) 추가
  /new-ad      광고 영상 만들기
  /ad-review   올리기 전 검수
  /render-mp4  업로드용 MP4 뽑기
  /music       배경음악 넣기
자세한 내용은 문서\motion-studio\README.md 에 있어요.

나중에 새 버전을 받으면 같은 방법으로 다시 실행하세요. 만들어 둔 브랜드와 영상은 그대로 두고
엔진·템플릿·도구만 바꾸며, 바꾸기 전에 전체를 백업합니다.

예전에 설치한 문서\bax-motion 폴더는 그대로 둬도 되고, 지워도 됩니다.
Bax 방콕 60초 영상은 스튜디오 안 videos\bax-bangkok 에 같이 들어 있어요.

무엇이 설치될지만 먼저 보고 싶으면, 이 폴더에서 PowerShell을 열고:
  powershell -ExecutionPolicy Bypass -File .\install.ps1 -DryRun
